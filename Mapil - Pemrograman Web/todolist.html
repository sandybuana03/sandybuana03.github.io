Membuat Struktur HTML

Langkah pertama: Membangun kerangka aplikasi

1 Buat File HTML Baru

Buat file baru dengan nama todo-list.html dan ketik kode berikut:

📄 todo-list.html
<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title> My To-Do List App </title> </head> <body> <div class="container"> <h1> 📝 My To-Do List </h1> <!-- Form untuk menambah tugas --> <form id="todoForm"> <input type="text" id="taskInput" placeholder="Masukkan tugas baru..."> <button type="submit"> Tambah Tugas </button> </form> <!-- Daftar tugas --> <ul id="todoList"> </ul> </div> </body> </html>

2 Penjelasan Struktur HTML

Mari kita pahami setiap bagian dari kode HTML di atas:

  • <div class="container"> - Wadah utama untuk semua elemen
  • <h1> - Judul aplikasi dengan emoji 📝
  • <form id="todoForm"> - Form untuk menambah tugas baru
  • <input id="taskInput"> - Input field untuk mengetik tugas
  • <button type="submit"> - Tombol untuk menambah tugas
  • <ul id="todoList"> - Daftar yang akan menampilkan semua tugas

3 Coba Buka di Browser

Simpan file dan buka di browser. Kamu akan melihat struktur dasar yang masih polos tanpa styling. Jangan khawatir, kita akan memperindahnya di langkah selanjutnya!

JavaScript Dasar

Membuat aplikasi menjadi interaktif

1 Tambahkan JavaScript

Tambahkan kode JavaScript berikut sebelum tag </body>:

⚡ JavaScript Dasar (tambahkan sebelum </body>)
<script> // Array untuk menyimpan semua tugas let todos = []; // Ambil elemen-elemen HTML yang dibutuhkan const todoForm = document.getElementById('todoForm'); const taskInput = document.getElementById('taskInput'); const todoList = document.getElementById('todoList'); // Fungsi untuk membuat ID unik function generateId() { return Date.now() .toString(36) + Math.random() .toString(36) .substr(2); } // Fungsi untuk menambah tugas baru function addTodo(taskText) { const newTodo = { id: generateId(), text: taskText, completed: false, createdAt: new Date() }; todos.push(newTodo); renderTodos(); saveTodos(); } // Event listener untuk form submit todoForm.addEventListener( 'submit', function(e) { // Mencegah refresh halaman e.preventDefault(); const taskText = taskInput.value.trim(); if (taskText !== '') { addTodo(taskText); // Kosongkan input taskInput.value = ''; } } ); // Fungsi sementara untuk render dan save // (akan kita lengkapi nanti) function renderTodos() { console.log('Todos:', todos); } function saveTodos() { console.log('Saving todos...'); } </script>

2 Penjelasan Kode JavaScript

Mari kita pahami setiap bagian dari kode JavaScript:

  • let todos = [] - Array untuk menyimpan semua tugas
  • document.getElementById() - Mengambil elemen HTML berdasarkan ID
  • generateId() - Membuat ID unik untuk setiap tugas
  • addTodo() - Fungsi untuk menambah tugas baru ke array
  • addEventListener() - Mendengarkan event submit pada form
  • e.preventDefault() - Mencegah halaman refresh saat submit

CRUD Operations

Create, Read, Update, Delete - Operasi lengkap untuk tugas

1 Fungsi Render Todos (READ)

Ganti fungsi renderTodos() yang kosong dengan kode berikut:

📖 Fungsi Render (READ) - Ganti fungsi renderTodos()
function renderTodos() { // Kosongkan daftar terlebih dahulu todoList.innerHTML = ''; // Loop melalui semua todos todos.forEach(function(todo) { // Buat elemen li untuk setiap todo const li = document.createElement('li'); li.className = 'todo-item' + (todo.completed ? ' completed' : ''); li.innerHTML = ` <span class="todo-text"> ${todo.text} </span> <div class="todo-buttons"> <button class="complete-btn" onclick="toggleComplete('${todo.id}')"> ${todo.completed ? '↩️ Batal' : '✅ Selesai'} </button> <button class="delete-btn" onclick="deleteTodo('${todo.id}')"> 🗑️ Hapus </button> </div> `; // Tambahkan ke daftar todoList.appendChild(li); }); // Tampilkan pesan jika tidak ada tugas if (todos.length === 0) { todoList.innerHTML = '<li style="text-align: center; color: #888; padding: 20px;">' + 'Belum ada tugas. Yuk tambah tugas pertama! 🎯</li>'; } }

2 Fungsi Toggle Complete (UPDATE)

Tambahkan fungsi untuk menandai tugas sebagai selesai atau belum:

✏️ Fungsi Update - Tambahkan setelah fungsi renderTodos()
// Fungsi untuk toggle status completed function toggleComplete(id) { // Cari todo berdasarkan ID const todoIndex = todos.findIndex( todo => todo.id === id ); if (todoIndex !== -1) { // Toggle status completed todos[todoIndex].completed = !todos[todoIndex].completed; // Render ulang dan simpan renderTodos(); saveTodos(); } }

3 Fungsi Delete Todo (DELETE)

Tambahkan fungsi untuk menghapus tugas:

🗑️ Fungsi Delete - Tambahkan setelah fungsi toggleComplete()
// Fungsi untuk menghapus todo function deleteTodo(id) { // Konfirmasi sebelum menghapus if (confirm( 'Apakah kamu yakin ingin menghapus tugas ini?' )) { // Filter array untuk menghapus todo dengan ID tertentu todos = todos.filter( todo => todo.id !== id ); // Render ulang dan simpan renderTodos(); saveTodos(); } }

Local Storage

Menyimpan data secara permanen di browser

1 Fungsi Save ke Local Storage

Ganti fungsi saveTodos() yang kosong dengan kode berikut:

💾 Fungsi Save - Ganti fungsi saveTodos()
// Fungsi untuk menyimpan todos ke localStorage function saveTodos() { try { // Konversi array todos ke JSON string const todosJSON = JSON.stringify(todos); // Simpan ke localStorage dengan key 'myTodos' localStorage.setItem( 'myTodos', todosJSON ); console.log('✅ Data berhasil disimpan!'); } catch (error) { console.error( '❌ Gagal menyimpan data:', error ); } }

2 Fungsi Load dari Local Storage

Tambahkan fungsi untuk memuat data saat halaman dibuka:

📂 Fungsi Load - Tambahkan setelah fungsi saveTodos()
// Fungsi untuk memuat todos dari localStorage function loadTodos() { try { // Ambil data dari localStorage const savedTodos = localStorage.getItem('myTodos'); if (savedTodos) { // Parse JSON string kembali ke array todos = JSON.parse(savedTodos); console.log( '📂 Data berhasil dimuat!', todos ); } else { console.log( '📝 Belum ada data tersimpan, memulai dengan array kosong' ); } // Render todos yang sudah dimuat renderTodos(); } catch (error) { console.error( '❌ Gagal memuat data:', error ); todos = []; // Reset ke array kosong jika error renderTodos(); } }

3 Panggil loadTodos() saat Halaman Dimuat

Tambahkan kode berikut di akhir script untuk memuat data saat halaman dibuka:

🚀 Inisialisasi - Tambahkan di akhir script sebelum </script>
// Muat data saat halaman pertama kali dibuka document.addEventListener( 'DOMContentLoaded', function() { console.log( '🎯 Aplikasi To-Do List dimuat!' ); loadTodos(); } );

Validasi Form

Memastikan input pengguna valid dan aman

1 CSS untuk Error Message

Tambahkan CSS untuk styling error message di dalam tag <style>:

❌ CSS Error Styling - Tambahkan di <style>
/* Styling untuk error message */ .error-message { background: linear-gradient( 135deg, #ff6b6b, #ee5a52 ); color: white; padding: 12px 20px; border-radius: 8px; margin: 10px 0; font-size: 0.9rem; display: flex; align-items: center; gap: 10px; animation: shake 0.5s ease-in-out; } /* Animasi shake untuk error */ @keyframes shake { 0%, 100% { transform: translateX(0); } 10%, 30%, 50%, 70%, 90% { transform: translateX(-5px); } 20%, 40%, 60%, 80% { transform: translateX(5px); } } /* Input error state */ .input-error { border-color: #ff6b6b !important; box-shadow: 0 0 0 3px rgba(255, 107, 107, 0.2); }

2 Fungsi Validasi

Tambahkan fungsi-fungsi untuk validasi input:

🔍 Fungsi Validasi - Tambahkan setelah fungsi loadTodos()
// Fungsi untuk menampilkan pesan error function showMessage(message) { // Hapus pesan sebelumnya jika ada const existingMessage = document.querySelector('.error-message'); if (existingMessage) { existingMessage.remove(); } // Buat elemen pesan baru const messageDiv = document.createElement('div'); messageDiv.className = 'error-message'; messageDiv.innerHTML = `❌ ${message}`; // Tambahkan setelah form todoForm.insertAdjacentElement( 'afterend', messageDiv ); // Hapus pesan setelah 3 detik setTimeout(() => { if (messageDiv.parentNode) { messageDiv.remove(); } }, 3000); } // Fungsi validasi input function validateInput(text) { // Hapus spasi di awal dan akhir text = text.trim(); // Cek apakah kosong if (text === '') { return { valid: false, message: 'Tugas tidak boleh kosong!' }; } // Cek panjang minimum if (text.length < 3) { return { valid: false, message: 'Tugas minimal 3 karakter!' }; } // Cek panjang maksimum if (text.length > 100) { return { valid: false, message: 'Tugas maksimal 100 karakter!' }; } // Cek apakah tugas sudah ada const isDuplicate = todos.some( todo => todo.text.toLowerCase() === text.toLowerCase() ); if (isDuplicate) { return { valid: false, message: 'Tugas ini sudah ada dalam daftar!' }; } return { valid: true, message: 'Input valid!' }; }

3 Update Event Listener dengan Validasi

Ganti event listener form untuk menggunakan validasi:

✅ Form dengan Validasi - Ganti event listener form
// Event listener untuk form submit dengan validasi lengkap todoForm.addEventListener( 'submit', function(e) { e.preventDefault(); const taskText = taskInput.value; // Hapus class error sebelumnya taskInput.classList.remove('input-error'); // Validasi input const validation = validateInput(taskText); if (!validation.valid) { // Tampilkan error showMessage(validation.message); taskInput.classList.add('input-error'); taskInput.focus(); // Focus kembali ke input return; } // Jika valid, tambah tugas addTodo(taskText.trim()); taskInput.value = ''; } );
