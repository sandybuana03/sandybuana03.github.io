📊 Step 1: Setup Database & Environment

Penjelasan Lengkap:

Database adalah fondasi dari sistem backend. Pada langkah ini, kita akan menyiapkan environment development, membuat database MySQL, dan mengkonfigurasi koneksi yang aman dan efisien.

📋 Prerequisites (Yang Harus Disiapkan):

  • XAMPP/WAMP/MAMP atau server lokal lainnya
  • PHP versi 7.4 atau lebih baru
  • MySQL/MariaDB
  • Text editor (VS Code, Sublime, dll)
  • Browser untuk testing

🔧 1. Persiapan Environment

Pastikan XAMPP sudah terinstall dan berjalan:

# Jalankan XAMPP Control Panel # Start Apache dan MySQL # Buka http://localhost/phpmyadmin untuk akses database

Jika menggunakan Linux/Mac, pastikan service MySQL dan Apache sudah running.

🗄️ 2. Membuat Database

Buat database baru melalui phpMyAdmin atau command line:

-- Melalui phpMyAdmin atau MySQL Command Line CREATE DATABASE sekolah_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; -- Gunakan database yang baru dibuat USE sekolah_db; -- Cek database yang tersedia SHOW DATABASES;

Penjelasan:

  • CHARACTER SET utf8mb4: Mendukung emoji dan karakter Unicode
  • COLLATE utf8mb4_unicode_ci: Pengurutan yang case-insensitive

🔗 3. Konfigurasi Koneksi Database

Buat file config.php untuk mengatur koneksi database:

<?php // config.php - Konfigurasi Database define('DB_HOST', 'localhost'); define('DB_USERNAME', 'root'); define('DB_PASSWORD', ''); // Kosong untuk XAMPP default define('DB_NAME', 'sekolah_db'); define('DB_CHARSET', 'utf8mb4'); // Kelas Database untuk koneksi yang lebih aman class Database { private $host = DB_HOST; private $username = DB_USERNAME; private $password = DB_PASSWORD; private $database = DB_NAME; private $charset = DB_CHARSET; public $conn; public function __construct() { $this->connect(); } private function connect() { try { $dsn = "mysql:host={$this->host};dbname={$this->database};charset={$this->charset}"; $options = [ PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION, PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC, PDO::ATTR_EMULATE_PREPARES => false, ]; $this->conn = new PDO($dsn, $this->username, $this->password, $options); } catch(PDOException $e) { die("Koneksi database gagal: " . $e->getMessage()); } } public function getConnection() { return $this->conn; } } // Untuk backward compatibility dengan mysqli $host = DB_HOST; $username = DB_USERNAME; $password = DB_PASSWORD; $database = DB_NAME; $conn = new mysqli($host, $username, $password, $database); if ($conn->connect_error) { die("Koneksi gagal: " . $conn->connect_error); } // Set charset untuk mysqli $conn->set_charset("utf8mb4"); ?>

Keunggulan konfigurasi ini:

  • Menggunakan konstanta untuk keamanan
  • Support PDO dan MySQLi
  • Error handling yang proper
  • Charset UTF8MB4 untuk support emoji

🧪 4. Test Koneksi Database

Buat file test_connection.php untuk memastikan koneksi berhasil:

<?php require_once 'config.php'; echo "<h2>Test Koneksi Database</h2>"; // Test MySQLi Connection if ($conn->connect_error) { echo "<p style='color: red;'>❌ MySQLi: Koneksi gagal - " . $conn->connect_error . "</p>"; } catch(Exception $e) { echo "<p style='color: red;'>❌ PDO: " . $e->getMessage() . "</p>"; } ?>

💡 Tips Penting:

  • Selalu gunakan environment variables untuk production
  • Jangan commit password database ke version control
  • Gunakan connection pooling untuk aplikasi dengan traffic tinggi
  • Aktifkan slow query log untuk monitoring performa

✅ Checklist Step 1:

  • XAMPP/server lokal sudah berjalan
  • Database 'sekolah_db' sudah dibuat
  • File config.php sudah dibuat dan dikonfigurasi
  • Test koneksi berhasil (MySQLi dan PDO)
  • Charset UTF8MB4 sudah diset

🗃️ Step 2: Membuat Tabel Database

Penjelasan Lengkap:

Desain tabel database adalah langkah krusial yang menentukan efisiensi dan skalabilitas sistem. Kita akan membuat 3 tabel utama dengan relasi yang tepat, indexing yang optimal, dan constraint yang memastikan integritas data.

🎯 Tujuan Desain Database:

  • Normalisasi data untuk menghindari redundansi
  • Optimasi query dengan indexing yang tepat
  • Fleksibilitas untuk pengembangan fitur masa depan
  • Keamanan data dengan constraint dan validasi

Tabel Admin - Manajemen Pengguna Sistem:

CREATE TABLE admin ( id INT AUTO_INCREMENT PRIMARY KEY, username VARCHAR(50) UNIQUE NOT NULL, password VARCHAR(255) NOT NULL, nama_lengkap VARCHAR(100) NOT NULL, email VARCHAR(100) UNIQUE NOT NULL, role ENUM('super_admin', 'admin', 'operator') DEFAULT 'admin', avatar VARCHAR(255) DEFAULT NULL, last_login TIMESTAMP NULL, login_attempts INT DEFAULT 0, is_active BOOLEAN DEFAULT TRUE, reset_token VARCHAR(100) DEFAULT NULL, reset_token_expires TIMESTAMP NULL, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP, -- Indexes untuk optimasi query INDEX idx_username (username), INDEX idx_email (email), INDEX idx_role (role), INDEX idx_active (is_active) ) ENGINE=InnoDB;
📋 Penjelasan Field:
  • id: Primary key auto increment
  • username: Unique identifier untuk login
  • password: Hash password (bcrypt/argon2)
  • role: Level akses (super_admin, admin, operator)
  • login_attempts: Counter untuk security
  • reset_token: Token untuk reset password
🔒 Fitur Keamanan:
  • Password hashing dengan salt
  • Login attempt limiting
  • Account activation/deactivation
  • Secure password reset
  • Session tracking
⚡ Optimasi Performa:
-- Index untuk query yang sering digunakan CREATE INDEX idx_admin_login ON admin(username, is_active); CREATE INDEX idx_admin_role_active ON admin(role, is_active); -- Contoh query yang dioptimasi: SELECT * FROM admin WHERE username = 'admin' AND is_active = 1; SELECT COUNT(*) FROM admin WHERE role = 'admin' AND is_active = 1;

Tabel Guru:

CREATE TABLE guru ( id INT AUTO_INCREMENT PRIMARY KEY, nip VARCHAR(20) UNIQUE NOT NULL, nama_lengkap VARCHAR(100) NOT NULL, email VARCHAR(100) UNIQUE, no_telepon VARCHAR(15), alamat TEXT, mata_pelajaran VARCHAR(100), jenis_kelamin ENUM('L', 'P') NOT NULL, tanggal_lahir DATE, status ENUM('aktif', 'non_aktif') DEFAULT 'aktif', created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP );

Tabel guru menyimpan data lengkap guru termasuk mata pelajaran yang diampu.

Tabel Siswa:

CREATE TABLE siswa ( id INT AUTO_INCREMENT PRIMARY KEY, nis VARCHAR(20) UNIQUE NOT NULL, nama_lengkap VARCHAR(100) NOT NULL, kelas VARCHAR(10) NOT NULL, jurusan VARCHAR(50), jenis_kelamin ENUM('L', 'P') NOT NULL, tanggal_lahir DATE, alamat TEXT, no_telepon VARCHAR(15), email VARCHAR(100), nama_wali VARCHAR(100), no_telepon_wali VARCHAR(15), status ENUM('aktif', 'lulus', 'pindah', 'drop_out') DEFAULT 'aktif', created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP );

Tabel siswa menyimpan data lengkap siswa termasuk informasi wali.

✅ Struktur Tabel:

  • Setiap tabel memiliki primary key auto increment
  • Field unique untuk mencegah duplikasi data
  • Timestamp otomatis untuk tracking perubahan
  • Enum untuk membatasi pilihan data

🔌 Step 3: Membuat API Endpoints

Penjelasan:

API endpoints adalah titik akses untuk melakukan operasi CRUD (Create, Read, Update, Delete) pada data sekolah.

API Admin (admin_api.php):

<?php require_once 'config.php'; header('Content-Type: application/json'); $method = $_SERVER['REQUEST_METHOD']; $input = json_decode(file_get_contents('php://input'), true); switch($method) { case 'GET': if(isset($_GET['id'])) { getAdmin($_GET['id']); } else { getAllAdmin(); } break; case 'POST': createAdmin($input); break; case 'PUT': updateAdmin($input); break; case 'DELETE': deleteAdmin($_GET['id']); break; } function getAllAdmin() { global $conn; $result = $conn->query("SELECT id, username, nama_lengkap, email, role, created_at FROM admin"); $admin = []; while($row = $result->fetch_assoc()) { $admin[] = $row; } echo json_encode($admin); } function createAdmin($data) { global $conn; $password = password_hash($data['password'], PASSWORD_DEFAULT); $stmt = $conn->prepare("INSERT INTO admin (username, password, nama_lengkap, email, role) VALUES (?, ?, ?, ?, ?)"); $stmt->bind_param("sssss", $data['username'], $password, $data['nama_lengkap'], $data['email'], $data['role']); if($stmt->execute()) { echo json_encode(["status" => "success", "message" => "Admin berhasil ditambahkan"]); } else { echo json_encode(["status" => "error", "message" => "Gagal menambahkan admin"]); } } ?>

API Guru (guru_api.php):

<?php require_once 'config.php'; header('Content-Type: application/json'); $method = $_SERVER['REQUEST_METHOD']; $input = json_decode(file_get_contents('php://input'), true); function getAllGuru() { global $conn; $result = $conn->query("SELECT * FROM guru WHERE status = 'aktif' ORDER BY nama_lengkap"); $guru = []; while($row = $result->fetch_assoc()) { $guru[] = $row; } echo json_encode($guru); } function createGuru($data) { global $conn; $stmt = $conn->prepare("INSERT INTO guru (nip, nama_lengkap, email, no_telepon, alamat, mata_pelajaran, jenis_kelamin, tanggal_lahir) VALUES (?, ?, ?, ?, ?, ?, ?, ?)"); $stmt->bind_param("ssssssss", $data['nip'], $data['nama_lengkap'], $data['email'], $data['no_telepon'], $data['alamat'], $data['mata_pelajaran'], $data['jenis_kelamin'], $data['tanggal_lahir']); if($stmt->execute()) { echo json_encode(["status" => "success", "message" => "Data guru berhasil ditambahkan"]); } else { echo json_encode(["status" => "error", "message" => "Gagal menambahkan data guru"]); } } function updateGuru($data) { global $conn; $stmt = $conn->prepare("UPDATE guru SET nama_lengkap=?, email=?, no_telepon=?, alamat=?, mata_pelajaran=?, jenis_kelamin=?, tanggal_lahir=? WHERE id=?"); $stmt->bind_param("sssssssi", $data['nama_lengkap'], $data['email'], $data['no_telepon'], $data['alamat'], $data['mata_pelajaran'], $data['jenis_kelamin'], $data['tanggal_lahir'], $data['id']); if($stmt->execute()) { echo json_encode(["status" => "success", "message" => "Data guru berhasil diupdate"]); } else { echo json_encode(["status" => "error", "message" => "Gagal mengupdate data guru"]); } } ?>

API Siswa (siswa_api.php):

<?php require_once 'config.php'; header('Content-Type: application/json'); function getAllSiswa() { global $conn; $result = $conn->query("SELECT * FROM siswa WHERE status = 'aktif' ORDER BY kelas, nama_lengkap"); $siswa = []; while($row = $result->fetch_assoc()) { $siswa[] = $row; } echo json_encode($siswa); } function getSiswaByKelas($kelas) { global $conn; $stmt = $conn->prepare("SELECT * FROM siswa WHERE kelas = ? AND status = 'aktif' ORDER BY nama_lengkap"); $stmt->bind_param("s", $kelas); $stmt->execute(); $result = $stmt->get_result(); $siswa = []; while($row = $result->fetch_assoc()) { $siswa[] = $row; } echo json_encode($siswa); } function createSiswa($data) { global $conn; $stmt = $conn->prepare("INSERT INTO siswa (nis, nama_lengkap, kelas, jurusan, jenis_kelamin, tanggal_lahir, alamat, no_telepon, email, nama_wali, no_telepon_wali) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)"); $stmt->bind_param("sssssssssss", $data['nis'], $data['nama_lengkap'], $data['kelas'], $data['jurusan'], $data['jenis_kelamin'], $data['tanggal_lahir'], $data['alamat'], $data['no_telepon'], $data['email'], $data['nama_wali'], $data['no_telepon_wali']); if($stmt->execute()) { echo json_encode(["status" => "success", "message" => "Data siswa berhasil ditambahkan"]); } else { echo json_encode(["status" => "error", "message" => "Gagal menambahkan data siswa"]); } } ?>

Authentication (auth.php):

<?php session_start(); require_once 'config.php'; header('Content-Type: application/json'); function login($username, $password) { global $conn; $stmt = $conn->prepare("SELECT id, username, password, nama_lengkap, role FROM admin WHERE username = ?"); $stmt->bind_param("s", $username); $stmt->execute(); $result = $stmt->get_result(); if($result->num_rows == 1) { $user = $result->fetch_assoc(); if(password_verify($password, $user['password'])) { $_SESSION['user_id'] = $user['id']; $_SESSION['username'] = $user['username']; $_SESSION['role'] = $user['role']; echo json_encode([ "status" => "success", "message" => "Login berhasil", "user" => [ "id" => $user['id'], "username" => $user['username'], "nama_lengkap" => $user['nama_lengkap'], "role" => $user['role'] ] ]); } else { echo json_encode(["status" => "error", "message" => "Password salah"]); } } else { echo json_encode(["status" => "error", "message" => "Username tidak ditemukan"]); } } function logout() { session_destroy(); echo json_encode(["status" => "success", "message" => "Logout berhasil"]); } function checkAuth() { if(!isset($_SESSION['user_id'])) { echo json_encode(["status" => "error", "message" => "Unauthorized"]); exit; } } ?>

⚠️ Keamanan:

  • Gunakan prepared statements untuk mencegah SQL injection
  • Hash password dengan password_hash()
  • Validasi input dari user
  • Implementasi session untuk authentication

🔐 Step 4: Implementasi Keamanan

Penjelasan Lengkap:

Keamanan adalah aspek terpenting dalam pengembangan backend. Kita akan implementasi berbagai layer keamanan untuk melindungi data sekolah dari berbagai ancaman cyber.

🛡️ 1. Input Validation & Sanitization

Validasi input adalah pertahanan pertama terhadap serangan:

<?php // validation.php - Kelas untuk validasi input class InputValidator { public static function validateEmail($email) { return filter_var($email, FILTER_VALIDATE_EMAIL) !== false; } public static function validatePhone($phone) { return preg_match('/^[0-9+\-\s()]{10,15}$/', $phone); } public static function validateNIP($nip) { return preg_match('/^[0-9]{8,20}$/', $nip); } public static function validateNIS($nis) { return preg_match('/^[0-9]{6,15}$/', $nis); } public static function sanitizeString($input) { return htmlspecialchars(trim($input), ENT_QUOTES, 'UTF-8'); } public static function validatePassword($password) { // Minimal 8 karakter, ada huruf besar, kecil, angka return preg_match('/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)[a-zA-Z\d@$!%*?&]{8,}$/', $password); } public static function validateRequired($fields, $data) { $errors = []; foreach($fields as $field) { if(empty($data[$field])) { $errors[] = "Field {$field} wajib diisi"; } } return $errors; } } ?>

💉 2. Pencegahan SQL Injection

❌ Cara Yang Salah:
// JANGAN LAKUKAN INI! $query = "SELECT * FROM admin WHERE username = '{$_POST['username']}'"; $result = mysqli_query($conn, $query);
✅ Cara Yang Benar:
// Gunakan Prepared Statement $stmt = $conn->prepare("SELECT * FROM admin WHERE username = ?"); $stmt->bind_param("s", $_POST['username']); $stmt->execute();

🔑 3. Authentication & Authorization

<?php // auth_middleware.php - Middleware untuk autentikasi class AuthMiddleware { public static function requireLogin() { session_start(); if(!isset($_SESSION['user_id'])) { http_response_code(401); echo json_encode(['error' => 'Unauthorized - Login required']); exit; } } public static function requireRole($required_roles) { self::requireLogin(); if(!in_array($_SESSION['role'], $required_roles)) { http_response_code(403); echo json_encode(['error' => 'Forbidden - Insufficient permissions']); exit; } } public static function rateLimiting($max_attempts = 5, $time_window = 300) { $ip = $_SERVER['REMOTE_ADDR']; $key = "rate_limit_{$ip}"; if(!isset($_SESSION[$key])) { $_SESSION[$key] = ['count' => 0, 'first_attempt' => time()]; } $data = $_SESSION[$key]; if(time() - $data['first_attempt'] > $time_window) { $_SESSION[$key] = ['count' => 1, 'first_attempt' => time()]; } else { $_SESSION[$key]['count']++; if($_SESSION[$key]['count'] > $max_attempts) { http_response_code(429); echo json_encode(['error' => 'Too many requests']); exit; } } } } ?>

🌐 4. Security Headers & CORS

<?php // security_headers.php - Set security headers function setSecurityHeaders() { // Prevent XSS attacks header('X-Content-Type-Options: nosniff'); header('X-Frame-Options: DENY'); header('X-XSS-Protection: 1; mode=block'); // HTTPS enforcement (untuk production) if(isset($_SERVER['HTTPS']) && $_SERVER['HTTPS'] === 'on') { header('Strict-Transport-Security: max-age=31536000; includeSubDomains'); } // Content Security Policy header("Content-Security-Policy: default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'"); // CORS untuk API header('Access-Control-Allow-Origin: http://localhost:3000'); // Sesuaikan dengan frontend header('Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS'); header('Access-Control-Allow-Headers: Content-Type, Authorization'); header('Access-Control-Allow-Credentials: true'); } // Panggil di setiap API endpoint setSecurityHeaders(); ?>

⚠️ Checklist Keamanan:

  • Semua input divalidasi dan disanitasi
  • Prepared statements untuk semua query
  • Password di-hash dengan algoritma kuat
  • Session management yang aman
  • Rate limiting untuk API endpoints
  • Security headers diset dengan benar
  • Error handling yang tidak expose sensitive info

🚀 Step 6: Deployment & Production

Penjelasan Lengkap:

Deployment adalah proses memindahkan aplikasi dari environment development ke production server. Kita akan membahas berbagai opsi deployment dan best practices.

🖥️ 1. Server Requirements

Minimum Requirements:
  • • PHP 7.4+ (Recommended: PHP 8.1+)
  • • MySQL 5.7+ atau MariaDB 10.3+
  • • Apache 2.4+ atau Nginx 1.18+
  • • SSL Certificate (Let's Encrypt)
  • • RAM: 1GB minimum, 2GB recommended
  • • Storage: 10GB minimum
PHP Extensions:
  • • mysqli atau pdo_mysql
  • • json
  • • mbstring
  • • openssl
  • • curl
  • • gd (untuk image processing)

⚙️ 2. Environment Configuration

Buat file .env untuk konfigurasi production:

# .env - Production Environment Variables # Database Configuration DB_HOST=localhost DB_NAME=sekolah_production DB_USERNAME=sekolah_user DB_PASSWORD=strong_password_here DB_CHARSET=utf8mb4 # Application Settings APP_ENV=production APP_DEBUG=false APP_URL=https://sekolah.domain.com # Security JWT_SECRET=your-super-secret-jwt-key-here ENCRYPTION_KEY=32-character-encryption-key-here SESSION_LIFETIME=7200 # Email Configuration (untuk reset password) MAIL_HOST=smtp.gmail.com MAIL_PORT=587 MAIL_USERNAME=noreply@sekolah.com MAIL_PASSWORD=app_password_here MAIL_ENCRYPTION=tls # File Upload MAX_FILE_SIZE=5242880 UPLOAD_PATH=/var/www/uploads/
<?php // config_production.php - Load environment variables function loadEnv($file) { if (!file_exists($file)) { throw new Exception('.env file not found'); } $lines = file($file, FILE_IGNORE_NEW_LINES | FILE_SKIP_EMPTY_LINES); foreach ($lines as $line) { if (strpos($line, '#') === 0) continue; list($key, $value) = explode('=', $line, 2); $_ENV[trim($key)] = trim($value); putenv(trim($key) . '=' . trim($value)); } } // Load environment variables loadEnv(__DIR__ . '/.env'); // Database configuration from environment define('DB_HOST', $_ENV['DB_HOST']); define('DB_NAME', $_ENV['DB_NAME']); define('DB_USERNAME', $_ENV['DB_USERNAME']); define('DB_PASSWORD', $_ENV['DB_PASSWORD']); ?>
