Pengenalan Dunia IT

🌟 Apa itu Industri IT?

Industri IT (Information Technology) adalah bidang yang berkaitan dengan pengembangan, pemeliharaan, dan penggunaan sistem komputer, perangkat lunak, dan jaringan untuk memproses dan mendistribusikan data.

Di era digital ini, hampir semua aspek kehidupan kita bergantung pada teknologi - dari aplikasi di smartphone, website yang kita kunjungi, hingga game yang kita mainkan!

Software Developer

🔍 Apa itu Software Developer?

Software Developer adalah orang yang merancang, membuat, dan memelihara aplikasi atau program komputer. Mereka seperti arsitek digital yang membangun "rumah" berupa software untuk memenuhi kebutuhan pengguna.

📋 Tugas Utama

  • • Menulis kode program
  • • Mendesain arsitektur software
  • • Testing dan debugging
  • • Maintenance aplikasi
  • • Dokumentasi kode

🛠️ Skill yang Dibutuhkan

  • • Bahasa pemrograman (Java, Python, C++, C#)
  • • Problem solving & logical thinking
  • • Algoritma dan struktur data
  • • Database management (SQL)
  • • Version control (Git/GitHub)
  • • Software testing & debugging

💼 Jenis-jenis Software Developer

🖥️
Desktop Apps

Microsoft Office, Adobe Photoshop

☁️
Cloud Apps

Google Drive, Dropbox

🔧
System Software

Operating Systems, Drivers

💰 Prospek Karir & Gaji

Jenjang Karir:
  • • Junior Developer (0-2 tahun)
  • • Senior Developer (3-5 tahun)
  • • Tech Lead (5+ tahun)
  • • Software Architect
Estimasi Gaji (Indonesia):
  • • Junior: 4-8 juta/bulan
  • • Senior: 10-20 juta/bulan
  • • Tech Lead: 20-35 juta/bulan
  • • Architect: 35+ juta/bulan

Web Developer

🔍 Apa itu Web Developer?

Web Developer adalah orang yang membuat dan memelihara website. Mereka bertanggung jawab membuat website yang kita kunjungi setiap hari, mulai dari tampilan yang menarik hingga fungsi yang bekerja dengan baik.

🎨

Frontend Developer

Membuat tampilan website yang dilihat pengguna

Tools: HTML, CSS, JavaScript

Framework: React, Vue, Angular

⚙️

Backend Developer

Membuat sistem di balik layar website

Tools: PHP, Python, Node.js

Database: MySQL, MongoDB

🔄

Fullstack Developer

Menguasai frontend dan backend

Skills: Frontend + Backend

Bonus: DevOps, Cloud

🎥 Roadmap Belajar Web Development

Level 1
Dasar-dasar (1-2 bulan)
  • • HTML: Struktur halaman web
  • • CSS: Styling dan layout
  • • JavaScript: Interaktivitas dasar
Level 2
Menengah (2-4 bulan)
  • • React/Vue: Framework frontend
  • • Node.js: Backend JavaScript
  • • Database: MySQL/MongoDB
Level 3
Lanjutan (4-6 bulan)
  • • Cloud deployment (AWS, Vercel)
  • • Testing & optimization
  • • Advanced frameworks & tools

💡 Tips Sukses untuk Pemula

🎯 Do's (Yang Harus Dilakukan):
  • ✅ Praktik coding setiap hari (minimal 1 jam)
  • ✅ Buat project kecil untuk portfolio
  • ✅ Bergabung dengan komunitas developer
  • ✅ Belajar dari tutorial dan dokumentasi
  • ✅ Jangan takut bertanya dan mencari bantuan
❌ Don'ts (Yang Harus Dihindari):
  • ❌ Belajar terlalu banyak bahasa sekaligus
  • ❌ Hanya menonton tutorial tanpa praktik
  • ❌ Menyerah saat menghadapi error
  • ❌ Tidak membuat backup kode
  • ❌ Mengabaikan best practices

UI/UX Designer

🔍 Apa itu UI/UX Designer?

UI/UX Designer adalah orang yang merancang tampilan dan pengalaman pengguna dalam aplikasi atau website. Mereka memastikan produk digital tidak hanya terlihat cantik, tapi juga mudah dan nyaman digunakan.

🖼️ UI (User Interface)

Fokus pada tampilan visual: warna, font, tombol, layout

👤 UX (User Experience)

Fokus pada pengalaman pengguna: kemudahan, efisiensi, kepuasan

Data Analyst

🔍 Apa itu Data Analyst?

Data Analyst adalah orang yang mengumpulkan, mengolah, dan menganalisis data untuk membantu perusahaan membuat keputusan bisnis yang tepat. Mereka seperti "detektif data" yang mencari pola dan insight dari tumpukan informasi.

🎯 Demo: Analisis Data Sederhana

📈 Data Penjualan Toko Online (contoh)
Data Mentah:
Januari: 150 produk terjual
Februari: 200 produk terjual
Maret: 180 produk terjual
April: 250 produk terjual
Mei: 300 produk terjual
Insight yang Ditemukan:
  • ✅ Tren penjualan naik 100% (Jan-Mei)
  • ✅ Pertumbuhan tertinggi di April (+39%)
  • ✅ Rata-rata penjualan: 216 produk/bulan
  • 🎯 Prediksi Juni: 320-350 produk
💡 Rekomendasi Bisnis:

Tingkatkan stok produk untuk bulan Juni, fokus pada strategi marketing yang berhasil di April, dan siapkan kapasitas pengiriman yang lebih besar.

🛠️ Tools yang Digunakan

📊
Excel/Google Sheets

Analisis dasar, pivot table

🐍
Python/R

Analisis advanced, machine learning

📈
Tableau/Power BI

Visualisasi data, dashboard

📋 Tugas Data Analyst

  • • Mengumpulkan data dari berbagai sumber
  • • Membersihkan dan memproses data
  • • Membuat visualisasi dan dashboard
  • • Mengidentifikasi tren dan pola
  • • Membuat laporan dan presentasi
  • • Memberikan rekomendasi bisnis

  • c) Tahun 5: Cita-cita karir kamu?

4. Refleksi Pembelajaran (25 poin)

Setelah mempelajari berbagai profesi IT, tuliskan:

  • a) 3 hal baru yang kamu pelajari hari ini
  • b) Profesi mana yang paling mengejutkan bagimu? Mengapa?
