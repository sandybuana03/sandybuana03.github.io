🔗 Apa itu Jaringan Komputer?

Jaringan komputer adalah kumpulan perangkat yang saling terhubung untuk berbagi data dan sumber daya. Seperti jalan raya yang menghubungkan kota-kota, jaringan menghubungkan komputer-komputer!

Network Administrator

"Dokter" untuk jaringan komputer!

👨‍💼 Apa itu Network Administrator?

Network Administrator adalah profesional yang bertanggung jawab mengelola, memelihara, dan mengamankan jaringan komputer dalam suatu organisasi. Mereka adalah "superhero" yang memastikan internet dan jaringan selalu berjalan lancar!

📋 Tugas dan Tanggung Jawab

🔧 Instalasi & Konfigurasi

  • • Memasang perangkat jaringan (router, switch, access point)
  • • Konfigurasi IP address, subnet, dan VLAN
  • • Setup server (Windows Server, Linux) dan workstation
  • • Instalasi sistem operasi jaringan (Windows Server, Ubuntu Server)

🔍 Monitoring & Troubleshooting

  • • Memantau kinerja jaringan 24/7 menggunakan monitoring tools
  • • Diagnosa dan perbaikan masalah koneksi (ping, traceroute, nslookup)
  • • Analisis traffic dan bandwidth menggunakan Wireshark
  • • Maintenance preventif perangkat (update firmware, cleaning)

🛡️ Keamanan Jaringan

  • • Konfigurasi firewall (pfSense, Cisco ASA) dan antivirus server
  • • Manajemen user access dan permission (Active Directory)
  • • Backup data otomatis dan disaster recovery planning
  • • Monitoring keamanan dan intrusion detection system (IDS)

📊 Dokumentasi & Pelaporan

  • • Dokumentasi topologi jaringan dan konfigurasi perangkat
  • • Laporan kinerja sistem dan utilisasi bandwidth bulanan
  • • Perencanaan upgrade hardware dan ekspansi jaringan
  • • Pembuatan SOP (Standard Operating Procedure) IT

Cloud Engineer

Arsitek masa depan di "awan"!

👨‍💻 Apa itu Cloud Engineer?

Cloud Engineer adalah profesional yang merancang, membangun, dan mengelola infrastruktur cloud. Mereka adalah "arsitek digital" yang membangun rumah untuk aplikasi dan data di "awan"!

🏗️ Tugas dan Tanggung Jawab

🏗️ Desain & Arsitektur

  • • Merancang arsitektur cloud yang scalable
  • • Memilih layanan cloud sesuai kebutuhan bisnis
  • • Optimasi performa, keamanan, dan biaya
  • • Desain high availability dan disaster recovery

🚀 Deployment & Migration

  • • Deploy aplikasi menggunakan Docker container dan AWS Lambda
  • • Migrasi workload dari server fisik ke cloud (lift and shift)
  • • Implementasi CI/CD pipeline dengan Jenkins/GitLab CI
  • • Infrastructure as Code menggunakan Terraform/CloudFormation

🔒 Keamanan & Compliance

  • • Implementasi security best practices (least privilege, MFA)
  • • Identity and Access Management (AWS IAM, Azure AD)
  • • Compliance audit (SOC 2, ISO 27001) dan security assessment
  • • Encryption data at rest/in transit dan VPC security

📈 Monitoring & Optimasi

  • • Monitoring performa dengan CloudWatch, Prometheus, Grafana
  • • Cost optimization (Reserved Instances, Spot Instances)
  • • Auto-scaling groups dan Application Load Balancer
  • • Alerting (PagerDuty, Slack) dan incident response 24/7

Tugas Pembelajaran

Saatnya menguji pemahaman kalian!

📋 Soal Essay

Soal 1: Analisis Profesi (25 poin)

Jelaskan perbedaan utama antara Network Administrator dan Cloud Engineer dalam hal:

  • Tugas dan tanggung jawab sehari-hari
  • Skill teknis yang dibutuhkan
  • Tools yang digunakan
  • Prospek karir dan gaji

Soal 2: Studi Kasus (25 poin)

Sebuah SMK ingin mengupgrade sistem IT mereka. Saat ini mereka menggunakan server fisik di sekolah untuk website dan sistem akademik. Mereka ingin beralih ke cloud untuk menghemat biaya dan meningkatkan performa. Sebagai konsultan IT:

  • Rekomendasikan platform cloud yang cocok dan berikan alasannya
  • Jelaskan langkah-langkah migrasi yang perlu dilakukan
  • Sebutkan keuntungan yang akan didapat sekolah
  • Identifikasi tantangan yang mungkin dihadapi

Soal 3: Perencanaan Karir (25 poin)

Buatlah rencana karir 5 tahun ke depan untuk salah satu profesi (Network Administrator atau Cloud Engineer). Rencana harus mencakup:

  • Target posisi setiap tahun
  • Skill dan sertifikasi yang akan dipelajari
  • Strategi untuk mencapai target tersebut
  • Estimasi gaji di setiap level

Soal 4: Refleksi Pembelajaran (25 poin)

Setelah mempelajari materi ini, refleksikan:

  • Profesi mana yang lebih menarik bagi Anda dan mengapa?
  • Apa yang akan Anda lakukan mulai dari sekarang untuk mempersiapkan karir di bidang ini?
  • Tantangan apa yang Anda antisipasi dan bagaimana mengatasinya?
  • Bagaimana profesi ini dapat berkontribusi untuk kemajuan Indonesia?

📋 Petunjuk Pengerjaan:

  • • Jawab semua soal dengan lengkap dan jelas
  • • Gunakan bahasa yang baik dan benar
  • • Berikan contoh konkret jika diperlukan
  • • Total nilai: 100 poin
  • • Waktu pengerjaan: 90 menit
