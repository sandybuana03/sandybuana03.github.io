Apa itu Perangkat Lunak?

🖥️ Definisi Perangkat Lunak

Perangkat lunak (software) adalah kumpulan instruksi atau program yang memberitahu komputer apa yang harus dilakukan. Berbeda dengan perangkat keras yang bisa kita sentuh, software adalah bagian "tak terlihat" yang membuat komputer bisa bekerja.

🎮 Demo: Klik untuk melihat contoh!

🔧

Perangkat Keras

  • • Bisa disentuh (tangible)
  • • Contoh: CPU, RAM, Monitor
  • • Komponen fisik komputer
  • • Rusak = perlu diganti
💾

Perangkat Lunak

  • • Tidak bisa disentuh (intangible)
  • • Contoh: Windows, Chrome, WhatsApp
  • • Program dan aplikasi
  • • Error = perlu diperbaiki/update

Sejarah Perkembangan Software

🕰️

Era 1940-1950an

Awal Mula Software

  • • Program ditulis langsung dalam bahasa mesin (0 dan 1)
  • • Menggunakan kartu berlubang (punch cards)
  • • Satu program untuk satu komputer khusus
  • • Programmer harus ahli elektronik juga
🔤

Era 1950-1960an

Bahasa Pemrograman Tingkat Tinggi

  • • Lahir bahasa FORTRAN (1957) dan COBOL (1959)
  • • Program lebih mudah ditulis dan dipahami
  • • Mulai ada sistem operasi batch processing
  • • Compiler dan assembler berkembang
💻

Era 1970-1980an

Personal Computer & Mikroprosesor

  • • Lahir mikroprosesor Intel 4004 (1971)
  • • Komputer personal seperti Apple II (1977)
  • • Sistem operasi CP/M dan MS-DOS (1981)
  • • Bahasa C (1972) dan Pascal populer
🖱️

Era 1990an

GUI dan World Wide Web

  • • Windows 95 dengan GUI yang user-friendly
  • • World Wide Web (WWW) diluncurkan (1991)
  • • Browser Netscape dan Internet Explorer
  • • Bahasa Java (1995) dan Visual Basic
🌐

Era 2000an

Web 2.0 dan Mobile Revolution

  • • Web 2.0 dengan konten interaktif
  • • iPhone (2007) memulai era smartphone
  • • Social media: Facebook, YouTube, Twitter
  • • Framework: PHP, ASP.NET, Ruby on Rails
🤖

Era 2010-Sekarang

AI, Cloud, dan Mobile-First

  • • AI/ML: Deep Learning, ChatGPT (2022)
  • • Cloud: AWS, Google Cloud, Azure
  • • Mobile-first dan responsive design
  • • JavaScript ecosystem: React, Node.js, Vue

Bahasa Pemrograman

🗣️ Apa itu Bahasa Pemrograman?

Bahasa pemrograman adalah cara kita "berbicara" dengan komputer. Seperti bahasa manusia (Indonesia, Inggris), setiap bahasa pemrograman punya aturan dan kosakata sendiri.

Analogi: Jika komputer adalah orang asing, bahasa pemrograman adalah penerjemah yang membantu kita berkomunikasi dengannya.
