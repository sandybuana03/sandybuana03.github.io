System Analyst

Detektif di dunia teknologi!

🎯 Apa itu System Analyst?

System Analyst adalah profesi yang bertugas menganalisis kebutuhan bisnis, merancang solusi sistem informasi, dan memastikan sistem yang dikembangkan sesuai dengan kebutuhan pengguna. Mereka berperan sebagai jembatan komunikasi antara stakeholder bisnis (seperti klien, manajemen) dengan tim teknis (developer, programmer). System Analyst juga bertanggung jawab membuat dokumentasi sistem, spesifikasi kebutuhan (requirement specification), dan memastikan proyek berjalan sesuai timeline dan budget.

📋

Tugas Utama

  • • Menganalisis kebutuhan bisnis dan user requirements
  • • Merancang sistem informasi dan arsitektur sistem
  • • Membuat dokumentasi sistem (SRS, flowchart, ERD)
  • • Koordinasi dengan stakeholder dan tim developer
  • • Melakukan system testing dan user acceptance testing
  • • Membuat wireframe dan prototype sistem
  • • Mengelola perubahan requirement (change management)
  • • Melakukan feasibility study dan cost-benefit analysis
🧠

Skill yang Dibutuhkan

  • • Kemampuan analisis dan berpikir sistematis
  • • Komunikasi dan presentasi yang baik
  • • Pemahaman proses bisnis dan domain knowledge
  • • Pengetahuan teknologi (database, programming, network)
  • • Problem solving dan critical thinking
  • • Project management dan time management
  • • Kemampuan modeling (UML, BPMN, ERD)
  • • Negotiation dan stakeholder management

Tester (QA)

Quality Assurance - Penjaga kualitas aplikasi!

🎯 Apa itu Tester (QA)?

Quality Assurance (QA) Tester adalah profesi yang bertanggung jawab memastikan kualitas software atau aplikasi melalui proses testing yang sistematis. Mereka bertugas menemukan bug, memverifikasi fungsionalitas sistem, dan memastikan software memenuhi requirement yang telah ditetapkan sebelum dirilis ke pengguna. QA Tester juga berperan dalam meningkatkan proses development dengan memberikan feedback dan rekomendasi perbaikan. Perbedaan QA (Quality Assurance) dan QC (Quality Control): QA fokus pada pencegahan defect melalui proses, sedangkan QC fokus pada deteksi defect melalui testing.

🔍

Tugas Utama

  • • Membuat test plan dan test case berdasarkan requirement
  • • Melakukan manual testing (functional, UI/UX, integration)
  • • Mengembangkan dan menjalankan automated testing
  • • Menemukan, mendokumentasi, dan melaporkan bug/defect
  • • Verifikasi perbaikan bug dan regression testing
  • • Melakukan performance dan load testing
  • • Koordinasi dengan developer untuk bug fixing
  • • Membuat test report dan metrics quality
🛠️

Jenis Testing

  • • Functional Testing: Unit, Integration, System, Acceptance
  • • Performance Testing: Load, Stress, Volume, Spike
  • • Security Testing: Authentication, Authorization, Data Protection
  • • Usability Testing: User Experience, Accessibility
  • • Compatibility Testing: Browser, OS, Device
  • • Regression Testing: Memastikan fitur lama tetap berfungsi
  • • API Testing: Testing interface antar sistem

Tugas Essay

Jawablah pertanyaan-pertanyaan berikut dengan lengkap dan jelas:

1. Analisis Profesi (25 poin)

Jelaskan perbedaan utama antara profesi System Analyst dan Tester (QA). Berikan contoh konkret tugas yang dilakukan masing-masing profesi dalam pengembangan sebuah aplikasi e-commerce.

2. Studi Kasus System Analyst (25 poin)

Sebuah sekolah ingin membuat sistem informasi akademik untuk mengelola data siswa, nilai, dan jadwal. Sebagai System Analyst, jelaskan langkah-langkah yang akan Anda lakukan untuk menganalisis kebutuhan sistem ini.

3. Studi Kasus Testing (25 poin)

Anda diminta untuk melakukan testing pada fitur "Forgot Password" di sebuah aplikasi. Buatlah minimal 5 test case yang mencakup skenario normal dan skenario error yang mungkin terjadi.

4. Refleksi Karir (25 poin)

Dari kedua profesi yang telah dipelajari (System Analyst dan Tester), manakah yang lebih menarik bagi Anda? Jelaskan alasan pilihan Anda dan rencana persiapan yang akan Anda lakukan untuk mencapai profesi tersebut.

📌 Petunjuk Pengerjaan:

  • • Jawaban harus berdasarkan materi yang telah dipelajari
  • • Gunakan bahasa yang jelas dan mudah dipahami
  • • Berikan contoh konkret untuk memperkuat jawaban
  • • Minimal 100 kata per soal
  • • Waktu pengerjaan: 60 menit
