Pengenalan Desain UI

🖥️ Apa itu User Interface (UI)?

User Interface atau UI adalah tampilan visual dari sebuah aplikasi atau website yang memungkinkan pengguna berinteraksi dengan sistem. UI mencakup semua elemen yang bisa dilihat dan diklik oleh pengguna.

💡 Contoh UI dalam kehidupan sehari-hari:

  • • Tombol kirim pesan di aplikasi WhatsApp
  • • Menu navigasi dan search bar di website
  • • Icon aplikasi dan notifikasi di smartphone
  • • Form login dan tombol masuk di media sosial
  • • Dashboard dan sidebar di aplikasi e-learning

🧩 Komponen Utama UI:

🔘 Input Elements: Textbox, button, checkbox
🧭 Navigation: Menu, breadcrumb, pagination
📊 Information: Text, images, icons
📦 Containers: Cards, modals, panels
💬 Feedback: Alerts, tooltips, notifications
🎨 Visual: Colors, typography, spacing

📈 Evolusi UI Design:

1980s

Command Line Interface (CLI)

Hanya teks, tidak ada elemen visual

1990s

Graphical User Interface (GUI)

Windows, icons, mouse interaction

2000s

Web UI

Browser-based interfaces, CSS styling

2010s

Mobile & Touch UI

Responsive, gesture-based, app interfaces

2020s

AI & Voice UI

Chatbots, voice assistants, adaptive interfaces

🎯 Mengapa Desain UI Penting?

😊

Pengalaman Pengguna

UI yang baik membuat pengguna merasa nyaman dan mudah menggunakan aplikasi.

⚡

Efisiensi

Pengguna dapat menyelesaikan tugas dengan cepat dan tanpa kebingungan.

💼

Nilai Bisnis

UI yang menarik meningkatkan kepercayaan dan loyalitas pengguna.

🏆

Kompetitif

Aplikasi dengan UI bagus lebih unggul dari kompetitor.

🔄 UI vs UX: Apa Bedanya?

UI (User Interface)

  • • Fokus pada tampilan visual
  • • Warna, font, tombol, icon
  • • Layout dan komposisi
  • • Interaksi visual

UX (User Experience)

  • • Fokus pada pengalaman dan perasaan pengguna
  • • Alur dan journey pengguna dalam aplikasi
  • • Kemudahan, efisiensi, dan kepuasan pengguna
  • • Riset pengguna, testing, dan analisis data
  • • Memecahkan masalah pengguna secara efektif

✨ 3. Kesederhanaan (Simplicity)

"Less is more" - Desain yang sederhana lebih mudah dipahami dan digunakan. Hindari elemen yang tidak perlu.

💡 Tips Kesederhanaan:

✅ Batasi pilihan warna

❌ Warna yang berlebihan
❌ Animasi yang mengganggu

💬 4. Feedback & Response

Sistem harus memberikan feedback yang jelas dan tepat waktu ketika pengguna melakukan aksi. Feedback membantu pengguna memahami apakah aksi mereka berhasil, gagal, atau sedang diproses.

♿ 5. Aksesibilitas (Accessibility)

Aksesibilitas memastikan bahwa UI dapat digunakan oleh semua orang, termasuk mereka yang memiliki keterbatasan fisik, visual, atau kognitif. Ini bukan hanya tentang kebaikan hati, tetapi juga tentang menciptakan produk yang inklusif.

🎯 Prinsip WCAG (Web Content Accessibility Guidelines):

1. Perceivable (Dapat Dipersepsi)

Informasi harus dapat dilihat atau didengar

2. Operable (Dapat Dioperasikan)

Interface dapat digunakan dengan berbagai cara

3. Understandable (Dapat Dipahami)

Informasi dan operasi UI mudah dipahami

4. Robust (Kokoh)

Dapat diinterpretasi oleh berbagai teknologi

🛠️ Panduan Praktis Aksesibilitas:

🎨

Kontras Warna

Minimal 4.5:1 untuk teks normal, 3:1 untuk teks besar

📝

Alt Text untuk Gambar

Deskripsi gambar untuk screen reader

⌨️

Navigasi Keyboard

Semua fungsi dapat diakses dengan keyboard

📏

Ukuran Target

Minimal 44x44 pixel untuk area yang dapat diklik

🏷️

Label yang Jelas

Setiap input field harus memiliki label yang deskriptif

Tugas Pembelajaran

Kerjakan tugas berikut untuk menguji pemahaman kamu!

1️⃣ Analisis Prinsip UI

Pilih satu aplikasi yang sering kamu gunakan (WhatsApp, Instagram, YouTube, Shopee, Gojek, dll). Analisis aplikasi tersebut berdasarkan 5 prinsip dasar desain UI yang telah dipelajari:

  • • Konsistensi (Consistency)
  • • Hierarki Visual (Visual Hierarchy)
  • • Kesederhanaan (Simplicity)
  • • Feedback & Response
  • • Aksesibilitas (Accessibility)

📋 Format Jawaban:

Untuk setiap prinsip, berikan contoh konkret dari aplikasi yang kamu pilih dan jelaskan mengapa itu merupakan penerapan prinsip tersebut.

2️⃣ Desain Color Palette

Buatlah color palette untuk sebuah aplikasi pembelajaran online untuk siswa SMK. Color palette harus terdiri dari:

  • • 1 warna primer (warna utama)
  • • 2 warna sekunder (warna pendukung)
  • • 3 warna netral (abu-abu, putih, hitam)

🎨 Yang harus dijelaskan:

  • • Kode warna (hex code) untuk setiap warna
  • • Alasan pemilihan warna tersebut
  • • Fungsi masing-masing warna dalam aplikasi

3️⃣ Wireframe Sederhana

Buatlah wireframe (sketsa layout) untuk halaman login sebuah aplikasi e-learning. Wireframe harus mencakup:

  • • Logo aplikasi
  • • Form input (username dan password)
  • • Tombol login
  • • Link "Lupa Password"
  • • Link "Daftar Akun Baru"

✏️ Cara mengerjakan:

Gambar wireframe di kertas atau menggunakan aplikasi digital. Fokus pada layout dan posisi elemen, bukan detail visual.

4️⃣ Evaluasi UI/UX

Temukan satu website atau aplikasi yang menurutmu memiliki UI yang buruk atau membingungkan. Berikan kritik konstruktif dengan:

  • • Identifikasi 3 masalah UI yang kamu temukan
  • • Jelaskan mengapa itu menjadi masalah
  • • Berikan saran perbaikan untuk setiap masalah

💡 Tips:

Gunakan prinsip-prinsip UI yang sudah dipelajari sebagai dasar evaluasi. Berikan saran yang realistis dan dapat diterapkan.

📤 Instruksi Pengumpulan

• Kerjakan semua tugas dalam satu dokumen (Word/PDF)

• Sertakan nama, kelas, dan nomor absen di header

• Untuk wireframe, bisa difoto jika digambar tangan atau screenshot jika digital

• Deadline pengumpulan: 1 minggu setelah pembelajaran

• Kirim ke email guru atau upload ke platform yang ditentukan
