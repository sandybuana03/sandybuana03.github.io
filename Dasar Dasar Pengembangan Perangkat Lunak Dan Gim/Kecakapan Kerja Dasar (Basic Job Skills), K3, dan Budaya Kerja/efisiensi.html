Pengenalan Efisiensi & Efektivitas Algoritma

🤖 Apa itu Algoritma?

Algoritma adalah langkah-langkah sistematis untuk menyelesaikan masalah. Seperti resep masakan, algoritma memberikan instruksi yang jelas dan berurutan.

🔍 Contoh Algoritma dalam Kehidupan:

📱 Instagram: Algoritma timeline
🎵 Spotify: Rekomendasi musik
🗺️ Google Maps: Rute tercepat
🛒 Shopee: Pencarian produk
📺 Netflix: Rekomendasi film
💬 WhatsApp: Kompresi gambar

🏗️ Karakteristik Algoritma yang Baik:

✓ Input: Memiliki 0 atau lebih masukan
✓ Output: Menghasilkan minimal 1 keluaran
✓ Definiteness: Setiap langkah jelas
✓ Finiteness: Berhenti dalam waktu terbatas
✓ Effectiveness: Dapat dilaksanakan
✓ Generality: Berlaku untuk berbagai input

⚖️ Trade-off dalam Algoritma

⏱️ Time vs Space

Algoritma cepat sering butuh memori lebih banyak

Contoh: Hash table vs Array biasa

🎯 Speed vs Accuracy

Algoritma cepat kadang kurang akurat

Contoh: Approximate vs Exact algorithms

🔧 Simple vs Optimal

Algoritma sederhana vs yang dioptimasi

Contoh: Bubble sort vs Quick sort

Efisiensi Algoritma

Mengapa Efisiensi Penting?

⏱️ Waktu: User tidak suka menunggu lama
💾 Memori: RAM terbatas, harus hemat
🔋 Baterai: Algoritma efisien hemat daya
💰 Biaya: Server yang efisien lebih murah

🌍 Dampak Nyata Efisiensi Algoritma:

📱 Google: Menghemat 0.5 detik = $1.2 miliar revenue
🛒 Amazon: 100ms delay = 1% penurunan sales
🌱 Algoritma efisien = Kurangi emisi karbon
⚡ Data center hemat 30% energi dengan optimasi

🔍 Demo: Pencarian Linear vs Binary

Mari lihat perbedaan efisiensi antara dua algoritma pencarian pada data yang sudah terurut!

Data terurut (1-100):

🐌 Linear Search

Cek satu per satu dari awal sampai ketemu

Kompleksitas: O(n) - Worst case: n langkah

Bisa digunakan pada data terurut maupun tidak terurut

🚀 Binary Search

Bagi dua area pencarian setiap langkah

Kompleksitas: O(log n) - Worst case: log₂(n) langkah

Hanya bisa digunakan pada data yang sudah terurut

💡 Kesimpulan:

Untuk data 100 elemen: Linear Search butuh maksimal 100 langkah, Binary Search hanya butuh maksimal 7 langkah (log₂(100) ≈ 6.64). Semakin besar data, semakin terlihat keunggulan Binary Search!

🔄 Demo: Algoritma Sorting

Lihat bagaimana berbagai algoritma sorting bekerja dengan efisiensi yang berbeda!

Array yang akan diurutkan:

Langkah-langkah:

🐌 Bubble Sort

Bandingkan elemen bersebelahan, tukar jika perlu

O(n²) - Lambat tapi mudah dipahami

Tidak efisien untuk data besar

🔍 Selection Sort

Cari elemen terkecil, pindahkan ke depan

O(n²) - Sedikit lebih baik dari bubble

Performa konsisten tapi tetap lambat

🚀 Quick Sort

Bagi array berdasarkan pivot, urutkan rekursif

O(n log n) - Sangat cepat untuk data besar

Algoritma favorit untuk sorting

Kompleksitas Waktu

Apa itu Big O Notation?

Big O adalah cara untuk mengukur seberapa cepat waktu eksekusi algoritma bertambah ketika ukuran input bertambah. Seperti mengukur kecepatan mobil!

🟢

O(1) - Constant

Waktu tetap, tidak peduli ukuran data

Contoh: Akses array[0], operasi matematika sederhana

🔵

O(log n) - Logarithmic

Waktu bertambah pelan saat data bertambah

Contoh: Binary Search, pencarian di pohon seimbang

🟡

O(n) - Linear

Waktu bertambah sebanding dengan data

Contoh: Linear Search, loop sederhana, print semua elemen

🟠

O(n²) - Quadratic

Waktu bertambah kuadrat dari data

Contoh: Bubble Sort, nested loop, perbandingan semua pasangan
