Pengenalan Aset Proyek

🎯 Apa itu Aset Proyek?

Aset proyek adalah semua file dan resource yang dibutuhkan untuk membuat sebuah aplikasi atau website. Seperti bahan-bahan untuk memasak, aset adalah "bahan" untuk membuat proyek digital!

🏠 Analogi Rumah:

Membangun Rumah:
  • • Batu bata → HTML (struktur)
  • • Cat & dekorasi → CSS (tampilan)
  • • Listrik & pipa → JavaScript (fungsi)
Membangun Website:
  • • Gambar & foto → Konten visual
  • • Font & tipografi → Gaya teks
  • • Audio & video → Media interaktif
💻

Source Code

File program (.html, .css, .js)

Inti aplikasi
🖼️

Media Visual

Foto, icon, ilustrasi, video

Pengalaman visual
🎵

Pengalaman audio

Pengelolaan Source Code

📝 Apa itu Source Code?

Source code adalah file-file berisi kode program yang ditulis programmer. Ini adalah "resep" untuk membuat aplikasi bekerja!

🌐

HTML

Struktur halaman web

🎨

CSS

Styling dan tampilan

⚡

JavaScript

Interaksi dan logika

📋 Best Practices

✅ Yang Harus Dilakukan

  • • Gunakan nama file yang jelas
  • • Pisahkan HTML, CSS, dan JS
  • • Buat komentar pada kode
  • • Backup secara rutin

❌ Yang Harus Dihindari

  • • Nama file dengan spasi
  • • Campur semua kode dalam 1 file
  • • Tidak ada dokumentasi
  • • Lupa backup

Tugas Praktik

Terapkan pengetahuan yang sudah dipelajari!

🎯 Tugas 1: Analisis Struktur Proyek

Instruksi: Perhatikan struktur folder berikut dan identifikasi masalah yang ada:

📁 Website Sekolah/
├── 📄 halaman utama.html
├── 📄 style untuk web.css
├── 📄 script 1.js
├── 📄 script 2.js
├── 🖼️ logo sekolah.png
├── 🖼️ foto guru.jpg
├── 🎵 lagu mars sekolah.mp3
└── 📄 README.txt

Pertanyaan:

  1. Sebutkan 5 masalah dalam struktur folder di atas!
  2. Buatlah struktur folder yang lebih baik untuk proyek tersebut!
  3. Jelaskan alasan dari setiap perubahan yang kamu buat!

🛠️ Tugas 2: Rencana Tata Kelola

Skenario: Kamu ditugaskan membuat website e-commerce sederhana untuk toko online. Website ini akan memiliki halaman home, produk, keranjang, dan checkout.

Yang harus kamu buat:

  1. Struktur folder lengkap untuk proyek e-commerce
  2. Konvensi penamaan file yang akan digunakan
  3. Rencana backup dan version control
  4. Checklist tata kelola harian untuk proyek ini

💡 Tugas 3: Studi Kasus

Kasus: Tim development kamu mengalami masalah berikut:

Masalah 1: File gambar terlalu besar, website jadi lambat
Masalah 2: Developer sering overwrite file satu sama lain
Masalah 3: Sulit mencari file tertentu karena nama tidak konsisten

Tugas kamu:

Berikan solusi konkret untuk setiap masalah di atas berdasarkan materi yang sudah dipelajari!
