Pengenalan Struktur Percabangan

🤖 Apa itu Struktur Percabangan?

Struktur percabangan (selection/kondisi) adalah struktur kontrol yang memungkinkan program untuk membuat keputusan berdasarkan kondisi tertentu. Seperti persimpangan jalan, program akan memilih jalur mana yang akan diambil berdasarkan kondisi yang diberikan.

🌟 Contoh dalam Kehidupan Sehari-hari:

🌧️

Jika hujan

Bawa payung

🍕

Jika lapar

Makan makanan

😴

Jika mengantuk

Tidur

🎯 Jenis-jenis Struktur Percabangan

1️⃣ If Statement

Percabangan satu arah - hanya mengeksekusi kode jika kondisi benar.

if (kondisi) {
  // kode yang dijalankan
}

2️⃣ If-Else Statement

Percabangan dua arah - ada pilihan jika kondisi benar atau salah.

if (kondisi) {
  // jika benar
} else {
  // jika salah
}

3️⃣ If-Else If Statement

Percabangan bertingkat - banyak kondisi yang bisa dicek.

if (kondisi1) {
  // kode 1
} else if (kondisi2) {
  // kode 2
} else {
  // kode default
}

4️⃣ Switch Case Statement

Percabangan multi-pilihan - cocok untuk banyak pilihan tetap.

switch (variabel) {
  case nilai1:
    // kode
    break;
  default:
    // kode default
}
🔍

If Statement

Percabangan Satu Arah

📖 Konsep If Statement

If statement adalah struktur percabangan paling sederhana. Kode di dalam blok if hanya akan dijalankan jika kondisi bernilai true (benar). Jika kondisi false (salah), maka kode akan dilewati.

🎭 Simulasi If Statement

💻 Sintaks If Statement

Struktur Dasar:

if (kondisi) {
  // kode yang dijalankan jika kondisi benar
}

Contoh dalam JavaScript:

let umur = 18;
if (umur >= 17) {
  console.log("Sudah boleh punya SIM!");
}

If-Else Statement

Percabangan Dua Arah

🎪 Konsep If-Else Statement

If-else statement memberikan dua pilihan: satu untuk kondisi benar (true) dan satu untuk kondisi salah (false). Ini seperti persimpangan jalan dengan dua arah - kita pasti akan mengambil salah satu jalur.

🎮 Simulasi Cek Nilai

⚡ Sintaks If-Else Statement

Struktur Dasar:

if (kondisi) {
  // kode jika kondisi benar
} else {
  // kode jika kondisi salah
}

Contoh Praktis:

let nilai = 75;
if (nilai >= 70) {
  console.log("Lulus! 🎉");
} else {
  console.log("Belum lulus 😢");
}

If-Else If Statement

Percabangan Bertingkat

🌈 Konsep If-Else If Statement

If-else if statement memungkinkan kita untuk mengecek beberapa kondisi secara berurutan. Seperti memilih menu di restoran - kita punya banyak pilihan dan akan memilih yang pertama kali cocok dengan selera kita.

🌡️ Simulasi Cek Suhu

🔧 Sintaks If-Else If Statement

Struktur Dasar:

if (kondisi1) {
  // kode untuk kondisi1
} else if (kondisi2) {
  // kode untuk kondisi2
} else if (kondisi3) {
  // kode untuk kondisi3
} else {
  // kode default
}

Contoh Grading System:

let nilai = 85;
if (nilai >= 90) {
  grade = "A";
} else if (nilai >= 80) {
  grade = "B";
} else if (nilai >= 70) {
  grade = "C";
} else if (nilai >= 60) {
  grade = "D";
} else {
  grade = "E";
}

Switch Case Statement

Percabangan Multi-Pilihan

🎪 Konsep Switch Case Statement

Switch case statement adalah alternatif yang lebih rapi untuk if-else if ketika kita perlu membandingkan satu variabel dengan banyak nilai yang berbeda. Seperti remote TV dengan banyak tombol - setiap tombol punya fungsi yang berbeda.

📅 Simulasi Hari dalam Seminggu

⚙️ Sintaks Switch Case Statement

Struktur Dasar:

switch (variabel) {
  case nilai1:
    // kode untuk nilai1
    break;
  case nilai2:
    // kode untuk nilai2
    break;
  default:
    // kode default
}

💡 Tips: Jangan lupa break; di setiap case untuk menghindari fall-through!

Contoh Kalkulator Sederhana:

let operator = "+";
let a = 10, b = 5;

switch (operator) {
  case "+":
    result = a + b;
    break;
  case "-":
    result = a - b;
    break;
  case "*":
    result = a * b;
    break;
  case "/":
    result = a / b;
    break;
  default:
    result = "Operator tidak valid";
}

🧮 Demo Interaktif: Kalkulator Mini

⚖️ Switch vs If-Else If

✅ Kapan Pakai Switch?

  • • Membandingkan satu variabel dengan banyak nilai tetap
  • • Nilai yang dibandingkan adalah konstanta (angka, string)
  • • Kode lebih rapi dan mudah dibaca
  • • Performa sedikit lebih baik untuk banyak case

🎯 Kapan Pakai If-Else If?

  • • Kondisi yang kompleks (>, <, >=, <=)
  • • Membandingkan berbagai variabel
  • • Kondisi dengan operator logika (&&, ||)
  • • Rentang nilai (misalnya: 80-89)

Tugas Pembelajaran

Uji Pemahaman Kalian!

1️⃣ Analisis Kode

Perhatikan kode berikut dan jelaskan apa yang akan terjadi jika variabel umur = 16:

let umur = 16;
if (umur >= 17) {
  console.log("Boleh buat SIM");
} else {
  console.log("Belum boleh buat SIM");
}

2️⃣ Membuat Flowchart

Buatlah flowchart sederhana untuk program yang mengecek apakah sebuah angka adalah bilangan genap atau ganjil. Gunakan struktur if-else.

3️⃣ Menulis Kode

Buatlah program menggunakan if-else if untuk menentukan kategori BMI (Body Mass Index) berdasarkan kriteria berikut:

  • • BMI < 18.5: Kurus
  • • BMI 18.5-24.9: Normal
  • • BMI 25-29.9: Gemuk
  • • BMI ≥ 30: Obesitas

4️⃣ Switch Case Challenge

Buatlah program menggunakan switch case untuk menampilkan nama bulan berdasarkan nomor bulan (1-12). Jangan lupa tambahkan case default untuk input yang tidak valid!

5️⃣ Studi Kasus

Kalian diminta membuat sistem penilaian untuk sebuah game. Buatlah program yang menentukan level pemain berdasarkan skor:

  • • Skor 0-199: Pemula
  • • Skor 200-499: Menengah
  • • Skor 500-799: Mahir
  • • Skor 800-999: Expert
  • • Skor ≥ 1000: Master

Jelaskan mengapa kalian memilih menggunakan if-else if atau switch case untuk kasus ini!
