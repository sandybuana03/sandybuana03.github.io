Pengenalan Materi

🏢 Apa itu Pengelolaan Aset Proyek?

Pengelolaan aset proyek adalah proses mengatur, melacak, dan mengelola semua sumber daya digital yang digunakan dalam sebuah proyek IT. Ini termasuk software, kode program, gambar, musik, dan semua file digital lainnya.

📋 Regulasi di Indonesia:

  • • UU No. 28 Tahun 2014: Tentang Hak Cipta
  • • UU No. 11 Tahun 2008: Tentang Informasi dan Transaksi Elektronik (ITE)
  • • Peraturan Menteri: Tentang penggunaan software legal di instansi pemerintah

⚖️ Mengapa Penting?

  • • Menghindari masalah hukum
  • • Menjaga reputasi perusahaan
  • • Menghemat biaya lisensi
  • • Memastikan keamanan data

🎯 Contoh Aset Digital

  • • Software dan aplikasi
  • • Kode program dan library
  • • Gambar dan ikon
  • • Font dan template

Jenis-Jenis Lisensi Perangkat Lunak

🔒 Proprietary Software (Berbayar)

Karakteristik:

  • • Kode sumber tertutup
  • • Harus membeli lisensi
  • • Dukungan resmi dari vendor
  • • Fitur lengkap dan terintegrasi

Contoh:

  • • Microsoft Office
  • • Adobe Photoshop
  • • Windows OS
  • • AutoCAD

🔓 Open Source Software (Gratis)

Karakteristik:

  • • Kode sumber terbuka
  • • Gratis untuk digunakan
  • • Dapat dimodifikasi
  • • Komunitas yang aktif

Contoh:

  • • LibreOffice
  • • GIMP
  • • Linux Ubuntu
  • • Visual Studio Code

🆓 Freeware

Karakteristik:

  • • Gratis selamanya untuk digunakan
  • • Kode sumber tertutup
  • • Tidak boleh dimodifikasi
  • • Fitur lengkap tanpa batasan waktu
  • • Biasanya didukung iklan atau donasi

Contoh:

  • • Skype
  • • Google Chrome
  • • WhatsApp Desktop
  • • VLC Media Player
  • • Audacity

🎨 Creative Commons (CC)

Jenis Lisensi CC:

  • • CC0: Domain publik, bebas digunakan
  • • CC BY: Wajib mencantumkan kredit
  • • CC BY-SA: Kredit + share alike
  • • CC BY-NC: Kredit + non-komersial
  • • CC BY-ND: Kredit + no derivatives

Cocok untuk:

  • • Gambar dan foto
  • • Musik dan audio
  • • Video dan animasi
  • • Dokumen dan artikel
  • • Font dan desain

⭐ Freemium

Karakteristik:

  • • Versi dasar gratis
  • • Fitur premium berbayar
  • • Tidak ada batasan waktu
  • • Upgrade opsional

Contoh:

  • • Canva (desain)
  • • Figma (UI/UX)
  • • Notion (produktivitas)
  • • GitHub (repositori)

⏰ Shareware (Trial)

Karakteristik:

  • • Gratis untuk periode tertentu
  • • Fitur terbatas atau watermark
  • • Harus beli setelah trial habis
  • • Untuk mencoba sebelum membeli

Contoh:

  • • Adobe Creative Suite (trial)
  • • Microsoft Office (trial)
  • • Antivirus (trial)
  • • Game premium (demo)

Hak Cipta (Copyright)

📚 Apa itu Hak Cipta?

Hak cipta adalah hak eksklusif yang diberikan kepada pencipta untuk mengontrol penggunaan, distribusi, dan modifikasi karya mereka. Ini melindungi karya intelektual seperti software, musik, gambar, dan tulisan.

Yang Dilindungi Hak Cipta:

  • • Kode program dan software
  • • Desain website dan aplikasi
  • • Gambar dan ilustrasi
  • • Musik dan audio
  • • Video dan animasi
  • • Teks dan dokumentasi

🚫 Yang TIDAK Boleh Dilakukan

  • • Mengcopy kode tanpa izin
  • • Menggunakan gambar dari Google
  • • Download software bajakan
  • • Menggunakan font berbayar gratis
  • • Copy-paste dari website lain

✅ Yang BOLEH Dilakukan

  • • Menggunakan open source software
  • • Gambar dari Unsplash/Pixabay
  • • Font gratis dari Google Fonts
  • • Kode dengan lisensi MIT/GPL
  • • Membuat karya sendiri

Pengelolaan Aset Digital

📋 Langkah-Langkah Pengelolaan Aset

1 Inventarisasi Aset

Buat daftar semua software, gambar, font, dan aset digital yang digunakan dalam proyek

2 Cek Lisensi

Pastikan setiap aset memiliki lisensi yang sesuai dengan kebutuhan proyek

3 Dokumentasi

Simpan semua dokumen lisensi dan bukti pembelian dengan rapi

4 Monitoring

Pantau masa berlaku lisensi dan perpanjang sebelum habis

5 Update Berkala

Lakukan audit berkala untuk memastikan compliance

6 Backup & Arsip

Simpan backup semua aset dan dokumentasi lisensi

Excel, Google Sheets, Airtable, Trello, Asana

🔍 License Scanning

Git, GitHub, GitLab, Bitbucket

📚 Documentation

Menggunakan software yang sudah habis masa berlakunya

  • • Buat sistem penamaan yang konsisten

Studi Kasus Nyata

⚠️ Kasus 1: Perusahaan Kena Denda Miliaran

Situasi:

Sebuah perusahaan IT di Jakarta menggunakan software Adobe dan Microsoft tanpa lisensi resmi untuk menghemat biaya. Mereka menggunakan software bajakan selama 3 tahun.

Yang Terjadi:

  • • Audit mendadak dari BSA (Business Software Alliance)
  • • Ditemukan 50+ software ilegal
  • • Denda Rp 2.5 miliar
  • • Reputasi perusahaan hancur

💡 Pelajaran: Menghemat biaya lisensi justru merugikan lebih besar!

✅ Kasus 2: Startup Sukses dengan Open Source

Situasi:

Startup teknologi di Bandung membangun aplikasi e-commerce menggunakan 100% open source dan free tools untuk menekan biaya operasional.

Tools yang Digunakan:

  • • Linux Ubuntu (OS)
  • • VS Code (Editor)
  • • React.js (Frontend)
  • • Node.js (Backend)
  • • PostgreSQL (Database)

💡 Hasil: Berhasil menghemat Rp 500 juta biaya lisensi dan berkembang pesat!

🎓 Kasus 3: Proyek Sekolah yang Benar

Situasi:

Tim siswa SMK membuat website sekolah untuk lomba. Mereka ingin menggunakan berbagai aset digital tapi tidak punya budget besar.

Solusi Cerdas:

🎨 Design & Media
  • • Gambar: Unsplash, Pixabay
  • • Ikon: Heroicons, Feather
  • • Font: Google Fonts
  • • Logo: Canva (gratis)
💻 Development
  • • Editor: VS Code
  • • Framework: Bootstrap
  • • Version Control: Git
  • • Repository: GitHub
🌐 Deployment
  • • Hosting: Netlify/Vercel
  • • Domain: Freenom (.tk)
  • • CDN: Cloudflare (gratis)
  • • Analytics: Google Analytics

💡 Hasil: Website profesional dengan biaya Rp 0 dan 100% legal!

🏢 Kasus 4: Perusahaan yang Beralih ke Open Source

Situasi:

Perusahaan software house dengan 50 karyawan ingin mengurangi biaya lisensi yang mencapai Rp 500 juta per tahun. Mereka memutuskan migrasi ke open source.

Strategi Migrasi:

📊 Sebelum (Proprietary)
  • • Windows Server: Rp 200 juta
  • • Microsoft Office: Rp 150 juta
  • • Adobe Creative Suite: Rp 100 juta
  • • Database Oracle: Rp 50 juta
🆓 Sesudah (Open Source)
  • • Ubuntu Server: Gratis
  • • LibreOffice: Gratis
  • • GIMP + Inkscape: Gratis
  • • PostgreSQL: Gratis

💡 Hasil: Hemat Rp 450 juta/tahun + kontrol penuh atas sistem!

🎮 Kasus 5: Game Developer Indie yang Sukses

Situasi:

Developer indie membuat game mobile dengan budget terbatas. Mereka harus cerdas memilih tools dan aset yang legal namun terjangkau.

Stack Technology:

🎯 Game Engine
  • • Unity (Personal - gratis)
  • • Godot (open source)
  • • Blender (3D modeling)
🎨 Art & Audio
  • • GIMP (graphics)
  • • Audacity (audio editing)
  • • Freesound (sound effects)
📱 Publishing
  • • Google Play Console
  • • Unity Analytics (gratis)
  • • GitHub (version control)

💡 Hasil: Game sukses di Play Store dengan investasi tools minimal!

  • 2. Apa konsekuensi yang mungkin terjadi?
  • 3. Bagaimana seharusnya teman kalian bertindak?
