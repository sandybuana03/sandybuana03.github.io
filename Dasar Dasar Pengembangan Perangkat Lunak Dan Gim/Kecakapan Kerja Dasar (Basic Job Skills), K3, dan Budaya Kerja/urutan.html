Konsep Dasar Struktur Urutan

📖 Definisi Struktur Urutan

Struktur Urutan (Sequential Structure) adalah struktur algoritma dimana setiap langkah atau instruksi dilaksanakan secara berurutan dari atas ke bawah, satu per satu, tanpa ada lompatan atau pengulangan.

🎯 Langkah 1 → Langkah 2 → Langkah 3 → Selesai

🍳 Analogi Sederhana

🍜 Membuat Mie Instan

  1. 1Rebus air
  2. 2Masukkan mie
  3. 3Tunggu 3 menit
  4. 4Tambah bumbu
  5. 5Aduk dan sajikan

💻 Program Sederhana

  1. 1Input nama
  2. 2Input umur
  3. 3Hitung tahun lahir
  4. 4Tampilkan hasil
  5. 5Program selesai

💡 Perhatikan: Kedua contoh di atas mengikuti urutan yang tidak bisa ditukar!

🔬 Analisis Mendalam: Mengapa "Deterministik"?

🎯 Apa Artinya Deterministik?

Deterministik berarti dengan input yang sama, algoritma akan selalu menghasilkan output yang sama. Tidak ada unsur kebetulan atau acak!

✅ Contoh Deterministik
  • • 5 + 3 = 8 (selalu)
  • • Resep kue (hasil konsisten)
  • • Menghitung luas persegi
  • • Konversi suhu C ke F
❌ Bukan Deterministik
  • • Melempar dadu
  • • Cuaca besok
  • • Hasil undian
  • • Random number generator

🧪 Eksperimen: Uji Deterministik

Coba hitung: (10 + 5) × 2 - 3

Karakteristik Struktur Urutan

🎯 1. Berurutan (Sequential)

Setiap langkah harus dilakukan secara berurutan, tidak boleh melompat atau mengacak urutan.

Contoh: Tidak bisa langsung memakai baju sebelum mandi! 🚿👕

⏱️ 2. Satu per Satu

Hanya satu instruksi yang dijalankan pada satu waktu, tidak ada yang bersamaan.

Contoh: Tidak bisa mengetik sambil mengklik mouse di tempat yang sama! ⌨️🖱️

🚫 3. Tidak Ada Lompatan

Tidak ada percabangan atau pengulangan, semua langkah dijalankan dari awal sampai akhir.

Contoh: Seperti membaca buku dari halaman 1, 2, 3... sampai selesai! 📖

🎪 4. Deterministik

Dengan input yang sama, akan selalu menghasilkan output yang sama.

Contoh: 2 + 3 akan selalu = 5, tidak pernah berubah! 🧮

⚖️ Kelebihan dan Kekurangan

✅ Kelebihan

  • •Mudah dipahami dan dibuat
  • •Logika sederhana dan jelas
  • •Cocok untuk masalah linear
  • •Mudah di-debug
  • •Eksekusi cepat dan efisien
  • •Mudah dikonversi ke kode program

❌ Kekurangan

  • •Tidak fleksibel
  • •Tidak bisa menangani kondisi
  • •Tidak efisien untuk masalah kompleks
  • •Sulit untuk masalah bercabang
  • •Tidak bisa mengulang proses
  • •Terbatas untuk aplikasi sederhana

🎯 Kapan Menggunakan Struktur Urutan?

✅ Cocok Untuk:
  • • Perhitungan matematika sederhana
  • • Konversi data (suhu, mata uang)
  • • Input-proses-output linear
  • • Algoritma dasar tanpa kondisi
  • • Proses berurutan yang pasti
❌ Tidak Cocok Untuk:
  • • Sistem dengan pilihan menu
  • • Validasi input pengguna
  • • Proses berulang (loop)
  • • Logika bisnis kompleks
  • • Sistem interaktif

🧪 Eksperimen: Bandingkan Efisiensi

🔄 Dengan Struktur Urutan

⚡ Waktu: ~0.001 detik

🔀 Dengan Struktur Kompleks

1. Input jari-jari
2. Cek apakah r > 0?
3. Jika ya, hitung luas
4. Jika tidak, tampilkan error
5. Ulangi jika input salah
6. Tampilkan hasil
⏳ Waktu: ~0.005 detik
