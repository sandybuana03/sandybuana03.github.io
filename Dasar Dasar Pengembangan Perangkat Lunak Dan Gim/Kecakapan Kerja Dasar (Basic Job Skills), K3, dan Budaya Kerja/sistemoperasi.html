Pengenalan Sistem Operasi

🤖 Apa itu Sistem Operasi?

Sistem Operasi (OS) adalah software yang mengelola hardware komputer dan menyediakan layanan untuk program aplikasi. Bayangkan OS seperti manajer yang mengatur semua aktivitas di komputer!

Fungsi Utama OS:

  • 🔧 Mengelola hardware (CPU, RAM, Storage)
  • 📁 Mengatur file dan folder
  • 🛡️ Menyediakan keamanan sistem
  • 🎮 Menjalankan aplikasi
  • 🌐 Mengelola jaringan dan koneksi
  • 👥 Mengatur user dan permission

Komponen OS:

  • 🧠 Kernel (inti sistem)
  • 🖥️ User Interface (GUI/CLI)
  • 📂 File System
  • 🔄 Process Manager
  • 💾 Memory Manager
  • 🔌 Device Drivers

💡 Analogi Sederhana:

OS seperti manajer restoran yang mengatur:

👨‍🍳 Chef (CPU) - memasak pesanan
🍽️ Meja (RAM) - tempat kerja sementara
🏪 Gudang (Storage) - penyimpanan bahan

🕰️

1940s-1950s: Era Awal

1960s-1970s: Batch & Time-sharing

🖥️

1980s-1990s: Personal Computer

MS-DOS, Windows, Mac OS - era GUI dimulai

🌐

2000s-sekarang: Internet & Mobile

Linux server dominan, mobile OS (iOS/Android), cloud computing
