Pengenalan CLI

Mari berkenalan dengan Command Line Interface!

🖥️ Apa itu Command Line Interface?

Command Line Interface (CLI) adalah cara berkomunikasi dengan komputer menggunakan perintah teks. Bayangkan seperti chatting dengan komputer, tapi menggunakan bahasa khusus yang dia mengerti!

C:\Users\Siswa> dir

✅ Keunggulan CLI

  • • ⚡ Lebih cepat dari GUI
  • • 🎯 Presisi tinggi
  • • 🤖 Bisa diotomatisasi
  • • 💾 Hemat resource
  • • 🔧 Kontrol penuh sistem

🎨 GUI vs CLI

🖱️ GUI: Point & Click
⌨️ CLI: Type & Enter

🌟 Mengapa Penting untuk SMK?

Sebagai siswa SMK, menguasai CLI akan membuatmu unggul di dunia kerja. Banyak pekerjaan IT membutuhkan skill ini, dari web development, system administration, hingga cybersecurity. CLI adalah fondasi untuk menjadi teknisi yang handal!

Apa itu CLI?

Memahami CLI secara mendalam

🔍 Definisi Lengkap

CLI adalah antarmuka berbasis teks yang memungkinkan pengguna berinteraksi dengan sistem operasi atau aplikasi melalui perintah yang diketik. Tidak seperti GUI yang menggunakan ikon dan menu, CLI menggunakan perintah teks.

🖥️

Terminal

Program yang menjalankan CLI

🐚

Shell

Interpreter perintah

⚡

Command

Perintah yang dijalankan

🎭 Jenis-jenis CLI

🪟 Windows
  • • Command Prompt (cmd)
  • • PowerShell
  • • Windows Terminal
🐧 Linux/Mac
  • • Bash
  • • Zsh
  • • Fish

🎯 Cara Membuka CLI

🪟 Windows:
  • • Win + R → ketik "cmd" → Enter
  • • Win + X → pilih "Command Prompt"
  • • Start Menu → ketik "cmd"
  • • Shift + Right-click di folder → "Open command window here"

🐧 Linux/Mac:
  • • Ctrl + Alt + T (Linux)
  • • Cmd + Space → ketik "terminal" (Mac)
  • • Applications → Terminal
  • • Right-click → "Open Terminal Here"

Perintah Dasar CLI

Mari pelajari perintah-perintah fundamental!

📋 dir / ls

Melihat isi folder/direktori

Windows:
C:\Users\Siswa> dir
Desktop/
Documents/
Downloads/
Linux/Mac:
user@computer:~$ ls
Desktop Documents Downloads

📍 cd

Pindah ke folder lain (Change Directory)

Windows:
C:\Users\Siswa> cd Desktop
C:\Users\Siswa\Desktop>
Linux/Mac:
user@computer:~$ cd Desktop
user@computer:~/Desktop$

🎮 Simulasi Interaktif

C:\Users\Siswa> Ketik perintah di bawah!
C:\Users\Siswa>

❓ help

Menampilkan bantuan

🧹 cls / clear

Windows: cls | Linux/Mac: clear

Membersihkan layar terminal

🚪 exit

Keluar dari CLI

💡 Tips Penting

  • ⌨️ Gunakan Tab untuk auto-complete
  • ⬆️ Panah atas untuk perintah sebelumnya
  • 📝 Linux/Mac case-sensitive, Windows tidak (huruf besar/kecil)
  • 🔤 Spasi memisahkan perintah dan parameter

Navigasi File System

Menjelajahi file dan folder dengan CLI

🗂️ Struktur Direktori

🪟 Windows Structure:
C:\
├── Users/
│ ├── Siswa/
│ │ ├── Desktop/
│ │ ├── Documents/
│ │ └── Downloads/
├── Program Files/
└── Windows/
🐧 Linux Structure:
/
├── home/
│ └── user/
│ ├── Desktop/
│ ├── Documents/
│ └── Downloads/
├── usr/
└── etc/

🎯 Path Absolut

Path lengkap dari root directory

cd C:\Users\Siswa\Desktop

🔗 Path Relatif

Path dari lokasi saat ini

cd Desktop
cd ..
cd ./Documents

🧭 Perintah Navigasi Penting

Windows: cd (tanpa parameter)
Linux/Mac: pwd

Lihat lokasi/direktori saat ini

cd ..

Naik satu level

Windows: cd %USERPROFILE%
Linux/Mac: cd ~

Ke home directory (folder user)

Windows: cd \ atau cd C:\
Linux/Mac: cd /

Ke root directory (direktori utama)

Manipulasi File & Folder

Membuat, menghapus, dan mengelola file

📁 Membuat Folder

Windows: mkdir nama_folder
Windows: md nama_folder
Linux/Mac: mkdir nama_folder

Kedua sistem operasi menggunakan mkdir, Windows juga bisa pakai md

📄 Membuat File

Windows: echo "Hello" > file.txt
Windows: type nul > file.txt (kosong)
Linux/Mac: echo "Hello" > file.txt
Linux/Mac: touch file.txt (kosong)

Membuat file dengan isi atau file kosong

🗑️ Menghapus File & Folder

Hapus File:

Windows: del nama_file.txt
Linux/Mac: rm nama_file.txt

Hapus Folder:

Windows: rmdir nama_folder (kosong)
Windows: rmdir /s nama_folder (berisi)
Linux/Mac: rmdir nama_folder (kosong)
Linux/Mac: rm -r nama_folder (berisi)

⚠️ Hati-hati! Penghapusan melalui CLI bersifat permanen!

📋 Copy & Move

Copy:
Windows: copy file.txt backup.txt
Linux/Mac: cp file.txt backup.txt
Move:
Windows: move file.txt folder/
Linux/Mac: mv file.txt folder/

👁️ Melihat Isi File

Melihat Seluruh Isi:
Windows: type nama_file.txt
Linux/Mac: cat nama_file.txt
Melihat Per Halaman:
Windows: more nama_file.txt
Linux/Mac: less nama_file.txt

Tips & Tricks

Menjadi master CLI dengan tips jitu!

⚡ Shortcut Keyboard

Universal:
  • Tab Auto-complete
  • ↑↓ History perintah
  • Ctrl+C Stop perintah
  • Ctrl+L Clear screen
    • Linux/Mac:
  • Ctrl+A Awal baris
  • Ctrl+E Akhir baris
  • Ctrl+U Hapus baris
  • Ctrl+R Search history

    • 🔍 Wildcard & Pattern

    • * - Semua file
    • *.txt - File .txt saja
    • ? - Satu karakter
    • file?.txt - file1.txt, file2.txt

    🔗 Piping & Redirection

    Output ke File:

    dir > daftar.txt
    echo "Hello" >> file.txt

    Pipe Commands:

    dir | find "txt"
    ls | grep "file"

    🎨 Kustomisasi CLI

    Ubah Warna:

    color 0A (Hijau di hitam)

    Ubah Title:

    title "CLI Keren Saya"

    ⚠️ Kesalahan Umum

    ❌ Salah:
    CD desktop

    Huruf besar semua

    ✅ Benar:
    cd Desktop

    Sesuai nama asli folder

    ❌ Salah:
    del *.* /s

    Berbahaya!

    ✅ Benar:
    del file.txt

    Spesifik file

    🏆 Pro Tips

    • 🎯
      Gunakan alias: Buat shortcut untuk perintah panjang doskey ll=dir /w
    • 📚
      Pelajari help: Setiap perintah punya manual dir /?
    • 🔄
      Batch files: Otomatisasi tugas berulang dengan .bat
