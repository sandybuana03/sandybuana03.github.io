Pengenalan Pseudocode

Bayangkan kamu ingin mengajarkan temanmu cara membuat mie instan. Kamu tidak bisa langsung bilang "bikin mie", kan?

Definisi Pseudocode

Apa itu Pseudocode? 🤔

Pseudocode adalah cara penulisan algoritma yang menggunakan bahasa sehari-hari (bahasa natural) yang mudah dipahami, namun tetap mengikuti struktur logika pemrograman.

🔤 Asal Kata

Pseudo = Palsu/Tiruan

Code = Kode Program

Jadi: "Kode Tiruan" atau "Kode Semu"

🎯 Tujuan

  • • Memudahkan perencanaan program
  • • Komunikasi antar programmer
  • • Dokumentasi algoritma
  • • Debugging dan testing

💭 Ingat!

Pseudocode bukan bahasa pemrograman yang bisa dijalankan komputer. Ini hanya alat bantu untuk merencanakan dan menjelaskan algoritma!

⭐

Karakteristik Pseudocode

🗣️

Bahasa Natural

Menggunakan bahasa sehari-hari yang mudah dipahami, bukan sintaks pemrograman yang rumit.

📋

Terstruktur

Mengikuti alur logika yang jelas dengan urutan langkah yang sistematis.

🎯

Spesifik

Setiap langkah dijelaskan dengan detail dan tidak ambigu.

🔄

Independen

Tidak terikat pada bahasa pemrograman tertentu.

🔍 Contoh Perbandingan

❌ Bukan Pseudocode

for(int i=0; i<10; i++){

  printf("%d", i);

}

Ini adalah kode C yang sesungguhnya

✅ Pseudocode

UNTUK i = 0 SAMPAI 9

  TAMPILKAN i

AKHIR UNTUK

Mudah dipahami siapa saja!

Struktur Dasar Pseudocode

📥📤 Input dan Output

Input:

BACA nama

INPUT umur

MASUKKAN nilai

Output:

TULIS "Hello World"

TAMPILKAN hasil

CETAK total

📦 Deklarasi Variabel & Assignment

Deklarasi Variabel:

DEKLARASI

  nama : string

  umur : integer

  tinggi : real

  lulus : boolean

Assignment (Pemberian Nilai):

nama ← "Budi"

umur ← 17

tinggi ← 165.5

lulus ← true

📝 Tipe Data Dasar:

string: teks
integer: bilangan bulat
real: bilangan desimal
boolean: true/false

🔢 Operator Matematika:

+ penjumlahan
- pengurangan
* perkalian
/ pembagian
MOD sisa bagi

⚖️ Operator Perbandingan:

= sama dengan
≠ tidak sama
> lebih besar
< lebih kecil
≥ lebih besar sama dengan
≤ lebih kecil sama dengan

🔀 Struktur Percabangan

IF Sederhana:

JIKA kondisi MAKA

  aksi

AKHIR JIKA

IF-ELSE:

JIKA kondisi MAKA

  aksi1

SELAIN ITU

  aksi2

AKHIR JIKA

🔄 Struktur Perulangan

FOR (Perulangan Terhitung):

UNTUK i = 1 SAMPAI 10

  aksi

AKHIR UNTUK

Digunakan ketika jumlah perulangan sudah diketahui

WHILE (Perulangan Berkondisi):

SELAMA kondisi

  aksi

AKHIR SELAMA

Perulangan selama kondisi masih benar

REPEAT-UNTIL:

ULANGI

  aksi

SAMPAI kondisi

Minimal dijalankan 1 kali, berhenti ketika kondisi benar

🔍 Perbedaan WHILE vs REPEAT-UNTIL:

WHILE:

• Cek kondisi di awal

• Mungkin tidak dijalankan sama sekali

• Lanjut SELAMA kondisi benar

REPEAT-UNTIL:

• Cek kondisi di akhir

• Minimal dijalankan 1 kali

• Berhenti SAMPAI kondisi benar

Contoh Praktis Pseudocode

🟦 Contoh 1: Menghitung Luas Persegi

Pseudocode:

MULAI

DEKLARASI

  sisi : real

  luas : real

TULIS "Masukkan panjang sisi:"

BACA sisi

luas ← sisi * sisi

TULIS "Luas persegi:", luas

🔢 Contoh 2: Mencari Nilai Terbesar dari 3 Angka

Pseudocode:

MULAI

DEKLARASI

  a, b, c, max : integer

TULIS "Masukkan 3 angka:"

BACA a, b, c

max ← a

JIKA b > max MAKA

  max ← b

AKHIR JIKA

JIKA c > max MAKA

  max ← c

AKHIR JIKA

TULIS "Nilai terbesar:", max

🔄 Contoh 3: Menghitung Faktorial

Pseudocode:

MULAI

DEKLARASI

  n, i, faktorial : integer

TULIS "Masukkan bilangan:"

BACA n

JIKA n >= 0 MAKA

  faktorial ← 1

  UNTUK i = 1 SAMPAI n

    faktorial ← faktorial * i

  AKHIR UNTUK

  TULIS n, "! =", faktorial

SELAIN ITU

  TULIS "Faktorial tidak terdefinisi untuk bilangan negatif"

AKHIR JIKA

SELESAI

💡 Catatan: 0! = 1 (faktorial nol sama dengan satu)
