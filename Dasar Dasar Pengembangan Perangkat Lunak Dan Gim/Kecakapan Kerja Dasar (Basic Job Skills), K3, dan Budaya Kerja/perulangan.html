📚 Pengenalan Struktur Perulangan

🔄 Apa itu Perulangan?

Perulangan (looping) adalah struktur kontrol yang memungkinkan kita menjalankan blok kode yang sama berulang kali sampai kondisi tertentu terpenuhi atau sejumlah iterasi tertentu tercapai.

🎭 Analogi Kehidupan Sehari-hari:

🏃‍♂️

For Loop: Lari keliling lapangan 10 kali (jumlah pasti)

📚

While Loop: Baca buku sampai selesai (kondisi dinamis)

🎵

Do-While: Dengar lagu minimal 1x, ulangi jika suka

🧠 Filosofi Perulangan:

Perulangan mencerminkan pola berpikir manusia yang efisien. Ketika kita menemukan solusi yang berhasil, kita cenderung mengulanginya sampai masalah selesai.

Contoh: Saat belajar mengendarai sepeda, kita mengulang gerakan "kayuh → keseimbangan → kayuh" sampai mahir.

🎯 Mengapa Perulangan Penting?

✅ Keuntungan:

  • • Menghemat waktu coding (DRY principle)
  • • Kode lebih efisien dan rapi
  • • Mudah maintenance dan debugging
  • • Mengurangi kesalahan copy-paste
  • • Memungkinkan pemrosesan data besar
  • • Dasar untuk algoritma kompleks

❌ Tanpa Loop:

  • • Kode sangat panjang dan repetitif
  • • Banyak pengulangan kode (code duplication)
  • • Sulit diubah dan di-maintain
  • • Rawan error dan typo
  • • Tidak scalable untuk data besar
  • • Melanggar prinsip clean code

💡 Contoh Perbandingan:

❌ Tanpa Loop (100 baris!):

print(1)
print(2)
print(3)
...
print(100)

✅ Dengan Loop (3 baris!):

for i = 1 to 100 {
  print(i)
}

🔢 Jenis-jenis Perulangan

🔁

For Loop

Untuk perulangan dengan jumlah yang sudah diketahui

Kapan: Iterasi array, countdown, pattern
🔄

While Loop

🔃

Do-While

Kapan: Menu systems, game loops, user input

🎯 Pemilihan Loop yang Tepat:

🔁 Gunakan FOR ketika: Tahu jumlah iterasi pasti, iterasi array/list, membuat pattern

🔄 Gunakan WHILE ketika: Kondisi dinamis, tidak tahu kapan berhenti, validasi input

🔃 Gunakan DO-WHILE ketika: Perlu eksekusi minimal 1x, menu interaktif, game loop

🔁 For Loop

📝 Sintaks For Loop

JavaScript
for (inisialisasi; kondisi; increment/decrement) {
// kode yang akan diulang
}

📋 Penjelasan Bagian:

  • Inisialisasi: Menentukan nilai awal variabel counter (misal: i = 1)
  • Kondisi: Syarat untuk melanjutkan loop (misal: i <= 10)
  • Increment/Decrement: Mengubah nilai counter setiap iterasi (misal: i++)

For loop digunakan ketika kita sudah tahu berapa kali perulangan akan dilakukan.

💡 Contoh Penggunaan For Loop

🎯 Contoh 1: Cetak Angka

Pseudocode
for (i = 1; i <= 5; i++) {
print(i)
}

Output: 1 2 3 4 5

Loop berjalan 5 kali, i dimulai dari 1

🌟 Contoh 2: Tabel Perkalian

Pseudocode
for (i = 1; i <= 3; i++) {
print("2 x " + i + " = " + (2*i))
}

Output:

2 x 1 = 2
2 x 2 = 4
2 x 3 = 6

⚡ Variasi For Loop:

Mundur (Decrement):
Pseudocode
for (i = 5; i >= 1; i--) { ... }
Loncat 2 angka:
Pseudocode
for (i = 0; i <= 10; i += 2) { ... }

🔧 Advanced For Loop Techniques

🎨 Array Processing:

JavaScript
fruits = ["apple", "banana", "orange"]
for (i = 0; i < fruits.length; i++) {
print(i + ": " + fruits[i])
}

Output: 0: apple, 1: banana, 2: orange

🧮 Mathematical Series:

JavaScript
sum = 0
for (i = 1; i <= 10; i++) {
sum += i
}
print("Sum: " + sum)

Menghitung 1+2+3+...+10 = 55

🎯 For Loop Best Practices:

✅ Good Practices:

  • • Gunakan nama variabel yang jelas (i, j, k untuk simple loops)
  • • Hindari modifikasi counter di dalam loop
  • • Gunakan const untuk batas yang tidak berubah
  • • Pertimbangkan performa untuk loop besar

❌ Avoid These:

  • • Infinite loops (lupa increment)
  • • Off-by-one errors (< vs <=)
  • • Nested loops yang terlalu dalam
  • • Modifikasi array saat iterasi

🔄 While Loop

📝 Sintaks While Loop

JavaScript
while (kondisi) {
// kode yang akan diulang
// PENTING: update kondisi!
}

🔍 Cara Kerja While Loop:

  1. Cek kondisi terlebih dahulu
  2. Jika kondisi true, jalankan kode di dalam loop
  3. Setelah selesai, kembali ke langkah 1
  4. Jika kondisi false, keluar dari loop

While loop digunakan ketika kita tidak tahu pasti berapa kali perulangan akan dilakukan, tapi kita tahu kondisi kapan harus berhenti.

⚠️ Hati-hati Infinite Loop!

🚨 Contoh Loop Tak Terhingga (JANGAN DILAKUKAN!):

Pseudocode
i = 1
while (i <= 10) {
print(i)
// LUPA: i = i + 1
}

Loop ini akan berjalan selamanya karena nilai i tidak pernah berubah!

✅ Versi yang Benar:

Pseudocode
i = 1
while (i <= 10) {
print(i)
i = i + 1 // atau i++
}

Sekarang nilai i bertambah setiap iterasi, sehingga loop akan berhenti saat i > 10

🔃 Do-While Loop

📝 Sintaks Do-While Loop

JavaScript
do {
// kode yang akan diulang
// update kondisi jika perlu
} while (kondisi);

🔍 Cara Kerja Do-While Loop:

  1. Jalankan kode di dalam blok do terlebih dahulu
  2. Setelah selesai, cek kondisi di bagian while
  3. Jika kondisi true, ulangi dari langkah 1
  4. Jika kondisi false, keluar dari loop

Do-while loop mirip dengan while loop, tapi kode akan dijalankan minimal 1 kali, baru kemudian dicek kondisinya. Cocok untuk validasi input atau menu yang harus tampil minimal sekali.

🔍 Perbedaan While vs Do-While

🔄 While Loop

  • • Cek kondisi dulu, baru jalankan
  • • Bisa jadi tidak dijalankan sama sekali
  • • Kondisi di awal

🔃 Do-While Loop

  • • Jalankan dulu, baru cek kondisi
  • • Pasti dijalankan minimal 1 kali
  • • Kondisi di akhir

🎯 Nested Loop (Loop Bersarang)

🏗️ Apa itu Nested Loop?

Nested loop adalah loop di dalam loop. Seperti boneka matryoshka - ada boneka di dalam boneka! 🪆

Pseudocode
for (i = 1; i <= 3; i++) { // Loop luar
for (j = 1; j <= 2; j++) { // Loop dalam
print("i=" + i + ", j=" + j)
}
}

🔄 Cara Kerja Nested Loop:

Output contoh di atas:

i=1, j=1
i=1, j=2
i=2, j=1
i=2, j=2
i=3, j=1
i=3, j=2

Total iterasi: 3 × 2 = 6 kali

🧮 Algoritma & Optimasi Loop

🔍 Algoritma Searching dengan Loop

🎯 Linear Search

JavaScript
function linearSearch(arr, target) {
for (i = 0; i < arr.length; i++) {
if (arr[i] == target) {
return i // Found at index i
}
}
return -1 // Not found
}

Mencari elemen satu per satu dari awal sampai akhir

Kompleksitas: O(n) - worst case

⚡ Binary Search

JavaScript
function binarySearch(arr, target) {
left = 0, right = arr.length - 1
while (left <= right) {
mid = (left + right) / 2
if (arr[mid] == target) return mid
if (arr[mid] < target) left = mid + 1
else right = mid - 1
}
return -1
}

Untuk array yang sudah terurut, bagi dua area pencarian

Kompleksitas: O(log n) - jauh lebih cepat!

📊 Algoritma Sorting dengan Loop

🔄 Bubble Sort

JavaScript
function bubbleSort(arr) {
for (i = 0; i < arr.length; i++) {
for (j = 0; j < arr.length-i-1; j++) {
if (arr[j] > arr[j+1]) {
swap(arr[j], arr[j+1])
}
}
}
}

Membandingkan elemen bersebelahan dan menukar jika perlu

Kompleksitas: O(n²) - sederhana tapi lambat

⚡ Selection Sort

JavaScript
function selectionSort(arr) {
for (i = 0; i < arr.length; i++) {
minIndex = i
for (j = i+1; j < arr.length; j++) {
if (arr[j] < arr[minIndex]) {
minIndex = j
}
}
swap(arr[i], arr[minIndex])
}
}

Mencari elemen terkecil dan menempatkannya di posisi yang benar

Kompleksitas: O(n²) - lebih efisien dari bubble sort

⚡ Optimasi Loop Performance

🚀 Loop Optimization Techniques

JavaScript

✅ Cache Array Length:

// Slow: recalculates length every iteration
for (i = 0; i < arr.length; i++) { ... }
// Fast: cache the length
len = arr.length
for (i = 0; i < len; i++) { ... }
JavaScript

✅ Minimize Function Calls:

// Slow: function call in every iteration
for (i = 0; i < arr.length; i++) {
  result.push(expensiveFunction(arr[i]))
}
// Fast: batch processing
processedData = batchProcess(arr)

🎯 Loop Unrolling & Early Exit

JavaScript

✅ Early Exit Strategy:

for (i = 0; i < arr.length; i++) {
  if (arr[i] == target) {
    return i // Exit immediately when found
  }
}
JavaScript

✅ Break Complex Conditions:

// Slow: complex condition every iteration
for (i = 0; i < len && !found && count < max; i++)
// Fast: use break statements
for (i = 0; i < len; i++) {
  if (found || count >= max) break
}

🧠 Advanced Loop Patterns

🔄 Two Pointers Technique

JavaScript
// Find pair that sums to target
left = 0, right = arr.length - 1
while (left < right) {
sum = arr[left] + arr[right]
if (sum == target) return [left, right]
if (sum < target) left++
else right--
}

Efisien untuk array yang sudah terurut

🎯 Sliding Window

JavaScript
// Find max sum of k consecutive elements
windowSum = sum(arr[0:k])
maxSum = windowSum
for (i = k; i < arr.length; i++) {
windowSum += arr[i] - arr[i-k]
maxSum = max(maxSum, windowSum)
}

Optimal untuk subarray problems

🔍 Fast & Slow Pointers

JavaScript
// Detect cycle in linked list
slow = head, fast = head
while (fast && fast.next) {
slow = slow.next
fast = fast.next.next
if (slow == fast) return true
}
return false

Floyd's cycle detection algorithm

📊 Frequency Counter

JavaScript
// Count character frequency
freq = {}
for (char in string) {
freq[char] = (freq[char] || 0) + 1
}
// Now analyze frequencies

Powerful for anagram, duplicate detection
