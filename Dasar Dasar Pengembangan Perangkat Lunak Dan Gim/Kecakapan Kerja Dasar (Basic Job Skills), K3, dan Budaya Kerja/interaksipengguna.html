Pengenalan Interaksi Pengguna

🤝 Apa itu Interaksi Pengguna?

Interaksi pengguna adalah cara manusia berkomunikasi dan berinteraksi dengan sistem digital seperti website, aplikasi mobile, atau software. Ini mencakup semua cara pengguna memberikan input dan menerima feedback dari sistem.

💡 Contoh sederhana: Ketika kamu menekan tombol "Like" di media sosial, itu adalah interaksi. Sistem merespons dengan mengubah warna tombol dan menambah jumlah like.

📚 Sejarah dan Evolusi Interface

💻

Era Command Line

1970-1980an: Pengguna mengetik perintah teks untuk berinteraksi dengan komputer

🖱️

Era GUI

1980-2000an: Graphical User Interface dengan mouse, window, dan ikon

👆

Era Touch & Voice

2000an-sekarang: Layar sentuh, gesture, dan voice command

🎯 Jenis-jenis Interaksi Digital

👆 Touch Interaction

  • • Tap: Sentuh sekali untuk memilih
  • • Double tap: Sentuh dua kali untuk zoom
  • • Long press: Tahan untuk menu konteks
  • • Swipe: Geser untuk navigasi
  • • Pinch: Cubit untuk zoom in/out

🗣️ Voice Interaction

  • • Voice command: "Ok Google", "Hey Siri"
  • • Voice search: Pencarian dengan suara
  • • Dictation: Dikte teks dengan suara
  • • Voice navigation: Navigasi dengan suara

🖱️ Mouse & Keyboard

  • • Click: Klik kiri untuk memilih
  • • Right click: Menu konteks
  • • Drag & drop: Seret dan lepas
  • • Keyboard shortcuts: Ctrl+C, Ctrl+V
  • • Hover: Efek saat kursor di atas elemen

🤲 Gesture Interaction

  • • Hand tracking: Deteksi gerakan tangan
  • • Eye tracking: Mengikuti arah pandangan
  • • Motion control: Kontrol dengan gerakan tubuh
  • • AR/VR gestures: Interaksi di dunia virtual

🎭 Contoh Nyata: Good vs Bad UX

❌ Contoh UX Buruk

Website E-commerce Lama:

  • • Loading 10+ detik
  • • Harus registrasi dulu sebelum lihat harga
  • • Checkout 15 langkah
  • • Tidak ada search filter
  • • Pop-up iklan setiap 30 detik

✅ Contoh UX Baik

Shopee/Tokopedia:

  • • Loading cepat dengan skeleton screen
  • • Bisa browse tanpa registrasi
  • • Checkout 1-click dengan e-wallet
  • • Search dengan AI dan filter lengkap
  • • Notifikasi yang relevan dan tidak mengganggu

Konsep Dasar UI/UX

🎨 UI (User Interface)

UI adalah tampilan visual yang dilihat dan disentuh pengguna. Ini mencakup tombol, menu, warna, font, dan semua elemen visual lainnya.

🎨

Visual Design

Warna, tipografi, ikon, gambar

📱

Layout

Tata letak elemen di layar

🔘

Interactive Elements

Tombol, form, slider

❤️ UX (User Experience)

UX adalah keseluruhan pengalaman pengguna saat menggunakan produk. Ini tentang perasaan, kemudahan, dan kepuasan pengguna.

🧠

Usability

Seberapa mudah digunakan

😊

Emotion

Perasaan saat menggunakan

🎯

Goal Achievement

Mencapai tujuan dengan mudah

⚖️ Perbedaan UI dan UX

Aspek UI (User Interface) UX (User Experience)
Fokus Tampilan visual dan interaksi Pengalaman dan kepuasan pengguna
Tujuan Membuat interface yang menarik dan fungsional Membuat penggunaan mudah, efisien, dan menyenangkan
Elemen Tombol, warna, font, ikon, layout Alur navigasi, kecepatan, kemudahan, kepuasan
Proses Desain visual, prototyping, styling Riset pengguna, testing, analisis perilaku
Analogi Desain interior rumah (tampilan) Kenyamanan dan kemudahan hidup di rumah

🎮 Demo Interaktif: UI vs UX

Contoh UI Buruk vs Baik

❌ Contoh UI Buruk:
  • • Teks terlalu panjang dan tidak jelas
  • • Ukuran tombol terlalu kecil
  • • Warna terlalu mencolok
  • • Tidak ada hierarki visual
✅ Contoh UI Baik:
  • • Teks singkat dan jelas
  • • Ukuran tombol mudah diklik
  • • Warna kontras yang tepat
  • • Ada efek hover untuk feedback

Contoh UX Buruk vs Baik

❌ Pengalaman UX Buruk:
  • • Harus mengisi 20+ field untuk registrasi
  • • Tidak ada konfirmasi setelah submit form
  • • Loading lama tanpa indikator progress
  • • Error message tidak jelas dan membantu
  • • Navigasi membingungkan dan tidak konsisten
✅ Pengalaman UX Baik:
  • • Registrasi mudah dengan Google/Facebook
  • • Notifikasi sukses yang jelas dan informatif
  • • Loading cepat dengan indikator progress
  • • Error message yang membantu dan solutif
  • • Navigasi intuitif dan mudah dipahami

Alur Navigasi

🛤️ Apa itu Alur Navigasi?

Alur navigasi adalah jalur yang dilalui pengguna untuk mencapai tujuan mereka dalam aplikasi. Seperti peta jalan yang menunjukkan cara tercepat ke tujuan.

Contoh Alur Navigasi E-commerce:

🎯 Prinsip Alur Navigasi yang Baik

⚡

Efisien

Minimal klik untuk mencapai tujuan. Idealnya maksimal 3-4 langkah.

🧭

Jelas

Pengguna selalu tahu di mana mereka berada dan ke mana bisa pergi.

🔄

Fleksibel

Ada beberapa cara untuk mencapai tujuan yang sama.

↩️

Reversible

Mudah kembali ke langkah sebelumnya jika salah.

🎨 Tips Desain yang Menarik

Warna & Kontras

  • ✓ Gunakan warna kontras untuk teks (contoh: teks hitam di background putih)
  • ✓ Maksimal 3-4 warna utama dalam satu interface
  • ✓ Warna konsisten untuk fungsi sama (semua tombol primary biru)
  • ✓ Gunakan warna untuk membedakan status (hijau=sukses, merah=error)

Tipografi

  • ✓ Font mudah dibaca (Arial, Roboto, Open Sans)
  • ✓ Ukuran minimal 16px untuk mobile, 14px untuk desktop
  • ✓ Hierarki yang jelas (H1: 32px, H2: 24px, H3: 20px)
  • ✓ Line height 1.4-1.6 untuk keterbacaan optimal

Spacing & Layout

  • ✓ Berikan ruang bernafas (white space) antar elemen
  • ✓ Grup elemen yang berkaitan dengan jarak yang dekat
  • ✓ Alignment yang konsisten (rata kiri, tengah, atau kanan)
  • ✓ Gunakan grid system untuk layout yang rapi

Interaksi

  • ✓ Animasi halus dan cepat (200-300ms)
  • ✓ Hover effect yang jelas (perubahan warna/shadow)
  • ✓ Loading indicator untuk proses yang membutuhkan waktu
  • ✓ Ukuran tombol minimal 44px untuk touch target

Tugas Pembelajaran

Kerjakan tugas berikut untuk menguji pemahaman kalian!

📋 Soal Essay

Soal 1: Analisis UI/UX Aplikasi (25 poin)

Pilih satu aplikasi mobile yang sering kalian gunakan (Instagram, TikTok, Shopee, WhatsApp, dll). Analisis aplikasi tersebut berdasarkan:

  • Nama aplikasi yang dipilih dan alasan memilihnya
  • Kelebihan UI: warna, layout, tipografi, ikon (minimal 3 poin)
  • Kelebihan UX: kemudahan navigasi, kecepatan, kepuasan pengguna (minimal 3 poin)
  • Kekurangan: aspek yang membingungkan atau menyulitkan (minimal 2 poin)
  • Saran perbaikan: solusi konkret untuk mengatasi kekurangan

Soal 2: Desain Alur Navigasi (25 poin)

Buatlah alur navigasi untuk aplikasi "Perpustakaan Digital SMK" yang memiliki fitur-fitur berikut:

  • Autentikasi: Login/Register siswa
  • Pencarian: Cari buku berdasarkan judul/penulis/kategori
  • Baca Online: Membaca buku digital langsung di aplikasi
  • Peminjaman: Pinjam buku fisik dari perpustakaan
  • Riwayat: Melihat history peminjaman dan bacaan
  • Profil: Kelola akun dan preferensi

Tugas: Gambarkan alur navigasi dalam bentuk diagram sederhana (bisa menggunakan teks dengan panah →) atau deskripsi langkah-langkah detail. Jelaskan juga jenis struktur navigasi yang kalian pilih dan alasannya.

Soal 3: Prinsip Desain Interaksi (25 poin)

Jelaskan bagaimana menerapkan 5 prinsip desain interaksi (Visibility, Feedback, Affordance, Consistency, Error Prevention) pada desain form pendaftaran siswa baru online. Berikan contoh konkret untuk setiap prinsip.

Soal 4: Studi Kasus (25 poin)

Kalian diminta merancang interface untuk aplikasi "Kantin Digital SMK" yang memungkinkan siswa memesan makanan dari kantin sekolah. Jelaskan:

  • Elemen UI apa saja yang dibutuhkan?
  • Bagaimana alur navigasi dari buka app sampai selesai pesan?
  • Feedback apa yang perlu diberikan ke pengguna?
  • Bagaimana mencegah error dalam proses pemesanan?
