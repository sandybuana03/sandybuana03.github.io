✨ Solusi: Version Control System!

Version Control System (VCS) adalah sistem yang membantu kita mengelola perubahan pada file-file project dari waktu ke waktu.

Apa itu Git?

🎯 Definisi Git

Git adalah sistem version control yang paling populer di dunia. Dibuat oleh Linus Torvalds (pembuat Linux) pada tahun 2005.

💡 Fun Fact: Nama "Git" berasal dari bahasa slang Inggris yang artinya "orang bodoh" - Linus Torvalds suka humor! 😄

🌟 Keunggulan Git

🚀

Super Cepat

Operasi Git sangat cepat karena sebagian besar bekerja secara lokal

🌐

Distributed

Setiap developer punya copy lengkap dari history project

🔒

Aman

Menggunakan SHA-1 hash untuk memastikan integritas data

🆓

Gratis

Open source dan gratis untuk semua orang

Perintah Git Dasar

🚀 Setup Awal

👤 git config --global user.name "Nama Kamu"

Mengatur nama pengguna

📧 git config --global user.email "email@kamu.com"

Mengatur email pengguna

📁 Membuat Repository

🆕 git init

Membuat repository baru di folder saat ini

📥 git clone [url]

Mengcopy repository dari internet ke komputer

📝 Workflow Dasar

📊 git status

Melihat status file (mana yang berubah, mana yang belum di-commit)

➕
git add [nama-file] git add .

Menambahkan file ke staging area. Gunakan titik (.) untuk menambahkan semua file

📸 git commit -m "pesan commit"

Menyimpan snapshot dengan pesan deskriptif

🌿 Mengelola Branch

🌱 git branch [nama-branch]

Membuat branch baru

🔄 git checkout [nama-branch]

Pindah ke branch lain

⚡ git checkout -b [nama-branch]

Membuat dan langsung pindah ke branch baru

🌐 Sinkronisasi

📤 git push origin [nama-branch]

Mengirim perubahan ke repository online

📥 git pull

Mengambil perubahan terbaru dari repository online

🎮 Simulator Git

Klik tombol di atas untuk melihat simulasi perintah Git! Mulai dengan "git status" untuk melihat kondisi repository.

🔄 Proses Kolaborasi

Step 1

Buat Branch Baru

Setiap developer membuat branch untuk fitur yang akan dikerjakan

git checkout -b nama-fitur
Step 2

Kerjakan Fitur

Developer bekerja di branch masing-masing tanpa mengganggu yang lain

Step 3

Push ke Remote

Kirim perubahan ke repository online

git push origin nama-fitur
Step 4

Pull Request

Minta tim untuk review dan merge ke branch utama

⚠️ Mengatasi Konflik

Konflik terjadi ketika dua orang mengubah baris yang sama dalam file yang sama.

Contoh Konflik:

<<<<<<< HEAD

background-color: blue;

=======

background-color: red;

>>>>>>> branch-lain

Solusi:

  1. 1. Diskusikan dengan tim mana yang benar
  2. 2. Edit file untuk menghapus marker konflik
  3. 3. Commit hasil yang sudah diperbaiki
