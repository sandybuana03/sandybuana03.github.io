Pengenalan Sistem Operasi

🔍 Apa itu Sistem Operasi?

Sistem Operasi (Operating System/OS) adalah perangkat lunak yang mengelola sumber daya komputer dan menyediakan layanan untuk program aplikasi. OS bertindak sebagai jembatan antara pengguna dengan perangkat keras komputer.

Fungsi Utama Sistem Operasi:

  • • Process Management: Mengelola program yang berjalan
  • • Memory Management: Mengatur penggunaan RAM
  • • File System: Mengorganisir file dan folder
  • • Device Management: Mengelola hardware
  • • User Interface: Menyediakan antarmuka pengguna
  • • Security: Melindungi sistem dan data
  • • Network Management: Mengelola koneksi jaringan
  • • Error Handling: Menangani kesalahan sistem

💡 Analogi Sederhana

Bayangkan OS seperti manajer hotel yang mengatur kamar (memori), tamu (program), fasilitas (hardware), dan layanan (network). Tanpa manajer, hotel akan kacau!

Microsoft Windows

📖 Sejarah dan Karakteristik

Windows adalah sistem operasi yang dikembangkan oleh Microsoft sejak 1985. Dikenal dengan antarmuka grafis yang user-friendly dan kompatibilitas yang luas dengan berbagai perangkat lunak.

🕰️ Timeline Windows:

  • • 1985: Windows 1.0 (GUI pertama)
  • • 1995: Windows 95 (Start Menu)
  • • 2001: Windows XP (stabilitas)
  • • 2009: Windows 7 (populer)
  • • 2012: Windows 8 (touch interface)
  • • 2015: Windows 10 (universal)
  • • 2021: Windows 11 (modern design)
  • • 2024: Windows 11 24H2 (AI features)

✅ Kelebihan:

  • • User interface yang mudah dipahami
  • • Kompatibilitas software yang luas
  • • Dukungan hardware yang excellent
  • • Banyak dokumentasi dan tutorial
  • • Gaming performance yang optimal
  • • Microsoft Office terintegrasi
  • • Plug and play hardware support

❌ Kekurangan:

  • • Berbayar (lisensi mulai $139)
  • • Lebih rentan terhadap malware
  • • Membutuhkan resource yang besar
  • • Update yang sering dan besar
  • • Masalah privasi (telemetry)
  • • Aplikasi bawaan yang tidak perlu
  • • Registry yang kompleks

🌐 Dukungan Jaringan Windows

🔧 Fitur Jaringan Built-in:

  • • Network and Sharing Center: Pusat kontrol jaringan
  • • Windows Firewall: Keamanan jaringan
  • • Remote Desktop: Akses jarak jauh
  • • File Sharing: Berbagi file dalam jaringan
  • • HomeGroup: Jaringan rumah sederhana
  • • VPN Client: Koneksi aman
  • • WiFi Direct: Koneksi peer-to-peer
  • • Network Discovery: Deteksi perangkat

🏢 Untuk Lingkungan Enterprise:

  • • Active Directory: Manajemen user/komputer
  • • Group Policy: Konfigurasi terpusat
  • • WSUS: Update management
  • • DHCP/DNS Server: Network services
  • • Hyper-V: Virtualization platform
  • • IIS: Web server
  • • RRAS: Routing and remote access
  • • NPS: Network policy server

Linux

📖 Sejarah dan Karakteristik

Linux adalah sistem operasi open source yang dikembangkan oleh Linus Torvalds pada 1991. Dikenal dengan stabilitas, keamanan, dan fleksibilitas yang tinggi.

🕰️ Timeline Linux:

  • • 1991: Linus Torvalds mulai Linux kernel
  • • 1993: Debian didirikan
  • • 1994: Red Hat Linux diluncurkan
  • • 2004: Ubuntu pertama kali rilis
  • • 2008: Android (berbasis Linux) diluncurkan
  • • 2010: Linux mendominasi server web
  • • 2016: Windows Subsystem for Linux
  • • 2024: 500+ distribusi aktif

✅ Kelebihan:

  • • Gratis dan open source
  • • Sangat stabil dan aman
  • • Highly customizable dan fleksibel
  • • Performa yang excellent
  • • Cocok untuk server dan embedded
  • • Resource usage yang efisien
  • • Community support yang kuat
  • • Tidak ada virus seperti Windows

❌ Kekurangan:

  • • Learning curve yang steep untuk pemula
  • • Kompatibilitas software terbatas
  • • Dukungan hardware kadang terbatas
  • • Interface kurang familiar bagi user Windows
  • • Gaming support masih terbatas
  • • Fragmentasi banyak distribusi
  • • Butuh pengetahuan command line

macOS

📖 Sejarah dan Karakteristik

macOS adalah sistem operasi yang dikembangkan oleh Apple untuk komputer Mac. Dikenal dengan desain yang elegan, performa yang optimal, dan integrasi yang sempurna dengan ekosistem Apple.

🕰️ Timeline macOS:

  • • 1984: Mac OS (System 1.0)
  • • 2001: Mac OS X (Darwin kernel)
  • • 2011: Mac OS X Lion (App Store)
  • • 2016: macOS Sierra (nama baru)
  • • 2020: macOS Big Sur (design refresh)
  • • 2021: macOS Monterey (Universal Control)
  • • 2022: macOS Ventura (Stage Manager)
  • • 2023: macOS Sonoma (widgets interaktif)

✅ Kelebihan:

  • • Desain UI/UX yang excellent
  • • Performa optimal (Apple Silicon M-series)
  • • Keamanan tinggi (Gatekeeper, XProtect)
  • • Integrasi sempurna ekosistem Apple
  • • Cocok untuk creative work
  • • Unix-based (powerful terminal)
  • • Battery life yang excellent
  • • Minim malware dan virus

❌ Kekurangan:

  • • Hanya bisa di hardware Apple
  • • Harga yang mahal (mulai $999)
  • • Kompatibilitas software terbatas
  • • Kurang customizable
  • • Gaming support terbatas
  • • Upgrade hardware sulit/tidak bisa
  • • Vendor lock-in ecosystem
  • • Repair cost yang tinggi

🌐 Dukungan Jaringan macOS

🔧 Fitur Jaringan Built-in:

  • • Network Preferences: GUI network config
  • • Built-in Firewall: Application firewall
  • • AirDrop: Wireless file sharing

  • • Bonjour: Zero-config networking
  • • Back to My Mac: Remote access (legacy)
  • • Internet Sharing: Hotspot functionality
  • • VPN Client: Built-in VPN support

🍎 Ekosistem Apple:

  • • Handoff: Continue tasks across devices
  • • iCloud: Seamless data sync
  • • AirPlay: Wireless media streaming
  • • Universal Clipboard: Copy/paste across devices
  • • Continuity Camera: Use iPhone as webcam
  • • Sidecar: iPad as second display
  • • Universal Control: Control multiple Macs
  • • iPhone Mirroring: Control iPhone from Mac

🎮 Demo: Network Configuration

🖱️ GUI Method:

  1. 1. Klik Apple menu → System Preferences (atau System Settings di macOS 13+)
  2. 2. Pilih "Network"
  3. 3. Pilih interface (Wi-Fi, Ethernet, dll)
  4. 4. Klik "Advanced" untuk pengaturan detail
  5. 5. Tab TCP/IP, DNS, Proxies, Hardware tersedia

⌨️ Terminal Commands:

# Melihat konfigurasi network

$ ifconfig

# Test koneksi

# Melihat routing table

$ netstat -rn

# Flush DNS cache

$ sudo dscacheutil -flushcache
