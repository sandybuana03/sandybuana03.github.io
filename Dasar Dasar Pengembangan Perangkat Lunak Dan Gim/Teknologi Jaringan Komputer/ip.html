Pengenalan IP Address

🏠 Apa itu IP Address?

IP Address (Internet Protocol Address) adalah alamat unik yang diberikan kepada setiap perangkat yang terhubung ke jaringan komputer. Bayangkan seperti alamat rumah, tapi untuk perangkat digital!

Contoh: 192.168.1.1

💡 Tahukah Kamu?

Setiap kali kamu mengakses website, smartphone atau komputer kamu menggunakan IP Address untuk "menemukan" server website tersebut di internet. Tanpa IP Address, internet tidak akan bisa berfungsi!

🎯 Fungsi IP Address

📍

Identifikasi Perangkat

Memberikan alamat unik untuk setiap perangkat dalam jaringan

Contoh: Komputer, printer, smartphone, smart TV, router

🚚

Pengiriman Data

Memastikan data sampai ke tujuan yang benar

Seperti alamat pos untuk mengirim paket data

🌐

Komunikasi Jaringan

Memungkinkan perangkat saling berkomunikasi

Baik dalam LAN maupun internet global

🔍

Lokasi Logis

Menentukan posisi dalam hierarki jaringan

Membantu proses routing dan switching

🔐

Keamanan Jaringan

Membantu mengontrol akses jaringan

Firewall dan ACL menggunakan IP untuk filtering

📊

Monitoring & Logging

Melacak aktivitas jaringan

Untuk troubleshooting dan analisis performa

🏗️ Sejarah Singkat IP Address

1974

Konsep Internet Protocol pertama kali diperkenalkan oleh Vint Cerf dan Bob Kahn

1981

IPv4 resmi didefinisikan dalam RFC 791, menggunakan alamat 32-bit

1998

IPv6 dikembangkan untuk mengatasi keterbatasan alamat IPv4

🔧 Jenis-Jenis IP Address

🏠 Berdasarkan Lokasi

  • IP Private: Untuk jaringan internal (192.168.x.x)
  • IP Public: Untuk akses internet (8.8.8.8)

⚙️ Berdasarkan Konfigurasi

  • IP Statis: Alamat tetap, tidak berubah
  • IP Dinamis: Alamat berubah otomatis (DHCP)

IPv4 Dasar

📐 Format IPv4

IPv4 terdiri dari 4 bagian (oktet) yang dipisahkan titik. Setiap oktet berisi angka 0-255.

🔍 Detail Struktur:

  • • 32 bit total - Setiap oktet = 8 bit
  • • Notasi desimal - Mudah dibaca manusia
  • • Range 0-255 - Nilai maksimal 8 bit (2^8 - 1)
  • • 4.294.967.296 alamat - Total kombinasi IPv4

🌐 Protokol Internet (IP)

IP adalah protokol komunikasi yang mengatur bagaimana data dikirim melalui jaringan. IP bekerja pada Layer 3 (Network Layer) dalam model OSI.

🎯 Karakteristik IP:

  • • Connectionless: Tidak perlu koneksi sebelum mengirim
  • • Best Effort: Tidak menjamin pengiriman
  • • Unreliable: Tidak ada konfirmasi penerimaan
  • • Packet Switching: Data dipecah jadi paket-paket

📦 Header IP:

  • • Version: Versi IP (4 untuk IPv4)
  • • TTL: Time To Live (hop limit)
  • • Protocol: Protokol layer atas (TCP/UDP)
  • • Source/Dest IP: Alamat pengirim & tujuan

🔢 Sistem Biner dalam IP Address

Komputer memahami IP dalam bentuk biner (0 dan 1). Setiap oktet terdiri dari 8 bit dengan nilai maksimal 255.

🔄 DHCP (Dynamic Host Configuration Protocol)

DHCP adalah layanan yang secara otomatis memberikan konfigurasi IP kepada perangkat dalam jaringan.

🎯 Fungsi DHCP:

  • • Memberikan IP Address otomatis
  • • Mengatur Subnet Mask
  • • Menentukan Default Gateway
  • • Konfigurasi DNS Server
  • • Mengatur lease time (waktu sewa)

🔄 Proses DHCP:

DISCOVER: Client mencari server
OFFER: Server menawarkan IP
REQUEST: Client meminta IP
ACK: Server mengkonfirmasi

🔀 NAT (Network Address Translation)

NAT adalah teknologi yang memungkinkan beberapa perangkat dengan IP private mengakses internet menggunakan satu IP public.

🎯 Jenis NAT:

  • • Static NAT: 1:1 mapping tetap
  • • Dynamic NAT: Pool IP public
  • • PAT/NAPT: Port-based (paling umum)
  • • Port Forwarding: Akses dari luar

✅ Keuntungan NAT:

  • • Menghemat IP public
  • • Meningkatkan keamanan
  • • Menyembunyikan topologi internal
  • • Memungkinkan sharing internet

🔄 Contoh NAT:

192.168.1.10:3000 → NAT → 203.0.113.1:5000

IP Private → IP Public dengan port mapping

Subnet Mask

🎭 Apa itu Subnet Mask?

Subnet Mask adalah nilai biner yang digunakan untuk memisahkan bagian network (jaringan) dan host (perangkat) dalam IP Address. Seperti "topeng" yang menutupi bagian network.

IP: 192.168.1.100

📊 Notasi CIDR

CIDR (Classless Inter-Domain Routing) adalah notasi singkat untuk subnet mask menggunakan /angka. Angka tersebut menunjukkan jumlah bit '1' dalam subnet mask.

Cara Menghitung CIDR:

Hitung jumlah bit '1' dalam subnet mask biner. Contoh: 255.255.255.0 = 11111111.11111111.11111111.00000000 = 24 bit '1' = /24

🔧 Teknik Subnetting Lanjutan

📊 VLSM (Variable Length Subnet Mask):

  • • Subnet dengan ukuran berbeda-beda
  • • Efisiensi penggunaan IP address
  • • Sesuai kebutuhan setiap departemen
  • • Mengurangi pemborosan alamat IP

🎯 Supernetting (Route Summarization):

  • • Menggabungkan beberapa subnet
  • • Mengurangi ukuran routing table
  • • Meningkatkan efisiensi routing
  • • Contoh: 192.168.0.0/22 = 4 subnet /24

💡 Contoh VLSM:

• Kantor Pusat (100 host): 192.168.1.0/25 (126 host)
• Cabang A (50 host): 192.168.1.128/26 (62 host)
• Cabang B (20 host): 192.168.1.192/27 (30 host)
• Point-to-Point: 192.168.1.224/30 (2 host)

Pengenalan IPv6

🚀 Mengapa IPv6?

⚠️ Masalah IPv4

  • • Alamat terbatas (~4 miliar)
  • • Hampir habis digunakan
  • • Konfigurasi rumit

✨ Solusi IPv6

  • • Alamat sangat banyak
  • • Konfigurasi otomatis
  • • Keamanan lebih baik

🔢 Format IPv6

IPv6 menggunakan 8 grup angka heksadesimal (0-9, A-F) yang dipisahkan titik dua (:). Setiap grup terdiri dari 4 digit heksadesimal (16 bit), total 128 bit.

2001:0db8:85a3:0000:0000:8a2e:0370:7334
Format lengkap IPv6
2001:db8:85a3::8a2e:370:7334
Format disingkat (:: mengganti 0000:0000)

📊 Perbandingan IPv4 vs IPv6

Aspek IPv4 IPv6
Panjang 32 bit 128 bit
Jumlah Alamat ~4 miliar ~340 undecillion
Format 192.168.1.1 2001:db8::1
Konfigurasi Manual/DHCP Otomatis

🌐 IP Private vs Public

🏠 IP Private

  • • Digunakan dalam jaringan lokal
  • • Tidak bisa diakses dari internet
  • • Dapat digunakan berulang di jaringan berbeda
  • • Contoh: 192.168.1.1, 10.0.0.1

🌍 IP Public

  • • Digunakan untuk akses internet
  • • Unik di seluruh dunia
  • • Dikelola oleh ISP
  • • Contoh: 8.8.8.8, 1.1.1.1

🌍 Seberapa Banyak IPv6?

🤯

IPv6 memiliki 340.282.366.920.938.463.463.374.607.431.768.211.456 alamat!
