Pengenalan IP Address

Mari kenali dasar-dasar IP Address terlebih dahulu! 🌟

🏠

Apa itu IP Address?

IP Address (Internet Protocol Address) adalah alamat unik berupa deretan angka yang diberikan kepada setiap perangkat yang terhubung ke jaringan komputer. Seperti alamat rumah di dunia nyata, IP Address memungkinkan perangkat untuk saling mengenali dan berkomunikasi dalam jaringan.

🎯 Fungsi Utama:

  • • Identifikasi unik setiap perangkat
  • • Routing (pengalihan) data ke tujuan
  • • Memungkinkan komunikasi antar perangkat
  • • Menentukan lokasi logis dalam jaringan

💡 Contoh Penggunaan:

  • • Mengakses website (browsing)
  • • Mengirim dan menerima email
  • • Video call dan voice call
  • • Online gaming dan streaming

💡 Contoh IP Address: 192.168.1.1 (Gateway router), 8.8.8.8 (Google DNS), 1.1.1.1 (Cloudflare DNS)

🔢

Format dan Struktur IP Address

📊 Struktur Oktet

IP Address IPv4 terdiri dari 4 bagian yang dipisahkan oleh titik (.), setiap bagian disebut oktet karena terdiri dari 8 bit:

192 . 168 . 1 . 1
Oktet 1
(8 bit)
Oktet 2
(8 bit)
Oktet 3
(8 bit)
Oktet 4
(8 bit)
Total: 32 bit (4 × 8 bit)

🔢 Rentang Nilai:

Setiap oktet: 0-255 (2⁸ = 256 nilai)

Total IPv4: 2³² = 4,294,967,296 alamat

💻 Contoh Konversi Biner:

192 = 11000000 (biner)

168 = 10101000 (biner)

🌐

Jenis-Jenis IP Address

🌍

Public IP Address

  • • Dapat diakses dari internet
  • • Unik secara global
  • • Diberikan oleh ISP
  • • Contoh: 8.8.8.8, 1.1.1.1
🏠

Private IP Address

  • • Hanya untuk jaringan lokal
  • • Tidak dapat diakses internet
  • • Dapat digunakan berulang
  • • Contoh: 192.168.1.1, 10.0.0.1

📋 Rentang Private IP:

• Kelas A: 10.0.0.0 - 10.255.255.255

• Kelas B: 172.16.0.0 - 172.31.255.255

• Kelas C: 192.168.0.0 - 192.168.255.255

Pembagian Kelas IP Address

IP Address dibagi menjadi beberapa kelas berdasarkan kebutuhan jaringan! 📊

📋

Mengapa Ada Kelas IP?

Pembagian kelas IP dibuat untuk mengatur alokasi alamat IP secara efisien berdasarkan ukuran jaringan. Sistem ini memungkinkan organisasi mendapatkan jumlah alamat IP yang sesuai dengan kebutuhan mereka, tanpa pemborosan atau kekurangan alamat.

🎯 Prinsip Pembagian Kelas:

  • • Kelas A: Sedikit jaringan, banyak host per jaringan
  • • Kelas B: Seimbang antara jumlah jaringan dan host
  • • Kelas C: Banyak jaringan, sedikit host per jaringan
🏢

Kelas A

Jaringan Besar
126 jaringan × 16+ juta host

🏬

Kelas B

Jaringan Menengah
16,384 jaringan × 65K host

🏠

Kelas C

Jaringan Kecil
2+ juta jaringan × 254 host

📊

Tabel Ringkasan Kelas IP

Kelas Rentang Oktet Pertama Subnet Mask Default Jumlah Network Host per Network
A 1 - 126 255.0.0.0 (/8) 126 16,777,214
B 128 - 191 255.255.0.0 (/16) 16,384 65,534
C 192 - 223 255.255.255.0 (/24) 2,097,152 254

📝 Catatan Penting:

  • • 0.x.x.x: Reserved untuk "this network"
  • • 127.x.x.x: Reserved untuk loopback (localhost)
  • • 224-239: Kelas D untuk multicast
  • • 240-255: Kelas E untuk eksperimental
🅰️

Kelas A - Jaringan Raksasa

Untuk organisasi besar yang membutuhkan jutaan alamat IP! 🏢

📈

Karakteristik Kelas A

🎯 Rentang IP

1.0.0.0 - 126.255.255.255

Oktet pertama: 1-126

🎭 Subnet Mask

255.0.0.0 atau /8

8 bit network, 24 bit host

👥 Jumlah Host

16,777,214 host per jaringan

2²⁴ - 2 = 16,777,214

🌐 Jumlah Jaringan

126 jaringan tersedia

0.x.x.x dan 127.x.x.x reserved

🔢

Format dan Struktur Kelas A

N . H . H . H
Network (8 bit)
Host (8 bit)
Host (8 bit)
Host (8 bit)

N = Network ID (1 oktet) | H = Host ID (3 oktet)

💡 Contoh Kelas A:

• 10.0.0.1 (Private)

• 50.100.200.5 (Public)

• 126.255.255.254 (Public)

🔒 IP Khusus:

• 0.x.x.x (Reserved)

• 127.x.x.x (Loopback)

• 10.x.x.x (Private)

🧮

Perhitungan Kelas A

📊 Perhitungan Host:

• Host bit = 24 bit (3 oktet)

• Total alamat = 2²⁴ = 16,777,216

• Network address = 1 alamat

• Broadcast address = 1 alamat

• Host valid = 16,777,214

🌐 Perhitungan Network:

• Network bit = 8 bit (1 oktet)

• Rentang oktet pertama = 1-126

• 0.x.x.x = Reserved "this network"

• 127.x.x.x = Reserved loopback

• Network valid = 126 (1-126)

🏢

Penggunaan Kelas A

🌍 Organisasi yang Menggunakan:

  • • Perusahaan multinasional (IBM, Microsoft)
  • • Internet Service Provider (ISP) besar
  • • Pemerintahan negara
  • • Universitas besar dunia
  • • Organisasi militer
  • • Perusahaan teknologi raksasa

📋 Contoh Implementasi:

Network: 10.0.0.0/8 (Private - untuk jaringan internal besar)

Gateway: 10.0.0.1

Host Range: 10.0.0.2 - 10.255.255.254

Broadcast: 10.255.255.255

⚖️

Keuntungan & Kekurangan

✅ Keuntungan:

  • • Sangat banyak host (16+ juta)
  • • Cocok untuk organisasi besar
  • • Fleksibilitas subnetting tinggi
  • • Efisien untuk jaringan raksasa

❌ Kekurangan:

  • • Jumlah network terbatas (126)
  • • Boros untuk jaringan kecil
  • • Kompleksitas manajemen tinggi
  • • Broadcast domain sangat besar
🅱️

Kelas B - Jaringan Menengah

Cocok untuk organisasi menengah dengan ribuan perangkat! 🏬

📊

Karakteristik Kelas B

🎯 Rentang IP

128.0.0.0 - 191.255.255.255

Oktet pertama: 128-191

🎭 Subnet Mask

255.255.0.0 atau /16

16 bit network, 16 bit host

👥 Jumlah Host

65,534 host per jaringan

2¹⁶ - 2 = 65,534

🌐 Jumlah Jaringan

16,384 jaringan tersedia

2¹⁴ = 16,384 network

🔢

Format dan Struktur Kelas B

N . N . H . H
Network (8 bit)
Network (8 bit)
Host (8 bit)
Host (8 bit)

N = Network ID (2 oktet) | H = Host ID (2 oktet)

💡 Contoh Kelas B:

• 172.16.1.1 (Private)

• 150.100.50.25 (Public)

• 191.255.255.254 (Public)

🔒 Private Range:

• 172.16.0.0 - 172.31.255.255

• Total: 16 network private

• Untuk jaringan menengah

🧮

Perhitungan Kelas B

📊 Perhitungan Host:

• Host bit = 16 bit (2 oktet)

• Total alamat = 2¹⁶ = 65,536

• Network address = 1 alamat

• Broadcast address = 1 alamat

• Host valid = 65,534

🌐 Perhitungan Network:

• Network bit = 16 bit (2 oktet)

• Oktet pertama = 128-191 (64 nilai)

• Oktet kedua = 0-255 (256 nilai)

• Total network = 64 × 256 = 16,384

• Network valid = 16,384

🏬

Penggunaan Kelas B

🏢 Organisasi yang Menggunakan:

  • • Universitas menengah
  • • Perusahaan regional
  • • Rumah sakit besar
  • • ISP regional
  • • Pemerintah daerah
  • • Perusahaan manufaktur

📋 Contoh Implementasi:

Network: 172.16.0.0/16 (Private - untuk kampus/perusahaan)

Gateway: 172.16.0.1

Host Range: 172.16.0.2 - 172.16.255.254

Broadcast: 172.16.255.255

🔧

Subnetting Kelas B

🎯 Contoh Subnetting 172.16.0.0/16:

Subnet Network Host Range Broadcast
/17 172.16.0.0 172.16.0.1 - 172.16.127.254 172.16.127.255
/18 172.16.0.0 172.16.0.1 - 172.16.63.254 172.16.63.255
/24 172.16.1.0 172.16.1.1 - 172.16.1.254 172.16.1.255
⚖️

Keuntungan & Kekurangan

✅ Keuntungan:

  • • Seimbang antara network dan host
  • • Cocok untuk organisasi menengah
  • • Fleksibilitas subnetting baik
  • • Tidak terlalu boros alamat

❌ Kekurangan:

  • • Terbatas untuk jaringan besar
  • • Boros untuk jaringan kecil
  • • Kompleksitas menengah
  • • Broadcast domain cukup besar

Kelas C - Jaringan Kecil

Perfect untuk rumah, kantor kecil, dan warnet! 🏠

🏠

Karakteristik Kelas C

🎯 Rentang IP

192.0.0.0 - 223.255.255.255

Oktet pertama: 192-223

🎭 Subnet Mask

255.255.255.0 atau /24

24 bit network, 8 bit host

👥 Jumlah Host

254 host per jaringan

2⁸ - 2 = 254

🌐 Jumlah Jaringan

2,097,152 jaringan tersedia

2²¹ = 2,097,152 network

🔢

Format dan Struktur Kelas C

N . N . N . H
Network (8 bit)
Network (8 bit)
Network (8 bit)
Host (8 bit)

N = Network ID (3 oktet) | H = Host ID (1 oktet)

💡 Contoh Kelas C:

• 192.168.1.1 (Private)

• 200.100.75.10 (Public)

• 223.255.255.254 (Public)

🔒 Private Range:

• 192.168.0.0 - 192.168.255.255

• Total: 256 network private

• Paling populer untuk rumah

🧮

Perhitungan Kelas C

📊 Perhitungan Host:

• Host bit = 8 bit (1 oktet)

• Total alamat = 2⁸ = 256

• Network address = 1 alamat

• Broadcast address = 1 alamat

• Host valid = 254

🌐 Perhitungan Network:

• Network bit = 24 bit (3 oktet)

• Oktet pertama = 192-223 (32 nilai)

• Oktet kedua = 0-255 (256 nilai)

• Oktet ketiga = 0-255 (256 nilai)

• Total = 32 × 256 × 256 = 2,097,152

• Network valid = 2,097,152

🏘️

Penggunaan Kelas C

🏠 Organisasi yang Menggunakan:

  • • Rumah tangga (WiFi rumah)
  • • Warnet dan game center
  • • Kantor kecil (SOHO)
  • • Sekolah dasar/menengah
  • • Toko dan restoran
  • • Klinik dan apotek

📋 Contoh Implementasi Rumah:

Network: 192.168.1.0/24 (Private - untuk WiFi rumah)

Router/Gateway: 192.168.1.1

Host Range: 192.168.1.2 - 192.168.1.254

Broadcast: 192.168.1.255

Perangkat: HP, laptop, smart TV, IoT devices

🔧

Subnetting Kelas C

🎯 Contoh Subnetting 192.168.1.0/24:

Subnet Network Host Range Hosts
/25 192.168.1.0 192.168.1.1 - 192.168.1.126 126
/26 192.168.1.0 192.168.1.1 - 192.168.1.62 62
/27 192.168.1.0 192.168.1.1 - 192.168.1.30 30
/28 192.168.1.0 192.168.1.1 - 192.168.1.14 14

⚖️

Keuntungan & Kekurangan

✅ Keuntungan:

  • • Sangat banyak network tersedia
  • • Cocok untuk jaringan kecil
  • • Mudah dikelola dan dikonfigurasi
  • • Efisien untuk SOHO
  • • Broadcast domain kecil

❌ Kekurangan:

  • • Terbatas hanya 254 host
  • • Tidak cocok untuk jaringan besar
  • • Perlu banyak network untuk skala besar
  • • Subnetting terbatas
  • • Routing kompleks jika banyak subnet
