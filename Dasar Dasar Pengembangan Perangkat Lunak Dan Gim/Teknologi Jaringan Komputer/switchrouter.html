Pengenalan Jaringan Komputer

Apa itu Jaringan Komputer? 🌐

Jaringan komputer adalah kumpulan komputer yang saling terhubung untuk berbagi data, file, dan sumber daya lainnya. Bayangkan seperti jalan raya yang menghubungkan berbagai kota!

Contoh Sederhana:

Di warnet, semua komputer terhubung dalam satu jaringan sehingga bisa sharing internet dan bermain game online bersama.

Perangkat Jaringan 🔧

Untuk membangun jaringan, kita membutuhkan perangkat khusus. Dua yang paling penting adalah:

🔄

Switch

Menghubungkan perangkat dalam satu jaringan lokal

📡

Router

Menghubungkan jaringan yang berbeda

🔄

Apa itu Switch?

Pengertian Switch 📖

Switch adalah perangkat jaringan Layer 2 yang berfungsi menghubungkan beberapa perangkat dalam satu jaringan lokal (LAN). Switch bekerja dengan cara mempelajari MAC address setiap perangkat yang terhubung dan membuat tabel MAC address untuk pengiriman data yang efisien.

Analogi Sederhana:

Switch seperti petugas pos yang sangat pintar. Dia mengingat alamat rumah setiap orang di kampung, jadi ketika ada surat, dia langsung tahu harus diantar ke rumah mana tanpa perlu bertanya-tanya!

🔍 Cara Kerja Switch:

1. Learning: Switch mempelajari MAC address dari setiap frame yang masuk
2. Flooding: Jika MAC tujuan belum dikenal, broadcast ke semua port
3. Forwarding: Mengirim frame langsung ke port tujuan yang tepat
4. Filtering: Memblokir frame yang tidak perlu diteruskan

Fungsi Switch ⚙️

🔗

Menghubungkan Perangkat

Menghubungkan komputer, printer, dan perangkat lain dalam satu jaringan

📊

Meneruskan Data

Mengirim data hanya ke perangkat yang dituju, bukan ke semua perangkat

🧠

Belajar MAC Address

Mengingat alamat fisik setiap perangkat yang terhubung

⚡

Full Duplex

Bisa mengirim dan menerima data secara bersamaan

Karakteristik Switch 🔍

  • ✓ Bekerja di Layer 2 (Data Link Layer)
  • ✓ Menggunakan MAC Address untuk identifikasi
  • ✓ Membuat collision domain terpisah untuk setiap port
  • ✓ Mendukung full-duplex communication
  • ✓ Memiliki MAC Address Table (CAM Table)

Jenis-jenis Switch 🏷️

🔧

Unmanaged Switch

  • • Plug-and-play, tidak perlu konfigurasi
  • • Cocok untuk jaringan rumah/SOHO
  • • Harga lebih murah
  • • Fitur terbatas
⚙️

Managed Switch

  • • Dapat dikonfigurasi dan dimonitor
  • • Mendukung VLAN, QoS, SNMP
  • • Cocok untuk enterprise
  • • Fitur keamanan lengkap
🌐

Layer 3 Switch

  • • Kombinasi switch dan router
  • • Bisa routing antar VLAN
  • • Performa tinggi
  • • Harga lebih mahal
⚡

PoE Switch

  • • Menyediakan daya melalui kabel UTP
  • • Cocok untuk IP camera, AP WiFi
  • • Mengurangi kabel power
  • • Instalasi lebih mudah
📡

Apa itu Router?

Pengertian Router 📖

Router adalah perangkat jaringan Layer 3 yang menghubungkan dua atau lebih jaringan yang berbeda dengan menggunakan IP address. Router memiliki kemampuan untuk menentukan jalur terbaik (routing) untuk mengirim data antar jaringan berdasarkan routing table.

Analogi Sederhana:

Router seperti sistem GPS yang pintar. Dia tahu semua jalan di kota, bisa memilih rute tercepat, dan bahkan bisa mencari jalan alternatif jika ada kemacetan!

🗺️ Cara Kerja Router:

1. Menerima Paket: Router menerima paket data dari jaringan sumber
2. Membaca Header: Menganalisis IP address tujuan dalam header paket
3. Konsultasi Routing Table: Mencari jalur terbaik ke jaringan tujuan
4. Forward Paket: Mengirim paket melalui interface yang tepat
5. Update TTL: Mengurangi Time To Live untuk mencegah loop

Fungsi Router ⚙️

🌐

Menghubungkan Jaringan

Menghubungkan jaringan lokal dengan internet atau jaringan lain

🗺️

Routing

Menentukan jalur terbaik untuk mengirim data

🛡️

Firewall

Melindungi jaringan dari ancaman luar

📍

NAT

Mengubah alamat IP private menjadi public

Karakteristik Router 🔍

  • ✓ Bekerja di Layer 3 (Network Layer)
  • ✓ Menggunakan IP Address untuk routing
  • ✓ Memiliki routing table untuk menentukan jalur
  • ✓ Bisa menghubungkan jaringan dengan subnet berbeda

Jenis-jenis Router 📋

🏠

Home Router

Router untuk rumah, biasanya ada WiFi, NAT, dan DHCP built-in

🏢

Enterprise Router

Router untuk perusahaan besar dengan fitur advanced dan redundancy

🌍

Core Router

Router backbone internet dengan kapasitas sangat tinggi

🔄 Protokol Routing:

Static Routing

Jalur dikonfigurasi manual oleh administrator

RIP (Routing Information Protocol)

Protokol routing sederhana, maksimal 15 hop

OSPF (Open Shortest Path First)

Protokol link-state, cocok untuk jaringan besar

EIGRP (Enhanced Interior Gateway Routing Protocol)

Protokol Cisco, hybrid distance-vector

BGP (Border Gateway Protocol)

Protokol routing internet antar ISP

Default Route

Jalur default untuk semua tujuan yang tidak dikenal

⚖️

Perbedaan Switch vs Router

Aspek 🔄 Switch 📡 Router
OSI Layer Layer 2 (Data Link) Layer 3 (Network)
Alamat yang Digunakan MAC Address IP Address
Fungsi Utama Menghubungkan perangkat dalam LAN Menghubungkan jaringan berbeda
Collision Domain Setiap port = 1 domain Setiap interface = 1 domain
Broadcast Domain Semua port = 1 domain Setiap interface = 1 domain
Harga Lebih murah Lebih mahal

🔄 Kapan Menggunakan Switch?

  • ✓ Menghubungkan komputer dalam satu ruangan
  • ✓ Membuat jaringan LAN sederhana
  • ✓ Menambah port pada router
  • ✓ Budget terbatas
  • ✓ Memisahkan collision domain

📡 Kapan Menggunakan Router?

  • ✓ Menghubungkan ke internet
  • ✓ Menghubungkan jaringan berbeda
  • ✓ Butuh keamanan (firewall)
  • ✓ Membuat WiFi hotspot
  • ✓ Routing antar subnet/VLAN

🏢 Studi Kasus: Membangun Jaringan Sekolah

🏫

Skenario

  • • 3 ruang kelas (masing-masing 10 PC)
  • • 1 ruang guru (5 PC)
  • • 1 ruang server
  • • Semua butuh akses internet
  • • Budget terbatas
🛠️

Solusi

  • • 1 Router untuk koneksi internet
  • • 4 Switch untuk setiap ruangan
  • • Kabel UTP Cat5e/Cat6
  • • 1 Modem dari ISP
  • • Patch Panel untuk manajemen kabel
💡

Keuntungan

  • • Setiap ruang punya jaringan lokal
  • • Semua bisa akses internet
  • • Mudah troubleshooting
  • • Bisa sharing printer per ruang
  • • Scalable untuk ekspansi

🎯 Mengapa Butuh Keduanya?

Switch: Menghubungkan semua PC dalam satu ruangan, sharing printer lokal, transfer file antar PC dalam ruang yang sama dengan kecepatan tinggi.

Router: Memberikan akses internet ke semua ruangan, mengatur traffic antar ruangan, menyediakan keamanan dengan firewall built-in.
