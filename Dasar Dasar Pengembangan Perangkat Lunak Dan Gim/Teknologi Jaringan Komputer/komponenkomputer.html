Pengenalan Komputer

🏗️ Apa itu Komputer?

Komputer adalah mesin elektronik yang dapat menerima, memproses, menyimpan, dan mengeluarkan data. Seperti tubuh manusia, komputer memiliki berbagai "organ" yang bekerja sama!

🔄 Siklus Kerja Komputer (IPO):

📥
INPUT

Keyboard, Mouse, Mic

⚙️
PROCESS

CPU & RAM

📤
OUTPUT

Monitor, Speaker, Printer

🧠

CPU - Otak Komputer

Memproses semua instruksi dan perhitungan

⚡

RAM - Memori Kerja

Menyimpan data sementara saat bekerja

🔌

Motherboard - Jalan Raya

Menghubungkan semua komponen

💾

Storage - Gudang Data

Menyimpan data secara permanen

🔄 Bagaimana Mereka Bekerja Sama?

Bayangkan komputer seperti dapur! CPU adalah koki, RAM adalah meja kerja, Motherboard adalah lantai dapur yang menghubungkan semua area, dan Storage adalah lemari penyimpanan bahan makanan.

📚 Sejarah Singkat Komputer:

1940s: Komputer pertama sebesar ruangan 🏢

1970s: Mikroprosesor pertama (Intel 4004) 🔬

1980s: PC untuk rumah tangga 🏠

1990s: Internet dan multimedia 🌐

2000s: Multi-core dan mobile 📱

2020s: AI dan quantum computing 🤖

CPU (Central Processing Unit)

Otak dari komputer yang memproses semua instruksi

⚙️ Apa itu CPU?

CPU adalah komponen yang menjalankan instruksi program komputer. Seperti otak manusia, CPU mengambil keputusan dan melakukan perhitungan.

📥

Fetch

Mengambil instruksi dari memori

🔍

Decode

Memahami instruksi yang diambil

⚡

Execute

Menjalankan instruksi tersebut

RAM (Random Access Memory)

Memori kerja komputer untuk menyimpan data sementara

🏃‍♀️ Apa itu RAM?

RAM adalah memori sementara yang menyimpan data dan program yang sedang digunakan. Seperti meja kerja - semakin luas, semakin banyak pekerjaan yang bisa dilakukan bersamaan!

📏 Kapasitas RAM

  • • 4GB: Tugas ringan
  • • 8GB: Multitasking normal
  • • 16GB: Gaming & editing
  • • 32GB+: Professional work

🏎️ Jenis RAM

  • • DDR4: Standar saat ini
  • • DDR5: Generasi terbaru
  • • SO-DIMM: Untuk laptop
  • • DIMM: Untuk desktop

⚠️ Yang Terjadi Jika RAM Kurang

  • • Komputer menjadi lambat
  • • Program sering hang atau crash
  • • Tidak bisa membuka banyak aplikasi
  • • Sistem menggunakan storage sebagai RAM (lebih lambat)

🚀 Teknologi RAM Terbaru:

DDR5 vs DDR4:

  • • Kecepatan: 4800-8400 MHz vs 2133-3200 MHz
  • • Efisiensi daya: 1.1V vs 1.2V
  • • Kapasitas maksimal: 128GB vs 32GB per modul

Dual Channel:

  • • 2 stick RAM = bandwidth 2x lipat
  • • Performa gaming meningkat 10-15%
  • • Lebih stabil untuk multitasking

HDD (Hard Disk Drive)

  • • Kecepatan: Lambat (5400-7200 RPM)

  • • Kapasitas: Sedang (128GB-4TB - Gigabyte/Terabyte)

  • • Kegunaan: OS & program

🔮 Teknologi Storage Masa Depan:

QLC vs TLC NAND:

  • • TLC (Triple-Level Cell): 3 bit per sel, lebih cepat, tahan lama
  • • QLC (Quad-Level Cell): 4 bit per sel, lebih murah, kapasitas besar
  • • 3D NAND: NAND Flash berlapis vertikal untuk efisiensi
  • • Perbandingan: TLC untuk performa, QLC untuk storage massal

Teknologi Baru:

  • • Optane: Intel 3D XPoint (memori super cepat)
  • • DirectStorage: GPU akses storage langsung
  • • Smart SSD: SSD dengan AI untuk optimasi

Tugas Pembelajaran

Uji pemahaman kamu tentang komponen utama komputer

📋 Petunjuk Pengerjaan

  • • Jawab semua pertanyaan dengan lengkap dan jelas
  • • Gunakan bahasa yang mudah dipahami
  • • Berikan contoh jika diperlukan
  • • Tulis jawaban di buku tugas atau ketik di komputer

1️⃣ Analisis Komponen

Soal: Jelaskan fungsi utama dari masing-masing komponen berikut dan berikan analogi sederhana untuk memudahkan pemahaman:

  • a) CPU (Central Processing Unit)
  • b) RAM (Random Access Memory)
  • c) Motherboard
  • d) Storage (HDD/SSD)

2️⃣ Studi Kasus

Soal: Seorang siswa ingin merakit komputer untuk keperluan:

  • • Menjalankan software desain grafis
  • • Bermain game modern
  • • Multitasking (banyak aplikasi bersamaan)

Berikan rekomendasi spesifikasi untuk setiap komponen (CPU, RAM, Storage) beserta alasannya!

3️⃣ Perbandingan Teknologi

Soal: Buatlah tabel perbandingan antara HDD dan SSD dengan kriteria:

  • • Kecepatan akses data
  • • Kapasitas penyimpanan
  • • Harga per GB
  • • Daya tahan (durability)
  • • Konsumsi listrik

4️⃣ Troubleshooting

Soal: Identifikasi kemungkinan penyebab dan solusi untuk masalah berikut:

  • a) Komputer sangat lambat saat membuka banyak aplikasi
  • b) Komputer sering hang saat bermain game
  • c) Waktu booting (menyala) sangat lama
  • d) Komputer tidak bisa menyala sama sekali

5️⃣ Kreativitas

Soal: Buatlah diagram atau gambar yang menunjukkan bagaimana keempat komponen utama (CPU, RAM, Motherboard, Storage) saling terhubung dan bekerja sama dalam sebuah komputer. Berikan penjelasan singkat untuk setiap koneksi!

⏰ Waktu & Penilaian

Waktu pengerjaan: 60 menit

Dikumpulkan: Pertemuan berikutnya

Penilaian berdasarkan:

  • • Kelengkapan jawaban (40%)
  • • Kejelasan penjelasan (30%)
  • • Kreativitas & analisis (30%)
