Apa itu Topologi Jaringan?

Topologi jaringan adalah cara atau pola pengaturan hubungan antar perangkat dalam sebuah jaringan komputer. Topologi menentukan bagaimana data mengalir dari satu perangkat ke perangkat lainnya.

🏘️ Analogi Tata Kota

🏙️ Tata Kota
  • 🏠 Rumah: Tempat tinggal warga
  • 🛣️ Jalan: Penghubung antar rumah
  • 🚦 Persimpangan: Titik pertemuan jalan
  • 🏢 Pusat Kota: Area utama aktivitas
💻 Jaringan Komputer
  • 💻 Komputer: Perangkat pengguna
  • 🔗 Kabel: Media penghubung
  • 🌐 Hub/Switch: Titik koneksi
  • 🖥️ Server: Pusat layanan

Sejarah Perkembangan Topologi

🕰️

Era 1960-1970: Awal Mula

Topologi Bus pertama kali digunakan dalam jaringan ARPANET. Sederhana tapi rentan terhadap gangguan.

⭐

Era 1980-1990: Revolusi Star

Topologi Star mulai populer dengan hadirnya hub dan switch. Lebih stabil dan mudah dikelola.

🌐

Era 2000-Sekarang: Hybrid & Wireless

Kombinasi berbagai topologi dan integrasi dengan teknologi wireless untuk fleksibilitas maksimal.

Topologi Bus

Topologi linear sederhana

Pengertian Topologi Bus

Topologi Bus adalah topologi jaringan yang menggunakan satu kabel utama (backbone) sebagai media transmisi. Semua perangkat terhubung ke kabel utama ini secara linear.

Karakteristik Topologi Bus

✅ Kelebihan

  • • Ekonomis: Menggunakan kabel sedikit
  • • Mudah dipasang: Instalasi sederhana
  • • Fleksibel: Mudah menambah perangkat
  • • Cocok untuk LAN kecil: Ideal untuk jaringan sederhana

❌ Kekurangan

  • • Single point of failure: Jika kabel utama rusak, semua terputus
  • • Collision domain: Data bisa bertabrakan
  • • Kinerja menurun: Semakin banyak perangkat, semakin lambat
  • • Sulit troubleshooting: Susah mencari masalah

Implementasi Nyata Topologi Bus

🏠 Contoh Penggunaan (Era 1990-2000)

  • • Warnet era awal: 5-10 komputer dengan kabel coaxial
  • • Lab komputer lama: Sistem pembelajaran sederhana
  • • Kantor kecil: Sharing printer dan file basic
  • • Jaringan rumahan: Menghubungkan 2-3 PC

Catatan: Topologi Bus jarang digunakan saat ini karena keterbatasannya

⚙️ Spesifikasi Teknis

  • • Kabel: Coaxial RG-58 (10Base2) atau RG-8 (10Base5)
  • • Terminator: 50 ohm di kedua ujung kabel
  • • Panjang maksimal: 185m (10Base2), 500m (10Base5)
  • • Jumlah node: Max 30 (10Base2), Max 100 (10Base5)
  • • Kecepatan: 10 Mbps
  • • Metode akses: CSMA/CD (Carrier Sense Multiple Access with Collision Detection)

Cara Kerja Data dalam Bus

📡 Proses Transmisi Data

1
Carrier Sense

Komputer mengecek apakah kabel sedang digunakan

2
Multiple Access

Jika kosong, komputer mulai mengirim data

3
Collision Detection

Jika ada tabrakan data, tunggu waktu random lalu coba lagi

4
Broadcast

Data dikirim ke semua perangkat, hanya yang dituju yang memproses

Topologi Star

Topologi terpusat paling populer

Pengertian Topologi Star

Topologi Star adalah topologi jaringan dimana semua perangkat terhubung ke satu titik pusat (hub/switch). Setiap perangkat memiliki koneksi langsung ke pusat.

Karakteristik Topologi Star

✅ Kelebihan

  • • Mudah dikelola: Kontrol terpusat
  • • Fault tolerance: Jika satu PC rusak, yang lain tetap jalan
  • • Mudah troubleshooting: Masalah mudah dilacak
  • • Kinerja stabil: Tidak ada collision

❌ Kekurangan

  • • Ketergantungan pada hub: Jika hub rusak, semua terputus
  • • Biaya kabel tinggi: Butuh banyak kabel
  • • Biaya hub/switch: Perlu perangkat pusat
  • • Keterbatasan port: Terbatas jumlah port hub

Studi Kasus: Implementasi Star di Sekolah

🏫 Skenario: SMK Teknologi Maju

SMK dengan 3 lab komputer (masing-masing 25 PC), 1 ruang guru (15 PC), dan 1 server room. Total 90 perangkat.

  • • Printer sharing di setiap lab
  • • Monitoring dan kontrol terpusat

Troubleshooting Topologi Star

🚨

Masalah: Semua PC tidak bisa akses internet

Kemungkinan penyebab:

  • • Switch/hub pusat mati atau rusak
  • • Kabel uplink ke router terputus
  • • Power supply switch bermasalah

Langkah troubleshooting:

  1. 1. Cek lampu indikator switch
  2. 2. Test ping ke gateway
  3. 3. Periksa kabel uplink
  4. 4. Restart switch jika perlu
⚠️

Masalah: Satu PC tidak terkoneksi

Kemungkinan penyebab:

  • • Kabel UTP dari PC ke switch rusak
  • • Port switch bermasalah
  • • Network card PC bermasalah

Langkah troubleshooting:

  1. 1. Cek lampu link di port switch
  2. 2. Ganti kabel UTP dengan yang baru
  3. 3. Coba port switch yang lain
  4. 4. Update driver network card

Topologi Ring

Topologi melingkar teratur

Pengertian Topologi Ring

Topologi Ring adalah topologi jaringan dimana setiap perangkat terhubung dengan dua perangkat lainnya, membentuk jalur melingkar. Data bergerak dalam satu arah mengelilingi ring.

Karakteristik Topologi Ring

✅ Kelebihan

  • • Tidak ada collision: Data bergerak satu arah dengan token passing
  • • Performa konsisten: Setiap node mendapat giliran yang adil
  • • Bandwidth terjamin: Tidak ada kontention seperti di Bus
  • • Hemat kabel: Setiap node hanya butuh 2 koneksi
  • • Mudah monitoring: Data flow dapat dipantau dengan mudah

❌ Kekurangan

  • • Single point of failure: Satu node/kabel rusak, seluruh ring terputus
  • • Sulit troubleshooting: Susah isolasi masalah tanpa memutus ring
  • • Delay tinggi: Data harus melewati semua node sebelum sampai tujuan
  • • Sulit rekonfigurasi: Menambah/hapus node harus memutus ring
  • • Token loss: Jika token hilang, seluruh jaringan berhenti

🔄 Cara Kerja Token Ring

🎫
Token Passing

Token beredar mengelilingi ring

📤
Data Transmission

Node menangkap token untuk kirim data

🔄
Token Release

Token dilepas setelah data terkirim

Standar IEEE 802.5, kecepatan 4-16 Mbps, populer di lingkungan IBM

🌐
FDDI (Fiber Distributed Data Interface)

Ring ganda dengan fiber optic, kecepatan 100 Mbps, untuk backbone

Topologi Mesh

Topologi saling terhubung

Pengertian Topologi Mesh

Topologi Mesh adalah topologi jaringan dimana setiap perangkat terhubung langsung dengan semua perangkat lainnya. Ini memberikan redundancy dan fault tolerance yang sangat tinggi.

Karakteristik Topologi Mesh

✅ Kelebihan

  • • Fault tolerance tinggi: Banyak jalur alternatif
  • • Tidak ada bottleneck: Multiple paths
  • • Keamanan tinggi: Data bisa lewat jalur berbeda
  • • Bandwidth dedicated: Setiap link eksklusif

❌ Kekurangan

  • • Biaya sangat tinggi: Banyak kabel dan port
  • • Kompleksitas tinggi: Sulit konfigurasi
  • • Maintenance sulit: Banyak koneksi
  • • Routing complex: Banyak path choices

Topologi Hybrid: Kombinasi Mesh

🌐 Partial Mesh vs Full Mesh

🔗 Partial Mesh
  • • Tidak semua node terhubung langsung
  • • Hanya node penting yang fully connected
  • • Lebih ekonomis dari full mesh
  • • Cocok untuk WAN dan internet backbone
🕸️ Full Mesh
  • • Setiap node terhubung ke semua node lain
  • • Redundancy maksimal
  • • Biaya sangat tinggi
  • • Hanya untuk aplikasi mission-critical

🧮 Rumus Perhitungan Koneksi Mesh

Jumlah Koneksi = n × (n-1) ÷ 2

dimana n = jumlah node

3 Node
3×2÷2 = 3 koneksi
5 Node
5×4÷2 = 10 koneksi
10 Node
10×9÷2 = 45 koneksi

🌐
Internet Backbone

ISP menggunakan mesh untuk routing alternatif jika ada jalur yang down

🏥
Hospital Network

Sistem kritikal rumah sakit butuh full mesh untuk zero downtime
