🎯 Fokus Pembelajaran: NIC bekerja di Layer 2 (Data Link) untuk mengelola MAC Address dan Frame, sedangkan Media Transmisi bekerja di Layer 1 (Physical) untuk mengirim sinyal dan bit data.

Network Interface Card (NIC)

Memahami fungsi dan cara kerja kartu jaringan

Apa itu Network Interface Card?

NIC adalah perangkat keras yang memungkinkan komputer berkomunikasi dalam jaringan. Seperti kartu pos yang memiliki alamat, NIC memiliki MAC Address unik untuk identifikasi!

Visualisasi Network Interface Card

RJ45
CHIP
MAC: 00:1B:44:11:3A:B7
NIC

✨ Setiap bagian NIC memiliki fungsi penting dalam komunikasi jaringan!

🎯 Fungsi Utama NIC

  • • Konversi Data: Mengubah data digital ke sinyal listrik
  • • Addressing: Memberikan alamat unik (MAC Address)
  • • Frame Processing: Membuat dan memproses frame data
  • • Error Detection: Mendeteksi kesalahan transmisi

⚙️ Cara Kerja NIC

  1. Menerima data dari sistem operasi
  2. Membungkus data dalam frame Ethernet
  3. Menambahkan MAC address tujuan
  4. Mengirim sinyal melalui media transmisi

🔍 MAC Address

Apa itu MAC Address?
  • • Media Access Control Address
  • • Alamat fisik unik setiap NIC
  • • Format: 6 byte (48 bit)
  • • Contoh: 00:1B:44:11:3A:B7
Karakteristik:
  • • Ditetapkan oleh pabrik (burned-in)
  • • Tidak bisa diubah secara permanen
  • • Digunakan di Layer 2 (Data Link)
  • • Unik di seluruh dunia

🔧 Langkah Instalasi NIC

Persiapan:
  1. Matikan komputer dan cabut kabel power
  2. Buka casing komputer
  3. Gunakan gelang anti-statis
  4. Identifikasi slot PCI/PCIe kosong
Instalasi:
  1. Lepas bracket slot yang akan digunakan
  2. Masukkan NIC ke slot dengan hati-hati
  3. Tekan hingga terpasang sempurna
  4. Kencangkan sekrup penahan
⚠️ Tips Penting:
  • • Pastikan komputer dalam keadaan mati saat instalasi
  • • Jangan menyentuh komponen elektronik dengan tangan basah
  • • Install driver setelah hardware terpasang
  • • Test konektivitas setelah instalasi selesai

Klasifikasi NIC

NIC memiliki berbagai jenis berdasarkan teknologi, kecepatan, dan cara pemasangannya. Mari kita pelajari satu per satu!

🔧 Berdasarkan Pemasangan

  • • Performa lebih stabil
  • • Harga lebih murah
🔌

  • • Plug and play
  • • Mudah dipindah-pindah
  • • Cocok untuk laptop

🚀

💡 Tips Memilih NIC

Pertimbangan Teknis:
  • • Kecepatan sesuai kebutuhan
  • • Kompatibilitas dengan motherboard
  • • Dukungan driver sistem operasi
  • • Fitur tambahan (VLAN, QoS)
Pertimbangan Praktis:
  • • Budget yang tersedia
  • • Kebutuhan mobilitas
  • • Rencana upgrade masa depan
  • • Brand dan garansi

Media Transmisi

Mengenal berbagai media penghubung dalam jaringan

Apa itu Media Transmisi?

Media transmisi adalah jalur fisik yang digunakan untuk mengirim data dari satu perangkat ke perangkat lain. Seperti jalan raya untuk kendaraan, media transmisi adalah jalan untuk data!

Jenis-jenis Media Transmisi

🔌 Guided Media (Terpandu)
🔌
Twisted Pair
UTP Cable
  • • Murah dan mudah instalasi
  • • Jarak maksimal 100m
  • • Rentan interferensi
💡
Fiber Optic
Fiber Cable
  • • Kecepatan sangat tinggi
  • • Jarak sangat jauh
  • • Tidak ada interferensi
📺
Coaxial
Coax Cable
  • • Tahan interferensi
  • • Jarak lebih jauh
  • • Untuk TV kabel/internet
📡 Unguided Media (Tidak Terpandu)
📻
Radio Wave
WiFi/Bluetooth
  • • Wireless, mudah setup
  • • Jarak terbatas
  • • Rentan interferensi
🛰️
Satellite
Global Coverage
  • • Jangkauan global
  • • Latency tinggi
  • • Area terpencil

📊 Perbandingan Karakteristik

Media Kecepatan Jarak Biaya
UTP Sedang 100m Rendah
Fiber Optic Sangat Tinggi 100km+ Tinggi
Wireless Bervariasi Terbatas Sedang

Kabel UTP

Memahami Unshielded Twisted Pair secara detail

Kabel UTP (Unshielded Twisted Pair)

UTP adalah jenis kabel yang paling umum digunakan dalam jaringan LAN. Terdiri dari 4 pasang kabel yang dipilin untuk mengurangi interferensi elektromagnetik!

📏 Kategori UTP

Cat 5 100 Mbps (100 MHz)
Cat 5e 1 Gbps (100 MHz)
Cat 6 1 Gbps (250 MHz)
Cat 6a 10 Gbps (500 MHz)

🔧 Jenis Konfigurasi Kabel

Straight-through

PC ↔ Switch/Hub, PC ↔ Router

Kedua ujung: T568A atau T568B

Crossover

PC ↔ PC, Switch ↔ Switch, Hub ↔ Hub

Ujung 1: T568A, Ujung 2: T568B

Rollover/Console

PC ↔ Console Port Router/Switch

Pin 1↔8, 2↔7, 3↔6, 4↔5

💡 Digunakan untuk: PC ↔ PC, Switch ↔ Switch, Hub ↔ Hub

⚡ Pin yang Aktif dalam Ethernet
Fast Ethernet (10/100 Mbps)
Pin 1 & 2: TX (Transmit)
Pin 3 & 6: RX (Receive)
Pin 4, 5, 7, 8: Tidak digunakan
Gigabit Ethernet (1000 Mbps)
Pin 1 & 2: Pair 1 (Bi-directional)
Pin 3 & 6: Pair 2 (Bi-directional)
Pin 4 & 5: Pair 3 (Bi-directional)
Pin 7 & 8: Pair 4 (Bi-directional)

Penting: Pada crossover, pin 1↔3 dan pin 2↔6 ditukar untuk memungkinkan komunikasi langsung antar perangkat sejenis

⚠️ Kelebihan dan Kekurangan UTP

✅ Kelebihan:
  • • Harga murah dan mudah didapat
  • • Instalasi mudah dan fleksibel
  • • Kompatibel dengan banyak perangkat
  • • Maintenance mudah
❌ Kekurangan:
  • • Rentan terhadap interferensi EMI
  • • Jarak terbatas (maksimal 100m)
  • • Bandwidth terbatas dibanding fiber
  • • Keamanan data kurang

🔧 Praktik Crimping Kabel UTP

🛠️ Alat yang Dibutuhkan:
✂️
Crimping Tool
🔌
RJ45 Connector
📏
Cable Stripper
🔍
Cable Tester
📋 Langkah Crimping:
  1. Kupas jacket kabel UTP sepanjang 2-3 cm
  2. Pisahkan dan luruskan 8 kabel twisted pair
  3. Susun kabel sesuai standar T568A atau T568B
  4. Potong ujung kabel agar rata (12-13mm)
  5. Masukkan kabel ke konektor RJ45
  6. Pastikan semua kabel masuk sempurna
  7. Crimp menggunakan crimping tool
  8. Test kabel dengan cable tester
⚠️ Tips Sukses:
  • • Pastikan urutan warna kabel benar
  • • Jangan terlalu banyak mengupas jacket
  • • Tekan crimping tool dengan kuat dan merata
  • • Selalu test kabel sebelum digunakan

Fiber Optic

Teknologi transmisi data menggunakan cahaya

Kabel Fiber Optic

Fiber optic menggunakan serat kaca atau plastik untuk mengirim data dalam bentuk pulsa cahaya. Seperti mengirim pesan dengan senter melalui pipa transparan!

🔍 Jenis Fiber Optic

Single Mode (SMF)
  • • Core diameter: 9 μm
  • • Jarak sangat jauh (100+ km)
  • • Bandwidth sangat tinggi
  • • Untuk backbone & WAN
Multi Mode (MMF)
  • • Core diameter: 50/62.5 μm
  • • Jarak sedang (2-10 km)
  • • Lebih murah dari SMF
  • • Untuk LAN & campus network

⚡ Karakteristik Fiber

  • • Kecepatan: Mendekati kecepatan cahaya
  • • Bandwidth: Sangat tinggi (Tbps)
  • • Attenuation: Sangat rendah
  • • Immunity: Kebal interferensi EMI

🔧 Instalasi & Maintenance Fiber Optic

🛠️ Peralatan Khusus:
⚡
Fusion Splicer

Penyambung serat

🔍
OTDR

Optical Time Domain Reflectometer

💡
Light Source

Sumber cahaya test

📊
Power Meter

Pengukur daya optik

📋 Proses Instalasi:
  1. Survey lokasi dan perencanaan jalur kabel
  2. Instalasi kabel fiber optic (aerial/underground)
  3. Splicing (penyambungan) serat optik
  4. Terminasi konektor di kedua ujung
  5. Testing dengan OTDR dan power meter
  6. Dokumentasi hasil pengukuran
  7. Commissioning dan handover
⚠️ Hal Penting dalam Instalasi Fiber Optic:
🚨 Keamanan Kerja:
  • • JANGAN PERNAH lihat langsung ke ujung fiber yang aktif
  • • Gunakan safety glasses khusus fiber optic
  • • Buang potongan fiber di tempat khusus (berbahaya jika tertelan)
  • • Matikan laser source saat cleaning konektor
🔧 Kualitas Instalasi:
  • • Bersihkan konektor dengan alkohol isopropyl
  • • Minimum bend radius: 10x diameter kabel
  • • Cek loss budget sebelum dan sesudah instalasi
  • • Dokumentasi hasil pengukuran OTDR
