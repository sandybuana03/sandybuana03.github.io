Pengenalan Jaringan Komputer

🌍

Apa itu Jaringan Komputer?

Jaringan komputer adalah kumpulan komputer yang saling terhubung untuk berbagi data, informasi, dan sumber daya. Bayangkan seperti jalan raya yang menghubungkan berbagai kota!

💡

Analogi Sederhana: Jaringan komputer seperti sistem pos. Ada pengirim (client), kantor pos (server), dan berbagai cara pengiriman (protokol).

📜

Sejarah Singkat Jaringan

🚀

1960s - ARPANET

Jaringan pertama yang dikembangkan oleh DARPA (AS) untuk menghubungkan universitas dan lembaga penelitian

📡

1980s - TCP/IP

Protokol standar dikembangkan, memungkinkan berbagai jaringan terhubung

🌐

1990s - World Wide Web

Tim Berners-Lee menciptakan WWW, membuat internet mudah diakses semua orang

📱

2000s - Internet Modern

Era mobile internet, cloud computing, dan Internet of Things (IoT)

🔧

Komponen Utama Jaringan

💻

Node

Perangkat yang terhubung dalam jaringan (komputer, printer, router, switch)

🔌

Media Transmisi

Saluran untuk mengirim data (kabel, fiber optik, wireless, bluetooth)

📋

Protokol

Aturan komunikasi dalam jaringan (TCP/IP, HTTP, FTP, SMTP)

🗺️

Topologi

Bentuk/struktur jaringan (star, ring, bus, mesh, hybrid)

📏

Jenis Jaringan Berdasarkan Cakupan

📱

PAN (Personal Area Network)

Jangkauan: 1-10 meter

Contoh: Bluetooth headset, smartwatch, hotspot HP

🏠

LAN (Local Area Network)

Jangkauan: Dalam satu gedung/kampus

Contoh: WiFi sekolah, jaringan kantor, warnet

🏙️

MAN (Metropolitan Area Network)

Jangkauan: Satu kota/wilayah metropolitan

Contoh: Jaringan antar kampus, TV kabel kota

🌍

WAN (Wide Area Network)

Jangkauan: Antar kota, negara, benua

Contoh: Internet, jaringan bank nasional, satelit

Arsitektur Client-Server

Model dimana ada komputer yang berperan sebagai pelayan (server) dan komputer yang dilayani (client). Seperti restoran dengan pelayan dan pelanggan!

🔗

Arsitektur Peer-to-Peer

Model dimana setiap komputer bisa berperan sebagai client dan server sekaligus. Seperti teman-teman yang saling berbagi makanan!

🖥️

Arsitektur Client-Server

📖

Pengertian

Client-Server adalah model arsitektur jaringan dimana ada pembagian tugas yang jelas antara dua komponen utama:

💻

CLIENT

Komputer atau aplikasi yang meminta layanan, data, atau sumber daya. Client mengirim permintaan (request) ke server.

Contoh: Browser web, aplikasi email, game online
🖥️

SERVER

Komputer yang menyediakan layanan, data, atau sumber daya. Server memproses permintaan dan mengirim respons ke client.

Contoh: Web server, database server, file server
🔄

Cara Kerja

1. Client mengirim request (permintaan) ke server
2. Server memproses request tersebut
3. Server mengirim response (tanggapan) kembali ke client
4. Client menerima dan menampilkan hasil

Kelebihan Client-Server

  • • Keamanan tinggi: Data terpusat dan mudah dikontrol
  • • Manajemen mudah: Administrasi terpusat di server
  • • Backup terjamin: Data tersimpan aman di server
  • • Kontrol akses: Dapat mengatur siapa yang boleh mengakses
  • • Performa stabil: Server khusus untuk melayani client
⚠️

Kekurangan Client-Server

  • • Biaya tinggi: Perlu server khusus dan maintenance
  • • Single point of failure: Jika server rusak, semua terganggu
  • • Butuh admin: Perlu tenaga ahli untuk mengelola server
  • • Bottleneck: Server bisa overload jika client terlalu banyak
  • • Ketergantungan: Client tidak bisa bekerja tanpa server

Arsitektur Peer-to-Peer (P2P)

📖

Pengertian Peer-to-Peer (P2P)

Peer-to-Peer (P2P) adalah model arsitektur jaringan dimana setiap komputer (disebut peer) dapat berperan sebagai client dan server sekaligus. Tidak ada server pusat yang mengontrol jaringan.

💡

Analogi Sederhana: Seperti grup teman yang saling berbagi makanan. Setiap orang bisa memberi dan menerima makanan dari teman lainnya tanpa ada "koordinator" khusus.

🔄

Karakteristik P2P

  • • Desentralisasi: Tidak ada server pusat
  • • Peer setara: Setiap komputer memiliki peran yang sama
  • • Berbagi langsung: Data dibagi langsung antar peer
  • • Skalabilitas: Semakin banyak peer, semakin kuat jaringan

Kelebihan P2P

  • • Tanpa server pusat: Tidak perlu investasi server mahal
  • • Biaya rendah: Setiap peer berkontribusi sumber daya
  • • Fault tolerance: Jika satu peer offline, yang lain tetap berjalan
  • • Skalabilitas tinggi: Performa meningkat seiring bertambahnya peer
  • • Bandwidth terdistribusi: Beban jaringan tersebar merata
⚠️

Kekurangan P2P

  • • Keamanan rendah: Sulit mengontrol konten dan akses
  • • Sulit dikelola: Tidak ada kontrol terpusat
  • • Kualitas tidak konsisten: Bergantung pada peer yang online
  • • Backup sulit: Data tersebar di banyak tempat
  • • Masalah legal: Sulit mengatur hak cipta dan konten ilegal
🔄

Jenis-Jenis P2P

🔵

Pure P2P (Murni)

Tidak ada server pusat sama sekali. Semua peer memiliki peran yang sama dan berkomunikasi langsung.

Contoh: Gnutella, Freenet, beberapa aplikasi blockchain

Karakteristik: Sangat terdistribusi, sulit dikontrol, tahan terhadap sensor

🟢

Hybrid P2P (Campuran)

Menggunakan server pusat untuk koordinasi awal, tapi transfer data dilakukan langsung antar peer.

Contoh: BitTorrent (tracker server), Napster (dulu), Skype (dulu)

Karakteristik: Lebih mudah dikelola, performa lebih baik, masih ada titik kontrol

🟣

Structured P2P (Terstruktur)

Menggunakan algoritma khusus (DHT - Distributed Hash Table) untuk mengorganisir peer secara efisien.

Contoh: Chord, Kademlia, BitTorrent DHT

Karakteristik: Pencarian efisien, skalabilitas tinggi, kompleksitas sedang

🔒

Tantangan Keamanan P2P

⚠️ Risiko Keamanan

🦠
Malware & Virus

File yang dibagikan bisa mengandung virus atau malware berbahaya

👤
Identitas Palsu

Sulit memverifikasi identitas peer yang sebenarnya

📊
Data Poisoning

Peer jahat bisa menyebarkan data palsu atau rusak

✅ Solusi Keamanan

🔐
Enkripsi

Mengenkripsi data yang dikirim antar peer

✅
Digital Signature

Memverifikasi keaslian data dan pengirim

⭐
Reputation System

Sistem rating untuk menilai kepercayaan peer

🚀

Perbandingan Client-Server vs P2P

Aspek Perbandingan Client-Server 🖥️ Peer-to-Peer 🔗
Struktur Jaringan Terpusat (ada server utama) Tersebar (tidak ada pusat)
Biaya Implementasi Tinggi (perlu server khusus) Rendah (menggunakan PC biasa)
Tingkat Keamanan Tinggi (kontrol terpusat) Rendah (sulit dikontrol)
Kemudahan Kontrol Mudah (admin terpusat) Sulit (tidak ada admin pusat)
Keandalan Sistem Bergantung pada server Tidak bergantung satu titik
Skalabilitas Terbatas kapasitas server Tinggi (bertambah dengan peer)
Kecepatan Transfer Konsisten (tergantung server) Bervariasi (tergantung peer)
Backup Data Mudah (terpusat di server) Sulit (tersebar di peer)
🏢

Kapan Pakai Client-Server?

  • ✅ Butuh keamanan tinggi
  • ✅ Data harus terpusat
  • ✅ Kontrol ketat diperlukan
  • ✅ Aplikasi bisnis/perbankan
🔗

Kapan Pakai P2P?

  • ✅ Berbagi file besar
  • ✅ Biaya harus murah
  • ✅ Tidak butuh kontrol ketat
  • ✅ Aplikasi komunitas
