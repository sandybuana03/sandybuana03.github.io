Pengenalan TCP/IP

🌐 Apa itu TCP/IP?

TCP/IP (Transmission Control Protocol/Internet Protocol) adalah seperti "aturan main" yang digunakan semua perangkat di internet untuk berkomunikasi. Bayangkan seperti bahasa universal yang dipahami semua komputer di dunia!

🏗️ Model 4 Layer TCP/IP

TCP/IP terdiri dari 4 lapisan (layer) yang bekerja sama seperti tim:

💻

Layer 4: Application Layer

Tempat aplikasi seperti WhatsApp, Instagram, Chrome bekerja

🚛

Layer 3: Transport Layer

Mengatur pengiriman data, memastikan sampai dengan benar

🌍

Layer 2: Internet Layer

Menentukan jalur terbaik untuk mengirim data

🔗

Layer 1: Network Access Layer

Mengirim data melalui kabel, WiFi, atau media fisik lainnya

📮 Analogi Sederhana

Bayangkan kalian mengirim surat ke teman. TCP/IP seperti sistem pos:
• Application Layer: Isi surat yang kalian tulis
• Transport Layer: Amplop dan cara pengemasan
• Internet Layer: Alamat tujuan dan rute pengiriman
• Network Access Layer: Kendaraan pos yang membawa surat

💻

Layer Aplikasi (Application Layer)

🎯 Fungsi Utama

Layer Aplikasi adalah tempat dimana aplikasi yang kita gunakan sehari-hari berinteraksi dengan jaringan. Ini adalah layer yang paling dekat dengan pengguna (kita)!

📱 Contoh Aplikasi

🌐

Web Browser

Chrome, Firefox, Safari - menggunakan protokol HTTP/HTTPS

📧

Email

Gmail, Outlook - menggunakan protokol SMTP, POP3, IMAP

💬

Chat Apps

WhatsApp, Telegram, Discord

📁

File Transfer

Google Drive, Dropbox - menggunakan protokol FTP/SFTP

🔧 Protokol Utama

HTTP/HTTPS: Untuk browsing website
SMTP: Untuk mengirim email
FTP: Untuk transfer file
DNS: Untuk mengubah nama domain jadi IP address

Layer Transport

🎯 Fungsi Utama

Layer Transport bertanggung jawab untuk memastikan data sampai dengan benar dan lengkap. Seperti kurir yang memastikan paket kalian sampai dengan selamat!

✅ Reliable Delivery

Memastikan semua data sampai tanpa ada yang hilang

🔢 Error Detection

Mendeteksi dan memperbaiki data yang rusak

🔧 Protokol Utama

🤝

TCP (Transmission Control Protocol)

Sifat: Reliable (dapat diandalkan)

Kecepatan: Lebih lambat tapi aman

Digunakan untuk: Web browsing, email, file transfer

Analogi: Seperti pos kilat yang ada resi dan konfirmasi

⚡

UDP (User Datagram Protocol)

Sifat: Unreliable (tidak ada jaminan)

Kecepatan: Sangat cepat

Digunakan untuk: Video streaming, game online, DNS

Analogi: Seperti siaran radio, cepat tapi tidak ada konfirmasi

Layer Internet

🎯 Fungsi Utama

Layer Internet bertugas menentukan jalur terbaik untuk mengirim data dari sumber ke tujuan. Seperti GPS yang mencari rute tercepat untuk sampai ke tempat tujuan!

🗺️

Routing

Menentukan jalur terbaik

📍

Addressing

Memberikan alamat IP

📦

Packaging

Membungkus data dalam paket

🏠 IP Address

IP Address adalah alamat unik setiap perangkat di internet, seperti alamat rumah kalian!

4️⃣ IPv4

Format: 192.168.1.1

Panjang: 32 bit

Jumlah: ~4.3 miliar alamat

6️⃣ IPv6

Format: 2001:db8::1

Panjang: 128 bit

Jumlah: Hampir tak terbatas!

🔧 Protokol Utama: IP (Internet Protocol)

Tugas Protokol IP:

✅ Memberikan alamat unik (IP Address)
✅ Memecah data jadi paket-paket kecil
✅ Menentukan rute pengiriman
✅ Menyatukan paket di tujuan

Layer Akses Jaringan

🎯 Fungsi Utama

Layer Akses Jaringan adalah layer paling bawah yang bertugas mengirim data melalui media fisik. Seperti jalan raya tempat kendaraan (data) berjalan!

🚚 Physical Transmission

Mengirim sinyal melalui kabel, WiFi, atau media lainnya

🏷️ MAC Addressing

Menggunakan alamat MAC untuk identifikasi perangkat

🌐 Jenis Media Transmisi

📡

WiFi (Wireless)

Menggunakan gelombang radio

Kecepatan: 54 Mbps - 1 Gbps

🔌

Ethernet (Kabel)

Menggunakan kabel UTP/STP

Kecepatan: 10 Mbps - 100 Gbps

💡

Fiber Optic

Menggunakan cahaya

Kecepatan: 1 Gbps - 100 Tbps

📱

Cellular (4G/5G)

Menggunakan tower seluler

Kecepatan: 1 Mbps - 10 Gbps

🛰️

Satellite

Menggunakan satelit

Kecepatan: 1 Mbps - 100 Mbps

🔵

Bluetooth

Jarak pendek

Kecepatan: 1 Mbps - 50 Mbps

🏷️ MAC Address

MAC (Media Access Control) Address adalah alamat fisik unik setiap perangkat jaringan. Seperti nomor seri yang tidak bisa diganti!

Format MAC Address:

AA:BB:CC:DD:EE:FF

6 pasang karakter hexadecimal

Contoh MAC Address:

00:1B:44:11:3A:B7
AC:DE:48:00:11:22
08:00:27:12:34:56
