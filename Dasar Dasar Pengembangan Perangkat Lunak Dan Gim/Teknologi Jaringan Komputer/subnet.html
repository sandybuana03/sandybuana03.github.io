Pengenalan Subnet Mask

Mari kenali apa itu subnet mask dan mengapa penting dalam jaringan!

🌐 Apa itu Subnet Mask?

Subnet mask adalah serangkaian angka 32-bit yang digunakan untuk membagi jaringan IP menjadi bagian-bagian kecil yang disebut subnet. Subnet mask bekerja seperti filter yang memisahkan alamat jaringan (network) dari alamat perangkat (host).

💡 Analogi Sederhana:

Bayangkan alamat rumah: "Jl. Merdeka No. 123, Jakarta Pusat". Subnet mask seperti kode pos yang membantu membedakan "Jakarta Pusat" (network) dari "No. 123" (host).

🔍 Definisi Teknis:

Subnet mask adalah nilai biner 32-bit yang digunakan dalam operasi AND bitwise dengan IP address untuk menentukan network address dan host address.

🏠

Contoh Subnet Mask

255.255.255.0

Format paling umum untuk jaringan kecil

Dalam Biner:

11111111.11111111.11111111.00000000

24 bit network, 8 bit host

Konsep Dasar Subnet Mask

Memahami cara kerja subnet mask secara mendalam

🔢 Sistem Biner dalam Subnet Mask

Subnet mask menggunakan sistem biner (0 dan 1) untuk menentukan bagian network dan host dari IP address. Setiap oktet subnet mask terdiri dari 8 bit yang dapat bernilai 0 atau 1.

Bit 1 (Network)

Menunjukkan bagian alamat jaringan

11111111

= 255 dalam desimal

Bit 0 (Host)

Menunjukkan bagian alamat perangkat

00000000

= 0 dalam desimal

🔍 Aturan Penting:

  • • Bit network (1) harus berurutan dari kiri
  • • Bit host (0) harus berurutan dari kanan
  • • Tidak boleh ada bit 1 setelah bit 0
  • • Contoh SALAH: 11110011 (tidak berurutan)

⚙️ Operasi AND Bitwise

Subnet mask bekerja dengan operasi AND bitwise untuk memisahkan network dan host address. Operasi ini dilakukan bit per bit antara IP address dan subnet mask.

🔢 Aturan Operasi AND:

1 AND 1 = 1

1 AND 0 = 0

0 AND 1 = 0

0 AND 0 = 0

📝 Contoh Perhitungan Operasi AND:

IP Address: 192.168.1.100
11000000.10101000.00000001.01100100
Subnet Mask: 255.255.255.0
11111111.11111111.11111111.00000000
AND
Network Address: 192.168.1.0
11000000.10101000.00000001.00000000

Penjelasan: Setiap bit IP address di-AND dengan bit subnet mask. Bit 1 AND 1 = 1, bit 1 AND 0 = 0, bit 0 AND 1 = 0, bit 0 AND 0 = 0. Hasilnya adalah network address yang mengidentifikasi jaringan.

🏠 Network Address

Alamat yang mengidentifikasi jaringan secara keseluruhan. Diperoleh dengan operasi AND antara IP address dan subnet mask.

192.168.1.0

Network address untuk subnet /24

Karakteristik:
  • • Semua bit host bernilai 0
  • • Tidak dapat digunakan untuk perangkat
  • • Mengidentifikasi seluruh subnet
  • • Digunakan dalam routing table

📡 Broadcast Address

Alamat khusus untuk mengirim data ke semua perangkat dalam subnet sekaligus. Diperoleh dengan mengubah semua bit host menjadi 1.

192.168.1.255

Broadcast address untuk subnet /24

Fungsi:
  • • Mengirim data ke semua host
  • • Tidak dapat digunakan untuk perangkat
  • • Digunakan untuk protokol discovery
  • • Penting untuk DHCP dan ARP

🧮 Menghitung Jumlah Host

📐 Rumus Dasar

2ⁿ - 2

n = jumlah bit host

Mengapa dikurangi 2?

• -1 untuk network address

• -1 untuk broadcast address

📊 Contoh Perhitungan

/24 → 8 bit host

2⁸ - 2 = 256 - 2 = 254 host

/26 → 6 bit host

2⁶ - 2 = 64 - 2 = 62 host

/30 → 2 bit host

2² - 2 = 4 - 2 = 2 host

💡 Tips Praktis

🎯 Menghafal Subnet Mask:
  • • /24 = 255.255.255.0 (paling umum)
  • • /16 = 255.255.0.0 (jaringan menengah)
  • • /8 = 255.0.0.0 (jaringan besar)
  • • /30 = 255.255.255.252 (point-to-point)
🔍 Identifikasi Cepat:
  • • Lihat oktet terakhir subnet mask
  • • 0 = 8 bit host, 128 = 1 bit host
  • • 192 = 6 bit host, 224 = 5 bit host
  • • 240 = 4 bit host, 248 = 3 bit host

📐 Penjelasan Lengkap CIDR

🔍 Apa itu CIDR?

CIDR (Classless Inter-Domain Routing) adalah metode alokasi alamat IP dan routing yang diperkenalkan pada tahun 1993 untuk menggantikan sistem kelas IP tradisional (A, B, C).

🎯 Tujuan CIDR:
  • • Mengatasi pemborosan alamat IP
  • • Mengurangi ukuran routing table
  • • Memberikan fleksibilitas pembagian jaringan
  • • Memperlambat habisnya alamat IPv4
⚡ Keunggulan CIDR:
  • • Subnet mask dapat disesuaikan kebutuhan
  • • Agregasi rute (route summarization)
  • • Efisiensi penggunaan alamat IP
  • • Mendukung VLSM (Variable Length Subnet Mask)

📊 Cara Kerja CIDR

CIDR menggunakan notasi "/n" dimana n adalah jumlah bit yang digunakan untuk network address.

Contoh: 192.168.1.0/24
  • • /24 = 24 bit pertama untuk network
  • • 8 bit sisanya untuk host (32-24=8)
  • • 2⁸ = 256 alamat total
  • • 254 alamat untuk host (256-2)
Perbandingan dengan Sistem Kelas:

❌ Sistem Kelas Lama:

Kelas C = /24 (254 host) - TETAP

✅ Sistem CIDR:

/25 (126 host), /26 (62 host), /27 (30 host) - FLEKSIBEL

💡 Tips Mudah Mengingat

Format CIDR

Angka setelah "/" menunjukkan jumlah bit network. Semakin besar angka, semakin sedikit host yang tersedia.

Format Desimal

255 = semua bit network, 0 = semua bit host. Kombinasi keduanya menentukan pembagian jaringan.

🏠 IP Address Private

IP address private adalah alamat yang digunakan dalam jaringan lokal dan tidak dapat diakses langsung dari internet.

Kelas A Private

10.0.0.0 - 10.255.255.255

Subnet: /8

Kelas B Private

172.16.0.0 - 172.31.255.255

Subnet: /12 (16 blok /16)

Kelas C Private

192.168.0.0 - 192.168.255.255

Subnet: /16 (256 blok /24)

🎯 Cara Menentukan Kelas IP

Lihat Oktet Pertama:
  • 1-126 = Kelas A
  • 128-191 = Kelas B
  • 192-223 = Kelas C
Contoh:
  • 10.0.0.1 → Kelas A
  • 172.16.0.1 → Kelas B
  • 192.168.1.1 → Kelas C
