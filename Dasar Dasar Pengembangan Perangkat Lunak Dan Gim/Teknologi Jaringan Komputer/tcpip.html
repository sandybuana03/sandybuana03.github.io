Pengenalan TCP/IP

Memahami fondasi komunikasi internet

Apa itu TCP/IP?

TCP/IP (Transmission Control Protocol/Internet Protocol) adalah kumpulan protokol komunikasi yang digunakan untuk menghubungkan perangkat di internet dan jaringan komputer. TCP/IP adalah "bahasa universal" yang memungkinkan berbagai jenis perangkat berkomunikasi satu sama lain.

🏃‍♂️ Analogi Sistem Pos

📮 Sistem Pos Tradisional
  • 📝 Surat: Pesan yang dikirim
  • 📦 Amplop: Pembungkus surat
  • 🏠 Alamat: Tujuan pengiriman
  • 🚚 Kurir: Pengantar surat
  • 📋 Aturan: Prosedur pengiriman
  • 🏢 Kantor Pos: Pusat distribusi
💻 Sistem TCP/IP
  • 📄 Data: Informasi yang dikirim
  • 📦 Packet: Pembungkus data
  • 🏠 IP Address: Alamat komputer
  • 🌐 Router: Pengarah data
  • 📋 Protocol: Aturan komunikasi
  • 🏢 ISP: Penyedia layanan internet

Mengapa TCP/IP Penting?

🌍 Universalitas

  • • Standar global untuk komunikasi internet
  • • Kompatibel dengan semua sistem operasi
  • • Mendukung berbagai jenis perangkat
  • • Platform-independent protocol

🔧 Fleksibilitas

  • • Scalable untuk jaringan kecil hingga global
  • • Mendukung berbagai aplikasi
  • • Dapat beradaptasi dengan teknologi baru
  • • Robust dan fault-tolerant

Layer Aplikasi

Interface antara user dan jaringan

Fungsi Layer Aplikasi

Layer Aplikasi adalah layer teratas dalam model TCP/IP yang berinteraksi langsung dengan pengguna. Layer ini menyediakan layanan jaringan kepada aplikasi dan menangani komunikasi antar proses.

🎯 Tanggung Jawab Utama

  • • Menyediakan interface untuk aplikasi
  • • Menangani format dan representasi data
  • • Mengatur sesi komunikasi
  • • Menyediakan layanan keamanan
  • • Mengelola autentikasi pengguna

🔧 Karakteristik

  • • Bekerja dengan data aplikasi
  • • Tidak peduli dengan routing
  • • Fokus pada layanan end-user
  • • Menggunakan protokol standar
  • • Platform independent

Layer Transport

Mengatur pengiriman data end-to-end

Fungsi Layer Transport

Layer Transport bertanggung jawab untuk pengiriman data yang reliable dan efisien antara aplikasi di host yang berbeda. Layer ini menyediakan layanan komunikasi end-to-end.

🎯 Layanan Utama

  • • Segmentasi dan reassembly data
  • • Error detection dan correction
  • • Flow control (pengaturan aliran)
  • • Congestion control (kontrol kemacetan)
  • • Multiplexing/demultiplexing

🔧 Mekanisme

  • • Port numbers untuk addressing
  • • Sequence numbers untuk ordering
  • • Acknowledgments untuk konfirmasi
  • • Timers untuk retransmission
  • • Window size untuk flow control

TCP vs UDP

🤝

TCP (Reliable)

  • ✅ Connection-oriented: 3-way handshake
  • ✅ Reliable: Guaranteed delivery
  • ✅ Error checking: Checksum validation
  • ✅ Flow control: Window-based
  • ✅ Congestion control: Adaptive
  • ❌ Overhead: Header 20+ bytes
Cocok untuk:

HTTP, FTP, SMTP, SSH, Telnet

⚡

UDP (Fast)

  • ❌ Connectionless: No handshake
  • ❌ Unreliable: Best effort delivery
  • ❌ No error recovery: Fire and forget
  • ❌ No flow control: Send at will
  • ❌ No congestion control: No adaptation
  • ✅ Low overhead: Header 8 bytes
Cocok untuk:

DNS, DHCP, Gaming, Streaming, SNMP

Layer Internet

Routing dan pengalamatan global

Fungsi Layer Internet

Layer Internet bertanggung jawab untuk routing paket data melalui jaringan yang berbeda. Layer ini menentukan jalur terbaik untuk mengirim data dari sumber ke tujuan melalui internetwork.

🎯 Tanggung Jawab Utama

  • • Logical addressing (IP addressing)
  • • Routing paket antar network
  • • Path determination
  • • Packet forwarding
  • • Fragmentasi dan reassembly

🔧 Protokol Utama

  • • IP: Internet Protocol
  • • ICMP: Internet Control Message Protocol
  • • ARP: Address Resolution Protocol
  • • RARP: Reverse ARP
  • • IGMP: Internet Group Management Protocol

Layer Network Access

Physical dan Data Link Layer

Fungsi Layer Network Access

Layer Network Access menggabungkan Physical Layer dan Data Link Layer dari model OSI. Layer ini bertanggung jawab untuk transmisi data dalam jaringan lokal dan konversi data menjadi sinyal fisik.

🎯 Physical Layer (Layer 1)

  • • Transmisi bit melalui media fisik
  • • Konversi data ke sinyal elektrik/optik
  • • Spesifikasi kabel dan konektor
  • • Timing dan sinkronisasi
  • • Voltage levels dan encoding

🔧 Data Link Layer (Layer 2)

  • • Frame formatting dan addressing
  • • Error detection dan correction
  • • Flow control dalam LAN
  • • MAC (Media Access Control)
  • • Switching dan bridging

Switching vs Routing

🔄 Layer 2 Switching

  • • Bekerja dengan MAC address
  • • Forwarding dalam LAN segment
  • • MAC address table learning
  • • Collision domain separation
  • • VLAN support

Contoh: Switch Ethernet, Bridge

🌐 Layer 3 Routing

  • • Bekerja dengan IP address
  • • Forwarding antar network
  • • Routing table lookup
  • • Broadcast domain separation
  • • Inter-VLAN routing

Contoh: Router, Layer 3 Switch

Private vs Public IP

🔒 Private IP Address

Digunakan dalam jaringan lokal (LAN)

  • • Class A: 10.0.0.0 - 10.255.255.255
  • • Class B: 172.16.0.0 - 172.31.255.255
  • • Class C: 192.168.0.0 - 192.168.255.255

Tidak dapat diakses langsung dari internet

🌐 Public IP Address

Digunakan untuk komunikasi internet

  • • Unik secara global
  • • Dapat diakses dari internet
  • • Dikelola oleh ISP
  • • Terbatas jumlahnya

Contoh: 8.8.8.8 (Google DNS)

Subnetting Dasar

🔢 Contoh Subnetting

Network: 192.168.1.0/24

Subnet Mask: 255.255.255.0

Network Information
  • • Network Address: 192.168.1.0
  • • Broadcast Address: 192.168.1.255
  • • First Host: 192.168.1.1
  • • Last Host: 192.168.1.254
  • • Total Hosts: 254
Subnet Calculation
  • • Network Bits: 24
  • • Host Bits: 8
  • • Possible Hosts: 2^8 - 2 = 254
  • • Subnet Mask: /24
