Pengenalan Pemrograman

🤖 Apa itu Pemrograman?

Pemrograman adalah proses memberikan instruksi kepada komputer untuk menyelesaikan suatu masalah atau tugas tertentu. Bayangkan kalian sedang mengajari robot untuk melakukan sesuatu!

Analogi Sederhana:

Seperti memberikan resep masakan kepada teman. Kalian harus menjelaskan langkah demi langkah dengan jelas agar hasilnya sesuai harapan!

📜 Sejarah Singkat Pemrograman Terstruktur

🕰️

1960an

Era "Spaghetti Code" - kode tidak terstruktur

💡

🚀

1970an+

Menjadi standar industri programming

Mengapa Perlu Struktur?

❌ Era Spaghetti Code (Dulu)

  • • Kode melompat-lompat (GOTO statements)
  • • Sulit di-debug dan dipelihara
  • • Proyek sering gagal
  • • Tim kesulitan kolaborasi
  • • Biaya maintenance tinggi

✅ Structured Programming (Sekarang)

  • • Alur program jelas dan logis
  • • Mudah dipahami dan dipelihara
  • • Tingkat kesuksesan proyek tinggi
  • • Kolaborasi tim efektif
  • • Biaya development rendah

Definisi Pemrograman Terstruktur

📝 Definisi Formal

Pemrograman terstruktur adalah paradigma pemrograman yang menggunakan struktur kontrol yang jelas dan terorganisir untuk membuat program yang mudah dibaca, dipahami, dan dipelihara.

🏗️ Karakteristik Utama

📋

Urutan (Sequence)

Instruksi dijalankan satu per satu secara berurutan

🔄

Perulangan (Loop)

Mengulang instruksi tertentu sesuai kondisi

🤔

Percabangan (Selection)

Memilih instruksi berdasarkan kondisi tertentu

📦

Modularitas

Program dibagi menjadi bagian-bagian kecil

🎯 Tujuan & Landasan Teoritis

📐Teorema Böhm-Jacopini (1966)

Membuktikan bahwa setiap program dapat ditulis menggunakan hanya tiga struktur kontrol dasar tanpa GOTO:

Sequence
Urutan Linear
Selection
IF-THEN-ELSE
Iteration
WHILE Loop
👁️

Readability

Kode mudah dibaca dan dipahami

🔧

Maintainability

Mudah diperbaiki dan diperbarui

♻️

Reusability

Kode dapat digunakan kembali

🏢 Studi Kasus: Aplikasi Dunia Nyata

🏪Sistem Kasir Minimarket

Sequence: Scan barcode → Hitung total → Terima pembayaran

Selection: Jika member, beri diskon 10%

Loop: Ulangi scan sampai selesai

Function: Modul cetak struk, hitung pajak

🎮Game Sederhana

Sequence: Inisialisasi → Tampilkan menu → Mulai game

Selection: Jika score > high score, simpan

Loop: Game loop utama sampai game over

Function: Modul input, render, collision

💡 Contoh Algoritma: Menghitung Nilai Rata-rata Kelas

Pseudocode Terstruktur:
MULAI
  total = 0
  jumlah_siswa = 0
  TULIS "Masukkan jumlah siswa:"
  BACA jumlah_siswa
  
  UNTUK i = 1 SAMPAI jumlah_siswa
    TULIS "Nilai siswa ke-", i, ":"
    BACA nilai
    total = total + nilai
  SELESAI UNTUK
  
  rata_rata = total / jumlah_siswa
  TULIS "Rata-rata kelas:", rata_rata
SELESAI
Analisis Struktur:
Sequence: Inisialisasi variabel, input jumlah siswa
Loop: Mengulang input nilai sesuai jumlah siswa
Process: Menghitung total dan rata-rata
Output: Menampilkan hasil rata-rata
⚡

Prinsip Dasar Pemrograman Terstruktur

1️⃣ Prinsip Top-Down Design

Memecah masalah besar menjadi bagian-bagian kecil yang lebih mudah diselesaikan.

Contoh: Membuat Program Kasir

  • • Input data barang
  • • Hitung total harga
  • • Hitung diskon (jika ada)
  • • Tampilkan struk

2️⃣ Prinsip Single Entry Single Exit

✅Benar

Setiap blok program memiliki satu pintu masuk dan satu pintu keluar

❌Salah

Program melompat-lompat tanpa aturan yang jelas

3️⃣ Prinsip Modularitas

Program dibagi menjadi modul-modul kecil yang memiliki fungsi spesifik.

📥

Input Module

Menangani input data

⚙️

Process Module

Memproses data

📤

Output Module

Menampilkan hasil

4️⃣ Prinsip Clarity (Kejelasan) & Best Practices

Penamaan yang Bermakna

❌ Buruk:
a, b, c, x1, temp, data
✅ Baik:
nama_siswa, total_nilai, rata_rata_kelas

Komentar yang Efektif

// Menghitung rata-rata nilai kelas
// Input: array nilai siswa
// Output: nilai rata-rata (float)
rata = total / jumlah_siswa;

📋 Checklist Best Practices

Code Quality:
✓ Gunakan indentasi konsisten
✓ Satu fungsi, satu tugas
✓ Hindari nested loop berlebihan
✓ Validasi input pengguna
Documentation:
✓ Dokumentasi fungsi utama
✓ Jelaskan algoritma kompleks
✓ Contoh penggunaan
✓ Update dokumentasi rutin

Struktur Program Terstruktur

📋 1. Struktur Urutan (Sequence)

Instruksi dijalankan satu per satu dari atas ke bawah.

// Contoh struktur urutan
mulai
  tulis "Masukkan nama: "
  baca nama
  tulis "Halo " + nama
selesai

🤔 2. Struktur Percabangan (Selection)

IF-THEN-ELSE

jika nilai >= 75 maka
  tulis "Lulus"
selain itu
  tulis "Tidak Lulus"
selesai jika

SWITCH-CASE

pilih hari
  kasus 1: "Senin"
  kasus 2: "Selasa"
  default: "Hari lain"
selesai pilih

🔄 3. Struktur Perulangan (Loop)

FOR Loop

untuk i = 1 sampai 10
  tulis i
selesai untuk

WHILE Loop

selama i <= 10
  tulis i
  i = i + 1
selesai selama

DO-WHILE

lakukan
  tulis i
  i = i + 1
selama i <= 10

📦 4. Struktur Modular (Functions/Procedures)

Function (Mengembalikan Nilai)

fungsi hitungLuas(panjang, lebar)
  luas = panjang * lebar
  kembalikan luas
selesai fungsi

Procedure (Tidak Mengembalikan)

prosedur tampilkanPesan(pesan)
  tulis "Pesan: " + pesan
selesai prosedur

Tugas Pemahaman

📋 Petunjuk Pengerjaan

  • ✏️Jawab semua pertanyaan dengan lengkap dan jelas
  • 💭Gunakan bahasa sendiri, jangan copy-paste
  • 📖Berikan contoh jika diminta
  • 🎯Fokus pada pemahaman konsep, bukan hafalan

1 Soal Definisi

Jelaskan dengan kata-kata sendiri apa yang dimaksud dengan pemrograman terstruktur! Berikan minimal 3 karakteristik utamanya.

2 Soal Prinsip

Sebutkan dan jelaskan 4 prinsip dasar pemrograman terstruktur yang telah dipelajari! Berikan contoh penerapan masing-masing prinsip.

3 Soal Struktur

Bandingkan ketiga struktur kontrol (sequence, selection, loop)! Kapan masing-masing struktur digunakan? Berikan contoh kasus nyata untuk setiap struktur.

4 Soal Analisis

Mengapa pemrograman terstruktur penting dalam pengembangan software? Apa yang terjadi jika kita tidak menggunakan prinsip-prinsip pemrograman terstruktur?

5 Soal Penerapan

Buatlah pseudocode (algoritma dalam bahasa manusia) untuk program menghitung luas dan keliling persegi panjang! Terapkan prinsip-prinsip pemrograman terstruktur yang telah dipelajari.

💡 Tips Pengerjaan

Do's ✅

  • • Baca soal dengan teliti
  • • Gunakan contoh konkret
  • • Jelaskan dengan bahasa sendiri
  • • Hubungkan dengan materi yang dipelajari

Don'ts ❌

  • • Jangan copy-paste dari internet
  • • Jangan jawab asal-asalan
  • • Jangan lupa berikan contoh
  • • Jangan terburu-buru
