Apa itu List? 🤔

Definisi List

List adalah struktur data di Python yang bisa menyimpan banyak item dalam satu variabel. Bayangkan seperti tas sekolah yang bisa diisi berbagai macam barang! 🎒

💡 Analogi Sederhana:

List seperti rak buku di perpustakaan. Setiap buku memiliki posisi (index) yang tetap, kamu bisa menambah buku baru, mengganti buku lama, atau mengambil buku tertentu kapan saja!

🏠 Analogi Rumah:

List seperti lemari dengan banyak laci. Setiap laci bernomor (index) dan bisa diisi barang apapun. Kamu bisa buka laci nomor 0, 1, 2, dst untuk mengambil atau menaruh barang!

Sejarah Singkat

List adalah salah satu tipe data fundamental yang ada sejak Python pertama kali dibuat oleh Guido van Rossum pada tahun 1991. Konsep ini terinspirasi dari array dalam bahasa pemrograman lain, namun dibuat lebih fleksibel dan mudah digunakan.

Karakteristik List

  • • Ordered: Urutan data tetap terjaga
  • • Mutable: Bisa diubah setelah dibuat
  • • Allow Duplicates: Boleh ada data yang sama
  • • Mixed Types: Bisa campuran tipe data
  • • Indexed: Setiap item punya nomor posisi

Kegunaan List dalam Kehidupan

  • 📚 Daftar mata pelajaran sekolah
  • 🛒 Daftar belanja bulanan
  • 🎵 Playlist lagu favorit
  • 👥 Kontak teman-teman
  • 📊 Data nilai ujian
  • 🎮 High score dalam game

Slicing (Memotong List)

slicing_dasar.py
1angka = [1, 2, 3, 4, 5]
2
3# Mengambil beberapa item
4print(angka[1:4]) # [2, 3, 4]
5print(angka[:3]) # [1, 2, 3]
6print(angka[2:]) # [3, 4, 5]
slicing_lanjut.py
1# Slicing dengan step
2print(angka[::2]) # [1, 3, 5]
3print(angka[1::2]) # [2, 4]
4
5# Membalik list
6print(angka[::-1]) # [5, 4, 3, 2, 1]
7print(angka[-3:]) # [3, 4, 5]
Penjelasan Slicing

Format: list[start:stop:step]

  • • start: index awal (default: 0)
  • • stop: index akhir (tidak termasuk)
  • • step: langkah (default: 1)

💡 Index negatif dimulai dari akhir: -1 = item terakhir

Contoh Khusus:

  • • [::] - seluruh list
  • • [::-1] - balik list
  • • [::2] - ambil setiap 2 item
  • • [-3:] - 3 item terakhir
  • • [1:-1] - tanpa item pertama & terakhir

Memodifikasi List ✏️

Mengubah Item

mengubah_item.py
1buah = ["apel", "pisang", "jeruk"]
2# Mengubah item index 1
3buah[1] = "mangga"
4print(buah) # Output: ["apel", "mangga", "jeruk"]

Menambah Item

menambah_item.py
1buah = ["apel", "pisang", "jeruk"]
2
3# 1. append() - Menambah di akhir
4buah.append("durian")
5print(buah) # ["apel", "pisang", "jeruk", "durian"]
6
7# 2. insert() - Menambah di posisi tertentu
8buah.insert(1, "semangka")
9print(buah) # ["apel", "semangka", "pisang", "jeruk", "durian"]
10
11# 3. extend() - Menambah beberapa item sekaligus
12buah.extend(["nanas", "kelapa"])
13print(buah) # ["apel", "semangka", "pisang", "jeruk", "durian", "nanas", "kelapa"]
Penjelasan Method Menambah
append(item)

Menambahkan satu item di akhir list. Paling sering digunakan!

💡 Seperti menambah barang di ujung antrian

insert(index, item)

Menambahkan item di posisi tertentu. Item lain akan bergeser.

💡 Seperti menyerobot antrian di posisi tertentu

extend(list)

Menambahkan semua item dari list lain ke akhir list.

💡 Seperti menggabungkan dua antrian

Menghapus Item

menghapus_item.py
1buah = ["apel", "pisang", "jeruk", "mangga"]
2
3# 1. remove() - Hapus berdasarkan nilai
4buah.remove("apel")
5print(buah) # ["pisang", "jeruk", "mangga"]
6
7# 2. del - Hapus berdasarkan index
8del buah[0] # Hapus item pertama
9print(buah) # ["jeruk", "mangga"]
10
11# 3. pop() - Hapus dan ambil item
12item_terakhir = buah.pop() # Hapus item terakhir
13print(item_terakhir) # "mangga"
14print(buah) # ["jeruk"]
15
16# 4. pop(index) - Hapus item di posisi tertentu
17buah2 = ["a", "b", "c", "d"]
18item_tengah = buah2.pop(1) # Hapus index 1
19print(item_tengah) # "b"
20print(buah2) # ["a", "c", "d"]
Penjelasan Method Menghapus
remove(item)

Menghapus item pertama yang ditemukan berdasarkan nilai.

⚠️ Error jika item tidak ada!

del list[index]

Menghapus item berdasarkan posisi index.

⚠️ Error jika index tidak valid!

pop(index)

Menghapus dan mengembalikan item. Tanpa index = item terakhir.

💡 Berguna untuk mengambil dan hapus sekaligus!

🚨 Tips Penting:
  • • Selalu cek apakah item ada sebelum menggunakan remove()
  • • Gunakan try-except untuk menangani error
  • • pop() lebih aman karena mengembalikan nilai
  • • Index negatif juga bisa digunakan: pop(-1) = item terakhir

Method List yang Berguna 🛠️

Mengurutkan List

sorting_lengkap.py
1# Contoh sorting dengan angka
2angka = [64, 34, 25, 12, 22, 11, 90]
3print("Sebelum diurutkan:", angka)
4
5# 1. Urutkan ascending (kecil ke besar)
6angka.sort()
7print("Ascending:", angka) # [11, 12, 22, 25, 34, 64, 90]
8
9# 2. Urutkan descending (besar ke kecil)
10angka.sort(reverse=True)
11print("Descending:", angka) # [90, 64, 34, 25, 22, 12, 11]
12
13# 3. Sorting dengan string
14nama = ["Zara", "Andi", "Budi", "Citra"]
15nama.sort()
16print("Nama terurut:", nama) # ['Andi', 'Budi', 'Citra', 'Zara']
17
18# 4. Sorting tanpa mengubah list asli (sorted)
19nilai = [85, 92, 78, 96]
20nilai_terurut = sorted(nilai)
21print("Asli:", nilai) # [85, 92, 78, 96]
22print("Terurut:", nilai_terurut) # [78, 85, 92, 96]
Perbedaan sort() vs sorted()
list.sort()
  • • Mengubah list asli
  • • Tidak mengembalikan nilai
  • • Lebih efisien memori
  • • Method dari list

💡 Gunakan jika ingin mengubah list asli

sorted(list)
  • • List asli tidak berubah
  • • Mengembalikan list baru
  • • Butuh memori tambahan
  • • Built-in function

Mencari dalam List

searching_lengkap.py
1# Data untuk contoh pencarian
2buah = ["apel", "pisang", "jeruk", "apel", "mangga"]
3angka = [10, 20, 30, 20, 40]
4
5# 1. Mencari index item pertama yang ditemukan
6pos_pisang = buah.index("pisang")
7print(f"Pisang ada di index: {pos_pisang}") # Index: 1
8
9# 2. Mencari dengan range tertentu
10pos_apel = buah.index("apel", 1) # Cari mulai dari index 1
11print(f"Apel kedua ada di index: {pos_apel}") # Index: 3
12
13# 3. Menghitung kemunculan item
14jumlah_apel = buah.count("apel")
15print(f"Jumlah apel: {jumlah_apel}") # Jumlah: 2
16
17# 4. Mengecek keberadaan item (in operator)
18if "mangga" in buah:
19 print("Mangga tersedia!")
20else:
21 print("Mangga tidak ada")
22
23# 5. Pencarian aman dengan try-except
24try:
25 pos = buah.index("durian")
26 print(f"Durian ada di index: {pos}")
27except ValueError:
28 print("Durian tidak ditemukan dalam list")
Method Pencarian dalam List
index(item)

Mencari posisi item pertama yang ditemukan

  • • Mengembalikan index
  • • Error jika tidak ada
  • • Hanya item pertama
count(item)

Menghitung berapa kali item muncul

  • • Mengembalikan angka
  • • 0 jika tidak ada
  • • Hitung semua kemunculan
item in list

Mengecek apakah item ada dalam list

  • • Mengembalikan True/False
  • • Tidak ada error
  • • Paling aman digunakan
💡 Tips Pencarian:
  • • Gunakan in untuk cek keberadaan sebelum index()
  • • try-except untuk menangani item yang tidak ada
  • • count() berguna untuk data duplikat
  • • Pencarian case-sensitive untuk string

Method Lainnya

method_lainnya_lengkap.py
1# Data untuk demonstrasi
2angka = [10, 20, 30, 40, 50]
3buah = ["apel", "pisang", "jeruk"]
4nama = ["Andi", "Budi", "Citra"]
5
6# 1. REVERSE - Membalik urutan list
7print("Sebelum reverse:", buah) # ['apel', 'pisang', 'jeruk']
8buah.reverse()
9print("Setelah reverse:", buah) # ['jeruk', 'pisang', 'apel']
10
11# 2. LEN - Menghitung panjang list
12panjang_angka = len(angka)
13print(f"Panjang list angka: {panjang_angka}") # 5
14
15# 3. CLEAR - Mengosongkan list
16temp_list = [1, 2, 3]
17print("Sebelum clear:", temp_list) # [1, 2, 3]
18temp_list.clear()
19print("Setelah clear:", temp_list) # []
20
21# 4. COPY - Menyalin list (shallow copy)
22salinan_nama = nama.copy()
23salinan_nama.append("Dina")
24print("List asli:", nama) # ['Andi', 'Budi', 'Citra']
25print("List salinan:", salinan_nama) # ['Andi', 'Budi', 'Citra', 'Dina']
26
27# 5. MIN, MAX, SUM - Operasi matematika
28nilai_min = min(angka)
29nilai_max = max(angka)
30total = sum(angka)
31rata_rata = total / len(angka)
32print(f"Nilai terkecil: {nilai_min}") # 10
33print(f"Nilai terbesar: {nilai_max}") # 50
34print(f"Total: {total}") # 150
35print(f"Rata-rata: {rata_rata}") # 30.0
36
37# 6. OPERASI LIST - Menggabung dan mengulang
38list1 = [1, 2]
39list2 = [3, 4]
40gabungan = list1 + list2 # [1, 2, 3, 4]
41ulang = ["Ha"] * 3 # ['Ha', 'Ha', 'Ha']
42print("Gabungan:", gabungan)
43print("Ulang:", ulang)
44
45# 7. MEMBERSHIP TESTING - Cek keberadaan
46ada_apel = "apel" in buah
47tidak_ada_durian = "durian" not in buah
48print(f"Apel ada? {ada_apel}") # True
49print(f"Durian tidak ada? {tidak_ada_durian}") # True

Membuat salinan shallow dari list

📊 Fungsi Analisis:

Menghitung jumlah item dalam list

Ringkasan Lengkap Method List
✏️ Method Modifikasi:
  • • append(item) - tambah di akhir
  • • insert(index, item) - tambah di posisi
  • • extend(list) - tambah banyak item
  • • remove(item) - hapus berdasarkan nilai
  • • pop(index) - hapus dan ambil item
  • • clear() - kosongkan list
  • • reverse() - balik urutan
  • • sort() - urutkan list
🔍 Method Pencarian:
  • • index(item) - cari posisi item
  • • count(item) - hitung kemunculan
  • • item in list - cek keberadaan
  • • item not in list - cek ketidakberadaan
📋 Method Utilitas:
  • • copy() - salin list
  • • len(list) - panjang list
🧮 Fungsi Matematika:
  • • min(list) - nilai terkecil
  • • max(list) - nilai terbesar
  • • sum(list) - jumlah total
  • • sorted(list) - urutkan tanpa ubah asli
🔗 Operasi List:
  • • list1 + list2 - gabung list
  • • list * n - ulang list n kali
  • • list[start:end] - slicing
🎯 Tips Penggunaan Method:
  • • Method yang mengubah list: append, insert, remove, pop, clear, reverse, sort
  • • Method yang tidak mengubah list: index, count, copy
  • • Fungsi built-in: len, min, max, sum, sorted
  • • Operator: in, not in, +, *, []
  • • Gunakan help(list) di Python untuk melihat semua method
