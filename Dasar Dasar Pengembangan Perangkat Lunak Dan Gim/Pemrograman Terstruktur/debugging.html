📚 Pengenalan Debugging

🔍 Apa itu Debugging?

Debugging adalah proses mencari, mengidentifikasi, dan memperbaiki kesalahan (bug) dalam program. Istilah "bug" pertama kali digunakan oleh Grace Hopper ketika menemukan kupu-kupu yang menyebabkan komputer error! 🦋

📖 Sejarah Debugging

1947: Grace Hopper menemukan kupu-kupu di komputer Harvard Mark II

1950an: Istilah "debugging" mulai populer di kalangan programmer

Sekarang: Debugging menjadi skill fundamental setiap programmer

🐛 ➡️ 🔍 ➡️ 🔧 ➡️ ✅

Bug → Deteksi → Analisis → Perbaikan → Solved!

⚠️ Jenis-Jenis Error dalam Python

🔤 1. Syntax Error (Error Sintaks)

Error yang terjadi karena penulisan kode tidak sesuai aturan Python. Seperti salah ketik atau lupa tanda kurung.

❌ Contoh Syntax Error

# Lupa titik dua
if x > 5  ← Error!
    print("Besar")

# Lupa kurung tutup
print("Hello"  ← Error!

# Indentasi salah
if x > 5:
print("Besar")  ← Error!

✅ Perbaikan

# Tambah titik dua
if x > 5:
    print("Besar")

# Tambah kurung tutup
print("Hello")

# Indentasi benar
if x > 5:
    print("Besar")

⚡ 2. Runtime Error (Error Saat Berjalan)

Error yang terjadi saat program berjalan. Sintaks benar, tapi ada masalah dalam eksekusi.

🔢 ZeroDivisionError

# Pembagian dengan nol
hasil = 10 / 0  ← Error!

# Contoh dalam fungsi
def bagi(a, b):
    return a / b  ← Berbahaya!

print(bagi(10, 0))
ZeroDivisionError: division by zero

Solusi:
if b != 0:
    return a / b
else:
    return "Error: Tidak bisa bagi nol"

📝 NameError

# Variabel tidak didefinisikan
print(nama)  ← Error!

# Typo dalam nama variabel
username = "admin"
print(usernme)  ← Typo!

# Variabel di luar scope
def fungsi():
    x = 10
print(x)  ← x tidak ada di sini!
NameError: name 'nama' is not defined

Penyebab Umum:
• Lupa mendefinisikan variabel
• Typo dalam nama variabel
• Masalah scope variabel
• Case sensitivity (Nama ≠ nama)

🔤 TypeError

# Operasi tipe data salah
hasil = "5" + 3  ← Error!

# Fungsi dengan argumen salah
len(123)  ← int tidak punya len!

# Indexing tipe data salah
angka = 123
print(angka[0])  ← int tidak bisa diindex!
TypeError: can only concatenate str to str

Solusi:
• Konversi tipe: str(3) atau int("5")
• Cek tipe: isinstance(x, int)
• Gunakan f-string: f"Nilai: {angka}"

📋 IndexError & KeyError

# IndexError - list
data = [1, 2, 3]
print(data[5])  ← Index tidak ada!

# KeyError - dictionary
siswa = {"nama": "Ali"}
print(siswa["umur"])  ← Key tidak ada!

# AttributeError
teks = "hello"
teks.append("world")  ← str tidak punya append!
IndexError: list index out of range KeyError: 'umur' AttributeError: 'str' has no attribute 'append'

Pencegahan:
• Cek panjang: if i < len(data)
• Gunakan get(): dict.get("key", default)
• Cek attribute: hasattr(obj, "method")

🧠 3. Logic Error (Error Logika)

Program berjalan tanpa error, tapi hasilnya salah karena logika yang keliru.

🎯 Contoh Logic Error

❌ Logika Salah:

# Menghitung rata-rata
nilai1 = 80
nilai2 = 90
nilai3 = 70
rata_rata = (nilai1 + nilai2 + nilai3) / 2  ← Salah!
print(rata_rata)  # Output: 120

✅ Logika Benar:

# Menghitung rata-rata
nilai1 = 80
nilai2 = 90
nilai3 = 70
rata_rata = (nilai1 + nilai2 + nilai3) / 3  ← Benar!
print(rata_rata)  # Output: 80.0

🔧 Teknik Debugging Sederhana

👀 1. Read Error Messages (Baca Pesan Error)

Pesan error Python sangat informatif! Jangan panik, baca dengan teliti untuk memahami masalahnya.

🔍 Cara Membaca Error Message

  File "program.py", line 3, in <module>
    print(nama)
NameError: name 'nama' is not defined

📍 Informasi Lokasi:

  • • File: program.py
  • • Baris: 3
  • • Kode: print(nama)

⚠️ Jenis & Penjelasan:

  • • Jenis: NameError
  • • Masalah: variabel 'nama' tidak didefinisikan

🖨️ 2. Print Debugging

Teknik paling sederhana: tambahkan print() untuk melihat nilai variabel dan alur program.

❌ Kode Bermasalah

# Program hitung faktorial
def faktorial(n):
    hasil = 1
    for i in range(1, n):
        hasil *= i
    return hasil

print(faktorial(5))  # Output: 24 (salah!)

🔍 Dengan Print Debug

# Program hitung faktorial + debug
def faktorial(n):
    print(f"Input n: {n}")  # Debug
    hasil = 1
    for i in range(1, n):
        print(f"i: {i}, hasil: {hasil}")  # Debug
        hasil *= i
    return hasil

print(faktorial(5))
# Terlihat: range(1,5) = [1,2,3,4]
# Seharusnya: range(1,6) = [1,2,3,4,5]

🎯 4. Divide and Conquer

Bagi program menjadi bagian-bagian kecil dan test satu per satu untuk menemukan sumber masalah.

🔍 Step 1: Isolasi Fungsi

Test setiap fungsi secara terpisah dengan input yang diketahui

🔍 Step 2: Test Input/Output

Pastikan input dan output sesuai ekspektasi

🔍 Step 3: Cek Kondisi Edge Case

Test dengan nilai ekstrem: 0, negatif, string kosong, dll

🧪 Assert Debugging

Gunakan assert untuk memastikan kondisi tertentu:

def hitung_rata_rata(nilai_list):
    assert len(nilai_list) > 0, "List tidak boleh kosong!"
    assert all(isinstance(x, (int, float)) for x in nilai_list), "Semua nilai harus angka!"
    
    total = sum(nilai_list)
    rata = total / len(nilai_list)
    
    assert 0 <= rata <= 100, f"Rata-rata aneh: {rata}"
    return rata

🛡️ 6. Defensive Programming

Tulis kode yang "tahan banting" untuk mencegah bug sejak awal!

✅ Input Validation

def bagi_aman(a, b):
    # Validasi input
    if not isinstance(a, (int, float)):
        raise TypeError("a harus berupa angka")
    if not isinstance(b, (int, float)):
        raise TypeError("b harus berupa angka")
    if b == 0:
        raise ValueError("Tidak bisa membagi dengan nol")
    
    return a / b

🔒 Try-Except yang Baik

def baca_file_aman(nama_file):
    # Validasi input terlebih dahulu
    if not nama_file or not isinstance(nama_file, str):
        print("Nama file harus berupa string yang valid")
        return None
    
    try:
        with open(nama_file, 'r', encoding='utf-8') as file:
            konten = file.read()
        return konten
    except FileNotFoundError:
        print(f"File '{nama_file}' tidak ditemukan")
        return None
    except PermissionError:
        print(f"Tidak ada izin membaca '{nama_file}'")
        return None
    except UnicodeDecodeError:
        print(f"File '{nama_file}' tidak bisa dibaca (encoding error)")
        return None
    except Exception as e:
        print(f"Error tidak terduga: {e}")
        return None

✅ Kalkulator yang Sudah Diperbaiki 

def kalkulator_fixed():
    print("=== KALKULATOR SEDERHANA (FIXED) ===")
    
    try:
        # Konversi ke float untuk mendukung desimal
        angka1 = float(input("Masukkan angka pertama: "))
        operator = input("Masukkan operator (+, -, *, /): ").strip()
        angka2 = float(input("Masukkan angka kedua: "))
        
        # Validasi operator
        if operator not in ["+", "-", "*", "/"]:
            print(f"Error: Operator '{operator}' tidak valid!")
            return
        
        if operator == "+":
            hasil = angka1 + angka2
        elif operator == "-":
            hasil = angka1 - angka2
        elif operator == "*":
            hasil = angka1 * angka2
        elif operator == "/":
            if angka2 == 0:
                print("Error: Tidak bisa membagi dengan nol!")
                return
            hasil = angka1 / angka2
        
        # Format hasil untuk tampilan yang lebih baik
        if hasil == int(hasil):
            hasil = int(hasil)

🎮 Kasus 2: Debug Program Pencarian

🐛 Program Bermasalah:

def cari_nama(daftar_siswa, nama_dicari):
    for i in range(len(daftar_siswa)):
        if daftar_siswa[i] == nama_dicari:
            return i
    return -1

# Test
siswa = ["Ali", "Budi", "Citra", "Dina"]
print(cari_nama(siswa, "ali"))  # Output: -1 (tidak ditemukan)
print(cari_nama(siswa, "Ali "))  # Output: -1 (tidak ditemukan)

✅ Versi yang Diperbaiki:

def cari_nama_fixed(daftar_siswa, nama_dicari):
    # Validasi input
    if not daftar_siswa:
        print("Daftar siswa kosong!")
        return -1
    
    if not nama_dicari:
        print("Nama yang dicari tidak boleh kosong!")
        return -1
    
    # Normalisasi: lowercase dan strip whitespace
    nama_dicari = nama_dicari.lower().strip()
    
    for i, nama in enumerate(daftar_siswa):
        if nama.lower().strip() == nama_dicari:
            print(f"Ditemukan '{nama}' di posisi {i}")
            return i
    
    print(f"'{nama_dicari}' tidak ditemukan dalam daftar")
    return -1

# Test yang lebih robust
siswa = ["Ali", "Budi", "Citra", "Dina"]
print(cari_nama_fixed(siswa, "ali"))     # Sekarang ditemukan!
print(cari_nama_fixed(siswa, "Ali "))    # Sekarang ditemukan!
print(cari_nama_fixed(siswa, "Eko"))     # Tidak ditemukan

🧪 Kasus 3: Debug Program Sorting

🐛 Bubble Sort Bermasalah:

def bubble_sort_buggy(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i):  ← Bug: IndexError!
            if arr[j] > arr[j+1]:  ← j+1 bisa melebihi index!
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr

# Test
data = [64, 34, 25, 12, 22]
print(bubble_sort_buggy(data))  # IndexError!

Masalah: Ketika i=0, range(0, n-i) = range(0, 5), sehingga j bisa sampai 4. Ketika j=4, maka arr[j+1] = arr[5] yang tidak ada (IndexError)!

✅ Bubble Sort dengan Debug:

def bubble_sort_debug(arr, debug=False):
    if not arr:
        return []
    
    arr = arr.copy()  # Jangan ubah array asli
    n = len(arr)
    
    if debug:
        print(f"Array awal: {arr}")
    
    for i in range(n):
        swapped = False
        # Perbaikan: range(0, n-i-1) untuk menghindari IndexError
        for j in range(0, n-i-1):
            if debug:
                print(f"  Bandingkan arr[{j}]={arr[j]} dengan arr[{j+1}]={arr[j+1]}")
            
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
                swapped = True
                if debug:
                    print(f"    Tukar! Sekarang: {arr}")
        
        if debug:
            print(f"Iterasi {i+1}: {arr}")
        
        # Optimasi: jika tidak ada pertukaran, array sudah terurut
        if not swapped:
            if debug:
                print("Array sudah terurut, berhenti lebih awal!")
            break
    
    return arr

# Test dengan debug
data = [64, 34, 25, 12, 22]
hasil = bubble_sort_debug(data, debug=True)
print(f"Hasil akhir: {hasil}")
