Pengenalan Tipe Data Python 📚

Apa itu Tipe Data?

Tipe data adalah cara Python mengenali dan mengategorikan berbagai jenis informasi. Bayangkan seperti kotak-kotak penyimpanan yang berbeda untuk menyimpan barang yang berbeda pula! 📦

Analogi Sederhana

Seperti di kehidupan nyata, kita punya kotak untuk menyimpan sepatu, lemari untuk baju, dan kulkas untuk makanan. Begitu juga di Python! 👟👕🍎

Mengapa Penting?

Dengan tipe data yang tepat, program kita jadi lebih efisien, cepat, dan tidak mudah error. Seperti menggunakan alat yang tepat untuk pekerjaan yang tepat! 🔧

Integer - Bilangan Bulat 🔢

Apa itu Integer?

Integer adalah tipe data untuk menyimpan bilangan bulat (tanpa koma). Seperti menghitung jumlah apel, umur, atau skor game! 🍎👶🎮

42

Bilangan Positif

0

Nol

-15

Bilangan Negatif

Demo Interaktif Integer

# Contoh penggunaan Integer
umur = 17
jumlah_siswa = 30
suhu = -5
# Operasi matematika
hasil = umur + 3
print(hasil) # Output: 20

Coba Sendiri!

Tips & Trik Operasi Integer

Operasi Matematika

10 + 5 = 15 (penjumlahan)
10 - 3 = 7 (pengurangan)
4 * 6 = 24 (perkalian)
15 // 4 = 3 (pembagian bulat)
15 % 4 = 3 (sisa bagi)
2 ** 3 = 8 (pangkat)

Fungsi Berguna

abs(-5) = 5 (nilai mutlak)
max(3,7,1) = 7 (nilai terbesar)
min(3,7,1) = 1 (nilai terkecil)
pow(2,3) = 8 (pangkat)
divmod(17,5) = (3,2) (bagi & sisa)

Hal Penting yang Perlu Diingat

⚠️ Perbedaan dengan String

umur = 17 ← Integer (bisa dihitung)
umur = "17" ← String (tidak bisa dihitung)

💡 Tips Pembagian

15 / 4 = 3.75 (hasil Float)
15 // 4 = 3 (hasil Integer)

Contoh Program Nyata

Program Hitung Usia

# Program hitung usia
tahun_lahir = 2006
tahun_sekarang = 2024
usia = tahun_sekarang - tahun_lahir
print(f"Usia kamu: {usia} tahun")
# Output: Usia kamu: 18 tahun

Program Cek Genap/Ganjil

# Cek genap atau ganjil
angka = 15
sisa = angka % 2
if sisa == 0:
print("Genap")
else:
print("Ganjil")
# Output: Ganjil

String - Teks dan Karakter 📝

Apa itu String?

String adalah tipe data untuk menyimpan teks, kata, kalimat, atau karakter. Seperti nama, alamat, pesan, atau apapun yang bisa kita baca! 📖✍️💬

"Hello"

Kata Sederhana

"Budi Santoso"

Nama Lengkap

"123"

Angka sebagai Teks

Demo Interaktif String

# Contoh penggunaan String
nama = "Siti Nurhaliza"
kelas = "XII RPL 1"
pesan = "Selamat belajar Python!"
# Menggabungkan string
salam = "Halo, " + nama
print(salam) # Output: Halo, Siti Nurhaliza

Generator Salam Otomatis

Kapan Menggunakan String?

Menyimpan nama, alamat
Email dan nomor telepon
Pesan dan komentar
Kategori dan label
Deskripsi dan keterangan
Password dan kode

Operasi String yang Berguna

Menggabungkan String

Menggunakan + :

nama_depan = "Budi"
nama_belakang = "Santoso"
nama_lengkap = nama_depan + " " + nama_belakang
# Hasil: "Budi Santoso"

Menggunakan f-string:

nama = "Siti"
umur = 17
pesan = f"Halo {nama}, umur kamu {umur} tahun"
# Hasil: "Halo Siti, umur kamu 17 tahun"

Fungsi String Berguna

Mengubah Huruf:

  • .upper() → BESAR
  • .lower() → kecil
  • .title() → Judul
  • .capitalize() → Kapital

Informasi String:

  • len() → panjang
  • .count() → hitung karakter
  • .find() → cari posisi
  • .startswith() → cek awalan

Membersihkan:

  • .strip() → hapus spasi
  • .replace() → ganti teks
  • .split() → pisah jadi list
  • .join() → gabung dari list

Boolean - True atau False ✅❌

Apa itu Boolean?

Boolean adalah tipe data yang hanya punya 2 nilai: True (benar) atau False (salah). Seperti saklar lampu: nyala atau mati, ya atau tidak! 💡🔛🔚

✅
True

Benar, Ya, Nyala, Aktif

❌
False

Salah, Tidak, Mati, Nonaktif

Demo Interaktif Boolean

# Contoh penggunaan Boolean
sudah_lulus = True
masih_sekolah = False
umur = 17
# Perbandingan menghasilkan Boolean
dewasa = umur >= 18
print(dewasa) # Output: False

Cek Status Siswa

Kapan Menggunakan Boolean?

Status login (masuk/keluar)
Kelulusan (lulus/tidak lulus)
Visibilitas (tampil/sembunyi)
Status perangkat (on/off)
Persetujuan (setuju/tidak)
Izin akses (boleh/tidak boleh)
