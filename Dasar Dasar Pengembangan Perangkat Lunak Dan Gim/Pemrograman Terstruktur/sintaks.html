Apa itu Python?

Python adalah bahasa pemrograman tingkat tinggi yang dibuat oleh Guido van Rossum di Belanda. Pengembangan dimulai pada Desember 1989 dan versi pertama (0.9.0) dirilis pada Februari 1991. Python dirancang dengan filosofi "kode yang mudah dibaca" dan sintaks yang memungkinkan programmer mengekspresikan konsep dalam lebih sedikit baris kode.

🎭 Fun Fact:

Nama "Python" diambil dari acara komedi BBC "Monty Python's Flying Circus" yang disukai Guido van Rossum, bukan dari ular python! Guido ingin nama yang pendek, unik, dan sedikit misterius.

Aturan Penulisan Python

Sintaks dasar yang harus diikuti

📋

Aturan Dasar Python

Python memiliki beberapa aturan penting yang membedakannya dari bahasa pemrograman lain.

✅ Yang Harus Diingat:

  • 🔤 Python case sensitive (huruf besar/kecil berbeda)
  • 📏 Menggunakan indentasi (spasi) untuk blok kode
  • 🚫 Tidak perlu titik koma (;) di akhir baris
  • : Menggunakan tanda titik dua (:) untuk blok kode

⭐ Keunggulan Python:

  • ✨ Kode lebih bersih dan mudah dibaca
  • 🎯 Lebih sedikit simbol yang membingungkan
  • 🏗️ Struktur kode yang jelas
  • 🗣️ Mirip dengan bahasa Inggris
🔤

Case Sensitive

Python membedakan huruf besar dan kecil. Variabel nama berbeda dengan Nama.

nama = "Budi"
Nama = "Sari"
NAMA = "Andi"
# Ketiga variabel ini berbeda!
🚫

Tidak Perlu Titik Koma

Berbeda dengan bahasa lain, Python tidak memerlukan titik koma (;) di akhir setiap baris.

# Salah (tidak perlu titik koma)
print("Hello");
# Benar
print("Hello")

Print & Output

Menampilkan hasil ke layar

🖥️

Fungsi print()

Fungsi print() adalah fungsi paling dasar dalam Python yang digunakan untuk menampilkan output ke layar. Ini adalah cara kita "berbicara" dengan pengguna program.

💡 Kenapa penting?

  • • Menampilkan hasil perhitungan
  • • Memberikan informasi kepada user
  • • Debug dan testing program
# Contoh dasar print
print("Hello, World!")
print("Selamat datang di Python")
📝

Print Teks

Untuk menampilkan teks, gunakan tanda petik (") atau petik tunggal (').

print("Halo Dunia!")
print('Python itu mudah')
print("Saya belajar coding")
Output yang akan muncul:
Halo Dunia!
Python itu mudah
Saya belajar coding
🔢

Print Angka

Untuk menampilkan angka, tidak perlu tanda petik.

print(123)

print(2024)
Output yang akan muncul:
123
45.67
2024

Komentar dalam Python

Cara memberikan catatan dalam kode

📝

Apa itu Komentar?

Komentar adalah teks dalam kode yang tidak dijalankan oleh komputer. Komentar digunakan untuk memberikan penjelasan, catatan, atau dokumentasi tentang kode yang kita tulis.

🤔 Mengapa Komentar Penting?

  • 💭 Membantu kita mengingat fungsi kode
  • 👥 Memudahkan orang lain memahami kode kita
  • 📚 Dokumentasi untuk kode yang kompleks
  • 🔍 Membantu saat debugging (mencari error)
💬
📝
#️⃣

Komentar Satu Baris

Menggunakan tanda pagar (#) untuk membuat komentar satu baris.

# Ini adalah komentar
print("Hello World")
nama = "Budi" # Menyimpan nama
📄

Komentar Multi Baris

Menggunakan tiga tanda petik (""") untuk komentar yang panjang.

"""
Ini adalah komentar
yang panjang dan bisa
ditulis dalam beberapa baris
"""
print("Program dimulai")

Indentasi dalam Python

Aturan spasi yang sangat penting!

🎯

Apa itu Indentasi?

Indentasi adalah spasi atau tab di awal baris kode. Dalam Python, indentasi bukan hanya untuk membuat kode terlihat rapi, tetapi juga menentukan struktur dan alur program! Berbeda dengan bahasa pemrograman lain yang menggunakan kurung kurawal {}, Python menggunakan indentasi untuk mengelompokkan blok kode.

🔥 Mengapa Indentasi Penting?

  • 🏗️ Python menggunakan indentasi untuk mengelompokkan kode
  • 🔄 Menggantikan kurung kurawal {} seperti bahasa lain
  • ✨ Membuat kode lebih bersih dan mudah dibaca
  • 📐 Memaksa programmer menulis kode yang terstruktur
📏
🐍
✅

Indentasi yang Benar

Gunakan 4 spasi atau 1 tab untuk setiap level indentasi. Konsisten adalah kunci!

# Contoh indentasi yang benar
nama = "Budi"
if nama == "Budi":
print("Halo Budi!")
print("Selamat datang")
❌

Indentasi yang Salah

Indentasi yang tidak konsisten akan menyebabkan error!

# Contoh indentasi yang salah
nama = "Budi"
if nama == "Budi":
print("Halo Budi!") # Error!
print("Selamat datang") # Error!
📊

Level Indentasi

Semakin dalam struktur kode, semakin banyak indentasi yang diperlukan.

# Level 0 (tidak ada indentasi)
print("Program dimulai")
# Level 1 (4 spasi)
if True:
print("Level 1")
# Level 2 (8 spasi)
if True:
print("Level 2")

📐 Aturan Level Indentasi:

  • 0 Kode utama (0 spasi)
  • 1 Di dalam blok pertama (4 spasi)
  • 2 Di dalam blok kedua (8 spasi)
  • ... Dan seterusnya...
