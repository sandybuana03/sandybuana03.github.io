📚 Pengenalan Struktur Percabangan Python

🐍 Apa itu Struktur Percabangan di Python?

Struktur percabangan di Python adalah cara untuk membuat program yang bisa "berpikir" dan mengambil keputusan. Python menggunakan indentasi (spasi) untuk menentukan blok kode, bukan kurung kurawal seperti bahasa lain. Ini membuat kode Python lebih bersih dan mudah dibaca!

🤔 ➡️ 🐍 ➡️ ✅

Kondisi → Python Evaluasi → Keputusan

🌟 Mengapa Percabangan Penting?

✅ Dalam Kehidupan:

"Jika hujan, bawa payung"

💻 Dalam Python:

"if cuaca == 'hujan': bawa_payung()"

🎯 Operator Logika Python

and
Kedua kondisi harus benar
True and True → True
True and False → False
or
Salah satu kondisi benar
True or False → True
False or False → False
not
Membalik kondisi
not True → False
not False → True

🔍 If Statement Python

💡 Konsep If Statement

If statement di Python adalah yang paling sederhana. Seperti berkata: "JIKA kondisi ini benar, MAKA lakukan aksi ini." Ingat, Python sangat peduli dengan indentasi!

🌧️ ➡️ 🐍 ➡️ ☂️

Jika hujan → Python cek → Bawa payung

# Contoh sederhana if statement
cuaca = "hujan"

if cuaca == "hujan":
    print("Bawa payung! ☂️")

📝 Sintaks If Python 

if kondisi:
    # Aksi yang dilakukan jika kondisi benar
    print("Kondisi benar!")

⚠️ Penting!

Jangan lupa titik dua (:) dan indentasi 4 spasi!

🌡️ Cek Suhu

💡 Tips & Trik Python If Statement

✅ Yang Benar:
  • • Gunakan 4 spasi untuk indentasi
  • • Jangan lupa titik dua (:)
  • • Gunakan == untuk perbandingan
  • • Konsisten dengan indentasi
❌ Hindari:
  • • Menggunakan = untuk perbandingan
  • • Mencampur tab dan spasi
  • • Lupa indentasi pada blok kode
  • • Menulis kondisi yang terlalu kompleks

⚖️ If-Else Statement Python

🎭 Konsep If-Else Python

If-Else di Python memberikan dua pilihan: "JIKA kondisi benar, lakukan A. JIKA TIDAK (else), lakukan B." Seperti saklar lampu - nyala atau mati, tidak ada pilihan ketiga.

🌞 ➡️ 🐍 ➡️ 👕 / 🧥

Jika cerah → Python cek → Kaos / Jaket

# Contoh if-else Python
cuaca = "cerah"

if cuaca == "cerah":
    print("Pakai kaos! 👕")
else:
    print("Pakai jaket! 🧥")

📝 Sintaks If-Else Python 

if kondisi:
    # Jika kondisi benar
    print("Kondisi benar!")
else:
    # Jika kondisi salah
    print("Kondisi salah!")

💡 Tips!

Else tidak perlu kondisi, langsung diikuti titik dua (:)

🎯 If-Elif-Else Statement Python

🌈 Konsep If-Elif-Else Python

If-Elif-Else di Python seperti menu restoran dengan banyak pilihan. Python akan mengecek kondisi satu per satu dari atas ke bawah, dan memilih yang pertama kali cocok. "elif" adalah singkatan dari "else if".

🍕 🍔 🍜 🍰

Banyak pilihan, satu keputusan Python

📝 Sintaks If-Elif-Else Python 

if kondisi1:
    # Jika kondisi1 benar
    print("Kondisi 1 benar")
elif kondisi2:
    # Jika kondisi2 benar
    print("Kondisi 2 benar")
else:
    # Jika semua kondisi salah
    print("Semua kondisi salah")

🔥 Keunggulan!

Bisa punya banyak elif sesuai kebutuhan!

🏆 Studi Kasus: Sistem Penerimaan Mahasiswa

Contoh penggunaan elif yang lebih kompleks dalam kehidupan nyata:

# Sistem penerimaan mahasiswa berdasarkan nilai
nilai_matematika = 85
nilai_bahasa = 78
nilai_ipa = 82

if rata_rata >= 90:
    print("Diterima di Jurusan Kedokteran! 🏥")
elif rata_rata >= 85:
    print("Diterima di Jurusan Teknik! ⚙️")
elif rata_rata >= 80:
    print("Diterima di Jurusan Ekonomi! 💼")
elif rata_rata >= 75:
    print("Diterima di Jurusan Sastra! 📚")
else:
    print("Maaf, belum memenuhi syarat 😔")
🎯 Poin Penting:
  • • Python mengecek kondisi dari atas ke bawah
  • • Kondisi pertama yang benar akan dijalankan
  • • Kondisi setelahnya akan diabaikan
  • • Urutan kondisi sangat penting!

🏗️ Nested If Python

🎚️ Konsep Nested If Python

Nested If adalah if di dalam if. Seperti kotak di dalam kotak. Berguna ketika kita perlu mengecek kondisi tambahan setelah kondisi pertama terpenuhi. Di Python, indentasi menjadi sangat penting!

📦 ➡️ 📦 ➡️ 🎁

Kondisi dalam kondisi

📝 Sintaks Nested If Python 

if kondisi_luar:
    # Kode untuk kondisi luar
    print("Kondisi luar benar")
    
    if kondisi_dalam:
        # Kode untuk kondisi dalam
        print("Kondisi dalam juga benar")
    else:
        print("Kondisi dalam salah")
else:
    print("Kondisi luar salah")

⚠️ Penting tentang Indentasi Python!

  • • If luar: 4 spasi dari margin kiri
  • • If dalam: 8 spasi dari margin kiri (4 + 4)
  • • Semua baris dalam blok yang sama harus punya indentasi sama
  • • Jangan campur tab dan spasi - gunakan spasi saja

🎫 Demo: Sistem Tiket Bioskop

Cek apakah kamu bisa nonton film dan dapat diskon!

# Sistem tiket bioskop Python
umur = int(input("Umur: "))
status = input("Status (student/adult): ")

if umur >= 17:

else:

⚡ Nested If vs Operator Logika

✅ Pakai Nested If Jika:

  • • Kondisi kedua hanya dicek jika kondisi pertama benar
  • • Ada aksi berbeda untuk setiap level
  • • Logika bertingkat yang kompleks
  • • Ingin kode lebih terstruktur

🔗 Pakai Operator Logika Jika:

  • • Semua kondisi harus dicek bersamaan
  • • Kondisi sederhana (and, or, not)
  • • Ingin kode lebih ringkas
  • • Tidak ada aksi bertingkat

🎮 Contoh Perbandingan

🏗️ Nested If

if umur >= 18:
    if punya_sim:
        print("Boleh nyetir")
    else:
        print("Bikin SIM dulu")
else:
    print("Belum cukup umur")

🔗 Operator Logika

if umur >= 18 and punya_sim:
    print("Boleh nyetir")
else:
    print("Tidak boleh nyetir")
