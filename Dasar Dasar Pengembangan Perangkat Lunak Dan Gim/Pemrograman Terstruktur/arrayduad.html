📚 Pengenalan Array Multi Dimensi

Apa itu Array Multi Dimensi?

Array multi dimensi adalah array yang berisi array lain sebagai elemennya. Bayangkan seperti lemari dengan banyak laci, dan setiap laci memiliki kotak-kotak kecil di dalamnya.

🎯 Mengapa Array Multi Dimensi Penting?

✓

Organisasi Data Terstruktur

Menyimpan data dalam bentuk tabel yang mudah dipahami

✓

Efisiensi Memori

Menghemat ruang penyimpanan data

✓

Kemudahan Akses

Mengakses data dengan koordinat yang jelas

✓

Dasar Algoritma

Fondasi untuk algoritma yang lebih kompleks

🧠 Konsep Dasar Array 2D

Struktur Array 2D

Array 2D memiliki baris (row) dan kolom (column). Setiap elemen dapat diakses menggunakan indeks [baris][kolom].

📏 Dimensi

  • • Baris (Row): Horizontal
  • • Kolom (Column): Vertikal
  • • Indeks: Dimulai dari 0

🎯 Akses Elemen

  • • array[baris][kolom]
  • • array[0][0] = elemen pertama
  • • array[1][2] = baris 2, kolom 3

⚡ Membuat Array 2D di Python

Cara 1: List Bersarang (Nested List)

Cara paling sederhana adalah membuat list yang berisi list lain.

Python Code 
# Membuat array 2D sederhana
array_2d = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

print("Array 2D:")
for baris in array_2d:
    print(baris)

Output:

Array 2D:
[1, 2, 3]
[4, 5, 6]
[7, 8, 9]

Setiap baris dicetak sebagai list terpisah

Cara 2: Menggunakan List Comprehension

Cara yang lebih efisien untuk membuat array dengan pola tertentu.

Python Code 
# Membuat array 3x3 berisi angka 0
baris = 3
kolom = 3
array_kosong = [[0 for j in range(kolom)] for i in range(baris)]

# Membuat array dengan nilai berurutan
array_urut = [[i*kolom + j + 1 for j in range(kolom)] for i in range(baris)]

print("Array kosong:")
for baris in array_kosong:
    print(baris)

print("\nArray berurutan:")
for baris in array_urut:
    print(baris)

Cara 4: Membuat Array dari Input User

Membuat array berdasarkan input dari pengguna secara dinamis.

Python Code 
# Membuat array dari input user
def buat_array_dari_input():
    # Minta ukuran array dengan validasi
    while True:
        try:
            baris = int(input("Masukkan jumlah baris (1-10): "))
            kolom = int(input("Masukkan jumlah kolom (1-10): "))
            if 1 <= baris <= 10 and 1 <= kolom <= 10:
                break
            else:
                print("Ukuran harus antara 1-10!")
        except ValueError:
            print("Masukkan angka yang valid!")
    
    # Inisialisasi array kosong
    array_2d = []
    
    # Input nilai untuk setiap elemen
    for i in range(baris):
        baris_data = []
        print(f"Masukkan nilai untuk baris {i+1}:")
        for j in range(kolom):
            while True:
                try:
                    nilai = int(input(f"  Kolom {j+1}: "))
                    baris_data.append(nilai)
                    break
                except ValueError:
                    print("    Masukkan angka yang valid!")
        array_2d.append(baris_data)
    
    return array_2d

# Fungsi untuk menampilkan array dengan rapi
def tampilkan_array(array):
    print("\nArray yang dibuat:")
    for i, baris in enumerate(array):
        print(f"Baris {i+1}: {baris}")

Cara 5: Array dengan Pola Khusus

Membuat array dengan pola matematika atau logika tertentu.

Python Code 
# 1. Matrix Identitas (diagonal 1, lainnya 0)
def buat_matrix_identitas(ukuran):
    matrix = [[1 if i == j else 0 for j in range(ukuran)] for i in range(ukuran)]
    return matrix

# 2. Matrix dengan pola papan catur
def buat_papan_catur(ukuran):
    papan = [[1 if (i + j) % 2 == 0 else 0 for j in range(ukuran)] for i in range(ukuran)]
    return papan

# 3. Matrix dengan nilai acak dalam range
import random
def buat_matrix_acak(baris, kolom, min_val=1, max_val=100):
    matrix = [[random.randint(min_val, max_val) for j in range(kolom)] for i in range(baris)]
    return matrix

# 4. Matrix spiral (nilai berurutan dalam pola spiral)
def buat_matrix_spiral(n):
    matrix = [[0 for j in range(n)] for i in range(n)]
    
    top, bottom = 0, n - 1
    left, right = 0, n - 1
    nilai = 1
    
    while top <= bottom and left <= right:
        # Isi baris atas
        for j in range(left, right + 1):
            matrix[top][j] = nilai
            nilai += 1
        top += 1
        
        # Isi kolom kanan
        for i in range(top, bottom + 1):
            matrix[i][right] = nilai
            nilai += 1
        right -= 1
        
        # Isi baris bawah
        if top <= bottom:
            for j in range(right, left - 1, -1):
                matrix[bottom][j] = nilai
                nilai += 1
            bottom -= 1
        
        # Isi kolom kiri
        if left <= right:
            for i in range(bottom, top - 1, -1):
                matrix[i][left] = nilai
                nilai += 1
            left += 1
    
    return matrix

# Contoh penggunaan
identitas = buat_matrix_identitas(4)
catur = buat_papan_catur(6)
spiral = buat_matrix_spiral(4)

print("Matrix Identitas 4x4:")
for baris in identitas:
    print(baris)

🎯 Mengakses Elemen Array 2D

Akses Elemen Tunggal

Untuk mengakses satu elemen, gunakan indeks [baris][kolom].

Python Code 
# Array contoh
nilai_siswa = [
    [85, 90, 78],  # Andi: Math, IPA, Bahasa
    [92, 88, 85],  # Budi: Math, IPA, Bahasa
    [79, 95, 90]   # Cici: Math, IPA, Bahasa
]

# Mengakses elemen
print("Nilai Math Andi:", nilai_siswa[0][0])  # Output: 85
print("Nilai IPA Budi:", nilai_siswa[1][1])  # Output: 88
print("Nilai Bahasa Cici:", nilai_siswa[2][2])  # Output: 90

Akses Seluruh Baris atau Kolom

Python Code 
# Mengakses seluruh baris (semua nilai satu siswa)
print("Semua nilai Andi:", nilai_siswa[0])  # Output: [85, 90, 78]

# Mengakses kolom (nilai satu mata pelajaran semua siswa)
nilai_math = []
for i in range(len(nilai_siswa)):
    nilai_math.append(nilai_siswa[i][0])  # Kolom 0 = Math
print("Nilai Math semua siswa:", nilai_math)  # Output: [85, 92, 79]

# Cara lebih singkat dengan list comprehension
nilai_ipa = [baris[1] for baris in nilai_siswa]  # Kolom 1 = IPA
print("Nilai IPA semua siswa:", nilai_ipa)  # Output: [90, 88, 95]

# Mengakses nilai Bahasa (kolom 2)
nilai_bahasa = [baris[2] for baris in nilai_siswa]
print("Nilai Bahasa semua siswa:", nilai_bahasa)  # Output: [78, 85, 90]

🔧 Operasi pada Array 2D

1. Mengubah Nilai Elemen

Python Code 
# Array awal
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

# Mengubah elemen di baris 1, kolom 1 (nilai 5 menjadi 50)
matrix[1][1] = 50

print("Matrix setelah diubah:")
for baris in matrix:
    print(baris)

2. Menambah Baris atau Kolom

Python Code 
# Menambah baris baru
baris_baru = [10, 11, 12]
matrix.append(baris_baru)

# Menambah kolom baru (menambah elemen di setiap baris)
for i in range(len(matrix)):
    matrix[i].append(0)  # Menambah kolom dengan nilai 0

print("Matrix setelah ditambah baris dan kolom:")
for baris in matrix:
    print(baris)

3. Operasi Matematika

Python Code 
# Menghitung jumlah semua elemen
total = 0
for baris in matrix:
    for elemen in baris:
        total += elemen
print("Total semua elemen:", total)

# Mencari nilai maksimum
max_nilai = matrix[0][0]
for baris in matrix:
    for elemen in baris:
        if elemen > max_nilai:
            max_nilai = elemen
print("Nilai maksimum:", max_nilai)

# Menghitung rata-rata per baris
for i, baris in enumerate(matrix):
    rata_rata = sum(baris) / len(baris)
    print(f"Rata-rata baris {i+1}: {rata_rata:.2f}")
