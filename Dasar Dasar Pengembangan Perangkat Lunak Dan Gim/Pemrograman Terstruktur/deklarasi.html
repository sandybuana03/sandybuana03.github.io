Kenapa Perlu Variabel?

✨ Menyimpan Data

Seperti menyimpan nama, umur, atau nilai di kotak khusus

Contoh: nilai_matematika = 85

🔄 Menggunakan Berulang

Data yang disimpan bisa dipakai berkali-kali

print(nama) # Bisa dipanggil kapan saja

📝 Mudah Diubah

Isi kotak bisa diganti kapan saja

skor = 75 → skor = 90

🎯 Mudah Dipahami

Nama variabel menjelaskan isinya

tinggi_badan lebih jelas dari x

🚫 Tanpa Variabel vs ✅ Dengan Variabel

❌ Tanpa Variabel (Ribet!)
print("Halo, Ahmad")
print("Ahmad berumur 17")
print("Ahmad tinggi 170")
# Kalau nama berubah, harus ganti semua!
✅ Dengan Variabel (Mudah!)
nama = "Ahmad"
print(f"Halo, {nama}")
print(f"{nama} berumur 17")
print(f"{nama} tinggi 170")
# Ganti sekali di variabel, semua berubah!

🏷️

Cara Membuat Variabel

Di Python, membuat variabel sangat mudah! Cukup tulis nama variabel, tanda sama dengan (=), lalu isinya.

# Membuat variabel nama
nama = "Siti"

# Membuat variabel umur
umur = 16

# Membuat variabel tinggi
tinggi = 165.5
✅ Variabel berhasil dibuat!
nama berisi: "Siti"
umur berisi: 16
tinggi berisi: 165.5
📝

Aturan Nama Variabel

  • ✅ Boleh huruf, angka, underscore (_)
  • ✅ Dimulai dengan huruf atau _
  • ✅ Tidak boleh ada spasi
  • ✅ Case sensitive (besar-kecil beda)
  • ❌ Tidak boleh kata kunci Python
  • ❌ Tidak boleh karakter khusus (@, #, $)
💡

Contoh Nama yang Baik

  • ✅ nama_siswa
  • ✅ nilai_matematika
  • ✅ jumlah_uang
  • ✅ alamat_rumah
  • ✅ total_harga_barang
  • ✅ is_lulus (untuk boolean)
⚠️

Contoh Nama Variabel: Benar vs Salah

✅ BENAR

nama_lengkap = "Ahmad"
umur_siswa = 17
nilai_akhir = 85.5
is_hadir = True
_private_data = "secret"
kelas12 = "XII RPL"

❌ SALAH

nama lengkap = "Ahmad" # ada spasi
2nama = "Budi" # dimulai angka
nilai-akhir = 85 # ada tanda minus
class = "XII" # kata kunci Python
nama@siswa = "Ali" # karakter @
def = 100 # kata kunci Python
🎯

Tips Penamaan Variabel yang Profesional

🏆 Best Practices

  • • Deskriptif: nama_siswa bukan n
  • • Konsisten: gunakan snake_case
  • • Jelas: total_harga bukan th
  • • Bahasa: pilih Indonesia atau Inggris
  • • Boolean: awali dengan is_, has_, can_

🚫 Hindari

  • • Singkatan: nm, tgl, hrg
  • • Angka saja: var1, data2
  • • Kata kunci: if, for, while, class
  • • Ambigu: data, info, temp
  • • Terlalu panjang: nama_lengkap_siswa_kelas_12_rpl_1

Mengetahui Tipe Data Variabel

Python punya fungsi type() untuk mengetahui tipe data suatu variabel. Sangat berguna untuk debugging!

nama = "Siti"
umur = 16
tinggi = 165.5
lulus = True

print(type(nama)) # <class 'str'>
print(type(umur)) # <class 'int'>
print(type(tinggi)) # <class 'float'>
print(type(lulus)) # <class 'bool'>
🔬 Hasil Pengecekan Tipe:
nama: <class 'str'> - String/Teks
umur: <class 'int'> - Integer/Bilangan Bulat
tinggi: <class 'float'> - Float/Bilangan Desimal
lulus: <class 'bool'> - Boolean/Benar-Salah
🔄

Konversi Tipe Data (Type Casting)

Kadang kita perlu mengubah tipe data. Python menyediakan fungsi untuk konversi tipe data.

📝 String ke Angka

angka_str = "123"
angka_int = int(angka_str)
angka_float = float(angka_str)
# "123" → 123 → 123.0

🔢 Angka ke String

umur = 17
umur_str = str(umur)
pesan = "Umur: " + umur_str
# 17 → "17" → "Umur: 17"

✅ Angka ke Boolean

nilai = 85
ada_nilai = bool(nilai)
# 85 → True (bukan 0)
# 0 → False

💫 Float ke Integer

tinggi = 170.8
tinggi_bulat = int(tinggi)
# 170.8 → 170 (dipotong)
# Hati-hati: tidak dibulatkan!
# Untuk pembulatan: round(170.8)
🔄 Hasil Konversi:
String "123" → Integer: 123
String "123" → Float: 123.0
Integer 17 → String: "17"
Float 170.8 → Integer: 170
Integer 85 → Boolean: True
Integer 0 → Boolean: False
🔄

Mengubah Isi Variabel

Variabel bisa diubah isinya kapan saja! Seperti mengganti isi kotak.

# Awalnya
skor = 75
print(skor) # Output: 75

# Diubah
skor = 90
print(skor) # Output: 90
🔄 Variabel berhasil diubah!
Skor awal: 75
Skor setelah diubah: 90
Nama awal: "Budi"
Nama setelah diubah: "Ahmad"

Operasi dengan Variabel

Variabel bisa digunakan untuk perhitungan matematika!

panjang = 10

Konstanta

Data yang tidak berubah sepanjang program!

🏛️

Apa itu Konstanta?

Konstanta adalah variabel yang nilainya tidak berubah sepanjang program berjalan. Seperti nilai π (pi) yang selalu 3.14159, atau jumlah hari dalam seminggu yang selalu 7.

🔄 Variabel Biasa

Bisa berubah kapan saja

skor = 75
skor = 90 # Berubah!

🔒 Konstanta

Tidak berubah sepanjang program

PI = 3.14159
# Tidak diubah lagi!
📝

Cara Membuat Konstanta

Di Python, konstanta dibuat dengan nama HURUF_BESAR_SEMUA. Ini adalah kesepakatan programmer.

# Konstanta matematika
PI = 3.14159
GRAVITASI = 9.8

# Konstanta aplikasi
NAMA_SEKOLAH = "SMK Nusantara"
JUMLAH_HARI_SEMINGGU = 7
BATAS_LULUS = 75

# Menggunakan konstanta
jari_jari = 5
luas_lingkaran = PI * jari_jari * jari_jari
print(f"Luas lingkaran: {luas_lingkaran}")
🔒 Konstanta dalam Aksi:
Luas lingkaran dengan jari-jari 5: 78.53975
Berat benda 10kg di bumi: 98.0 Newton
Sekolah: SMK Nusantara
Hari dalam seminggu: 7
✅

Kapan Pakai Konstanta?

  • • Nilai yang tidak berubah
  • • Konfigurasi aplikasi
  • • Nilai matematika (π, e)
  • • Batas-batas sistem
💡

Keuntungan Konstanta

  • • Kode lebih mudah dibaca
  • • Mudah diubah di satu tempat
  • • Menghindari kesalahan
  • • Dokumentasi otomatis

Tugas 1: Biodata Siswa

Buatlah program untuk menyimpan dan menampilkan biodata siswa menggunakan variabel!

📋 Yang harus dibuat:

  1. Buat variabel untuk menyimpan: nama, kelas, umur, tinggi, berat
  2. Isi variabel dengan data diri kamu
  3. Tampilkan semua data dengan format yang rapi
  4. Hitung dan tampilkan BMI (Berat / (Tinggi dalam meter)²)

💡 Contoh Output yang Diharapkan:

=== BIODATA SISWA ===
Nama: Ahmad Budi
Kelas: XII RPL 1
Umur: 17 tahun
Tinggi: 170 cm
Berat: 60 kg
BMI: 20.76
Status BMI: Normal

Rumus BMI: BMI = berat_kg / (tinggi_meter × tinggi_meter)

Contoh: BMI = 60 / (1.70 × 1.70) = 20.76

Tugas 2: Kasir Sederhana

Buatlah program kasir sederhana menggunakan variabel dan konstanta!

📋 Yang harus dibuat:

  1. Buat konstanta untuk nama toko dan pajak (10%)
  2. Buat variabel untuk 3 barang: nama, harga, jumlah
  3. Hitung total harga sebelum pajak
  4. Hitung pajak dan total akhir
  5. Tampilkan struk belanja yang rapi

💡 Tips:

  • • Gunakan NAMA_TOKO dan PAJAK sebagai konstanta
  • • Hitung subtotal = harga × jumlah untuk setiap barang
  • • Total pajak = total × PAJAK
  • • Gunakan f-string untuk format yang rapi
🎯

Tugas 3: Kalkulator Nilai Siswa

Buatlah program untuk menghitung nilai akhir siswa dengan bobot yang berbeda!

📋 Spesifikasi:

  1. Buat konstanta untuk bobot: BOBOT_TUGAS = 0.3, BOBOT_UTS = 0.3, BOBOT_UAS = 0.4
  2. Input nilai tugas, UTS, dan UAS
  3. Hitung nilai akhir dengan rumus bobot
  4. Tentukan grade (A: ≥85, B: ≥70, C: ≥60, D: <60)
  5. Tampilkan laporan lengkap

🎯 Contoh Output:

=== LAPORAN NILAI SISWA ===
Nama: Ahmad Budi
Nilai Tugas: 85
Nilai UTS: 80
Nilai UAS: 90

Bonus: Input dari Pengguna

Untuk membuat program yang lebih interaktif, kamu bisa menggunakan fungsi input() untuk meminta data dari pengguna!

# Meminta input dari pengguna
nama = input("Siapa nama kamu? ")
umur = int(input("Berapa umur kamu? "))
tinggi = float(input("Berapa tinggi kamu (cm)? "))

print(f"Halo {nama}, umur {umur}, tinggi {tinggi} cm")

Catatan: Fungsi input() selalu mengembalikan string, jadi perlu dikonversi ke int() atau float() jika diperlukan angka.
