Pengenalan Subprogram

🔍 Apa itu Subprogram?

Subprogram adalah bagian kecil dari program yang dibuat untuk melakukan tugas tertentu. Bayangkan seperti "alat khusus" yang bisa kita panggil kapan saja kita butuhkan!

🎯 Mengapa Perlu Subprogram?

  • • Menghindari pengulangan kode - Tulis sekali, pakai berkali-kali!
  • • Kode lebih rapi - Program jadi lebih terorganisir
  • • Mudah diperbaiki - Kalau ada error, cukup perbaiki di satu tempat
  • • Kerja tim lebih mudah - Setiap orang bisa fokus pada bagiannya
  • • Debugging lebih efisien - Masalah bisa diisolasi per fungsi
  • • Testing lebih mudah - Setiap fungsi bisa ditest terpisah

🌍 Analogi Kehidupan Sehari-hari

🍳 Memasak

Resep adalah seperti fungsi - sekali dibuat, bisa dipakai berulang kali untuk masakan yang sama

🏭 Pabrik

Mesin produksi seperti prosedur - melakukan tugas spesifik dalam proses manufaktur

🧮 Kalkulator

Tombol operasi (+, -, ×, ÷) adalah fungsi yang bisa dipanggil dengan input berbeda

📞 Telepon

Nomor kontak seperti nama fungsi - panggil sekali untuk terhubung

✅ Dengan Subprogram

// Buat fungsi sekali
function hitungLuas(p, l) {
return p * l;
}

// Pakai berkali-kali
luas1 = hitungLuas(5, 3);
luas2 = hitungLuas(10, 7);
luas3 = hitungLuas(8, 4);

// Mudah diubah jika perlu
// Cukup ubah di satu tempat!

Keuntungan: Kode 50% lebih pendek, mudah maintenance

❌ Tanpa Subprogram

// Tulis berulang-ulang
luas1 = 5 * 3;
luas2 = 10 * 7;
luas3 = 8 * 4;

// Kalau rumus berubah?
// Harus ubah semua! 😰
luas1 = 5 * 3 * 0.5; // lupa ubah
luas2 = 10 * 7 * 0.5;
luas3 = 8 * 4; // bug!

Masalah: Kode panjang, rawan error, sulit maintenance

75%

60%

80%

Programmer lebih produktif

🏗️ Jenis-jenis Subprogram

⚡ FUNGSI

Subprogram yang mengembalikan nilai

Contoh: Menghitung luas, mencari nilai maksimum

return hasil;

🔧 PROSEDUR

Subprogram yang melakukan aksi

Contoh: Menampilkan pesan, menyimpan data

console.log(pesan);

🔄 Kapan Menggunakan Masing-masing?

Gunakan FUNGSI jika:
  • • Perlu menghitung sesuatu
  • • Hasil akan digunakan lagi
  • • Ingin nilai kembalian
  • • Operasi matematika
Gunakan PROSEDUR jika:
  • • Perlu melakukan aksi
  • • Menampilkan output
  • • Menyimpan/mengubah data
  • • Tidak perlu nilai balik

Konsep Dasar Subprogram

🏗️ Struktur Subprogram

// 1. DEKLARASI (Header)
function namaFungsi(parameter1, parameter2) {

// 2. BODY (Isi)
// Kode untuk melakukan tugas
let hasil = parameter1 + parameter2;

// 3. RETURN (Kembalikan nilai)
return hasil;
}

🎯 Aturan Penamaan Subprogram

✅ Yang Baik
  • • hitungLuas() - jelas dan deskriptif
  • • cariNilaiMax() - menjelaskan tujuan
  • • tampilkanPesan() - kata kerja aktif
  • • validasiEmail() - spesifik
❌ Yang Buruk
  • • func1() - tidak deskriptif
  • • x() - terlalu singkat
  • • doSomething() - terlalu umum
  • • hitungluas() - tidak konsisten

💡 Penjelasan Detail:

  • Deklarasi: Komputer "mengenal" fungsi dan menyimpannya di memori
  • Pemanggilan: Program "memanggil" fungsi dengan memberikan parameter
  • Eksekusi: Komputer menjalankan kode di dalam fungsi
  • Return: Fungsi mengembalikan hasil ke tempat pemanggilan

⚠️ Kesalahan Umum dalam Subprogram

❌ Kesalahan Sintaks

Lupa kurung kurawal:

function test() return 5;

Lupa return pada fungsi:

function hitung() { 5 + 3; }

Parameter tanpa koma:

function tambah(a b) { }

Nama parameter tidak jelas:

function calc(x, y, z) { }

✅ Perbaikan

Gunakan kurung kurawal:

function test() { return 5; }

Tambahkan return:

function hitung() { return 5 + 3; }

Pisahkan dengan koma:

function tambah(a, b) { }

Nama parameter deskriptif:

function hitungVolume(panjang, lebar, tinggi) { }

🤔 Kesalahan Konseptual

❌ Salah Konsep:
  • • Menggunakan prosedur untuk menghitung nilai
  • • Menggunakan fungsi hanya untuk menampilkan
  • • Terlalu banyak parameter (>5)
  • • Fungsi melakukan banyak tugas sekaligus
  • • Tidak konsisten dalam penamaan
✅ Konsep Benar:
  • • Fungsi untuk menghitung dan mengembalikan nilai
  • • Prosedur untuk melakukan aksi/tugas
  • • Parameter maksimal 5 untuk kemudahan
  • • Satu subprogram = satu tugas spesifik
  • • Penamaan konsisten dan deskriptif

Fungsi (Function)

🎯 Apa itu Fungsi?

Fungsi adalah subprogram yang mengembalikan nilai setelah melakukan perhitungan atau pemrosesan.

📥

Input

➡️
⚙️

FUNGSI

➡️
📤

Output

📋 Ciri-ciri Fungsi

  • ✅ Selalu mengembalikan nilai
  • ✅ Menggunakan kata kunci return
  • ✅ Bisa digunakan dalam ekspresi
  • ✅ Hasil bisa disimpan ke variabel

🌟 Contoh Penggunaan

  • 🧮 Menghitung luas, volume
  • 🔢 Mencari nilai maksimum/minimum
  • 📊 Menghitung rata-rata
  • 🔤 Mengubah format teks

💻 Contoh Fungsi dalam Berbagai Bahasa

JavaScript

function tambah(a, b) {
return a + b;
}

let hasil = tambah(5, 3);
// hasil = 8

Python

def tambah(a, b):
return a + b

hasil = tambah(5, 3)
# hasil = 8

🔍 Penjelasan Kode:

JavaScript:
  • • function - kata kunci untuk membuat fungsi
  • • tambah - nama fungsi
  • • (a, b) - parameter input
  • • return - mengembalikan hasil
  • • let hasil = tambah(5, 3) - pemanggilan fungsi
Python:
  • • def - kata kunci untuk membuat fungsi
  • • tambah - nama fungsi
  • • (a, b): - parameter dengan titik dua
  • • Indentasi menggantikan kurung kurawal
  • • hasil = tambah(5, 3) - pemanggilan fungsi

Prosedur (Procedure)

🎯 Apa itu Prosedur?

Prosedur adalah subprogram yang melakukan aksi atau tugas tanpa mengembalikan nilai.

📥

Input

➡️
🔧

PROSEDUR

➡️
✨

Aksi

📋 Ciri-ciri Prosedur

  • ✅ Tidak mengembalikan nilai
  • ✅ Fokus pada melakukan aksi
  • ✅ Dipanggil sebagai statement
  • ✅ Bisa mengubah data global

🌟 Contoh Penggunaan

  • 📺 Menampilkan pesan
  • 💾 Menyimpan data
  • 🎨 Menggambar grafik
  • 📧 Mengirim email

⚖️ Perbedaan Fungsi vs Prosedur

Aspek ⚡ Fungsi 🔧 Prosedur
Return Value ✅ Ada (return) ❌ Tidak ada
Tujuan Menghitung nilai Melakukan aksi
Penggunaan Dalam ekspresi Sebagai statement
Contoh hitungLuas(5,3) tampilkanPesan("Halo")

💻 Contoh Prosedur dalam Berbagai Bahasa

JavaScript

function tampilkanSalam(nama) {
console.log("Halo " + nama);
console.log("Selamat belajar!");
// Tidak ada return
}

tampilkanSalam("Budi");
// Output: Halo Budi
// Selamat belajar!

Python

def tampilkan_salam(nama):
print(f"Halo {nama}")
print("Selamat belajar!")
# Tidak ada return

tampilkan_salam("Budi")
# Output: Halo Budi
# Selamat belajar!

🔍 Perbedaan Prosedur dengan Fungsi:

❌ Prosedur TIDAK:
  • • Menggunakan return untuk nilai
  • • Mengembalikan hasil perhitungan
  • • Digunakan dalam ekspresi matematika
  • • Disimpan ke dalam variabel
✅ Prosedur MELAKUKAN:
  • • Menampilkan output ke layar
  • • Menyimpan data ke file/database
  • • Mengubah nilai variabel global
  • • Melakukan aksi atau proses

Parameter & Argumen

🎯 Apa itu Parameter?

Parameter adalah "pintu masuk" data ke dalam subprogram. Seperti bahan-bahan yang dibutuhkan untuk membuat kue! 🍰

📋 Parameter

Variabel dalam deklarasi fungsi

function tambah(a, b)

📦 Argumen

Nilai yang dikirim saat pemanggilan

tambah(5, 3)

🔄 Jenis Parameter

📥 Parameter Input

Data yang dikirim ke subprogram

📤 Parameter Output

Data yang dikembalikan dari subprogram

🔄 Parameter Input-Output

Data yang dikirim dan diubah

📏 Jumlah Parameter

0️⃣ Tanpa Parameter
function sayHello()
1️⃣ Satu Parameter
function kuadrat(x)
🔢 Banyak Parameter
function hitungVolume(p,l,t)

💻 Contoh Parameter dalam Aksi

// Fungsi dengan berbagai jenis parameter

// 1. Tanpa parameter
function getRandomNumber() {
return Math.floor(Math.random() * 100) + 1;
}

// 2. Satu parameter
function kuadrat(angka) {
return angka * angka;
}

// 3. Banyak parameter
function hitungRataRata(nilai1, nilai2, nilai3) {
return (nilai1 + nilai2 + nilai3) / 3;
}

// 4. Parameter dengan nilai default (ES6)
function sapa(nama = "Teman") {
return "Halo " + nama + "!";
}

🎯 Cara Pemanggilan:

Pemanggilan Fungsi:
let random = getRandomNumber();
let hasil = kuadrat(5);
let rata = hitungRataRata(8, 7, 9);
let pesan = sapa("Budi");
Hasil Output:
random = 42 (angka acak)
hasil = 25
rata = 8
pesan = "Halo Budi!"

⚠️ Tips Menggunakan Parameter

✅ Yang Baik

  • • Gunakan nama parameter yang jelas
  • • Batasi jumlah parameter (max 5)
  • • Urutkan parameter logis
  • • Berikan nilai default jika perlu

❌ Yang Buruk

  • • Nama parameter tidak jelas (a, b, x)
  • • Terlalu banyak parameter
  • • Urutan parameter membingungkan
  • • Tidak ada dokumentasi

📝 Soal Essay

Soal 1: Konsep Dasar (20 poin)

Jelaskan perbedaan antara fungsi dan prosedur dalam pemrograman! Berikan masing-masing 2 contoh penggunaan dalam kehidupan sehari-hari.

Soal 2: Analisis Kode (25 poin)

Perhatikan kode berikut:

function hitungDiskon(harga, persenDiskon) {
let diskon = harga * persenDiskon / 100;
return harga - diskon;
}

a) Identifikasi parameter dan jelaskan fungsinya!
b) Apa yang dikembalikan oleh fungsi ini?
c) Berikan contoh pemanggilan fungsi dengan harga Rp 100.000 dan diskon 15%!

Soal 3: Desain Subprogram (30 poin)

Buatlah rancangan (pseudocode atau flowchart sederhana) untuk:

  • a) Fungsi untuk menghitung luas lingkaran (parameter: jari-jari)
  • b) Prosedur untuk menampilkan biodata siswa (parameter: nama, kelas, jurusan)

Soal 4: Studi Kasus (25 poin)

Kamu diminta membuat program kasir sederhana untuk toko. Program harus bisa:

  • • Menghitung total harga beberapa barang
  • • Menghitung pajak (10% dari total)
  • • Menghitung diskon jika total > Rp 100.000 (5%)
  • • Menampilkan struk pembelian lengkap

Tugas: Tentukan subprogram apa saja yang dibutuhkan (fungsi atau prosedur) beserta parameter yang diperlukan! Jelaskan mengapa memilih fungsi atau prosedur untuk setiap tugas.

Contoh format jawaban:
1. hitungTotal(daftarHarga) - FUNGSI, karena mengembalikan nilai total
2. tampilkanStruk(total, pajak) - PROSEDUR, karena hanya menampilkan output
