Pengenalan Algoritma

🤖 Apa itu Algoritma?

Algoritma adalah urutan langkah-langkah logis untuk menyelesaikan suatu masalah. Seperti resep masakan, algoritma memberikan instruksi step-by-step yang jelas dan terurut.

🏛️ Sejarah Singkat

Kata "algoritma" berasal dari nama matematikawan Persia Al-Khwarizmi (780-850 M) yang menulis buku tentang sistem angka Hindu-Arab dan aljabar.

Konsep algoritma sudah ada sejak zaman kuno, seperti algoritma Euclidean untuk mencari FPB (Faktor Persekutuan Terbesar) yang ditemukan sekitar 300 SM!

🔍 Karakteristik Algoritma yang Baik

✅ Input & Output Jelas

Harus jelas apa yang dibutuhkan (input) dan apa yang dihasilkan (output)

🎯 Definiteness

Setiap langkah harus jelas dan tidak ambigu

⏰ Finiteness

Algoritma harus berakhir dalam waktu yang terbatas

🔄 Effectiveness

Setiap operasi harus dapat dilakukan dengan tepat

🌍 Generality

Dapat menyelesaikan semua masalah dalam kategori yang sama

⚡ Efficiency

Menggunakan sumber daya (waktu, memori) secara optimal

🎭 Contoh Algoritma dalam Kehidupan Sehari-hari

🍳 Membuat Nasi Goreng

  1. 1. Siapkan bahan: nasi, telur, bawang, kecap
  2. 2. Panaskan minyak di wajan
  3. 3. Tumis bawang hingga harum
  4. 4. Masukkan telur, orak-arik
  5. 5. Tambahkan nasi, aduk rata
  6. 6. Beri kecap dan bumbu
  7. 7. Sajikan selagi hangat

🚗 Pergi ke Sekolah

  1. 1. Bangun pagi dan mandi
  2. 2. Sarapan dan siapkan tas
  3. 3. Cek cuaca untuk pilih pakaian
  4. 4. Keluar rumah tepat waktu
  5. 5. Pilih rute tercepat
  6. 6. Jika macet, cari jalan alternatif
  7. 7. Sampai di sekolah

💡 Tips Membuat Flowchart yang Baik

✅ Do's (Yang Harus Dilakukan)

  • • Gunakan simbol standar yang benar
  • • Alur dari atas ke bawah, kiri ke kanan
  • • Satu titik masuk, satu titik keluar
  • • Gunakan kata kerja aktif
  • • Beri label jelas pada setiap cabang
  • • Test dengan berbagai skenario

❌ Don'ts (Yang Harus Dihindari)

  • • Garis yang bersilangan tanpa perlu
  • • Terlalu banyak detail dalam satu simbol
  • • Menggunakan simbol yang salah
  • • Alur yang tidak jelas arahnya
  • • Lupa memberi label pada decision
  • • Infinite loop tanpa kondisi berhenti

Menulis Pseudocode

🎯 Apa itu Pseudocode?

Pseudocode adalah cara menulis algoritma menggunakan bahasa sehari-hari yang mudah dipahami, tapi tetap mengikuti struktur logika pemrograman.

✨ Karakteristik Pseudocode:

  • • Menggunakan bahasa yang mudah dipahami (bahasa sehari-hari)
  • • Tidak terikat aturan syntax bahasa pemrograman tertentu
  • • Fokus pada logika algoritma, bukan detail implementasi teknis
  • • Mudah diterjemahkan ke berbagai bahasa pemrograman (Python, Java, C++, dll)
  • • Membantu programmer merencanakan struktur program sebelum coding

📋 Struktur Dasar Pseudocode

🔄 Struktur Berurutan

MULAI
  Langkah 1
  Langkah 2
  Langkah 3
SELESAI

🔀 Struktur Percabangan

JIKA kondisi MAKA
  Aksi A
SELAIN ITU
  Aksi B
AKHIR JIKA

🔁 Struktur Perulangan

SELAMA kondisi LAKUKAN
  Aksi berulang
AKHIR SELAMA

📥📤 Input/Output

BACA variabel
TULIS "pesan"
TAMPILKAN hasil

🔄 Mencari Bilangan Prima

ALGORITMA CekBilanganPrima
MULAI
  TULIS "Masukkan bilangan: "
  BACA n
  JIKA n ≤ 1 MAKA
    TULIS n, " bukan bilangan prima"
  SELAIN ITU
    isPrima ← BENAR
    UNTUK i = 2 SAMPAI √n LAKUKAN
      JIKA n MOD i = 0 MAKA
        isPrima ← SALAH
        KELUAR DARI LOOP
      AKHIR JIKA
    AKHIR UNTUK
    JIKA isPrima MAKA
      TULIS n, " adalah bilangan prima"
    SELAIN ITU
      TULIS n, " bukan bilangan prima"
    AKHIR JIKA
  AKHIR JIKA
SELESAI

📊 Mengurutkan Array (Bubble Sort)

ALGORITMA BubbleSort
MULAI
  BACA array A[1..n]
  UNTUK i = 1 SAMPAI n-1 LAKUKAN
    UNTUK j = 1 SAMPAI n-i LAKUKAN
      JIKA A[j] > A[j+1] MAKA
        temp ← A[j]
        A[j] ← A[j+1]
        A[j+1] ← temp
      AKHIR JIKA
    AKHIR UNTUK
  AKHIR UNTUK
  TULIS "Array terurut: ", A
SELESAI

🎯 Kalkulator Sederhana

ALGORITMA KalkulatorSederhana
MULAI
  TULIS "Masukkan angka pertama: "
  BACA angka1
  TULIS "Masukkan operator (+,-,*,/): "
  BACA operator
  TULIS "Masukkan angka kedua: "
  BACA angka2
  PILIH operator
    KASUS '+': hasil ← angka1 + angka2
    KASUS '-': hasil ← angka1 - angka2
    KASUS '*': hasil ← angka1 × angka2
    KASUS '/':
      JIKA angka2 ≠ 0 MAKA
        hasil ← angka1 ÷ angka2
      SELAIN ITU
        TULIS "Error: Pembagian dengan nol"
      AKHIR JIKA
  AKHIR PILIH
  TULIS "Hasil: ", hasil
SELESAI

🔍 Pencarian Linear

ALGORITMA PencarianLinear
MULAI
  BACA array A[1..n]
  BACA x (nilai yang dicari)
  ditemukan ← SALAH
  posisi ← -1
  UNTUK i = 1 SAMPAI n LAKUKAN
    JIKA A[i] = x MAKA
      ditemukan ← BENAR
      posisi ← i
      KELUAR DARI LOOP
    AKHIR JIKA
  AKHIR UNTUK
  JIKA ditemukan MAKA
    TULIS "Data ditemukan di posisi: ", posisi
  SELAIN ITU
    TULIS "Data tidak ditemukan"
  AKHIR JIKA
SELESAI

💡 Tips Translasi yang Baik

✅ Yang Harus Dilakukan

  • • Pahami logika pseudocode dulu
  • • Perhatikan indentasi Python
  • • Gunakan nama variabel yang jelas

🎯 Soal 1: Program Konversi Suhu

Deskripsi: Buat program yang dapat mengkonversi suhu dari Celsius ke Fahrenheit dan Kelvin.

📐 Rumus:

  • • Fahrenheit = (Celsius × 9/5) + 32
  • • Kelvin = Celsius + 273.15

📤 Output yang diharapkan:

Masukkan suhu dalam Celsius: 25
25°C = 77.0°F
25°C = 298.15K

🎯 Soal 2: Program Diskon Belanja

Deskripsi: Buat program kasir yang menghitung total belanja dengan sistem diskon bertingkat.

💰 Aturan Diskon:

  • • Belanja < Rp 100.000: Tidak ada diskon
  • • Belanja Rp 100.000 - Rp 500.000: Diskon 10%
  • • Belanja > Rp 500.000: Diskon 20%

📤 Output yang diharapkan:

Masukkan total belanja: 150000
Total belanja: Rp 150,000
Diskon (10%): Rp 15,000
Total bayar: Rp 135,000

🎯 Soal 3: Program Deret Fibonacci

Deskripsi: Buat program yang menampilkan deret Fibonacci sebanyak n suku yang diinputkan user.

🔢 Aturan Fibonacci:

  • • Suku pertama = 0
  • • Suku kedua = 1
  • • Suku selanjutnya = jumlah dua suku sebelumnya
  • • Contoh: 0, 1, 1, 2, 3, 5, 8, 13, ...

📤 Output yang diharapkan:

Masukkan jumlah suku: 8
Deret Fibonacci:
0 1 1 2 3 5 8 13
