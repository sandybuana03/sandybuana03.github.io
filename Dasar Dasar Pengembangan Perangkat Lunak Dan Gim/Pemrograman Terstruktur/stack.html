Stack (Tumpukan) 📚

Stack adalah struktur data yang mengikuti prinsip LIFO (Last In, First Out)

Analogi Kehidupan Sehari-hari:

  • Menumpuk piring di dapur (ambil dari atas)
  • Tumpukan buku di meja (ambil yang paling atas)
  • Kartu yang ditumpuk (ambil kartu teratas)
  • Tumpukan koin (ambil koin paling atas)

Karakteristik:

  • Akses hanya dari satu ujung (top/puncak)
  • Operasi utama: Push (masuk) & Pop (keluar)
  • Struktur linear dengan aturan LIFO
  • Elemen terakhir masuk adalah yang pertama keluar
🍽️📚📦

Queue (Antrean) 🚶‍♂️

Queue adalah struktur data yang mengikuti prinsip FIFO (First In, First Out)

Analogi Kehidupan Sehari-hari:

  • Antrian di kasir supermarket (yang datang duluan dilayani duluan)
  • Antrian di bank (urutan sesuai nomor antrian)
  • Antrian kendaraan di lampu merah (yang depan jalan duluan)
  • Antrian boarding pesawat (sesuai urutan check-in)

Karakteristik:

  • Akses dari dua ujung (front untuk keluar, rear untuk masuk)
  • Operasi utama: Enqueue (masuk) & Dequeue (keluar)
  • Struktur linear dengan aturan FIFO
  • Elemen pertama masuk adalah yang pertama keluar

Studi Kasus: Text Editor 📝

Bagaimana Fitur Undo Bekerja?

Langkah-langkah:
  1. User mengetik "Hello"
  2. Action "type Hello" masuk ke stack
  3. User mengetik " World"
  4. Action "type World" masuk ke stack
  5. User tekan Ctrl+Z
  6. Action teratas di-pop dari stack
  7. Text kembali ke "Hello"
Visualisasi Stack:
type " World" ← POP
type "Hello"
empty

Keuntungan Stack

  • Operasi push/pop sangat cepat O(1)
  • Implementasi sederhana
  • Memory efficient untuk operasi LIFO
  • Cocok untuk rekursi dan backtracking

Kekurangan Stack

  • Akses terbatas (hanya top element)
  • Tidak cocok untuk random access
  • Stack overflow jika terlalu banyak data
  • Pencarian elemen membutuhkan O(n)

Studi Kasus: Sistem Antrian Bank 🏦

Bagaimana Sistem Antrian Bekerja?

Skenario:
  1. Andi datang ke bank (enqueue)
  2. Budi datang setelah Andi (enqueue)
  3. Citra datang setelah Budi (enqueue)
  4. Teller memanggil Andi (dequeue)
  5. Andi selesai, Budi dipanggil (dequeue)
  6. Doni datang (enqueue)
  7. Budi selesai, Citra dipanggil (dequeue)
Visualisasi Queue:
Awal:

Budi
Citra
Setelah Andi dilayani:
Budi
Citra
Doni

Keuntungan Queue

  • Fairness - first come, first served
  • Cocok untuk sistem real-time
  • Mudah diimplementasi
  • Efisien untuk buffering data

Kekurangan Queue

  • Akses terbatas (hanya front dan rear)
  • Tidak ada prioritas (kecuali priority queue)
  • Memory bisa terbuang (linear queue)
  • Pencarian elemen membutuhkan O(n)

Implementasi Python 🐍

Mari lihat bagaimana membuat Stack dan Queue di Python!

Implementasi Stack

stack_implementation.py
Python
 1 # Implementasi Stack menggunakan List
 2 class Stack:
 3     def __init__(self):
 4         self.items = []
 5     
 6     def push(self, item):
 7         """Menambahkan item ke puncak stack"""
 8         self.items.append(item)
 9         print(f"Push: {item} ditambahkan ke stack")
10     
11     def pop(self):
12         """Menghapus dan mengembalikan item dari puncak stack"""
13         if self.is_empty():
14             return "Stack kosong!"
15         item = self.items.pop()
16         print(f"Pop: {item} dihapus dari stack")
17         return item
18     
19     def peek(self):
20         """Melihat item di puncak stack tanpa menghapus"""
21         if self.is_empty():
22             return "Stack kosong!"
23         return self.items[-1]
24     
25     def is_empty(self):
26         """Mengecek apakah stack kosong"""
27         return len(self.items) == 0
28     
29     def size(self):
30         """Mengembalikan ukuran stack"""
31         return len(self.items)
32 
33 # Contoh penggunaan
34 stack = Stack()
35 stack.push("Piring 1")
36 stack.push("Piring 2")
37 stack.push("Piring 3")
38 print(f"Puncak stack: {stack.peek()}")
39 stack.pop()
40 print(f"Ukuran stack: {stack.size()}")

Implementasi Queue

queue_implementation.py
Python
 1 # Implementasi Queue menggunakan List
 2 class Queue:
 3     def __init__(self):
 4         self.items = []
 5     
 6     def enqueue(self, item):
 7         """Menambahkan item ke belakang queue"""
 8         self.items.append(item)
 9         print(f"Enqueue: {item} masuk ke antrian")
10     
11     def dequeue(self):
12         """Menghapus dan mengembalikan item dari depan queue"""
13         if self.is_empty():
14             return "Queue kosong!"
15         item = self.items.pop(0)  # O(n) complexity
16         print(f"Dequeue: {item} keluar dari antrian")
17         return item
18     
19     def front(self):
20         """Melihat item di depan queue tanpa menghapus"""
21         if self.is_empty():
22             return "Queue kosong!"
23         return self.items[0]
24     
25     def is_empty(self):
26         """Mengecek apakah queue kosong"""
27         return len(self.items) == 0
28     
29     def size(self):
30         """Mengembalikan ukuran queue"""
31         return len(self.items)
32 
32 
33 # Catatan: Implementasi ini menggunakan list Python
34 # Untuk efisiensi yang lebih baik, gunakan collections.deque
35 
36 # Contoh penggunaan
37 queue = Queue()
35 queue.enqueue("Orang 1")
36 queue.enqueue("Orang 2")
37 queue.enqueue("Orang 3")
38 print(f"Depan antrian: {queue.front()}")
39 queue.dequeue()
40 print(f"Ukuran antrian: {queue.size()}")

Perbandingan Stack vs Queue 📊

Stack (LIFO)

  • • Push: Tambah di akhir
  • • Pop: Hapus dari akhir
  • • Peek: Lihat elemen terakhir
  • • Cocok untuk: Undo/Redo, Function Call

Queue (FIFO)

  • • Enqueue: Tambah di akhir
  • • Dequeue: Hapus dari awal
  • • Front: Lihat elemen pertama
  • • Cocok untuk: Antrian, Scheduling
