Pengenalan Materi

🔍 Apa itu Data dalam Pemrograman?

Data adalah informasi yang disimpan dan diproses oleh program. Dalam Python, data dapat berupa angka, teks, daftar, atau struktur yang lebih kompleks. Bayangkan data seperti berbagai jenis wadah untuk menyimpan informasi!

🏠 Analogi Rumah:

Data seperti barang-barang di rumah:

  • • Alamat rumah → Data statis (tidak berubah)
  • • Daftar belanja → Data dinamis (sering berubah)
  • • Tanggal lahir → Data statis (tetap selamanya)
  • • Isi lemari → Data dinamis (bisa ditambah/dikurangi)

💾 Memory dalam Komputer:

Data Statis - Lokasi tetap
Data Dinamis - Lokasi fleksibel

Contoh Data dalam Kehidupan Sehari-hari:

profil_siswa.py
1
# Data Profil Siswa SMK
2
nama_lengkap = "Budi Santoso" # Statis - tidak berubah
3
nis = 2024001 # Statis - nomor tetap
4
kelas = "XI RPL 1" # Bisa berubah tiap tahun
5
nilai_harian = [85, 90, 78] # Dinamis - terus bertambah
6
ekstrakurikuler = ["Robotika", "Basket"] # Dinamis - bisa berubah
🔒

Data Statis

Data yang tidak dapat diubah setelah dibuat. Seperti nama yang tertulis di batu - permanen!

⚡

Data Dinamis

Data yang dapat diubah, ditambah, atau dikurangi. Seperti daftar belanja yang bisa dicoret-coret!

Data Statis (Immutable)

📖 Definisi Data Statis

Data statis (immutable) adalah data yang tidak dapat diubah setelah dibuat. Jika kita ingin "mengubah" data ini, Python sebenarnya membuat data baru.

Analogi Sederhana:

Seperti menulis dengan pulpen di kertas - sekali ditulis, tidak bisa dihapus. Jika mau mengubah, harus pakai kertas baru!

📋 Jenis-jenis Data Statis di Python

1. String (str)

Teks yang tidak bisa diubah

2. Integer (int)

Bilangan bulat

3. Float

Bilangan desimal

4. Tuple

Kumpulan data terurut

Data Dinamis (Mutable)

📖 Definisi Data Dinamis

Data dinamis (mutable) adalah data yang dapat diubah, ditambah, atau dikurangi setelah dibuat. Kita bisa memodifikasi isinya tanpa membuat objek baru.

Analogi Sederhana:

Seperti menulis dengan pensil di kertas - bisa dihapus, ditambah, atau diubah kapan saja!

📋 Jenis-jenis Data Dinamis di Python

1. List

Daftar yang bisa diubah

2. Dictionary (dict)

Pasangan key-value

3. Set

Kumpulan unik

4. Bytearray

Array byte yang bisa diubah

💻 Demo Interaktif: Data Dinamis

Perbandingan Data Statis vs Dinamis

Aspek Data Statis 🔒 Data Dinamis ⚡
Dapat Diubah ❌ Tidak ✅ Ya
Contoh Tipe str, int, tuple list, dict, set
Keamanan ✅ Lebih aman ⚠️ Perlu hati-hati
Penggunaan Memori ✅ Efisien ⚠️ Lebih banyak
Fleksibilitas ⚠️ Terbatas ✅ Sangat fleksibel
Dapat jadi Key Dict ✅ Ya ❌ Tidak

🔒 Kapan Gunakan Data Statis?

  • • Data yang tidak perlu diubah (nama, ID)
  • • Sebagai key dalam dictionary
  • • Koordinat atau posisi tetap
  • • Konfigurasi yang tidak berubah

⚡ Kapan Gunakan Data Dinamis?

  • • Daftar yang sering berubah (keranjang belanja)
  • • Data yang perlu diupdate (skor game)
  • • Koleksi yang dinamis (playlist musik)
  • • Buffer atau cache data

💡 Tips Memilih yang Tepat

🤔 Pertanyaan Panduan:

  • • Apakah data ini akan berubah selama program berjalan?
  • • Apakah perlu menambah/mengurangi item secara dinamis?
  • • Apakah akan digunakan sebagai key dictionary?
  • • Seberapa penting keamanan dan integritas data?
  • • Apakah performa memori menjadi prioritas?

⚡ Aturan Praktis:

  • • Default: Mulai dengan data statis
  • • Fleksibilitas: Ubah ke dinamis jika perlu
  • • Performa: Statis lebih cepat dan hemat memori
  • • Keamanan: Statis lebih aman dari perubahan tak terduga
  • • Debugging: Statis lebih mudah di-debug

🔒 Data Statis (Immutable)

  • • Tidak dapat diubah setelah dibuat
  • • Contoh: string, int, tuple
  • • Lebih aman dan efisien

  • • Dapat diubah, ditambah, dikurangi
  • • Contoh: list, dict, set
