🎮 Contoh Praktis Loop Python

🔢 Hitung 1 sampai 5

# For Loop Python
for i in range(1, 6):
    print(f"Angka: {i}")

# Output: Angka: 1, 2, 3, 4, 5

⏰ Countdown Timer

# While Loop Python
countdown = 5
while countdown > 0:
    print(f"⏰ {countdown}")
    countdown -= 1
print("🚀 Go!")

🛒 Hitung Total Belanja

# Loop untuk menghitung total
harga = [15000, 25000, 8000]
total = 0

for item in harga:
    total += item
    print(f"+ Rp{item:,}")

print(f"Total: Rp{total:,}")

📝 Validasi Input

# Loop sampai input valid
while True:
    umur = input("Umur: ")
    if umur.isdigit():
        umur = int(umur)
        if umur > 0:
            break
    print("Input tidak valid!")

print(f"Umur: {umur} tahun")

🔁 For Loop Python

💡 Konsep For Loop Python

For loop di Python seperti mesin otomatis yang bekerja untuk setiap item dalam koleksi. Bayangkan seperti pabrik yang memproses setiap produk satu per satu secara otomatis! Python akan mengulang kode untuk setiap elemen yang ada.

📦📦📦 ➡️ 🏭 ➡️ ✅✅✅

Koleksi Data → For Loop → Proses Semua

# Contoh sederhana for loop Python
buah = ["apel", "pisang", "jeruk"]

for item in buah:
    print(f"Saya suka {item} 🍎")

🔢 Memahami Range Function

range(stop)

0 sampai stop-1

range(start, stop)

start sampai stop-1

range(start, stop, step)

dengan langkah step

# Berbagai cara menggunakan range Python

# 1. range(stop) - mulai dari 0
for i in range(3):
    print(f"Angka: {i}")  
# Output: Angka: 0, Angka: 1, Angka: 2

# 2. range(start, stop) - dari start sampai stop-1
for i in range(1, 4):
    print(f"Angka: {i}")  
# Output: Angka: 1, Angka: 2, Angka: 3

# 3. range(start, stop, step) - dengan langkah tertentu
for i in range(0, 10, 2):
    print(f"Genap: {i}")  
# Output: Genap: 0, 2, 4, 6, 8

# 4. range mundur dengan step negatif
for i in range(5, 0, -1):
    print(f"Mundur: {i}")  
# Output: Mundur: 5, 4, 3, 2, 1

# 5. Contoh praktis - loop dengan index
buah = ["apel", "pisang", "jeruk"]
for i in range(len(buah)):
    print(f"{i+1}. {buah[i]}")
# Output: 1. apel, 2. pisang, 3. jeruk

⏳ While Loop Python

🎭 Konsep While Loop Python

While loop di Python seperti alarm yang terus berbunyi SELAMA kondisi masih benar. Berbeda dengan for loop yang sudah tahu berapa kali akan berulang, while loop akan terus berjalan sampai kondisinya menjadi False. Hati-hati jangan sampai infinite loop! ⚠️

🔔 ➡️ ❓ ➡️ 🔔/🔇

Kondisi Benar → Cek → Lanjut/Stop

# Contoh while loop Python
countdown = 5

while countdown > 0:
    print(f"Countdown: {countdown}")
    countdown -= 1

print("Selesai! 🚀")

⚖️ For Loop vs While Loop Python

🔁 For Loop Python
  • • Jumlah iterasi sudah diketahui
  • • Iterasi melalui koleksi/range
  • • Lebih mudah untuk counting
  • • Jarang terjadi infinite loop
  • • Sintaks lebih ringkas
for i in range(5):
    print(i)
⏳ While Loop Python
  • • Berdasarkan kondisi boolean
  • • Jumlah iterasi tidak pasti
  • • Cocok untuk validasi input
  • • Hati-hati infinite loop
  • • Lebih fleksibel untuk kondisi
i = 0
while i < 5:
    print(i)
    i += 1
🎯 Kapan Menggunakan Masing-masing?

Gunakan For Loop untuk:

  • • Iterasi list, tuple, string
  • • Counting dengan range
  • • Jumlah iterasi pasti

Gunakan While Loop untuk:

  • • Input validation
  • • Game loops
  • • Kondisi yang tidak pasti

⚠️ Menghindari Infinite Loop

❌ Bahaya!
# Infinite loop - jangan!
i = 0
while i < 10:
    print(i)
    # Lupa increment i!
✅ Aman!
# Loop yang aman
i = 0
while i < 10:
    print(i)
    i += 1  # Jangan lupa!

🏗️ Nested Loop Python

🎚️ Konsep Nested Loop Python

Nested Loop adalah loop di dalam loop! Seperti roda di dalam roda yang berputar. Loop luar berputar sekali, loop dalam berputar penuh. Sangat berguna untuk membuat pola, tabel, atau memproses data 2 dimensi seperti matriks! 🌀

🔄 ➡️ 🔄🔄🔄 ➡️ 📊

Loop Luar → Loop Dalam × N → Hasil Kompleks

🧠 Cara Kerja Nested Loop

# Contoh sederhana nested loop
for i in range(3):        # Loop luar: 3 kali
    for j in range(2):    # Loop dalam: 2 kali
        print(f"i={i}, j={j}")

# Output:
# i=0, j=0  i=0, j=1
# i=1, j=0  i=1, j=1
# i=2, j=0  i=2, j=1

Total eksekusi: Loop luar (3) × Loop dalam (2) = 6 kali eksekusi

🎯 Aplikasi Nested Loop

📋 Tabel Perkalian
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i}×{j}={i*j}", end=" ")
    print()  # New line
🏢 Matriks 2D
matrix = [[1,2], [3,4]]

for row in matrix:
    for col in row:
        print(col, end=" ")
    print()

                        ⚡
                        Break & Continue Python
                    


                    

                        

                            

                                🛑
                                Break Statement Python
                            

                            

                                Break adalah tombol "STOP" untuk loop! Ketika Python menemukan break, 
                                loop langsung berhenti total dan keluar. Seperti tombol emergency stop di lift! 🚨
                            

                            

                                

                                    
🔄 ➡️ 🛑 ➡️ ❌

                                    
Loop Berjalan → Break → Loop Berhenti

                                

                                

                                    
# Contoh break dalam loop
for i in range(10):
    if i == 5:
        break  # Stop di sini!
    print(i)

# Output: 0, 1, 2, 3, 4 (berhenti di 5)
                                    

                                

                            

                        


                        

                            

                                ⏭️
                                Continue Statement Python
                            

                            

                                Continue adalah tombol "SKIP" untuk loop! Ketika Python menemukan continue, 
                                iterasi saat ini dilewati dan langsung lanjut ke iterasi berikutnya. Seperti skip lagu! 🎵
                            

                            

                                

                                    
🔄 ➡️ ⏭️ ➡️ 🔄

                                    
Loop Berjalan → Continue → Skip ke Berikutnya

                                

                                

                                    
# Contoh continue dalam loop
for i in range(5):
    if i == 2:
        continue  # Skip angka 2
    print(i)

# Output: 0, 1, 3, 4 (skip angka 2)
                                    

                                

                            


                            

                                
🎯 Contoh Praktis Break & Continue Python

                                

                                    

                                        
🛑 Break - Cari Angka

                                        

                                            
# Cari angka 7 dalam list
numbers = [1, 3, 7, 9, 11]

for num in numbers:
    if num == 7:
        print("Ketemu 7!")
        break  # Stop di sini
    print(f"Cek: {num}")

# Output: Cek: 1, Cek: 3, Ketemu 7!
# Angka 9 dan 11 tidak diproses
                                            

                                        

                                    

                                    

                                        
⏭️ Continue - Skip Genap

                                        

                                            
# Tampilkan hanya angka ganjil
for i in range(1, 8):
    if i % 2 == 0:  # Jika genap
        continue  # Skip ke iterasi berikutnya
    print(f"Ganjil: {i}")

# Output: Ganjil: 1, Ganjil: 3, Ganjil: 5, Ganjil: 7
# Angka genap (2,4,6) di-skip
                                            

                                        

                                    

                                

                                
                                

                                    

                                        
🔍 Break - Login System

                                        

                                            
# Sistem login dengan 3 percobaan
password = "python123"
max_tries = 3

for attempt in range(max_tries):
    user_input = input("Password: ")
    if user_input == password:
        print("Login berhasil!")
        break  # Keluar jika benar
    print(f"Salah! Sisa {max_tries-attempt-1} percobaan")
else:
    print("Akun terkunci!")
                                            

                                        

                                    

                                    

                                        
📊 Continue - Filter Data

                                        

                                            
# Filter nilai siswa >= 70
nilai = [85, 60, 75, 45, 90]
lulus = []

for score in nilai:
    if score < 70:
        continue  # Skip nilai < 70
    lulus.append(score)
    print(f"Lulus: {score}")

print(f"Total lulus: {len(lulus)}")
# Output: Lulus: 85, 75, 90. Total: 3
                                            

                                        

                                    

                                

                            

                        


                        

                            

                                🎪
                                Break & Continue dalam Nested Loop
                            

                            

                                
⚠️ Penting: Hanya Mempengaruhi Loop Terdekat

                                

                                    
# Break hanya keluar dari loop dalam
for i in range(3):
    print(f"Loop luar: {i}")
    for j in range(3):
        if j == 1:
            break  # Hanya keluar dari loop j
        print(f"  Loop dalam: {j}")
    print("  Selesai loop dalam")

# Output menunjukkan loop luar tetap berjalan
