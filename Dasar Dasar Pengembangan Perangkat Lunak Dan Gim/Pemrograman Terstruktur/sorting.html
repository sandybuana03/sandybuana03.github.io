📚 Pengenalan Sorting & Searching

🔄

Sorting (Pengurutan)

Sorting adalah proses mengatur data dalam urutan tertentu (ascending/descending).

Ascending (Naik):

[3, 1, 4, 2] → [1, 2, 3, 4]

Descending (Turun):

[3, 1, 4, 2] → [4, 3, 2, 1]

🔍

Searching (Pencarian)

Searching adalah proses mencari data tertentu dalam kumpulan data.

Linear Search:

Cari 3 dalam [1, 2, 3, 4] → Index 2

Binary Search:

Cari 7 dalam [1, 3, 5, 7, 9] → Index 3

🔄 Sorting (Pengurutan)

🫧 Bubble Sort

Algoritma paling sederhana! Seperti gelembung air yang naik ke permukaan, angka besar akan "menggelembung" ke akhir list.

# Bubble Sort Python - Mengurutkan dari kecil ke besar

def bubble_sort(arr):

    n = len(arr)

    # Loop untuk setiap elemen

    for i in range(n):

        # Loop untuk membandingkan elemen bersebelahan

        for j in range(0, n-i-1):

            # Jika elemen kiri lebih besar, tukar posisi

            if arr[j] > arr[j+1]:

                arr[j], arr[j+1] = arr[j+1], arr[j]

    return arr

# Contoh penggunaan:

data = [64, 34, 25, 12, 22]

print(bubble_sort(data)) # Output: [12, 22, 25, 34, 64]

🎯 Selection Sort

Seperti memilih pemain terbaik! Cari yang terkecil, taruh di depan, lalu ulangi.

# Selection Sort Python

def selection_sort(arr):

    for i in range(len(arr)):

        min_idx = i

        for j in range(i+1, len(arr)):

            if arr[j] < arr[min_idx]:

                min_idx = j

        arr[i], arr[min_idx] = arr[min_idx], arr[i]

    return arr

💡 Cara Kerja: Temukan elemen terkecil, tukar dengan posisi pertama. Lalu cari elemen terkecil kedua, tukar dengan posisi kedua, dan seterusnya.

📥 Insertion Sort

Seperti menyusun kartu di tangan! Ambil satu kartu, sisipkan di posisi yang tepat.

# Insertion Sort Python

def insertion_sort(arr):

    for i in range(1, len(arr)):

        key = arr[i]

        j = i - 1

        while j >= 0 and arr[j] > key:

            arr[j + 1] = arr[j]

            j -= 1

        arr[j + 1] = key

    return arr

🎯 Keunggulan: Sangat efisien untuk data yang sudah hampir terurut! Sering digunakan untuk data kecil atau sebagai bagian dari algoritma hybrid.

⚡ Quick Sort (Preview)

Algoritma "divide and conquer" yang sangat cepat! Pilih pivot, bagi array, urutkan rekursif.

⚠️ Catatan: Quick Sort adalah materi lanjutan yang akan dipelajari di tingkat yang lebih tinggi. Kompleksitas rata-rata O(n log n), tapi bisa menjadi O(n²) dalam kasus terburuk.

✅ Kelebihan:

  • • Sangat cepat untuk data besar
  • • In-place sorting (hemat memori)
  • • Banyak digunakan di industri

⚠️ Kekurangan:

  • • Kompleks untuk dipahami
  • • Tidak stabil
  • • Worst case O(n²)

# Linear Search Python

def linear_search(arr, target):

    for i in range(len(arr)):

        if arr[i] == target:

            return i

    return -1

⚡ Binary Search

💡 Tips: Binary search jauh lebih cepat dari linear search untuk data besar! Untuk 1 juta data, linear search butuh rata-rata 500,000 langkah, binary search hanya sekitar 20 langkah! Rumusnya: maksimal log₂(n) langkah, dimana n = jumlah data.

# Binary Search Python - Pencarian pada data terurut

def binary_search(arr, target):

    # Tentukan batas kiri dan kanan

    left, right = 0, len(arr) - 1

    steps = 0

    

    while left <= right:

        steps += 1

        # Cari posisi tengah

        mid = (left + right) // 2

        print(f"Langkah {steps}: Cek posisi {mid}, nilai {arr[mid]}")

        

        if arr[mid] == target:

            return mid # Ketemu!

        elif arr[mid] < target:

            left = mid + 1 # Cari di kanan

        else:

            right = mid - 1 # Cari di kiri

    

    return -1 # Tidak ditemukan

# Contoh penggunaan:

data = [1, 3, 5, 7, 9, 11, 13, 15]

hasil = binary_search(data, 7) # Output: 3

🎯 Program Lengkap: Sistem Nilai Siswa

Mari buat program yang bisa mengurutkan dan mencari nilai siswa!

# Program Sistem Nilai Siswa

class SistemNilai:

    def __init__(self):

        self.nilai = []

        self.nama = []


    def tambah_siswa(self, nama, nilai):

        self.nama.append(nama)

        self.nilai.append(nilai)


    def urutkan_nilai(self):

        # Bubble sort - urutkan dari nilai tertinggi ke terendah

        n = len(self.nilai)

        for i in range(n):

            for j in range(0, n-i-1):

                # Jika nilai kiri < nilai kanan, tukar (descending)

                if self.nilai[j] < self.nilai[j+1]:

                    # Tukar nilai dan nama secara bersamaan

                    self.nilai[j], self.nilai[j+1] = self.nilai[j+1], self.nilai[j]

                    self.nama[j], self.nama[j+1] = self.nama[j+1], self.nama[j]


    def cari_siswa(self, nama_cari):

        for i in range(len(self.nama)):

            if self.nama[i].lower() == nama_cari.lower():

                return i

        return -1


# Contoh penggunaan

sistem = SistemNilai()

sistem.tambah_siswa("Andi", 85)

sistem.tambah_siswa("Budi", 92)

sistem.tambah_siswa("Citra", 78)


sistem.urutkan_nilai()

print("Ranking:", sistem.nama) # Output: ['Budi', 'Andi', 'Citra']

print("Nilai:", sistem.nilai) # Output: [92, 85, 78]
