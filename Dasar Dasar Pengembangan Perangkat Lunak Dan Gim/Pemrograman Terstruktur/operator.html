Pengenalan Operator Python 🐍

Apa itu Operator?

Operator adalah simbol khusus yang digunakan untuk melakukan operasi pada data atau variabel. Bayangkan operator seperti alat-alat di kotak perkakas yang membantu kita "mengolah" data! 🔧

🌟 Analogi Sederhana:

🧮
Seperti Kalkulator: Operator + seperti tombol tambah di kalkulator
⚖️
Seperti Timbangan: Operator > seperti membandingkan berat
🚦
Seperti Lampu Lalu Lintas: Operator and seperti "hijau DAN aman"
🔧
Seperti Alat: Setiap operator punya fungsi spesifik

Operator Aritmatika

Untuk perhitungan matematika seperti +, -, *, /

Operator Relasional

Untuk membandingkan nilai seperti >, <, ==

Operator Logika

Untuk logika program seperti and, or, not

Sejarah Singkat Operator

📜
Era Kuno

Simbol matematika seperti + dan - sudah digunakan sejak abad ke-15

💻
Era Komputer

Bahasa pemrograman pertama mengadopsi simbol matematika tradisional

🐍
Python Modern

Python membuat operator lebih mudah dibaca dan dipahami

Prioritas Operator (Operator Precedence)

Seperti matematika, Python punya aturan mana yang dikerjakan dulu:

1. Tertinggi ** (pangkat)
2. +, - (unary plus/minus)
3. *, /, //, % (kali, bagi)
4. +, - (tambah, kurang)
5. ==, !=, >, <, >=, <= (perbandingan)
6. not (negasi)
7. and (dan)
8. Terendah or (atau)
💡 Tips: Gunakan tanda kurung ( ) untuk mengubah urutan perhitungan!
Contoh: 2 + 3 * 4 = 14 (bukan 20)
Dengan kurung: (2 + 3) * 4 = 20

Demo Perbandingan Nilai

Pilih operator untuk membandingkan nilai! 🔍

Hasil True dan False

True (Benar)

Hasil perbandingan ketika kondisi terpenuhi. Contoh: 5 > 3 menghasilkan True karena 5 memang lebih besar dari 3.

False (Salah)

Hasil perbandingan ketika kondisi tidak terpenuhi. Contoh: 3 > 5 menghasilkan False karena 3 tidak lebih besar dari 5.

Kesalahan Umum & Cara Menghindarinya

❌ Menggunakan = untuk perbandingan

Salah:

if x = 5: # Error!

Benar:

if x == 5: # Correct!

⚠️ Membandingkan tipe data berbeda

Hati-hati:

"5" == 5 # False (string vs int)

Solusi:

int("5") == 5 # True

💡 Tips Perbandingan Angka Desimal

Hati-hati dengan floating point:

0.1 + 0.2 == 0.3 # False (floating point error)
# Solusi yang benar:
abs((0.1 + 0.2) - 0.3) < 1e-9 # True
# atau gunakan math.isclose()
import math
math.isclose(0.1 + 0.2, 0.3) # True

Perbandingan Berantai (Chaining)

Python memungkinkan perbandingan berantai yang sangat praktis:

Cara Tradisional:

if x > 0 and x < 100:
    print("Valid")

Cara Python (Lebih Elegan):

if 0 < x < 100:
    print("Valid")

Contoh Lainnya:

18 <= umur <= 65 # Usia kerja
0 <= nilai <= 100 # Nilai ujian valid
a < b < c < d # Urutan naik

Contoh Praktis dalam Kehidupan

AND - Semua harus benar

"Kamu bisa main game JIKA sudah mengerjakan PR AND sudah makan"

OR - Salah satu benar

"Kamu bisa masuk kelas JIKA membawa pensil OR membawa pulpen"

"Jika NOT hujan, maka kita bisa bermain di luar"

Hukum De Morgan

Hukum matematika yang sangat berguna untuk menyederhanakan ekspresi logika:

Hukum 1:

not (A and B) = (not A) or (not B)

Negasi dari AND menjadi OR dari negasi masing-masing

Hukum 2:

not (A or B) = (not A) and (not B)

Negasi dari OR menjadi AND dari negasi masing-masing

Contoh Praktis:

# Tidak (hujan DAN dingin) = (tidak hujan) ATAU (tidak dingin)
not (hujan and dingin) == (not hujan) or (not dingin)

Short-Circuit Evaluation

Python menggunakan evaluasi pintas untuk efisiensi:

Operator AND:

False and apapun = False

Jika kondisi pertama False, kondisi kedua tidak dievaluasi

Operator OR:

True or apapun = True

Jika kondisi pertama True, kondisi kedua tidak dievaluasi

Keuntungan:

  • • Program berjalan lebih cepat
  • • Mencegah error (misal: pembagian dengan nol)
  • • Kode lebih aman dan efisien

Operator Logika Lanjutan

🔄 XOR (Exclusive OR)

True jika salah satu True, tapi tidak keduanya:

# XOR manual dengan operator logika
(A and not B) or (not A and B)
# XOR untuk boolean (hanya jika A dan B boolean)
A != B # True XOR False = True, True XOR True = False
# XOR dengan operator bitwise (untuk integer)
A ^ B # 5 ^ 3 = 6

🎯 Operator in dan not in

Mengecek keanggotaan dalam koleksi:

'a' in 'apple' # True
5 not in [1, 2, 3] # True

🔍 Operator is dan is not

Mengecek identitas objek (bukan nilai):

x is None # Mengecek None
x is not None # Mengecek bukan None

💻 Contoh Kode Python Lengkap:

# Contoh penggunaan operator logika
sudah_pr = True
sudah_makan = False
hujan = True

print("=== OPERATOR LOGIKA DASAR ===")
# Operator AND
boleh_main = sudah_pr and sudah_makan
print("Boleh main game:", boleh_main)  # Output: False

# Operator OR
ada_alat_tulis = True or False
print("Ada alat tulis:", ada_alat_tulis)  # Output: True

# Operator NOT
tidak_hujan = not hujan
print("Tidak hujan:", tidak_hujan)  # Output: False

print("\n=== SHORT-CIRCUIT EVALUATION ===")
# AND: jika pertama False, kedua tidak dievaluasi
def fungsi_mahal():
    print("Fungsi ini dipanggil!")
    return True

print("Test AND (False and ...):")
result = False and fungsi_mahal()  # fungsi_mahal() tidak dipanggil
print("Result:", result)

print("\nTest OR (True or ...):")
result = True or fungsi_mahal()  # fungsi_mahal() tidak dipanggil
print("Result:", result)

print("\nTest AND (True and ...):")
result = True and fungsi_mahal()  # fungsi_mahal() AKAN dipanggil
print("Result:", result)

print("\n=== HUKUM DE MORGAN ===")
A, B = True, False
print("not (A and B):", not (A and B))
print("(not A) or (not B):", (not A) or (not B))
print("Sama?", not (A and B) == ((not A) or (not B)))

print("\n=== OPERATOR LANJUTAN ===")
# XOR (Exclusive OR)
def xor(a, b):
    return (a and not b) or (not a and b)

print("XOR(True, False):", xor(True, False))  # True
print("XOR(True, True):", xor(True, True))    # False

# Operator in
buah = ['apel', 'jeruk', 'mangga']
print("'apel' in buah:", 'apel' in buah)  # True
print("'durian' not in buah:", 'durian' not in buah)  # True

# Operator is
x = None
print("x is None:", x is None)  # True
print("x is not None:", x is not None)  # False

print("\n=== CONTOH PRAKTIS ===")
# Validasi login
username = "admin"
password = "12345"
is_admin = username == "admin"
valid_password = len(password) >= 5

if is_admin and valid_password:
    print("Login berhasil sebagai admin!")
elif not is_admin and valid_password:
    print("Login berhasil sebagai user!")
else:
    print("Login gagal!")

# Sistem keamanan
umur = 17

boleh_nyetir = (umur >= 18 and punya_sim) or (umur >= 17 and didampingi)
