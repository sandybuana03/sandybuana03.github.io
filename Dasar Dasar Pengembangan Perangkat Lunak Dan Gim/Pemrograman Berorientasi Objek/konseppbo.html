Pengenalan Paradigma Pemrograman

🤓

Apa itu Paradigma Pemrograman?

Paradigma pemrograman adalah pendekatan atau filosofi dalam menulis dan mengorganisir kode program untuk menyelesaikan masalah. Seperti halnya ada berbagai gaya menulis cerita (novel, puisi, drama), dalam pemrograman juga ada berbagai pendekatan untuk menyelesaikan masalah yang sama.

Analogi Sederhana:

Bayangkan kamu ingin membuat kue. Ada yang suka mengikuti resep step-by-step dari awal sampai akhir (seperti pemrograman prosedural), ada juga yang suka menyiapkan semua bahan dan alat dulu, lalu mengorganisir semuanya dengan rapi sebelum mulai (seperti PBO).

🏛️ Sejarah Singkat:

Era 1950-1960an

Pemrograman prosedural lahir dengan bahasa seperti FORTRAN dan COBOL untuk menyelesaikan perhitungan ilmiah dan bisnis.

Era 1980-1990an

PBO berkembang dengan bahasa seperti C++ dan Java untuk mengatasi kompleksitas software yang semakin besar.

🌍 Paradigma Pemrograman di Dunia Nyata

🏦

Sistem Perbankan

Menggunakan PBO untuk mengelola akun nasabah, transaksi, dan keamanan data dengan konsep class Account, Transaction, dll.

🎮

Game Development

PBO digunakan untuk karakter, item, dan environment. Setiap karakter adalah objek dengan atribut health, speed, dll.

🧮

Kalkulator Ilmiah

Prosedural cocok untuk operasi matematis sederhana yang berurutan dan tidak memerlukan state kompleks.

📝

Pemrograman Prosedural

Pendekatan yang fokus pada langkah-langkah atau prosedur untuk menyelesaikan masalah.

• Kode dijalankan dari atas ke bawah

• Menggunakan fungsi-fungsi

• Sederhana dan mudah dipahami

Contoh Aplikasi:

• Script backup otomatis

• Kalkulator sederhana

• Konversi mata uang

• Pengolahan file batch

🎨

Pemrograman Berorientasi Objek

Pendekatan yang fokus pada objek-objek yang memiliki data dan perilaku.

• Menggunakan class dan object

• Data dan fungsi digabung

• Lebih terorganisir untuk proyek besar

Contoh Aplikasi:

• Sistem manajemen sekolah

• E-commerce platform

• Social media app

• Game RPG

Pemrograman Prosedural

Karakteristik Utama

🔄

Sequential (Berurutan)

Program dijalankan dari atas ke bawah, satu instruksi setelah instruksi lainnya.

⚙️

Function-Based

Menggunakan fungsi-fungsi untuk membagi tugas menjadi bagian-bagian kecil.

📊

Data Terpisah

Data dan fungsi dipisahkan, data sering bersifat global dan dapat diakses dari berbagai fungsi.

🎯

Problem Solving

Fokus pada langkah-langkah untuk menyelesaikan masalah.

🏗️ Struktur Program Prosedural

📋

Komponen Utama:

1. Main Program

Titik awal eksekusi program yang mengatur alur utama

2. Functions/Procedures

Blok kode yang dapat dipanggil untuk tugas spesifik

3. Global Variables

Data yang dapat diakses dari seluruh program

🎯 Prinsip "Divide and Conquer"

Pemrograman prosedural menggunakan pendekatan memecah masalah besar menjadi sub-masalah yang lebih kecil dan mudah dikelola.

Contoh: Program Kasir Toko

• input_barang() - Input data barang

• hitung_total() - Hitung total harga

• hitung_diskon() - Hitung diskon

• cetak_struk() - Cetak struk belanja

Kelebihan & Kekurangan

👍 Kelebihan

✓

✓

🌟 Studi Kasus: Sistem Perpustakaan Sederhana

Skenario:

Membuat program untuk mengelola peminjaman buku di perpustakaan kecil dengan fitur: input buku, cari buku, pinjam buku, dan kembalikan buku.

Struktur Fungsi:

• main() - Menu utama

• input_buku() - Tambah buku baru

• cari_buku() - Cari buku berdasarkan judul

• pinjam_buku() - Proses peminjaman

• kembalikan_buku() - Proses pengembalian

• tampilkan_daftar() - Tampilkan semua buku

Data Global:

• daftar_buku[] - Array buku

• jumlah_buku - Counter buku

• daftar_peminjam[] - Array peminjam

• tanggal_pinjam[] - Array tanggal

💡 Insight:

Dalam pendekatan prosedural, semua data buku dan peminjam disimpan dalam variabel global yang dapat diakses oleh semua fungsi. Ini membuat program sederhana tapi kurang aman untuk data.

Pemrograman Berorientasi Objek

Konsep Dasar PBO

🏗️

Class (Kelas)

Template atau blueprint untuk membuat objek. Seperti denah rumah sebelum rumah dibangun.

Contoh: Class "Mobil" mendefinisikan bahwa setiap mobil punya merk, warna, dan bisa bergerak.

🎯

Object (Objek)

Instance dari class. Seperti rumah yang sudah jadi berdasarkan denah.

Contoh: "mobilSaya" adalah objek dari class Mobil dengan merk Toyota, warna merah.

📦

Attribute (Atribut)

Data atau properti yang dimiliki objek. Seperti warna, ukuran, nama.

Contoh: merk, warna, tahun, kecepatan adalah atribut mobil.

⚡

Method (Metode)

Fungsi atau perilaku yang dapat dilakukan objek. Seperti berjalan, berbicara.

Contoh: start(), stop(), accelerate() adalah method mobil.

🎭 Analogi Dunia Nyata: Sistem Sekolah

Class: Siswa

Atribut: nama, nis, kelas

Method: belajar(), ujian(), absen()

Class: Guru

Atribut: nama, nip, mataPelajaran

Method: mengajar(), nilaiSiswa()

Class: Kelas

Atribut: namaKelas, kapasitas

Method: tambahSiswa(), jadwal()

4 Pilar Utama PBO

🔒

Encapsulation (Enkapsulasi)

Menyembunyikan detail internal objek dan hanya menampilkan yang perlu diakses dari luar.

Contoh:

ATM menyembunyikan proses internal transfer uang. User hanya perlu tahu cara memasukkan PIN dan jumlah uang.

🧬

Inheritance (Pewarisan)

Kemampuan class untuk mewarisi sifat dan perilaku dari class lain (parent class).

Contoh:

Class "Mobil" dan "Motor" mewarisi dari class "Kendaraan" yang punya atribut roda dan method bergerak().

🎭

Polymorphism (Polimorfisme)

Kemampuan objek untuk memiliki banyak bentuk atau perilaku yang berbeda.

Contoh:

Method suara() pada class Hewan: Kucing.suara() = "Meong", Anjing.suara() = "Guk guk".

🎨

Abstraction (Abstraksi)

Menyembunyikan detail implementasi yang kompleks dan hanya menampilkan interface yang sederhana dan penting.

Contoh:

Ketika menggunakan method print(), kita tidak perlu tahu bagaimana komputer menampilkan teks ke layar. Kita hanya perlu tahu cara menggunakannya.

🌟 Studi Kasus: Sistem E-Commerce

Bagaimana 4 pilar PBO diterapkan dalam sistem toko online:

🔒 Encapsulation: Data kartu kredit disembunyikan, hanya method pembayaran yang bisa mengaksesnya.

🧬 Inheritance: Class "ProdukFisik" dan "ProdukDigital" mewarisi dari class "Produk".

🎭 Polymorphism: Method hitungOngkir() berbeda untuk setiap jenis produk.

🎨 Abstraction: User hanya perlu klik "Beli" tanpa tahu proses kompleks di backend.

🏗️ Keuntungan PBO dalam Pengembangan Software

♻️

Reusability

Class yang sudah dibuat bisa digunakan berulang kali di berbagai bagian program atau bahkan proyek lain.

🔧

Maintainability

Perubahan pada satu class tidak mempengaruhi class lain, membuat maintenance lebih mudah.

📈

Scalability

Mudah menambah fitur baru dengan membuat class baru atau mewarisi dari class yang ada.

Contoh Implementasi

📝

Contoh: Menghitung Luas Persegi Panjang (Prosedural)

# Program menghitung luas persegi panjang - Prosedural

def input_data():
    panjang = float(input("Masukkan panjang: "))
    lebar = float(input("Masukkan lebar: "))
    return panjang, lebar

def hitung_luas(panjang, lebar):
    return panjang * lebar

def tampilkan_hasil(panjang, lebar, luas):
    print(f"Panjang: {panjang} cm")
    print(f"Lebar: {lebar} cm")
    print(f"Luas: {luas} cm²")

# Program utama
panjang, lebar = input_data()
luas = hitung_luas(panjang, lebar)
tampilkan_hasil(panjang, lebar, luas)

Karakteristik Prosedural:

• Fungsi terpisah untuk setiap tugas spesifik

• Data dikirim sebagai parameter antar fungsi

• Eksekusi berurutan dari atas ke bawah (sequential)

• Fokus pada "apa yang harus dilakukan" (prosedur)

🎨

Contoh: Menghitung Luas Persegi Panjang (PBO)

# Program menghitung luas persegi panjang - PBO

class PersegiPanjang:
    def __init__(self, panjang, lebar):
        self.panjang = panjang  # Attribute (data)
        self.lebar = lebar      # Attribute (data)
    
    def hitung_luas(self):      # Method (behavior)
        return self.panjang * self.lebar
    
    def hitung_keliling(self):  # Method tambahan
        return 2 * (self.panjang + self.lebar)
    
    def tampilkan_info(self):   # Method (behavior)
        luas = self.hitung_luas()
        keliling = self.hitung_keliling()
        print(f"Panjang: {self.panjang} cm")
        print(f"Lebar: {self.lebar} cm")
        print(f"Luas: {luas} cm²")
        print(f"Keliling: {keliling} cm")

# Membuat objek dan menggunakan
persegi = PersegiPanjang(10, 5)
persegi.tampilkan_info()

Karakteristik PBO:

• Data (attributes) dan method (behavior) dalam satu class

• Objek memiliki state (data) dan behavior (method)

• Encapsulation: data dan fungsi terkait digabung dalam satu unit

• Fokus pada "siapa yang melakukan" (objek dan interaksinya)

Tugas 1: Analisis Kode

Perhatikan kedua contoh kode berikut untuk menghitung keliling lingkaran. Identifikasi mana yang menggunakan pendekatan prosedural dan mana yang menggunakan PBO. Jelaskan alasan kalian! 

# Kode A
import math

def hitung_keliling(radius):
    return 2 * math.pi * radius

radius = 7
keliling = hitung_keliling(radius)
print(f"Keliling: {keliling}")
                                    
# Kode B
import math

class Lingkaran:
    def __init__(self, radius):
        self.radius = radius
    
    def hitung_keliling(self):
        return 2 * math.pi * self.radius

lingkaran = Lingkaran(7)
print(f"Keliling: {lingkaran.hitung_keliling()}")

Kesimpulan Pembelajaran

🎯 Poin Utama:

• Pemrograman Prosedural cocok untuk program sederhana, script otomasi, dan perhitungan matematis dengan fokus pada fungsi dan prosedur

• PBO lebih cocok untuk aplikasi kompleks, sistem besar, dan proyek tim dengan fokus pada objek, encapsulation, inheritance, dan polymorphism

• Kedua paradigma memiliki kelebihan dan kekurangan masing-masing, tidak ada yang "terbaik" secara absolut

• Pemahaman kedua paradigma akan membuat kalian menjadi programmer yang lebih fleksibel dan mampu memilih pendekatan yang tepat

💡 Insight Penting:

"Tidak ada paradigma yang 'terbaik' secara absolut. Yang terbaik adalah paradigma yang paling sesuai dengan masalah yang ingin kalian selesaikan dan konteks proyeknya."
