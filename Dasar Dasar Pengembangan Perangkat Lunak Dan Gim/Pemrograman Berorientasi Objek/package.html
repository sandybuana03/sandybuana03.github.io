Apa itu Package? 🤔

📖 Definisi Package

Package adalah folder yang berisi beberapa file Python (module) yang saling berkaitan dan diorganisir untuk tujuan tertentu. Package membantu kita mengelompokkan kode berdasarkan fungsinya.

Struktur Folder Package 
my_project/
├── main.py
└── matematika/          ← Package
    ├── __init__.py      ← File khusus package
    ├── aritmatika.py    ← Module 1
    ├── geometri.py      ← Module 2
    └── statistik.py     ← Module 3

⚠️ Penting!

File __init__.py wajib ada di setiap package! File ini memberitahu Python bahwa folder tersebut adalah package.

🔍 Jenis-jenis Package

📁 Regular Package

Regular Package Structure 
mypackage/
├── __init__.py    ← Wajib ada!
├── module1.py
├── module2.py
└── subpackage/
    ├── __init__.py ← Wajib juga!
    └── module3.py

Ciri: Memiliki file __init__.py di setiap folder

📂 Namespace Package

Namespace Package Structure 
mypackage/
├── module1.py
├── module2.py
└── subpackage/
    └── module3.py
    
# Tidak ada __init__.py!

Ciri: Tidak memiliki __init__.py (Python 3.3+)

"""
Module untuk operasi aritmatika dasar
"""

def tambah(a, b):
    """
    Menambahkan dua angka
    
    Args:
        a (float): Angka pertama
        b (float): Angka kedua
    
    Returns:
        float: Hasil penjumlahan a + b
    
    Example:
        >>> tambah(5, 3)
        8
    """
    return a + b

def kurang(a, b):
    """Mengurangkan dua angka"""
    return a - b

def kali(a, b):
    """Mengalikan dua angka"""
    return a * b

def bagi(a, b):
    """
    Membagi dua angka
    
    Args:
        a (float): Pembilang
        b (float): Penyebut
    
    Returns:
        float or str: Hasil pembagian atau pesan error
    """
    if b != 0:
        return a / b
    else:
        return "Error: Tidak bisa dibagi nol!"

# Fungsi tambahan
def modulus(a, b):
    """Menghitung sisa bagi"""
    return a % b

def pangkat(a, b):
    """Menghitung a pangkat b"""
    return a ** b

"""
Module untuk operasi matematika lanjutan
"""
import math

def akar_kuadrat(x):
    """Menghitung akar kuadrat"""
    if x >= 0:
        return math.sqrt(x)
    else:
        return "Error: Tidak bisa akar kuadrat bilangan negatif!"

def logaritma(x, base=10):
    """Menghitung logaritma"""
    if x > 0:
        return math.log(x, base)
    else:
        return "Error: Logaritma hanya untuk bilangan positif!"

def faktorial(n):
    """Menghitung faktorial"""
    if n >= 0 and isinstance(n, int):
        return math.factorial(n)
    else:
        return "Error: Faktorial hanya untuk bilangan bulat non-negatif!"

def kombinasi(n, r):
    """Menghitung kombinasi C(n,r)"""
    if n >= r >= 0:
        return faktorial(n) // (faktorial(r) * faktorial(n - r))
    else:
        return "Error: n harus >= r >= 0"

                                        Namespace adalah sistem penamaan yang memungkinkan kita memiliki 
                                        fungsi atau variabel dengan nama yang sama di tempat yang berbeda tanpa konflik.
