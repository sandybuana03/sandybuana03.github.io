Pengenalan Prosedur & Fungsi

Apa itu Prosedur dan Fungsi?

Bayangkan kamu punya resep masakan favorit. Daripada menulis ulang resep itu setiap kali mau masak, lebih baik kamu simpan resepnya di buku khusus, kan? Nah, prosedur dan fungsi itu seperti "buku resep" dalam programming!

📝

Prosedur

Serangkaian instruksi yang melakukan tugas tertentu, tapi tidak mengembalikan nilai

🔄

Fungsi

Seperti prosedur, tapi mengembalikan nilai hasil perhitungan atau proses

Analogi Kehidupan Sehari-hari

🍳

Memasak

Resep = Fungsi
Bahan = Parameter
Masakan = Return Value

🧮

Kalkulator

Tombol = Fungsi
Angka = Parameter
Hasil = Return Value

🏭

Pabrik

Mesin = Fungsi
Bahan Baku = Parameter
Produk = Return Value

Mengapa Penting?

♻️

Reusable

Bisa dipakai berulang kali

🧹

Clean Code

Kode lebih rapi dan terorganisir

🐛

Easy Debug

Mudah mencari dan memperbaiki error

⚡

Efficient

Menghemat waktu dan tenaga

Sejarah Singkat

Konsep fungsi dalam programming terinspirasi dari matematika! Dalam matematika, fungsi f(x) = x² menerima input x dan menghasilkan output x².

📚 Matematika:

f(x) = x² + 2x + 1

f(3) = 9 + 6 + 1 = 16

💻 Programming:

def f(x):

return x**2 + 2*x + 1

f(3) # Output: 16

✅ Dengan Fungsi (Efisien)

dengan_fungsi.py 
def hitung_nilai_akhir(tugas, uts, uas):
    """Menghitung nilai akhir dengan bobot:
    Tugas: 30%, UTS: 30%, UAS: 40%"""
    return (tugas * 0.3) + (uts * 0.3) + (uas * 0.4)

# Penggunaan - jauh lebih simple!
siswa1 = hitung_nilai_akhir(85, 78, 82)
siswa2 = hitung_nilai_akhir(90, 85, 88)
siswa3 = hitung_nilai_akhir(75, 80, 85)

print(f"Nilai Akhir Siswa 1: {siswa1}")
print(f"Nilai Akhir Siswa 2: {siswa2}")
print(f"Nilai Akhir Siswa 3: {siswa3}")

# Hanya 10 baris untuk 100 siswa! 🎉

Struktur Dasar Fungsi Python

struktur_fungsi.py 
# Struktur dasar fungsi Python
def nama_fungsi(parameter1, parameter2):
    """
    Docstring: Penjelasan fungsi (opsional tapi direkomendasikan)
    """
    # Kode yang akan dijalankan
    hasil = parameter1 + parameter2
    
    # Mengembalikan nilai (opsional)
    return hasil

# Cara memanggil fungsi
hasil_penjumlahan = nama_fungsi(5, 3)
print(hasil_penjumlahan)  # Output: 8

🔍 Penjelasan Komponen:

  • def: Kata kunci untuk mendefinisikan fungsi
  • nama_fungsi: Nama yang akan digunakan untuk memanggil fungsi
  • parameter: Input yang diterima fungsi (opsional)
  • docstring: Dokumentasi fungsi (best practice)
  • return: Mengembalikan nilai hasil (opsional)

Memahami Prosedur

Apa itu Prosedur?

Prosedur adalah sekumpulan instruksi yang diberi nama dan dapat dipanggil kapan saja. Prosedur melakukan tugas tertentu tapi tidak mengembalikan nilai (atau mengembalikan None).

Ciri-ciri Prosedur:

  • • Menggunakan kata kunci def
  • • Tidak menggunakan return atau return None
  • • Fokus pada melakukan aksi/tindakan
  • • Biasanya untuk output, manipulasi data, atau efek samping

Jenis-jenis Prosedur

🖨️

Output Prosedur

Menampilkan informasi ke layar atau file

🔧

Manipulation Prosedur

Mengubah data atau variabel global

⚙️

Control Prosedur

Mengatur alur program atau sistem

Contoh Prosedur Sederhana

prosedur_salam.py 
def sapa_siswa(nama):
    """Prosedur untuk menyapa siswa"""
    print(f"Halo {nama}! Selamat belajar Python! 🐍")
    print("Semangat ya belajarnya!")

def sapa_dengan_waktu(nama, waktu):
    """Prosedur sapa dengan waktu"""
    if waktu == "pagi":
        print(f"Selamat pagi, {nama}! ☀️")
    elif waktu == "siang":
        print(f"Selamat siang, {nama}! 🌞")
    elif waktu == "malam":
        print(f"Selamat malam, {nama}! 🌙")
    else:
        print(f"Halo, {nama}! 👋")

# Memanggil prosedur
sapa_siswa("Budi")
sapa_dengan_waktu("Sari", "pagi")

Prosedur untuk Manipulasi Data

prosedur_data.py 
# Daftar siswa global
daftar_siswa = []

def tambah_siswa(nama, kelas):
    """Prosedur untuk menambah siswa ke daftar"""
    siswa_baru = {"nama": nama, "kelas": kelas}
    daftar_siswa.append(siswa_baru)
    print(f"✅ {nama} berhasil ditambahkan ke kelas {kelas}")

def tampilkan_semua_siswa():
    """Prosedur untuk menampilkan semua siswa"""
    if not daftar_siswa:
        print("📝 Belum ada siswa yang terdaftar")
        return
    
    print("📚 DAFTAR SISWA:")
    print("-" * 25)
    for i, siswa in enumerate(daftar_siswa, 1):
        print(f"{i}. {siswa['nama']} - Kelas {siswa['kelas']}")

def hapus_siswa(nama):
    """Prosedur untuk menghapus siswa dari daftar"""
    for siswa in daftar_siswa:
        if siswa['nama'].lower() == nama.lower():
            daftar_siswa.remove(siswa)
            print(f"❌ {nama} berhasil dihapus dari daftar")
            return
    print(f"⚠️ Siswa dengan nama {nama} tidak ditemukan")

# Contoh penggunaan
tambah_siswa("Budi", "XI RPL")
tambah_siswa("Sari", "XI TKJ")
tampilkan_semua_siswa()

Memahami Fungsi

Apa itu Fungsi?

Fungsi adalah prosedur yang mengembalikan nilai. Seperti mesin yang menerima input, memproses, dan menghasilkan output yang bisa kita gunakan.

Ciri-ciri Fungsi:

  • • Menggunakan kata kunci def
  • • Menggunakan return untuk mengembalikan nilai
  • • Hasil dapat disimpan dalam variabel
  • • Fokus pada menghasilkan nilai/hasil perhitungan

Contoh Fungsi Matematika

fungsi_matematika.py 
def hitung_luas_lingkaran(jari_jari):
    """Fungsi untuk menghitung luas lingkaran"""
    pi = 3.14159
    luas = pi * jari_jari * jari_jari
    return luas

def hitung_keliling_lingkaran(jari_jari):
    """Fungsi untuk menghitung keliling lingkaran"""
    pi = 3.14159
    keliling = 2 * pi * jari_jari
    return keliling

# Contoh penggunaan
r = 7
luas = hitung_luas_lingkaran(r)
keliling = hitung_keliling_lingkaran(r)

print(f"Jari-jari: {r} cm")
print(f"Luas: {luas:.2f} cm²")
print(f"Keliling: {keliling:.2f} cm")

Fungsi dengan Logika Kondisional

fungsi_nilai.py 
def tentukan_grade(nilai):
    """Fungsi untuk menentukan grade berdasarkan nilai"""
    if nilai >= 90:
        return "A"
    elif nilai >= 80:
        return "B"
    elif nilai >= 70:
        return "C"
    elif nilai >= 60:
        return "D"
    else:
        return "E"

def status_kelulusan(nilai):
    """Fungsi untuk menentukan status kelulusan"""
    if nilai >= 70:
        return "LULUS 🎉"
    else:
        return "BELUM LULUS 😔"

# Contoh penggunaan
nilai_siswa = 85
grade = tentukan_grade(nilai_siswa)
status = status_kelulusan(nilai_siswa)

print(f"Nilai: {nilai_siswa}")
print(f"Grade: {grade}")
print(f"Status: {status}")

Perbedaan Prosedur vs Fungsi

📝 Prosedur

  • • Tidak return nilai
  • • Fokus pada aksi/tindakan
  • • Contoh: print, input, file operations
  • • Hasil tidak bisa disimpan

🔄 Fungsi

  • • Return nilai
  • • Fokus pada perhitungan/hasil
  • • Contoh: matematika, konversi
  • • Hasil bisa disimpan & digunakan

Parameter & Argumen

Apa itu Parameter dan Argumen?

Parameter adalah "tempat" untuk menerima data dalam fungsi. Argumen adalah data yang kita berikan saat memanggil fungsi.

📥 Parameter

Variabel dalam definisi fungsi yang menerima nilai

def fungsi(parameter):

📤 Argumen

Nilai yang diberikan saat memanggil fungsi

fungsi(argumen)

Jenis-jenis Parameter

1. Parameter Wajib (Required)

parameter_wajib.py 
def perkenalan(nama, umur):
    return f"Halo, saya {nama}, umur {umur} tahun"

# Harus memberikan semua parameter
hasil = perkenalan("Budi", 17)
print(hasil)

2. Parameter Default

parameter_default.py 
def sapa(nama, sapaan="Halo"):
    return f"{sapaan}, {nama}!"

# Bisa pakai default atau ganti
print(sapa("Sari"))              # Halo, Sari!
print(sapa("Andi", "Selamat pagi"))  # Selamat pagi, Andi!

3. Keyword Arguments

keyword_args.py 
def info_siswa(nama, kelas, jurusan="Umum"):
    return f"{nama} - Kelas {kelas} - Jurusan {jurusan}"

# Berbagai cara pemanggilan
print(info_siswa("Maya", "XI"))
print(info_siswa("Doni", kelas="XII", jurusan="RPL"))
print(info_siswa(jurusan="TKJ", nama="Lina", kelas="X"))

Multiple Parameters & Return Values

multiple_params.py 
def hitung_statistik(angka1, angka2, angka3):
    """Fungsi menghitung berbagai statistik dari 3 angka"""
    total = angka1 + angka2 + angka3
    rata_rata = total / 3
    maksimum = max(angka1, angka2, angka3)
    minimum = min(angka1, angka2, angka3)
    
    # Return multiple values sebagai tuple
    return total, rata_rata, maksimum, minimum

# Contoh penggunaan
a, b, c = 85, 92, 78
total, rata, maks, mins = hitung_statistik(a, b, c)

print(f"Angka: {a}, {b}, {c}")
print(f"Total: {total}")
print(f"Rata-rata: {rata:.2f}")
print(f"Maksimum: {maks}")
print(f"Minimum: {mins}")

Scope Variabel

Apa itu Scope?

Scope adalah "wilayah" di mana variabel bisa diakses. Seperti ruang kelas - ada yang hanya bisa diakses di dalam kelas, ada yang bisa diakses di seluruh sekolah.

🏠 Local Scope

Variabel yang dibuat di dalam fungsi, hanya bisa diakses di dalam fungsi tersebut

🌍 Global Scope

Variabel yang dibuat di luar fungsi, bisa diakses dari mana saja

Contoh Local vs Global Scope

scope_example.py 
# Variabel global
nama_sekolah = "SMK Nusantara"  # Bisa diakses dimana saja

def info_siswa():
    # Variabel lokal
    nama_siswa = "Budi"  # Hanya bisa diakses di dalam fungsi ini
    kelas = "XI RPL"
    
    print(f"Siswa: {nama_siswa}")
    print(f"Kelas: {kelas}")
    print(f"Sekolah: {nama_sekolah}")  # Bisa akses variabel global

def info_guru():
    nama_guru = "Pak Andi"  # Variabel lokal berbeda
    print(f"Guru: {nama_guru}")
    print(f"Sekolah: {nama_sekolah}")  # Bisa akses variabel global
    # print(nama_siswa)  # ERROR! Tidak bisa akses variabel lokal fungsi lain

# Pemanggilan
info_siswa()
print("---")
info_guru()
print(f"Sekolah: {nama_sekolah}")  # Bisa akses variabel global
# print(nama_siswa)  # ERROR! Tidak bisa akses variabel lokal

Mengubah Variabel Global

global_keyword.py 
# Variabel global
skor_total = 0

def tambah_skor(poin):
    global skor_total  # Kata kunci untuk mengubah variabel global
    skor_total += poin
    print(f"Skor ditambah {poin}. Total sekarang: {skor_total}")

def reset_skor():
    global skor_total
    skor_total = 0
    print("Skor direset ke 0")

def tampilkan_skor():
    print(f"Skor saat ini: {skor_total}")

# Contoh penggunaan
tampilkan_skor()    # Skor saat ini: 0
tambah_skor(10)     # Skor ditambah 10. Total sekarang: 10
tambah_skor(25)     # Skor ditambah 25. Total sekarang: 35
tampilkan_skor()    # Skor saat ini: 35
reset_skor()        # Skor direset ke 0

⚠️ Hal Penting tentang Scope

❌ Yang Harus Dihindari

  • • Jangan terlalu banyak menggunakan variabel global
  • • Hindari nama variabel yang sama di scope berbeda
  • • Jangan lupa kata kunci global saat mengubah variabel global

✅ Best Practice

  • • Gunakan parameter untuk mengirim data ke fungsi
  • • Gunakan return untuk mengembalikan hasil
  • • Buat nama variabel yang jelas dan berbeda
  • • Minimalisir penggunaan variabel global

Tugas Praktik

Saatnya menguji pemahamanmu! Kerjakan tugas-tugas berikut dengan teliti.

Tugas 1: Membuat Prosedur Sederhana

Soal: Buatlah prosedur bernama tampilkan_biodata yang menerima parameter nama, umur, dan hobi. Prosedur ini harus menampilkan biodata dalam format yang rapi.

Contoh output:

=== BIODATA ===
Nama : Budi Santoso
Umur : 17 tahun
Hobi : Bermain game
===============

Tugas 2: Membuat Fungsi Matematika

Soal: Buatlah fungsi bernama hitung_diskon yang menerima parameter harga_asli dan persen_diskon. Fungsi ini harus mengembalikan harga setelah diskon.

Rumus: harga_diskon = harga_asli - (harga_asli × persen_diskon / 100)

Contoh: hitung_diskon(100000, 20) → 80000

Tugas 3: Fungsi dengan Logika

Soal: Buatlah fungsi bernama kategori_umur yang menerima parameter umur dan mengembalikan kategori berdasarkan aturan:

  • • 0-12 tahun: "Anak-anak"
  • • 13-17 tahun: "Remaja"
  • • 18-59 tahun: "Dewasa"
  • • 60+ tahun: "Lansia"

Tugas Bonus: Kalkulator Sederhana

Soal: Buatlah fungsi kalkulator yang menerima 3 parameter: angka1, operator (string), dan angka2. Fungsi harus mengembalikan hasil operasi atau pesan error jika operator tidak valid.

Operator yang didukung: "+", "-", "*", "/"

Contoh: kalkulator(10, "+", 5) → 15
