Pengenalan Reuse Kode 📚

Mengapa reuse kode penting dalam programming?

Apa itu Reuse Kode?

Reuse Kode (Code Reuse) adalah praktik menggunakan kembali kode yang sudah ada untuk menyelesaikan masalah yang serupa, tanpa perlu menulis ulang dari awal.

Analogi: Seperti menggunakan template surat yang sudah ada, tinggal ganti nama dan alamat. Tidak perlu menulis format surat dari awal! 📝

Mengapa Reuse Kode Penting?

Menghemat Waktu

Tidak perlu menulis kode yang sama berulang kali. Fokus pada fitur baru!

Mengurangi Bug

Kode yang sudah teruji lebih reliable daripada menulis ulang.

Mudah Maintenance

Update sekali, berlaku di semua tempat yang menggunakan kode tersebut.

Konsistensi

Semua bagian aplikasi menggunakan standar yang sama.

Inheritance sebagai Solusi

Dalam Python, Inheritance (Pewarisan) adalah mekanisme dimana sebuah class (child/subclass) dapat mewarisi atribut dan method dari class lain (parent/superclass). Dengan inheritance, kita bisa:

Berbagi Kode

Parent class menyediakan kode umum

Menambah Fitur

Child class menambah fitur spesifik

Modifikasi

Override method sesuai kebutuhan

Kode dengan Inheritance (Efisien!)

Python kode_efisien.py 
# DENGAN INHERITANCE - Kode efisien dan rapi! 🎉

# Parent Class - Semua kode umum di sini
class Hewan:
    def __init__(self, nama, umur):
        self.nama = nama
        self.umur = umur
        self.bernapas = "Paru-paru"
    
    def makan(self):  # ← Ditulis sekali, dipakai semua child
        print(f"{self.nama} sedang makan")
    
    def tidur(self):  # ← Ditulis sekali, dipakai semua child
        print(f"{self.nama} sedang tidur")
    
    def bergerak(self):  # ← Ditulis sekali, dipakai semua child
        print(f"{self.nama} sedang bergerak")
    
    def info(self):
        return f"{self.nama} adalah hewan berumur {self.umur} tahun"

# Child Classes - Hanya kode spesifik
class Kucing(Hewan):  # ← Mewarisi semua dari Hewan
    def __init__(self, nama, umur):
        super().__init__(nama, umur)
        self.jenis = "Mamalia"
    
    def bersuara(self):  # ← Hanya method unik
        print(f"{self.nama} mengeong")
    
    def memanjat(self):  # ← Method khusus kucing
        print(f"{self.nama} memanjat pohon")

class Anjing(Hewan):  # ← Mewarisi semua dari Hewan
    def __init__(self, nama, umur):
        super().__init__(nama, umur)
        self.jenis = "Mamalia"
    
    def bersuara(self):  # ← Hanya method unik
        print(f"{self.nama} menggonggong")
    
    def menjaga(self):  # ← Method khusus anjing
        print(f"{self.nama} menjaga rumah")

class Burung(Hewan):  # ← Mewarisi semua dari Hewan
    def __init__(self, nama, umur):
        super().__init__(nama, umur)
        self.jenis = "Aves"
    
    def bersuara(self):  # ← Hanya method unik
        print(f"{self.nama} berkicau")
    
    def terbang(self):  # ← Method khusus burung
        print(f"{self.nama} sedang terbang")

🎉 Keajaiban Inheritance:

  • • Method makan(), tidur(), bergerak(), info() hanya ditulis SEKALI di parent!
  • • Setiap child class otomatis punya akses ke semua method parent
  • • Total kode berkurang dari ~60 baris menjadi ~40 baris (33% lebih efisien)
  • • Update method parent = otomatis berlaku untuk semua child
  • • Child class fokus hanya pada fitur unik mereka
  • • Konsistensi interface - semua hewan punya method yang sama

Studi Kasus: Sistem Toko Online

Python toko_online.py 
# Parent Class - Produk Umum
class Produk:
    def __init__(self, nama, harga, stok):
        self.nama = nama
        self.harga = harga
        self.stok = stok
        self.terjual = 0
    
    def info_dasar(self):
        return f"{self.nama} - Rp{self.harga:,}"
    
    def cek_stok(self):
        return self.stok > 0
    
    def jual(self, jumlah=1):
        if self.stok >= jumlah:
            self.stok -= jumlah
            self.terjual += jumlah
            return True
        return False
    
    def hitung_total(self, jumlah):
        return self.harga * jumlah

# Child Class - Buku
class Buku(Produk):
    def __init__(self, nama, harga, stok, penulis, halaman):
        super().__init__(nama, harga, stok)
        self.penulis = penulis
        self.halaman = halaman
        self.kategori = "Buku"
    
    def info_lengkap(self):
        return f"{self.info_dasar()} | Penulis: {self.penulis}"
    
    def diskon_pelajar(self):
        return self.harga * 0.9  # Diskon 10%

# Child Class - Elektronik
class Elektronik(Produk):
    def __init__(self, nama, harga, stok, merk, garansi):
        super().__init__(nama, harga, stok)
        self.merk = merk
        self.garansi = garansi
        self.kategori = "Elektronik"
    
    def info_lengkap(self):
        return f"{self.info_dasar()} | Merk: {self.merk}"
    
    def hitung_total(self, jumlah):  # Override untuk pajak
        subtotal = super().hitung_total(jumlah)
        pajak = subtotal * 0.1  # Pajak 10%
        return subtotal + pajak

Contoh Penggunaan dan Output:

Python Melanjutkan kode di atas... 
# Membuat instance produk
buku1 = Buku("Python untuk Pemula", 75000, 20, "Dr. Budi", 300)
elektronik1 = Elektronik("Smartphone XYZ", 2500000, 10, "TechBrand", "2 tahun")

print("=== Informasi Produk ===")
print("Buku:", buku1.info_lengkap())  # Method khusus + method parent
print("Elektronik:", elektronik1.info_lengkap())  # Method khusus + method parent

print("\n=== Cek Stok (Method dari Parent) ===")
print(f"Buku tersedia: {buku1.cek_stok()}")  # Method dari parent class
print(f"Elektronik tersedia: {elektronik1.cek_stok()}")  # Method dari parent class

print("\n=== Simulasi Penjualan ===")
# Jual buku (menggunakan method parent)
if buku1.jual(3):  # Method dari parent class
    print(f"Berhasil jual 3 buku. Sisa stok: {buku1.stok}")
else:
    print("Stok tidak cukup!")

# Jual elektronik (menggunakan method parent)
if elektronik1.jual(1):  # Method dari parent class
    print(f"Berhasil jual 1 elektronik. Sisa stok: {elektronik1.stok}")

print("\n=== Perhitungan Total (Method Override) ===")
# Buku menggunakan method parent (tanpa pajak)
total_buku = buku1.hitung_total(2)  # Method dari parent
print(f"Total 2 buku: Rp{total_buku:,}")

# Elektronik menggunakan method override (dengan pajak)
total_elektronik = elektronik1.hitung_total(1)  # Method override
print(f"Total 1 elektronik (+ pajak): Rp{total_elektronik:,}")

print("\n=== Fitur Khusus Setiap Class ===")
# Method khusus buku
harga_diskon = buku1.diskon_pelajar()  # Method khusus Buku
print(f"Harga buku dengan diskon pelajar: Rp{harga_diskon:,}")

# Akses atribut khusus
print(f"Garansi elektronik: {elektronik1.garansi}")  # Atribut khusus Elektronik
print(f"Halaman buku: {buku1.halaman}")  # Atribut khusus Buku

  • • Parent class "Item" dengan atribut: judul, tahun_terbit, tersedia (boolean)

📋 Kriteria Penilaian:

  • • Penggunaan inheritance yang benar (25%)

💡 Tips Pengerjaan:

  • • Mulai dengan merancang parent class dulu

  • • Gunakan super() untuk memanggil parent constructor
  • • Beri nama method yang descriptive
  • • Tambahkan docstring untuk dokumentasi
  • • Test semua method yang dibuat
