Pemahaman Bermakna

Motivasi

Pengenalan OOP Python 📚

Apa itu Object-Oriented Programming (OOP)?

OOP adalah paradigma pemrograman yang mengorganisir kode berdasarkan konsep "objek". Bayangkan kamu punya mainan mobil-mobilan. Setiap mobil punya ciri-ciri (warna, merek) dan kemampuan (berjalan, klakson). Dalam OOP, ciri-ciri disebut atribut dan kemampuan disebut method! 🚗

Analogi Sederhana:

  • 🏠 Class = Blueprint/denah rumah
  • 🏡 Object = Rumah yang sudah jadi
  • 🎨 Atribut = Warna cat, jumlah kamar
  • 🔧 Method = Buka pintu, nyalakan lampu

🌍 Contoh OOP dalam Kehidupan Sehari-hari:

📱 Smartphone:
  • • Atribut: merek, warna, RAM, storage
  • • Method: telepon(), kirimPesan(), foto()
🎮 Karakter Game:
  • • Atribut: nama, level, HP, MP
  • • Method: serang(), lari(), gunakan_item()
🏦 Akun Bank:
  • • Atribut: nomor_rekening, saldo, pemilik
  • • Method: setor(), tarik(), cek_saldo()
📚 Buku:
  • • Atribut: judul, pengarang, halaman
  • • Method: buka(), tutup(), bookmark()

# Membuat class Mobil
class Mobil:
    # Constructor untuk inisialisasi atribut
    def __init__(self, warna, merek):
        self.warna = warna    # Atribut instance - warna mobil
        self.merek = merek    # Atribut instance - merek mobil
        self.kecepatan = 0    # Atribut instance - kecepatan awal
    
    # Method untuk menampilkan info mobil
    def info_mobil(self):
        print(f"Mobil {self.merek} berwarna {self.warna}")
        print(f"Kecepatan saat ini: {self.kecepatan} km/h")
    
    # Method untuk menjalankan mobil
    def jalan(self, kecepatan):
        self.kecepatan = kecepatan
        print(f"Mobil {self.merek} berjalan dengan kecepatan {kecepatan} km/h 🚗")
    
    # Method untuk klakson
    def klakson(self):
        print("Tin tin! 📯")
    
    # Method untuk berhenti
    def berhenti(self):
        self.kecepatan = 0
        print(f"Mobil {self.merek} berhenti")

# Membuat objek mobil (instansiasi)
mobil_saya = Mobil("merah", "Toyota")
mobil_teman = Mobil("biru", "Honda")

# Menggunakan method
mobil_saya.info_mobil()     # Menampilkan info
mobil_saya.jalan(60)        # Menjalankan mobil
mobil_saya.klakson()        # Membunyikan klakson
mobil_saya.berhenti()       # Menghentikan mobil

Atribut (Data) 📊

Apa itu Atribut?

Atribut adalah variabel yang menyimpan data atau karakteristik yang dimiliki oleh suatu objek. Seperti manusia punya nama, umur, tinggi badan - itulah atribut! Atribut mendefinisikan keadaan (state) dari objek. 👤

Contoh Atribut dalam Kehidupan:

🚗 Mobil:
  • • Warna
  • • Merek
  • • Tahun
👤 Siswa:
  • • Nama
  • • Kelas
  • • Nilai
📱 HP:
  • • Merek
  • • RAM
  • • Storage

Cara Membuat Atribut di Python

Python - atribut_dasar.py 
class Siswa:
    def __init__(self, nama, kelas, umur):
        # Ini adalah atribut instance
        self.nama = nama      # Atribut nama
        self.kelas = kelas    # Atribut kelas  
        self.umur = umur      # Atribut umur
        self.nilai = []       # Atribut nilai (list kosong)

# Membuat objek siswa
siswa1 = Siswa("Budi", "XII RPL", 17)
siswa2 = Siswa("Sari", "XII TKJ", 16)

# Mengakses atribut
print(f"Nama: {siswa1.nama}")     # Output: Nama: Budi
print(f"Kelas: {siswa1.kelas}")   # Output: Kelas: XII RPL
print(f"Umur: {siswa1.umur}")     # Output: Umur: 17

💡 Penjelasan Kode:

  • • __init__ adalah method khusus untuk inisialisasi objek
  • • self merujuk pada objek yang sedang dibuat
  • • self.nama artinya atribut nama milik objek ini
  • • Setiap objek punya atribut yang bisa berbeda-beda

Jenis-jenis Atribut

Instance Attribute (Atribut Instansi)

Atribut yang unik untuk setiap objek. Setiap objek bisa punya nilai berbeda.

class Mobil:
    def __init__(self, merek, warna):
        self.merek = merek    # Instance attribute
        self.warna = warna    # Instance attribute

# Setiap mobil punya merek dan warna berbeda
mobil1 = Mobil("Toyota", "merah")
mobil2 = Mobil("Honda", "biru")
Contoh: Nama siswa, umur, nilai - setiap siswa punya data yang berbeda

Class Attribute (Atribut Kelas)

Atribut yang sama untuk semua objek dari class yang sama.

class Siswa:
    sekolah = "SMK Nusantara"     # Class attribute - sama untuk semua siswa
    jumlah_siswa = 0              # Class attribute - counter siswa
    
    def __init__(self, nama):
        self.nama = nama          # Instance attribute - unik per siswa
        Siswa.jumlah_siswa += 1   # Increment counter saat siswa baru dibuat

# Membuat objek siswa
siswa1 = Siswa("Budi")
siswa2 = Siswa("Sari")

# Mengakses class attribute
print(siswa1.sekolah)         # SMK Nusantara
print(siswa2.sekolah)         # SMK Nusantara
print(Siswa.jumlah_siswa)     # 2 (total siswa yang dibuat)

# Class attribute bisa diakses dari class langsung
print(Siswa.sekolah)          # SMK Nusantara
Contoh: Nama sekolah, alamat sekolah - sama untuk semua siswa

Private Attribute (Atribut Privat)

Atribut yang tidak bisa diakses langsung dari luar class (dimulai dengan underscore).

class BankAccount:
    def __init__(self, saldo):
        self._saldo = saldo        # Protected (1 underscore)
        self.__pin = "1234"        # Private (2 underscore)
    
    def cek_saldo(self):
        return self._saldo

akun = BankAccount(1000000)
print(akun.cek_saldo())    # OK: 1000000
# print(akun.__pin)        # Error: tidak bisa diakses
Kegunaan: Melindungi data sensitif seperti password, PIN, atau data internal

Method (Perilaku) ⚙️

Apa itu Method?

Method adalah fungsi yang didefinisikan di dalam class dan menentukan perilaku atau aksi yang bisa dilakukan oleh objek. Seperti manusia bisa berjalan, berbicara, makan - itulah method! Method dapat mengakses dan memodifikasi atribut objek. 🚶‍♂️

Contoh Method dalam Kehidupan:

🚗 Mobil:
  • • Nyalakan mesin
  • • Berjalan
  • • Berhenti
👤 Siswa:
  • • Belajar
  • • Mengerjakan tugas
  • • Presentasi
📱 HP:
  • • Telepon
  • • Kirim pesan
  • • Foto

Cara Membuat Method di Python

Python - method_dasar.py 
class Siswa:
    def __init__(self, nama, kelas):
        self.nama = nama          # Atribut nama siswa
        self.kelas = kelas        # Atribut kelas siswa
        self.nilai = []           # Atribut list nilai (kosong di awal)
        self.hadir = 0            # Atribut jumlah kehadiran
    
    # Method untuk menambah nilai
    def tambah_nilai(self, mata_pelajaran, nilai):
        if 0 <= nilai <= 100:    # Validasi nilai
            self.nilai.append({
                'mapel': mata_pelajaran,
                'nilai': nilai
            })
            print(f"✅ Nilai {mata_pelajaran}: {nilai} berhasil ditambahkan!")
        else:
            print("❌ Nilai harus antara 0-100!")
    
    # Method untuk melihat semua nilai
    def lihat_nilai(self):
        print(f"\n=== Nilai {self.nama} ===")
        if not self.nilai:
            print("Belum ada nilai")
        else:
            total = 0
            for n in self.nilai:
                print(f"{n['mapel']}: {n['nilai']}")
                total += n['nilai']
            rata_rata = total / len(self.nilai)
            print(f"Rata-rata: {rata_rata:.1f}")
    
    # Method untuk perkenalan
    def perkenalan(self):
        print(f"Halo! Nama saya {self.nama} dari kelas {self.kelas} 👋")
    
    # Method untuk absensi
    def absen(self):
        self.hadir += 1
        print(f"{self.nama} hadir. Total kehadiran: {self.hadir}")

# Menggunakan method
siswa = Siswa("Andi", "XII RPL")
siswa.perkenalan()                    # Method tanpa parameter
siswa.tambah_nilai("Python", 90)      # Method dengan parameter
siswa.tambah_nilai("Database", 85)    # Method dengan parameter
siswa.tambah_nilai("Web", 110)        # Test validasi
siswa.lihat_nilai()                   # Method yang menghitung
siswa.absen()                         # Method yang mengubah atribut

💡 Penjelasan Method:

  • • Method adalah fungsi yang ada di dalam class
  • • Parameter pertama selalu self (merujuk objek)
  • • Method bisa menerima parameter tambahan
  • • Method bisa mengubah atribut objek

Hasil Perhitungan:

Jenis-jenis Method

Instance Method

Method yang bekerja dengan data objek (paling umum). Bisa mengakses dan mengubah atribut.

def perkenalan(self):
    print(f"Halo, nama saya {self.nama}")
    
def ubah_nama(self, nama_baru):
    self.nama = nama_baru
Ciri: Parameter pertama selalu self

Class Method

Method yang bekerja dengan class, bukan objek individual. Menggunakan decorator @classmethod.

class Siswa:
    jumlah_siswa = 0
    
    @classmethod
    def tambah_siswa(cls):
        cls.jumlah_siswa += 1
        
    @classmethod
    def get_jumlah_siswa(cls):
        return cls.jumlah_siswa
Ciri: Parameter pertama cls, bisa dipanggil tanpa membuat objek

Static Method

Method yang tidak tergantung pada class atau objek. Seperti fungsi biasa tapi ada di dalam class.

class MathUtils:
    @staticmethod
    def tambah(a, b):
        return a + b
    
    @staticmethod
    def is_genap(angka):
        return angka % 2 == 0
    
    @staticmethod
    def faktorial(n):
        if n <= 1:
            return 1
        return n * MathUtils.faktorial(n - 1)

# Bisa dipanggil tanpa membuat objek
hasil = MathUtils.tambah(5, 3)        # 8
genap = MathUtils.is_genap(4)         # True
fakto = MathUtils.faktorial(5)        # 120

print(f"5 + 3 = {hasil}")
print(f"4 adalah genap: {genap}")
print(f"5! = {fakto}")
Ciri: Tidak ada parameter self atau cls

Special Method (Magic Method)

Method khusus yang dimulai dan diakhiri dengan double underscore (__). Dipanggil otomatis oleh Python.

class Siswa:
    def __init__(self, nama):      # Constructor
        self.nama = nama
    
    def __str__(self):             # String representation
        return f"Siswa: {self.nama}"
    
    def __len__(self):             # Length
        return len(self.nama)

siswa = Siswa("Budi")
print(siswa)        # Otomatis panggil __str__
print(len(siswa))   # Otomatis panggil __len__
Contoh lain: __add__, __eq__, __lt__, __getitem__, __setitem__

Property Method

Method yang bisa diakses seperti atribut, tapi sebenarnya adalah fungsi. Untuk kontrol akses data.

class Lingkaran:
    def __init__(self, radius):
        self._radius = radius
    
    @property
    def luas(self):                # Getter
        return 3.14 * self._radius ** 2
    
    @property
    def radius(self):
        return self._radius
    
    @radius.setter                 # Setter
    def radius(self, nilai):
        if nilai > 0:
            self._radius = nilai

lingkaran = Lingkaran(5)
print(lingkaran.luas)      # Akses seperti atribut
lingkaran.radius = 10      # Set seperti atribut
Kegunaan: Validasi data, computed properties, backward compatibility

Python - perpustakaan.py 
class Buku:
    # Class attribute untuk tracking total buku
    total_buku = 0
    
    def __init__(self, judul, pengarang, tahun, isbn=None):
        # Atribut instance
        self.judul = judul
        self.pengarang = pengarang
        self.tahun = tahun
        self.isbn = isbn or f"ISBN-{Buku.total_buku + 1:04d}"
        self.tersedia = True      # Status ketersediaan
        self.peminjam = None      # Siapa yang meminjam
        self.tanggal_pinjam = None # Kapan dipinjam
        
        # Increment total buku
        Buku.total_buku += 1
    
    # Method untuk info buku
    def info_buku(self):
        status = "Tersedia" if self.tersedia else f"Dipinjam oleh {self.peminjam}"
        print(f"""
📖 === INFO BUKU ===
Judul: {self.judul}
Pengarang: {self.pengarang}
Tahun: {self.tahun}
ISBN: {self.isbn}
Status: {status}
        """)
    
    # Method untuk meminjam buku
    def pinjam(self, nama_peminjam):
        if self.tersedia:
            self.tersedia = False
            self.peminjam = nama_peminjam
            from datetime import datetime
            self.tanggal_pinjam = datetime.now().strftime("%Y-%m-%d")
            print(f"✅ Buku '{self.judul}' berhasil dipinjam oleh {nama_peminjam}")
            return True
        else:
            print(f"❌ Maaf, buku '{self.judul}' sedang dipinjam oleh {self.peminjam}")
            return False
    
    # Method untuk mengembalikan buku
    def kembalikan(self):
        if not self.tersedia:
            print(f"✅ Buku '{self.judul}' berhasil dikembalikan oleh {self.peminjam}")
            self.tersedia = True
            self.peminjam = None
            self.tanggal_pinjam = None
            return True
        else:
            print(f"❌ Buku '{self.judul}' tidak sedang dipinjam")
            return False
    
    # Method untuk representasi string
    def __str__(self):
        return f"{self.judul} - {self.pengarang} ({self.tahun})"

class Anggota:
    # Class attribute
    total_anggota = 0
    maksimal_pinjam = 3
    
    def __init__(self, nama, nomor_anggota=None):
        # Atribut instance
        self.nama = nama
        self.nomor_anggota = nomor_anggota or f"A{Anggota.total_anggota + 1:03d}"
        self.buku_dipinjam = []   # List objek buku yang dipinjam
        self.riwayat_pinjam = []  # Riwayat semua peminjaman
        
        # Increment total anggota
        Anggota.total_anggota += 1
    
    # Method untuk info anggota
    def info_anggota(self):
        print(f"""
👤 === INFO ANGGOTA ===
Nama: {self.nama}
Nomor Anggota: {self.nomor_anggota}
Jumlah Buku Dipinjam: {len(self.buku_dipinjam)}/{self.maksimal_pinjam}
Total Riwayat Pinjam: {len(self.riwayat_pinjam)}
        """)
        if self.buku_dipinjam:
            print("Buku yang sedang dipinjam:")
            for buku in self.buku_dipinjam:
                print(f"  - {buku}")
    
    # Method untuk meminjam buku
    def pinjam_buku(self, buku):
        if len(self.buku_dipinjam) < self.maksimal_pinjam:
            if buku.pinjam(self.nama):  # Jika berhasil dipinjam
                self.buku_dipinjam.append(buku)
                self.riwayat_pinjam.append(buku.judul)
                return True
        else:
            print(f"❌ Anda sudah meminjam {self.maksimal_pinjam} buku (maksimal)")
        return False
    
    # Method untuk mengembalikan buku
    def kembalikan_buku(self, buku):
        if buku in self.buku_dipinjam:
            if buku.kembalikan():  # Jika berhasil dikembalikan
                self.buku_dipinjam.remove(buku)
                return True
        else:
            print(f"❌ Anda tidak meminjam buku '{buku.judul}'")
        return False
    
    # Method untuk melihat riwayat
    def lihat_riwayat(self):
        print(f"\n📚 Riwayat Peminjaman {self.nama}:")
        if not self.riwayat_pinjam:
            print("Belum pernah meminjam buku")
        else:
            for i, judul in enumerate(self.riwayat_pinjam, 1):
                print(f"{i}. {judul}")
    
    # Method untuk representasi string
    def __str__(self):
        return f"Anggota: {self.nama} ({self.nomor_anggota})"

🛡️ Keamanan Data:
  • • Validasi input di method
  • • Gunakan property untuk kontrol akses
  • • Hindari akses langsung ke atribut sensitif
  • • Dokumentasi method dengan docstring
