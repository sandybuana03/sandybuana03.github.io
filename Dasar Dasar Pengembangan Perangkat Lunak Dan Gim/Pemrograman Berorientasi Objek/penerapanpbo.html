Pemahaman Bermakna

PBO (Pemrograman Berorientasi Objek) adalah cara berpikir dalam pemrograman yang meniru dunia nyata. Bayangkan dunia sebagai kumpulan objek yang saling berinteraksi - seperti mobil, rumah, manusia. Setiap objek punya karakteristik (atribut) dan kemampuan (method) tersendiri. Dengan PBO, kita bisa membuat program yang lebih terstruktur, mudah dipahami, dan mudah dikembangkan! 🌟

Pengenalan PBO Python 📚

Apa itu PBO?

PBO (Pemrograman Berorientasi Objek) atau OOP (Object-Oriented Programming) adalah paradigma pemrograman yang mengorganisir kode berdasarkan konsep "objek". Objek adalah entitas yang memiliki data (atribut) dan fungsi (method) yang bekerja dengan data tersebut.

💡 Analogi: Bayangkan sebuah mobil. Mobil punya warna, merek, kecepatan (atribut), dan bisa bergerak, berhenti, klakson (method).

Mengapa PBO Penting?

Kode lebih terorganisir
Mudah dipelihara
Dapat digunakan ulang
Mudah dikembangkan
Meniru dunia nyata
Kolaborasi tim lebih baik

4 Pilar Utama PBO

🏗️ Encapsulation

Menyembunyikan detail internal objek

🧬 Inheritance

Mewarisi sifat dari class lain

🎭 Polymorphism

Satu interface, banyak implementasi

🎯 Abstraction

Menyembunyikan kompleksitas, fokus pada interface

Konsep Dasar PBO 🧱

Perbedaan Pemrograman Prosedural vs PBO

❌ Pemrograman Prosedural

  • • Fokus pada fungsi/prosedur
  • • Data dan fungsi terpisah
  • • Sulit untuk program besar
  • • Kode sulit digunakan ulang

✅ Pemrograman Berorientasi Objek

  • • Fokus pada objek
  • • Data dan method dalam satu objek
  • • Cocok untuk program kompleks
  • • Kode mudah digunakan ulang

Demo Konsep Dasar

Mari lihat perbedaan pendekatan prosedural vs PBO dengan contoh sederhana:

1. Pendekatan Prosedural

Karakteristik: Data dan fungsi terpisah, fokus pada urutan langkah-langkah

Python - prosedural.py 
# Data terpisah (variabel global)
nama_siswa = "Budi"
umur_siswa = 17
kelas_siswa = "XII RPL"

# Fungsi terpisah dari data
def tampilkan_info(nama, umur, kelas):
    print(f"Nama: {nama}")
    print(f"Umur: {umur}")
    print(f"Kelas: {kelas}")

def ubah_kelas(kelas_baru):
    global kelas_siswa
    kelas_siswa = kelas_baru
    print(f"Kelas diubah menjadi: {kelas_siswa}")

# Penggunaan - harus passing semua parameter
tampilkan_info(nama_siswa, umur_siswa, kelas_siswa)
ubah_kelas("XII RPL 1")
Output Program Prosedural:
Nama: Budi
Umur: 17
Kelas: XII RPL
Kelas diubah menjadi: XII RPL 1
⚠️ Data dan fungsi terpisah, sulit dikelola untuk program besar!

2. Pendekatan PBO (Object-Oriented)

Karakteristik: Data dan method tergabung dalam objek, lebih terstruktur dan mudah dikelola

Python - oop.py 
# Class sebagai blueprint/cetakan
class Siswa:
    def __init__(self, nama, umur, kelas):
        # Attribute/data dalam objek
        self.nama = nama
        self.umur = umur
        self.kelas = kelas
    
    def tampilkan_info(self):
        # Method yang bekerja dengan data objek
        print(f"Nama: {self.nama}")
        print(f"Umur: {self.umur}")
        print(f"Kelas: {self.kelas}")
    
    def ubah_kelas(self, kelas_baru):
        # Method untuk mengubah data objek
        self.kelas = kelas_baru
        print(f"Kelas diubah menjadi: {self.kelas}")

# Membuat objek dari class
siswa1 = Siswa("Budi", 17, "XII RPL")
siswa1.tampilkan_info()  # Tidak perlu passing parameter
siswa1.ubah_kelas("XII RPL 1")
Output Program PBO:
Nama: Budi
Umur: 17
Kelas: XII RPL
Kelas diubah menjadi: XII RPL 1
✨ Data dan method tergabung dalam objek, lebih terorganisir!

Perbandingan Kedua Pendekatan

❌ Prosedural
  • • Data dan fungsi terpisah
  • • Sulit untuk program kompleks
  • • Banyak parameter yang harus di-pass
  • • Sulit maintenance dan debugging
✅ PBO
  • • Data dan method dalam satu objek
  • • Cocok untuk program kompleks
  • • Method otomatis akses data objek
  • • Mudah maintenance dan reusable

Class & Object 📦

Memahami Class dan Object

Class

Class adalah blueprint atau cetakan untuk membuat objek. Seperti denah rumah yang digunakan untuk membangun rumah.

💡 Contoh: Class "Mobil" mendefinisikan bahwa setiap mobil punya merek, warna, dan bisa bergerak.

Object

Object adalah instance atau wujud nyata dari class. Seperti rumah yang sudah jadi berdasarkan denah.

💡 Contoh: mobil1 = Mobil("Toyota", "Merah") adalah objek konkret dari class Mobil.

Inheritance (Pewarisan) 🧬

Apa itu Inheritance?

Inheritance adalah kemampuan sebuah class untuk mewarisi attribute dan method dari class lain. Seperti anak yang mewarisi sifat dari orang tuanya! 👨‍👩‍👧‍👦

Python - inheritance.py 
# Parent Class (Base Class)
class Hewan:
    def __init__(self, nama, umur):
        self.nama = nama
        self.umur = umur
        self.status_hidup = True
    
    def bersuara(self):
        return f"{self.nama} mengeluarkan suara"
    
    def info(self):
        return f"Nama: {self.nama}, Umur: {self.umur} tahun"
    
    def makan(self):
        return f"{self.nama} sedang makan"

# Child Classes - mewarisi dari Hewan
class Singa(Hewan):
    def __init__(self, nama, umur, wilayah="Savana"):
        super().__init__(nama, umur)  # Memanggil constructor parent
        self.wilayah = wilayah
        self.jenis = "Karnivora"
    
    def bersuara(self):  # Override method parent
        return f"{self.nama} berkata: Roar! 🦁"
    
    def berburu(self):  # Method khusus Singa
        return f"{self.nama} sedang berburu di {self.wilayah}"

class Gajah(Hewan):
    def __init__(self, nama, umur, berat=5000):
        super().__init__(nama, umur)  # Memanggil constructor parent
        self.berat = berat
        self.jenis = "Herbivora"
    
    def bersuara(self):  # Override method parent
        return f"{self.nama} berkata: Trumpet! 🐘"
    
    def mandi_lumpur(self):  # Method khusus Gajah
        return f"{self.nama} sedang mandi lumpur (berat: {self.berat}kg)"

class Monyet(Hewan):
    def __init__(self, nama, umur, ekor=True):
        super().__init__(nama, umur)  # Memanggil constructor parent
        self.ekor = ekor
        self.jenis = "Omnivora"
    
    def bersuara(self):  # Override method parent
        return f"{self.nama} berkata: Oook ook! 🐵"
    
    def memanjat(self):  # Method khusus Monyet
        ekor_status = "dengan ekor" if self.ekor else "tanpa ekor"
        return f"{self.nama} memanjat pohon {ekor_status}"

# ===== CONTOH PENGGUNAAN INHERITANCE =====
print("🧬 Demo Inheritance - Pewarisan dalam PBO")
print("=" * 50)

# 1. Membuat objek dari setiap child class
print("📝 1. Membuat objek hewan (Child classes):")
singa1 = Singa("Simba", 5, "Afrika")
gajah1 = Gajah("Dumbo", 10, 6000)
monyet1 = Monyet("George", 3, True)

print(f"✅ {singa1.nama} si Singa berhasil dibuat")
print(f"✅ {gajah1.nama} si Gajah berhasil dibuat") 
print(f"✅ {monyet1.nama} si Monyet berhasil dibuat")

# 2. Menggunakan method yang diwarisi dari parent class
print("\n📋 2. Method yang diwarisi dari class Hewan:")
print(f"📊 {singa1.info()}")    # Method dari parent
print(f"📊 {gajah1.info()}")    # Method dari parent
print(f"📊 {monyet1.info()}")   # Method dari parent

# 3. Menggunakan method yang di-override
print("\n🎭 3. Method override - bersuara() berbeda tiap hewan:")
print(f"🔊 {singa1.bersuara()}")   # Override method
print(f"🔊 {gajah1.bersuara()}")   # Override method  
print(f"🔊 {monyet1.bersuara()}")  # Override method

# 4. Method yang sama dari parent, hasil sama
print("\n🍽️ 4. Method makan() dari parent class:")
print(f"🍖 {singa1.makan()}")    # Method dari parent
print(f"🌿 {gajah1.makan()}")    # Method dari parent
print(f"🍌 {monyet1.makan()}")   # Method dari parent

# 5. Method khusus masing-masing child class
print("\n⭐ 5. Method khusus setiap child class:")
print(f"🏃 {singa1.berburu()}")        # Method khusus Singa
print(f"🛁 {gajah1.mandi_lumpur()}")   # Method khusus Gajah
print(f"🌳 {monyet1.memanjat()}")      # Method khusus Monyet

# 6. Akses attribute yang diwarisi dan yang baru
print("\n📊 6. Attribute inheritance:")
print(f"🦁 {singa1.nama} - Umur: {singa1.umur}, Jenis: {singa1.jenis}, Wilayah: {singa1.wilayah}")
print(f"🐘 {gajah1.nama} - Umur: {gajah1.umur}, Jenis: {gajah1.jenis}, Berat: {gajah1.berat}kg")
print(f"🐵 {monyet1.nama} - Umur: {monyet1.umur}, Jenis: {monyet1.jenis}, Ekor: {monyet1.ekor}")

# 7. Demonstrasi polymorphism dengan inheritance
print("\n🎯 7. Polymorphism dengan inheritance:")
daftar_hewan = [singa1, gajah1, monyet1]
print("🔄 Loop semua hewan dengan method yang sama:")
for hewan in daftar_hewan:
    print(f"   • {hewan.bersuara()}")  # Method sama, hasil beda!

print("\n✨ Kesimpulan Inheritance:")
print("   ✅ Child class mewarisi semua attribute & method parent")
print("   ✅ Child class bisa menambah attribute & method baru") 
print("   ✅ Child class bisa override method parent")
print("   ✅ super() digunakan untuk akses constructor parent")
print("   ✅ Code reuse - tidak perlu tulis ulang method yang sama")

Polymorphism 🎭

Apa itu Polymorphism?

Polymorphism berarti "banyak bentuk". Dalam PBO, polymorphism memungkinkan objek yang berbeda merespons method yang sama dengan cara yang berbeda. Seperti tombol "Play" yang bisa memutar musik, video, atau game! 🎮🎵📺

Python - polymorphism.py 
# Parent Class (Base Class)
class Kendaraan:
    def __init__(self, nama, kecepatan_max):
        self.nama = nama
        self.kecepatan_max = kecepatan_max
        self.posisi = 0
    
    def bergerak(self):
        # Method yang akan di-override oleh child classes
        return f"{self.nama} sedang bergerak"
    
    def info(self):
        return f"Kendaraan: {self.nama}, Kecepatan Max: {self.kecepatan_max} km/h"
    
    def berhenti(self):
        return f"{self.nama} berhenti"

# Child Classes - Implementasi berbeda untuk method yang sama
class Mobil(Kendaraan):
    def __init__(self, nama, kecepatan_max, jenis_bahan_bakar="Bensin"):
        super().__init__(nama, kecepatan_max)
        self.jenis_bahan_bakar = jenis_bahan_bakar
        self.roda = 4
    
    def bergerak(self):  # Override method parent
        self.posisi += 10
        return f"🚗 {self.nama} melaju di jalan raya dengan {self.roda} roda (posisi: {self.posisi}km)"
    
    def klakson(self):  # Method khusus Mobil
        return f"🚗 {self.nama}: Beep beep!"

class Pesawat(Kendaraan):
    def __init__(self, nama, kecepatan_max, ketinggian_max=10000):
        super().__init__(nama, kecepatan_max)
        self.ketinggian_max = ketinggian_max
        self.ketinggian_sekarang = 0
    
    def bergerak(self):  # Override method parent
        self.posisi += 50
        self.ketinggian_sekarang = 8000
        return f"✈️ {self.nama} terbang di udara pada ketinggian {self.ketinggian_sekarang}m (posisi: {self.posisi}km)"
    
    def lepas_landas(self):  # Method khusus Pesawat
        return f"✈️ {self.nama} sedang lepas landas!"

class Kapal(Kendaraan):
    def __init__(self, nama, kecepatan_max, jenis="Penumpang"):
        super().__init__(nama, kecepatan_max)
        self.jenis = jenis
        self.di_laut = True
    
    def bergerak(self):  # Override method parent
        self.posisi += 5
        return f"🚢 {self.nama} berlayar di laut dengan tenang (posisi: {self.posisi} mil laut)"
    
    def buang_jangkar(self):  # Method khusus Kapal
        return f"⚓ {self.nama} membuang jangkar!"

class Sepeda(Kendaraan):
    def __init__(self, nama, kecepatan_max=25):
        super().__init__(nama, kecepatan_max)
        self.roda = 2
        self.ramah_lingkungan = True
    
    def bergerak(self):  # Override method parent
        self.posisi += 2
        return f"🚴 {self.nama} dikayuh dengan tenaga manusia (posisi: {self.posisi}km)"
    
    def bel(self):  # Method khusus Sepeda
        return f"🚴 {self.nama}: Ring ring!"

# ===== CONTOH PENGGUNAAN POLYMORPHISM =====
print("🎭 Demo Polymorphism - Banyak Bentuk dalam PBO")
print("=" * 55)

# 1. Membuat objek dari berbagai child classes
print("📝 1. Membuat berbagai jenis kendaraan:")
mobil = Mobil("Toyota Avanza", 180, "Bensin")
pesawat = Pesawat("Garuda Indonesia", 900, 12000)
kapal = Kapal("KM Lawit", 45, "Ferry")
sepeda = Sepeda("Polygon", 25)

print(f"✅ {mobil.nama} (Mobil) berhasil dibuat")
print(f"✅ {pesawat.nama} (Pesawat) berhasil dibuat")
print(f"✅ {kapal.nama} (Kapal) berhasil dibuat")
print(f"✅ {sepeda.nama} (Sepeda) berhasil dibuat")

# 2. Polymorphism - Method yang sama, perilaku berbeda
print("\n🎭 2. Polymorphism - Method bergerak() dengan implementasi berbeda:")
kendaraan_list = [mobil, pesawat, kapal, sepeda]

for kendaraan in kendaraan_list:
    print(f"   {kendaraan.bergerak()}")  # Method sama, hasil berbeda!

# 3. Method yang diwarisi dari parent - hasil sama
print("\n📊 3. Method info() yang diwarisi dari parent class:")
for kendaraan in kendaraan_list:
    print(f"   📋 {kendaraan.info()}")

# 4. Polymorphism dengan method berhenti()
print("\n🛑 4. Method berhenti() - implementasi sama dari parent:")
for kendaraan in kendaraan_list:
    print(f"   🛑 {kendaraan.berhenti()}")

# 5. Method khusus masing-masing class (tidak polymorphic)
print("\n⭐ 5. Method khusus setiap jenis kendaraan:")
print(f"   {mobil.klakson()}")           # Method khusus Mobil
print(f"   {pesawat.lepas_landas()}")    # Method khusus Pesawat
print(f"   {kapal.buang_jangkar()}")     # Method khusus Kapal
print(f"   {sepeda.bel()}")              # Method khusus Sepeda

# 6. Demonstrasi polymorphism dengan function
print("\n🔄 6. Function yang menerima berbagai jenis kendaraan:")
def jalankan_kendaraan(kendaraan):
    """Function yang bisa menerima objek kendaraan apapun"""
    print(f"   🚀 Menjalankan: {kendaraan.bergerak()}")
    return kendaraan.berhenti()

print("   Function jalankan_kendaraan() dipanggil untuk setiap kendaraan:")
for kendaraan in kendaraan_list:
    hasil_berhenti = jalankan_kendaraan(kendaraan)
    print(f"   🛑 {hasil_berhenti}")

# 7. Polymorphism dengan isinstance() check
print("\n🔍 7. Mengecek tipe objek dengan isinstance():")
for kendaraan in kendaraan_list:
    if isinstance(kendaraan, Mobil):
        print(f"   🚗 {kendaraan.nama} adalah Mobil - {kendaraan.klakson()}")
    elif isinstance(kendaraan, Pesawat):
        print(f"   ✈️ {kendaraan.nama} adalah Pesawat - {kendaraan.lepas_landas()}")
    elif isinstance(kendaraan, Kapal):
        print(f"   🚢 {kendaraan.nama} adalah Kapal - {kendaraan.buang_jangkar()}")
    elif isinstance(kendaraan, Sepeda):
        print(f"   🚴 {kendaraan.nama} adalah Sepeda - {kendaraan.bel()}")

# 8. Polymorphism dengan Duck Typing
print("\n🦆 8. Duck Typing - 'If it walks like a duck...':")
def test_bergerak(obj):
    """Function yang tidak peduli tipe objek, asal punya method bergerak()"""
    try:
        return obj.bergerak()
    except AttributeError:
        return f"Objek {type(obj).__name__} tidak bisa bergerak"

# Test dengan berbagai objek
test_objects = [mobil, pesawat, "string", 123, sepeda]
for obj in test_objects:
    if hasattr(obj, 'bergerak'):  # Duck typing check
        print(f"   ✅ {test_bergerak(obj)}")
    else:
        print(f"   ❌ {type(obj).__name__} tidak memiliki method bergerak()")

print("\n✨ Kesimpulan Polymorphism:")
print("   ✅ Satu interface (method name), banyak implementasi")

print("   ✅ Memungkinkan kode yang lebih fleksibel dan mudah dipelihara")
print("   ✅ Duck typing: 'If it looks like a duck and quacks like a duck, it's a duck!'")
print("   ✅ Polymorphism membuat kode lebih generic dan reusable")

Encapsulation 🔒

Apa itu Encapsulation?

Encapsulation adalah prinsip menyembunyikan detail internal objek dan hanya mengekspos interface yang diperlukan. Seperti remote TV - kamu tidak perlu tahu cara kerja internal TV, cukup tekan tombol untuk mengoperasikannya! 📺🎮

Python - encapsulation.py 
class RekeningBank:
    def __init__(self, nama_pemilik, saldo_awal):
        self.nama_pemilik = nama_pemilik
        self.__saldo = saldo_awal  # Private attribute (__)
        self.__pin = "1234"        # Private attribute (__)
    
    def cek_saldo(self):  # Public method
        return f"Saldo: Rp{self.__saldo:,}"
    
    def setor_uang(self, jumlah):  # Public method
        if jumlah > 0:
            self.__saldo += jumlah
            return f"Berhasil setor Rp{jumlah:,}"
        return "Jumlah tidak valid"
    
    def tarik_uang(self, jumlah, pin):  # Public method dengan validasi
        if pin == self.__pin and jumlah <= self.__saldo:
            self.__saldo -= jumlah
            return f"Berhasil tarik Rp{jumlah:,}"
        return "PIN salah atau saldo tidak cukup"

# Parent Class (Base Class)
class Person:
    def __init__(self, nama, umur, id_number):
        self.nama = nama
        self.umur = umur
        self.id_number = id_number
        self.status_aktif = True
    
    def info(self):
        # Method yang akan di-override oleh child classes
        return f"Nama: {self.nama}, Umur: {self.umur}, ID: {self.id_number}"
    
    def ubah_status(self, status):
        self.status_aktif = status
        return f"Status {self.nama} diubah menjadi: {'Aktif' if status else 'Tidak Aktif'}"

# Child Class 1 - Siswa
class Siswa(Person):
    def __init__(self, nama, umur, id_number, kelas, jurusan="Umum"):
        super().__init__(nama, umur, id_number)  # Memanggil constructor parent
        self.kelas = kelas
        self.jurusan = jurusan
        self.__nilai = {}  # Private attribute (Encapsulation)
        self.__absensi = 0
        self.prestasi = []
    
    def info(self):  # Override method parent (Polymorphism)
        status = "Aktif" if self.status_aktif else "Tidak Aktif"
        return f"👨‍🎓 Siswa - {self.nama} ({self.kelas} {self.jurusan}) - Status: {status}"
    
    def tambah_nilai(self, mata_pelajaran, nilai):
        if 0 <= nilai <= 100:
            self.__nilai[mata_pelajaran] = nilai
            return f"✅ Nilai {mata_pelajaran}: {nilai} berhasil ditambahkan untuk {self.nama}"
        return f"❌ Nilai harus antara 0-100!"
    
    def lihat_nilai(self):  # Public method untuk akses private data
        if self.__nilai:
            return self.__nilai.copy()  # Return copy untuk keamanan
        return "Belum ada nilai"
    
    def rata_rata(self):
        if self.__nilai:
            rata = sum(self.__nilai.values()) / len(self.__nilai)
            return round(rata, 2)
        return 0
    
    def tambah_absensi(self):
        self.__absensi += 1
        return f"📅 Absensi {self.nama}: {self.__absensi} hari"
    
    def tambah_prestasi(self, prestasi):
        self.prestasi.append(prestasi)
        return f"🏆 Prestasi '{prestasi}' ditambahkan untuk {self.nama}"

# Child Class 2 - Guru
class Guru(Person):
    def __init__(self, nama, umur, id_number, mata_pelajaran, gaji=5000000):
        super().__init__(nama, umur, id_number)  # Memanggil constructor parent
        self.mata_pelajaran = mata_pelajaran
        self.__gaji = gaji  # Private attribute (Encapsulation)
        self.kelas_diampu = []
        self.jam_mengajar = 0
    
    def info(self):  # Override method parent (Polymorphism)
        status = "Aktif" if self.status_aktif else "Tidak Aktif"
        return f"👨‍🏫 Guru - {self.nama} (Mapel: {self.mata_pelajaran}) - Status: {status}"
    
    def mengajar(self, kelas):
        if self.status_aktif:
            if kelas not in self.kelas_diampu:
                self.kelas_diampu.append(kelas)
            self.jam_mengajar += 2
            return f"📚 {self.nama} sedang mengajar {self.mata_pelajaran} di kelas {kelas}"
        return f"❌ {self.nama} tidak aktif, tidak bisa mengajar"
    
    def lihat_gaji(self):  # Public method untuk akses private data
        return f"💰 Gaji {self.nama}: Rp{self.__gaji:,}"
    
    def naik_gaji(self, kenaikan):
        if kenaikan > 0:
            self.__gaji += kenaikan
            return f"📈 Gaji {self.nama} naik Rp{kenaikan:,} menjadi Rp{self.__gaji:,}"
        return "❌ Kenaikan harus positif!"

# Child Class 3 - Staff
class Staff(Person):
    def __init__(self, nama, umur, id_number, jabatan, departemen="Administrasi"):
        super().__init__(nama, umur, id_number)
        self.jabatan = jabatan
        self.departemen = departemen
        self.tugas_selesai = 0
    
    def info(self):  # Override method parent (Polymorphism)
        status = "Aktif" if self.status_aktif else "Tidak Aktif"
        return f"👔 Staff - {self.nama} ({self.jabatan}, {self.departemen}) - Status: {status}"
    
    def kerjakan_tugas(self, nama_tugas):
        if self.status_aktif:
            self.tugas_selesai += 1
            return f"✅ {self.nama} menyelesaikan tugas: {nama_tugas} (Total: {self.tugas_selesai})"
        return f"❌ {self.nama} tidak aktif"

# Main System Class
class Sekolah:
    def __init__(self, nama_sekolah, alamat=""):
        self.nama_sekolah = nama_sekolah
        self.alamat = alamat
        self.daftar_siswa = []
        self.daftar_guru = []
        self.daftar_staff = []
        self.mata_pelajaran = []
    
    def tambah_siswa(self, siswa):
        self.daftar_siswa.append(siswa)
        return f"👨‍🎓 Siswa {siswa.nama} berhasil ditambahkan ke {self.nama_sekolah}"
    
    def tambah_guru(self, guru):
        self.daftar_guru.append(guru)
        if guru.mata_pelajaran not in self.mata_pelajaran:
            self.mata_pelajaran.append(guru.mata_pelajaran)
        return f"👨‍🏫 Guru {guru.nama} berhasil ditambahkan ke {self.nama_sekolah}"
    
    def tambah_staff(self, staff):
        self.daftar_staff.append(staff)
        return f"👔 Staff {staff.nama} berhasil ditambahkan ke {self.nama_sekolah}"
    
    def info_sekolah(self):
        return f"""
🏫 === INFO {self.nama_sekolah.upper()} ===
📍 Alamat: {self.alamat}
👨‍🎓 Jumlah Siswa: {len(self.daftar_siswa)} orang
👨‍🏫 Jumlah Guru: {len(self.daftar_guru)} orang  
👔 Jumlah Staff: {len(self.daftar_staff)} orang
📚 Mata Pelajaran: {len(self.mata_pelajaran)} mapel
        """
    
    def tampilkan_semua_orang(self):
        # Polymorphism - method info() berbeda untuk setiap class
        semua_orang = self.daftar_siswa + self.daftar_guru + self.daftar_staff
        hasil = []
        for orang in semua_orang:
            hasil.append(orang.info())  # Method sama, hasil berbeda!
        return hasil
