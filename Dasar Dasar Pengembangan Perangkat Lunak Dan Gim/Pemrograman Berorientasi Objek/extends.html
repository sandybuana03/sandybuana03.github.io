Pengenalan Inheritance 📚

Mari kenali konsep dasar pewarisan dalam pemrograman

Apa itu Inheritance?

Inheritance (Pewarisan) adalah salah satu konsep fundamental dalam Object-Oriented Programming (OOP). Konsep ini memungkinkan sebuah class (class anak) untuk mewarisi properti dan method dari class lain (class induk).

💡 Analogi: Seperti anak yang mewarisi sifat dari orang tuanya, class anak juga mewarisi "sifat" dari class induknya!

Mengapa Inheritance Penting?

Keuntungan:

  • Mengurangi duplikasi kode
  • Kode lebih mudah dipelihara
  • Mendukung reusability

Manfaat:

  • Struktur kode lebih terorganisir
  • Pengembangan lebih efisien
  • Mudah untuk extend fitur

Terminologi Penting

Parent Class

Class induk yang diwarisi

Child Class

Class anak yang mewarisi

Inheritance

Proses pewarisan

Konsep Dasar Inheritance 💡

Memahami cara kerja pewarisan dengan contoh sederhana

Contoh Sederhana: Kendaraan

Mari kita lihat contoh inheritance dengan class Kendaraan sebagai parent class:

Python - kendaraan.py 
# Class Parent (Induk)
class Kendaraan:
    def __init__(self, merk, warna):
        self.merk = merk
        self.warna = warna
    
    def info(self):
        return f"Kendaraan {self.merk} berwarna {self.warna}"
    
    def bergerak(self):
        return "Kendaraan sedang bergerak"

# Class Child (Anak) - mewarisi dari Kendaraan
class Mobil(Kendaraan):
    def __init__(self, merk, warna, jumlah_pintu):
        super().__init__(merk, warna)  # Memanggil constructor parent
        self.jumlah_pintu = jumlah_pintu
    
    def klakson(self):
        return "Beep beep! 🚗"

# Penggunaan
mobil1 = Mobil("Toyota", "Merah", 4)
print(mobil1.info())        # Method dari parent class
print(mobil1.bergerak())    # Method dari parent class  
print(mobil1.klakson())     # Method dari child class

Syntax & Extends 🔧

Mempelajari cara penulisan inheritance yang benar

Syntax Dasar Inheritance

Python - syntax_inheritance.py 
# Template dasar inheritance
class ParentClass:
    def __init__(self, parameter):
        self.attribute = parameter
    
    def parent_method(self):
        return "Method dari parent class"

class ChildClass(ParentClass):  # Syntax inheritance
    def __init__(self, parameter, new_parameter):
        super().__init__(parameter)  # Panggil constructor parent
        self.new_attribute = new_parameter
    
    def child_method(self):
        return "Method dari child class"

# Contoh penggunaan
obj = ChildClass("nilai1", "nilai2")
print(obj.parent_method())  # Bisa akses method parent
print(obj.child_method())   # Method sendiri

📝 Penjelasan Syntax:

  • class ChildClass(ParentClass): - Mendeklarasikan inheritance
  • super().__init__(parameter): - Memanggil constructor parent
  • super().method_name(): - Memanggil method parent

Contoh Praktis: Sistem Pengguna

Python - user_system.py 
# Parent Class
class User:
    def __init__(self, nama, email):
        self.nama = nama
        self.email = email
        self.status = "Aktif"
    
    def info(self):
        return f"User: {self.nama} ({self.email})"
    
    def login(self):
        return f"{self.nama} berhasil login"

# Child Class 1: Admin
class Admin(User):
    def __init__(self, nama, email, level_akses):
        super().__init__(nama, email)
        self.level_akses = level_akses
    
    def kelola_user(self, user):
        return f"Admin {self.nama} mengelola user {user}"
    
    def backup_data(self):
        return "Data berhasil di-backup oleh admin"

# Child Class 2: Member
class Member(User):
    def __init__(self, nama, email, membership_type):
        super().__init__(nama, email)
        self.membership_type = membership_type
    
    def upgrade_membership(self):
        return f"Membership {self.nama} berhasil di-upgrade"

# Penggunaan
admin1 = Admin("Budi", "budi@admin.com", "Super Admin")
member1 = Member("Sari", "sari@member.com", "Premium")

print(admin1.info())           # Method dari parent
print(admin1.kelola_user("Sari"))  # Method dari child
print(member1.login())         # Method dari parent
print(member1.upgrade_membership())  # Method dari child

Method Overriding ✏️

Mengubah perilaku method yang diwarisi dari parent class

Apa itu Method Overriding?

Method Overriding adalah kemampuan child class untuk memberikan implementasi yang berbeda dari method yang sudah ada di parent class. Child class dapat "menimpa" atau mengubah perilaku method parent.

💡 Analogi: Seperti anak yang punya cara berbeda dalam melakukan sesuatu dibanding orang tuanya!

Contoh: Hewan dan Suaranya

Python - hewan_suara.py 
# Parent Class
class Hewan:
    def __init__(self, nama):
        self.nama = nama
    
    def bersuara(self):
        return f"{self.nama} mengeluarkan suara"
    
    def bergerak(self):
        return f"{self.nama} sedang bergerak"

# Child Class 1: Kucing - Override method bersuara
class Kucing(Hewan):
    def bersuara(self):  # Method Overriding
        return f"{self.nama} berkata: Meow! 🐱"
    
    def memanjat(self):
        return f"{self.nama} sedang memanjat pohon"

# Child Class 2: Anjing - Override method bersuara
class Anjing(Hewan):
    def bersuara(self):  # Method Overriding
        return f"{self.nama} berkata: Woof! 🐶"
    
    def menggonggong(self):
        return f"{self.nama} menggonggong keras"

# Child Class 3: Burung - Override method bersuara dan bergerak
class Burung(Hewan):
    def bersuara(self):  # Method Overriding
        return f"{self.nama} berkata: Tweet tweet! 🐦"
    
    def bergerak(self):  # Method Overriding
        return f"{self.nama} sedang terbang di udara"
    
    def terbang(self):
        return f"{self.nama} terbang tinggi"

# Penggunaan
kucing1 = Kucing("Kitty")
anjing1 = Anjing("Buddy")
burung1 = Burung("Tweety")

print(kucing1.bersuara())   # Output: Kitty berkata: Meow! 🐱
print(anjing1.bersuara())   # Output: Buddy berkata: Woof! 🐶
print(burung1.bersuara())   # Output: Tweety berkata: Tweet tweet! 🐦
print(burung1.bergerak())   # Output: Tweety sedang terbang di udara

Demo: Hewan Bersuara

Cara Kerja Method Overriding

Langkah-langkah:

  1. 1. Child class membuat method dengan nama yang sama
  2. 2. Python akan menggunakan method dari child class
  3. 3. Method parent "tertimpa" oleh method child
  4. 4. Bisa tetap akses method parent dengan super()

Keuntungan:

  • • Perilaku yang lebih spesifik
  • • Fleksibilitas dalam implementasi
  • • Tetap mempertahankan interface yang sama
  • • Mendukung polimorfisme

Super Function 🚀

Mengakses method dan atribut dari parent class

Apa itu super()?

super() adalah fungsi built-in Python yang memungkinkan child class untuk mengakses method dan atribut dari parent class. Ini sangat berguna ketika kita ingin:

  • • Memanggil constructor parent class
  • • Menggunakan method parent dalam method yang di-override
  • • Memperluas fungsionalitas tanpa menghilangkan yang lama

Penggunaan super() dalam Constructor

Python - super_constructor.py 
# Contoh penggunaan super() dalam constructor
class Pegawai:
    def __init__(self, nama, gaji):
        self.nama = nama
        self.gaji = gaji
        self.status = "Aktif"
        print(f"Constructor Pegawai dipanggil untuk {nama}")
    
    def info(self):
        return f"Pegawai: {self.nama}, Gaji: Rp{self.gaji:,}"
    
    def bekerja(self):
        return f"{self.nama} sedang bekerja"

class Manager(Pegawai):
    def __init__(self, nama, gaji, departemen, jumlah_bawahan):
        # Panggil constructor parent class
        super().__init__(nama, gaji)
        
        # Tambahkan atribut khusus manager
        self.departemen = departemen
        self.jumlah_bawahan = jumlah_bawahan
        print(f"Constructor Manager dipanggil untuk {nama}")
    
    def info(self):
        # Gunakan method parent + tambahan info
        info_dasar = super().info()
        return f"{info_dasar}, Departemen: {self.departemen}, Bawahan: {self.jumlah_bawahan}"
    
    def rapat(self):
        return f"Manager {self.nama} sedang memimpin rapat"

# Penggunaan
print("=== Membuat objek Manager ===")
manager1 = Manager("Budi", 15000000, "IT", 5)
print("\n=== Info Manager ===")
print(manager1.info())
print(manager1.bekerja())  # Method dari parent
print(manager1.rapat())    # Method sendiri

Demo: Buat Pegawai/Manager

Tips Menggunakan super()

💡 Tip 1: Selalu gunakan super() di constructor

Pastikan parent class ter-inisialisasi dengan benar sebelum menambahkan atribut child class.

💡 Tip 2: Kombinasikan dengan method overriding

Gunakan super() untuk memanggil method parent, lalu tambahkan fungsionalitas khusus.

💡 Tip 3: Perhatikan urutan parameter

Pastikan parameter yang dikirim ke super() sesuai dengan yang dibutuhkan parent class.
