Pengenalan Method & Konstruktor

🔧

Apa itu Method?

Method adalah fungsi yang berada di dalam class. Seperti tombol-tombol pada remote TV, method adalah "tombol" yang bisa kita tekan untuk melakukan sesuatu pada objek.

Contoh: Method gas() pada mobil untuk menambah kecepatan
🏗️

Apa itu Konstruktor?

Konstruktor adalah method khusus yang otomatis dipanggil saat objek dibuat. Seperti cetakan kue yang membentuk kue sesuai bentuknya, konstruktor "mencetak" objek dengan nilai awal.

Contoh: __init__() mengatur merk dan warna mobil saat dibuat

Method dalam Python

Pengertian Method

Method adalah fungsi yang didefinisikan di dalam class dan menjadi bagian dari objek. Method memungkinkan objek untuk melakukan aksi atau operasi tertentu, seperti mengubah nilai atribut atau menampilkan informasi.

Ciri-ciri Method:

  • • Selalu memiliki parameter self sebagai parameter pertama (untuk instance method)
  • • Dapat mengakses dan memodifikasi atribut objek melalui self
  • • Dipanggil menggunakan notasi titik: objek.method()
  • • Dapat menerima parameter tambahan selain self
  • • Dapat mengembalikan nilai menggunakan return

Mengapa Menggunakan self?

Parameter self adalah referensi ke objek yang sedang memanggil method. Ini memungkinkan method untuk:

  • • Mengakses atribut objek: self.nama
  • • Memodifikasi atribut objek: self.umur = 20
  • • Memanggil method lain dalam objek yang sama: self.method_lain()

class Mobil:
    # Konstruktor untuk inisialisasi objek
    def __init__(self, merk, warna):
        self.merk = merk        # Atribut merk mobil
        self.warna = warna      # Atribut warna mobil
        self.kecepatan = 0     # Kecepatan awal = 0
        self.mesin_hidup = False # Status mesin
    
    # Method untuk menghidupkan mesin
    def nyalakan_mesin(self):
        self.mesin_hidup = True
        print(f"Mesin mobil {self.merk} dinyalakan!")
    
    # Method untuk menambah kecepatan
    def gas(self, tambah_kecepatan=10):
        if not self.mesin_hidup:
            print("Nyalakan mesin terlebih dahulu!")
            return
        
        self.kecepatan += tambah_kecepatan
        print(f"Mobil {self.merk} berakselerasi! Kecepatan: {self.kecepatan} km/h")
    
    # Method untuk mengurangi kecepatan
    def rem(self, kurang_kecepatan=10):
        if self.kecepatan > 0:
            self.kecepatan = max(0, self.kecepatan - kurang_kecepatan)
            print(f"Mobil {self.merk} melambat! Kecepatan: {self.kecepatan} km/h")
        else:
            print("Mobil sudah berhenti!")
    
    # Method untuk menampilkan informasi mobil
    def info(self):
        status_mesin = "Hidup" if self.mesin_hidup else "Mati"
        print(f"=== Info Mobil ===")
        print(f"Merk: {self.merk}")
        print(f"Warna: {self.warna}")
        print(f"Kecepatan: {self.kecepatan} km/h")
        print(f"Status Mesin: {status_mesin}")

# Contoh penggunaan class Mobil
print("=== Membuat Objek Mobil ===")
mobil_saya = Mobil("Toyota", "Merah")  # Konstruktor dipanggil

print("\n=== Menggunakan Method ===")
mobil_saya.info()                    # Menampilkan info awal
mobil_saya.gas()                     # Coba gas tanpa nyalakan mesin
mobil_saya.nyalakan_mesin()          # Nyalakan mesin dulu
mobil_saya.gas()                     # Sekarang bisa gas
mobil_saya.gas(20)                   # Gas dengan kecepatan custom
mobil_saya.rem(15)                   # Rem dengan pengurangan custom
mobil_saya.info()                    # Lihat info akhir

Jenis-jenis Method

Instance Method

Method yang bekerja pada instance objek tertentu

def method(self):
    return self.atribut

Class Method

Method yang bekerja pada class, bukan instance

@classmethod
def method(cls):
    return cls.atribut

Static Method

Method independen, tidak butuh self atau cls

@staticmethod
def method():
    return "hasil"

class Kalkulator:
    def __init__(self, nama):
        self.nama = nama
        self.riwayat = []
    
    def tambah(self, a, b):
        """Method dengan 2 parameter"""
        hasil = a + b
        self.riwayat.append(f"{a} + {b} = {hasil}")
        return hasil
    
    def pangkat(self, angka, eksponen=2):
        """Method dengan parameter default"""
        hasil = angka ** eksponen
        self.riwayat.append(f"{angka}^{eksponen} = {hasil}")
        return hasil
    
    def operasi_banyak(self, operasi, *angka):
        """Method dengan *args (variadic arguments)"""
        if operasi == "jumlah":
            hasil = sum(angka)
        elif operasi == "kali":
            hasil = 1
            for num in angka:
                hasil *= num
        self.riwayat.append(f"{operasi}({angka}) = {hasil}")
        return hasil
    
    def tampilkan_riwayat(self):
        print(f"Riwayat {self.nama}:")
        for operasi in self.riwayat:
            print(f"  {operasi}")

Konstruktor Python

Apa itu Konstruktor?

Konstruktor adalah method khusus yang otomatis dipanggil saat objek dibuat. Di Python, konstruktor menggunakan nama __init__ (init adalah singkatan dari initialization).

Fungsi Konstruktor:

  • • Inisialisasi Otomatis: Mengatur nilai awal atribut objek
  • • Dipanggil Otomatis: Tidak perlu memanggil secara manual
  • • Persiapan Objek: Memastikan objek siap digunakan
  • • Kustomisasi: Menerima parameter untuk pengaturan khusus
  • • Validasi Input: Memeriksa kebenaran data yang diberikan
  • • Setup Awal: Melakukan konfigurasi yang diperlukan

Kapan Konstruktor Dipanggil?

Saat membuat objek:

mobil = Mobil("Toyota", "Merah")

↑ __init__ dipanggil di sini

Yang terjadi:

  • 1. Objek baru dibuat
  • 2. __init__ dipanggil otomatis
  • 3. Atribut diinisialisasi
  • 4. Objek siap digunakan

Konstruktor Sederhana

def __init__(self):
    self.atribut = "nilai"

Konstruktor dengan Parameter

def __init__(self, param1, param2):

class Mahasiswa:
    def __init__(self, nama, nim, umur, jurusan="Belum Ditentukan"):
        # Validasi nama
        if not nama or len(nama.strip()) < 2:
            raise ValueError("Nama harus minimal 2 karakter")
        
        # Validasi NIM
        if not nim or len(nim) != 10:
            raise ValueError("NIM harus 10 digit")
        
        # Validasi umur
        if not isinstance(umur, int) or umur < 17 or umur > 30:
            raise ValueError("Umur harus antara 17-30 tahun")
        
        # Inisialisasi atribut setelah validasi
        self.nama = nama.strip().title()
        self.nim = nim
        self.umur = umur
        self.jurusan = jurusan
        self.mata_kuliah = []
        self.ipk = 0.0
        
        # Setup awal
        self._generate_email()
        print(f"✅ Mahasiswa {self.nama} berhasil terdaftar!")
    
    def _generate_email(self):
        """Method private untuk generate email otomatis"""
        nama_clean = self.nama.lower().replace(" ", ".")
        self.email = f"{nama_clean}@university.ac.id"
    
    def tambah_matkul(self, matkul):
        if matkul not in self.mata_kuliah:
            self.mata_kuliah.append(matkul)
            print(f"Mata kuliah '{matkul}' ditambahkan")
        else:
            print(f"Mata kuliah '{matkul}' sudah ada")
    
    def info_lengkap(self):
        print(f"Nama: {self.nama}")
        print(f"NIM: {self.nim}")
        print(f"Umur: {self.umur} tahun")
        print(f"Jurusan: {self.jurusan}")
        print(f"Email: {self.email}")
        print(f"Mata Kuliah: {', '.join(self.mata_kuliah) if self.mata_kuliah else 'Belum ada'}")

class Siswa:
    def __init__(self, nama, kelas, umur):
        # Inisialisasi atribut
        self.nama = nama
        self.kelas = kelas
        self.umur = umur
        self.nilai = []  # List kosong untuk menyimpan nilai
        
        # Pesan saat objek dibuat
        print(f"Siswa {self.nama} berhasil didaftarkan!")
    
    def tambah_nilai(self, nilai):
        self.nilai.append(nilai)
        print(f"Nilai {nilai} ditambahkan untuk {self.nama}")
    
    def rata_rata(self):
        if len(self.nilai) > 0:
            return sum(self.nilai) / len(self.nilai)
        return 0
    
    def info_siswa(self):
        rata = self.rata_rata()
        print(f"Nama: {self.nama}")
        print(f"Kelas: {self.kelas}")
        print(f"Umur: {self.umur} tahun")
        print(f"Rata-rata nilai: {rata:.2f}")

# Membuat objek siswa (konstruktor dipanggil otomatis)
siswa1 = Siswa("Budi", "XII RPL", 17)
siswa2 = Siswa("Sari", "XII TKJ", 16)

# Menggunakan method
siswa1.tambah_nilai(85)
siswa1.tambah_nilai(90)
siswa1.info_siswa()

class Buku:
    def __init__(self, judul, penulis, tahun, stok=1):
        """
        Konstruktor untuk membuat objek Buku
        """
        self.judul = judul
        self.penulis = penulis
        self.tahun = tahun
        self.stok = stok
        self.dipinjam = 0
        
        print(f"📚 Buku '{self.judul}' berhasil ditambahkan ke perpustakaan!")
    
    def info_buku(self):
        """
        Method untuk menampilkan informasi buku
        """
        print(f"📖 Judul: {self.judul}")
        print(f"✍️  Penulis: {self.penulis}")
        print(f"📅 Tahun: {self.tahun}")
        print(f"📦 Stok: {self.stok}")
        print(f"📤 Dipinjam: {self.dipinjam}")
        print(f"✅ Tersedia: {self.stok - self.dipinjam}")
    
    def pinjam_buku(self, jumlah=1):
        """
        Method untuk meminjam buku
        """
        if self.stok - self.dipinjam >= jumlah:
            self.dipinjam += jumlah
            print(f"✅ Berhasil meminjam {jumlah} buku '{self.judul}'")
            print(f"📊 Sisa tersedia: {self.stok - self.dipinjam}")
        else:
            tersedia = self.stok - self.dipinjam
            print(f"❌ Maaf, hanya tersedia {tersedia} buku '{self.judul}'")
    
    def kembalikan_buku(self, jumlah=1):
        """
        Method untuk mengembalikan buku
        """
        if self.dipinjam >= jumlah:
            self.dipinjam -= jumlah
            print(f"✅ Berhasil mengembalikan {jumlah} buku '{self.judul}'")
            print(f"📊 Total tersedia: {self.stok - self.dipinjam}")
        else:
            print(f"❌ Tidak bisa mengembalikan {jumlah} buku. Hanya {self.dipinjam} yang dipinjam")
    
    def tambah_stok(self, jumlah):
        """
        Method untuk menambah stok buku
        """
        self.stok += jumlah
        print(f"📈 Stok buku '{self.judul}' bertambah {jumlah}. Total stok: {self.stok}")

# Contoh penggunaan
buku1 = Buku("Python untuk Pemula", "John Doe", 2023, 5)
buku2 = Buku("Web Development", "Jane Smith", 2022, 3)

# Menggunakan method
buku1.info_buku()
buku1.pinjam_buku(2)
buku1.kembalikan_buku(1)
buku1.tambah_stok(2)
