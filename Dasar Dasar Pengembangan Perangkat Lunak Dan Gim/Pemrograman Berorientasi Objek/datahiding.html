Apa itu Enkapsulasi?

Enkapsulasi adalah salah satu pilar utama dalam pemrograman berorientasi objek (OOP). Konsep ini memungkinkan kita untuk "menyembunyikan" data dan method dari akses langsung dari luar class.

Bayangkan enkapsulasi seperti kapsul obat 💊 - isi obat (data) dilindungi oleh cangkang kapsul, dan hanya bisa diakses dengan cara yang benar!

Konsep Dasar

Memahami prinsip-prinsip enkapsulasi

Tingkatan Akses dalam Python

🌍 Public (Publik)

Dapat diakses dari mana saja, baik dari dalam class maupun dari luar class.

Contoh: nama, umur

🏠 Protected (Terlindungi)

Hanya dapat diakses dari dalam class dan class turunannya. Ditandai dengan underscore (_).

Contoh: _alamat, _telepon

⚠️ Ini hanya konvensi, masih bisa diakses dari luar tapi tidak disarankan.

🔒 Private (Pribadi)

Hanya dapat diakses dari dalam class itu sendiri. Ditandai dengan double underscore (__).

Contoh: __password, __saldo

🔐 Python menggunakan "name mangling" untuk menyembunyikan attribute ini.

Catatan Penting tentang Python

Python tidak memiliki enkapsulasi yang benar-benar "ketat" seperti Java atau C++. Semua access modifier di Python lebih bersifat konvensi dan petunjuk untuk programmer lain bahwa data tersebut tidak seharusnya diakses langsung.

Python | contoh_akses.py 
class ContohAkses:
    def __init__(self):
        self.public_var = "Saya bisa diakses dari mana saja! 🌍"
        self._protected_var = "Saya untuk keluarga class ini 🏠"
        self.__private_var = "Saya sangat rahasia! 🔒"
    
    def tampilkan_semua(self):
        print("Dari dalam class:")
        print(f"Public: {self.public_var}")
        print(f"Protected: {self._protected_var}")
        print(f"Private: {self.__private_var}")

# Membuat objek
obj = ContohAkses()

# Akses dari luar class
print("Dari luar class:")
print(obj.public_var)        # ✅ Berhasil
print(obj._protected_var)    # ⚠️ Bisa, tapi tidak disarankan
# print(obj.__private_var)   # ❌ AttributeError!

# Cara mengakses private variable (name mangling)
# print(obj._ContohAkses__private_var)  # ✅ Bisa, tapi tidak disarankan

# Cara yang benar: gunakan method public
obj.tampilkan_semua()        # ✅ Cara yang tepat

Implementasi Access Modifier

Python | rekening_bank.py 
class RekeningBank:
    def __init__(self, nama, saldo_awal):
        self.nama = nama                    # 🌍 Public
        self._nomor_rekening = "001234"     # 🏠 Protected
        self.__saldo = saldo_awal           # 🔒 Private
        self.__pin = "1234"                 # 🔒 Private
    
    def cek_saldo(self):                    # 🌍 Public method
        return f"Saldo Anda: Rp {self.__saldo:,}"
    
    def __validasi_pin(self, pin):          # 🔒 Private method
        return pin == self.__pin
    
    def tarik_uang(self, jumlah, pin):      # 🌍 Public method
        if self.__validasi_pin(pin):
            if jumlah <= self.__saldo:
                self.__saldo -= jumlah
                return f"Berhasil tarik Rp {jumlah:,}"
            else:
                return "Saldo tidak cukup!"
        else:
            return "PIN salah!"

# Penggunaan
rekening = RekeningBank("Ani", 1000000)
print(rekening.nama)                 # ✅ Public - OK
print(rekening.cek_saldo())          # ✅ Public method - OK
print(rekening.tarik_uang(50000, "1234"))  # ✅ OK

class Siswa:
    def __init__(self, nama, nis, kelas):
        # Validasi input
        if not nama or not isinstance(nama, str):
            raise ValueError("Nama harus berupa string dan tidak boleh kosong")
        if not nis or not isinstance(nis, str):
            raise ValueError("NIS harus berupa string dan tidak boleh kosong")
        if not kelas or not isinstance(kelas, str):
            raise ValueError("Kelas harus berupa string dan tidak boleh kosong")
            
        # Public attributes
        self.nama = nama.strip()
        self.kelas = kelas.strip()
        
        # Protected attributes
        self._nis = nis.strip()
        self._tanggal_masuk = "2024-07-01"
        
        # Private attributes
        self.__nilai_rapor = []
        self.__password = "default123"
        self.__status_aktif = True
    
    # Public methods
    def perkenalan(self):
        return f"Halo! Saya {self.nama} dari kelas {self.kelas}"
    
    def info_dasar(self):
        return {
            'nama': self.nama,
            'kelas': self.kelas,
            'nis': self._nis,  # Protected bisa diakses dalam class
            'status': 'Aktif' if self.__status_aktif else 'Tidak Aktif'
        }
    
    # Private method untuk validasi
    def __validasi_password(self, password):
        return password == self.__password
    
    # Public method untuk mengubah password
    def ubah_password(self, password_lama, password_baru):
        if self.__validasi_password(password_lama):
            if len(password_baru) >= 6:
                self.__password = password_baru
                return "Password berhasil diubah"
            else:
                return "Password baru minimal 6 karakter"
        else:
            return "Password lama salah!"
    
    # Public method untuk akses data private dengan aman
    def tambah_nilai(self, nilai, password):
        if self.__validasi_password(password):
            if isinstance(nilai, (int, float)) and 0 <= nilai <= 100:
                self.__nilai_rapor.append(float(nilai))
                return f"Nilai {nilai} berhasil ditambahkan"
            else:
                return "Nilai harus berupa angka antara 0-100"
        else:
            return "Password salah!"
    
    def lihat_nilai(self, password):
        if self.__validasi_password(password):
            if len(self.__nilai_rapor) > 0:
                rata_rata = sum(self.__nilai_rapor) / len(self.__nilai_rapor)
                return {
                    'nilai': self.__nilai_rapor.copy(),  # Return copy untuk keamanan
                    'rata_rata': round(rata_rata, 2),
                    'jumlah_nilai': len(self.__nilai_rapor)
                }
            else:
                return {"pesan": "Belum ada nilai"}
        else:
            return {"error": "Password salah!"}

# Contoh penggunaan
try:
    siswa1 = Siswa("Budi Santoso", "2024001", "XII IPA 1")
    print(siswa1.perkenalan())
    print(siswa1.info_dasar())
    
    # Menambah nilai dengan password
    print(siswa1.tambah_nilai(85, "default123"))
    print(siswa1.tambah_nilai(90, "default123"))
    
    # Melihat nilai
    hasil = siswa1.lihat_nilai("default123")
    print(f"Rata-rata: {hasil['rata_rata']}")
    
except ValueError as e:
    print(f"Error: {e}")

Getter & Setter

Mengakses data private dengan aman

Apa itu Getter dan Setter?

Getter

Method untuk mengambil/membaca nilai dari attribute private.

def get_nama(self):
return self.__nama

Setter

Method untuk mengubah/menulis nilai ke attribute private.

def set_nama(self, nama):
self.__nama = nama
Python | getter_setter_example.py 
class Produk:
    def __init__(self, nama, harga):
        # Validasi input saat inisialisasi
        if not isinstance(nama, str) or len(nama.strip()) == 0:
            raise ValueError("Nama produk harus berupa string dan tidak boleh kosong")
        if not isinstance(harga, (int, float)) or harga <= 0:
            raise ValueError("Harga harus berupa angka positif")
            
        self.__nama = nama.strip()
        self.__harga = float(harga)
        self.__stok = 0
    
    # GETTER METHODS
    def get_nama(self):
        return self.__nama
    
    def get_harga(self):
        return self.__harga
    
    def get_stok(self):
        return self.__stok
    
    def get_info_lengkap(self):
        return {
            'nama': self.__nama,
            'harga': self.__harga,
            'stok': self.__stok,
            'tersedia': self.__stok > 0
        }
    
    # SETTER METHODS dengan validasi
    def set_nama(self, nama_baru):
        if isinstance(nama_baru, str) and len(nama_baru.strip()) > 0:
            self.__nama = nama_baru.strip()
            return f"Nama berhasil diubah: {self.__nama}"
        else:
            return "Error: Nama harus berupa text dan tidak boleh kosong!"
    
    def set_harga(self, harga_baru):
        if isinstance(harga_baru, (int, float)) and harga_baru > 0:
            self.__harga = float(harga_baru)
            return f"Harga berhasil diubah: Rp {self.__harga:,.0f}"
        else:
            return "Error: Harga harus angka positif!"
    
    def tambah_stok(self, jumlah):
        if isinstance(jumlah, int) and jumlah > 0:
            self.__stok += jumlah
            return f"Stok bertambah {jumlah}. Total: {self.__stok}"
        else:
            return "Error: Jumlah harus berupa bilangan bulat positif!"
    
    def kurangi_stok(self, jumlah):
        if isinstance(jumlah, int) and jumlah > 0:
            if jumlah <= self.__stok:
                self.__stok -= jumlah
                return f"Stok berkurang {jumlah}. Sisa: {self.__stok}"
            else:
                return f"Error: Stok tidak cukup! Stok tersedia: {self.__stok}"
        else:
            return "Error: Jumlah harus berupa bilangan bulat positif!"

# Contoh penggunaan
try:
    produk1 = Produk("Laptop Gaming", 15000000)
    print(f"Produk: {produk1.get_nama()}")
    print(f"Harga: Rp {produk1.get_harga():,.0f}")
    
    # Menambah stok
    print(produk1.tambah_stok(10))
    
    # Mengubah harga
    print(produk1.set_harga(14500000))
    
    # Info lengkap
    info = produk1.get_info_lengkap()
    print(f"Info: {info}")
    
except ValueError as e:
    print(f"Error: {e}")

Bonus: Property Decorator (Pythonic Way)

Python menyediakan cara yang lebih elegan untuk membuat getter dan setter menggunakan @property decorator. Ini membuat kode lebih bersih dan mudah dibaca.

Python | property_example.py 
class Mahasiswa:
    def __init__(self, nama, ipk):
        self._nama = nama
        self._ipk = ipk
    
    @property
    def nama(self):
        """Getter untuk nama"""
        return self._nama
    
    @nama.setter
    def nama(self, value):
        """Setter untuk nama dengan validasi"""
        if isinstance(value, str) and len(value.strip()) > 0:
            self._nama = value.strip()
        else:
            raise ValueError("Nama harus berupa string dan tidak boleh kosong")
    
    @property
    def ipk(self):
        """Getter untuk IPK"""
        return self._ipk
    
    @ipk.setter
    def ipk(self, value):
        """Setter untuk IPK dengan validasi"""
        if isinstance(value, (int, float)) and 0.0 <= value <= 4.0:
            self._ipk = float(value)
        else:
            raise ValueError("IPK harus antara 0.0 - 4.0")
    
    @property
    def predikat(self):
        """Property read-only untuk predikat berdasarkan IPK"""
        if self._ipk >= 3.5:
            return "Cum Laude"
        elif self._ipk >= 3.0:
            return "Sangat Memuaskan"
        elif self._ipk >= 2.5:
            return "Memuaskan"
        else:
            return "Cukup"

# Penggunaan seperti attribute biasa
mhs = Mahasiswa("Sari", 3.8)
print(mhs.nama)        # Menggunakan getter
print(mhs.ipk)         # Menggunakan getter
print(mhs.predikat)    # Read-only property

mhs.nama = "Sari Dewi" # Menggunakan setter
mhs.ipk = 3.9          # Menggunakan setter dengan validasi

Keuntungan @property

  • ✅ Sintaks lebih bersih dan natural
  • ✅ Dapat membuat read-only properties
  • ✅ Validasi otomatis saat assignment
  • ✅ Lebih Pythonic dan mudah dibaca
