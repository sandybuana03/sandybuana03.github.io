Pengenalan Polimorfisme

🔄

Apa itu Polimorfisme?

Polimorfisme berasal dari bahasa Yunani yang berarti "banyak bentuk". Dalam pemrograman, polimorfisme memungkinkan satu interface untuk berbagai tipe data atau objek yang berbeda.

⚡

Method Overloading

Method overloading adalah kemampuan untuk membuat beberapa method dengan nama yang sama tetapi dengan parameter yang berbeda (jumlah, tipe, atau urutan parameter).

⚠️

Penting: Python tidak mendukung method overloading tradisional seperti Java atau C++. Di Python, jika kita mendefinisikan method dengan nama sama, method terakhir akan menimpa yang sebelumnya. Namun, kita bisa mencapai efek serupa dengan teknik-teknik khusus!

🎭

Analogi Sederhana

Bayangkan kamu punya remote TV. Tombol "Volume" bisa digunakan untuk menaikkan volume (tanpa parameter), menaikkan ke level tertentu (dengan parameter angka), atau bahkan mute (dengan parameter khusus). Satu tombol, banyak fungsi!

🔍 Perbedaan dengan Bahasa Lain:

Java/C++ (True Overloading):

Compiler memilih method berdasarkan signature

Python (Simulated Overloading):

Satu method dengan logika kondisional internal

💻 Contoh Sederhana

Python - calculator.py Method Overloading 
class Calculator:
    def add(self, a, b=0, c=0):
        """Simulasi method overloading dengan default parameters"""
        return a + b + c
    
    def multiply(self, *args):
        """Simulasi method overloading dengan *args"""
        if len(args) == 0:
            return 0
        result = 1
        for num in args:
            result *= num
        return result

# Penggunaan - satu method, berbagai cara pemanggilan
calc = Calculator()

# Method add dengan parameter berbeda
print(calc.add(5))        # Output: 5 (5+0+0)
print(calc.add(5, 3))     # Output: 8 (5+3+0)
print(calc.add(5, 3, 2))  # Output: 10 (5+3+2)

# Method multiply dengan jumlah parameter variabel
print(calc.multiply(2))         # Output: 2
print(calc.multiply(2, 3))      # Output: 6
print(calc.multiply(2, 3, 4))   # Output: 24
print(calc.multiply())          # Output: 0 (tidak ada parameter)

🎉 Keren kan? Satu method bisa digunakan dengan berbagai cara tergantung parameter yang diberikan!

Implementasi Method Overloading

1️⃣ Teknik Default Parameters

Python - shape.py Default Parameters 
class Shape:
    def draw(self, x=0, y=0, color="black", size=1):
        """Simulasi overloading dengan default parameters"""
        return f"Menggambar di ({x}, {y}) dengan warna {color} dan ukuran {size}"
    
    def area(self, length, width=None):
        """Menghitung luas - persegi atau persegi panjang"""
        if width is None:
            # Jika hanya satu parameter, anggap sebagai persegi
            return length * length
        else:
            # Jika dua parameter, anggap sebagai persegi panjang
            return length * width

# Contoh penggunaan - satu method, berbagai parameter
shape = Shape()

# Method draw dengan parameter yang berbeda-beda
print(shape.draw())                    
# Output: Menggambar di (0, 0) dengan warna black dan ukuran 1

print(shape.draw(10, 20))             
# Output: Menggambar di (10, 20) dengan warna black dan ukuran 1

print(shape.draw(10, 20, "red"))      
# Output: Menggambar di (10, 20) dengan warna red dan ukuran 1

print(shape.draw(10, 20, "blue", 2))  
# Output: Menggambar di (10, 20) dengan warna blue dan ukuran 2

# Method area - perilaku berbeda berdasarkan jumlah parameter
print(f"Luas persegi: {shape.area(5)}")           # Output: 25
print(f"Luas persegi panjang: {shape.area(5, 3)}")  # Output: 15

2️⃣ Teknik *args dan **kwargs

Python - printer.py Variable Arguments 
class Printer:
    def print_info(self, *args, **kwargs):
        """Method overloading dengan *args dan **kwargs"""
        
        if len(args) == 1 and not kwargs:
            # Satu parameter string
            return f"Pesan: {args[0]}"
            
        elif len(args) == 2 and not kwargs:
            # Dua parameter (nama dan pesan)
            return f"{args[0]} berkata: {args[1]}"
            
        elif args and kwargs:
            # Kombinasi args dan kwargs
            message = f"Data: {', '.join(map(str, args))}"
            options = ', '.join([f"{k}={v}" for k, v in kwargs.items()])
            return f"{message} | Opsi: {options}"
            
        elif kwargs and not args:
            # Hanya kwargs
            return f"Pengaturan: {', '.join([f'{k}={v}' for k, v in kwargs.items()])}"
        
        return "Format tidak dikenali"

# Contoh penggunaan
printer = Printer()

print(printer.print_info("Hello World!"))
print(printer.print_info("Alice", "Selamat pagi!"))
print(printer.print_info("Data1", "Data2", format="json", debug=True))
print(printer.print_info(theme="dark", font_size=12))

3️⃣ Teknik @overload Decorator (Type Hints)

Python - math_helper.py @overload Decorator 
from typing import overload, Union

class MathHelper:
    @overload
    def process(self, value: int) -> str: ...
    
    @overload  
    def process(self, value: float) -> str: ...
    
    @overload
    def process(self, value: str) -> int: ...
    
    def process(self, value: Union[int, float, str]) -> Union[str, int]:
        """Implementasi aktual - @overload hanya untuk type hints"""
        if isinstance(value, int):
            return f"Integer: {value}"
        elif isinstance(value, float):
            return f"Float: {value:.2f}"
        elif isinstance(value, str):
            try:
                return len(value)
            except:
                return 0
        return "Unknown type"

# Penggunaan - IDE akan memberikan type hints yang tepat
helper = MathHelper()
print(helper.process(42))        # "Integer: 42"
print(helper.process(3.14))      # "Float: 3.14"  
print(helper.process("hello"))   # 5 (panjang string)

💡 Catatan: @overload hanya untuk type hints dan tidak mengubah perilaku runtime. Implementasi sebenarnya tetap menggunakan satu method dengan logika kondisional.

4️⃣ Teknik Type Checking

Python - converter.py Type Checking 
class Converter:
    def convert(self, value):
        """Method overloading berdasarkan tipe data"""
        
        if isinstance(value, int):
            # Konversi integer ke string
            return f"Integer {value} menjadi string: '{value}'"
            
        elif isinstance(value, float):
            # Konversi float ke integer
            return f"Float {value} menjadi integer: {int(value)}"
            
        elif isinstance(value, str):
            # Coba konversi string ke number
            try:
                if '.' in value:
                    return f"String '{value}' menjadi float: {float(value)}"
                else:
                    return f"String '{value}' menjadi integer: {int(value)}"
            except ValueError:
                return f"String '{value}' tidak bisa dikonversi ke number"
                
        elif isinstance(value, list):
            # Konversi list ke string
            return f"List {value} menjadi string: '{', '.join(map(str, value))}'"
            
        else:
            return f"Tipe {type(value)} tidak didukung"

# Contoh penggunaan
converter = Converter()

print(converter.convert(42))           # Integer
print(converter.convert(3.14))         # Float  
print(converter.convert("123"))        # String angka
print(converter.convert("hello"))      # String biasa
print(converter.convert([1, 2, 3]))    # List

Python - payment_system.py Real World Example 
class PaymentSystem:
    def process_payment(self, amount, method="cash", **details):
        """Method overloading untuk berbagai metode pembayaran"""
        
        if method == "cash":
            return self._process_cash(amount)
            
        elif method == "card":
            card_number = details.get('card_number', 'Unknown')
            return self._process_card(amount, card_number)
            
        elif method == "digital":
            wallet = details.get('wallet', 'Unknown')
            return self._process_digital(amount, wallet)
            
        elif method == "installment":
            months = details.get('months', 1)
            return self._process_installment(amount, months)
    
    def _process_cash(self, amount):
        return f"💵 Pembayaran tunai: Rp {amount:,}"
    
    def _process_card(self, amount, card_number):
        masked_card = f"****-****-****-{card_number[-4:]}"
        return f"💳 Pembayaran kartu {masked_card}: Rp {amount:,}"
    
    def _process_digital(self, amount, wallet):
        return f"📱 Pembayaran {wallet}: Rp {amount:,}"
    
    def _process_installment(self, amount, months):
        monthly = amount / months
        return f"🏦 Cicilan {months}x: Rp {monthly:,.0f}/bulan (Total: Rp {amount:,})"

# Contoh penggunaan
payment = PaymentSystem()

# Berbagai cara pembayaran dengan method yang sama
print(payment.process_payment(100000))  # Cash default
print(payment.process_payment(250000, "card", card_number="1234567890123456"))
print(payment.process_payment(500000, "digital", wallet="GoPay"))
print(payment.process_payment(1200000, "installment", months=12))

Python - logger.py Logging System 
from datetime import datetime

class Logger:
    def log(self, message, level="INFO", include_time=True, **metadata):
        """Method overloading untuk berbagai jenis logging"""
        
        # Buat timestamp jika diperlukan
        timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S") if include_time else ""
        
        # Format level
        level_emoji = {
            "INFO": "ℹ️",
            "WARNING": "⚠️", 
            "ERROR": "❌",
            "SUCCESS": "✅",
            "DEBUG": "🐛"
        }
        
        emoji = level_emoji.get(level, "📝")
        
        # Buat log message
        log_parts = []
        
        if timestamp:
            log_parts.append(f"[{timestamp}]")
            
        log_parts.append(f"{emoji} {level}")
        log_parts.append(message)
        
        # Tambahkan metadata jika ada
        if metadata:
            meta_str = " | ".join([f"{k}={v}" for k, v in metadata.items()])
            log_parts.append(f"({meta_str})")
        
        return " ".join(log_parts)
    
    def quick_log(self, *messages):
        """Quick logging untuk multiple messages"""
        return "\n".join([self.log(msg, include_time=False) for msg in messages])

# Contoh penggunaan
logger = Logger()

# Berbagai cara logging
print(logger.log("Aplikasi dimulai"))
print(logger.log("File tidak ditemukan", "ERROR", user="admin", file="data.txt"))
print(logger.log("Proses selesai", "SUCCESS", False))
print(logger.log("Memory usage tinggi", "WARNING", memory="85%", cpu="60%"))

print("\n" + "="*50)
print("Quick Log:")
print(logger.quick_log("Step 1: Validasi data", "Step 2: Proses data", "Step 3: Simpan hasil"))

🎯 Tugas 1: Buat Class "TextFormatter"

Instruksi:

  • • Buat class TextFormatter dengan method format_text()
  • • Method harus bisa menerima berbagai parameter:
  • - Hanya text: kembalikan text biasa
  • - Text + uppercase: kembalikan text KAPITAL
  • - Text + prefix: kembalikan "prefix: text"
  • - Text + prefix + suffix: kembalikan "prefix: text :suffix"
  • • Gunakan teknik default parameters atau *args/**kwargs

Contoh Output yang Diharapkan:

formatter = TextFormatter()
print(formatter.format_text("hello"))                    # "hello"
print(formatter.format_text("hello", uppercase=True))    # "HELLO"  
print(formatter.format_text("hello", prefix="Greeting")) # "Greeting: hello"
print(formatter.format_text("hello", prefix="Hi", suffix="World")) # "Hi: hello :World"

  • - 2 angka: kembalikan penjumlahan
  • - 2 angka + operator: lakukan operasi sesuai operator (+, -, *, /)
  • - List angka: kembalikan total semua angka
