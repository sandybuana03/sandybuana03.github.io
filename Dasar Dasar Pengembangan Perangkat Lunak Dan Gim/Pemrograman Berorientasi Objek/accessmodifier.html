Pengenalan Access Modifier 📚

Apa itu Access Modifier?

Access Modifier adalah cara untuk mengatur tingkat akses terhadap atribut (variabel) dan method (fungsi) dalam sebuah class. Bayangkan seperti tingkat keamanan di rumah: ada ruangan yang boleh dimasuki siapa saja, ada yang hanya untuk keluarga, dan ada yang benar-benar privat! 🏠🔐

🎯 Definisi Teknis:

Access Modifier adalah mekanisme dalam Object-Oriented Programming (OOP) yang menentukan visibilitas dan aksesibilitas dari anggota class (atribut dan method). Ini adalah implementasi dari prinsip Encapsulation - salah satu pilar utama OOP.

💡 Contoh Sederhana:

Bayangkan kamu punya smartphone:

  • • Public: Layar, tombol volume (semua orang bisa lihat dan gunakan)
  • • Protected: Sistem operasi (hanya aplikasi tertentu yang bisa akses)
  • • Private: Kode keamanan, data enkripsi (hanya sistem internal yang bisa akses)
🌍

Public

Bisa diakses dari mana saja

Sintaks: nama_atribut

Contoh: self.nama

🏠

Protected

Hanya untuk keluarga (inheritance)

Sintaks: _nama_atribut

Contoh: self._umur

🔒

Private

Hanya untuk class itu sendiri

Sintaks: __nama_atribut

Contoh: self.__password

Sejarah dan Konsep

📚 Asal Usul

Konsep Access Modifier berasal dari bahasa pemrograman seperti C++ dan Java. Python mengadopsi konsep ini dengan pendekatan yang lebih fleksibel menggunakan konvensi penamaan.

🐍 Python Way

Python mengikuti filosofi "We are all consenting adults" - memberikan kepercayaan kepada programmer untuk menggunakan Access Modifier dengan bijak.

🏛️ Prinsip Encapsulation

Encapsulation adalah prinsip menyembunyikan detail implementasi internal dan hanya mengekspos interface yang diperlukan. Access Modifier adalah alat untuk mencapai ini.

🎭 Information Hiding

Menyembunyikan informasi yang tidak perlu diketahui oleh pengguna class, sehingga mengurangi kompleksitas dan meningkatkan keamanan.

Mengapa Penting?

🛡️ Keamanan Data

Melindungi data penting dari akses yang tidak diinginkan

Contoh: Password, nomor kartu kredit, kunci enkripsi

🏗️ Struktur Kode

Membuat kode lebih terorganisir dan mudah dipelihara

Manfaat: Kode lebih modular, mudah di-debug, dan scalable

🚫 Mencegah Error

Mengurangi kemungkinan kesalahan dalam program

Cara: Validasi data, kontrol akses, dan konsistensi state

👥 Kerja Tim

Memudahkan kolaborasi dengan programmer lain

Keuntungan: Interface yang jelas, dokumentasi implisit

Public Access Modifier 🌍

Apa itu Public?

Public adalah tingkat akses yang paling terbuka. Atribut atau method yang bersifat public dapat diakses dari mana saja - baik dari dalam class, luar class, maupun class turunan. Di Python, secara default semua atribut dan method adalah public! 🎉

💡 Ciri-ciri Public:

  • • Tidak ada underscore (_) di depan nama
  • • Bisa diakses langsung dari objek
  • • Bisa diubah dari luar class

Contoh Kode Public

Python siswa.py 
class Siswa:
    def __init__(self, nama, kelas):
        self.nama = nama        # Public attribute
        self.kelas = kelas      # Public attribute
        self.nilai = []         # Public attribute
    
    def tambah_nilai(self, nilai):  # Public method
        self.nilai.append(nilai)
        print(f"Nilai {nilai} berhasil ditambahkan! ✅")
    
    def tampilkan_info(self):       # Public method
        print(f"Nama: {self.nama}")
        print(f"Kelas: {self.kelas}")
        print(f"Nilai: {self.nilai}")

# Penggunaan
siswa1 = Siswa("Andi", "XII RPL")

# Akses public attribute (bisa langsung)
print(siswa1.nama)          # Output: Andi
print(siswa1.kelas)         # Output: XII RPL

# Ubah public attribute (bisa langsung)
siswa1.nama = "Budi"
print(siswa1.nama)          # Output: Budi

# Panggil public method
siswa1.tambah_nilai(85)     # Output: Nilai 85 berhasil ditambahkan! ✅
siswa1.tampilkan_info()     # Menampilkan semua info

Kapan Menggunakan Public?

✅ Gunakan untuk:

  • • Data yang memang perlu diakses dari luar
  • • Method yang menjadi interface class
  • • Atribut yang sering digunakan
  • • Konstanta yang bersifat global
  • • Method utility yang umum

⚠️ Hati-hati:

  • • Data bisa diubah sembarangan
  • • Kurang kontrol terhadap validasi
  • • Bisa menimbulkan bug jika disalahgunakan
  • • Sulit melacak perubahan data
  • • Dapat melanggar prinsip encapsulation

Private Access Modifier 🔒

Apa itu Private?

Private adalah tingkat akses yang paling ketat! Atribut atau method yang bersifat private hanya bisa diakses dari dalam class itu sendiri. Di Python, kita menggunakan double underscore (__) di depan nama untuk membuatnya private. 🔐

🔒 Ciri-ciri Private:

  • • Menggunakan double underscore (__) di depan nama
  • • Tidak bisa diakses langsung dari luar class
  • • Hanya bisa diakses melalui method dalam class

Contoh Kode Private

Python rekening.py 
class RekeningBank:
    def __init__(self, nama, saldo_awal):
        self.nama = nama                    # Public
        self.__saldo = saldo_awal          # Private (pakai __)
        self.__pin = "1234"                # Private
    
    def cek_saldo(self):                   # Public method
        return f"Saldo Anda: Rp {self.__saldo:,}"
    
    def __validasi_pin(self, pin):         # Private method
        return pin == self.__pin
    
    def tarik_uang(self, jumlah, pin):     # Public method
        if not self.__validasi_pin(pin):
            return "PIN salah! ❌"
        
        if jumlah > self.__saldo:
            return "Saldo tidak cukup! 💸"
        
        self.__saldo -= jumlah
        return f"Berhasil tarik Rp {jumlah:,}. Sisa saldo: Rp {self.__saldo:,} ✅"
    
    def setor_uang(self, jumlah):          # Public method
        self.__saldo += jumlah
        return f"Berhasil setor Rp {jumlah:,}. Saldo: Rp {self.__saldo:,} ✅"

# Penggunaan
rekening = RekeningBank("Andi", 1000000)

# Akses public attribute (bisa)
print(rekening.nama)                    # Output: Andi

# Akses private attribute (TIDAK BISA langsung)
# print(rekening.__saldo)               # Error!
# print(rekening.__pin)                 # Error!

# Akses melalui public method (bisa)
print(rekening.cek_saldo())             # Output: Saldo Anda: Rp 1,000,000
print(rekening.tarik_uang(50000, "1234"))  # Berhasil
print(rekening.tarik_uang(50000, "0000"))  # PIN salah!

Name Mangling di Python

Python menggunakan teknik "Name Mangling" untuk private attribute. Mari kita lihat bagaimana cara kerjanya:

🔍 Cara Kerja

class MyClass:
    def __init__(self):
        self.__private = "rahasia"

obj = MyClass()

# Tidak bisa diakses langsung
# print(obj.__private)  # Error!

# Tapi bisa diakses dengan name mangling
print(obj._MyClass__private)  # "rahasia"

Python mengubah __private menjadi _MyClass__private

📋 Aturan Name Mangling

  • • Dimulai dengan __ (double underscore)
  • • Tidak diakhiri dengan __
  • • Diubah menjadi _ClassName__attribute
  • • Hanya berlaku dalam definisi class
  • • Tidak berlaku untuk method khusus (__init__, __str__)

Contoh Kasus Nyata Private

🔐 Sistem Login

class UserAccount:
    def __init__(self, username):
        self.username = username    # Public
        self.__password_hash = ""   # Private
        self.__login_attempts = 0   # Private
    
    def __hash_password(self, password):  # Private
        # Simulasi hashing password
        return f"hashed_{password}"
    
    def set_password(self, password):     # Public
        if len(password) < 8:
            raise ValueError("Password minimal 8 karakter")
        self.__password_hash = self.__hash_password(password)
    
    def login(self, password):            # Public
        if self.__login_attempts >= 3:
            return "Akun terkunci!"
        
        if self.__hash_password(password) == self.__password_hash:
            self.__login_attempts = 0
            return "Login berhasil!"
        else:
            self.__login_attempts += 1
            return "Password salah!"

Password hash dan login attempts harus private untuk keamanan.

Protected Access Modifier 🛡️

Apa itu Protected?

Protected adalah tingkat akses menengah. Atribut atau method yang bersifat protected bisa diakses dari dalam class itu sendiri dan class turunannya (inheritance). Di Python, kita menggunakan single underscore (_) di depan nama. 👨‍👩‍👧‍👦

🏠 Ciri-ciri Protected:

  • • Menggunakan single underscore (_) di depan nama
  • • Bisa diakses dari class dan subclass
  • • Konvensi "jangan akses dari luar"

Contoh Kode Protected

Python kendaraan.py 
class Kendaraan:
    def __init__(self, merk, tahun):
        self.merk = merk                    # Public
        self._tahun = tahun                 # Protected (pakai _)
        self._kondisi = "Baik"              # Protected
        self.__nomor_mesin = "ABC123"       # Private
    
    def _perawatan_rutin(self):             # Protected method
        print("Melakukan perawatan rutin... 🔧")
        self._kondisi = "Seperti Baru"
    
    def info_dasar(self):                   # Public method
        return f"Kendaraan {self.merk} tahun {self._tahun}"

class Mobil(Kendaraan):  # Inheritance dari Kendaraan
    def __init__(self, merk, tahun, jenis):
        super().__init__(merk, tahun)
        self.jenis = jenis                  # Public
        self._kapasitas = 5                 # Protected
    
    def service_mobil(self):                # Public method
        # Bisa akses protected dari parent class
        print(f"Service mobil {self.merk} tahun {self._tahun}")
        self._perawatan_rutin()             # Akses protected method
        print(f"Kondisi sekarang: {self._kondisi}")
    
    def info_lengkap(self):
        # Bisa akses protected attribute
        return f"{self.jenis} {self.merk} ({self._tahun}) - Kapasitas: {self._kapasitas} orang"

# Penggunaan
mobil = Mobil("Toyota", 2020, "SUV")

# Akses public (bisa)
print(mobil.merk)                          # Toyota
print(mobil.jenis)                         # SUV

# Akses protected (secara teknis bisa, tapi tidak disarankan)
print(mobil._tahun)                        # 2020 (tapi jangan!)

# Cara yang benar: akses melalui method
print(mobil.info_lengkap())                # SUV Toyota (2020) - Kapasitas: 5 orang
mobil.service_mobil()                      # Service dengan akses protected

Inheritance dan Protected

Protected sangat berguna dalam inheritance. Mari lihat contoh lengkap:

Python inheritance_example.py 
class Animal:
    def __init__(self, name, species):
        self.name = name                    # Public
        self._species = species             # Protected
        self._energy = 100                  # Protected
        self.__dna = "ATCG123"             # Private
    
    def _rest(self):                       # Protected method
        """Method untuk istirahat - bisa digunakan subclass"""
        self._energy = min(100, self._energy + 20)
        print(f"{self.name} beristirahat. Energi: {self._energy}")
    
    def _consume_energy(self, amount):     # Protected method
        """Method untuk mengurangi energi"""
        self._energy = max(0, self._energy - amount)
    
    def get_info(self):                    # Public method
        return f"{self.name} adalah {self._species}"

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name, "Anjing")
        self.breed = breed                 # Public
        self._bark_volume = 5              # Protected
    
    def bark(self):                        # Public method
        """Anjing menggonggong"""
        self._consume_energy(5)            # Akses protected method parent
        print(f"{self.name} menggonggong! Volume: {self._bark_volume}")
        
        if self._energy < 20:              # Akses protected attribute parent
            print(f"{self.name} kelelahan...")
            self._rest()                   # Akses protected method parent
    
    def train(self):                       # Public method
        """Melatih anjing"""
        print(f"Melatih {self.name} ({self._species})")  # Akses protected
        self._consume_energy(15)
        
        if self._energy < 30:
            self._rest()

class Cat(Animal):
    def __init__(self, name, color):
        super().__init__(name, "Kucing")
        self.color = color                 # Public
        self._stealth_mode = False         # Protected
    
    def hunt(self):                        # Public method
        """Kucing berburu"""
        if not self._stealth_mode:
            self._activate_stealth()       # Protected method
        
        self._consume_energy(10)           # Akses protected parent
        print(f"{self.name} sedang berburu...")
        
        if self._energy < 25:
            self._rest()                   # Akses protected parent
    
    def _activate_stealth(self):           # Protected method
        """Mengaktifkan mode siluman"""
        self._stealth_mode = True
        print(f"{self.name} masuk mode siluman")

# Penggunaan
dog = Dog("Buddy", "Golden Retriever")
cat = Cat("Whiskers", "Orange")

# Public access - OK
print(dog.get_info())                      # OK
dog.bark()                                 # OK
cat.hunt()                                 # OK

# Protected access - Secara teknis bisa, tapi tidak disarankan
print(dog._energy)                         # Bisa, tapi jangan!
dog._rest()                                # Bisa, tapi jangan!

# Private access - Tidak bisa langsung
# print(dog.__dna)                         # Error!

🎯 Poin Penting:

  • • Subclass bisa mengakses protected attribute dan method dari parent
  • • Protected memungkinkan sharing functionality antar class dalam hierarchy
  • • Tetap memberikan "peringatan" kepada programmer lain untuk tidak mengakses langsung

Template Method Pattern

Protected sangat berguna untuk Template Method Pattern - pola desain yang mendefinisikan kerangka algoritma:

Python template_pattern.py 
class DataProcessor:
    """Template class untuk memproses data"""
    
    def process_data(self, data):          # Public - template method
        """Template method yang mendefinisikan alur kerja"""
        print("Memulai pemrosesan data...")
        
        # Langkah-langkah yang bisa di-override subclass
        validated_data = self._validate_data(data)
        processed_data = self._transform_data(validated_data)
        result = self._save_data(processed_data)
        
        print("Pemrosesan selesai!")
        return result
    
    def _validate_data(self, data):        # Protected - bisa di-override
        """Validasi data - implementasi default"""
        print("Validasi data default...")
        if not data:
            raise ValueError("Data tidak boleh kosong")
        return data
    
    def _transform_data(self, data):       # Protected - harus di-override
        """Transform data - harus diimplementasi subclass"""
        raise NotImplementedError("Subclass harus implement _transform_data")
    
    def _save_data(self, data):            # Protected - bisa di-override
        """Simpan data - implementasi default"""
        print(f"Menyimpan data: {data}")
        return {"status": "saved", "data": data}

class CSVProcessor(DataProcessor):
    """Processor khusus untuk file CSV"""
    
    def _validate_data(self, data):        # Override protected method
        """Validasi khusus untuk CSV"""
        print("Validasi format CSV...")
        super()._validate_data(data)       # Panggil parent validation
        
        if not isinstance(data, str):
            raise ValueError("Data harus berupa string CSV")
        return data
    
    def _transform_data(self, data):       # Implement abstract protected method
        """Transform CSV ke dictionary"""
        print("Mengubah CSV ke dictionary...")
        lines = data.strip().split('\n')
        headers = lines[0].split(',')
        result = []
        
        for line in lines[1:]:
            values = line.split(',')
            result.append(dict(zip(headers, values)))
        
        return result

class JSONProcessor(DataProcessor):
    """Processor khusus untuk JSON"""
    
    def _transform_data(self, data):       # Implement abstract protected method
        """Transform JSON string ke dictionary"""
        print("Parsing JSON...")
        import json
        return json.loads(data)
    
    def _save_data(self, data):            # Override protected method
        """Simpan dengan format khusus JSON"""
        print("Menyimpan dalam format JSON khusus...")
        return {"status": "json_saved", "count": len(data), "data": data}

# Penggunaan
csv_data = "name,age\nJohn,25\nJane,30"
json_data = '{"users": [{"name": "John", "age": 25}]}'

csv_processor = CSVProcessor()
json_processor = JSONProcessor()

# Template method yang sama, implementasi berbeda
csv_result = csv_processor.process_data(csv_data)
json_result = json_processor.process_data(json_data)

🏗️ Keuntungan Template Method:

  • • Alur kerja yang konsisten di semua subclass
  • • Fleksibilitas untuk customize langkah-langkah tertentu
  • • Code reuse yang maksimal
  • • Mudah menambah processor baru
