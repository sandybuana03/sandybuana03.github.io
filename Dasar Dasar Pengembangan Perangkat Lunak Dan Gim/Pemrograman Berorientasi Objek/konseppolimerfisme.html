Pengenalan Polimorfisme

🎭 Apa itu Polimorfisme?

Polimorfisme berasal dari bahasa Yunani yang berarti "banyak bentuk". Dalam pemrograman, polimorfisme adalah kemampuan objek yang berbeda untuk merespons pesan yang sama dengan cara yang berbeda.

Analogi Sederhana: Bayangkan kamu punya 3 hewan peliharaan: anjing 🐕, kucing 🐱, dan burung 🐦. Ketika kamu bilang "bersuara!", masing-masing akan mengeluarkan suara yang berbeda - anjing menggonggong, kucing mengeong, burung berkicau.

Keuntungan Polimorfisme

  • ✨ Kode lebih fleksibel
  • 🔧 Mudah dipelihara
  • 📈 Dapat diperluas
  • 🎯 Lebih efisien

Jenis Polimorfisme

  • 🔄 Method Overriding
  • 🦆 Duck Typing
  • ⚡ Operator Overloading
  • 🎪 Interface Polymorphism

Konsep Dasar Polimorfisme

🏗️ Inheritance sebagai Fondasi

Polimorfisme bekerja dengan baik ketika ada hubungan inheritance (pewarisan) antar class. Mari lihat contoh dasar:

Python hewan.py 
# Class induk (parent class)
class Hewan:
    def __init__(self, nama):
        self.nama = nama
    
    def bersuara(self):
        pass  # Method yang akan di-override
    
    def info(self):
        return f"Ini adalah {self.nama}"

# Class anak (child class)
class Anjing(Hewan):
    def bersuara(self):
        return "Guk guk! 🐕"

class Kucing(Hewan):
    def bersuara(self):
        return "Meow meow! 🐱"

class Burung(Hewan):
    def bersuara(self):
        return "Kicau kicau! 🐦"

🎯 Implementasi Polimorfisme

Sekarang kita bisa menggunakan polimorfisme untuk memanggil method yang sama pada objek yang berbeda:

Python main.py 
# Membuat objek dari berbagai class
hewan_list = [
    Anjing("Buddy"),
    Kucing("Whiskers"), 
    Burung("Tweety")
]

# Polimorfisme dalam aksi!
print("🎭 Demo Polimorfisme:")
print("=" * 30)

for hewan in hewan_list:
    print(f"{hewan.info()}")
    print(f"Suara: {hewan.bersuara()}")
    print("-" * 20)

Method Overriding

                    


                    

                        

                            
🎯 Apa itu Method Overriding?

                            
Method overriding adalah kemampuan class anak untuk memberikan implementasi spesifik dari method yang sudah didefinisikan di class induk.

                            
                            

                                
Analogi: Seperti resep masakan turun temurun. Nenek punya resep rendang, tapi setiap anak dan cucu bisa memodifikasi resep tersebut sesuai selera mereka! 👵➡️👩‍🍳➡️👨‍🍳

                            

                        


                        

                            
🚗 Contoh: Kendaraan

                            
                            

                                

                                    
                                    Python
                                    kendaraan.py
                                

                                
class Kendaraan:
    def __init__(self, merk, warna):
        self.merk = merk
        self.warna = warna
    
    def start_engine(self):
        return "Engine started! 🔥"
    
    def stop_engine(self):
        return "Engine stopped! ⏹️"
    
    def info(self):
        return f"{self.merk} berwarna {self.warna}"

class Mobil(Kendaraan):
    def start_engine(self):  # Override method
        return "Mobil: Vroom vroom! 🚗💨"
    
    def klakson(self):  # Method tambahan
        return "Beep beep! 📯"

class Motor(Kendaraan):
    def start_engine(self):  # Override method
        return "Motor: Ngeng ngeng! 🏍️💨"
    
    def gas_pol(self):  # Method tambahan
        return "Ngeeeeng! 🏁"

class Sepeda(Kendaraan):
    def start_engine(self):  # Override method
        return "Sepeda: Kayuh kayuh! 🚴‍♂️ (No engine needed!)"
    
    def bel(self):  # Method tambahan
        return "Kring kring! 🔔"

                            


                            

                                

                                    
                                    Python
                                    contoh_penggunaan.py
                                

                                
# Contoh penggunaan kelas kendaraan
def test_kendaraan():
    # Membuat objek dari berbagai kendaraan
    mobil = Mobil("Toyota", "Merah")
    motor = Motor("Honda", "Hitam") 
    sepeda = Sepeda("Polygon", "Biru")
    
    # List kendaraan untuk polimorfisme
    kendaraan_list = [mobil, motor, sepeda]
    
    print("🚗 Test Polimorfisme Kendaraan:")
    print("=" * 40)
    
    for kendaraan in kendaraan_list:
        print(f"\n{kendaraan.info()}")
        print(f"Start: {kendaraan.start_engine()}")
        print(f"Stop: {kendaraan.stop_engine()}")
        
        # Method khusus masing-masing kendaraan
        if hasattr(kendaraan, 'klakson'):
            print(f"Klakson: {kendaraan.klakson()}")
        elif hasattr(kendaraan, 'gas_pol'):
            print(f"Gas pol: {kendaraan.gas_pol()}")
        elif hasattr(kendaraan, 'bel'):
            print(f"Bel: {kendaraan.bel()}")
        
        print("-" * 30)

# Jalankan test
test_kendaraan()

Duck Typing

                        
"If it walks like a duck and quacks like a duck, then it's a duck!" 🦆

                    


                    

                        

                            
🤔 Apa itu Duck Typing?

                            
Duck typing adalah konsep di Python dimana tipe objek tidak sepenting perilaku objek tersebut. Jika objek memiliki method yang dibutuhkan, maka objek tersebut bisa digunakan!

                            
                            

                                
Filosofi: "Jika sesuatu berjalan seperti bebek dan bersuara seperti bebek, maka itu adalah bebek!" - Tidak peduli apakah itu benar-benar bebek atau bukan. 🦆

                            

                        


                        

                            
🎵 Contoh: Pemutar Musik

                            
                            

                                

                                    
                                    Python
                                    music_player.py
                                

                                
# Tidak ada inheritance, tapi punya method yang sama!

class MP3Player:
    def __init__(self, brand):
        self.brand = brand
    
    def play(self):
        return f"{self.brand} MP3: ♪ Playing music... 🎵"
    
    def stop(self):
        return f"{self.brand} MP3: ⏹️ Music stopped"

class Smartphone:
    def __init__(self, model):
        self.model = model
    
    def play(self):
        return f"{self.model}: 🎶 Streaming from Spotify... 📱"
    
    def stop(self):
        return f"{self.model}: ⏸️ Paused streaming"

class Radio:
    def __init__(self, frequency):
        self.frequency = frequency
    
    def play(self):
        return f"Radio {self.frequency}FM: 📻 On air... 🎙️"
    
    def stop(self):
        return f"Radio {self.frequency}FM: 📴 Signal off"

# Fungsi yang menggunakan duck typing
def start_music_session(devices):
    print("🎉 Memulai sesi musik!")
    print("=" * 30)
    
    for device in devices:
        # Duck typing: tidak peduli tipe objek,
        # yang penting punya method play() dan stop()
        print(device.play())
        print(device.stop())
        print("-" * 20)

# Contoh penggunaan duck typing
def demo_music_devices():
    # Membuat berbagai perangkat musik
    mp3_player = MP3Player("Sony Walkman")
    smartphone = Smartphone("iPhone 13")
    radio = Radio("101.1")
    
    # List perangkat untuk duck typing
    music_devices = [mp3_player, smartphone, radio]
    
    print("🎵 Demo Duck Typing - Pemutar Musik:")
    print("=" * 45)
    
    # Duck typing dalam aksi!
    for device in music_devices:
        print(f"\n🎧 Testing {device.__class__.__name__}:")
        print(f"▶️  {device.play()}")
        print(f"⏹️  {device.stop()}")
        print("-" * 35)
    
    print("\n💡 Semua perangkat bisa digunakan dengan cara yang sama!")
    print("   Meskipun tidak ada hubungan inheritance antar class!")

# Jalankan demo
demo_music_devices()

🏪 Sistem Kasir Toko

                            
Mari buat sistem kasir yang bisa menghitung harga berbagai jenis produk dengan cara yang berbeda!

                            
                            

                                

                                    
                                    Python
                                    kasir_toko.py
                                

                                
class Produk:
    def __init__(self, nama, harga_dasar):
        self.nama = nama
        self.harga_dasar = harga_dasar
    
    def hitung_harga(self, jumlah):
        return self.harga_dasar * jumlah
    
    def info(self):
        return f"{self.nama} - Rp {self.harga_dasar:,}"

class ProdukDiskon(Produk):
    def __init__(self, nama, harga_dasar, diskon_persen):
        super().__init__(nama, harga_dasar)
        self.diskon_persen = diskon_persen
    
    def hitung_harga(self, jumlah):  # Override
        harga_normal = super().hitung_harga(jumlah)
        diskon = harga_normal * (self.diskon_persen / 100)
        return harga_normal - diskon

class ProdukGrosir(Produk):
    def __init__(self, nama, harga_dasar, min_grosir, harga_grosir):
        super().__init__(nama, harga_dasar)
        self.min_grosir = min_grosir
        self.harga_grosir = harga_grosir
    
    def hitung_harga(self, jumlah):  # Override
        if jumlah >= self.min_grosir:
            return self.harga_grosir * jumlah
        return super().hitung_harga(jumlah)

# Contoh penggunaan sistem kasir
def demo_kasir_toko():
    # Membuat berbagai jenis produk
    beras = Produk("Beras Premium", 15000)
    minyak = ProdukDiskon("Minyak Goreng", 25000, 20)  # Diskon 20%
    gula = ProdukGrosir("Gula Pasir", 14000, 10, 12000)  # Min 10 untuk grosir
    
    # List produk untuk polimorfisme
    produk_list = [beras, minyak, gula]
    
    print("🏪 Demo Sistem Kasir Toko:")
    print("=" * 40)
    
    # Simulasi pembelian
    pembelian = [
        (beras, 2),    # 2 kg beras
        (minyak, 5),   # 5 botol minyak (dapat diskon)
        (gula, 15)     # 15 kg gula (dapat harga grosir)
    ]
    
    total_belanja = 0
    
    print("\n🧾 STRUK BELANJA")
    print("=" * 30)
    
    for produk, jumlah in pembelian:
        harga = produk.hitung_harga(jumlah)
        total_belanja += harga
        
        print(f"{jumlah}x {produk.nama}")
        
        # Tampilkan info khusus berdasarkan jenis produk
        if isinstance(produk, ProdukDiskon):
            print(f"   (Diskon {produk.diskon_persen}%)")
        elif isinstance(produk, ProdukGrosir) and jumlah >= produk.min_grosir:
            print(f"   (Harga Grosir)")
        
        print(f"   Rp {harga:,}")
        print("-" * 25)
    
    print(f"\nTOTAL: Rp {total_belanja:,}")
    print("\n💡 Polimorfisme memungkinkan sistem kasir")
    print("   menghitung harga berbagai jenis produk")
    print("   dengan cara yang berbeda!")

# Jalankan demo
demo_kasir_toko()
