Pengenalan Class dan Object

Apa itu Class?

Class adalah seperti "cetakan kue" atau "blueprint" yang digunakan untuk membuat objek. Bayangkan class seperti cetakan kue yang bisa digunakan berulang-ulang untuk membuat kue dengan bentuk yang sama!

🏗️ Analogi Arsitektur:

Class = Blueprint rumah | Object = Rumah yang dibangun
Satu blueprint bisa digunakan untuk membangun banyak rumah dengan desain sama tapi lokasi berbeda!

🏠🏠🏠 ← 📋

Rumah (Objects) ← Blueprint (Class)

Apa itu Object?

Object adalah hasil dari class yang sudah "dicetak" atau dibuat. Jika class adalah cetakan, maka object adalah kue yang dihasilkan dari cetakan tersebut.

Contoh dalam kehidupan nyata:

Class: Mobil

Object: Avanza putih, Innova hitam, Xenia silver

Class: Siswa

Object: Budi (XII RPL 1), Sari (XII RPL 2)

🎮 Analogi Game:

Class = Template karakter (Warrior, Mage, Archer)
Object = Karakter pemain (Budi si Warrior level 10, Sari si Mage level 15)

Konsep Fundamental OOP

📦 Encapsulation

Menyembunyikan detail internal dan hanya menampilkan interface yang diperlukan

🧬 Inheritance

Class anak dapat mewarisi sifat dari class parent

🎭 Polymorphism

Satu interface dapat memiliki implementasi yang berbeda

🎯 Abstraction

Fokus pada apa yang dilakukan, bukan bagaimana cara kerjanya

Mengapa OOP Penting?

🎯 Organisasi: Kode lebih rapi dan terstruktur

🔄 Reusable: Bisa digunakan berulang-ulang

🛠️ Maintainable: Mudah diperbaiki dan dikembangkan

🧩 Modular: Setiap bagian punya fungsi sendiri

👥 Collaborative: Tim bisa bekerja pada bagian berbeda

🔒 Secure: Data dapat dilindungi dengan enkapsulasi

🌍 Aplikasi di Dunia Nyata:

  • • E-commerce: Class Product, User, Order, Payment
  • • Social Media: Class User, Post, Comment, Like
  • • Game: Class Player, Enemy, Weapon, Level
  • • Banking: Class Account, Transaction, Customer

Membuat Class Dasar

Sintaks Dasar Class

Python class_dasar.py 
# 1. Class kosong - hanya struktur dasar
class Siswa:
    pass  # Placeholder untuk class kosong

# 2. Class dengan atribut class (shared)
class Mobil:
    # Atribut class - sama untuk semua object
    roda = 4
    jenis_kendaraan = "Darat"
    
    # Method sederhana
    def klakson(self):
        return "Beep beep!"
    
    def info_dasar(self):
        return f"Kendaraan {self.jenis_kendaraan} dengan {self.roda} roda"

# 3. Class dengan atribut dan method lebih lengkap
class Hewan:
    # Atribut class
    kingdom = "Animalia"
    
    def bersuara(self):
        return "Hewan ini bersuara"
    
    def bergerak(self):
        return "Hewan ini bergerak"
    
    def info_kingdom(self):
        return f"Termasuk dalam kingdom: {self.kingdom}"

# Contoh penggunaan:
# mobil1 = Mobil()
# print(mobil1.klakson())  # Output: Beep beep!
# print(mobil1.info_dasar())  # Output: Kendaraan Darat dengan 4 roda

📝 Penjelasan:

  • • class adalah kata kunci untuk membuat class
  • • Nama class menggunakan PascalCase (huruf pertama kapital)
  • • pass digunakan jika class masih kosong
  • • self merujuk pada object yang sedang digunakan

Perbedaan Atribut Class vs Instance

🏢 Atribut Class

  • • Shared oleh semua object
  • • Didefinisikan di level class
  • • Contoh: Mobil.roda = 4
  • • Berubah untuk semua instance

👤 Atribut Instance

  • • Unik untuk setiap object
  • • Didefinisikan dengan self
  • • Contoh: self.nama = "Budi"
  • • Independen antar instance

Best Practices & Tips

💡 Naming Convention: Gunakan PascalCase

🎯 Single Responsibility: Satu class untuk satu konsep

📝 Dokumentasi: Beri docstring yang jelas

🔧 Self Parameter: Selalu gunakan self di method

🏗️ Encapsulation: Gunakan _ untuk private attributes

🧪 Testing: Test setiap method yang dibuat

⚠️ Common Mistakes:

  • • Lupa menggunakan self parameter
  • • Menggunakan camelCase instead of PascalCase
  • • Membuat class terlalu kompleks (God Object)
  • • Tidak menggunakan constructor saat diperlukan

Constructor (__init__)

Apa itu Constructor?

Constructor adalah method khusus yang otomatis dipanggil saat object dibuat. Seperti "setup awal" saat kita membeli HP baru - langsung diatur nama, wallpaper, dll.

Python constructor_lengkap.py 
# 1. Constructor dengan parameter wajib
class Siswa:
    def __init__(self, nama, kelas, umur):
        """
        Constructor untuk membuat object Siswa
        Args:
            nama (str): Nama lengkap siswa
            kelas (str): Kelas siswa (contoh: XII RPL 1)
            umur (int): Umur siswa dalam tahun
        """
        # Atribut instance (unik untuk setiap object)
        self.nama = nama
        self.kelas = kelas
        self.umur = umur
        self.nilai = []  # List untuk menyimpan nilai
        self.absensi = 0  # Counter kehadiran
        self.status = "Aktif"  # Status siswa
        
    def perkenalan(self):
        return f"Halo! Nama saya {self.nama}, kelas {self.kelas}, umur {self.umur} tahun"
    
    def tambah_nilai(self, mata_pelajaran, nilai):
        """Menambahkan nilai untuk mata pelajaran tertentu"""
        if 0 <= nilai <= 100:
            self.nilai.append({
                'mapel': mata_pelajaran,
                'nilai': nilai,
                'grade': self._hitung_grade(nilai)
            })
            return f"Nilai {mata_pelajaran}: {nilai} berhasil ditambahkan!"
        else:
            return "Nilai harus antara 0-100!"
    
    def _hitung_grade(self, nilai):
        """Method private untuk menghitung grade"""
        if nilai >= 90: return 'A'
        elif nilai >= 80: return 'B'
        elif nilai >= 70: return 'C'
        elif nilai >= 60: return 'D'
        else: return 'E'
    
    def rata_rata(self):
        """Menghitung rata-rata nilai"""
        if not self.nilai:
            return 0
        total = sum(item['nilai'] for item in self.nilai)
        return total / len(self.nilai)

# 2. Constructor dengan parameter default
class Produk:
    def __init__(self, nama, harga, kategori="Umum", stok=0):
        """Constructor dengan parameter default"""
        self.nama = nama
        self.harga = harga
        self.kategori = kategori
        self.stok = stok
        self.terjual = 0
    
    def jual(self, jumlah=1):
        if self.stok >= jumlah:
            self.stok -= jumlah
            self.terjual += jumlah
            return f"Berhasil menjual {jumlah} {self.nama}"
        return "Stok tidak mencukupi!"

# Contoh penggunaan:
# siswa1 = Siswa("Budi Santoso", "XII RPL 1", 17)
# siswa1.tambah_nilai("Matematika", 85)
# print(siswa1.rata_rata())  # Output: 85.0

# produk1 = Produk("Laptop Gaming", 15000000, "Elektronik", 5)
# print(produk1.jual(2))  # Output: Berhasil menjual 2 Laptop Gaming

🔍 Penjelasan Detail:

  • • __init__ adalah nama khusus untuk constructor
  • • Parameter pertama selalu self
  • • self.nama = nama menyimpan data ke object
  • • Setiap object punya data yang terpisah

Method dalam Class

Apa itu Method?

Method adalah fungsi yang ada di dalam class. Seperti "kemampuan" atau "aksi" yang bisa dilakukan object. Misalnya mobil bisa "jalan", "belok", "klakson" - itu semua adalah method!

Python method_example.py 
class Kalkulator:
    def __init__(self, nama_kalkulator):
        self.nama = nama_kalkulator
        self.riwayat = []
    
    def tambah(self, a, b):
        hasil = a + b
        operasi = f"{a} + {b} = {hasil}"
        self.riwayat.append(operasi)
        return hasil
    
    def kurang(self, a, b):
        hasil = a - b
        operasi = f"{a} - {b} = {hasil}"
        self.riwayat.append(operasi)
        return hasil
    
    def lihat_riwayat(self):
        if not self.riwayat:
            return "Belum ada operasi yang dilakukan"
        return "\n".join(self.riwayat)
    
    def reset_riwayat(self):
        self.riwayat = []
        return "Riwayat berhasil dihapus!"

Jenis-jenis Method

🔧 Instance Method

Method biasa yang menggunakan self dan bisa akses data object

def method(self):

🏭 Class Method

Method yang bekerja di level class, menggunakan @classmethod

@classmethod
def method(cls):

⚡ Static Method

Method independen yang tidak akses class/instance

@staticmethod
def method():

🔒 Method Visibility:

Public: def method(self)

Bisa diakses dari mana saja

Protected: def _method(self)

Untuk internal class/subclass

Private: def __method(self)

Hanya untuk class itu sendiri

Special Methods (Magic Methods)

Special methods adalah method dengan nama khusus yang diawali dan diakhiri dengan double underscore (__). Method ini dipanggil otomatis oleh Python dalam situasi tertentu.

🏗️ Object Lifecycle

  • __init__() - Constructor
  • __del__() - Destructor
  • __new__() - Object creation

📝 String Representation

  • __str__() - User-friendly string
  • __repr__() - Developer string
  • __format__() - Custom formatting

🔢 Arithmetic Operations

  • __add__() - Addition (+)
  • __sub__() - Subtraction (-)
  • __mul__() - Multiplication (*)

📊 Comparison

  • __eq__() - Equal (==)
  • __lt__() - Less than (<)
  • __len__() - Length

Instansiasi Object

Cara Membuat Object

Instansiasi adalah proses membuat object dari class. Seperti mencetak kue dari cetakan - satu cetakan bisa menghasilkan banyak kue yang berbeda-beda!

Python instansiasi.py 
# Definisi class
class Handphone:
    def __init__(self, merk, model, warna):
        self.merk = merk
        self.model = model
        self.warna = warna
        self.baterai = 100
        self.status = "mati"
    
    def nyalakan(self):
        self.status = "hidup"
        return f"{self.merk} {self.model} berhasil dinyalakan!"
    
    def matikan(self):
        self.status = "mati"
        return f"{self.merk} {self.model} dimatikan"
    
    def info_hp(self):
        return f"HP: {self.merk} {self.model} ({self.warna}) - Baterai: {self.baterai}% - Status: {self.status}"

# Instansiasi - membuat object dari class
hp1 = Handphone("Samsung", "Galaxy A54", "Biru")
hp2 = Handphone("iPhone", "14 Pro", "Ungu")
hp3 = Handphone("Xiaomi", "Redmi Note 12", "Hitam")

# Menggunakan method
print(hp1.info_hp())
print(hp1.nyalakan())
print(hp2.info_hp())

📱 Penjelasan:

  • • hp1 = Handphone(...) membuat object baru
  • • Setiap object punya data yang terpisah
  • • hp1.nyalakan() memanggil method pada object
  • • Satu class bisa membuat banyak object berbeda
