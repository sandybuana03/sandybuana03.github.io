Pengenalan Method Overriding 📖

Mari kenali konsep dasar yang akan kita pelajari!

Apa itu Method Overriding? 🤔

Method Overriding adalah kemampuan subclass (class anak) untuk mengganti implementasi method yang sudah ada di superclass (class induk) dengan implementasi yang baru. Method di class anak akan "menimpa" method di class induk ketika dipanggil.

Analogi Sederhana:

🐕 Anjing dan 🐱 Kucing sama-sama hewan, keduanya punya method "bersuara()". Tapi implementasinya berbeda: Anjing menggonggong "Woof!", Kucing mengeong "Meow!". Masing-masing "meng-override" method bersuara() dari class Hewan induknya.

⚠️ Penting untuk Diingat:

Method Overriding berbeda dengan Method Overloading. Overriding mengubah implementasi method yang sudah ada, sedangkan Overloading membuat method baru dengan parameter berbeda (Python tidak mendukung overloading secara native).

Keuntungan 👍

  • • Kode lebih fleksibel dan mudah diubah
  • • Setiap class bisa punya perilaku unik
  • • Mendukung prinsip polymorphism
  • • Memudahkan maintenance kode

Yang Perlu Diingat ⚠️

  • • Method harus punya nama yang sama
  • • Parameter harus sama (signature)
  • • Hanya mengubah implementasi/isi method
  • • Bisa menggunakan super() untuk akses parent

Contoh Sederhana 💡

Mari lihat contoh sederhana method overriding:

Python • contoh_sederhana.py 
# Class induk (Parent/Superclass)
class Hewan:
    def __init__(self, nama):
        self.nama = nama
    
    def bersuara(self):
        return f"{self.nama} bersuara dengan cara umum"
    
    def info(self):
        return f"Ini adalah {self.nama}"

# Class anak (Child/Subclass) 
class Anjing(Hewan):
    def __init__(self, nama):
        super().__init__(nama)  # Panggil constructor parent
    
    def bersuara(self):  # Method overriding
        return f"{self.nama} menggonggong: Woof! Woof! 🐕"

class Kucing(Hewan):
    def __init__(self, nama):
        super().__init__(nama)  # Panggil constructor parent
    
    def bersuara(self):  # Method overriding
        return f"{self.nama} mengeong: Meow! Meow! 🐱"

# Penggunaan
anjing = Anjing("Buddy")
kucing = Kucing("Whiskers")
hewan_umum = Hewan("Hewan X")

print(hewan_umum.bersuara())  # Output: Hewan X bersuara dengan cara umum
print(anjing.bersuara())      # Output: Buddy menggonggong: Woof! Woof! 🐕
print(kucing.bersuara())      # Output: Whiskers mengeong: Meow! Meow! 🐱

🖥️ Output Program:

Hewan X bersuara dengan cara umum
Buddy menggonggong: Woof! Woof! 🐕
Whiskers mengeong: Meow! Meow! 🐱

Perhatikan: Method bersuara() di class Anjing dan Kucing meng-override method bersuara() dari class Hewan, sehingga menghasilkan output yang berbeda sesuai implementasi masing-masing.

Konsep Dasar Method Overriding 💡

Memahami aturan dan cara kerja method overriding

Aturan Method Overriding 📋

✅ Yang Boleh Diubah:

  • • Isi/implementasi method (logic di dalam method)
  • • Return value dan tipe return
  • • Menambah fungsionalitas baru
  • • Menggunakan super() untuk akses parent method
  • • Menambah exception handling

❌ Yang Harus Tetap Sama:

  • • Nama method (harus identik)
  • • Jumlah parameter
  • • Urutan parameter
  • • Method signature secara keseluruhan
  • • Access modifier tidak boleh lebih restrictive

💡 Catatan Penting:

Method signature adalah kombinasi nama method + parameter (jumlah, tipe, urutan). Untuk method overriding, signature harus persis sama dengan method di parent class.

Menggunakan super() 🪄

super() adalah fungsi khusus untuk mengakses method dari parent class. Berguna ketika kita ingin menambah fungsionalitas, bukan mengganti sepenuhnya.

Python • super_example.py 
class Kendaraan:
    def __init__(self, merk, tahun):
        self.merk = merk
        self.tahun = tahun
    
    def info(self):
        return f"Kendaraan {self.merk} tahun {self.tahun}"

class Mobil(Kendaraan):
    def __init__(self, merk, tahun, pintu):
        super().__init__(merk, tahun)  # Panggil constructor parent
        self.pintu = pintu
    
    def info(self):
        # Gunakan method parent + tambahan info
        info_dasar = super().info()
        return f"{info_dasar} dengan {self.pintu} pintu 🚗"

# Penggunaan
mobil = Mobil("Toyota", 2023, 4)
print(mobil.info())

🖥️ Output Program:

Kendaraan Toyota tahun 2023 dengan 4 pintu 🚗

Method Overriding dan Polymorphism 🔄

Method overriding adalah implementasi dari konsep Polymorphism dalam OOP. Polymorphism memungkinkan objek yang berbeda merespons method yang sama dengan cara berbeda.

Python • polymorphism_demo.py 
# Demonstrasi Polymorphism dengan Method Overriding
class Hewan:
    def bersuara(self):
        pass

class Anjing(Hewan):
    def bersuara(self):
        return "Woof!"

class Kucing(Hewan):
    def bersuara(self):
        return "Meow!"

class Sapi(Hewan):
    def bersuara(self):
        return "Moo!"

# Polymorphism in action
def buat_hewan_bersuara(hewan):
    return hewan.bersuara()

# List berisi objek dari class yang berbeda
daftar_hewan = [Anjing(), Kucing(), Sapi()]

# Satu method, behavior berbeda untuk setiap objek
for hewan in daftar_hewan:
    print(f"Hewan bersuara: {buat_hewan_bersuara(hewan)}")

🖥️ Output Program:

Hewan bersuara: Woof!
Hewan bersuara: Meow!
Hewan bersuara: Moo!

Ini adalah Polymorphism! Satu method bersuara() dipanggil pada objek yang berbeda, tapi menghasilkan behavior yang berbeda sesuai implementasi di masing-masing class.

# Parent Class
class BentukGeometri:
    def __init__(self, nama):
        self.nama = nama
    
    def luas(self):
        return "Luas belum dihitung"
    
    def keliling(self):
        return "Keliling belum dihitung"
    
    def info(self):
        return f"Ini adalah {self.nama}"

# Child Class 1: Persegi
class Persegi(BentukGeometri):
    def __init__(self, sisi):
        super().__init__("Persegi")
        self.sisi = sisi
    
    # Override method luas
    def luas(self):
        return self.sisi * self.sisi
    
    # Override method keliling  
    def keliling(self):
        return 4 * self.sisi
    
    # Override method info
    def info(self):
        return f"{super().info()} dengan sisi {self.sisi} cm"

# Child Class 2: Lingkaran
class Lingkaran(BentukGeometri):
    def __init__(self, jari_jari):
        super().__init__("Lingkaran")
        self.jari_jari = jari_jari
        self.pi = 3.14159
    
    # Override method luas
    def luas(self):
        return self.pi * self.jari_jari * self.jari_jari
    
    # Override method keliling
    def keliling(self):
        return 2 * self.pi * self.jari_jari
    
    # Override method info
    def info(self):
        return f"{super().info()} dengan jari-jari {self.jari_jari} cm"

# Penggunaan
persegi = Persegi(5)
lingkaran = Lingkaran(7)

print("📐 PERSEGI:")
print(f"Info: {persegi.info()}")
print(f"Luas: {persegi.luas()} cm²")
print(f"Keliling: {persegi.keliling()} cm")

print("\n⭕ LINGKARAN:")
print(f"Info: {lingkaran.info()}")
print(f"Luas: {lingkaran.luas():.2f} cm²")
print(f"Keliling: {lingkaran.keliling():.2f} cm")

# Base Character Class
class Character:
    def __init__(self, name, health, attack):
        self.name = name
        self.health = health
        self.max_health = health
        self.attack = attack
        self.level = 1
    
    def attack_enemy(self, enemy):
        damage = self.attack
        enemy.take_damage(damage)
        return f"{self.name} menyerang dengan damage {damage}! ⚔️"
    
    def take_damage(self, damage):
        self.health -= damage
        if self.health < 0:
            self.health = 0
    
    def special_skill(self):
        return f"{self.name} menggunakan skill dasar! ✨"
    
    def is_alive(self):
        return self.health > 0

# Warrior Class - Override special_skill dan attack_enemy
class Warrior(Character):
    def __init__(self, name):
        super().__init__(name, health=120, attack=25)
        self.rage_mode = False
    
    def attack_enemy(self, enemy):  # Method Overriding
        damage = self.attack
        if self.rage_mode:
            damage = int(damage * 1.5)  # Bonus damage saat rage
            self.rage_mode = False  # Reset rage setelah digunakan
        
        enemy.take_damage(damage)
        return f"{self.name} menyerang dengan damage {damage}! ⚔️"
    
    def special_skill(self):  # Method Overriding
        self.rage_mode = True
        return f"{self.name} menggunakan BERSERKER RAGE! Serangan berikutnya +50% damage! 🔥⚔️"

# Mage Class - Override special_skill dan attack_enemy
class Mage(Character):
    def __init__(self, name):
        super().__init__(name, health=80, attack=35)
        self.mana = 100
        self.max_mana = 100
    
    def attack_enemy(self, enemy):  # Method Overriding
        if self.mana >= 20:
            magic_damage = self.attack + 15
            enemy.take_damage(magic_damage)
            self.mana -= 20
            return f"{self.name} menyerang dengan MAGIC MISSILE! Damage {magic_damage}! 🔮✨"
        else:
            # Fallback ke serangan biasa jika mana habis
            return super().attack_enemy(enemy) + " (Mana habis, serangan fisik)"
    
    def special_skill(self):  # Method Overriding
        if self.mana >= 50:
            self.mana -= 50
            heal_amount = 30
            self.health = min(self.health + heal_amount, self.max_health)
            return f"{self.name} menggunakan HEALING SPELL! +{heal_amount} HP! 💚🔮"
        else:
            return f"{self.name} tidak punya cukup mana untuk healing! 😵"

# Archer Class - Tambahan untuk variasi
class Archer(Character):
    def __init__(self, name):
        super().__init__(name, health=100, attack=30)
        self.arrows = 10
    
    def attack_enemy(self, enemy):  # Method Overriding
        if self.arrows > 0:
            critical_chance = 0.3  # 30% chance critical
            import random
            damage = self.attack
            if random.random() < critical_chance:
                damage = int(damage * 2)
                result = f"{self.name} CRITICAL HIT dengan panah! Damage {damage}! 🏹💥"
            else:
                result = f"{self.name} menembak panah! Damage {damage}! 🏹"
            
            enemy.take_damage(damage)
            self.arrows -= 1
            return result
        else:
            return super().attack_enemy(enemy) + " (Panah habis, serangan fisik)"
    
    def special_skill(self):  # Method Overriding
        if self.arrows >= 3:
            self.arrows -= 3
            return f"{self.name} menggunakan TRIPLE SHOT! Serangan berikutnya 3x lipat! 🏹🏹🏹"
        else:
            return f"{self.name} tidak punya cukup panah untuk triple shot! 🏹"

# Demo Game

print()

print("⚔️ PERTARUNGAN:")

Python • kendaraan_system.py 
class Kendaraan:
    def __init__(self, merk, model):
        self.merk = merk
        self.model = model
        self.kecepatan = 0
        self.mesin_hidup = False
    
    def nyalakan_mesin(self):
        self.mesin_hidup = True
        return f"Mesin {self.merk} {self.model} dinyalakan! 🔥"
    
    def gas(self, tambah_kecepatan):
        if self.mesin_hidup:
            self.kecepatan += tambah_kecepatan
            return f"Kecepatan: {self.kecepatan} km/h 🚗💨"
        return "Nyalakan mesin dulu! 😅"
    
    def klakson(self):
        return "Beep beep! 📯"

class MobilSport(Kendaraan):
    def __init__(self, merk, model):
        super().__init__(merk, model)
        self.turbo = False
    
    def nyalakan_mesin(self):  # Override
        self.mesin_hidup = True
        return f"🏎️ VROOOM! Mesin sport {self.merk} {self.model} menyala! 🔥🔥"
    
    def gas(self, tambah_kecepatan):  # Override
        if self.mesin_hidup:
            if self.turbo:
                tambah_kecepatan *= 2  # Turbo boost!
            self.kecepatan += tambah_kecepatan
            return f"🏎️ NGEBUT! Kecepatan: {self.kecepatan} km/h {'(TURBO!)' if self.turbo else ''} 💨💨"
        return "Nyalakan mesin dulu! 😅"
    
    def aktifkan_turbo(self):
        self.turbo = True
        return "🚀 TURBO ACTIVATED! 🔥"
    
    def klakson(self):  # Override
        return "HONK HONK! 🎺🏎️"

class Truk(Kendaraan):
    def __init__(self, merk, model):
        super().__init__(merk, model)
        self.muatan = 0
    
    def nyalakan_mesin(self):  # Override
        self.mesin_hidup = True
        return f"🚛 BRUM BRUM! Mesin diesel {self.merk} {self.model} hidup! 🔥"
    
    def gas(self, tambah_kecepatan):  # Override
        if self.mesin_hidup:
            # Truk lebih lambat karena berat
            kecepatan_efektif = tambah_kecepatan * 0.7
            self.kecepatan += kecepatan_efektif
            return f"🚛 Truk melaju pelan... Kecepatan: {self.kecepatan:.1f} km/h 📦"
        return "Nyalakan mesin dulu! 😅"
    
    def klakson(self):  # Override
        return "TEEEEET! TEEEET! 📯🚛"

# Demo Sistem Kendaraan
sport_car = MobilSport("Ferrari", "F8")
truk = Truk("Hino", "Ranger")

print(sport_car.klakson())

print(truk.nyalakan_mesin())
print(truk.gas(50))
print(truk.klakson())
