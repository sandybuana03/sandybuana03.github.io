Pengenalan Enkapsulasi

Apa itu Enkapsulasi?

🔐 Enkapsulasi adalah salah satu pilar utama dalam Object-Oriented Programming (OOP). Konsep ini memungkinkan kita untuk "membungkus" data dan method dalam satu unit (class) dan mengontrol akses terhadap data tersebut.

Keuntungan Enkapsulasi

  • ✅ Data lebih aman
  • ✅ Kontrol akses yang baik
  • ✅ Kode lebih terstruktur
  • ✅ Mudah maintenance

Analogi Sederhana

🏠 Seperti rumah dengan pintu dan jendela. Kamu tidak bisa langsung masuk ke kamar tidur, harus melalui pintu depan dulu. Begitu juga dengan data dalam class!

Konsep Enkapsulasi

Tingkat Akses dalam Python

🌍

Public

Bisa diakses dari mana saja

Python - public_attribute.py
self.nama = "John"
🏠

Protected

Hanya untuk class dan subclass

Python - protected_attribute.py
self._nama = "John"
🔒

Private

Hanya dalam class itu sendiri

Python - private_attribute.py
self.__nama = "John"

Contoh Sederhana

Python - mahasiswa.py
class Mahasiswa:
    def __init__(self, nama, nim):
        self.nama = nama          # Public - bisa diakses langsung
        self._jurusan = "TI"      # Protected - sebaiknya tidak diakses langsung  
        self.__ipk = 0.0          # Private - tidak bisa diakses langsung
    
    def tampilkan_info(self):
        print(f"Nama: {self.nama}")
        print(f"Jurusan: {self._jurusan}")
        print(f"IPK: {self.__ipk}")

# Penggunaan
mhs = Mahasiswa("Budi", "12345")
print(mhs.nama)        # ✅ Bisa diakses
print(mhs._jurusan)    # ⚠️ Bisa tapi tidak disarankan
# print(mhs.__ipk)     # ❌ Error! Tidak bisa diakses

Getter & Setter Methods

Apa itu Getter & Setter?

📤

Getter

Method untuk mengambil nilai atribut private

Python - getter_example.py
def get_nama(self):
    return self.__nama
📥

Setter

Method untuk mengubah nilai atribut private

Python - setter_example.py
def set_nama(self, nama):
    if nama:
        self.__nama = nama

Contoh Lengkap: Class Siswa

Python - siswa_dengan_getter_setter.py
class Siswa:
    def __init__(self, nama, umur, nilai):
        self.__nama = nama
        self.__umur = umur
        self.__nilai = nilai
    
    # Getter Methods
    def get_nama(self):
        return self.__nama
    
    def get_umur(self):
        return self.__umur
    
    def get_nilai(self):
        return self.__nilai
    
    # Setter Methods dengan Validasi
    def set_nama(self, nama):
        if isinstance(nama, str) and len(nama) > 0:
            self.__nama = nama
        else:
            print("❌ Nama harus berupa string dan tidak kosong!")
    
    def set_umur(self, umur):
        if isinstance(umur, int) and 5 <= umur <= 25:
            self.__umur = umur
        else:
            print("❌ Umur harus antara 5-25 tahun!")
    
    def set_nilai(self, nilai):
        if isinstance(nilai, (int, float)) and 0 <= nilai <= 100:
            self.__nilai = nilai
        else:
            print("❌ Nilai harus antara 0-100!")
    
    def tampilkan_info(self):
        print(f"👤 Nama: {self.__nama}")
        print(f"🎂 Umur: {self.__umur} tahun")
        print(f"📊 Nilai: {self.__nilai}")
        
        # Menentukan grade
        if self.__nilai >= 90:
            grade = "A (Excellent! 🌟)"
        elif self.__nilai >= 80:
            grade = "B (Good! 👍)"
        elif self.__nilai >= 70:
            grade = "C (Fair 👌)"
        elif self.__nilai >= 60:
            grade = "D (Need Improvement 📚)"
        else:
            grade = "E (Study Harder! 💪)"
        
        print(f"🏆 Grade: {grade}")

# Contoh Penggunaan
siswa = Siswa("Andi", 17, 85)
siswa.tampilkan_info()

# Menggunakan getter
print(f"\nNama siswa: {siswa.get_nama()}")

# Menggunakan setter dengan validasi
siswa.set_nilai(95)  # ✅ Valid
siswa.set_nilai(150) # ❌ Invalid
siswa.set_umur(-5)   # ❌ Invalid

Property Decorator

Cara Modern: @property

🎯 Property decorator membuat getter dan setter lebih elegan dan mudah digunakan. Kita bisa mengakses atribut private seperti atribut biasa, tapi tetap dengan kontrol penuh!

Cara Lama (Ribet)

Python - cara_lama.py
siswa.set_nama("Budi")
nama = siswa.get_nama()
siswa.set_nilai(90)
nilai = siswa.get_nilai()

Cara Baru (Elegan)

Python - cara_baru.py
siswa.nama = "Budi"
nama = siswa.nama
siswa.nilai = 90
nilai = siswa.nilai

Implementasi Property Decorator

Python - siswa_dengan_property.py
class Siswa:
    def __init__(self, nama, nilai):
        self.__nama = nama
        self.__nilai = nilai
    
    # Property untuk NAMA
    @property
    def nama(self):
        """Getter untuk nama"""
        return self.__nama
    
    @nama.setter
    def nama(self, nama):
        """Setter untuk nama dengan validasi"""
        if isinstance(nama, str) and len(nama.strip()) > 0:
            self.__nama = nama.strip().title()
        else:
            raise ValueError("❌ Nama harus berupa string dan tidak kosong!")
    
    # Property untuk NILAI
    @property
    def nilai(self):
        """Getter untuk nilai"""
        return self.__nilai
    
    @nilai.setter
    def nilai(self, nilai):
        """Setter untuk nilai dengan validasi"""
        if isinstance(nilai, (int, float)) and 0 <= nilai <= 100:
            self.__nilai = float(nilai)
        else:
            raise ValueError("❌ Nilai harus antara 0-100!")
    
    # Property READ-ONLY untuk grade
    @property
    def grade(self):
        """Property read-only untuk menghitung grade"""
        if self.__nilai >= 90:
            return "A"
        elif self.__nilai >= 80:
            return "B"
        elif self.__nilai >= 70:
            return "C"
        elif self.__nilai >= 60:
            return "D"
        else:
            return "E"
    
    def __str__(self):
        return f"👤 {self.__nama} - Nilai: {self.__nilai} (Grade {self.grade})"

# Contoh Penggunaan yang Elegan
siswa = Siswa("andi", 85)

# Menggunakan property seperti atribut biasa
print(f"Nama: {siswa.nama}")        # Getter
print(f"Nilai: {siswa.nilai}")      # Getter
print(f"Grade: {siswa.grade}")      # Read-only property

# Mengubah nilai dengan validasi otomatis
siswa.nama = "budi setiawan"        # Setter (otomatis jadi "Budi Setiawan")
siswa.nilai = 95                    # Setter

print(f"\nSetelah diupdate: {siswa}")

Cara Kerja Property Decorator

1. @property (Getter)

Mengubah method menjadi atribut yang bisa diakses tanpa tanda kurung ()

2. @nama.setter (Setter)

Memungkinkan assignment (=) dengan validasi otomatis

3. Read-Only Property

Hanya @property tanpa setter - tidak bisa diubah dari luar

Tugas Praktik

Tugas: Buat Class Kendaraan

Deskripsi Tugas

Buatlah class Kendaraan yang menerapkan konsep enkapsulasi dengan property decorator untuk mengelola data kendaraan di rental mobil.

Atribut yang Diperlukan

  • 🚗 merk (string, min 2 karakter)
  • 🏷️ model (string, min 2 karakter)
  • 📅 tahun (integer, 1990-2024)
  • 💰 harga_sewa (float, > 0)
  • 📊 status ("Tersedia"/"Disewa")

Method yang Diperlukan

  • 🔧 sewa() - ubah status jadi "Disewa"
  • ↩️ kembalikan() - ubah status jadi "Tersedia"
  • 💸 hitung_biaya(hari) - hitung biaya sewa
  • 📄 info() - tampilkan info lengkap

Property Read-Only yang Diperlukan

  • 🏷️ nama_lengkap - gabungan merk dan model
  • ⏰ umur - hitung umur kendaraan dari tahun sekarang
  • 💎 kategori_harga - "Murah" (<100k), "Sedang" (100k-300k), "Mahal" (>300k)

Kriteria Penilaian

1
Semua atribut menggunakan private (double underscore)
2
Property decorator digunakan dengan benar
3
Validasi data pada setiap setter
4
Property read-only berfungsi dengan baik
5
Semua method bekerja sesuai spesifikasi
6
Kode bersih dan mudah dibaca
