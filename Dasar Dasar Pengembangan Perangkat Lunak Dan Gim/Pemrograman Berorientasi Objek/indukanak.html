Pengenalan Inheritance

🧬 Apa itu Inheritance?

Inheritance atau Pewarisan adalah salah satu pilar utama dalam pemrograman berorientasi objek (OOP) yang memungkinkan sebuah class (class anak) untuk mewarisi atribut dan method dari class lain (class induk).

Konsep ini memungkinkan kita untuk membuat hierarki class yang terorganisir, mengurangi duplikasi kode, dan memudahkan maintenance program.

👑 Class Induk (Parent/Superclass)

Class yang memberikan warisan kepada class lain. Berisi atribut dan method yang bersifat umum dan bisa digunakan oleh class anak.

Karakteristik:
  • Mendefinisikan behavior umum
  • Dapat diinstansiasi sendiri
  • Menjadi template untuk subclass

👶 Class Anak (Child/Subclass)

Class yang menerima warisan dari class induk. Bisa menggunakan, memodifikasi, atau menambahkan fitur baru.

Kemampuan:
  • Mewarisi semua atribut & method
  • Menambah fitur baru
  • Override method yang ada

🎯 Mengapa Inheritance Penting?

♻️ Code Reusability

Menghindari penulisan kode yang sama berulang-ulang. Sekali tulis, bisa dipakai berkali-kali!

🔧 Easy Maintenance

Perubahan di superclass otomatis berlaku untuk semua subclass. Update sekali, semua terupdate!

🏗️ Better Organization

Membuat struktur kode yang hierarkis dan mudah dipahami. Seperti pohon keluarga!

🎨 Polymorphism Support

Memungkinkan object berbeda merespons method yang sama dengan cara berbeda.

# Sintaks dasar inheritance dalam Python

class NamaClassInduk:
    # Class variable - dibagi oleh semua instance
    jumlah_instance = 0
    
    def __init__(self, parameter1, parameter2):
        # Constructor (__init__) adalah method khusus yang dipanggil
        # saat object dibuat. Ini menginisialisasi atribut object.
        self.atribut1 = parameter1  # Instance variable
        self.atribut2 = parameter2  # Instance variable
        
        # Increment class variable
        NamaClassInduk.jumlah_instance += 1
        print(f"Object {self.__class__.__name__} dibuat!")
    
    def method_induk(self):
        # Method yang bisa diwarisi oleh semua subclass
        return f"Method dari {self.__class__.__name__}"
    
    def info(self):
        # Method untuk menampilkan informasi object
        return f"Class: {self.__class__.__name__}, Atribut: {self.atribut1}, {self.atribut2}"
    
    @classmethod
    def get_jumlah_instance(cls):
        # Class method - bisa dipanggil tanpa membuat object
        return f"Total instance {cls.__name__}: {cls.jumlah_instance}"
    
    @staticmethod
    def info_inheritance():
        # Static method - tidak butuh self atau cls
        return "Inheritance memungkinkan code reuse dan hierarki class"

class NamaClassAnak(NamaClassInduk):  # Inheritance syntax
    def __init__(self, parameter1, parameter2, parameter3):
        # Memanggil constructor parent class dengan super()
        super().__init__(parameter1, parameter2)
        
        # Menambahkan atribut khusus untuk subclass
        self.atribut3 = parameter3
        print(f"Subclass {self.__class__.__name__} siap!")
    
    def method_anak(self):
        # Method khusus yang hanya ada di subclass
        return f"Method khusus dari {self.__class__.__name__}"
    
    def method_induk(self):
        # Method overriding - mengganti implementasi method parent
        parent_result = super().method_induk()  # Memanggil method parent
        return f"{parent_result} + Enhancement dari subclass"
    
    def info(self):
        # Override method info dengan tambahan informasi
        parent_info = super().info()  # Dapatkan info dari parent
        return f"{parent_info}, Atribut3: {self.atribut3}"

🔧 Constructor (__init__)

  • • Method khusus yang dipanggil saat object dibuat
  • • Digunakan untuk menginisialisasi atribut
  • • self merujuk pada object yang sedang dibuat
  • • super().__init__() memanggil constructor parent

⚡ Konsep Penting

  • • MRO: Urutan pencarian method dalam inheritance
  • • isinstance(): Cek apakah object adalah instance dari class
  • • issubclass(): Cek apakah class adalah subclass dari class lain
  • • Class vs Instance variable: Shared vs unique data
  • • @classmethod/@staticmethod: Method khusus dalam class

💡 Penjelasan Sintaks Lengkap

def method(self): Instance method

super().method(): Akses method parent dalam override

# Class Induk (Superclass)
class Kendaraan:
    # Class variable (shared by all instances)
    total_kendaraan = 0
    
    def __init__(self, merk, warna, tahun_produksi):
        # Instance variables (unique for each object)
        self.merk = merk
        self.warna = warna
        self.tahun_produksi = tahun_produksi
        self.kecepatan = 0
        self.mesin_hidup = False
        
        # Increment total kendaraan
        Kendaraan.total_kendaraan += 1
    
    def info_dasar(self):
        return f"Kendaraan {self.merk} ({self.tahun_produksi}) berwarna {self.warna}"
    
    def nyalakan_mesin(self):
        if not self.mesin_hidup:
            self.mesin_hidup = True
            return f"Mesin {self.merk} dinyalakan! 🔥"
        return f"Mesin {self.merk} sudah hidup!"
    
    def matikan_mesin(self):
        if self.mesin_hidup:
            self.mesin_hidup = False
            self.kecepatan = 0
            return f"Mesin {self.merk} dimatikan! 🔌"
        return f"Mesin {self.merk} sudah mati!"
    
    def bergerak(self, tambah_kecepatan=10):
        if self.mesin_hidup:
            self.kecepatan += tambah_kecepatan
            return f"{self.merk} bergerak dengan kecepatan {self.kecepatan} km/h"
        return f"Nyalakan mesin {self.merk} terlebih dahulu!"
    
    def berhenti(self):
        if self.kecepatan > 0:
            self.kecepatan = 0
            return f"{self.merk} berhenti total!"
        return f"{self.merk} sudah berhenti!"

# Class Anak (Subclass) - Mobil
class Mobil(Kendaraan):
    def __init__(self, merk, warna, tahun_produksi, jumlah_pintu, jenis_transmisi):
        # Memanggil constructor parent class
        super().__init__(merk, warna, tahun_produksi)
        
        # Atribut khusus mobil
        self.jumlah_pintu = jumlah_pintu
        self.jenis_transmisi = jenis_transmisi
        self.ac_hidup = False
        self.radio_hidup = False
    
    def klakson(self):
        return f"{self.merk}: Beep beep! 🚗"
    
    def nyalakan_ac(self):
        if self.mesin_hidup:
            self.ac_hidup = True
            return f"AC {self.merk} dinyalakan! ❄️"
        return "Nyalakan mesin terlebih dahulu!"
    
    def putar_musik(self):
        self.radio_hidup = True
        return f"🎵 Musik diputar di {self.merk}!"
    
    def info_lengkap(self):
        info = super().info_dasar()  # Memanggil method parent
        return f"{info} - {self.jumlah_pintu} pintu, transmisi {self.jenis_transmisi}"

# Class Anak (Subclass) - Motor
class Motor(Kendaraan):
    def __init__(self, merk, warna, tahun_produksi, cc, jenis):
        super().__init__(merk, warna, tahun_produksi)
        
        # Atribut khusus motor
        self.cc = cc
        self.jenis = jenis  # sport, matic, bebek
        self.helm_tersedia = True
    
    def klakson(self):
        return f"{self.merk}: Tin tin! 🏍️"
    
    def pakai_helm(self):
        if self.helm_tersedia:
            self.helm_tersedia = False
            return f"Helm dipakai! Safety first! ⛑️"
        return "Helm sudah dipakai!"
    
    def lepas_helm(self):
        if not self.helm_tersedia:
            self.helm_tersedia = True
            return f"Helm dilepas! 👤"
        return "Helm belum dipakai!"
    
    def wheelie(self):
        if self.mesin_hidup and self.kecepatan > 20:
            return f"{self.merk} melakukan wheelie! 🤸‍♂️"
        return "Kecepatan tidak cukup untuk wheelie!"
    
    def info_lengkap(self):
        info = super().info_dasar()
        return f"{info} - {self.cc}cc, jenis {self.jenis}"

# Class Anak (Subclass) - Truk
class Truk(Kendaraan):
    def __init__(self, merk, warna, tahun_produksi, kapasitas_muatan):
        super().__init__(merk, warna, tahun_produksi)
        
        # Atribut khusus truk
        self.kapasitas_muatan = kapasitas_muatan  # dalam ton
        self.muatan_saat_ini = 0
    
    def klakson(self):
        return f"{self.merk}: HOOOONK! 🚛"
    
    def muat_barang(self, berat):
        if self.muatan_saat_ini + berat <= self.kapasitas_muatan:
            self.muatan_saat_ini += berat
            return f"Barang {berat} ton dimuat! Total muatan: {self.muatan_saat_ini} ton"
        return f"Kapasitas tidak cukup! Maksimal {self.kapasitas_muatan} ton"
    
    def bongkar_muatan(self):
        if self.muatan_saat_ini > 0:
            muatan_lama = self.muatan_saat_ini
            self.muatan_saat_ini = 0
            return f"Semua muatan ({muatan_lama} ton) dibongkar!"
        return "Truk sudah kosong!"
    
    def info_lengkap(self):
        info = super().info_dasar()
        return f"{info} - Kapasitas: {self.kapasitas_muatan} ton, Muatan: {self.muatan_saat_ini} ton"

# Polymorphism dengan Inheritance
def demo_kendaraan(kendaraan_list):
    """
    Fungsi untuk mendemonstrasikan polymorphism
    - Method yang sama dipanggil pada object berbeda
    - Setiap object memberikan response yang berbeda
    """
    for kendaraan in kendaraan_list:
        print(f"=== {kendaraan.merk} ===")
        print(kendaraan.nyalakan_mesin())  # Method sama, behavior berbeda
        print(kendaraan.klakson())         # Method override
        print(kendaraan.info_lengkap())    # Method extension
        print()

def demo_polymorphism_advanced():
    """
    Demo polymorphism yang lebih advanced dengan berbagai skenario
    """
    print("🚗 DEMO POLYMORPHISM LENGKAP 🚗")
    print("=" * 50)
    
    # 1. Membuat berbagai jenis kendaraan
    print("\n1️⃣ MEMBUAT KENDARAAN")
    mobil = Mobil("Toyota Avanza", "Silver", 2023, 4, "Manual")
    motor = Motor("Yamaha NMAX", "Biru", 2023, 155, "Matic")
    truk = Truk("Hino Dutro", "Putih", 2023, 8)
    
    # 2. Menyimpan dalam list (semua adalah Kendaraan)
    kendaraan_list = [mobil, motor, truk]
    print(f"Total kendaraan: {len(kendaraan_list)}")
    
    # 3. Demo polymorphism - method yang sama, hasil berbeda
    print("\n2️⃣ DEMO POLYMORPHISM - METHOD KLAKSON")
    for i, kendaraan in enumerate(kendaraan_list, 1):
        print(f"{i}. {kendaraan.klakson()}")
    
    # 4. Demo polymorphism - method bergerak dengan parameter
    print("\n3️⃣ DEMO POLYMORPHISM - METHOD BERGERAK")
    for kendaraan in kendaraan_list:
        print(f"- {kendaraan.nyalakan_mesin()}")
        print(f"- {kendaraan.bergerak(25)}")
        print()
    
    # 5. Demo polymorphism - method info_lengkap
    print("4️⃣ DEMO POLYMORPHISM - INFO LENGKAP")
    for kendaraan in kendaraan_list:
        print(f"📋 {kendaraan.info_lengkap()}")
    
    # 6. Demo isinstance() - type checking
    print("\n5️⃣ DEMO TYPE CHECKING")
    for kendaraan in kendaraan_list:
        print(f"\n🔍 {kendaraan.merk}:")
        print(f"   - isinstance(kendaraan, Kendaraan): {isinstance(kendaraan, Kendaraan)}")
        print(f"   - isinstance(kendaraan, Mobil): {isinstance(kendaraan, Mobil)}")
        print(f"   - isinstance(kendaraan, Motor): {isinstance(kendaraan, Motor)}")
        print(f"   - isinstance(kendaraan, Truk): {isinstance(kendaraan, Truk)}")
        print(f"   - Type: {type(kendaraan).__name__}")
    
    # 7. Demo method khusus setiap subclass
    print("\n6️⃣ DEMO METHOD KHUSUS SUBCLASS")
    for kendaraan in kendaraan_list:
        print(f"\n🎯 {kendaraan.merk} - Method Khusus:")
        if isinstance(kendaraan, Mobil):
            print(f"   - {kendaraan.nyalakan_ac()}")
            print(f"   - {kendaraan.putar_musik()}")
        elif isinstance(kendaraan, Motor):
            print(f"   - {kendaraan.pakai_helm()}")
            print(f"   - {kendaraan.wheelie()}")
        elif isinstance(kendaraan, Truk):
            print(f"   - {kendaraan.muat_barang(5)}")
            print(f"   - {kendaraan.bongkar_muatan()}")

Class Induk (Superclass)

🎯 Apa itu Superclass?

Superclass atau Class Induk adalah class yang memberikan warisan kepada class lain. Class ini berisi atribut dan method yang bersifat umum dan bisa digunakan oleh class-class turunannya.

Python - hewan.py 
# Contoh Superclass: Hewan
class Hewan:
    # Class variable - dibagi oleh semua instance
    total_hewan = 0
    
    def __init__(self, nama, jenis):
        # Instance variables - unik untuk setiap object
        self.nama = nama
        self.jenis = jenis
        self.lapar = True
        self.energi = 100
        self.umur = 0
        
        # Increment total hewan setiap kali object dibuat
        Hewan.total_hewan += 1
        print(f"🐾 Hewan baru lahir: {nama} ({jenis})")
    
    def makan(self):
        """Method untuk memberi makan hewan"""
        if self.lapar:
            self.lapar = False
            self.energi += 20
            if self.energi > 100:
                self.energi = 100
            return f"{self.nama} sedang makan 🍽️ (Energi: {self.energi}%)"
        else:
            return f"{self.nama} sudah kenyang! 😊"
    
    def tidur(self):
        """Method untuk membuat hewan tidur"""
        self.energi += 30
        if self.energi > 100:
            self.energi = 100
        return f"{self.nama} sedang tidur 😴 (Energi pulih: {self.energi}%)"
    
    def bermain(self):
        """Method untuk membuat hewan bermain"""
        if self.energi >= 20:
            self.energi -= 20
            self.lapar = True
            return f"{self.nama} sedang bermain! 🎮 (Energi: {self.energi}%, Lapar: {self.lapar})"
        else:
            return f"{self.nama} terlalu lelah untuk bermain 😴"
    
    def info(self):
        """Method untuk menampilkan informasi hewan"""
        status_lapar = "Lapar 🍽️" if self.lapar else "Kenyang 😊"
        return f"Nama: {self.nama} | Jenis: {self.jenis} | Energi: {self.energi}% | Status: {status_lapar}"
    
    def bertambah_umur(self):
        """Method untuk menambah umur hewan"""
        self.umur += 1
        return f"{self.nama} sekarang berumur {self.umur} tahun 🎂"
    
    @classmethod
    def get_total_hewan(cls):
        """Class method untuk mendapatkan total hewan"""
        return f"Total hewan yang ada: {cls.total_hewan} ekor 🐾"
    
    @staticmethod
    def info_superclass():
        """Static method untuk informasi tentang superclass"""
        return "Hewan adalah superclass yang menyediakan behavior dasar untuk semua hewan 🦁"

Class Anak (Subclass)

🎯 Apa itu Subclass?

Subclass atau Class Anak adalah class yang mewarisi atribut dan method dari superclass. Subclass bisa menambahkan fitur baru atau memodifikasi fitur yang diwarisi.

# Subclass: Kucing (mewarisi dari Hewan)
class Kucing(Hewan):
    def __init__(self, nama, warna_bulu):
        # Memanggil constructor parent class dengan super()
        super().__init__(nama, "Kucing")  # Memanggil Hewan.__init__()
        
        # Menambahkan atribut khusus untuk Kucing
        self.warna_bulu = warna_bulu
        print(f"🐱 Kucing {nama} dengan bulu {warna_bulu} siap bermain!")
    
    def meong(self):
        """Method khusus kucing untuk bersuara"""
        return f"{self.nama} berkata: Meong! 🐱"
    
    def bermain(self):
        """Override method bermain() dari Hewan dengan aktivitas khusus kucing"""
        if self.energi >= 20:
            self.energi -= 15  # Kucing lebih efisien energi
            self.lapar = True
            return f"{self.nama} sedang bermain dengan bola benang 🧶 (Energi: {self.energi}%)"
        else:
            return f"{self.nama} terlalu lelah untuk bermain 😴"
    
    def panjat_pohon(self):
        """Method khusus kucing untuk memanjat"""
        if self.energi >= 30:
            self.energi -= 25
            return f"{self.nama} memanjat pohon dengan lincah! 🌳 (Energi: {self.energi}%)"
        else:
            return f"{self.nama} terlalu lelah untuk memanjat 😿"
    
    def info_lengkap(self):
        """Override method info() dengan informasi tambahan kucing"""
        basic_info = self.info()  # Memanggil method dari parent
        return f"{basic_info} | Warna Bulu: {self.warna_bulu} | Jenis: Kucing 🐱"

Method Overriding

🎯 Apa itu Method Overriding?

Method Overriding adalah kemampuan subclass untuk memberikan implementasi baru terhadap method yang sudah ada di superclass. Ini memungkinkan subclass memiliki behavior yang berbeda untuk method yang sama.

Python - burung_override.py 
# Superclass (Parent Class)
class Burung:
    # Class variable untuk menghitung total burung
    total_burung = 0
    
    def __init__(self, nama, jenis):
        self.nama = nama
        self.jenis = jenis
        self.energi = 100
        self.posisi = "di tanah"
        
        # Increment total burung setiap kali object dibuat
        Burung.total_burung += 1
        print(f"🐦 Burung {nama} ({jenis}) lahir! Total burung: {Burung.total_burung}")
    
    def bersuara(self):
        """Method dasar untuk bersuara - akan di-override oleh subclass"""
        return f"{self.nama} mengeluarkan suara burung umum 🐦"
    
    def terbang(self):
        """Method dasar untuk terbang - akan di-override oleh subclass"""
        if self.energi >= 20:
            self.energi -= 20
            self.posisi = "di udara"
            return f"{self.nama} sedang terbang tinggi ✈️ (Energi: {self.energi}%)"
        return f"{self.nama} terlalu lelah untuk terbang 😴"
    
    def istirahat(self):
        """Method yang tidak di-override - sama untuk semua burung"""
        self.energi = 100
        self.posisi = "di tanah"
        return f"{self.nama} beristirahat dan energi pulih 100% 😴"

Fungsi super()

🎯 Apa itu super()?

super() adalah fungsi built-in Python yang memungkinkan subclass untuk mengakses method dan atribut dari superclass. Ini sangat berguna untuk memanggil constructor induk atau method yang di-override.

Dengan super(), kita bisa memperluas functionality tanpa mengulangi kode yang sudah ada di parent class.

✅ Kegunaan super()

  • • Memanggil constructor parent class
  • • Mengakses method yang di-override
  • • Memperluas functionality existing method
  • • Menghindari duplikasi kode

🎯 Kapan Menggunakan?

  • • Di dalam __init__() subclass
  • • Saat override method tapi ingin tetap jalankan parent
  • • Multiple inheritance (MRO)
  • • Cooperative inheritance pattern

class Handphone:
    def __init__(self, merk, model, tahun):
        self.merk = merk
        self.model = model
        self.tahun = tahun
        self.baterai = 100
        self.status_panggilan = False
        print(f"📱 Handphone {merk} {model} dibuat!")
    
    def telepon(self, nomor):
        if self.baterai > 10:
            self.status_panggilan = True
            self.baterai -= 5
            return f"📞 Menelepon {nomor} dari {self.merk} {self.model}"
        return "🔋 Baterai terlalu rendah untuk menelepon!"
    
    def sms(self, nomor, pesan):
        if self.baterai > 2:
            self.baterai -= 2
            return f"💬 SMS ke {nomor}: '{pesan}' dari {self.merk} {self.model}"
        return "🔋 Baterai terlalu rendah untuk SMS!"
    
    def charge_battery(self):
        self.baterai = 100
        return f"🔌 {self.merk} {self.model} di-charge! Baterai: 100%"
    
    def info_dasar(self):
        return f"{self.merk} {self.model} ({self.tahun}) - Baterai: {self.baterai}%"

# Subclass menggunakan super()
class Smartphone(Handphone):
    def __init__(self, merk, model, tahun, os, ram):
        # Memanggil constructor parent dengan super()
        super().__init__(merk, model, tahun)
        
        # Atribut tambahan untuk smartphone
        self.os = os
        self.ram = ram
        self.apps = []
        self.wifi_connected = False
        self.data_usage = 0
        
        print(f"📲 Smartphone dengan OS {os} siap digunakan!")
    
    def telepon(self, nomor):
        # Menggunakan super() untuk memanggil method parent
        basic_call = super().telepon(nomor)
        
        # Menambahkan fitur video call untuk smartphone
        if self.status_panggilan:
            return basic_call + " 📹 (Video call tersedia!)"
        return basic_call
    
    def sms(self, nomor, pesan):
        # Extend functionality SMS dengan emoji dan delivery report
        basic_sms = super().sms(nomor, pesan)
        if "SMS ke" in basic_sms:
            return basic_sms + " ✅ (Terkirim dengan enkripsi)"
        return basic_sms
    
    def install_app(self, app_name, size_mb):
        if len(self.apps) < 50:  # Maksimal 50 apps
            self.apps.append({"name": app_name, "size": size_mb})
            self.data_usage += size_mb
            return f"📱 Aplikasi '{app_name}' ({size_mb}MB) berhasil diinstall!"
        return "📱 Storage penuh! Hapus beberapa aplikasi terlebih dahulu."
    
    def uninstall_app(self, app_name):
        for app in self.apps:
            if app["name"] == app_name:
                self.apps.remove(app)
                return f"🗑️ Aplikasi '{app_name}' berhasil dihapus!"
        return f"❌ Aplikasi '{app_name}' tidak ditemukan!"
    
    def connect_wifi(self, network_name):
        self.wifi_connected = True
        return f"📶 Terhubung ke WiFi '{network_name}'"
    
    def info_lengkap(self):
        # Menggunakan super() untuk mendapatkan info dasar
        basic_info = super().info_dasar()
        
        # Menambahkan info khusus smartphone
        return (f"{basic_info}\n"
                f"OS: {self.os} | RAM: {self.ram}GB | Apps: {len(self.apps)}\n"
                f"WiFi: {'Connected' if self.wifi_connected else 'Disconnected'} | "
                f"Data Usage: {self.data_usage}MB")

# Multiple Inheritance Example
class Device:
    def __init__(self, brand):
        self.brand = brand
        print(f"Device {brand} initialized")
    
    def power_on(self):
        return f"{self.brand} device powered on"

class Camera:
    def __init__(self, megapixel):
        self.megapixel = megapixel
        print(f"Camera {megapixel}MP initialized")
    
    def take_photo(self):
        return f"📸 Photo taken with {self.megapixel}MP camera"

class GPS:
    def __init__(self, accuracy):
        self.accuracy = accuracy
        print(f"GPS with {accuracy}m accuracy initialized")
    
    def get_location(self):
        return f"📍 Current location (±{self.accuracy}m accuracy)"

# Multiple Inheritance - mewarisi dari 3 class sekaligus
class SmartCamera(Device, Camera, GPS):
    def __init__(self, brand, megapixel, accuracy, model):
        # Memanggil constructor semua parent class
        Device.__init__(self, brand)
        Camera.__init__(self, megapixel)
        GPS.__init__(self, accuracy)
        
        self.model = model
        print(f"SmartCamera {model} ready!")
    
    def smart_photo(self):
        # Menggunakan fitur dari semua parent class
        location = self.get_location()
        photo = self.take_photo()
        return f"{photo} with GPS data: {location}"

⚠️ Diamond Problem

Terjadi ketika class mewarisi dari 2+ class yang memiliki parent class yang sama:

    A
   / \
  B   C
   \ /
    D

Python menyelesaikan ini dengan Method Resolution Order (MRO)

✅ Best Practices

• Gunakan super(): Lebih aman dari explicit call

• Cooperative inheritance: Semua class harus support super()

• Cek MRO: Gunakan ClassName.__mro__

• Hindari deep hierarchy: Maksimal 3-4 level

🎯 Soal: Sistem Sekolah

Buatlah sistem sekolah sederhana dengan inheritance! 🏫

Instruksi Lengkap:

  1. Buat class Orang sebagai superclass dengan atribut: nama, umur
  2. Buat method perkenalan() yang menampilkan nama dan umur
  3. Buat class Siswa yang mewarisi dari Orang dengan atribut tambahan: kelas, nilai
  4. Buat class Guru yang mewarisi dari Orang dengan atribut tambahan: mata_pelajaran, gaji
  5. Override method perkenalan() di kedua subclass
  6. Gunakan super() untuk memanggil method induk
  7. Tambahkan method khusus: belajar() untuk Siswa, mengajar() untuk Guru
