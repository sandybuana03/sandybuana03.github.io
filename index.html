Belum Ada Materi

Materi pembelajaran akan muncul di sini setelah file HTML diunggah ke folder materi

📋 Cara Menambah Materi:

  1. 1. Buat folder bernama "materi" di direktori website
  2. 2. Simpan file HTML materi pembelajaran di folder tersebut
  3. 3. Setiap file HTML akan otomatis muncul sebagai kartu materi
  4. 4. Gunakan tag meta untuk informasi tambahan (kategori, deskripsi, dll)
