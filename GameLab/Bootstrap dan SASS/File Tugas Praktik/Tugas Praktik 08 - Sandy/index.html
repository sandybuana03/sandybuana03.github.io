Belajar Variabel dan Tipe Data di SASS

Pengembangan CSS yang lebih efisien, terstruktur, dan mudah dirawat.

Apa itu Variabel pada SASS?

Dalam SASS, variabel digunakan untuk menyimpan nilai yang dapat digunakan kembali di seluruh stylesheet. Hal ini membantu membuat penulisan CSS lebih efisien, konsisten, dan mudah dikelola saat terjadi perubahan.

Format Penulisan Variabel

$nama-variabel: nilai;

Contoh Penggunaan


$primary-color: #2daae1;

.button {
  background-color: $primary-color;
}

Macam-Macam Tipe Data Variabel

Berikut adalah beberapa tipe data yang dapat digunakan pada variabel SASS:

  • String – contoh: "Buana Toys"
  • Number – contoh: 16px, 1.5rem, 300
  • Color – contoh: #ff5733, rgb(40, 120, 220)
  • Boolean – contoh: true atau false
  • List – contoh: (small, medium, large)
  • Map – contoh: (primary: #007bff, danger: #dc3545)

Variabel Global dan Lokal

Variabel Global dapat digunakan di seluruh file SCSS, sedangkan Variabel Lokal hanya berlaku di dalam block di mana variabel itu dideklarasikan.

Contoh Variabel Global

$font-main: 'Poppins', sans-serif;

Contoh Variabel Lokal


.content {
  $local-color: #333;
  color: $local-color;
}
