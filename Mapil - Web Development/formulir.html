🎯 Pengenalan Formulir Pendaftaran Interaktif

Selamat datang di pembelajaran praktik membuat Aplikasi Formulir Pendaftaran Interaktif! 🎉

🎯 Apa yang akan kita pelajari?

Dalam pembelajaran ini, kita akan membuat formulir pendaftaran yang keren dengan fitur-fitur canggih seperti:

  • 📝 Multi-step Form - Formulir dengan beberapa langkah
  • ✅ Validasi Real-time - Cek input langsung saat mengetik
  • 📊 Progress Bar - Indikator kemajuan yang dinamis
  • 🎬 Animasi Smooth - Transisi yang halus antar langkah
  • 📱 Responsive Design - Tampil bagus di HP dan komputer
  • 📄 Download PDF - Simpan data sebagai file PDF

🛠️ Teknologi yang digunakan:

🏗️

HTML5

Struktur formulir multi-langkah dengan semantic markup

🎨

CSS3

Styling modern dengan animasi dan transisi yang smooth

⚡

JavaScript

Interaktivitas, validasi, dan manajemen state

🎯 Hasil akhir yang akan kita buat:

Sebuah formulir pendaftaran yang profesional dengan pengalaman pengguna yang luar biasa! Pengguna akan merasakan kemudahan berpindah antar langkah dengan animasi yang smooth, validasi yang membantu, dan progress bar yang memberikan feedback visual.

💡 Tips Belajar:

  • Ikuti setiap langkah secara berurutan
  • Praktikkan setiap kode yang diberikan
  • Jangan ragu untuk bereksperimen
  • Pahami konsep sebelum melanjutkan ke langkah berikutnya

⚡ Langkah 4: Validasi JavaScript

Sekarang kita akan membuat sistem validasi yang mencegah pengguna melanjutkan ke langkah berikutnya jika data belum valid. Validasi akan berjalan real-time saat pengguna mengetik.

🔍 Jenis Validasi yang akan dibuat:

  • Required Fields: Memastikan field wajib diisi
  • Email Format: Validasi format email yang benar
  • Phone Number: Validasi nomor telepon Indonesia
  • Real-time Validation: Validasi saat mengetik
  • Step Validation: Validasi per langkah sebelum lanjut
⚡ validation.js - Sistem Validasi
// Sistem Validasi Formulir class FormValidator { constructor() { this.rules = { nama: { required: true, minLength: 2, pattern: /^[a-zA-Z\s]+$/, message: 'Nama harus diisi minimal 2 karakter dan hanya huruf' }, email: { required: true, pattern: /^[^\s@]+@[^\s@]+\.[^\s@]+$/, message: 'Format email tidak valid' }, telepon: { required: true, pattern: /^(\+62|62|0)[0-9]{9,13}$/, message: 'Nomor telepon tidak valid (contoh: 081234567890)' }, program: { required: true, message: 'Pilih salah satu program' }, jadwal: { required: true, message: 'Pilih jadwal belajar' }, agreement: { required: true, message: 'Anda harus menyetujui syarat dan ketentuan' } }; this.initializeValidation(); } // Inisialisasi event listeners untuk validasi real-time initializeValidation() { // Validasi saat mengetik (real-time) document.querySelectorAll('input, select').forEach(input => { input.addEventListener('input', (e) => { this.validateField(e.target); }); input.addEventListener('blur', (e) => { this.validateField(e.target); }); }); // Validasi radio buttons document.querySelectorAll('input[type="radio"]').forEach(radio => { radio.addEventListener('change', (e) => { this.validateRadioGroup(e.target.name); }); }); // Validasi checkbox document.querySelectorAll('input[type="checkbox"]').forEach(checkbox => { checkbox.addEventListener('change', (e) => { this.validateField(e.target); }); }); } // Validasi field individual validateField(field) { const fieldName = field.name || field.id; const rule = this.rules[fieldName]; if (!rule) return true; let isValid = true; let errorMessage = ''; // Cek required if (rule.required) { if (field.type === 'checkbox') { if (!field.checked) { isValid = false; errorMessage = rule.message; } } else if (!field.value.trim()) { isValid = false; errorMessage = rule.message; } } // Cek pattern jika field tidak kosong if (isValid && field.value.trim() && rule.pattern) { if (!rule.pattern.test(field.value.trim())) { isValid = false; errorMessage = rule.message; } } // Cek minimum length if (isValid && field.value.trim() && rule.minLength) { if (field.value.trim().length < rule.minLength) { isValid = false; errorMessage = rule.message; } } // Tampilkan hasil validasi this.showValidationResult(field, isValid, errorMessage); return isValid; } // Validasi radio group validateRadioGroup(groupName) { const radios = document.querySelectorAll(`input[name="${groupName}"]`); const isChecked = Array.from(radios).some(radio => radio.checked); const rule = this.rules[groupName]; if (!rule) return true; const errorElement = document.getElementById(groupName + 'Error'); if (rule.required && !isChecked) { if (errorElement) { errorElement.textContent = rule.message; errorElement.style.display = 'block'; } return false; } else { if (errorElement) { errorElement.textContent = ''; errorElement.style.display = 'none'; } return true; } } // Tampilkan hasil validasi showValidationResult(field, isValid, errorMessage) { const errorElement = document.getElementById(field.id + 'Error'); if (isValid) { field.classList.remove('error'); if (errorElement) { errorElement.textContent = ''; errorElement.style.display = 'none'; } // Tambahkan efek success field.style.borderColor = '#48bb78'; setTimeout(() => { if (field.classList.contains('error') === false) { field.style.borderColor = ''; } }, 2000); } else { field.classList.add('error'); if (errorElement) { errorElement.textContent = errorMessage; errorElement.style.display = 'block'; } // Animasi shake untuk error field.classList.add('error-shake'); setTimeout(() => { field.classList.remove('error-shake'); }, 500); } } // Validasi step sebelum melanjutkan validateStep(stepNumber) { const stepElement = document.querySelector(`[data-step="${stepNumber}"]`); const inputs = stepElement.querySelectorAll('input, select'); let isStepValid = true; inputs.forEach(input => { if (input.type === 'radio') { // Validasi radio group hanya sekali per group const groupName = input.name; if (!document.querySelector(`input[name="${groupName}"]:checked`)) { this.validateRadioGroup(groupName); isStepValid = false; } } else { if (!this.validateField(input)) { isStepValid = false; } } }); return isStepValid; } // Validasi seluruh form validateForm() { let isFormValid = true; for (let step = 1; step <= 3; step++) { if (!this.validateStep(step)) { isFormValid = false; } } return isFormValid; } // Reset validasi resetValidation() { document.querySelectorAll('.error').forEach(element => { element.classList.remove('error'); }); document.querySelectorAll('.error-message').forEach(element => { element.textContent = ''; element.style.display = 'none'; }); } } // Inisialisasi validator const formValidator = new FormValidator();

🗃️ Yang akan kita kelola:

  • Form Data: Semua input pengguna disimpan dalam objek
  • Step State: Status langkah saat ini dan yang sudah selesai
  • Validation State: Status validasi setiap field
  • Local Storage: Simpan data sementara di browser
  • Auto Save: Simpan otomatis saat pengguna mengetik
💾 state-manager.js - Manajemen State
// State Manager untuk Formulir class FormStateManager { constructor() { this.state = { currentStep: 1, completedSteps: [], formData: { nama: '', email: '', telepon: '', program: '', jadwal: '', agreement: false }, validationState: { nama: { isValid: false, message: '' }, email: { isValid: false, message: '' }, telepon: { isValid: false, message: '' }, program: { isValid: false, message: '' }, jadwal: { isValid: false, message: '' }, agreement: { isValid: false, message: '' } }, metadata: { startTime: new Date(), lastSaved: null, version: '1.0' } }; this.storageKey = 'formRegistrationState'; this.autoSaveInterval = null; this.initializeState(); } // Inisialisasi state dari localStorage atau default initializeState() { const savedState = this.loadFromStorage(); if (savedState) { this.state = { ...this.state, ...savedState }; this.restoreFormData(); } this.startAutoSave(); this.bindFormEvents(); } // Simpan data ke localStorage saveToStorage() { try { const stateToSave = { ...this.state, metadata: { ...this.state.metadata, lastSaved: new Date() } }; localStorage.setItem(this.storageKey, JSON.stringify(stateToSave)); console.log('State saved to localStorage'); } catch (error) { console.error('Failed to save state:', error); } } // Load data dari localStorage loadFromStorage() { try { const savedState = localStorage.getItem(this.storageKey); if (savedState) { return JSON.parse(savedState); } } catch (error) { console.error('Failed to load state:', error); } return null; } // Update form data updateFormData(fieldName, value) { this.state.formData[fieldName] = value; this.saveToStorage(); // Trigger event untuk komponen lain this.dispatchStateChange('formData', fieldName, value); } // Update validation state updateValidationState(fieldName, isValid, message = '') { this.state.validationState[fieldName] = { isValid, message }; this.saveToStorage(); this.dispatchStateChange('validation', fieldName, { isValid, message }); } // Update current step updateCurrentStep(step) { // Tandai step sebelumnya sebagai completed if (step > this.state.currentStep) { if (!this.state.completedSteps.includes(this.state.currentStep)) { this.state.completedSteps.push(this.state.currentStep); } } this.state.currentStep = step; this.saveToStorage(); this.dispatchStateChange('step', 'current', step); } // Bind event listeners ke form elements bindFormEvents() { // Text inputs document.querySelectorAll('input[type="text"], input[type="email"], input[type="tel"], select').forEach(input => { input.addEventListener('input', (e) => { this.updateFormData(e.target.name || e.target.id, e.target.value); }); }); // Radio buttons document.querySelectorAll('input[type="radio"]').forEach(radio => { radio.addEventListener('change', (e) => { if (e.target.checked) { this.updateFormData(e.target.name, e.target.value); } }); }); // Checkboxes document.querySelectorAll('input[type="checkbox"]').forEach(checkbox => { checkbox.addEventListener('change', (e) => { this.updateFormData(e.target.name || e.target.id, e.target.checked); }); }); } // Restore form data ke form elements restoreFormData() { Object.keys(this.state.formData).forEach(fieldName => { const value = this.state.formData[fieldName]; const element = document.querySelector(`[name="${fieldName}"], #${fieldName}`); if (element) { if (element.type === 'radio') { const radioButton = document.querySelector(`input[name="${fieldName}"][value="${value}"]`); if (radioButton) radioButton.checked = true; } else if (element.type === 'checkbox') { element.checked = value; } else { element.value = value; } } }); } // Auto save setiap 30 detik startAutoSave() { this.autoSaveInterval = setInterval(() => { this.saveToStorage(); }, 30000); // 30 seconds } // Stop auto save stopAutoSave() { if (this.autoSaveInterval) { clearInterval(this.autoSaveInterval); } } // Dispatch custom events untuk state changes dispatchStateChange(type, field, value) { const event = new CustomEvent('stateChange', { detail: { type, field, value, state: this.state } }); document.dispatchEvent(event); } // Get current form data getFormData() { return { ...this.state.formData }; } // Reset state resetState() { this.state = { currentStep: 1, completedSteps: [], formData: { nama: '', email: '', telepon: '', program: '', jadwal: '', agreement: false }, validationState: { nama: { isValid: false, message: '' }, email: { isValid: false, message: '' }, telepon: { isValid: false, message: '' }, program: { isValid: false, message: '' }, jadwal: { isValid: false, message: '' }, agreement: { isValid: false, message: '' } }, metadata: { startTime: new Date(), lastSaved: null, version: '1.0' } }; localStorage.removeItem(this.storageKey); this.dispatchStateChange('reset', null, null); } } // Inisialisasi state manager const stateManager = new FormStateManager();

📈 Fitur Progress Bar:

  • Step Indicators: Lingkaran bernomor yang berubah warna

  • Smooth Animation: Transisi yang halus saat update
  • Interactive: Bisa klik untuk navigasi (jika diizinkan)
📊 progress-controller.js - Progress Bar
// Progress Bar Controller class ProgressController { constructor() { this.totalSteps = 3; this.currentStep = 1; this.progressFill = document.getElementById('progressFill'); this.stepIndicators = document.querySelectorAll('.step-indicator'); this.initializeProgress(); } // Inisialisasi progress bar initializeProgress() { this.updateProgress(1); this.bindEvents(); } // Update progress bar updateProgress(step) { this.currentStep = step; // Hitung persentase const percentage = ((step - 1) / (this.totalSteps - 1)) * 100; // Update progress fill dengan animasi this.animateProgressFill(percentage); // Update step indicators this.updateStepIndicators(step); // Dispatch event this.dispatchProgressEvent(step, percentage); } // Animasi progress fill animateProgressFill(targetPercentage) { const currentWidth = parseFloat(this.progressFill.style.width) || 0; const difference = targetPercentage - currentWidth; const duration = 500; const steps = 30; const stepValue = difference / steps; const stepDuration = duration / steps; let currentStep = 0; const animate = () => { if (currentStep < steps) { const newWidth = currentWidth + (stepValue * currentStep); this.progressFill.style.width = newWidth + '%'; currentStep++; setTimeout(animate, stepDuration); } else { this.progressFill.style.width = targetPercentage + '%'; } }; animate(); } // Update step indicators updateStepIndicators(currentStep) { this.stepIndicators.forEach((indicator, index) => { const stepNumber = index + 1; indicator.classList.remove('active', 'completed'); if (stepNumber < currentStep) { indicator.classList.add('completed'); indicator.innerHTML = '✓'; } else if (stepNumber === currentStep) { indicator.classList.add('active'); indicator.innerHTML = stepNumber; } else { indicator.innerHTML = stepNumber; } }); } // Bind events bindEvents() { // Listen untuk state changes document.addEventListener('stateChange', (e) => { if (e.detail.type === 'step' && e.detail.field === 'current') { this.updateProgress(e.detail.value); } }); } // Dispatch progress event dispatchProgressEvent(step, percentage) { const event = new CustomEvent('progressUpdate', { detail: { step, percentage, isComplete: step === this.totalSteps } }); document.dispatchEvent(event); } } // Inisialisasi progress controller const progressController = new ProgressController();

// PDF Generator menggunakan jsPDF class PDFGenerator { constructor() { this.loadJsPDF(); } // Load jsPDF library loadJsPDF() { return new Promise((resolve, reject) => { if (typeof window.jsPDF !== 'undefined') { resolve(); return; } const script = document.createElement('script'); script.src = 'https://cdnjs.cloudflare.com/ajax/libs/jspdf/2.5.1/jspdf.umd.min.js'; script.onload = () => resolve(); script.onerror = () => reject(new Error('Failed to load jsPDF library')); document.head.appendChild(script); }); } // Generate PDF dari form data async generatePDF(formData) { try { await this.loadJsPDF(); if (typeof window.jsPDF === 'undefined') { throw new Error('jsPDF library not available'); } const { jsPDF } = window.jsPDF; const doc = new jsPDF(); // Setup document this.setupDocument(doc); // Add header this.addHeader(doc); // Add form data this.addFormData(doc, formData); // Add footer this.addFooter(doc); // Generate filename const filename = this.generateFilename(formData); // Save PDF doc.save(filename); return filename; } catch (error) { console.error('Error generating PDF:', error); throw error; } } // Setup document properties setupDocument(doc) { doc.setProperties({ title: 'Formulir Pendaftaran', subject: 'Data Pendaftaran Program', author: 'Sistem Pendaftaran', creator: 'Form Registration System' }); } // Add header ke PDF addHeader(doc) { doc.setFontSize(20); doc.setFont(undefined, 'bold'); doc.text('📚 FORMULIR PENDAFTARAN', 105, 30, { align: 'center' }); doc.setFontSize(12); doc.setFont(undefined, 'normal'); doc.text('Program Pembelajaran Teknologi', 105, 40, { align: 'center' }); doc.setLineWidth(0.5); doc.line(20, 50, 190, 50); const today = new Date().toLocaleDateString('id-ID'); doc.setFontSize(10); doc.text(`Tanggal: ${today}`, 20, 60); } // Add form data ke PDF addFormData(doc, formData) { let yPosition = 80; doc.setFontSize(14); doc.setFont(undefined, 'bold'); doc.text('DATA PENDAFTAR', 20, yPosition); yPosition += 15; const fields = [ { label: 'Nama Lengkap', value: formData.nama }, { label: 'Email', value: formData.email }, { label: 'Nomor Telepon', value: formData.telepon }, { label: 'Program Dipilih', value: this.formatProgram(formData.program) }, { label: 'Jadwal Belajar', value: this.formatJadwal(formData.jadwal) } ]; doc.setFontSize(11); doc.setFont(undefined, 'normal'); fields.forEach(field => { if (field.value) { doc.setFont(undefined, 'bold'); doc.text(field.label + ':', 20, yPosition); doc.setFont(undefined, 'normal'); doc.text(field.value, 70, yPosition); yPosition += 12; } }); } // Add footer ke PDF addFooter(doc) { const pageHeight = doc.internal.pageSize.height; doc.setFontSize(8); doc.setFont(undefined, 'italic'); doc.text('Dokumen ini dibuat secara otomatis oleh sistem pendaftaran', 105, pageHeight - 20, { align: 'center' }); doc.text('Terima kasih atas pendaftaran Anda!', 105, pageHeight - 10, { align: 'center' }); } // Format program name formatProgram(program) { const programs = { 'web-development': 'Web Development', 'mobile-development': 'Mobile Development', 'data-science': 'Data Science' }; return programs[program] || program; } // Format jadwal formatJadwal(jadwal) { const jadwalMap = { 'pagi': 'Pagi (08:00-12:00)', 'siang': 'Siang (13:00-17:00)', 'malam': 'Malam (18:00-22:00)' }; return jadwalMap[jadwal] || jadwal; } // Generate filename generateFilename(formData) { const date = new Date().toISOString().split('T')[0]; const name = formData.nama.replace(/\s+/g, '_').toLowerCase(); return `pendaftaran_${name}_${date}.pdf`; } } // Inisialisasi PDF generator const pdfGenerator = new PDFGenerator();

🔧 Langkah 8: File main.js - Menghubungkan Semua Komponen

Sekarang kita akan membuat file main.js yang berfungsi sebagai koordinator utama untuk menghubungkan semua komponen yang telah kita buat di langkah-langkah sebelumnya.

🔗 Fungsi main.js:

  • Inisialisasi: Memulai semua komponen saat halaman dimuat
  • Event Coordination: Menghubungkan event antar komponen
  • Navigation Control: Mengatur perpindahan antar langkah
  • Form Submission: Menangani submit form dan generate PDF
  • Error Handling: Menangani error dan fallback
🔧 js/main.js - Koordinator Utama
// Main Application Controller class FormApplication { constructor() { this.currentStep = 1; this.totalSteps = 3; this.isInitialized = false; // Komponen-komponen aplikasi this.validator = null; this.stateManager = null; this.progressController = null; this.pdfGenerator = null; this.init(); } // Inisialisasi aplikasi async init() { try { // Tunggu DOM ready if (document.readyState === 'loading') { document.addEventListener('DOMContentLoaded', () => this.initializeComponents()); } else { this.initializeComponents(); } } catch (error) { console.error('Failed to initialize application:', error); this.showError('Gagal memuat aplikasi. Silakan refresh halaman.'); } } // Inisialisasi semua komponen initializeComponents() { try { // Inisialisasi komponen (pastikan class sudah tersedia) if (typeof FormValidator !== 'undefined') { this.validator = new FormValidator(); } if (typeof FormStateManager !== 'undefined') { this.stateManager = new FormStateManager(); } if (typeof ProgressController !== 'undefined') { this.progressController = new ProgressController(); } if (typeof PDFGenerator !== 'undefined') { this.pdfGenerator = new PDFGenerator(); } // Setup event listeners this.setupEventListeners(); // Setup navigation this.setupNavigation(); // Restore state jika ada this.restoreApplicationState(); this.isInitialized = true; console.log('Application initialized successfully'); } catch (error) { console.error('Error initializing components:', error); this.showError('Terjadi kesalahan saat memuat komponen.'); } } // Setup event listeners setupEventListeners() { // Listen untuk state changes document.addEventListener('stateChange', (e) => { this.handleStateChange(e.detail); }); // Listen untuk progress updates document.addEventListener('progressUpdate', (e) => { this.handleProgressUpdate(e.detail); }); // Form submission const form = document.getElementById('multiStepForm'); if (form) { form.addEventListener('submit', (e) => { e.preventDefault(); this.handleFormSubmission(); }); } } // Setup navigation buttons setupNavigation() { const prevBtn = document.getElementById('prevBtn'); const nextBtn = document.getElementById('nextBtn'); const submitBtn = document.getElementById('submitBtn'); if (prevBtn) { prevBtn.addEventListener('click', () => this.previousStep()); } if (nextBtn) { nextBtn.addEventListener('click', () => this.nextStep()); } if (submitBtn) { submitBtn.addEventListener('click', () => this.handleFormSubmission()); } // Update button states this.updateNavigationButtons(); } // Handle state changes handleStateChange(detail) { if (detail.type === 'step') { this.currentStep = detail.value; this.updateNavigationButtons(); } } // Handle progress updates handleProgressUpdate(detail) { // Bisa ditambahkan logic tambahan untuk progress updates console.log('Progress updated:', detail); } // Pindah ke step berikutnya nextStep() { if (!this.validator || !this.stateManager) { console.error('Required components not initialized'); return; } // Validasi step saat ini if (this.validator.validateStep(this.currentStep)) { if (this.currentStep < this.totalSteps) { this.currentStep++; this.showStep(this.currentStep); this.stateManager.updateCurrentStep(this.currentStep); } } else { this.showError('Mohon lengkapi semua field yang wajib diisi.'); } } // Pindah ke step sebelumnya previousStep() { if (this.currentStep > 1) { this.currentStep--; this.showStep(this.currentStep); if (this.stateManager) { this.stateManager.updateCurrentStep(this.currentStep); } } } // Tampilkan step tertentu showStep(step) { // Hide semua steps document.querySelectorAll('.form-step').forEach(stepEl => { stepEl.classList.remove('active'); }); // Show step yang diminta const targetStep = document.querySelector(`[data-step="${step}"]`); if (targetStep) { targetStep.classList.add('active'); } // Update progress jika ada if (this.progressController) { this.progressController.updateProgress(step); } // Update summary jika step 3 if (step === 3) { this.updateSummary(); } this.updateNavigationButtons(); } // Update navigation buttons updateNavigationButtons() { const prevBtn = document.getElementById('prevBtn'); const nextBtn = document.getElementById('nextBtn'); const submitBtn = document.getElementById('submitBtn'); if (prevBtn) { prevBtn.style.display = this.currentStep > 1 ? 'block' : 'none'; } if (nextBtn) { nextBtn.style.display = this.currentStep < this.totalSteps ? 'block' : 'none'; } if (submitBtn) { submitBtn.style.display = this.currentStep === this.totalSteps ? 'block' : 'none'; } } // Update summary di step 3 updateSummary() { if (!this.stateManager) return; const formData = this.stateManager.getFormData(); const summaryContainer = document.getElementById('dataSummary'); if (summaryContainer) { const programNames = { 'web-development': 'Web Development', 'mobile-development': 'Mobile Development', 'data-science': 'Data Science' }; const jadwalNames = { 'pagi': 'Pagi (08:00-12:00)', 'siang': 'Siang (13:00-17:00)', 'malam': 'Malam (18:00-22:00)' }; summaryContainer.innerHTML = `
Nama Lengkap: ${formData.nama || '-'}
Email: ${formData.email || '-'}
Telepon: ${formData.telepon || '-'}
Program: ${programNames[formData.program] || formData.program || '-'}
Jadwal: ${jadwalNames[formData.jadwal] || formData.jadwal || '-'}
`; } } // Handle form submission async handleFormSubmission() { try { // Validasi final if (!this.validator || !this.validator.validateForm()) { this.showError('Mohon lengkapi semua field yang diperlukan.'); return; } // Show loading this.showLoading(true); // Get form data const formData = this.stateManager ? this.stateManager.getFormData() : {}; // Generate PDF if (this.pdfGenerator) { const filename = await this.pdfGenerator.generatePDF(formData); this.showSuccess(`PDF berhasil diunduh: ${filename}`); // Reset form setelah berhasil setTimeout(() => { this.resetForm(); }, 2000); } else { throw new Error('PDF Generator tidak tersedia'); } } catch (error) { console.error('Form submission error:', error); this.showError('Gagal membuat PDF. Silakan coba lagi.'); } finally { this.showLoading(false); } } // Reset form resetForm() { if (this.stateManager) { this.stateManager.resetState(); } if (this.validator) { this.validator.resetValidation(); } this.currentStep = 1; this.showStep(1); // Clear form const form = document.getElementById('multiStepForm'); if (form) { form.reset(); } } // Restore application state restoreApplicationState() { if (this.stateManager) { const currentStep = this.stateManager.state.currentStep; if (currentStep && currentStep !== this.currentStep) { this.currentStep = currentStep; this.showStep(currentStep); } } } // Show loading state showLoading(show) { const submitBtn = document.getElementById('submitBtn'); if (submitBtn) { if (show) { submitBtn.disabled = true; submitBtn.innerHTML = '⏳ Membuat PDF...'; submitBtn.classList.add('loading'); } else { submitBtn.disabled = false; submitBtn.innerHTML = '📄 Download PDF'; submitBtn.classList.remove('loading'); } } } // Show error message showError(message) { // Bisa menggunakan toast notification atau alert alert('❌ ' + message); } // Show success message showSuccess(message) { // Bisa menggunakan toast notification atau alert alert('✅ ' + message); } } // Inisialisasi aplikasi const app = new FormApplication();
