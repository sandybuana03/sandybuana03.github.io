Pengenalan Basis Data

🗃️ Apa itu Basis Data?

Basis data adalah kumpulan data yang disimpan secara sistematis dalam komputer sehingga dapat diakses dan dikelola dengan mudah. Bayangkan seperti lemari arsip digital yang super canggig dengan sistem pencarian yang sangat cepat!

🏢 Contoh di Dunia Bisnis:

  • 🏦 Bank: Data nasabah & transaksi
  • 🏥 Rumah Sakit: Rekam medis pasien
  • 🎓 Sekolah: Data siswa & nilai
  • 🛒 E-commerce: Produk & pesanan
  • ✈️ Maskapai: Jadwal & reservasi

📱 Contoh di Kehidupan Sehari-hari:

  • 📞 Kontak di HP kalian
  • 🎵 Playlist di Spotify
  • 👥 Teman di Instagram/Facebook
  • 📧 Email di Gmail
  • 🎮 Progress game online

🔍 Mengapa Basis Data Penting?

⚡

Akses Cepat

Cari data dalam milidetik

🔒

Aman

Data terlindungi dari kerusakan

👥

Multi-User

Banyak orang bisa akses bersamaan

💻 Apa itu SQL?

SQL (Structured Query Language) adalah bahasa khusus untuk berkomunikasi dengan basis data. Seperti bahasa Inggris untuk berbicara dengan orang asing, SQL adalah bahasa untuk "berbicara" dengan database!

🌟 Mengapa SQL Penting?

  • ✅ Digunakan di 90% aplikasi dunia
  • ✅ Skill paling dicari di tech industry
  • ✅ Gaji programmer SQL tinggi
  • ✅ Mudah dipelajari pemula
  • ✅ Standar internasional sejak 1986

💼 Karir dengan SQL:

  • 👨‍💻 Backend Developer
  • 📊 Data Analyst
  • 🗄️ Database Administrator
  • 🔬 Data Scientist
  • 🏗️ System Architect

🎯 Fun Fact tentang SQL:

• Dibuat oleh IBM pada tahun 1974
• Awalnya bernama SEQUEL
• Digunakan oleh Google, Facebook, Netflix
• Ada lebih dari 200 perintah SQL

DDL - Data Definition Language

Perintah untuk membuat dan mengubah struktur database

📝 CREATE - Membuat Database/Tabel

Perintah CREATE digunakan untuk membuat database baru atau tabel baru. Seperti membangun rumah, kita harus membuat fondasinya dulu!

Contoh Membuat Database:

CREATE DATABASE sekolah_saya;
-- Membuat database bernama 'sekolah_saya'

Contoh Membuat Tabel:

CREATE TABLE siswa (
  id INT PRIMARY KEY,
  nama VARCHAR(50),
  kelas VARCHAR(10),
  umur INT
);
-- Membuat tabel siswa dengan 4 kolom

🔧 ALTER - Mengubah Struktur Tabel

Perintah ALTER digunakan untuk mengubah struktur tabel yang sudah ada. Seperti renovasi rumah, kita bisa menambah kamar atau mengubah yang sudah ada!

Menambah Kolom:

ALTER TABLE siswa
ADD alamat VARCHAR(100);

Mengubah Kolom:

ALTER TABLE siswa
MODIFY nama VARCHAR(100);

🗑️ DROP - Menghapus Database/Tabel

Perintah DROP digunakan untuk menghapus database atau tabel. Hati-hati! Seperti menghancurkan rumah, sekali dihapus tidak bisa dikembalikan!

⚠️ PERINGATAN: Perintah ini akan menghapus SEMUA data!

DROP TABLE siswa;
-- Menghapus tabel siswa beserta semua datanya

DROP DATABASE sekolah_saya;
-- Menghapus database sekolah_saya

📊 Tipe Data dalam SQL

Setiap kolom dalam tabel harus memiliki tipe data yang sesuai. Seperti menentukan jenis kotak untuk menyimpan barang yang berbeda!

🔢 Tipe Angka:

  • INT - Bilangan bulat (-2M s/d 2M)
  • BIGINT - Bilangan bulat besar
  • DECIMAL(10,2) - Desimal presisi
  • FLOAT - Bilangan pecahan

📝 Tipe Teks:

  • VARCHAR(50) - Teks variabel
  • CHAR(10) - Teks tetap
  • TEXT - Teks panjang
  • ENUM - Pilihan terbatas

📅 Tipe Waktu:

  • DATE - Tanggal (YYYY-MM-DD)
  • TIME - Waktu (HH:MM:SS)
  • DATETIME - Tanggal + waktu
  • TIMESTAMP - Cap waktu

💡 Tips Memilih Tipe Data:

• Gunakan VARCHAR untuk nama, alamat
• Gunakan INT untuk ID, umur, jumlah
• Gunakan DECIMAL untuk harga, gaji
• Gunakan DATE untuk tanggal lahir

🔒 Constraints (Batasan)

Constraints adalah aturan yang diterapkan pada kolom untuk menjaga kualitas data. Seperti peraturan di sekolah!

🔑 Constraint Utama:

PRIMARY KEY - Kunci utama, unik & tidak boleh kosong
FOREIGN KEY - Kunci asing, referensi ke tabel lain
UNIQUE - Nilai harus unik, tidak boleh duplikat
NOT NULL - Tidak boleh kosong

✅ Constraint Lainnya:

CHECK - Validasi kondisi tertentu
DEFAULT - Nilai default jika kosong
AUTO_INCREMENT - Otomatis bertambah

📝 Contoh Penggunaan Constraints:

CREATE TABLE mahasiswa (
  id INT PRIMARY KEY AUTO_INCREMENT,
  nim VARCHAR(10) UNIQUE NOT NULL,
  nama VARCHAR(50) NOT NULL,
  umur INT CHECK(umur >= 17),
  status VARCHAR(10) DEFAULT 'Aktif'
);

⚡ Index - Mempercepat Pencarian

Index seperti daftar isi di buku - membantu database menemukan data dengan cepat!

🚀 Keuntungan Index:

  • ⚡ Pencarian data super cepat
  • 📊 Query SELECT lebih efisien
  • 🔍 WHERE clause lebih optimal
  • 📈 Performa database meningkat

⚠️ Kerugian Index:

  • 💾 Membutuhkan storage tambahan
  • 🐌 INSERT/UPDATE lebih lambat
  • 🔧 Maintenance overhead
  • 📝 Harus dikelola dengan baik

📝 Contoh Membuat Index:

-- Membuat index pada kolom nama untuk pencarian cepat
CREATE INDEX idx_nama ON siswa(nama);

-- Membuat index gabungan
CREATE INDEX idx_kelas_umur ON siswa(kelas, umur);

DML - Data Manipulation Language

Perintah untuk menambah, mengubah, dan menghapus data

➕ INSERT - Menambah Data

Perintah INSERT digunakan untuk menambahkan data baru ke dalam tabel. Seperti menulis nama di buku tamu!

Menambah Satu Data:

INSERT INTO siswa (id, nama, kelas, umur)
VALUES (1, 'Budi Santoso', 'XII RPL', 17);
-- Menambah data siswa baru

Menambah Banyak Data Sekaligus:

INSERT INTO siswa (id, nama, kelas, umur)
VALUES
  (2, 'Siti Aminah', 'XII TKJ', 16),
  (3, 'Ahmad Rizki', 'XII MM', 17);

🔄 UPDATE - Mengubah Data

Perintah UPDATE digunakan untuk mengubah data yang sudah ada. Seperti mengoreksi tulisan dengan tip-ex!

Mengubah Data Tertentu:

UPDATE siswa
SET kelas = 'XII RPL 1'
WHERE id = 1;
-- Mengubah kelas siswa dengan id = 1

⚠️ PENTING: Selalu gunakan WHERE! Tanpa WHERE, semua data akan berubah!

UPDATE siswa
SET umur = umur + 1
WHERE kelas = 'XII RPL';
-- Menambah umur semua siswa kelas XII RPL

🗑️ DELETE - Menghapus Data

Perintah DELETE digunakan untuk menghapus data dari tabel. Seperti menghapus nama dari daftar!

⚠️ HATI-HATI: Data yang dihapus tidak bisa dikembalikan!

DELETE FROM siswa
WHERE id = 3;
-- Menghapus siswa dengan id = 3

DELETE FROM siswa
WHERE umur < 16;
-- Menghapus semua siswa yang umurnya kurang dari 16

DQL - Data Query Language

Perintah untuk mencari dan menampilkan data

📋 SELECT - Menampilkan Data

Perintah SELECT adalah yang paling sering digunakan! Seperti mencari file di komputer, kita bisa mencari data dengan berbagai kriteria.

Menampilkan Semua Data:

SELECT * FROM siswa;
-- Tampilkan semua kolom dan baris

Menampilkan Kolom Tertentu:

SELECT nama, kelas
FROM siswa;

🎯 WHERE - Filtering Data

WHERE digunakan untuk mencari data dengan kondisi tertentu. Seperti filter di Instagram!

Kondisi Sederhana:

SELECT * FROM siswa
WHERE kelas = 'XII RPL';
-- Tampilkan siswa kelas XII RPL saja

Kondisi dengan Operator:

SELECT nama, umur FROM siswa
WHERE umur >= 17;
-- Siswa yang umurnya 17 tahun ke atas

Kondisi Gabungan (AND, OR):

SELECT * FROM siswa
WHERE kelas = 'XII RPL' AND umur > 16;
-- Siswa XII RPL yang umurnya di atas 16

📊 ORDER BY - Mengurutkan Data

ORDER BY digunakan untuk mengurutkan hasil pencarian. Seperti mengurutkan playlist musik!

Urutan Naik (ASC):

SELECT * FROM siswa
ORDER BY nama ASC;
-- Urutkan nama A-Z

Urutan Turun (DESC):

SELECT * FROM siswa
ORDER BY umur DESC;
-- Urutkan umur terbesar dulu

🔢 LIMIT - Membatasi Hasil

LIMIT digunakan untuk membatasi jumlah data yang ditampilkan. Seperti "tampilkan 10 postingan terbaru"!

SELECT * FROM siswa
ORDER BY umur DESC
LIMIT 5;
-- Tampilkan 5 siswa tertua

📊 Fungsi Agregat - Menghitung Data

Fungsi agregat digunakan untuk melakukan perhitungan pada sekumpulan data. Seperti kalkulator untuk data!

🧮 Fungsi Utama:

COUNT() - Menghitung jumlah baris
SUM() - Menjumlahkan nilai
AVG() - Menghitung rata-rata
MAX() - Nilai tertinggi
MIN() - Nilai terendah

📝 Contoh Penggunaan:

-- Menghitung jumlah siswa
SELECT COUNT(*) FROM siswa;

-- Rata-rata umur siswa
SELECT AVG(umur) FROM siswa;

-- Siswa tertua dan termuda
SELECT MAX(umur), MIN(umur)
FROM siswa;

👥 GROUP BY & HAVING - Mengelompokkan Data

GROUP BY mengelompokkan data berdasarkan kriteria tertentu, HAVING memfilter hasil grup. Seperti mengelompokkan siswa berdasarkan kelas!

📊 GROUP BY - Mengelompokkan:

-- Jumlah siswa per kelas
SELECT kelas, COUNT(*) as jumlah_siswa
FROM siswa
GROUP BY kelas;

Hasil: XII RPL (15 siswa), XII TKJ (12 siswa), XII MM (10 siswa)

🔍 HAVING - Filter Grup:

-- Kelas dengan siswa lebih dari 10 orang
SELECT kelas, COUNT(*) as jumlah
FROM siswa
GROUP BY kelas
HAVING COUNT(*) > 10;

Perbedaan: WHERE filter sebelum grup, HAVING filter setelah grup

🔗 JOIN - Menggabungkan Tabel

JOIN digunakan untuk menggabungkan data dari dua atau lebih tabel. Seperti menggabungkan puzzle!

🔗 Jenis JOIN:

INNER JOIN - Data yang ada di kedua tabel
LEFT JOIN - Semua data tabel kiri
RIGHT JOIN - Semua data tabel kanan
FULL JOIN - Semua data kedua tabel

📝 Contoh JOIN:

-- Gabungkan data siswa dengan nilai
SELECT s.nama, n.mata_pelajaran, n.nilai
FROM siswa s
INNER JOIN nilai n
ON s.id = n.siswa_id;

🎭 Subquery - Query dalam Query

Subquery adalah query yang berada di dalam query lain. Seperti boneka matryoshka!

🔍 Subquery di WHERE:

-- Siswa dengan umur di atas rata-rata
SELECT nama, umur FROM siswa
WHERE umur > (SELECT AVG(umur) FROM siswa);

📊 Subquery di SELECT:

-- Tampilkan nama dan selisih dengan rata-rata
SELECT nama, umur,
  (umur - (SELECT AVG(umur) FROM siswa)) as selisih
FROM siswa;

DCL - Data Control Language

Perintah untuk mengatur hak akses dan keamanan data

🛡️ Apa itu DCL?

DCL adalah perintah untuk mengatur siapa saja yang boleh mengakses database. Seperti sistem keamanan di gedung - ada yang boleh masuk ke semua ruangan, ada yang hanya boleh ke ruangan tertentu!

Mengapa DCL Penting?

  • 🔒 Melindungi data sensitif dari akses yang tidak sah
  • 👥 Mengatur hak akses berbeda untuk user berbeda
  • 🛡️ Mencegah kerusakan data oleh user yang tidak berwenang
  • 📊 Memastikan integritas dan keamanan database

✅ GRANT - Memberikan Hak Akses

Perintah GRANT digunakan untuk memberikan izin kepada user untuk melakukan operasi tertentu. Seperti memberikan kunci ruangan kepada seseorang!

Memberikan Hak SELECT:

GRANT SELECT ON siswa TO 'guru_bk';
-- Guru BK hanya bisa melihat data siswa

Memberikan Beberapa Hak Sekaligus:

GRANT SELECT, INSERT, UPDATE ON siswa
TO 'admin_sekolah';
-- Admin bisa lihat, tambah, dan ubah data

Memberikan Semua Hak:

GRANT ALL PRIVILEGES ON sekolah_saya.*
TO 'kepala_sekolah';
-- Kepala sekolah punya akses penuh

❌ REVOKE - Mencabut Hak Akses

Perintah REVOKE digunakan untuk mencabut izin yang sudah diberikan. Seperti mengambil kembali kunci ruangan!

Mencabut Hak Tertentu:

REVOKE INSERT ON siswa FROM 'guru_bk';
-- Guru BK tidak bisa lagi menambah data

Mencabut Semua Hak:

REVOKE ALL PRIVILEGES ON siswa
FROM 'mantan_admin';
-- Hapus semua akses mantan admin

🎭 Jenis-jenis Hak Akses (Privileges)

Ada berbagai macam hak akses yang bisa diberikan sesuai kebutuhan:

Hak Akses Data:

  • • SELECT - Melihat data
  • • INSERT - Menambah data
  • • UPDATE - Mengubah data
  • • DELETE - Menghapus data

Hak Akses Struktur:

  • • CREATE - Membuat tabel/database
  • • ALTER - Mengubah struktur
  • • DROP - Menghapus tabel/database
  • • INDEX - Membuat index

🎬 Contoh Skenario di Sekolah

Mari lihat bagaimana DCL diterapkan dalam sistem informasi sekolah:

👨‍🏫 Guru Mata Pelajaran:

Hanya bisa melihat dan mengubah nilai siswa di kelasnya

GRANT SELECT, UPDATE ON nilai TO 'guru_matematika';

👩‍💼 Staff TU:

Bisa mengelola data siswa tapi tidak bisa melihat nilai

GRANT SELECT, INSERT, UPDATE ON siswa TO 'staff_tu';

👨‍💻 IT Support:

Bisa mengelola struktur database tapi tidak bisa lihat data sensitif

GRANT CREATE, ALTER, DROP ON sekolah_saya.* TO 'it_support';
