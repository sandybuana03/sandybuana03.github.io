📖 Pengertian Algoritma

📋

🎯 Definisi

Algoritma adalah urutan langkah-langkah logis yang sistematis untuk menyelesaikan suatu masalah atau mencapai tujuan tertentu.

📚 Definisi Formal:

"Algoritma adalah prosedur komputasi yang terdefinisi dengan baik yang mengambil beberapa nilai sebagai input dan menghasilkan beberapa nilai sebagai output" - Thomas H. Cormen

📜 Sejarah Singkat Algoritma

🏛️ Era Kuno (300 SM)

Algoritma Euclidean untuk mencari FPB (Faktor Persekutuan Terbesar)

Masih digunakan hingga sekarang!

🕌 Era Islam (825 M)

Al-Khwarizmi menulis "Kitab al-Jabr" yang memperkenalkan aljabar

Dari namanya lahir kata "algoritma"

💻 Era Modern (1940s)

Alan Turing mengembangkan konsep algoritma untuk komputer

Bapak ilmu komputer modern

🌐 Era Digital (1990s-sekarang)

Algoritma menjadi tulang punggung internet dan AI

Google, Facebook, dll menggunakan algoritma kompleks

✨ Ciri-ciri Algoritma

  • 🎯 Jelas (Definiteness): Setiap langkah mudah dipahami dan tidak ambigu
  • 🔄 Terbatas (Finiteness): Ada awal dan akhir yang jelas
  • 📊 Input/Output: Ada masukan dan keluaran yang terdefinisi
  • ⚡ Efektif (Effectiveness): Dapat dilaksanakan dalam waktu terbatas
  • 🎲 Umum (Generality): Dapat menyelesaikan semua masalah dalam kategori yang sama

🍳 Contoh Sehari-hari

Algoritma Membuat Mie Instan:

  1. 1. Rebus air 400ml
  2. 2. Masukkan mie
  3. 3. Tunggu 3 menit

  5. 5. Aduk dan sajikan

🔍 Analisis:

Input: Mie mentah, air, bumbu | Output: Mie siap makan | Langkah: Jelas dan terbatas

🔍 Algoritma Pencarian

📚 Linear Search (Sequential)

Mencari satu per satu dari awal sampai akhir. Seperti mencari nama di daftar hadir.

Cara kerja: Periksa elemen [0], [1], [2]... sampai ketemu

⏱️ Kompleksitas: O(n) | 💾 Memori: O(1)

✅ Cocok untuk: Data kecil, data tidak terurut

⚡ Binary Search

Membagi data jadi dua terus menerus. Seperti menebak angka dengan "lebih besar/kecil".

Cara kerja: Cek tengah → bagi dua → ulangi

⏱️ Kompleksitas: O(log n) | 💾 Memori: O(1)

✅ Cocok untuk: Data besar yang sudah terurut

🔗 Hash Table Search

Menggunakan fungsi hash untuk langsung menuju lokasi data.

⏱️ Kompleksitas: O(1) rata-rata | 💾 Memori: O(n)

✅ Cocok untuk: Pencarian super cepat, database

🌳 Tree Search (DFS/BFS)

Pencarian dalam struktur pohon atau graf.

⏱️ Kompleksitas: O(V+E) | 💾 Memori: O(V)

✅ Cocok untuk: Struktur hierarki, game AI

📊 Algoritma Pengurutan (Sorting)

🫧 Bubble Sort

Seperti gelembung naik ke atas. Tukar posisi jika tidak urut.

Analogi: Gelembung air naik ke permukaan

⏱️ O(n²) | 💾 O(1) | 😊 Mudah dipahami

🎯 Selection Sort

Pilih yang terkecil, letakkan di depan. Ulangi terus.

Analogi: Memilih pemain terbaik untuk tim

⏱️ O(n²) | 💾 O(1) | 😊 Mudah dipahami

📥 Insertion Sort

Masukkan elemen ke posisi yang tepat satu per satu.

Analogi: Menyusun kartu di tangan

⏱️ O(n²) | 💾 O(1) | 🚀 Cepat untuk data kecil

⚡ Quick Sort

Bagi data jadi kelompok kecil-besar, urutkan masing-masing.

Analogi: Divide and conquer seperti strategi perang

⏱️ O(n log n) rata-rata | 💾 O(log n)

🔀 Merge Sort

Bagi jadi bagian kecil, urutkan, lalu gabungkan kembali.

Analogi: Menggabungkan dua antrian yang sudah terurut

⏱️ O(n log n) stabil | 💾 O(n)

🏔️ Heap Sort

Menggunakan struktur heap untuk mengurutkan data.

Analogi: Turnamen eliminasi untuk mencari juara

⏱️ O(n log n) | 💾 O(1) | 🎯 Konsisten

🌐 Algoritma Graph & Path Finding

🗺️ Dijkstra's Algorithm

Mencari jalur terpendek dari satu titik ke semua titik lain.

Contoh: GPS mencari rute tercepat ke tujuan

⏱️ O((V+E) log V) | Tidak boleh ada edge negatif

🌟 A* (A-Star)

Dijkstra yang lebih pintar dengan heuristic function.

Contoh: AI dalam game untuk mencari jalan

⏱️ Lebih cepat dari Dijkstra | Butuh heuristic yang baik

🔍 Breadth-First Search (BFS)

Jelajahi semua tetangga terdekat dulu sebelum ke level berikutnya.

Contoh: Mencari teman di social network berdasarkan kedekatan

⏱️ O(V+E) | Menjamin jalur terpendek (unweighted)

🕳️ Depth-First Search (DFS)

Jelajahi sedalam mungkin sebelum backtrack.

Contoh: Menyelesaikan maze, mencari cycle dalam graph

⏱️ O(V+E) | Hemat memori, cocok untuk deteksi cycle

🎯 Algoritma Khusus

🔐 Algoritma Kriptografi

RSA, AES untuk enkripsi dan keamanan data.

Contoh: HTTPS, password hashing, blockchain

Keamanan tinggi | Komputasi intensif

🗜️ Algoritma Kompresi

Huffman, LZ77 untuk mengecilkan ukuran file.

Contoh: ZIP, JPEG, MP3, video streaming

Hemat storage | Trade-off kualitas vs ukuran

🤖 Machine Learning

Neural Networks, Decision Trees, SVM untuk AI.

Contoh: Rekomendasi Netflix, face recognition, chatbot

Butuh data besar | Hasil semakin akurat

🎲 Algoritma Randomized

Monte Carlo, Las Vegas menggunakan randomness.

Contoh: Shuffle playlist, sampling data, game mechanics

Cepat untuk masalah kompleks | Hasil probabilistik

🧩 Klasifikasi Berdasarkan Paradigma

🔄 Divide and Conquer

Bagi masalah jadi sub-masalah kecil, selesaikan, gabungkan.

Contoh: Merge Sort, Quick Sort, Binary Search

💰 Greedy Algorithm

Pilih solusi terbaik lokal di setiap langkah.

Contoh: Dijkstra, Huffman Coding, Fractional Knapsack

📊 Dynamic Programming

Simpan hasil sub-masalah untuk menghindari perhitungan ulang.

Contoh: Fibonacci, Knapsack Problem, Longest Common Subsequence

⚡ Kompleksitas Algoritma

⏱️

Bagaimana mengukur seberapa cepat dan efisien algoritma?

🎯 Apa itu Kompleksitas?

Kompleksitas algoritma adalah cara mengukur seberapa banyak waktu dan memori yang dibutuhkan algoritma untuk menyelesaikan masalah.

⏰ Kompleksitas Waktu

Seberapa lama algoritma berjalan?

O(1) - Konstan 🚀

Selalu cepat, tidak peduli data sebanyak apa

O(n) - Linear 📈

Makin banyak data, makin lama

O(n²) - Kuadrat 📊

Sangat lambat untuk data banyak

💾 Kompleksitas Ruang

Seberapa banyak memori yang dibutuhkan?

Sedikit Memori 💚

Hemat, cocok untuk HP dengan RAM kecil

Sedang 💛

Wajar, tidak terlalu boros

Banyak Memori ❤️

Boros, butuh spek tinggi
