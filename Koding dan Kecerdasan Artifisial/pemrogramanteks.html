📚 Pengenalan Pemrograman Berbasis Teks

🤖 Apa itu Pemrograman Berbasis Teks?

Pemrograman berbasis teks adalah metode membuat program komputer dengan menuliskan instruksi-instruksi dalam bentuk teks menggunakan bahasa pemrograman tertentu. Berbeda dengan pemrograman visual yang menggunakan drag-and-drop, pemrograman berbasis teks mengharuskan kita mengetik kode secara manual.

Contoh sederhana:

print("Halo, Dunia!")
print("Selamat datang di dunia pemrograman!")

✅ Kelebihan

  • • Kontrol penuh atas program
  • • Fleksibilitas tinggi
  • • Performa optimal
  • • Mudah di-debug

⚠️ Tantangan

  • • Perlu belajar sintaks
  • • Rawan typo
  • • Butuh logika yang kuat
  • • Waktu development lebih lama

🧠 Konsep Dasar Pemrograman

1. 📝 Algoritma

Algoritma adalah langkah-langkah logis untuk menyelesaikan masalah. Seperti resep masakan!

Contoh: Algoritma Membuat Mie Instan

  1. Siapkan air 400ml
  2. Rebus air hingga mendidih
  3. Masukkan mie ke air mendidih
  4. Masak selama 3 menit
  5. Tambahkan bumbu
  6. Aduk dan sajikan

2. 🔤 Sintaks

Sintaks adalah aturan penulisan dalam bahasa pemrograman. Seperti tata bahasa dalam bahasa Indonesia!

❌ Salah

print "Halo Dunia"  // Kurang tanda kurung
Print("Halo")       // P besar, seharusnya kecil

✅ Benar

print("Halo Dunia")  // Sintaks yang benar
print("Halo")        // p kecil, ada tanda kurung

3. 📦 Variabel

Variabel adalah "kotak" untuk menyimpan data. Seperti loker di sekolah!

nama = "Budi"           // Menyimpan teks
umur = 17               // Menyimpan angka
tinggi = 165.5          // Menyimpan angka desimal
lulus = True            // Menyimpan nilai benar/salah

4. 🔄 Struktur Kontrol

Mengatur alur program: percabangan dan perulangan

🌿 Percabangan (IF)

if umur >= 17:
    print("Boleh punya SIM")
else:
    print("Belum boleh punya SIM")

🔄 Perulangan (FOR)

for i in range(5):
    print("Hitung ke-", i+1)
# Output: Hitung ke-1, 2, 3, 4, 5

5. ⚙️ Fungsi

Fungsi adalah blok kode yang bisa digunakan berulang kali. Seperti rumus matematika!

def sapa(nama):
    return "Halo, " + nama + "!"

# Menggunakan fungsi
pesan1 = sapa("Budi")    # "Halo, Budi!"
pesan2 = sapa("Sari")    # "Halo, Sari!"

🏗️ Struktur Program

🏠 Anatomi Program

Seperti rumah yang memiliki pondasi, dinding, dan atap, program juga memiliki struktur dasar yang harus dipahami.

Contoh Struktur Program Python:

# 1. IMPORT/LIBRARY (Pondasi)
import math
import random

# 2. KONSTANTA (Pengaturan Global)
PI = 3.14159
MAX_SCORE = 100

# 3. FUNGSI (Blok Bangunan)
def hitung_luas_lingkaran(radius):
    return PI * radius * radius

def sapa_user(nama):
    return f"Halo, {nama}! Selamat datang!"

# 4. PROGRAM UTAMA (Isi Rumah)
if __name__ == "__main__":
    print("=== Program Kalkulator Lingkaran ===")
    
    # Input dari user
    nama = input("Masukkan nama Anda: ")
    print(sapa_user(nama))
    
    # Proses perhitungan
    r = float(input("Masukkan radius lingkaran: "))
    luas = hitung_luas_lingkaran(r)
    
    # Output hasil
    print(f"Luas lingkaran dengan radius {r} adalah {luas:.2f}")

🐛 Debugging: Berburu Bug

🤔 Apa itu Bug dan Debugging?

🐛 Bug

Bug adalah kesalahan dalam program yang menyebabkan program tidak berjalan sesuai yang diharapkan.

Contoh Bug:

  • • Program crash/berhenti mendadak
  • • Hasil perhitungan salah
  • • Fitur tidak berfungsi
  • • Program berjalan lambat

🔍 Debugging

Debugging adalah proses mencari, menemukan, dan memperbaiki bug dalam program.

Langkah Debugging:

  1. Identifikasi masalah
  2. Reproduksi bug
  3. Analisis kode
  4. Perbaiki bug
  5. Test ulang

🎮 Demo: Debugging Simulator

Mari coba debug kode yang bermasalah ini:

Kode Bermasalah:

def hitung_rata_rata(numbers):
    total = 0
    for num in numbers:
        total += num
    return total / len(numbers)

# Test
data = [10, 20, 30, 40]
print("Rata-rata:", hitung_rata_rata(data))

# Bug: Apa yang terjadi jika data kosong?
data_kosong = []
print("Rata-rata data kosong:", hitung_rata_rata(data_kosong))

Identifikasi Masalah:

Masalah: Division by zero error ketika list kosong!

Penyebab: len(numbers) = 0, sehingga total / 0 = error

Solusi:

def hitung_rata_rata(numbers):
    if len(numbers) == 0:  # Cek list kosong
        return 0  # atau return None
    
    total = 0
    for num in numbers:
        total += num
    return total / len(numbers)

Soal 2: Analisis Kode (25 poin)

Perhatikan kode Python berikut:

def hitung_nilai_akhir(tugas, uts, uas):
    nilai_tugas = tugas * 0.3
    nilai_uts = uts * 0.3
    nilai_uas = uas * 0.4
    total = nilai_tugas + nilai_uts + nilai_uas
    return total

nama = "Budi"
tugas = 85
uts = 78
uas = 90

hasil = hitung_nilai_akhir(tugas, uts, uas)
print(f"Nilai akhir {nama}: {hasil}")
