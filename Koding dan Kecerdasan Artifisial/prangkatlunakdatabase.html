📚 Pengenalan Database

🌟 Apa itu Database?

Database adalah kumpulan data yang tersimpan secara sistematis dan terorganisir. Bayangkan seperti perpustakaan digital yang sangat rapi!

🔧 Database Management System (DBMS)

DBMS adalah software yang digunakan untuk mengelola database. Seperti pustakawan yang mengatur buku-buku di perpustakaan.

🏗️ Komponen Database

📋
Tabel: Tempat menyimpan data
📊
Field: Kolom dalam tabel
📄
Record: Baris data dalam tabel

💡 Pengertian Database Lebih Dalam

🎯 Definisi Lengkap

Database adalah sekumpulan data yang saling berhubungan dan disimpan secara sistematis dalam komputer sehingga dapat diakses dengan mudah menggunakan software tertentu.

✅ Keuntungan Database

  • • Data tersimpan aman dan terorganisir
  • • Mudah mencari dan mengakses data
  • • Dapat diakses banyak user bersamaan
  • • Menghindari duplikasi data
  • • Backup dan recovery data mudah

⚠️ Tantangan Database

  • • Membutuhkan keahlian khusus
  • • Biaya implementasi tinggi
  • • Perlu maintenance rutin
  • • Risiko keamanan data
  • • Kompleksitas sistem tinggi

🔧 Jenis-Jenis Database Management System

📊 Relational Database (RDBMS)

Database yang menyimpan data dalam bentuk tabel yang saling berhubungan. Seperti Excel yang lebih canggih dan bisa dihubungkan antar sheet.

Contoh:
  • • MySQL
  • • PostgreSQL
  • • Microsoft SQL Server
  • • Oracle Database
Keunggulan:
  • • Struktur data jelas
  • • Konsistensi data terjaga
  • • Mendukung SQL

🌐 NoSQL Database

Database yang tidak menggunakan struktur tabel tradisional. Lebih fleksibel untuk data yang tidak terstruktur.

Contoh:
  • • MongoDB
  • • Redis
  • • Cassandra
  • • Firebase
Keunggulan:
  • • Fleksibel
  • • Performa tinggi
  • • Scalable

☁️ Cloud Database

Database yang disimpan dan dikelola di cloud (internet). Seperti Google Drive tapi untuk database.

Contoh:
  • • Amazon RDS
  • • Google Cloud SQL
  • • Microsoft Azure SQL
  • • Firebase Firestore
Keunggulan:
  • • Akses dari mana saja
  • • Backup otomatis
  • • Maintenance mudah

📝 Tugas Pembelajaran

📋 Soal 1: Analisis Kasus

Sebuah toko online memiliki masalah: data produk tersebar di berbagai file Excel, sering terjadi duplikasi data, dan sulit mencari produk tertentu.

Jelaskan bagaimana database dapat menyelesaikan masalah tersebut dan sebutkan 3 keuntungan utama yang akan didapat!

🔧 Soal 2: Pemilihan DBMS

Kamu diminta membantu sekolah memilih software database untuk sistem informasi siswa. Sekolah memiliki 1000 siswa dan budget terbatas.

Rekomendasikan 2 pilihan DBMS yang cocok beserta alasannya masing-masing!

💡 Soal 3: Desain Database

Buatlah rancangan sederhana untuk database perpustakaan sekolah. Tentukan tabel apa saja yang dibutuhkan dan field-field utama di setiap tabel.

Gambarkan atau jelaskan struktur database perpustakaan dengan minimal 3 tabel!

🎯 Tips Mengerjakan

  • • Baca soal dengan teliti
  • • Gunakan bahasa yang mudah dipahami
  • • Berikan contoh konkret jika memungkinkan
  • • Hubungkan dengan materi yang sudah dipelajari
