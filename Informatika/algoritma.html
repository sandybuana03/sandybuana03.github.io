Pengenalan Algoritma Standar

Mari berkenalan dengan dunia algoritma!

🌟 Apa itu Algoritma?

Bayangkan kamu sedang memasak mie instan. Kamu pasti mengikuti langkah-langkah tertentu: rebus air, masukkan mie, tunggu 3 menit, tambahkan bumbu, aduk, dan sajikan. Nah, rangkaian langkah-langkah sistematis inilah yang disebut algoritma!

Definisi Formal:

Algoritma adalah urutan langkah-langkah logis dan sistematis yang digunakan untuk menyelesaikan suatu masalah atau mencapai tujuan tertentu.

📋

Sistematis

Langkah-langkah tersusun rapi dan berurutan

🎯

Terarah

Memiliki tujuan yang jelas dan spesifik

✅

Terbatas

Memiliki titik awal dan akhir yang jelas

Definisi & Konsep Dasar

Memahami fondasi algoritma standar

🔍 Karakteristik Algoritma yang Baik

✨ Input yang Jelas

Algoritma harus memiliki input yang terdefinisi dengan baik, bisa nol atau lebih.

🎯 Output yang Pasti

Setiap algoritma harus menghasilkan output yang jelas dan dapat diprediksi.

📏 Definiteness (Ketepatan)

Setiap langkah harus jelas, tidak ambigu, dan dapat dipahami dengan pasti.

⏱️ Finiteness (Terbatas)

Algoritma harus berakhir setelah sejumlah langkah yang terbatas.

⚡ Effectiveness (Efektif)

Setiap langkah harus dapat dilaksanakan dan memberikan hasil yang diinginkan.

🌍 Generality (Umum)

Algoritma dapat diterapkan untuk berbagai kasus dalam domain yang sama.

📊 Kompleksitas Algoritma

Kompleksitas algoritma adalah cara untuk mengukur seberapa efisien suatu algoritma. Ada dua jenis kompleksitas utama:

⏰ Kompleksitas Waktu

Mengukur berapa lama waktu yang dibutuhkan algoritma untuk menyelesaikan masalah.

O(1) - Konstan (sangat cepat)

O(log n) - Logaritmik (cepat)

O(n) - Linear (sedang)

O(n²) - Kuadratik (lambat)

💾 Kompleksitas Ruang

Mengukur berapa banyak memori yang dibutuhkan algoritma untuk berjalan.

O(1) - Memori tetap

O(n) - Memori sebanding data

O(n²) - Memori kuadratik

Trade-off: Waktu vs Ruang

🎪 Analogi Sederhana: Mencari Buku di Perpustakaan

🐌 Cara Lambat (O(n))

Cek satu per satu dari rak pertama sampai ketemu bukunya

🚀 Cara Cepat (O(log n))

Gunakan katalog atau sistem pencarian untuk langsung ke lokasi buku

⚡ Cara Instan (O(1))

Sudah tahu persis di mana buku itu berada

Jenis-Jenis Algoritma Standar

Mengenal berbagai kategori algoritma yang sering digunakan

🔄

Algoritma Sorting (Pengurutan)

Algoritma untuk mengurutkan data dari kecil ke besar atau sebaliknya.

Bubble Sort

Membandingkan elemen bersebelahan dan menukarnya jika tidak berurutan

Quick Sort

Membagi data menjadi bagian kecil dan mengurutkannya secara rekursif

Merge Sort

Membagi data menjadi dua bagian, urutkan, lalu gabungkan kembali

🔎

Algoritma Searching (Pencarian)

Algoritma untuk mencari data tertentu dalam kumpulan data.

Linear Search

Mencari satu per satu dari awal hingga data ditemukan

Binary Search

Mencari dengan membagi data menjadi dua bagian berulang kali

Hash Search

Menggunakan fungsi hash untuk akses data yang sangat cepat

🌳 Algoritma Graph dan Tree

🗺️ Pathfinding

Mencari jalur terpendek atau terbaik

  • • Dijkstra's Algorithm
  • • A* Algorithm
  • • Breadth-First Search

🌲 Tree Traversal

Mengunjungi semua node dalam tree

  • • Pre-order Traversal
  • • In-order Traversal
  • • Post-order Traversal

🔗 Graph Analysis

Menganalisis hubungan dalam graph

  • • Depth-First Search
  • • Minimum Spanning Tree
  • • Topological Sort

Implementasi Algoritma

Cara menerapkan algoritma dalam pemrograman

📝 Langkah-langkah Implementasi

1️⃣

Analisis Masalah

Pahami masalah yang akan diselesaikan dengan detail

2️⃣

Desain Algoritma

Buat pseudocode atau flowchart algoritma

3️⃣

Coding

Implementasikan algoritma dalam bahasa pemrograman

4️⃣

Testing

Uji algoritma dengan berbagai kasus test

💻 Contoh Implementasi: Binary Search

📋 Pseudocode

FUNCTION binarySearch(array, target):

left = 0

right = length(array) - 1

WHILE left ≤ right:

mid = (left + right) / 2

IF array[mid] = target:

RETURN mid

ELSE IF array[mid] < target:

left = mid + 1

ELSE:

right = mid - 1

RETURN -1

🔍 Cara Kerja

Step 1: Tentukan batas kiri dan kanan array

Step 2: Hitung posisi tengah

Step 3: Bandingkan dengan target

Step 4: Perkecil area pencarian

Step 5: Ulangi sampai ketemu

📋 Yang harus disertakan:

  • ✅ Input yang diperlukan
