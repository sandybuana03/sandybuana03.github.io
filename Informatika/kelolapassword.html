Pengenalan Kata Sandi

Mari berkenalan dengan dunia password dan keamanan digital!

🔑 Apa itu Kata Sandi?

Kata sandi atau password adalah kombinasi karakter (huruf, angka, simbol) yang digunakan untuk memverifikasi identitas pengguna saat mengakses sistem, aplikasi, atau layanan digital.

Contoh: Saat kamu login Instagram, WhatsApp, atau email, kamu memasukkan username dan password untuk membuktikan bahwa kamu adalah pemilik akun tersebut.

Jenis Ancaman Password

Kenali musuh-musuh password kamu!

🔨 Brute Force Attack

Hacker menggunakan program komputer untuk mencoba semua kombinasi password secara otomatis sampai menemukan yang benar.

Contoh:

Program mencoba: a, b, c, ..., aa, ab, ac, ..., 123, 124, 125...

⏱️ Waktu untuk Membobol:

Password 4 karakter: 37 detik
Password 6 karakter: 2 hari
Password 8 karakter: 200 tahun

📚 Dictionary Attack

Hacker menggunakan daftar password yang paling sering digunakan orang, seperti "password", "123456", nama, tanggal lahir.

🎯 Target Favorit:

123456 password qwerty admin sayang indonesia

🎣 Phishing

Hacker membuat website palsu yang mirip dengan website asli untuk mencuri username dan password kamu.

Contoh:

Email palsu dari "Instagram" yang meminta kamu login di link mencurigakan

🚨 Tanda-tanda Phishing:

  • • URL aneh (bukan domain resmi)
  • • Desain website tidak rapi
  • • Meminta data sensitif
  • • Bahasa tidak baku
  • • Terburu-buru/mengancam

👥 Social Engineering

Hacker memanipulasi psikologi manusia untuk mendapatkan informasi password, bukan menggunakan teknologi.

📞

Telepon Palsu

Menyamar sebagai customer service

👫

Teman Palsu

Berpura-pura kenal untuk dapat info

🎁

Hadiah Palsu

Menawarkan hadiah untuk dapat data

Membuat Password Kuat

Belajar membuat password yang tidak bisa ditembus hacker!

✅ Kriteria Password Kuat

📏

Minimal 12 Karakter

Semakin panjang, semakin sulit ditebak

🔤

Huruf Besar & Kecil

Kombinasi A-Z dan a-z

🔢

Angka

Tambahkan angka 0-9

🔣

Simbol Khusus

Gunakan !@#$%^&*

🎯 Teknik Membuat Password

1. Metode Kalimat (Passphrase)

Buat kalimat yang mudah diingat, lalu modifikasi:

Kalimat: "Saya suka makan bakso 3 kali seminggu!"

Password: SayaSukaMakanBakso3KaliSeminggu!

2. Metode Akronim

Ambil huruf pertama dari setiap kata:

Kalimat: "Aku Lahir Tanggal 15 Agustus 2005 Di Jakarta"

Password: ALT15A2005DJ

3. Metode Substitusi

Ganti huruf dengan angka atau simbol:

Kata: "SekolahKu"

Substitusi: S3k0l4hKu! (e→3, o→0, a→4)

🧪 Simulasi: Password Checker

Kekuatan:
-
❌ Minimal 12 karakter
❌ Huruf besar (A-Z)
❌ Huruf kecil (a-z)
❌ Angka (0-9)
❌ Simbol (!@#$%^&*)

❌ Yang Harus Dihindari

📅 Tanggal lahir atau tahun lahir
👤 Nama lengkap atau nama panggilan
📱 Nomor telepon
🔢 Urutan angka (123456)
⌨️ Pola keyboard (qwerty)
❤️ Kata umum (sayang, cinta)

Password Manager

Solusi cerdas untuk mengelola semua password kamu!

🤔 Apa itu Password Manager?

Password Manager adalah aplikasi yang menyimpan, mengelola, dan mengamankan semua password kamu dalam satu tempat yang terenkripsi.

Analogi Sederhana:

Seperti brankas digital yang menyimpan semua kunci rumah, mobil, dan lemari kamu. Kamu hanya perlu ingat 1 kunci utama untuk membuka brankas.

🔑 Cara Kerja:

1 Buat 1 Master Password yang kuat
2 Simpan semua password lain di aplikasi
3 Aplikasi otomatis isi password saat login

Two-Factor Authentication

Keamanan berlapis untuk perlindungan maksimal!

🤔 Apa itu 2FA?

Two-Factor Authentication (2FA) adalah sistem keamanan yang membutuhkan DUA cara verifikasi untuk login ke akun kamu.

Analogi Sederhana:

Seperti ATM yang butuh kartu DAN PIN. Meskipun kartu hilang, uang tetap aman karena pencuri tidak tahu PIN.

🔐 Dua Faktor:

1

Something You Know

Password, PIN

2

Something You Have

HP, Email, Aplikasi

📱 Jenis-jenis 2FA

💬

SMS

Kode verifikasi dikirim via SMS ke HP kamu

✓ Mudah digunakan
✗ Bisa di-intercept
📧

Email

Kode verifikasi dikirim ke email kamu

✓ Gratis
✗ Lambat
📲

Authenticator App

Kode dari aplikasi khusus (Google Authenticator)

✓ Paling aman
✓ Offline

📋 Cara Mengaktifkan 2FA

Instagram:

Settings → Security → Two-Factor Authentication → Get Started

WhatsApp:

Settings → Account → Two-Step Verification → Enable

Gmail:

Google Account → Security → 2-Step Verification → Get Started

Facebook:

Settings → Security and Login → Two-Factor Authentication → Edit
