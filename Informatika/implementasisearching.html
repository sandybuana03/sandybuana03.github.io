Algoritma Pencarian

Mari belajar cara mencari data dengan efisien!

🎯

Apa itu Algoritma Pencarian?

Algoritma pencarian adalah cara sistematis untuk menemukan data tertentu dalam kumpulan data.

⚡

Mengapa Penting?

Dalam dunia programming, kita sering perlu mencari data. Algoritma yang tepat membuat pencarian lebih cepat!

📋 Jenis-jenis Algoritma Pencarian

🔍 Linear Search

Mencari satu per satu dari awal sampai akhir

⚡ Binary Search

Mencari dengan membagi data menjadi dua bagian

🔍

Linear Search

Pencarian sederhana dari awal sampai akhir

💡 Konsep Linear Search

Linear Search adalah algoritma pencarian paling sederhana. Bayangkan kamu mencari buku di rak, kamu akan melihat satu per satu dari kiri ke kanan sampai ketemu!

🎮 Demo Interaktif

Coba cari angka dalam array: [5, 2, 8, 1, 9, 3]

📝 Langkah-langkah Linear Search

  1. Mulai dari elemen pertama (index 0)
  2. Bandingkan elemen saat ini dengan data yang dicari
  3. Jika sama, return index (posisi ditemukan)
  4. Jika tidak sama, lanjut ke elemen berikutnya
  5. Ulangi sampai data ditemukan atau sampai akhir array
  6. Jika sampai akhir tidak ketemu, return -1 (tidak ditemukan)

💻 Implementasi dalam Python

📄 linear_search.py
def linear_search(arr, target): """ Function untuk melakukan linear search arr: list data yang akan dicari target: data yang dicari return: index jika ditemukan, -1 jika tidak ditemukan """ # Loop melalui setiap elemen dalam list for i in range(len(arr)): # Jika elemen saat ini sama dengan target if arr[i] == target: return i # Return index dimana data ditemukan return -1 # Return -1 jika data tidak ditemukan # Program utama if __name__ == "__main__": # Contoh list data data = [5, 2, 8, 1, 9, 3] cari = 8 # Panggil function linear_search hasil = linear_search(data, cari) # Tampilkan hasil if hasil != -1: print(f"Data {cari} ditemukan di index {hasil}") else: print(f"Data {cari} tidak ditemukan")

⏱️ Kompleksitas Waktu

Best Case: O(1) - Data ditemukan di posisi pertama

Average Case: O(n) - Rata-rata memeriksa setengah elemen

Worst Case: O(n) - Data ditemukan di akhir atau tidak ada

⚡

Binary Search

Pencarian super cepat dengan teknik divide and conquer!

💡 Konsep Binary Search

Binary Search seperti bermain tebak angka! Kamu tebak di tengah, lalu eliminasi setengah kemungkinan. Syarat penting: Data harus sudah terurut dari kecil ke besar atau sebaliknya!

⚠️ Peringatan: Binary Search hanya bekerja pada data yang sudah diurutkan!

Jika data belum terurut, hasil pencarian akan salah.

🎮 Demo Interaktif

Coba cari angka dalam array terurut: [1, 2, 3, 5, 8, 9]

📝 Langkah-langkah Binary Search

  1. Tentukan batas kiri (left = 0) dan kanan (right = length-1)
  2. Hitung posisi tengah: mid = (left + right) / 2
  3. Bandingkan elemen tengah dengan data yang dicari
  4. Jika sama, return mid (ditemukan!)
  5. Jika data lebih kecil, cari di bagian kiri (right = mid - 1)
  6. Jika data lebih besar, cari di bagian kanan (left = mid + 1)
  7. Ulangi sampai ditemukan atau left > right

💻 Implementasi dalam Python

📄 binary_search.py
def binary_search(arr, target): """ Function untuk melakukan binary search arr: list data yang sudah terurut target: data yang dicari return: index jika ditemukan, -1 jika tidak ditemukan """ left = 0 # Batas kiri right = len(arr) - 1 # Batas kanan # Loop selama masih ada area pencarian while left <= right: mid = left + (right - left) // 2 # Hitung posisi tengah (hindari overflow) # Jika elemen tengah sama dengan target if arr[mid] == target: return mid # Data ditemukan di posisi mid # Jika target lebih kecil, cari di bagian kiri elif arr[mid] > target: right = mid - 1 # Jika target lebih besar, cari di bagian kanan else: left = mid + 1 return -1 # Data tidak ditemukan # Program utama if __name__ == "__main__": # List harus sudah terurut untuk binary search! data = [1, 2, 3, 5, 8, 9, 12, 15, 18, 20] cari = 8 # Panggil function binary_search hasil = binary_search(data, cari) # Tampilkan hasil if hasil != -1: print(f"Data {cari} ditemukan di index {hasil}") else: print(f"Data {cari} tidak ditemukan")

⏱️ Kompleksitas Waktu

Best Case: O(1) - Data ditemukan di tengah

Average Case: O(log n) - Sangat efisien!

Worst Case: O(log n) - Tetap cepat!

💡 Tips: Binary Search 1000x lebih cepat dari Linear Search untuk data besar!

🤔 Kapan Menggunakan Algoritma Mana?

🔍 Gunakan Linear Search jika:

  • Data belum terurut
  • Data berukuran kecil (< 100 elemen)
  • Mencari berdasarkan string/teks
  • Perlu pencarian fleksibel (sebagian kata)

⚡ Gunakan Binary Search jika:

  • Data sudah terurut
  • Data berukuran besar (> 1000 elemen)
  • Mencari berdasarkan angka/ID
  • Perlu pencarian yang sangat cepat

Studi Kasus

Aplikasi nyata algoritma pencarian dalam sistem perpustakaan

📚 Kasus: Sistem Pencarian Buku Perpustakaan

Kita akan membuat sistem pencarian buku di perpustakaan yang bisa mencari berdasarkan:

  • 🔢 Nomor ID Buku (menggunakan Binary Search)
  • 📖 Judul Buku (menggunakan Linear Search)
  • 👤 Nama Pengarang (menggunakan Linear Search)

🏗️ Langkah 1: Buat Class Buku

📄 buku.py
class Buku: """Class untuk merepresentasikan data buku""" def __init__(self, id, judul, pengarang, tahun): """ Constructor untuk membuat objek Buku id: nomor ID buku (integer) judul: judul buku (string) pengarang: nama pengarang (string) tahun: tahun terbit (integer) """ self.id = id self.judul = judul self.pengarang = pengarang self.tahun = tahun # Getter methods (properties) def get_id(self): return self.id def get_judul(self): return self.judul def get_pengarang(self): return self.pengarang def get_tahun(self): return self.tahun def tampilkan_info(self): """Method untuk menampilkan informasi buku""" print(f"📖 ID: {self.id} | Judul: {self.judul} | Pengarang: {self.pengarang} | Tahun: {self.tahun}")

🔍 Langkah 2: Buat Class Sistem Perpustakaan

📄 sistem_perpustakaan.py
from buku import Buku class SistemPerpustakaan: """Class untuk mengelola sistem perpustakaan""" def __init__(self, kapasitas): """ Constructor untuk sistem perpustakaan kapasitas: maksimal jumlah buku yang bisa disimpan """ self.daftar_buku = [] self.kapasitas = kapasitas def tambah_buku(self, buku): """Method untuk menambah buku ke perpustakaan""" if len(self.daftar_buku) < self.kapasitas: self.daftar_buku.append(buku) print("✅ Buku berhasil ditambahkan!") else: print("❌ Perpustakaan sudah penuh!") def cari_berdasarkan_id(self, id): """Binary Search berdasarkan ID (data harus terurut)""" print(f"🔍 Mencari buku dengan ID: {id}") print("⚡ Menggunakan Binary Search...") # Urutkan list berdasarkan ID terlebih dahulu (syarat binary search) self.daftar_buku.sort(key=lambda buku: buku.get_id()) left = 0 right = len(self.daftar_buku) - 1 step = 1 while left <= right: mid = left + (right - left) // 2 print(f"Step {step}: Memeriksa ID {self.daftar_buku[mid].get_id()} di index {mid}") if self.daftar_buku[mid].get_id() == id: print("✅ Buku ditemukan!") return self.daftar_buku[mid] if self.daftar_buku[mid].get_id() > id: print("ID target lebih kecil, cari di bagian kiri") right = mid - 1 else: print("ID target lebih besar, cari di bagian kanan") left = mid + 1 step += 1 print("❌ Buku tidak ditemukan") return None def cari_berdasarkan_judul(self, judul): """Linear Search berdasarkan judul""" print(f"🔍 Mencari buku dengan judul: {judul}") print("🔍 Menggunakan Linear Search...") for i, buku in enumerate(self.daftar_buku): print(f"Memeriksa: {buku.get_judul()}") if buku.get_judul().lower() == judul.lower(): print("✅ Buku ditemukan!") return buku print("❌ Buku tidak ditemukan") return None def cari_berdasarkan_pengarang(self, pengarang): """Linear Search berdasarkan pengarang""" print(f"🔍 Mencari buku karya: {pengarang}") print("🔍 Menggunakan Linear Search...") ditemukan = False for buku in self.daftar_buku: if buku.get_pengarang().lower() == pengarang.lower(): if not ditemukan: print("✅ Buku-buku ditemukan:") ditemukan = True buku.tampilkan_info() if not ditemukan: print("❌ Tidak ada buku dari pengarang tersebut") def tampilkan_semua_buku(self): """Method untuk menampilkan semua buku""" print("\n📚 DAFTAR SEMUA BUKU:") print("=" * 50) if len(self.daftar_buku) == 0: print("Perpustakaan masih kosong") return for buku in self.daftar_buku: buku.tampilkan_info()

start_time) * 1000000000 print(f"⏱️ Waktu: {duration:.0f} ns") elif pilihan == 2: judul = input("Masukkan judul buku: ") start_time = time.time() buku_by_judul = perpus.cari_berdasarkan_judul(judul) end_time = time.time() if buku_by_judul is not None: buku_by_judul.tampilkan_info() duration = (end_time - start_time) * 1000000000 print(f"⏱️ Waktu: {duration:.0f} ns") elif pilihan == 3: pengarang = input("Masukkan nama pengarang: ") start_time = time.time() perpus.cari_berdasarkan_pengarang(pengarang) end_time = time.time() duration = (end_time - start_time) * 1000000000 print(f"⏱️ Waktu: {duration:.0f} ns") elif pilihan == 4: perpus.tampilkan_semua_buku() elif pilihan == 5: new_id = int(input("ID buku: ")) new_judul = input("Judul: ") new_pengarang = input("Pengarang: ") new_tahun = int(input("Tahun: ")) perpus.tambah_buku(Buku(new_id, new_judul, new_pengarang, new_tahun)) elif pilihan == 6: print("👋 Terima kasih telah menggunakan sistem perpustakaan!") break else: print("❌ Pilihan tidak valid!") except ValueError: print("❌ Masukkan angka yang valid!") except KeyboardInterrupt: print("\n👋 Program dihentikan oleh user.") break except Exception as e: print(f"❌ Terjadi kesalahan: {e}") # Jalankan program utama if __name__ == "__main__": main()
