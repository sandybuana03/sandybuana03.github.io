Apa itu Algoritma Pencarian?

Algoritma Pencarian adalah cara sistematis untuk menemukan data tertentu dalam kumpulan data. Bayangkan kamu sedang mencari buku favorit di perpustakaan yang besar - kamu butuh strategi yang tepat!

Mengapa Penting?

  • Menghemat waktu dalam mencari data
  • Dasar untuk aplikasi database dan search engine
  • Skill fundamental untuk programmer

Linear Search

Mencari satu per satu dari awal sampai akhir. Sederhana tapi bisa lambat untuk data besar.

Time: O(n) | Space: O(1)

Binary Search

Membagi data menjadi dua bagian berulang kali. Cepat tapi butuh data yang sudah terurut.

Time: O(log n) | Space: O(1)

Linear Search 🔍

Pencarian berurutan dari awal sampai akhir

Konsep Dasar

Linear Search adalah algoritma pencarian paling sederhana. Kita memeriksa setiap elemen dalam array satu per satu sampai menemukan yang dicari.

Analogi & Contoh Nyata

Analogi: Seperti mencari kunci di dalam tas. Kamu mengeluarkan barang satu per satu sampai ketemu kunci yang dicari!

Aplikasi nyata: Mencari nama di daftar kontak HP, mencari file di folder yang tidak terurut, atau mencari produk di toko online tanpa filter.

1 Langkah-langkah Linear Search

  1. Mulai dari elemen pertama (indeks 0)
  2. Bandingkan dengan nilai yang dicari
  3. Jika sama, return indeks tersebut
  4. Jika tidak, lanjut ke elemen berikutnya
  5. Ulangi sampai ketemu atau sampai akhir array
linear_search.py 
def linear_search(arr, target):
    """
    Fungsi untuk melakukan pencarian linear
    arr: list yang akan dicari
    target: nilai yang dicari
    return: indeks jika ditemukan, -1 jika tidak
    """
    # Validasi input
    if not arr:
        return -1  # Array kosong
    
    for i in range(len(arr)):
        if arr[i] == target:
            return i  # Ditemukan! Return indeks
    return -1  # Tidak ditemukan

# Contoh penggunaan
data = [64, 34, 25, 12, 22, 11, 90]
cari = 25

hasil = linear_search(data, cari)
if hasil != -1:
    print(f"Nilai {cari} ditemukan di indeks {hasil}")
else:
    print(f"Nilai {cari} tidak ditemukan")

Kompleksitas Waktu Linear Search

O(1)
Best Case
Data di posisi pertama
O(n/2)
Average Case
Data di tengah rata-rata
O(n)
Worst Case
Data di akhir/tidak ada

Penjelasan: n adalah jumlah elemen dalam array. Dalam kasus terburuk, kita harus memeriksa semua n elemen.

Binary Search ⚡

Pencarian cepat dengan teknik divide and conquer

Konsep Dasar

Binary Search adalah algoritma pencarian yang sangat efisien untuk data yang sudah terurut. Prinsipnya adalah membagi data menjadi dua bagian dan memilih bagian yang mungkin berisi data yang dicari.

Analogi & Contoh Nyata

Analogi: Seperti menebak angka 1-100. Kamu mulai dari 50. Jika terlalu besar, coba 25. Jika terlalu kecil, coba 75. Terus bagi dua sampai ketemu!

Aplikasi nyata: Mencari kata di kamus, sistem pencarian Google, database bank, atau mencari lagu di Spotify (yang sudah diurutkan alfabetis).

Syarat Penting!

Binary Search hanya bisa digunakan pada data yang sudah terurut (ascending atau descending).

1 Langkah-langkah Binary Search

  1. Tentukan batas kiri (left) dan kanan (right)
  2. Hitung posisi tengah: mid = (left + right) / 2
  3. Bandingkan arr[mid] dengan target
  4. Jika sama, return mid
  5. Jika arr[mid] > target, cari di bagian kiri (right = mid - 1)
  6. Jika arr[mid] < target, cari di bagian kanan (left = mid + 1)
  7. Ulangi sampai ketemu atau left > right
binary_search.py 
def binary_search(arr, target):
    """
    Fungsi untuk melakukan pencarian binary
    arr: list yang sudah terurut
    target: nilai yang dicari
    return: indeks jika ditemukan, -1 jika tidak
    """
    # Validasi input
    if not arr:
        return -1  # Array kosong
    
    left = 0
    right = len(arr) - 1
    
    while left <= right:
        mid = (left + right) // 2
        
        if arr[mid] == target:
            return mid  # Ditemukan!
        elif arr[mid] > target:
            right = mid - 1  # Cari di bagian kiri
        else:
            left = mid + 1   # Cari di bagian kanan
    
    return -1  # Tidak ditemukan

# Contoh penggunaan
data = [11, 12, 22, 25, 34, 64, 90]  # Harus terurut!
cari = 25

hasil = binary_search(data, cari)
if hasil != -1:
    print(f"Nilai {cari} ditemukan di indeks {hasil}")
else:
    print(f"Nilai {cari} tidak ditemukan")

Kompleksitas Waktu Binary Search

O(1)
Best Case
Data di posisi tengah pertama
O(log n)
Average Case
Rata-rata log₂(n) langkah
O(log n)
Worst Case
Maksimal log₂(n) langkah

Penjelasan: log₂(n) artinya berapa kali kita bisa membagi n dengan 2 sampai jadi 1. Contoh: untuk 1000 data, maksimal butuh log₂(1000) ≈ 10 langkah saja!

Fungsi Linear Search 
def linear_search(data_list, target):
    """
    Fungsi untuk melakukan pencarian linear
    
    Parameter:
    - data_list: list berisi data yang akan dicari
    - target: nilai yang ingin dicari
    
    Return:
    - indeks jika ditemukan
    - -1 jika tidak ditemukan
    """
    print(f"🔍 Mencari nilai: {target}")
    print(f"📊 Data: {data_list}")
    print("=" * 40)
    
    # Loop untuk memeriksa setiap elemen
    for i in range(len(data_list)):
        print(f"Langkah {i+1}: Memeriksa indeks {i} = {data_list[i]}")
        
        # Bandingkan dengan target
        if data_list[i] == target:
            print(f"✅ DITEMUKAN! Nilai {target} ada di indeks {i}")
            return i
        else:
            print(f"❌ Tidak sama, lanjut ke elemen berikutnya...")
    
    # Jika sampai sini, berarti tidak ditemukan
    print(f"❌ Nilai {target} tidak ditemukan dalam data")
    return -1

def binary_search(data_list, target):
    """
    Fungsi untuk melakukan pencarian binary
    
    Parameter:
    - data_list: list berisi data yang sudah terurut
    - target: nilai yang ingin dicari
    
    Return:
    - indeks jika ditemukan
    - -1 jika tidak ditemukan
    """
    print(f"🔍 Mencari nilai: {target}")
    print(f"📊 Data terurut: {data_list}")
    print("=" * 50)
    
    left = 0
    right = len(data_list) - 1
    langkah = 1
    
    while left <= right:
        mid = (left + right) // 2
        
        print(f"\n🔄 Langkah {langkah}:")
        print(f"   Left: {left}, Right: {right}, Mid: {mid}")
        print(f"   Nilai di mid ({mid}): {data_list[mid]}")
        
        if data_list[mid] == target:
            print(f"✅ DITEMUKAN! Nilai {target} ada di indeks {mid}")
            return mid
        elif data_list[mid] > target:
            print(f"   {data_list[mid]} > {target}, cari di bagian KIRI")
            right = mid - 1
        else:
            print(f"   {data_list[mid]} < {target}, cari di bagian KANAN")
            left = mid + 1
        
        langkah += 1
    
    print(f"\n❌ Nilai {target} tidak ditemukan dalam data")
    return -1

def urutkan_data(data):
    """
    Fungsi untuk mengurutkan data menggunakan built-in sort

    data_asli = data.copy()

    print(f"   Data terurut: {data}")
    print("✅ Data berhasil diurutkan!")
    
    return data

✅ Kelebihan

  • • Efisien dalam penggunaan memori

Perbandingan & Analisis 📊

Linear Search vs Binary Search

Linear Search

✅ Kelebihan

  • • Sederhana dan mudah dipahami
  • • Tidak perlu data terurut
  • • Cocok untuk data kecil
  • • Implementasi mudah

❌ Kekurangan

  • • Lambat untuk data besar
  • • Kompleksitas O(n)
  • • Tidak efisien

🎯 Kapan Digunakan

  • • Data tidak terurut
  • • Jumlah data sedikit (< 100)
  • • Implementasi cepat

Binary Search

✅ Kelebihan

  • • Sangat cepat O(log n)
  • • Efisien untuk data besar
  • • Menghemat waktu
  • • Algoritma optimal

❌ Kekurangan

  • • Butuh data terurut
  • • Lebih kompleks
  • • Overhead sorting

🎯 Kapan Digunakan

  • • Data sudah terurut
  • • Jumlah data besar (> 1000)
  • • Pencarian berulang

Catatan: Perhitungan berdasarkan worst case scenario (data di posisi terakhir atau tidak ada)

Kesimpulan & Tips

Pilih Linear Search Jika:

  • Data tidak terurut dan sulit diurutkan
  • Jumlah data sedikit (< 100)
  • Butuh implementasi cepat
  • Data sering berubah/ditambah

Pilih Binary Search Jika:

  • Data sudah terurut atau bisa diurutkan
  • Jumlah data besar (> 1000)
  • Pencarian dilakukan berulang kali
  • Kecepatan adalah prioritas
