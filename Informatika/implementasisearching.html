📚 Pengenalan Algoritma Pencarian

🤖 Apa itu Algoritma Pencarian?

Algoritma pencarian adalah langkah-langkah sistematis untuk menemukan data tertentu dalam kumpulan data. Seperti mencari nama di buku telepon atau mencari lagu favorit di playlist!

"Pencarian yang efisien = Waktu yang dihemat = Produktivitas yang meningkat!"

🎯 Mengapa Penting?

  • • Menghemat waktu pencarian
  • • Meningkatkan performa aplikasi
  • • Dasar untuk sistem database
  • • Fundamental dalam programming

🌟 Contoh Penggunaan

  • • Pencarian di Google
  • • Mencari kontak di HP
  • • Filter produk di e-commerce
  • • Pencarian file di komputer

📊 Jenis-jenis Algoritma Pencarian

🔄 Pencarian Sekuensial

Mencari satu per satu dari awal hingga akhir

⚡ Pencarian Biner

Membagi data menjadi dua bagian berulang kali

🔄 Pencarian Sekuensial (Linear Search)

🎯 Konsep Dasar

Pencarian sekuensial adalah metode pencarian yang paling sederhana. Kita memeriksa setiap elemen data satu per satu dari awal hingga menemukan data yang dicari atau sampai akhir data.

Analogi: Seperti mencari kunci yang hilang dengan memeriksa setiap saku baju satu per satu!

🔍 Demo Interaktif

Coba cari angka dalam array berikut:

✅ Kelebihan

  • • Sederhana dan mudah dipahami
  • • Tidak perlu data terurut
  • • Cocok untuk data kecil
  • • Implementasi mudah

❌ Kekurangan

  • • Lambat untuk data besar
  • • Kompleksitas waktu O(n)
  • • Tidak efisien
  • • Boros waktu

📝 Langkah-langkah Algoritma

  1. 1. Mulai dari elemen pertama (indeks 0)
  2. 2. Bandingkan elemen saat ini dengan data yang dicari
  3. 3. Jika sama, data ditemukan! Kembalikan posisinya
  4. 4. Jika tidak sama, lanjut ke elemen berikutnya
  5. 5. Ulangi langkah 2-4 sampai data ditemukan atau sampai akhir array
  6. 6. Jika sampai akhir tidak ditemukan, kembalikan "tidak ditemukan"

⚡ Pencarian Biner (Binary Search)

🎯 Konsep Dasar

Pencarian biner adalah algoritma pencarian yang sangat efisien untuk data yang sudah terurut. Algoritma ini bekerja dengan membagi data menjadi dua bagian dan memilih bagian yang mungkin berisi data yang dicari.

Analogi: Seperti mencari kata dalam kamus! Kamu tidak mulai dari halaman 1, tapi langsung ke tengah dan memutuskan apakah kata yang dicari ada di bagian kiri atau kanan.

⚠️ Syarat Penting

📊 Data HARUS sudah terurut (ascending/descending) 📊

🔍 Demo Interaktif

Coba cari angka dalam array terurut berikut:

✅ Kelebihan

  • • Sangat cepat dan efisien
  • • Kompleksitas waktu O(log n)
  • • Cocok untuk data besar
  • • Menghemat waktu signifikan

❌ Kekurangan

  • • Data harus terurut dulu
  • • Lebih kompleks implementasinya
  • • Perlu pemahaman rekursi
  • • Tidak cocok untuk data kecil

📝 Langkah-langkah Algoritma

  1. 1. Tentukan batas kiri (left) = 0 dan batas kanan (right) = panjang array - 1
  2. 2. Hitung posisi tengah (mid) = (left + right) / 2
  3. 3. Bandingkan elemen tengah dengan data yang dicari:
  4. • Jika sama → data ditemukan!
  5. • Jika data yang dicari lebih kecil → cari di bagian kiri (right = mid - 1)
  6. • Jika data yang dicari lebih besar → cari di bagian kanan (left = mid + 1)
  7. 4. Ulangi langkah 2-3 sampai data ditemukan atau left > right

💡 Kapan Menggunakan Masing-masing?

🔄 Gunakan Pencarian Sekuensial jika:

  • • Data tidak terurut
  • • Jumlah data sedikit (< 100)
  • • Implementasi harus sederhana
  • • Tidak ada waktu untuk mengurutkan data

⚡ Gunakan Pencarian Biner jika:

  • • Data sudah terurut
  • • Jumlah data banyak (> 100)
  • • Kecepatan pencarian penting
  • • Sering melakukan pencarian

📝 Tugas Pembelajaran

📋 Soal 1: Analisis Kasus

Kamu diminta membuat sistem pencarian untuk perpustakaan sekolah yang memiliki 10.000 buku. Data buku disimpan dalam array berdasarkan nomor ISBN yang sudah terurut.

Pertanyaan:

  1. a) Algoritma pencarian mana yang lebih cocok? Jelaskan alasanmu!
  2. b) Berapa maksimal langkah pencarian yang diperlukan dengan algoritma pilihanmu?
  3. c) Apa keuntungan dan kerugian pilihan algoritma tersebut?

🔍 Soal 2: Implementasi Sederhana

Diberikan array: [2, 5, 8, 12, 16, 23, 38, 45, 56, 67, 78]

Tugas:

  1. a) Tuliskan langkah-langkah pencarian biner untuk mencari angka 23
  2. b) Tuliskan langkah-langkah pencarian sekuensial untuk mencari angka 23
  3. c) Bandingkan jumlah langkah yang diperlukan kedua algoritma

💭 Soal 3: Studi Kasus

Sebuah aplikasi e-commerce memiliki fitur pencarian produk. Mereka memiliki 1 juta produk yang datanya tidak terurut dan sering berubah (ada produk baru, produk dihapus).

Analisis:

  1. a) Algoritma pencarian mana yang lebih cocok untuk kasus ini?
  2. b) Apa tantangan yang dihadapi jika menggunakan pencarian biner?
  3. c) Bagaimana solusi yang bisa diterapkan untuk meningkatkan performa pencarian?

🎯 Soal 4: Optimasi

Kamu memiliki data nilai ujian 500 siswa yang tersimpan dalam array tidak terurut. Kamu sering diminta mencari nilai tertentu untuk keperluan ranking.

Rancang solusi:

  1. a) Strategi apa yang akan kamu gunakan untuk optimasi pencarian?
  2. b) Kapan waktu terbaik untuk mengurutkan data?
  3. c) Bagaimana cara menangani jika ada nilai baru yang ditambahkan?

📊 Soal 5: Pilihan Algoritma

Pilih algoritma yang tepat untuk setiap situasi berikut:

Situasi A:

Mencari nomor HP teman di daftar kontak yang berisi 50 nama (tidak terurut)

Pilihan: Pencarian Sekuensial / Pencarian Biner

Situasi B:

Mencari kata dalam kamus yang berisi 10.000 kata (sudah terurut alfabetis)

Pilihan: Pencarian Sekuensial / Pencarian Biner

Situasi C:

Mencari produk di toko online dengan 1000 produk (data sering berubah, tidak terurut)

Pilihan: Pencarian Sekuensial / Pencarian Biner

Situasi D:

Mencari data siswa berdasarkan NIS di database sekolah (5000 siswa, terurut berdasarkan NIS)

Pilihan: Pencarian Sekuensial / Pencarian Biner

Petunjuk: Pertimbangkan apakah data terurut, jumlah data, dan seberapa sering pencarian dilakukan.
