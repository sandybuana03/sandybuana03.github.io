📚 Pengenalan Algoritma Pencarian

🤖 Apa itu Algoritma Pencarian?

Algoritma pencarian adalah langkah-langkah sistematis untuk menemukan data tertentu dalam kumpulan data. Seperti mencari buku di perpustakaan atau mencari kontak di HP!

Contoh dalam Kehidupan Sehari-hari:

📱 Mencari kontak di HP

🛒 Mencari produk di e-commerce

🎯

📈

Skalabilitas

🔢 Jenis-jenis Algoritma Pencarian

🔄

Pencarian Sekuensial (Linear Search)

Mencari satu per satu dari awal hingga akhir

⚡

Pencarian Biner (Binary Search)

Membagi data menjadi dua bagian berulang kali

🔄 Pencarian Sekuensial

📖 Apa itu Pencarian Sekuensial?

Pencarian sekuensial adalah metode pencarian yang memeriksa setiap elemen dalam data satu per satu, mulai dari awal hingga menemukan data yang dicari atau sampai akhir data.

🎯 Analogi Sederhana:

Seperti mencari kunci di dalam tas dengan mengeluarkan barang satu per satu sampai ketemu!

🔍 Demo Interaktif

Array: [12, 45, 23, 67, 89, 34, 56, 78, 90, 11]

⚙️ Cara Kerja

1

Mulai dari elemen pertama

Periksa elemen di posisi index 0

2

Bandingkan dengan data yang dicari

Jika sama, pencarian selesai. Jika tidak, lanjut ke elemen berikutnya

3

Ulangi sampai ketemu atau habis

Terus periksa elemen berikutnya sampai data ditemukan atau array habis

✅ Kelebihan

  • • Sederhana dan mudah dipahami
  • • Bisa digunakan pada data yang tidak terurut
  • • Tidak memerlukan memori tambahan

❌ Kekurangan

  • • Lambat untuk data yang besar
  • • Kompleksitas waktu O(n)
  • • Tidak efisien untuk pencarian berulang

⚡ Pencarian Biner

📖 Apa itu Pencarian Biner?

Pencarian biner adalah metode pencarian yang membagi data menjadi dua bagian secara berulang. Data harus sudah terurut terlebih dahulu!

🎯 Analogi Sederhana:

Seperti menebak angka 1-100. Kamu mulai dari 50, jika terlalu besar coba 25, jika terlalu kecil coba 75, dan seterusnya!

🔍 Demo Interaktif

Array Terurut: [11, 12, 23, 34, 45, 56, 67, 78, 89, 90]

⚙️ Cara Kerja

1

Tentukan titik tengah

Hitung index tengah: (awal + akhir) / 2

2

Bandingkan dengan data yang dicari

Jika sama, selesai. Jika lebih kecil, cari di bagian kanan. Jika lebih besar, cari di bagian kiri

3

Ulangi pada bagian yang dipilih

Terus bagi dua sampai data ditemukan atau tidak ada lagi yang bisa dibagi

✅ Kelebihan

  • • Sangat cepat untuk data besar
  • • Kompleksitas waktu O(log n)
  • • Efisien untuk pencarian berulang

❌ Kekurangan

  • • Data harus sudah terurut
  • • Lebih kompleks untuk dipahami
  • • Tidak cocok untuk data yang sering berubah

🎯 Kapan Menggunakan Masing-masing?

🔄 Gunakan Pencarian Sekuensial Jika:

  • ✓ Data tidak terurut
  • ✓ Jumlah data sedikit (< 100)
  • ✓ Pencarian jarang dilakukan
  • ✓ Ingin implementasi sederhana

⚡ Gunakan Pencarian Biner Jika:

  • ✓ Data sudah terurut
  • ✓ Jumlah data banyak (> 100)
  • ✓ Pencarian sering dilakukan
  • ✓ Kecepatan adalah prioritas
