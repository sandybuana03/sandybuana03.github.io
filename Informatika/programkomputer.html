🤖 Apa itu Program Komputer?

Program komputer adalah kumpulan instruksi atau perintah yang ditulis dalam bahasa yang dapat dipahami oleh komputer. Program ini memberitahu komputer apa yang harus dilakukan, langkah demi langkah.

🍳 Analogi Sederhana:

Bayangkan kamu sedang mengajarkan teman cara membuat mie instan:

  1. Rebus air 400ml
  2. Masukkan mie ke air mendidih
  3. Tunggu 3 menit
  4. Masukkan bumbu
  5. Aduk dan sajikan

Nah, program komputer juga seperti itu! Kita memberikan instruksi step-by-step kepada komputer.

Konsep Dasar Pemrograman

Memahami fondasi pemrograman!

🧠 Algoritma

Algoritma adalah langkah-langkah logis untuk menyelesaikan masalah. Sebelum menulis program, kita harus memikirkan algoritmanya dulu!

🔍 Contoh Algoritma: Mencari Nomor HP di Kontak

  1. Buka aplikasi kontak
  2. Ketik nama yang dicari di kolom pencarian
  3. Lihat hasil pencarian
  4. Jika ditemukan, klik nama tersebut
  5. Jika tidak ditemukan, coba ejaan lain atau scroll manual

📦 Variabel

Variabel adalah "kotak" untuk menyimpan data. Seperti kotak yang diberi label, variabel punya nama dan bisa diisi dengan berbagai jenis data.

📝 Contoh Variabel:

nama "Budi"
umur 17
tinggi 165.5
lulus true

🏷️ Jenis Data:

  • String - Teks ("Halo")
  • Integer - Bilangan bulat (42)
  • Float - Bilangan desimal (3.14)
  • Boolean - True/False

🔄 Struktur Kontrol

Struktur kontrol mengatur alur jalannya program. Ada 3 jenis utama:

➡️

Sequential

Instruksi dijalankan berurutan dari atas ke bawah

🔀

Selection (If-Else)

Memilih instruksi berdasarkan kondisi tertentu

🔁

Repetition (Loop)

Mengulang instruksi beberapa kali

⚙️ Fungsi

Fungsi adalah blok kode yang dapat digunakan berulang kali. Seperti mesin yang menerima input dan menghasilkan output.

🧮 Contoh Fungsi: Kalkulator Sederhana

fungsi tambah(a, b):
hasil = a + b
kembalikan hasil
// Cara pakai:
total = tambah(5, 3) // hasilnya 8

Bahasa Pemrograman

Mengenal berbagai bahasa untuk berkomunikasi dengan komputer!

🗣️ Apa itu Bahasa Pemrograman?

Bahasa pemrograman adalah bahasa khusus yang digunakan untuk menulis instruksi kepada komputer. Sama seperti manusia punya bahasa Indonesia, Inggris, Jepang - komputer juga punya banyak "bahasa"!

🌍 Analogi Bahasa Manusia:

Bahasa Manusia:
  • • Indonesia: "Halo, apa kabar?"
  • • Inggris: "Hello, how are you?"
  • • Jepang: "Konnichiwa, genki desu ka?"
Bahasa Komputer:
  • • Python: print("Hello World")
  • • Java: System.out.println("Hello World")
  • • C++: cout << "Hello World";

🧠 Soal 2: Analisis Program

Perhatikan pseudocode (algoritma) berikut:

MULAI
INPUT nama_siswa
INPUT nilai_matematika
INPUT nilai_bahasa
INPUT nilai_ipa
rata_rata = (nilai_matematika + nilai_bahasa + nilai_ipa) / 3
JIKA rata_rata >= 80 MAKA
    status = "LULUS"
JIKA TIDAK
    status = "TIDAK LULUS"
OUTPUT nama_siswa, rata_rata, status
SELESAI
  1. Jelaskan apa yang dilakukan program ini langkah demi langkah!
  2. Jika seorang siswa bernama "Andi" mendapat nilai Matematika 85, Bahasa 75, dan IPA 90, apa output yang akan dihasilkan?
  3. Bagaimana cara memodifikasi program ini agar bisa menentukan grade (A, B, C, D, E) berdasarkan rata-rata?

💡 Soal 3: Algoritma Sederhana

Buatlah algoritma sederhana untuk kasus berikut:

🎯 Kasus: Menentukan Kelulusan Siswa

Seorang siswa akan dinyatakan LULUS jika:
• Nilai rata-rata >= 75
• Tidak ada nilai di bawah 60

Jika tidak memenuhi syarat, siswa dinyatakan TIDAK LULUS.

Input: Nama siswa, nilai Matematika, nilai Bahasa Indonesia, nilai IPA
Output: Nama siswa, rata-rata, dan status kelulusan

💡 Contoh Format Algoritma:
MULAI
INPUT nama
INPUT nilai1, nilai2, nilai3
rata_rata = (nilai1 + nilai2 + nilai3) / 3
JIKA ... MAKA
    ...
JIKA TIDAK
    ...
OUTPUT ...
