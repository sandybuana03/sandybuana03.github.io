Pengenalan Struktur Data

Mari mengenal dunia struktur data yang menarik!

🏗️ Apa itu Struktur Data?

Struktur data adalah cara khusus untuk menyimpan dan mengatur data dalam komputer sehingga dapat digunakan secara efisien. Bayangkan seperti lemari pakaian - kamu bisa menyimpan baju dengan berbagai cara:

👕

Cara Acak

Baju dilempar begitu saja - sulit mencari yang diinginkan

📚

Cara Teratur

Baju disusun rapi berdasarkan jenis - mudah ditemukan

Sama halnya dengan data di komputer! Struktur data membantu kita mengatur data agar:

  • Mudah dicari dan diakses
  • Efisien dalam penggunaan memori
  • Cepat dalam pemrosesan
  • Mudah dimodifikasi

🌟 Mengapa Struktur Data Penting?

🚀 Kecepatan

Struktur data yang tepat membuat program berjalan lebih cepat. Misalnya, mencari nama dalam daftar yang sudah diurutkan jauh lebih cepat daripada daftar acak.

💾 Efisiensi Memori

Menghemat ruang penyimpanan dengan mengatur data secara optimal.

🔧 Kemudahan Maintenance

Kode menjadi lebih mudah dipahami dan dimodifikasi.

🎯 Pemecahan Masalah

Setiap masalah memiliki struktur data yang paling cocok untuk menyelesaikannya.

🧠

Konsep Struktur Data

Memahami berbagai jenis struktur data dan kegunaannya

📊 Array (Larik)

Array adalah struktur data paling sederhana yang menyimpan elemen-elemen dengan tipe data sama dalam urutan tertentu.

🎯 Analogi Sederhana:

Bayangkan array seperti kotak penyimpanan dengan nomor:

A
B
C
D
E
[0]
[1]
[2]
[3]
[4]

✅ Kelebihan:

  • • Akses data sangat cepat dengan indeks
  • • Mudah dipahami dan digunakan
  • • Efisien untuk data berukuran tetap

❌ Kekurangan:

  • • Ukuran tetap (sulit diubah)
  • • Penyisipan/penghapusan lambat
  • • Memori terbuang jika tidak penuh

🔗 Linked List

Linked List adalah struktur data yang terdiri dari node-node yang saling terhubung melalui pointer.

🎯 Analogi Sederhana:

Seperti rantai manusia - setiap orang memegang tangan orang berikutnya:

👤
→
👤
→
👤
→
∅

✅ Kelebihan:

  • • Ukuran dinamis (bisa bertambah/berkurang)
  • • Penyisipan/penghapusan cepat
  • • Efisien penggunaan memori

❌ Kekurangan:

  • • Akses data lambat (harus berurutan)
  • • Membutuhkan memori tambahan untuk pointer
  • • Tidak bisa akses random

📚 Stack (Tumpukan)

Stack adalah struktur data yang mengikuti prinsip LIFO (Last In, First Out) - yang terakhir masuk, pertama keluar.

🎯 Analogi Sederhana:

Seperti tumpukan piring - piring yang terakhir ditaruh, pertama diambil:

Piring 3
Piring 2
Piring 1
↑ TOP

🔧 Operasi Utama:

Push: Menambah elemen ke atas

Pop: Mengambil elemen dari atas

Top/Peek: Melihat elemen teratas

isEmpty: Cek apakah kosong

🎮 Contoh Penggunaan:

  • • Undo/Redo dalam aplikasi
  • • Browser history (tombol back)
  • • Pemanggilan fungsi dalam program
  • • Evaluasi ekspresi matematika

🚶‍♂️ Queue (Antrian)

Queue adalah struktur data yang mengikuti prinsip FIFO (First In, First Out) - yang pertama masuk, pertama keluar.

🎯 Analogi Sederhana:

Seperti antrian di kasir - yang datang pertama, dilayani pertama:

FRONT →
👤
👤
👤
← REAR

🔧 Operasi Utama:

Enqueue: Menambah elemen di belakang

Dequeue: Mengambil elemen dari depan

Front: Melihat elemen terdepan

isEmpty: Cek apakah kosong

🎮 Contoh Penggunaan:

  • • Antrian printer
  • • Sistem operasi (penjadwalan proses)
  • • Streaming data
  • • Breadth-First Search (BFS)

Algoritma Standar

Algoritma penting yang sering digunakan dengan struktur data

🔍 Algoritma Pencarian (Searching)

1. Linear Search (Pencarian Linear)

Mencari data dengan memeriksa setiap elemen satu per satu dari awal hingga akhir.

🎯 Cara Kerja:

1. Mulai dari elemen pertama

2. Bandingkan dengan data yang dicari

3. Jika sama, data ditemukan

4. Jika tidak, lanjut ke elemen berikutnya

5. Ulangi sampai data ditemukan atau habis

Contoh: Mencari angka 7

3
1
4
7
2

Ditemukan di posisi ke-4!

✅ Kelebihan:

  • • Sederhana dan mudah dipahami
  • • Bisa digunakan pada data tidak terurut
  • • Tidak perlu memori tambahan

❌ Kekurangan:

  • • Lambat untuk data besar
  • • Kompleksitas waktu O(n)

2. Binary Search (Pencarian Biner)

Mencari data pada array yang sudah terurut dengan membagi dua area pencarian.

🎯 Cara Kerja:

1. Tentukan elemen tengah array

2. Bandingkan dengan data yang dicari

3. Jika sama, data ditemukan

4. Jika lebih kecil, cari di bagian kanan

5. Jika lebih besar, cari di bagian kiri

6. Ulangi sampai ditemukan

Contoh: Mencari angka 7 dalam array terurut

1
3
5
7
9
11
13

Tengah = 7, cocok! Ditemukan!

✅ Kelebihan:

  • • Sangat cepat O(log n)
  • • Efisien untuk data besar

❌ Kekurangan:

  • • Hanya untuk data terurut
  • • Perlu pengurutan terlebih dahulu

📊 Algoritma Pengurutan (Sorting)

1. Bubble Sort

Mengurutkan dengan membandingkan elemen bersebelahan dan menukarnya jika tidak sesuai urutan.

🎯 Cara Kerja:

1. Bandingkan elemen pertama dengan kedua

2. Tukar jika tidak sesuai urutan

3. Lanjut ke pasangan berikutnya

4. Ulangi sampai tidak ada pertukaran

Contoh: Mengurutkan [5, 2, 8, 1]

Awal:
5
2
8
1
→ Tukar 5 dan 2
Step 1:
2
5
8
1
→ 5 < 8, tidak tukar
Akhir:
1
2
5
8
✅ Terurut!

2. Selection Sort

Mengurutkan dengan mencari elemen terkecil dan menempatkannya di posisi yang benar.

🎯 Cara Kerja:

1. Cari elemen terkecil dalam array

2. Tukar dengan elemen pertama

3. Cari elemen terkecil kedua

4. Tukar dengan elemen kedua

5. Ulangi sampai selesai

Contoh: Mengurutkan [64, 25, 12, 22]

Awal:
64
25
12
22
→ 12 terkecil
Step 1:
12
25
64
22
→ 22 terkecil kedua
Akhir:
12
22
25
64
✅ Terurut!

⏱️ Kompleksitas Algoritma

Kompleksitas algoritma mengukur seberapa efisien algoritma dalam hal waktu dan ruang.

🕐 Kompleksitas Waktu

O(1) - Konstan: Sangat Cepat
O(log n) - Logaritmik: Cepat
O(n) - Linear: Sedang
O(n²) - Kuadratik: Lambat

📊 Perbandingan Algoritma

Linear Search: O(n)
Binary Search: O(log n)
Bubble Sort: O(n²)
Selection Sort: O(n²)
