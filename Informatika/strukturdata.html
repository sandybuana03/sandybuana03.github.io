Pengenalan Struktur Data

Mari mulai perjalanan belajar kita!

🌟 Apa itu Struktur Data?

Struktur Data adalah cara mengorganisir, menyimpan, dan mengatur data dalam komputer sehingga dapat digunakan secara efisien. Bayangkan seperti cara kita mengatur buku di perpustakaan atau barang di lemari.

🏠 Analogi Sederhana:

Struktur data seperti berbagai jenis wadah penyimpanan di rumah:

  • 📚 Rak buku = Array (data tersusun berurutan)
  • 🗂️ Filing cabinet = Database (data terorganisir)
  • 📦 Kotak bertumpuk = Stack (tumpukan data)
  • 🚶‍♂️ Antrian = Queue (data berurutan masuk-keluar)
🎯

Mengapa Penting?

  • ✓ Efisiensi: Program berjalan lebih cepat
  • ✓ Organisasi: Data tertata dengan rapi
  • ✓ Kemudahan: Mudah mencari dan mengubah data
  • ✓ Skalabilitas: Dapat menangani data besar
🌍

Contoh dalam Kehidupan

  • 📱 Kontak HP: Daftar nama tersusun alfabetis
  • 🎵 Playlist musik: Lagu-lagu dalam urutan tertentu
  • 📧 Email: Pesan tersusun berdasarkan waktu
  • 🛒 Keranjang belanja: Daftar barang yang akan dibeli
🚀

Konsep Dasar Struktur Data

Memahami fondasi yang kuat!

🏗️ Elemen Dasar Struktur Data

📦

Data/Elemen

Informasi yang disimpan dalam struktur data. Bisa berupa angka, teks, gambar, atau jenis data lainnya.

Contoh: Nama siswa, nilai ujian, alamat email
🔗

Relasi/Hubungan

Cara elemen-elemen data saling berhubungan atau terhubung satu sama lain dalam struktur.

Contoh: Urutan, hierarki, keterkaitan
⚡

Operasi

Tindakan yang dapat dilakukan pada struktur data seperti menambah, menghapus, mencari, atau mengubah data.

Contoh: Insert, Delete, Search, Update
📏

Kompleksitas

Ukuran seberapa efisien struktur data dalam hal waktu dan ruang penyimpanan yang dibutuhkan.

Contoh: O(1), O(n), O(log n)

🎭 Karakteristik Struktur Data

🔄 Linear vs Non-Linear

Linear: Data tersusun berurutan seperti barisan
Contoh: Array, List, Stack, Queue
Non-Linear: Data tersusun seperti pohon atau jaringan
Contoh: Tree, Graph

🏠 Static vs Dynamic

Static: Ukuran tetap, tidak bisa berubah
Contoh: Array dengan ukuran tetap
Dynamic: Ukuran bisa berubah sesuai kebutuhan
Contoh: Linked List, Dynamic Array

🎯 Homogeneous vs Heterogeneous

Homogeneous: Semua elemen bertipe sama
Contoh: Array of integers
Heterogeneous: Elemen bisa berbeda tipe
Contoh: Record, Object
💡

Tips Memilih Struktur Data

🤔 Pertimbangkan kebutuhan: Apa yang sering dilakukan?

⚡ Perhatikan efisiensi: Seberapa cepat operasinya?

💾 Ukur memori: Berapa banyak ruang yang dibutuhkan?

🔮 Pikirkan masa depan: Apakah data akan bertambah?

Jenis-Jenis Struktur Data

Mengenal berbagai macam struktur data!

📊

Array (Larik)

Array adalah kumpulan elemen yang disimpan dalam lokasi memori yang berurutan. Setiap elemen dapat diakses menggunakan indeks.

Karakteristik:

  • ✓ Ukuran tetap
  • ✓ Akses langsung dengan indeks
  • ✓ Elemen bertipe sama
  • ✓ Memori berurutan

Visualisasi Array:

10
25
30
45
50
[0]
[1]
[2]
[3]
[4]
Contoh penggunaan: Daftar nilai siswa, koordinat titik, data sensor
🔗

Linked List

Linked List adalah struktur data linear di mana elemen-elemen (node) dihubungkan menggunakan pointer atau referensi.

Karakteristik:

  • ✓ Ukuran dinamis
  • ✓ Akses berurutan
  • ✓ Mudah insert/delete
  • ✓ Memori tidak berurutan

Visualisasi Linked List:

A
→
B
→
C
→
NULL
Contoh penggunaan: Playlist musik, history browser, undo/redo
📚

Stack (Tumpukan)

Stack adalah struktur data yang mengikuti prinsip LIFO (Last In, First Out). Seperti tumpukan piring, yang terakhir ditaruh akan pertama diambil.

Operasi Utama:

  • ✓ Push (menambah ke atas)
  • ✓ Pop (mengambil dari atas)
  • ✓ Top/Peek (melihat elemen teratas)
  • ✓ isEmpty (cek kosong)

Visualisasi Stack:

30 ← Top
20
10
Bottom
Contoh penggunaan: Undo/Redo, function call, expression evaluation
🚶‍♂️

Queue (Antrian)

Queue adalah struktur data yang mengikuti prinsip FIFO (First In, First Out). Seperti antrian di kasir, yang pertama datang akan pertama dilayani.

Operasi Utama:

  • ✓ Enqueue (menambah di belakang)
  • ✓ Dequeue (mengambil dari depan)
  • ✓ Front (melihat elemen depan)
  • ✓ isEmpty (cek kosong)

Visualisasi Queue:

Front →
A
B
C
← Rear
Contoh penggunaan: Print queue, task scheduling, BFS algorithm
🌳

Tree (Pohon)

Tree adalah struktur data hierarkis yang terdiri dari node-node yang terhubung dalam bentuk seperti pohon terbalik.

Komponen:

  • ✓ Root (akar)
  • ✓ Parent & Child (induk & anak)
  • ✓ Leaf (daun)
  • ✓ Level & Height

Visualisasi Tree:

A (Root)
B
C
D
E
F
Contoh penggunaan: File system, decision tree, HTML DOM

Implementasi Struktur Data

Mari lihat bagaimana struktur data bekerja dalam kode!

📊

Implementasi Array

Contoh dalam JavaScript:

// Membuat array
let nilai = [85, 90, 78, 92, 88];

// Mengakses elemen
console.log(nilai[0]); // 85

// Mengubah elemen
nilai[2] = 80;

// Menambah elemen
nilai.push(95);

Operasi Array:

Akses: O(1) - Sangat cepat
Langsung ke indeks yang diinginkan
Pencarian: O(n) - Linear
Harus cek satu per satu
Insert/Delete: O(n) - Lambat
Harus geser elemen lain
📚

Implementasi Stack

Contoh dalam JavaScript:

// Membuat stack
let stack = [];

// Push (menambah)
stack.push(10);
stack.push(20);
stack.push(30);

// Pop (mengambil)
let top = stack.pop(); // 30

// Peek (melihat teratas)
let peek = stack[stack.length-1];

Contoh Aplikasi:

🔙 Undo/Redo Function

Setiap aksi disimpan di stack. Undo = pop dari stack aksi.

🧮 Evaluasi Ekspresi

Menghitung (2+3)*4 menggunakan stack untuk operator.

📞 Function Call

Setiap pemanggilan fungsi masuk ke call stack.

Tugas Pembelajaran

Saatnya menguji pemahaman kamu!

🎯 Soal Essay

Soal 1: Analisis Kasus

Kamu diminta untuk membuat sistem manajemen perpustakaan digital. Sistem ini harus dapat menyimpan informasi buku, melacak peminjaman, dan mengelola antrian reservasi buku.

Pertanyaan: Struktur data apa saja yang akan kamu gunakan untuk setiap fitur tersebut? Jelaskan alasan pemilihan masing-masing struktur data dan bagaimana implementasinya!

Soal 2: Perbandingan Efisiensi

Sebuah aplikasi media sosial perlu menyimpan dan menampilkan postingan pengguna. Ada dua pilihan: menggunakan Array atau Linked List.

Pertanyaan: Bandingkan kedua struktur data tersebut dalam konteks:
a) Menambah postingan baru
b) Menghapus postingan lama
c) Mencari postingan tertentu
d) Menampilkan semua postingan
Struktur data mana yang lebih cocok dan mengapa?

Soal 3: Desain Algoritma

Kamu ingin membuat fitur "Undo" dan "Redo" untuk aplikasi text editor. Pengguna dapat melakukan berbagai aksi seperti mengetik, menghapus, memformat teks, dan sebagainya.

Pertanyaan: Rancang algoritma untuk fitur Undo/Redo menggunakan struktur data yang tepat. Jelaskan bagaimana cara kerja algoritma tersebut dan berikan contoh skenario penggunaannya!

Soal 4: Studi Kasus Nyata

Perhatikan aplikasi-aplikasi berikut: WhatsApp, Instagram, Google Maps, dan Spotify. Setiap aplikasi menggunakan berbagai struktur data untuk fitur-fitur utamanya.

Pertanyaan: Pilih salah satu aplikasi di atas, identifikasi minimal 3 fitur utamanya, dan jelaskan struktur data apa yang mungkin digunakan untuk setiap fitur tersebut. Berikan alasan yang logis untuk setiap pilihan!

Soal 5: Optimasi dan Inovasi

Sebuah game online memiliki sistem ranking pemain yang harus diupdate secara real-time. Ada jutaan pemain dan ranking berubah setiap detik berdasarkan skor yang diperoleh.

Pertanyaan: Bagaimana kamu akan merancang sistem ranking yang efisien? Struktur data apa yang akan digunakan? Bagaimana menangani update yang sangat sering? Jelaskan solusi kreatif kamu!
