⚡ Mengapa Efisiensi Penting?

Bayangkan kamu punya 1 juta data siswa. Dengan struktur data yang tepat, pencarian bisa dilakukan dalam hitungan detik. Tapi dengan struktur yang salah, bisa memakan waktu berjam-jam! Inilah mengapa memilih struktur data yang tepat sangat penting.

Contoh Perbandingan Pencarian:

  • • Array (Linear Search): Mencari dalam 1000 data → rata-rata 500 langkah
  • • Array (Binary Search): Mencari dalam 1000 data → maksimal 10 langkah
  • • Hash Table: Mencari dalam 1000 data → rata-rata 1 langkah!

📊 Array (Larik)

Apa itu Array? 🤔

Array adalah struktur data yang menyimpan kumpulan elemen dengan tipe data yang sama dalam lokasi memori yang berurutan. Setiap elemen dapat diakses langsung menggunakan nomor indeks yang dimulai dari 0. Seperti kotak-kotak penyimpanan yang berjejer rapi dan diberi nomor urut! 📦📦📦

Karakteristik Array 📋

✅ Elemen disimpan secara berurutan di memori
✅ Setiap elemen memiliki index unik (dimulai dari 0)
✅ Ukuran tetap setelah dibuat (static array)
✅ Akses langsung ke elemen sangat cepat (waktu konstan O(1))
✅ Semua elemen memiliki tipe data yang sama

Keunggulan & Kelemahan Array ⚖️

✅ Keunggulan

  • • Akses elemen sangat cepat dengan index
  • • Penggunaan memori efisien (tidak ada overhead)
  • • Mudah dipahami dan diimplementasikan
  • • Cocok untuk operasi matematika dan iterasi

❌ Kelemahan

  • • Ukuran tetap (tidak bisa berubah setelah dibuat)
  • • Insert/delete di tengah array lambat O(n)
  • • Pemborosan memori jika tidak terpakai penuh
  • • Harus menentukan ukuran maksimum di awal

📚 Stack (Tumpukan)

Apa itu Stack? 🤔

Stack adalah struktur data linear yang mengikuti prinsip LIFO (Last In, First Out), artinya elemen yang terakhir dimasukkan akan menjadi yang pertama dikeluarkan. Operasi penambahan dan pengambilan elemen hanya bisa dilakukan di satu ujung yang disebut "top" (puncak). Seperti tumpukan piring - piring yang terakhir ditaruh akan diambil pertama kali! 🥞

Operasi Utama Stack 🛠️

⬆️

Push

Menambahkan elemen ke puncak stack

⬇️

Pop

Mengambil elemen dari puncak stack

👀

Peek/Top

Melihat elemen puncak tanpa mengambilnya

Keunggulan & Kelemahan Stack ⚖️

✅ Keunggulan

  • • Operasi push dan pop sangat cepat O(1)
  • • Implementasi sederhana dan mudah dipahami
  • • Cocok untuk recursive algorithms
  • • Efisien untuk undo/redo operations

❌ Kelemahan

  • • Akses terbatas hanya di puncak stack
  • • Tidak bisa mengakses elemen di tengah
  • • Ukuran terbatas (stack overflow)
  • • Tidak cocok untuk pencarian data

🚶 Queue (Antrian)

Apa itu Queue? 🤔

Queue adalah struktur data linear yang mengikuti prinsip FIFO (First In, First Out), artinya elemen yang pertama dimasukkan akan menjadi yang pertama dikeluarkan. Queue memiliki dua ujung: "rear/back" untuk menambah elemen dan "front" untuk mengambil elemen. Seperti antrian di bank - orang yang datang pertama akan dilayani pertama! 🏦👥

Keunggulan & Kelemahan Queue ⚖️

✅ Keunggulan

  • • Operasi enqueue dan dequeue cepat O(1)
  • • Menjamin keadilan (first come, first served)
  • • Cocok untuk sistem penjadwalan
  • • Mudah diimplementasikan

❌ Kelemahan

  • • Akses terbatas hanya di depan dan belakang
  • • Tidak bisa mengakses elemen di tengah
  • • Membutuhkan memori tambahan untuk pointer
  • • Tidak cocok untuk pencarian acak

🔗 Linked List (Daftar Berantai)

Apa itu Linked List? 🤔

Linked List adalah struktur data linear yang terdiri dari kumpulan node yang saling terhubung melalui pointer/referensi. Setiap node berisi dua bagian: data (informasi yang disimpan) dan pointer/next (alamat node berikutnya). Berbeda dengan Array, elemen-elemen dalam Linked List tidak harus disimpan di lokasi memori yang berurutan, sehingga ukurannya bisa berubah secara dinamis saat program berjalan! ⛓️

Komponen Linked List 🧩

Informasi yang disimpan dalam node

👉

Penunjuk ke node berikutnya

🏁

Head

Pointer yang menunjuk ke node pertama dalam linked list

Keunggulan & Kelemahan ⚖️

✅ Keunggulan

  • • Ukuran dinamis (bisa bertambah/berkurang)
  • • Efisien untuk insert/delete di awal
  • • Tidak perlu menentukan ukuran di awal
  • • Hemat memori (alokasi sesuai kebutuhan)

❌ Kelemahan

  • • Akses elemen tidak langsung (harus traversal)
  • • Membutuhkan memori tambahan untuk pointer
  • • Tidak cache-friendly
  • • Rentan terhadap memory leak

Jenis-jenis Linked List 📋

➡️

Singly Linked List

Setiap node hanya menunjuk ke node berikutnya

↔️

Doubly Linked List

Setiap node memiliki pointer ke node sebelum dan sesudahnya

🔄

Circular Linked List

Node terakhir menunjuk kembali ke node pertama

Jelaskan mengapa Array cocok digunakan untuk menyimpan daftar nilai siswa dalam satu kelas. Berikan 3 alasan dan contoh penggunaannya!

2. Implementasi Stack

Buatlah skenario penggunaan Stack dalam kehidupan sehari-hari selain contoh yang sudah diberikan. Jelaskan bagaimana prinsip LIFO diterapkan dalam skenario tersebut!

Hint: Pikirkan aktivitas yang melibatkan "terakhir masuk, pertama keluar".

3. Perbandingan Queue

Hint: Pertimbangkan keadilan pelayanan dan efisiensi operasional.

4. Desain Linked List

Rancang sebuah sistem playlist musik menggunakan konsep Linked List. Jelaskan bagaimana fitur "next song", "previous song", dan "add song" akan bekerja!

Hint: Pikirkan tentang node, pointer, dan operasi traversal.

5. Analisis Kasus

Sebuah aplikasi media sosial perlu menyimpan dan menampilkan postingan terbaru. Struktur data mana yang paling tepat digunakan? Jelaskan alasan dan cara implementasinya!

Hint: Pertimbangkan urutan tampilan, penambahan data baru, dan efisiensi akses.
