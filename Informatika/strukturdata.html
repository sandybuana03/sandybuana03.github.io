Pengenalan Struktur Data

🤓 Apa itu Struktur Data?

Struktur data adalah cara khusus untuk mengorganisir dan menyimpan data dalam komputer sehingga dapat digunakan secara efisien. Bayangkan seperti mengatur barang-barang di rumah - ada yang disimpan di lemari, ada yang di laci, ada yang digantung.

Jenis-Jenis Struktur Data

📋 1. Array (Larik)

Array adalah struktur data yang menyimpan elemen-elemen dengan tipe data yang sama dalam urutan yang berurutan. Seperti deretan rumah yang memiliki nomor alamat berurutan.

🎮 Demo Interaktif Array

10
25
30
45
50

Klik pada elemen array untuk melihat indeksnya!

✅ Kelebihan Array

  • • Akses data sangat cepat dengan indeks
  • • Mudah digunakan dan dipahami
  • • Hemat memori

❌ Kekurangan Array

  • • Ukuran tetap (tidak bisa berubah)
  • • Penyisipan dan penghapusan lambat
  • • Memori harus berurutan

🥞 2. Stack (Tumpukan)

Stack adalah struktur data yang mengikuti prinsip LIFO (Last In, First Out). Seperti tumpukan piring - piring yang terakhir ditaruh akan diambil pertama kali.

🎮 Demo Interaktif Stack

A
B
C

Push = menambah ke atas, Pop = mengambil dari atas

🎯 Penggunaan Stack

↩️

Undo/Redo
Dalam aplikasi

🌐

Browser History
Tombol back

🧮

Kalkulator
Operasi matematika

🚶‍♂️ 3. Queue (Antrian)

Queue adalah struktur data yang mengikuti prinsip FIFO (First In, First Out). Seperti antrian di kasir - orang yang datang pertama akan dilayani pertama.

🎮 Demo Interaktif Queue

1
→
2
→
3

Enqueue = masuk dari belakang, Dequeue = keluar dari depan

🎯 Penggunaan Queue

🖨️

Print Queue
Antrian cetak dokumen

💬

Chat Messages
Pesan berurutan

🎮

Game Matchmaking
Antrian pemain

🔗 4. Linked List (Daftar Berantai)

Linked List adalah struktur data yang terdiri dari node-node yang saling terhubung. Setiap node berisi data dan pointer ke node berikutnya. Seperti rantai yang setiap mata rantainya terhubung ke mata rantai berikutnya.

🎮 Visualisasi Linked List

A
→
B
→
C
→
NULL

Setiap kotak adalah node yang berisi data dan pointer ke node berikutnya

✅ Kelebihan Linked List

  • • Ukuran dinamis (bisa berubah)
  • • Penyisipan dan penghapusan cepat
  • • Tidak perlu memori berurutan

❌ Kekurangan Linked List

  • • Akses data lebih lambat
  • • Membutuhkan memori ekstra untuk pointer
  • • Tidak bisa akses langsung ke elemen

1. Pemahaman Konsep (25 poin)

Jelaskan dengan kata-kata sendiri apa yang dimaksud dengan struktur data dan mengapa struktur data penting dalam pemrograman. Berikan contoh analogi dari kehidupan sehari-hari!

Bandingkan antara Array dan Linked List. Sebutkan minimal 2 kelebihan dan 2 kekurangan masing-masing. Kapan sebaiknya menggunakan Array dan kapan menggunakan Linked List?

Anda diminta membuat fitur "Undo" dalam aplikasi text editor. Jelaskan bagaimana Anda akan menggunakan struktur data Stack untuk mengimplementasikan fitur ini. Berikan contoh langkah-langkahnya!

Sebuah restoran fast food ingin membuat sistem antrian digital untuk pelanggan. Jelaskan bagaimana struktur data Queue dapat digunakan untuk sistem ini. Apa operasi-operasi yang diperlukan?
