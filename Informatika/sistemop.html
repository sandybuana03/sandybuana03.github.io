🖥️ Apa itu Sistem Operasi?

📖 Definisi

Sistem Operasi (Operating System/OS) adalah perangkat lunak sistem yang bertindak sebagai perantara antara pengguna komputer dan perangkat keras komputer. OS mengelola sumber daya sistem dan menyediakan layanan untuk program aplikasi.

💡 Analogi Mudah:

OS seperti seorang direktur di perusahaan yang mengatur semua departemen (hardware) dan karyawan (software) agar bekerja harmonis dan efisien untuk mencapai tujuan bersama.

⚙️ Fungsi-Fungsi Sistem Operasi

🧠 1. Manajemen Proses

Mengatur dan mengontrol eksekusi program-program yang berjalan di komputer. OS bertanggung jawab untuk membuat, menjadwalkan, dan menghentikan proses.

📋 Tugas Utama:
  • • Membuat dan menghapus proses
  • • Penjadwalan CPU (scheduling)
  • • Sinkronisasi antar proses
  • • Komunikasi antar proses (IPC)
🔄 Algoritma Scheduling:
  • • First Come First Served (FCFS)
  • • Round Robin (RR)
  • • Shortest Job First (SJF)
  • • Priority Scheduling

💾 2. Manajemen Memori

Mengalokasikan dan mengelola penggunaan RAM untuk berbagai program. OS memastikan setiap program mendapat memori yang cukup tanpa saling mengganggu.

🎯 Fungsi Utama:
  • • Alokasi memori
  • • Dealokasi memori
  • • Memory protection
  • • Virtual memory
📊 Jenis Memori:
  • • RAM (Primary)
  • • Cache Memory
  • • Virtual Memory
  • • Swap Space
⚡ Teknik Optimasi:
  • • Paging
  • • Segmentation
  • • Garbage Collection
  • • Memory Compression

📁 3. Manajemen Sistem File

Mengorganisir, menyimpan, dan mengakses data dalam bentuk file dan direktori. OS menyediakan struktur hierarkis untuk penyimpanan data.

🗂️ Operasi File:
  • • Create (membuat file)
  • • Read (membaca file)
  • • Write (menulis file)
  • • Delete (menghapus file)
  • • Rename (mengubah nama)
💿 Jenis File System:
  • • NTFS (Windows)
  • • ext4 (Linux)
  • • APFS (macOS)
  • • FAT32 (Universal)
  • • exFAT (Flash drives)

🧹

Disk Cleanup

Hapus file temporary, cache, dan sampah sistem secara berkala

Cara: Disk Cleanup → Pilih drive → Centang semua → OK
🔄

Update Sistem

Selalu update OS dan driver untuk performa optimal

Manfaat: Bug fixes, security patches, fitur baru
⚙️

Startup Programs

Nonaktifkan program yang tidak perlu saat startup

Windows: Task Manager → Startup → Disable

🔧 Masalah Umum & Solusinya

🐌

Komputer Lambat

Sistem berjalan sangat lambat, aplikasi lama terbuka

💡 Solusi:
  • • Tutup program yang tidak digunakan
  • • Bersihkan file temporary
  • • Tambah RAM jika perlu
  • • Scan virus/malware
💙

Blue Screen of Death (BSOD)

Layar biru dengan pesan error, sistem restart otomatis

💡 Solusi:
  • • Catat kode error yang muncul
  • • Update driver hardware
  • • Cek RAM dengan MemTest
  • • System restore ke titik sebelumnya
🔥

Overheat (Panas Berlebih)

Komputer panas, fan berisik, sering hang atau shutdown

💡 Solusi:
  • • Bersihkan debu di dalam casing
  • • Pastikan fan CPU berfungsi
  • • Ganti thermal paste CPU
  • • Perbaiki ventilasi ruangan
💾

Disk Space Penuh

Storage hampir penuh, sistem lambat, tidak bisa install program

💡 Solusi:
  • • Uninstall program yang tidak digunakan
  • • Pindahkan file ke external storage
  • • Gunakan Disk Cleanup
  • • Kosongkan Recycle Bin
