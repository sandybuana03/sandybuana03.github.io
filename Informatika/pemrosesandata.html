Pengertian Data

📊 Definisi Data

Data adalah kumpulan fakta, angka, karakter, atau simbol yang belum diproses menjadi informasi. Data merupakan bahan mentah yang perlu diolah untuk menghasilkan informasi yang berguna.

Data + Pemrosesan = Informasi 💡

🔢 Data Kuantitatif

Data berupa angka yang dapat diukur dan dihitung.

Contoh:

  • • Umur: 17 tahun
  • • Tinggi: 165 cm
  • • Nilai: 85

📝 Data Kualitatif

Data berupa kategori atau deskripsi yang tidak dapat diukur dengan angka.

Contoh:

  • • Jenis Kelamin: Laki-laki
  • • Warna: Merah
  • • Status: Aktif

Kualitas Data

Memahami karakteristik data yang berkualitas

🎯 Apa itu Kualitas Data?

Kualitas data mengacu pada seberapa baik data memenuhi kebutuhan pengguna untuk tujuan tertentu. Data berkualitas adalah data yang akurat, lengkap, konsisten, dan dapat diandalkan.

✅ Akurasi (Accuracy)

Data harus benar dan sesuai dengan kenyataan.

Contoh: Tanggal lahir 01/01/2005 ✅

Salah: Tanggal lahir 32/01/2005 ❌

📋 Kelengkapan (Completeness)

Semua data yang diperlukan harus tersedia.

Lengkap: Nama, Email, No. HP ✅

Tidak Lengkap: Nama, Email, [kosong] ❌

🔄 Konsistensi (Consistency)

Format dan nilai data harus seragam.

Konsisten: 08123456789 ✅

Tidak Konsisten: +62-812-345-6789 ❌

⏰ Ketepatan Waktu (Timeliness)

Data harus up-to-date dan relevan.

Tepat Waktu: Data penjualan hari ini ✅

Terlambat: Data penjualan 6 bulan lalu ❌

Data Cleaning

Membersihkan data dari kesalahan dan inkonsistensi

🎯 Apa itu Data Cleaning?

Data cleaning adalah proses mengidentifikasi dan memperbaiki kesalahan, inkonsistensi, dan ketidakakuratan dalam dataset untuk meningkatkan kualitas data.

🔍 Masalah Umum Data

❌ Missing Values

🛠️ Teknik Cleaning

🔧 Handling Missing Values

  • • Hapus baris dengan data kosong
  • • Isi dengan nilai default
  • • Isi dengan rata-rata/median

🗑️ Remove Duplicates

  • • Identifikasi data duplikat
  • • Hapus duplikasi
  • • Pertahankan data terbaru

📐 Standardize Format

  • • Seragamkan format tanggal
  • • Standarisasi nomor telepon
  • • Konsistensi huruf besar/kecil

Validasi Data

Memastikan data memenuhi kriteria kualitas

🎯 Apa itu Validasi Data?

Validasi data adalah proses memverifikasi bahwa data memenuhi kriteria kualitas yang telah ditetapkan. Ini memastikan data akurat, lengkap, dan siap untuk digunakan.

🔍 Jenis Validasi

📝 Format Validation

Memastikan data sesuai format yang diharapkan

Email: harus mengandung @ dan domain

📊 Range Validation

Memastikan nilai dalam rentang yang valid

Umur: harus antara 0-120 tahun

🔗 Referential Validation

Memastikan referensi data valid

Kode Provinsi: harus ada di master provinsi

⚡ Teknik Validasi

🤖 Automated Validation

  • • Script validasi otomatis
  • • Rule-based checking
  • • Real-time validation

👁️ Manual Validation

  • • Review manual oleh expert
  • • Sampling dan spot check
  • • Cross-validation

📈 Statistical Validation

  • • Outlier detection
  • • Distribution analysis
  • • Correlation checking
