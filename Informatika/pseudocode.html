Definisi Pseudocode

Memahami apa itu pseudocode secara mendalam

🔍 Apa itu Pseudocode?

Pseudocode adalah cara penulisan algoritma menggunakan bahasa yang mirip dengan bahasa pemrograman, tetapi menggunakan bahasa natural (bahasa sehari-hari) yang mudah dipahami manusia.

✅ Karakteristik Pseudocode

  • • Menggunakan bahasa natural
  • • Struktur mirip bahasa pemrograman
  • • Mudah dipahami manusia
  • • Tidak terikat sintaks tertentu

🎯 Tujuan Pseudocode

  • • Merencanakan program
  • • Komunikasi antar programmer
  • • Dokumentasi algoritma
  • • Pembelajaran pemrograman

🆚 Pseudocode vs Bahasa Pemrograman

📝 Pseudocode

MULAI

INPUT nama

OUTPUT "Halo " + nama

SELESAI

✅ Mudah dipahami

💻 Python

nama = input("Masukkan nama: ")

print("Halo " + nama)

Struktur Dasar Pseudocode

Membangun fondasi yang kuat untuk pseudocode

📋 Struktur Umum

Template Dasar:

ALGORITMA [Nama_Algoritma]

DEKLARASI

// Deklarasi variabel

DESKRIPSI

MULAI

// Langkah-langkah algoritma

SELESAI

Penjelasan:

ALGORITMA

Nama dan tujuan algoritma

DEKLARASI

Tempat mendeklarasikan variabel

DESKRIPSI

Isi algoritma yang sebenarnya

🎯 Contoh Lengkap

Masalah: Menghitung Luas Persegi Panjang

ALGORITMA Hitung_Luas_Persegi_Panjang

DEKLARASI

panjang, lebar, luas : real

DESKRIPSI

MULAI

OUTPUT "Masukkan panjang: "

INPUT panjang

OUTPUT "Masukkan lebar: "

INPUT lebar

luas ← panjang * lebar

OUTPUT "Luas persegi panjang: ", luas

SELESAI

📥

INPUT

Menerima data dari pengguna

⚙️

PROSES

Mengolah data sesuai algoritma

📤

OUTPUT

Menampilkan hasil kepada pengguna

Variabel & Tipe Data

Tempat menyimpan data dalam pseudocode

🎯 Apa itu Variabel?

Konsep Variabel

Variabel adalah kotak penyimpanan dalam memori komputer yang diberi nama untuk menyimpan data yang dapat berubah-ubah.

📦 nama_variabel = nilai_data

Analogi Sederhana

🏷️

Variabel = Label pada kotak

📦

Kotak = Tempat penyimpanan

🎁

Isi kotak = Nilai/data

🎨 Tipe Data dalam Pseudocode

🔢

INTEGER

Bilangan bulat

10, -5, 0, 100
🎯

REAL

Bilangan desimal

3.14, -2.5, 0.75
📝

STRING

Teks/karakter

"Halo", "SMK", "123"
✅

BOOLEAN

Benar/Salah

TRUE, FALSE

📋 Deklarasi dan Penugasan Variabel

Cara Deklarasi:

DEKLARASI

nama_variabel : tipe_data

umur : integer

nama : string

tinggi : real

lulus : boolean

Cara Penugasan:

umur ← 17

nama ← "Budi"

tinggi ← 165.5

lulus ← TRUE

total ← harga * jumlah

💡 Aturan Penamaan Variabel

✅ Yang Boleh:

  • • Dimulai dengan huruf
  • • Menggunakan underscore (_)
  • • Kombinasi huruf dan angka
  • • Contoh: nama_siswa, nilai1

❌ Yang Tidak Boleh:

  • • Dimulai dengan angka
  • • Menggunakan spasi
  • • Kata kunci pseudocode
  • • Contoh: 1nama, nama siswa

Percabangan (Branching)

Membuat keputusan dalam algoritma

🤔 Apa itu Percabangan?

Konsep Percabangan

Percabangan adalah struktur kontrol yang memungkinkan program untuk membuat keputusan berdasarkan kondisi tertentu. Seperti persimpangan jalan yang memiliki beberapa pilihan arah.

🤔 Kondisi → ✅ Aksi

Contoh Sehari-hari

🌧️ Jika hujan → Bawa payung

🎯 Jika nilai ≥ 75 → Lulus

💰 Jika uang cukup → Beli barang

📝 Struktur IF-THEN

Format Dasar:

IF kondisi THEN

aksi yang dilakukan

ENDIF

Contoh:

IF nilai ≥ 75 THEN

OUTPUT "Selamat, Anda LULUS!"

ENDIF

🎯 Simulasi IF-THEN

Masukkan nilai untuk melihat hasil!

🔀 Struktur IF-THEN-ELSE

Format Dasar:

IF kondisi THEN

aksi jika kondisi benar

ELSE

aksi jika kondisi salah

ENDIF

Contoh:

IF umur ≥ 17 THEN

OUTPUT "Boleh punya SIM"

ELSE

OUTPUT "Belum boleh punya SIM"

ENDIF

🎮 Simulasi IF-THEN-ELSE

Masukkan umur untuk melihat hasil!

🎯 Percabangan Bertingkat (Nested IF)

Format:

IF kondisi1 THEN

IF kondisi2 THEN

aksi untuk kondisi1 dan kondisi2

ELSE

aksi untuk kondisi1 saja

ENDIF

ELSE

aksi jika kondisi1 salah

ENDIF

Contoh Grade Nilai:

IF nilai ≥ 90 THEN

grade ← "A"

ELSE IF nilai ≥ 80 THEN

grade ← "B"

ELSE IF nilai ≥ 70 THEN

grade ← "C"

ELSE

grade ← "D"

ENDIF

Perulangan (Looping)

Mengulang proses secara otomatis

🔁 Apa itu Perulangan?

Konsep Perulangan

Perulangan adalah struktur kontrol yang memungkinkan sekelompok instruksi dijalankan berulang kali sampai kondisi tertentu terpenuhi. Seperti melakukan push-up 10 kali!

🔄 Ulangi → ✅ Sampai Selesai

Contoh Sehari-hari

🏃 Lari keliling lapangan 5 kali

📚 Baca halaman 1 sampai 100

🎵 Putar lagu sampai bosan

🎨

Contoh Lengkap

Menggabungkan semua konsep pseudocode

🏪 Contoh: Program Kasir Sederhana

Buatlah program kasir yang dapat menghitung total belanja, memberikan diskon jika total ≥ 100.000, dan menampilkan kembalian jika pembayaran lebih dari total.

🎯 Fitur Program:

✅

Input harga dan jumlah barang

✅

Hitung total belanja

✅

Berikan diskon 10% jika ≥ 100.000

✅

Hitung kembalian

Tugas

Latihan soal untuk mengasah pemahaman

📋 Soal Latihan

Soal 1: Menghitung Rata-rata

Buatlah pseudocode untuk menghitung rata-rata dari 3 buah nilai yang diinputkan oleh pengguna. Program harus menampilkan hasil rata-rata tersebut.

💡 Petunjuk:

  • • Gunakan variabel untuk menyimpan 3 nilai
  • • Hitung total dari ketiga nilai
  • • Bagi total dengan 3 untuk mendapat rata-rata
  • • Tampilkan hasil rata-rata

Soal 2: Menentukan Bilangan Genap/Ganjil

Buatlah pseudocode untuk menentukan apakah sebuah bilangan yang diinputkan pengguna adalah bilangan genap atau ganjil.

💡 Petunjuk:

  • • Input sebuah bilangan dari pengguna
  • • Gunakan operasi MOD untuk mengecek sisa bagi
  • • Jika sisa bagi dengan 2 = 0, maka genap
  • • Jika tidak, maka ganjil

Soal 3: Menentukan Kategori Usia

Buatlah pseudocode untuk menentukan kategori usia seseorang berdasarkan umur yang diinputkan. Kategori: Anak-anak (0-12), Remaja (13-17), Dewasa (18-59), Lansia (60+).

💡 Petunjuk:

  • • Input umur dari pengguna
  • • Gunakan IF-THEN-ELSE bertingkat
  • • Cek kondisi: umur ≤ 12, ≤ 17, ≤ 59, atau > 59
  • • Tampilkan kategori usia yang sesuai

📝 Cara Mengerjakan:

  1. 1. Tulis pseudocode lengkap dengan struktur ALGORITMA, DEKLARASI, dan DESKRIPSI
  2. 2. Gunakan kata kunci yang tepat (IF-THEN-ELSE, FOR-DO, WHILE-DO, dll)
  3. 3. Perhatikan indentasi untuk menunjukkan struktur program
  4. 4. Berikan komentar jika diperlukan untuk menjelaskan langkah-langkah
