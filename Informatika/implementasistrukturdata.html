🎯 Apa itu Struktur Data?

Struktur data adalah cara mengorganisir dan menyimpan data di dalam komputer agar dapat digunakan secara efisien. Bayangkan seperti cara kita menyusun buku di rak, atau mengatur antrian di kantin sekolah! 📚

Dalam pembelajaran ini, kita akan mempelajari 3 struktur data dasar yang sangat penting:

  • 📝 List: Seperti daftar belanja yang bisa ditambah atau dikurangi
  • 📚 Stack: Seperti tumpukan piring, yang terakhir ditaruh yang pertama diambil
  • 🚶‍♂️ Queue: Seperti antrian di kasir, yang pertama datang yang pertama dilayani

📝 Praktik List

Belajar menggunakan List untuk menyimpan data berurutan

🤔 Apa itu List?

List adalah struktur data yang dapat menyimpan beberapa item dalam satu variabel. Seperti daftar belanja yang bisa kita tambah, hapus, atau ubah isinya! 🛒

⚡ Karakteristik List:

  • • Dapat menyimpan berbagai tipe data
  • • Urutan data tetap terjaga (ordered)
  • • Dapat diubah (mutable)
  • • Menggunakan index untuk mengakses data

📚 Praktik Stack

Belajar Stack - Tumpukan Data LIFO

🤔 Apa itu Stack?

Stack adalah struktur data yang mengikuti prinsip LIFO (Last In First Out). Bayangkan seperti tumpukan piring - piring yang terakhir ditaruh akan menjadi yang pertama diambil! 🍽️

⚡ Operasi Utama Stack:

  • • Push: Menambah data ke atas tumpukan
  • • Pop: Mengambil data dari atas tumpukan
  • • Peek/Top: Melihat data teratas tanpa mengambil
  • • isEmpty: Mengecek apakah stack kosong

🛠️ Langkah 1: Membuat Class Stack

📄 File: stack_class.py 
01# Class Stack untuk Tumpukan Data
02
03class Stack:
04    def __init__(self):
05        self.items = []  # List untuk menyimpan data
06    
07    def push(self, item):
08        """Menambah item ke atas stack"""
09        self.items.append(item)
10        print(f"✅ '{item}' ditambahkan ke stack")
11    
12    def pop(self):
13        """Mengambil item dari atas stack"""
14        if self.is_empty():
15            print("❌ Stack kosong!")
16            return None
17        item = self.items.pop()
18        print(f"📤 '{item}' diambil dari stack")
19        return item
20    
21    def peek(self):
22        """Melihat item teratas tanpa mengambil"""
23        if self.is_empty():
24            return None
25        return self.items[-1]
26    
27    def is_empty(self):
28        """Mengecek apakah stack kosong"""
29        return len(self.items) == 0
30    
31    def size(self):
32        """Mengembalikan ukuran stack"""
33        return len(self.items)
34    
35    def display(self):
36        """Menampilkan isi stack"""
37        print("📚 Isi Stack (dari atas ke bawah):")
38        if self.is_empty():
39            print("   (kosong)")
40        else:
41            for i in range(len(self.items) - 1, -1, -1):
42                print(f"   {self.items[i]}")

03class SimpleEditor:

🚶‍♂️ Praktik Queue

Belajar Queue - Antrian Data FIFO

🤔 Apa itu Queue?

Queue adalah struktur data yang mengikuti prinsip FIFO (First In First Out). Seperti antrian di kasir - orang yang pertama datang akan dilayani pertama! 🏪

⚡ Operasi Utama Queue:

  • • Enqueue: Menambah data di belakang antrian
  • • Dequeue: Mengambil data dari depan antrian
  • • Front: Melihat data terdepan tanpa mengambil
  • • isEmpty: Mengecek apakah queue kosong

🛠️ Langkah 1: Membuat Class Queue

📄 File: queue_class.py 
01# Class Queue untuk Antrian Data
02
03class Queue:
04    def __init__(self):
05        self.items = []  # List untuk menyimpan data
06    
07    def enqueue(self, item):
08        """Menambah item ke belakang queue"""
09        self.items.append(item)
10        print(f"✅ '{item}' masuk antrian")
11    
12    def dequeue(self):
13        """Mengambil item dari depan queue"""
14        if self.is_empty():
15            print("❌ Antrian kosong!")
16            return None
17        item = self.items.pop(0)  # Ambil dari index 0 (depan)
18        print(f"🚶‍♂️ '{item}' keluar dari antrian")
19        return item
20    
21    def front(self):
22        """Melihat item terdepan tanpa mengambil"""
23        if self.is_empty():
24            return None
25        return self.items[0]
26    
27    def is_empty(self):
28        """Mengecek apakah queue kosong"""
29        return len(self.items) == 0
30    
31    def size(self):
32        """Mengembalikan ukuran queue"""
33        return len(self.items)
34    
35    def display(self):
36        """Menampilkan isi queue"""
37        print("🚶‍♂️ Antrian (dari depan ke belakang):")
38        if self.is_empty():
39            print("   (kosong)")
40        else:
41            for i, item in enumerate(self.items):
42                print(f"   {i+1}. {item}")

01# Sistem Antrian Printer Lab Komputer
02
03class PrinterQueue:
04    def __init__(self):
05        self.queue = Queue()
06        self.job_counter = 1
07    
08    def add_print_job(self, user, document, pages):
09        """Menambah job print ke antrian"""
10        job = {
11            'id': self.job_counter,
12            'user': user,
13            'document': document,
14            'pages': pages
15        }
16        self.queue.enqueue(job)
17        print(f"🖨️ Job #{self.job_counter} dari {user} ditambahkan")
18        self.job_counter += 1
19    
20    def process_job(self):
21        """Memproses job print"""
22        if self.queue.is_empty():
23            print("❌ Tidak ada job untuk diproses")
24            return
25        
26        job = self.queue.dequeue()
27        print(f"⚡ Memproses Job #{job['id']}:")
28        print(f"   User: {job['user']}")
29        print(f"   Dokumen: {job['document']}")
30        print(f"   Halaman: {job['pages']}")
31        print("✅ Selesai diprint!")
32    
33    def show_queue(self):
34        """Menampilkan antrian print"""
35        print(f"\n📋 Antrian Print ({self.queue.size()} job):")
36        if self.queue.is_empty():
37            print("   (kosong)")
38        else:
39            for i, job in enumerate(self.queue.items):
40                print(f"   {i+1}. Job #{job['id']} - {job['user']} ({job['pages']} hal)")
41
