Pengenalan Struktur Data

🤖 Apa itu Struktur Data?

Struktur data adalah cara mengorganisir dan menyimpan data dalam komputer sehingga dapat digunakan secara efisien. Bayangkan seperti lemari pakaian - ada yang digantung, ada yang dilipat di laci, semua punya tempatnya!

📝

List

Seperti daftar belanja

Akses: O(1), Pencarian: O(n)
📚

Stack

Seperti tumpukan buku

Push/Pop: O(1)
🚶‍♂️

Queue

Seperti antrian bank

Enqueue/Dequeue: O(1)

⚡ Big O Notation - Kompleksitas Waktu

Big O menggambarkan seberapa cepat algoritma berjalan seiring bertambahnya data:

O(1)

Konstan

Waktu tetap, tidak peduli ukuran data

Akses array berdasarkan index
O(n)

Linear

Waktu bertambah seiring data

Mencari item dalam list
O(n²)

Kuadratik

Waktu bertambah eksponensial

Bubble sort algorithm

List (Daftar)

📋 Apa itu List?

List adalah struktur data yang menyimpan elemen-elemen secara berurutan. Seperti daftar belanja, setiap item memiliki posisi tertentu dan bisa diakses kapan saja!

Contoh List Sederhana:

0: Apel 🍎
1: Pisang 🍌
2: Jeruk 🍊
3: Anggur 🍇

⚡ Operasi pada List

➕ Menambah (Insert)

Menambahkan elemen baru ke posisi tertentu

❌ Menghapus (Delete)

Menghapus elemen dari posisi tertentu

🔍 Mencari (Search)

Mencari elemen dalam list

📍 Akses (Access)

Mengakses elemen berdasarkan indeks

💻 Contoh Kode List

// Python - Membuat dan menggunakan List
my_list = ["apel", "pisang", "jeruk"]

# Menambah item
my_list.append("anggur")        # ["apel", "pisang", "jeruk", "anggur"]

# Mengakses item berdasarkan index
print(my_list[0])               # Output: "apel"

# Menghapus item
my_list.remove("pisang")        # ["apel", "jeruk", "anggur"]

# Mencari item
if "jeruk" in my_list:
    print("Jeruk ditemukan!")   # Output: "Jeruk ditemukan!"

🔍 Jenis-jenis List

📋 Array (Static)

Ukuran tetap, akses cepat

Keunggulan: Akses O(1)
Kelemahan: Ukuran tidak bisa berubah

🔗 Linked List

Ukuran dinamis, fleksibel

Keunggulan: Ukuran dinamis
Kelemahan: Akses O(n)

Stack (Tumpukan)

📚 Apa itu Stack?

Stack adalah struktur data yang mengikuti prinsip LIFO (Last In, First Out). Seperti tumpukan buku - buku yang terakhir ditaruh akan diambil pertama kali!

Prinsip LIFO:

Buku C (Terakhir masuk)
Buku B
Buku A (Pertama masuk)

↑ Yang diambil pertama (Pop)

⚡ Operasi pada Stack

📥 Push

Menambahkan elemen ke puncak stack

📤 Pop

Mengeluarkan elemen dari puncak stack

👀 Peek/Top

Melihat elemen puncak tanpa mengeluarkannya

❓ isEmpty

Mengecek apakah stack kosong

Pemanggilan fungsi dalam program

Queue (Antrian)

🚶‍♂️ Apa itu Queue?

Queue adalah struktur data yang mengikuti prinsip FIFO (First In, First Out). Seperti antrian di bank - yang datang pertama akan dilayani pertama!

Prinsip FIFO:

Keluar →
A
B
C
← Masuk

A masuk pertama, A keluar pertama

⚡ Operasi pada Queue

📥 Enqueue

Menambahkan elemen ke belakang queue

📤 Dequeue

Mengeluarkan elemen dari depan queue

👀 Front

Melihat elemen depan tanpa mengeluarkannya

❓ isEmpty

Mengecek apakah queue kosong

🎮 Demo Interaktif Queue

← KELUAR
