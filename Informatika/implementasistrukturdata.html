List (Daftar)

🎯 Apa itu List?

List adalah struktur data yang menyimpan elemen-elemen secara berurutan. Seperti daftar belanja, setiap item memiliki posisi tertentu dan bisa diakses kapan saja!

Contoh List Daftar Belanja:

1. Beras 2. Telur 3. Susu 4. Roti

✨ Karakteristik List

  • 📍 Memiliki urutan/indeks
  • 🔄 Bisa diubah (mutable)
  • 📏 Panjang bisa berubah
  • 🎯 Akses langsung ke elemen
  • ➕ Bisa menambah elemen
  • ➖ Bisa menghapus elemen

Stack (Tumpukan)

🎯 Apa itu Stack?

Stack adalah struktur data yang mengikuti prinsip LIFO (Last In, First Out). Seperti tumpukan piring - piring yang terakhir ditaruh akan yang pertama diambil!

Prinsip LIFO:

🍽️

Piring teratas → Diambil pertama

Last In, First Out

🔧 Operasi Stack

📥 PUSH

Menambahkan elemen ke atas tumpukan

Seperti menambah piring ke tumpukan

📤 POP

Mengambil elemen dari atas tumpukan

Seperti mengambil piring teratas

Queue (Antrian)

🎯 Apa itu Queue?

Queue adalah struktur data yang mengikuti prinsip FIFO (First In, First Out). Seperti antrian di kasir - yang pertama datang akan dilayani pertama!

Prinsip FIFO:

🏪

Orang pertama → Dilayani pertama

First In, First Out

🔧 Operasi Queue

📥 ENQUEUE

Menambahkan elemen ke belakang antrian

Seperti bergabung di akhir antrian

📤 DEQUEUE

Mengambil elemen dari depan antrian

Seperti melayani orang pertama

Tugas Pembelajaran

📝 Soal 1: Analisis List

Jelaskan perbedaan antara List dengan Array biasa! Berikan contoh penggunaan List dalam kehidupan sehari-hari dan bagaimana operasi penambahan/penghapusan elemen bekerja.

📚 Soal 2: Implementasi Stack

Buatlah skenario penggunaan Stack dalam aplikasi text editor untuk fitur Undo/Redo. Jelaskan bagaimana operasi PUSH dan POP bekerja dalam konteks ini, serta berikan contoh langkah-langkahnya!

🚶‍♂️ Soal 3: Analisis Queue

Bandingkan penggunaan Queue dengan Stack! Kapan kita harus menggunakan Queue dan kapan menggunakan Stack? Berikan 3 contoh nyata penggunaan Queue dalam sistem komputer.

🎯 Soal 4: Studi Kasus

Anda diminta membuat sistem antrian untuk rumah sakit. Pasien yang datang lebih dulu harus dilayani lebih dulu, kecuali ada pasien emergency. Struktur data apa yang akan Anda gunakan dan bagaimana implementasinya?

💡 Soal 5: Kreativitas

Buatlah ide aplikasi sederhana yang menggunakan ketiga struktur data (List, Stack, Queue) sekaligus! Jelaskan fungsi masing-masing struktur data dalam aplikasi tersebut.

📋 Petunjuk Pengerjaan

• Jawab semua soal dengan lengkap dan jelas

• Gunakan bahasa yang mudah dipahami

• Berikan contoh konkret untuk memperjelas jawaban

• Kerjakan secara mandiri dan jujur
