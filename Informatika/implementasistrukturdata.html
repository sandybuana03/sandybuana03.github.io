List (Daftar)

📋 Apa itu List?

List adalah struktur data yang menyimpan elemen-elemen secara berurutan. Seperti daftar belanja, setiap item memiliki posisi tertentu dan bisa diakses kapan saja!

Contoh List Sederhana:

0: Apel 🍎
1: Pisang 🍌
2: Jeruk 🍊
3: Anggur 🍇

⚡ Operasi pada List

➕ Menambah (Insert)

Menambahkan elemen baru ke posisi tertentu

❌ Menghapus (Delete)

Menghapus elemen dari posisi tertentu

🔍 Mencari (Search)

Mencari elemen dalam list

📍 Akses (Access)

Mengakses elemen berdasarkan indeks

💻 Contoh Kode List

// Python - Membuat dan menggunakan List
my_list = ["apel", "pisang", "jeruk"]

# Menambah item
my_list.append("anggur")        # ["apel", "pisang", "jeruk", "anggur"]

# Mengakses item berdasarkan index
print(my_list[0])               # Output: "apel"

# Menghapus item
my_list.remove("pisang")        # ["apel", "jeruk", "anggur"]

# Mencari item
if "jeruk" in my_list:
    print("Jeruk ditemukan!")   # Output: "Jeruk ditemukan!"

🔍 Jenis-jenis List

📋 Array (Static)

Ukuran tetap, akses cepat

Keunggulan: Akses O(1), Cache-friendly
Kelemahan: Ukuran tidak bisa berubah
Contoh: int arr[100] dalam C/C++
💡 Cocok untuk data dengan ukuran yang sudah diketahui

🔗 Linked List

Ukuran dinamis, fleksibel

Keunggulan: Ukuran dinamis, Insert/Delete O(1)
Kelemahan: Akses O(n), Extra memory
Contoh: std::list dalam C++
💡 Cocok untuk data yang sering berubah ukuran

📊 Dynamic Array

Kombinasi array dan fleksibilitas

Keunggulan: Akses O(1), Ukuran dinamis
Kelemahan: Resize operation mahal
Contoh: ArrayList (Java), list (Python)
💡 Paling populer dalam pemrograman modern

🔄 Doubly Linked List

Linked list dengan pointer dua arah

Keunggulan: Traversal dua arah
Kelemahan: Memory overhead lebih besar
Contoh: std::deque dalam C++
💡 Cocok untuk navigasi maju-mundur

🎯 Perbandingan Kompleksitas Waktu

Operasi Array Dynamic Array Linked List
Access O(1) O(1) O(n)
Insert (End) N/A O(1)* O(1)
Insert (Middle) N/A O(n) O(1)
Delete N/A O(n) O(1)

* Amortized time complexity

Stack (Tumpukan)

📚 Apa itu Stack?

Stack adalah struktur data yang mengikuti prinsip LIFO (Last In, First Out). Seperti tumpukan buku - buku yang terakhir ditaruh akan diambil pertama kali!

Prinsip LIFO:

Buku C (Terakhir masuk)
Buku B
Buku A (Pertama masuk)

↑ Yang diambil pertama (Pop)

⚡ Operasi pada Stack

📥 Push

Menambahkan elemen ke puncak stack

📤 Pop

Mengeluarkan elemen dari puncak stack

👀 Peek/Top

Melihat elemen puncak tanpa mengeluarkannya

❓ isEmpty

Mengecek apakah stack kosong

🏗️ Implementasi Stack

📋 Array-based Stack

class ArrayStack:
    def __init__(self, size):
        self.stack = [None] * size
        self.top = -1
        self.size = size
    
    def push(self, item):
        if self.top < self.size - 1:
            self.top += 1
            self.stack[self.top] = item
        else:
            raise Exception("Stack Overflow")
    
    def pop(self):
        if self.top >= 0:
            item = self.stack[self.top]
            self.top -= 1
            return item
        else:
            raise Exception("Stack Underflow")
Keunggulan: Memory efficient, fast access
Kelemahan: Fixed size, stack overflow risk

🔗 Linked List Stack

class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

class LinkedStack:
    def __init__(self):
        self.head = None
    
    def push(self, item):
        new_node = Node(item)
        new_node.next = self.head
        self.head = new_node
    
    def pop(self):
        if self.head:
            item = self.head.data
            self.head = self.head.next
            return item
        else:
            raise Exception("Stack Underflow")
Keunggulan: Dynamic size, no overflow
Kelemahan: Extra memory for pointers

🧮 Contoh: Evaluasi Ekspresi Matematika

Infix ke Postfix (Shunting Yard)

Mengubah ekspresi seperti "3 + 4 * 2" menjadi "3 4 2 * +"

def infix_to_postfix(expression):
    precedence = {'+': 1, '-': 1, '*': 2, '/': 2, '^': 3}
    stack = []
    result = []
    
    for char in expression:
        if char.isalnum():  # Operand
            result.append(char)
        elif char == '(':
            stack.append(char)
        elif char == ')':
            while stack and stack[-1] != '(':
                result.append(stack.pop())
            stack.pop()  # Remove '('
        else:  # Operator
            while (stack and stack[-1] != '(' and
                   precedence.get(stack[-1], 0) >= precedence[char]):
                result.append(stack.pop())
            stack.append(char)
    
    while stack:
        result.append(stack.pop())
    
    return ''.join(result)

Evaluasi Postfix

def evaluate_postfix(expression):
    stack = []
    
    for char in expression:
        if char.isdigit():
            stack.append(int(char))
        else:  # Operator
            b = stack.pop()
            a = stack.pop()
            
            if char == '+':
                stack.append(a + b)
            elif char == '-':
                stack.append(a - b)
            elif char == '*':
                stack.append(a * b)
            elif char == '/':
                stack.append(a / b)
    
    return stack[0]

# Contoh: "342*+" = 3 + (4 * 2) = 11

🐛 Stack Overflow

def recursive_function(n):
    print(f"Call {n}")
    recursive_function(n + 1)  # No base case!

# Hasil: Stack Overflow
# Call 1
# Call 2
# Call 3
# ...
# RecursionError: maximum recursion depth exceeded

💡 Tips Debugging dengan Stack

  • • Baca stack trace dari atas ke bawah untuk menemukan error
  • • Function teratas adalah lokasi error terjadi
  • • Function terbawah adalah entry point program
  • • Stack overflow biasanya disebabkan infinite recursion

Queue (Antrian)

🚶‍♂️ Apa itu Queue?

Queue adalah struktur data yang mengikuti prinsip FIFO (First In, First Out). Seperti antrian di bank - yang datang pertama akan dilayani pertama!

Prinsip FIFO:

Keluar →
A
B
C
← Masuk

A masuk pertama, A keluar pertama

📤 Dequeue

Mengeluarkan elemen dari depan queue

👀 Front

Melihat elemen depan tanpa mengeluarkannya

Contoh: Antrian bank, print queue

⭐ Priority Queue

Queue dengan prioritas

Operasi: Insert dengan prioritas
Kompleksitas: O(log n) insert, O(1) extract
Contoh: Emergency room, OS scheduling

🔄 Circular Queue

Queue melingkar untuk efisiensi memori

Keunggulan: Memory efficient, no shifting

Queue yang bisa insert/delete dari kedua ujung

Operasi: Push/pop front & rear
Fleksibilitas: Bisa jadi stack atau queue
Contoh: Browser history, undo/redo

🏗️ Implementasi Queue

📋 Array-based Queue

class ArrayQueue:
    def __init__(self, size):
        self.queue = [None] * size
        self.front = 0
        self.rear = -1
        self.size = size
        self.count = 0
    
    def enqueue(self, item):
        if self.count < self.size:
            self.rear = (self.rear + 1) % self.size
            self.queue[self.rear] = item
            self.count += 1
        else:
            raise Exception("Queue Full")
    
    def dequeue(self):
        if self.count > 0:
            item = self.queue[self.front]
            self.front = (self.front + 1) % self.size
            self.count -= 1
            return item
        else:
            raise Exception("Queue Empty")
Keunggulan: Memory efficient, O(1) operations
Kelemahan: Fixed size

🔗 Linked List Queue

class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

class LinkedQueue:
    def __init__(self):
        self.front = None
        self.rear = None
    
    def enqueue(self, item):
        new_node = Node(item)
        if self.rear:
            self.rear.next = new_node
        else:
            self.front = new_node
        self.rear = new_node
    
    def dequeue(self):
        if self.front:
            item = self.front.data
            self.front = self.front.next
            if not self.front:
                self.rear = None
            return item
        else:
            raise Exception("Queue Empty")
Keunggulan: Dynamic size, no overflow
Kelemahan: Extra memory for pointers

⭐ Priority Queue dalam Aksi

🏥 Sistem Emergency Room

import heapq

class Patient:
    def __init__(self, name, priority):
        self.name = name
        self.priority = priority
    
    def __lt__(self, other):
        return self.priority < other.priority  # Lower number = higher priority

class EmergencyRoom:
    def __init__(self):
        self.queue = []
    
    def admit_patient(self, name, priority):
        patient = Patient(name, priority)
        heapq.heappush(self.queue, patient)
        print(f"{name} admitted with priority {priority}")
    
    def treat_next(self):
        if self.queue:
            patient = heapq.heappop(self.queue)
            print(f"Treating {patient.name} (priority {patient.priority})")
            return patient
        else:
            print("No patients waiting")

# Contoh penggunaan:
er = EmergencyRoom()
er.admit_patient("John", 3)      # Non-urgent
er.admit_patient("Alice", 1)     # Critical
er.admit_patient("Bob", 2)       # Urgent
er.treat_next()  # Alice (priority 1) treated first

💡 Keunggulan Priority Queue

  • • Elemen dengan prioritas tinggi dilayani lebih dulu
  • • Cocok untuk sistem real-time dan critical applications
  • • Implementasi menggunakan heap untuk efisiensi O(log n)
  • • Banyak digunakan dalam algoritma graph (Dijkstra, A*)
