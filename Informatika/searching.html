Pengenalan Algoritma Pencarian

🤓 Apa itu Algoritma Pencarian?

Algoritma pencarian adalah langkah-langkah sistematis untuk menemukan data tertentu dalam kumpulan data. Bayangkan kamu punya kotak berisi 100 kartu nama, dan kamu ingin mencari kartu dengan nama "Budi". Algoritma pencarian akan memberitahu kamu cara tercepat untuk menemukannya!

🎯 Jenis-jenis Algoritma Pencarian

Linear Search (Sequential Search)

Mencari data dengan memeriksa setiap elemen satu per satu secara berurutan dari awal hingga akhir array

Sederhana Data tidak perlu urut O(n)

Binary Search (Pencarian Biner)

Mencari data dengan membagi array menjadi dua bagian dan memilih bagian yang mungkin berisi target

Sangat cepat Data harus urut O(log n)
📝

Linear Search (Pencarian Berurutan)

🔍 Apa itu Linear Search?

Linear Search adalah algoritma pencarian paling sederhana. Cara kerjanya seperti mencari kunci yang hilang dengan memeriksa satu per satu dari tempat pertama sampai ketemu atau sampai semua tempat sudah diperiksa.

Analogi Sederhana:

Seperti mencari nama teman di daftar kelas. Kamu baca nama pertama, kalau bukan yang dicari, lanjut ke nama kedua, ketiga, dan seterusnya sampai ketemu atau sampai habis.

⚙️ Cara Kerja Linear Search

1

Mulai dari elemen pertama (indeks 0)

2

Bandingkan dengan data yang dicari

3

Jika sama, data ditemukan! Jika tidak, lanjut ke elemen berikutnya

4

Ulangi sampai data ketemu atau sampai akhir array

⚡ Analisis Linear Search

✅ Kelebihan

  • • Sederhana dan mudah dipahami
  • • Tidak perlu data yang sudah diurutkan
  • • Cocok untuk data kecil (< 100 elemen)
  • • Mudah diimplementasikan (hanya butuh loop)
  • • Bekerja pada semua jenis struktur data
  • • Tidak memerlukan memori tambahan (O(1) space)

❌ Kekurangan

  • • Lambat untuk data besar (O(n) time complexity)
  • • Worst case: harus memeriksa semua elemen
  • • Tidak efisien untuk pencarian berulang
  • • Tidak memanfaatkan struktur data yang terurut
  • • Performance menurun linear dengan ukuran data

Binary Search (Pencarian Biner)

🎯 Apa itu Binary Search?

Binary Search adalah algoritma pencarian yang sangat efisien dengan kompleksitas O(log n). Algoritma ini hanya dapat digunakan pada data yang sudah diurutkan (ascending atau descending). Prinsip kerjanya adalah "divide and conquer" - membagi masalah menjadi bagian yang lebih kecil.

Analogi Sederhana:

Seperti mencari kata di kamus atau permainan tebak angka. Kamu tidak mulai dari halaman 1, tapi langsung buka di tengah. Jika kata yang dicari ada di bagian awal (secara alfabetis), fokus ke setengah bagian kiri. Jika di bagian akhir, fokus ke setengah bagian kanan. Proses ini diulang sampai kata ditemukan atau area pencarian habis.

⚙️ Cara Kerja Binary Search

1

Tentukan elemen tengah dari array

2

Bandingkan dengan data yang dicari

3

Jika sama, data ditemukan!

4

Jika lebih kecil, cari di bagian kiri. Jika lebih besar, cari di bagian kanan

5

Ulangi proses sampai data ketemu atau tidak ada lagi yang bisa dicari

⚡ Analisis Binary Search

✅ Kelebihan

  • • Sangat cepat untuk data besar (O(log n))
  • • Efisiensi tidak menurun drastis dengan ukuran data
  • • Cocok untuk pencarian berulang pada data statis
  • • Mengurangi area pencarian 50% setiap langkah
  • • Optimal untuk database dan sistem besar
  • • Predictable performance (selalu log n)

❌ Kekurangan

  • • Data harus sudah diurutkan (preprocessing)
  • • Lebih kompleks untuk dipahami dan implement
  • • Overhead sorting jika data sering berubah
  • • Tidak cocok untuk data yang dinamis
  • • Memerlukan random access (tidak cocok untuk linked list)

🎯 Kapan Menggunakan Yang Mana?

Gunakan Linear Search Jika:

  • ✅ Data tidak banyak (< 100 elemen)
  • ✅ Data tidak perlu diurutkan
  • ✅ Pencarian jarang dilakukan
  • ✅ Ingin implementasi yang sederhana
  • ✅ Data sering berubah/ditambah

Gunakan Binary Search Jika:

  • ✅ Data banyak (> 100 elemen)
  • ✅ Data sudah diurutkan atau bisa diurutkan
  • ✅ Pencarian sering dilakukan
  • ✅ Kecepatan sangat penting
  • ✅ Data jarang berubah

💡 Contoh Penerapan di Dunia Nyata

📱

Kontak HP (Pencarian Nama)

Linear Search - Kontak tidak selalu urut alfabetis, sering ditambah/dihapus, dan jumlahnya relatif sedikit

📖

Kamus Fisik

Binary Search - Kata sudah diurutkan alfabetis, data statis, dan jumlahnya sangat banyak

🏦

Database Bank (Cari Rekening)

Binary Search - Nomor rekening diurutkan, data besar (jutaan), pencarian sering dilakukan

📚

Perpustakaan (Cari Buku)

Kombinasi - Linear untuk pencarian judul (tidak urut), Binary untuk pencarian berdasarkan kode buku (urut)

🛒

E-commerce (Cari Produk)

Hybrid - Menggunakan indexing dan algoritma pencarian canggih untuk berbagai kriteria pencarian
