🎯 Pengenalan Algoritma Pencarian

🤖 Apa itu Algoritma Pencarian?

Algoritma pencarian adalah serangkaian langkah sistematis dan terstruktur untuk menemukan data atau informasi tertentu dalam kumpulan data yang lebih besar. Ini adalah salah satu konsep fundamental dalam ilmu komputer yang digunakan hampir di setiap aplikasi digital.

🎯 Analogi Perpustakaan:

Bayangkan kamu mencari buku "Harry Potter" di perpustakaan besar dengan 10.000 buku. Kamu bisa mencari secara acak (tidak efisien) atau menggunakan sistem katalog yang terorganisir (efisien). Itulah perbedaan algoritma pencarian!

🎮 Analogi Game:

Seperti bermain "tebak angka 1-100". Kamu bisa menebak secara acak (1, 2, 3...) atau menggunakan strategi cerdas (mulai dari 50, lalu 25 atau 75). Strategi cerdas inilah yang disebut algoritma!

💡 Definisi Formal:

Algoritma Pencarian adalah prosedur komputasi yang mengambil input berupa kumpulan data dan nilai yang dicari, kemudian menghasilkan output berupa lokasi/posisi data tersebut atau informasi bahwa data tidak ditemukan.

🌟 Mengapa Algoritma Pencarian Sangat Penting?

🔍 Jenis-jenis Pencarian dalam Kehidupan

🎯 Pencarian Eksak (Exact Search)

Mencari data yang persis sama dengan yang dicari.

• Mencari nomor telepon tertentu

• Mencari ID siswa di database

• Mencari kata kunci spesifik

🌊 Pencarian Fuzzy (Fuzzy Search)

Mencari data yang mirip atau mendekati yang dicari.

• "Apel" → "Apple" (koreksi otomatis)

• Pencarian nama dengan ejaan berbeda

• Rekomendasi produk serupa

📖 Materi: Jenis-Jenis Algoritma Pencarian

🔍 Linear Search (Pencarian Berurutan)

🤔 Apa itu Linear Search?

Linear Search adalah algoritma pencarian paling sederhana yang bekerja dengan cara memeriksa setiap elemen dalam array satu per satu, dimulai dari elemen pertama hingga elemen yang dicari ditemukan atau sampai akhir array.

🏠 Analogi Kehidupan Sehari-hari:

Bayangkan kamu mencari kunci di dalam tas. Kamu akan mengeluarkan barang satu per satu dari tas sampai menemukan kunci tersebut. Itulah cara kerja Linear Search!

📝 Langkah-langkah Detail:

  1. 1 Mulai dari elemen pertama (index 0)
  2. 2 Bandingkan dengan elemen yang dicari
  3. 3 Jika sama, kembalikan posisi/index
  4. 4 Jika tidak sama, lanjut ke elemen berikutnya
  5. 5 Ulangi sampai ditemukan atau array habis

⚡ Karakteristik:

✅ Sederhana dan mudah dipahami
✅ Bisa untuk data tidak terurut
✅ Tidak perlu preprocessing
❌ Lambat untuk data besar
🕐 Kompleksitas waktu: O(n)

👍 Kelebihan Linear Search
  • • Mudah dipahami dan diimplementasikan
  • • Bekerja pada data terurut maupun tidak terurut
  • • Tidak memerlukan memori tambahan
  • • Cocok untuk dataset kecil
👎 Kekurangan Linear Search
  • • Lambat untuk dataset besar
  • • Tidak efisien jika data sudah terurut
  • • Worst case: harus cek semua elemen
  • • Kompleksitas waktu O(n)

⚡ Binary Search (Pencarian Biner)

🤔 Apa itu Binary Search?

Binary Search adalah algoritma pencarian yang sangat efisien untuk data yang sudah terurut. Algoritma ini bekerja dengan cara membagi array menjadi dua bagian dan menentukan di bagian mana elemen yang dicari berada, kemudian mengulangi proses ini hingga elemen ditemukan.

🎯 Analogi Kehidupan Sehari-hari:

Seperti bermain tebak angka 1-100. Kamu mulai dengan angka 50. Jika terlalu besar, coba 25. Jika terlalu kecil, coba 75. Dengan cara ini, kamu bisa menemukan angka dengan cepat!

📚 Analogi Kamus:

Ketika mencari kata di kamus, kamu tidak mulai dari halaman 1. Kamu buka di tengah, lalu tentukan apakah kata yang dicari ada di bagian kiri atau kanan, kemudian ulangi proses ini. Itulah Binary Search!

📝 Langkah-langkah Detail:

  1. 1 Pastikan data sudah terurut
  2. 2 Tentukan batas kiri (left) dan kanan (right)
  3. 3 Hitung posisi tengah: mid = (left + right) / 2
  4. 4 Bandingkan elemen tengah dengan target
  5. 5 Jika sama: ditemukan! Jika lebih besar: cari di kiri. Jika lebih kecil: cari di kanan
  6. 6 Ulangi sampai ditemukan atau left > right

⚡ Karakteristik:

✅ Sangat cepat untuk data besar
✅ Efisien dalam penggunaan waktu
✅ Kompleksitas logaritmik
❌ Data harus terurut terlebih dahulu
🕐 Kompleksitas waktu: O(log n)

  • • Sangat cepat untuk dataset besar

  • • Tidak cocok untuk data yang sering berubah
  • • Lebih kompleks untuk dipahami
  • • Memerlukan akses random ke elemen
