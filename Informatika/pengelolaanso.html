Pengelolaan Memori

💭 Apa itu Memori?

Memori komputer seperti meja kerja kamu. Semakin besar meja, semakin banyak buku dan alat tulis yang bisa kamu letakkan untuk bekerja. RAM (Random Access Memory) adalah "meja kerja" komputer tempat program-program bekerja.

🎯 Simulasi Memori

Memori Terpakai

🏗️ Jenis-jenis Memori

⚡ Memori Utama (RAM)

  • • Menyimpan program yang sedang berjalan
  • • Akses sangat cepat
  • • Data hilang saat komputer mati
  • • Contoh: DDR4, DDR5

💾 Memori Sekunder

  • • Menyimpan data permanen
  • • Akses lebih lambat dari RAM
  • • Data tetap ada saat komputer mati
  • • Contoh: HDD, SSD, Flash Drive

🎯 Teknik Pengelolaan Memori

📦 Partisi Memori

Membagi memori menjadi bagian-bagian untuk program yang berbeda, seperti membagi meja kerja menjadi beberapa area.

🔄 Virtual Memory

Menggunakan hard disk sebagai perpanjangan RAM ketika RAM penuh, seperti menggunakan laci meja saat meja kerja penuh.

📄 Paging

Membagi program menjadi halaman-halaman kecil yang bisa dipindah-pindah antara RAM dan hard disk.

⚙️

Pengelolaan Proses

🔄 Apa itu Proses?

Proses adalah program yang sedang berjalan di komputer. Bayangkan seperti chef di dapur - setiap chef (proses) sedang memasak hidangan (menjalankan tugas) yang berbeda secara bersamaan.

🔴

🎯 Algoritma Penjadwalan

🥇 First Come First Served (FCFS)

Proses yang datang pertama akan dilayani pertama, seperti antrian di kasir.

⏱️ Shortest Job First (SJF)

Proses dengan waktu eksekusi terpendek akan dijalankan terlebih dahulu.

🔄 Round Robin

Setiap proses mendapat jatah waktu yang sama secara bergiliran.

Antarmuka Kernel Hardware

🧠 Apa itu Kernel?

Kernel adalah inti dari sistem operasi, seperti jantung dalam tubuh manusia. Kernel menghubungkan software dengan hardware, mengatur semua komunikasi antara program dan perangkat keras komputer.

👤 User Applications

🔧 System Calls

🔗 Device Drivers

Device driver adalah penerjemah antara sistem operasi dan hardware. Seperti penerjemah bahasa, driver menerjemahkan perintah dari OS ke bahasa yang dimengerti oleh hardware.

📱 Contoh Driver:

  • • Driver USB

⚡ Fungsi Driver:

  • • Mengontrol hardware
  • • Menangani interrupt
  • • Optimasi performa

Interaksi dengan Pengguna

🎭 User Interface (UI)

User Interface adalah cara pengguna berinteraksi dengan komputer. Seperti dashboard mobil yang memungkinkan pengemudi mengontrol mobil, UI memungkinkan user mengontrol komputer.

💻 GUI (Graphical User Interface)

  • • Menggunakan gambar dan ikon
  • • Interaksi dengan mouse dan keyboard
  • • Mudah dipelajari pemula
  • • Contoh: Windows, macOS

⌨️ CLI (Command Line Interface)

  • • Menggunakan perintah teks
  • • Interaksi dengan keyboard saja
  • • Lebih cepat untuk expert
  • • Contoh: Terminal, Command Prompt

Tugas Pembelajaran

Jawablah pertanyaan-pertanyaan berikut dengan lengkap!

📋 Soal Essay

1. Pengelolaan Memori (20 poin)

Jelaskan perbedaan antara memori utama (RAM) dan memori sekunder (Storage). Berikan contoh penggunaan masing-masing dalam kehidupan sehari-hari dan mengapa keduanya penting dalam sistem komputer!

2. Manajemen Proses (20 poin)

Bayangkan kamu sedang menggunakan komputer untuk mengerjakan tugas. Kamu membuka browser, text editor, dan music player secara bersamaan. Jelaskan bagaimana sistem operasi mengelola ketiga proses tersebut agar bisa berjalan bersamaan!

3. Antarmuka Kernel (20 poin)

Mengapa kernel disebut sebagai "jantung" sistem operasi? Jelaskan peran kernel dalam menghubungkan software dengan hardware, dan berikan contoh konkret ketika kamu menyimpan file di komputer!

4. User Interface (20 poin)

Bandingkan kelebihan dan kekurangan antara GUI (Graphical User Interface) dan CLI (Command Line Interface). Dalam situasi apa sebaiknya menggunakan GUI dan kapan sebaiknya menggunakan CLI?

5. Utilitas Sistem (20 poin)

Sebutkan dan jelaskan 5 utilitas sistem yang sering kamu gunakan di komputer/laptop. Untuk setiap utilitas, jelaskan fungsinya dan mengapa utilitas tersebut penting untuk menjaga performa komputer!
