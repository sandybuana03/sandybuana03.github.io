🫧 Bubble Sort (Pengurutan Gelembung)

🫧

💡 Konsep Dasar

Bubble Sort bekerja seperti gelembung udara yang naik ke permukaan air. Elemen terbesar akan "menggelembung" ke posisi terakhir melalui pertukaran berulang dengan elemen di sebelahnya.

🎯 Cara Kerja:

  1. Bandingkan dua elemen yang bersebelahan
  2. Jika elemen kiri lebih besar dari kanan, tukar posisinya
  3. Lanjutkan sampai akhir array
  4. Ulangi proses untuk putaran berikutnya

💻 Kode Program

function bubbleSort(arr) {
    let n = arr.length;
    
    // Loop untuk setiap putaran
    for (let i = 0; i < n - 1; i++) {
        
        // Loop untuk membandingkan elemen
        for (let j = 0; j < n - i - 1; j++) {
            
            // Jika elemen kiri > kanan, tukar
            if (arr[j] > arr[j + 1]) {
                // Tukar posisi
                let temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
    
    return arr;
}

✅ Kelebihan

  • 🎯 Mudah dipahami dan diimplementasi
  • 🔍 Dapat mendeteksi array yang sudah terurut
  • 💾 Tidak memerlukan memori tambahan
  • 🔄 Algoritma stabil

❌ Kekurangan

  • 🐌 Lambat untuk data besar
  • ⏱️ Kompleksitas waktu O(n²)
  • 🔄 Banyak pertukaran yang tidak perlu
  • 📊 Tidak efisien untuk data acak

📝 Insertion Sort (Pengurutan Sisipan)

📝

💡 Konsep Dasar

Insertion Sort bekerja seperti cara kita menyusun kartu di tangan. Kita mengambil satu kartu, lalu menyisipkannya di posisi yang tepat di antara kartu-kartu yang sudah tersusun.

🎯 Cara Kerja:

  1. Mulai dari elemen kedua (indeks 1)
  2. Bandingkan dengan elemen-elemen sebelumnya
  3. Geser elemen yang lebih besar ke kanan
  4. Sisipkan elemen di posisi yang tepat

💻 Kode Program

function insertionSort(arr) {
    let n = arr.length;
    
    // Mulai dari elemen kedua
    for (let i = 1; i < n; i++) {
        let key = arr[i];  // Elemen yang akan disisipkan
        let j = i - 1;     // Posisi elemen sebelumnya
        
        // Geser elemen yang lebih besar ke kanan
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j = j - 1;
        }
        
        // Sisipkan elemen di posisi yang tepat
        arr[j + 1] = key;
    }
    
    return arr;
}

Langkah 2

🎯 Kapan Menggunakan?

🫧 Gunakan Bubble Sort ketika:

  • • Belajar konsep pengurutan dasar
  • • Data sangat kecil (< 10 elemen)
  • • Ingin algoritma yang mudah dipahami
  • • Tidak peduli dengan efisiensi

📝 Gunakan Insertion Sort ketika:

  • • Data kecil hingga menengah (< 50 elemen)
  • • Data hampir terurut
  • • Ingin algoritma yang efisien untuk data kecil
  • • Membangun algoritma hybrid

🌍 Aplikasi di Dunia Nyata

🫧 Bubble Sort digunakan dalam:

  • 📚 Pembelajaran algoritma di universitas
  • 🎮 Game sederhana untuk mengurutkan skor
  • 🔧 Sistem embedded dengan memori terbatas
  • 📊 Visualisasi algoritma untuk edukasi

📝 Insertion Sort digunakan dalam:

  • ⚡ Hybrid sorting algorithms (Timsort, Introsort)
  • 📱 Aplikasi mobile dengan data kecil
  • 🎯 Online algorithms (data streaming)
  • 🔄 Preprocessing untuk algoritma lain

🏆 Kesimpulan

Insertion Sort umumnya lebih baik daripada Bubble Sort karena melakukan lebih sedikit pertukaran dan lebih efisien pada data yang hampir terurut. Namun, keduanya memiliki kompleksitas waktu yang sama (O(n²)) dan cocok untuk pembelajaran konsep dasar algoritma pengurutan.

💡 Poin Penting:

  • • Kedua algoritma adalah fondasi untuk memahami sorting yang lebih kompleks
  • • Insertion Sort lebih praktis untuk implementasi nyata
  • • Bubble Sort lebih mudah dipahami untuk pembelajaran
  • • Keduanya masih digunakan dalam konteks tertentu hingga saat ini
