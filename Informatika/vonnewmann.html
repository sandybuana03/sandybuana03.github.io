🎯 Apa itu Model von Neumann?

🏗️

Definisi Sederhana

Model von Neumann adalah arsitektur dasar komputer yang menjelaskan bagaimana komputer menyimpan dan memproses informasi. Ini seperti "blueprint" atau cetak biru yang diikuti oleh hampir semua komputer modern!

🏠
Seperti Rumah

Model von Neumann seperti denah rumah yang menunjukkan di mana letak kamar tidur, dapur, dan ruang tamu. Semua rumah punya ruangan ini!

📚
Seperti Resep

Seperti resep masakan yang diikuti semua chef untuk membuat hidangan yang sama, tapi dengan variasi masing-masing.

Arsitektur Dasar

🎯 Prinsip Utama Model von Neumann

🗄️

Stored Program Concept

Program dan data disimpan dalam memori yang sama. Ini berbeda dengan komputer lama yang programnya "hard-wired" (tidak bisa diubah).

🔄

Sequential Processing

Instruksi dijalankan satu per satu secara berurutan, kecuali ada perintah untuk melompat ke instruksi lain.

🔍 Perbedaan dengan Komputer Lama

❌ Komputer Lama (Pre-von Neumann)

  • • Program "hard-wired" (tidak bisa diubah)
  • • Hanya bisa menjalankan satu jenis tugas
  • • Sulit diprogram ulang
  • • Memori terpisah untuk program dan data

✅ Model von Neumann

  • • Program disimpan dalam memori
  • • Bisa menjalankan berbagai program
  • • Mudah diprogram ulang
  • • Memori bersama untuk program dan data

⚠️ Keterbatasan Model von Neumann

🚧 Von Neumann Bottleneck

Visualisasi Masalah:
🧠

🐌 Masalah Utama:
  • • Sequential Access: CPU harus menunggu data dari memori
  • • Shared Bus: Tidak bisa mengambil instruksi dan data bersamaan
  • • Speed Gap: CPU 1000x lebih cepat dari RAM
  • • Bandwidth Limit: Jalur data terbatas
💡 Solusi Modern:
  • • Cache Hierarchy: L1, L2, L3 cache
  • • Pipelining: Eksekusi paralel instruksi
  • • Superscalar: Multiple execution units
  • • Prefetching: Prediksi data yang dibutuhkan

🔄 Evolusi Arsitektur Komputer

🏛️ Von Neumann vs Harvard

Von Neumann
CPU ↔ Bus ↔ Memory
(Program + Data)
  • ✅ Sederhana dan fleksibel
  • ✅ Mudah diprogram
  • ❌ Ada bottleneck
Harvard
CPU ↔ Bus1 ↔ Program Memory
CPU ↔ Bus2 ↔ Data Memory
  • ✅ Lebih cepat (paralel)
  • ✅ Tidak ada bottleneck
  • ❌ Lebih kompleks

🚀 Arsitektur Modern

🔄 Pipelining

Eksekusi instruksi secara bertumpang tindih

⚡ Superscalar

Multiple execution units dalam satu CPU

🧠 Out-of-Order

Eksekusi instruksi tidak berurutan

🔮 Branch Prediction

Prediksi jalur eksekusi program

🌐 Multicore

Multiple CPU cores dalam satu chip

⚙️

Komponen Utama

🧠 CPU (Central Processing Unit)

⚙️

ALU (Arithmetic Logic Unit)

Bagian CPU yang melakukan perhitungan matematika dan operasi logika.

Contoh Operasi:

  • • Penjumlahan: 5 + 3 = 8
  • • Perbandingan: 10 > 5 = True
  • • Operasi AND, OR, NOT
🎮

Control Unit

Bagian CPU yang mengatur dan mengontrol semua operasi komputer.

Fungsi Utama:

  • • Mengambil instruksi dari memori
  • • Menerjemahkan instruksi
  • • Mengatur aliran data

📊 Register CPU Penting

PC - Program Counter
Menyimpan alamat instruksi yang akan dijalankan selanjutnya
IR - Instruction Register
Menyimpan instruksi yang sedang dijalankan
ACC - Accumulator
Menyimpan hasil perhitungan sementara dari ALU
MAR - Memory Address Register
Menyimpan alamat memori yang sedang diakses

Catatan: Selain register di atas, CPU modern memiliki banyak register lain seperti MDR (Memory Data Register), general-purpose registers, dan register khusus lainnya.

Cara Kerja Model von Neumann

🔄 Siklus Fetch-Decode-Execute

📥

1. FETCH

CPU mengambil instruksi dari memori berdasarkan alamat yang ada di Program Counter (PC).

🔍

2. DECODE

Control Unit menerjemahkan instruksi untuk menentukan operasi apa yang harus dilakukan.

⚡

3. EXECUTE

CPU menjalankan instruksi tersebut, bisa berupa perhitungan, penyimpanan, atau operasi lainnya.

🎯 Contoh Siklus Sederhana

1
FETCH:
Ambil instruksi "LOAD A" dari alamat 0001
2
DECODE:
Terjemahkan: "Muat data dari alamat A ke register"
3
EXECUTE:
Jalankan: Ambil data dari alamat A, simpan di register

📍 Program Counter (PC)

🎯 Apa itu Program Counter?

Program Counter adalah register khusus yang menyimpan alamat instruksi yang akan dijalankan selanjutnya.

Analogi:

Seperti bookmark di buku yang menandai halaman mana yang sedang kamu baca!

🔄 Cara Kerja PC

  1. 1. PC menunjuk ke alamat instruksi
  2. 2. CPU mengambil instruksi dari alamat tersebut
  3. 3. PC bertambah 1 (menunjuk instruksi berikutnya)
  4. 4. Ulangi proses

🚌 Sistem Bus

Bus adalah jalur komunikasi yang menghubungkan semua komponen komputer.

📍

Address Bus

Membawa informasi alamat memori yang akan diakses.

Lebar: 32-bit atau 64-bit
📦

Data Bus

Membawa data aktual yang akan dikirim atau diterima.

Lebar: 8, 16, 32, atau 64-bit
🎮

Control Bus

Membawa sinyal kontrol seperti READ, WRITE, CLOCK.

Sinyal: R/W, Clock, Reset, dll

🆚 Perbandingan Arsitektur

🏛️ Von Neumann
  • • Satu bus untuk instruksi dan data
  • • Memori bersama
  • • Lebih sederhana
  • • Ada bottleneck
  • • Contoh: PC, laptop
🎓 Harvard
  • • Bus terpisah untuk instruksi dan data
  • • Memori terpisah
  • • Lebih kompleks
  • • Lebih cepat
  • • Contoh: Mikrokontroler, DSP
