Pengenalan Interface Java

Apa itu Interface? 🤔

Interface dalam Java adalah seperti blueprint atau kontrak yang menentukan method apa saja yang harus dimiliki oleh sebuah class, tanpa memberikan implementasinya.

Analogi Sederhana:

Bayangkan Interface seperti SIM (Surat Izin Mengemudi). SIM menentukan bahwa pemegang SIM harus bisa mengemudi, tapi tidak menjelaskan bagaimana cara mengemudinya. Setiap orang bisa punya gaya mengemudi yang berbeda!

Karakteristik Interface 📋

  • ✅ Method dalam interface bersifat abstract secara default (kecuali default dan static method)
  • ✅ Semua variabel dalam interface bersifat public, static, final
  • ✅ Class yang mengimplementasi interface harus mengimplementasi semua abstract methodnya
  • ✅ Satu class bisa mengimplementasi multiple interface
  • ✅ Interface tidak bisa diinstansiasi langsung (tidak bisa new Interface())

Mengapa Menggunakan Interface? 🎯

🔧 Fleksibilitas

Memungkinkan multiple inheritance dan membuat kode lebih fleksibel

📏 Standarisasi

Memastikan class mengikuti "kontrak" yang telah ditentukan

🔄 Polymorphism

Memungkinkan penggunaan polymorphism dengan lebih baik

🧩 Modularitas

Membuat kode lebih modular dan mudah dikelola

Konsep Dasar Interface

Sintaks Dasar Interface 📝

// Cara membuat Interface
public interface NamaInterface {
    // Konstanta (otomatis public static final)
    int KONSTANTA = 100;
    
    // Method abstract (otomatis public abstract)
    void methodSatu();
    int methodDua(String parameter);
    
    // Sejak Java 8, bisa ada default method
    default void methodDefault() {
        System.out.println("Method default");
    }
}

💡 Catatan Penting:

  • • Keyword interface digunakan untuk membuat interface
  • • Semua method otomatis public abstract
  • • Semua variabel otomatis public static final
  • • Sejak Java 8, interface bisa memiliki default method dan static method

Implementasi Interface 🔧

// Interface
public interface Kendaraan {
    // Konstanta
    int KECEPATAN_MAKSIMAL = 200;
    
    // Abstract methods
    void nyalakan();
    void matikan();
    void bergerak();
    
    // Default method (Java 8+)
    default void info() {
        System.out.println("Ini adalah kendaraan");
    }
}

// Class yang mengimplementasi interface
public class Mobil implements Kendaraan {
    private String merk;
    
    public Mobil(String merk) {
        this.merk = merk;
    }
    
    @Override
    public void nyalakan() {
        System.out.println(merk + " dinyalakan dengan kunci");
    }
    
    @Override
    public void matikan() {
        System.out.println(merk + " dimatikan");
    }
    
    @Override
    public void bergerak() {
        System.out.println(merk + " bergerak dengan 4 roda");
    }
    
    // Bisa override default method jika perlu
    @Override
    public void info() {
        System.out.println("Ini adalah mobil " + merk);
    }
}

🔑 Keyword Penting:

  • • implements - untuk mengimplementasi interface
  • • @Override - menandai method yang di-override

Implementasi Interface

Contoh Lengkap: Sistem Hewan 🐾

// Interface untuk hewan
public interface Hewan {
    String JENIS = "Makhluk Hidup"; // konstanta
    
    void bersuara();
    void bergerak();
    void makan();
}

// Interface untuk hewan peliharaan
public interface HewanPeliharaan {
    void bermain();
    void dipelihara();
}

// Class Kucing mengimplementasi kedua interface
public class Kucing implements Hewan, HewanPeliharaan {
    private String nama;
    
    public Kucing(String nama) {
        this.nama = nama;
    }
    
    @Override
    public void bersuara() {
        System.out.println(nama + " berkata: Meow!");
    }
    
    @Override
    public void bergerak() {
        System.out.println(nama + " berjalan dengan anggun");
    }
    
    @Override
    public void makan() {
        System.out.println(nama + " makan ikan");
    }
    
    @Override
    public void bermain() {
        System.out.println(nama + " bermain dengan bola benang");
    }
    
    @Override
    public void dipelihara() {
        System.out.println(nama + " senang dipelihara manusia");
    }
}

Penggunaan dalam Main Method 🚀

public class Main {
    public static void main(String[] args) {
        // Membuat objek kucing
        Kucing kucingku = new Kucing("Mimi");
        
        // Menggunakan method dari interface Hewan
        kucingku.bersuara();
        kucingku.bergerak();
        kucingku.makan();
        
        // Menggunakan method dari interface HewanPeliharaan
        kucingku.bermain();
        kucingku.dipelihara();
        
        // Polymorphism dengan interface
        Hewan hewan = new Kucing("Fluffy");
        hewan.bersuara(); // Tetap memanggil method Kucing
        
        HewanPeliharaan peliharaan = new Kucing("Whiskers");
        peliharaan.bermain(); // Method dari interface HewanPeliharaan
    }
}

Multiple Interface

Konsep Multiple Interface 🎯

Berbeda dengan class yang hanya bisa extends satu class, sebuah class bisa implements multiple interface sekaligus!

Keuntungan Multiple Interface:

  • • Mengatasi keterbatasan single inheritance di Java
  • • Membuat class lebih fleksibel dan powerful
  • • Memungkinkan kombinasi berbagai "kemampuan"
  • • Interface juga bisa extends interface lain (interface inheritance)

💡 Fakta Menarik:

Interface bisa extends multiple interface lain, contoh:

interface A { void methodA(); }
interface B { void methodB(); }
interface C extends A, B { void methodC(); }

Contoh: Smartphone Modern 📱

// Interface untuk kemampuan telepon
public interface Telepon {
    void telepon(String nomor);
    void terimaTelepn();
}

// Interface untuk kemampuan kamera
public interface Kamera {
    void fotoSelfie();
    void rekamVideo();
}

// Interface untuk kemampuan internet
public interface Internet {
    void browsingWeb();
    void kirimEmail();
}

// Interface untuk kemampuan gaming
public interface Gaming {
    void mainGame();
    void streamGame();
}

// Class Smartphone yang mengimplementasi semua interface
public class Smartphone implements Telepon, Kamera, Internet, Gaming {
    private String merk;
    
    public Smartphone(String merk) {
        this.merk = merk;
    }
    
    // Implementasi dari interface Telepon
    @Override
    public void telepon(String nomor) {
        System.out.println(merk + " menelepon ke " + nomor);
    }
    
    @Override
    public void terimaTelepn() {
        System.out.println(merk + " menerima panggilan");
    }
    
    // Implementasi dari interface Kamera
    @Override
    public void fotoSelfie() {
        System.out.println(merk + " mengambil foto selfie 📸");
    }
    
    @Override
    public void rekamVideo() {
        System.out.println(merk + " merekam video 4K 🎥");
    }
    
    // Implementasi dari interface Internet
    @Override
    public void browsingWeb() {
        System.out.println(merk + " browsing internet 🌐");
    }
    
    @Override
    public void kirimEmail() {
        System.out.println(merk + " mengirim email 📧");
    }
    
    // Implementasi dari interface Gaming
    @Override
    public void mainGame() {
        System.out.println(merk + " menjalankan game 🎮");
    }
    
    @Override
    public void streamGame() {
        System.out.println(merk + " streaming gameplay 📺");
    }
}

Langkah 1: Membuat Interface 🎯

File: interfaces/Bentuk.java

package interfaces;

public interface Bentuk {
    double PI = 3.14159; // konstanta
    
    double hitungLuas();
    double hitungKeliling();
    void tampilkanInfo();
}

File: interfaces/Warna.java

package interfaces;

public interface Warna {
    void setWarna(String warna);
    String getWarna();
    void tampilkanWarna();
}

Langkah 2: Implementasi Class 🔧

File: classes/Lingkaran.java

package classes;
import interfaces.*;

public class Lingkaran implements Bentuk, Warna {
    private double radius;
    private String warna;
    
    public Lingkaran(double radius) {
        this.radius = radius;
        this.warna = "Tidak ada warna";
    }
    
    @Override
    public double hitungLuas() {
        return PI * radius * radius;
    }
    
    @Override
    public double hitungKeliling() {
        return 2 * PI * radius;
    }
    
    @Override
    public void tampilkanInfo() {
        System.out.println("=== LINGKARAN ===");
        System.out.println("Radius: " + radius);
        System.out.println("Luas: " + hitungLuas());
        System.out.println("Keliling: " + hitungKeliling());
    }
    
    @Override
    public void setWarna(String warna) {
        this.warna = warna;
    }
    
    @Override
    public String getWarna() {
        return warna;
    }
    
    @Override
    public void tampilkanWarna() {
        System.out.println("Warna lingkaran: " + warna);
    }
}

File: classes/Persegi.java

package classes;
import interfaces.*;

public class Persegi implements Bentuk, Warna {
    private double sisi;
    private String warna;
    
    public Persegi(double sisi) {
        this.sisi = sisi;
        this.warna = "Tidak ada warna";
    }
    
    @Override
    public double hitungLuas() {
        return sisi * sisi;
    }
    
    @Override
    public double hitungKeliling() {
        return 4 * sisi;
    }
    
    @Override
    public void tampilkanInfo() {
        System.out.println("=== PERSEGI ===");
        System.out.println("Sisi: " + sisi);
        System.out.println("Luas: " + hitungLuas());
        System.out.println("Keliling: " + hitungKeliling());
    }
    
    @Override
    public void setWarna(String warna) {
        this.warna = warna;
    }
    
    @Override
    public String getWarna() {
        return warna;
    }
    
    @Override
    public void tampilkanWarna() {
        System.out.println("Warna persegi: " + warna);
    }
}

Langkah 3: Main Class 🚀

File: Main.java

import classes.*;
import interfaces.*;

public class Main {
    public static void main(String[] args) {
        // Membuat objek lingkaran
        Lingkaran lingkaran = new Lingkaran(7.0);
        lingkaran.setWarna("Merah");
        
        // Membuat objek persegi
        Persegi persegi = new Persegi(5.0);
        persegi.setWarna("Biru");
        
        // Menampilkan info bentuk
        lingkaran.tampilkanInfo();
        lingkaran.tampilkanWarna();
        System.out.println();
        
        persegi.tampilkanInfo();
        persegi.tampilkanWarna();
        System.out.println();
        
        // Polymorphism dengan interface
        Bentuk[] bentukArray = {lingkaran, persegi};
        
        System.out.println("=== POLYMORPHISM ===");
        for (Bentuk bentuk : bentukArray) {
            bentuk.tampilkanInfo();
            System.out.println();
        }
    }
}

🔍 Interface vs Abstract Class

Interface:

  • • Multiple inheritance (implements)
  • • Semua method abstract (kecuali default/static)
  • • Tidak bisa memiliki constructor
  • • Variabel otomatis public static final
  • • Keyword: interface, implements

Abstract Class:

  • • Single inheritance (extends)
  • • Bisa punya method concrete dan abstract
  • • Bisa memiliki constructor
  • • Variabel bisa berbagai access modifier
  • • Keyword: abstract, extends
