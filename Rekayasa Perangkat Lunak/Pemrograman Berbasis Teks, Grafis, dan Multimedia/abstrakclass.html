Pengenalan Abstract Class

Mari berkenalan dengan Abstract Class!

🤖 Apa itu Abstract Class?

Abstract Class adalah class yang dideklarasikan dengan keyword abstract dan tidak bisa dibuat objeknya secara langsung. Abstract Class berfungsi sebagai template untuk class lain.

💡 Analogi: Abstract Class seperti blueprint rumah. Blueprint tidak bisa dihuni, tapi digunakan untuk membangun rumah yang bisa dihuni!

🔍 Karakteristik Abstract Class

✅ Yang BISA:

  • • Punya method abstract (tanpa isi)
  • • Punya method biasa (dengan isi)
  • • Punya constructor
  • • Punya variabel
  • • Diwariskan ke class lain

❌ Yang TIDAK bisa:

  • • Tidak bisa dibuat objek dengan new
  • • Abstract method tidak boleh private (harus bisa di-override)
  • • Abstract method tidak boleh static (static tidak bisa di-override)
  • • Abstract method tidak boleh final (final tidak bisa di-override)
  • • Abstract class tidak boleh final (tidak bisa diwariskan)

🎭 Contoh Sederhana 

// File: Hewan.java
public abstract class Hewan {
    protected String nama;
    
    // Constructor
    public Hewan(String nama) {
        this.nama = nama;
    }
    
    // Method biasa - sudah ada isinya
    public void makan() {
        System.out.println(nama + " sedang makan");
    }
    
    // Abstract method - harus diisi di subclass
    public abstract void bersuara();
}

🎮 Demo: Coba Buat Objek Abstract Class

❌ Compile Error!
Cannot instantiate the type Hewan
// Kode yang error:
Hewan hewan = new Hewan("Fluffy"); // ❌ ERROR
💡 Abstract class tidak bisa dibuat objeknya langsung!
✅ Yang benar: Kucing kucing = new Kucing("Fluffy");

Konsep Dasar Abstract Class

Mari pahami konsep fundamental Abstract Class!

🏗️ Abstract Method vs Method Biasa

🔮 Abstract Method

  • • Method tanpa isi (body kosong)
  • • Harus diisi di subclass
  • • Pakai keyword abstract
  • • Diakhiri dengan semicolon (;)
// Abstract method
public abstract void bersuara();

🔧 Method Biasa

  • • Method dengan isi lengkap
  • • Bisa langsung dipakai subclass
  • • Bisa di-override atau tidak
  • • Method normal seperti biasa
// Method biasa
public void makan() {
    System.out.println("Sedang makan...");
}

🎭 Contoh Lengkap: Class Hewan 

// File: Hewan.java
public abstract class Hewan {
    protected String nama;
    protected int umur;
    
    // Constructor
    public Hewan(String nama, int umur) {
        this.nama = nama;
        this.umur = umur;
    }
    
    // Method biasa - sama untuk semua hewan
    public void makan() {
        System.out.println(nama + " sedang makan");
    }
    
    public void tidur() {
        System.out.println(nama + " sedang tidur");
    }
    
    // Abstract method - berbeda untuk setiap hewan
    public abstract void bersuara();
    public abstract void bergerak();
}

Abstract Method Detail

Mari pelajari Abstract Method lebih dalam!

📝 Aturan Abstract Method

✅ Aturan yang HARUS:

  • • Pakai keyword abstract
  • • Tidak boleh punya body/isi (diakhiri semicolon)
  • • Harus diimplementasi di subclass
  • • Bisa punya parameter dan return type
  • • Sebaiknya pakai @Override saat implementasi

❌ Aturan yang DILARANG:

  • • Tidak boleh private
  • • Tidak boleh static
  • • Tidak boleh final
  • • Tidak boleh punya isi { }

🎯 Contoh Abstract Method dengan Parameter 

// File: Kendaraan.java
public abstract class Kendaraan {
    protected String merk;
    
    public Kendaraan(String merk) {
        this.merk = merk;
    }
    
    // Abstract method dengan parameter
    public abstract void bergerak(int kecepatan);
    public abstract double hitungBBM(double jarak);
    
    // Method biasa
    public void berhenti() {
        System.out.println(merk + " berhenti");
    }
}

// Motor Honda

Inheritance dengan Abstract Class

Mari pelajari pewarisan dengan Abstract Class!

🔗 Aturan Inheritance

📋 Aturan Penting:

  • 1. Subclass HARUS mengisi semua abstract method dari parent
  • 2. Jika tidak mengisi semua, subclass juga harus abstract
  • 3. Subclass bisa menambah method baru
  • 4. Subclass bisa override method biasa dari parent
  • 5. Constructor parent dipanggil dengan super()

🎯 Contoh Inheritance Lengkap 

// Parent: Abstract Class Hewan
public abstract class Hewan {
    protected String nama;
    
    public Hewan(String nama) {
        this.nama = nama;
    }
    
    public abstract void bersuara();
    
    public void makan() {
        System.out.println(nama + " sedang makan");
    }
}

// Child: Class Kucing
public class Kucing extends Hewan {
    public Kucing(String nama) {
        super(nama); // panggil constructor parent
    }
    
    // Wajib mengisi abstract method
    public void bersuara() {
        System.out.println(nama + " berkata: Meow!");
    }
    
    // Method tambahan khusus kucing
    public void memanjat() {
        System.out.println(nama + " memanjat pohon");
    }
}

Abstract Class vs Interface

Mari bandingkan Abstract Class dengan Interface!

📊 Perbandingan

Aspek Abstract Class Interface
Keyword abstract class interface
Buat Objek ❌ Tidak bisa ❌ Tidak bisa
Method Biasa ✅ Boleh ada ✅ Boleh (default method)
Constructor ✅ Boleh ada ❌ Tidak boleh
Variabel ✅ Boleh ada (semua jenis) ✅ Hanya konstanta (public static final)
Multiple Inheritance ❌ Tidak ✅ Ya

🎯 Kapan Pakai Yang Mana?

🏛️ Pakai Abstract Class jika:

  • • Ada kode yang bisa dibagi
  • • Butuh constructor
  • • Butuh variabel instance
  • • Hubungan "is-a" yang kuat
  • • Ingin kontrol access modifier

🔌 Pakai Interface jika:

  • • Butuh multiple inheritance
  • • Mendefinisikan kontrak
  • • Tidak ada shared code
  • • Hubungan "can-do"
  • • Loose coupling

🎯 Langkah 1: Buat Abstract Class 

// File: src/abstrak/Kendaraan.java
package abstrak;

public abstract class Kendaraan {
    protected String merk;
    protected String model;
    protected boolean mesinHidup;
    
    // Constructor
    public Kendaraan(String merk, String model) {
        this.merk = merk;
        this.model = model;
        this.mesinHidup = false;
    }
    
    // Method biasa
    public void nyalakanMesin() {
        mesinHidup = true;
        System.out.println(merk + " dinyalakan");
    }
    
    // Abstract method
    public abstract void bergerak(int kecepatan);
    public abstract void klakson();
}

🚗 Langkah 2: Implementasi Class Mobil 

// File: src/implementasi/Mobil.java
package implementasi;
import abstrak.Kendaraan;

public class Mobil extends Kendaraan {
    private int jumlahPintu;
    
    public Mobil(String merk, String model, int jumlahPintu) {
        super(merk, model);
        this.jumlahPintu = jumlahPintu;
    }
    
    // Implementasi abstract method - WAJIB diisi
    @Override
    public void bergerak(int kecepatan) {
        if (!mesinHidup) {
            System.out.println("Nyalakan mesin terlebih dahulu!");
            return;
        }
        System.out.println(merk + " " + model + " bergerak " + kecepatan + " km/jam");
    }
    
    @Override
    public void klakson() {
        System.out.println("Beep! Beep!");
    }
    
    // Method khusus mobil
    public void bukaPintu() {
        System.out.println("Pintu mobil " + merk + " dibuka");
    }
    
    // Getter untuk jumlah pintu
    public int getJumlahPintu() {
        return jumlahPintu;
    }
}

🏍️ Langkah 3: Implementasi Class Motor 

// File: src/implementasi/Motor.java
package implementasi;
import abstrak.Kendaraan;

public class Motor extends Kendaraan {
    private String jenisMotor;
    
    public Motor(String merk, String model, String jenisMotor) {
        super(merk, model);
        this.jenisMotor = jenisMotor;
    }
    
    // Implementasi abstract method - WAJIB diisi
    @Override
    public void bergerak(int kecepatan) {
        if (!mesinHidup) {
            System.out.println("Nyalakan mesin terlebih dahulu!");
            return;
        }
        System.out.println(merk + " " + model + " (" + jenisMotor + ") bergerak " + kecepatan + " km/jam");
    }
    
    @Override
    public void klakson() {
        System.out.println("Tin! Tin!");
    }
    
    // Method khusus motor
    public void pasangHelm() {
        System.out.println("Helm untuk berkendara " + merk + " dipasang");
    }
    
    // Getter untuk jenis motor
    public String getJenisMotor() {
        return jenisMotor;
    }
}

🧪 Langkah 4: Test Class 

// File: src/main/TestAbstractClass.java
package main;
import implementasi.*;
import abstrak.Kendaraan;

public class TestAbstractClass {
    public static void main(String[] args) {
        System.out.println("=== Test Abstract Class Kendaraan ===");
        
        // Test Mobil
        System.out.println("\n--- Test Mobil ---");
        Mobil mobil = new Mobil("Toyota", "Avanza", 4);
        
        // Coba bergerak tanpa nyalakan mesin dulu
        mobil.bergerak(80);
        
        // Nyalakan mesin baru bergerak
        mobil.nyalakanMesin();
        mobil.bergerak(80);
        mobil.klakson();
        mobil.bukaPintu();
        System.out.println("Jumlah pintu: " + mobil.getJumlahPintu());
        
        // Test Motor
        System.out.println("\n--- Test Motor ---");
        Motor motor = new Motor("Honda", "Beat", "Matic");
        
        // Coba bergerak tanpa nyalakan mesin dulu
        motor.bergerak(60);
        
        // Nyalakan mesin baru bergerak
        motor.nyalakanMesin();
        motor.bergerak(60);
        motor.klakson();
        motor.pasangHelm();
        System.out.println("Jenis motor: " + motor.getJenisMotor());
        
        // Test Polymorphism dengan Abstract Class
        System.out.println("\n--- Test Polymorphism ---");
        Kendaraan[] kendaraans = {
            new Mobil("BMW", "X5", 4),
            new Motor("Yamaha", "NMAX", "Matic")
        };
        
        for (Kendaraan k : kendaraans) {
            k.nyalakanMesin();
            k.bergerak(50);
            k.klakson();
            System.out.println();
        }
    }
}

Tugas Abstract Class

Saatnya mengerjakan tugas untuk menguji pemahaman!

📋 Soal 1: Analisis Kode

Perhatikan kode berikut dan jawab pertanyaan di bawahnya:

public abstract class Bentuk {
    protected String warna;
    
    public Bentuk(String warna) {
        this.warna = warna;
    }
    
    public void tampilkanWarna() {
        System.out.println("Warna: " + warna);
    }
    
    public abstract double hitungLuas();
}

Pertanyaan:

  1. Mengapa class Bentuk dideklarasikan sebagai abstract?
  2. Apakah kita bisa membuat objek dari class Bentuk? Jelaskan!
  3. Method apa saja yang harus diimplementasi oleh subclass?
  4. Apa fungsi constructor dalam abstract class?

💻 Soal 2: Implementasi

Tugas Implementasi:

Buatlah implementasi lengkap dari abstract class Bentuk di atas dengan membuat:

  1. Class Lingkaran yang extends Bentuk
  2. Class Persegi yang extends Bentuk
  3. Class Main untuk testing

Ketentuan: Setiap class harus mengimplementasi method hitungLuas() sesuai dengan rumus matematika yang benar.

🤔 Soal 3: Konsep

Pertanyaan Konsep:

  1. Jelaskan perbedaan antara abstract method dan method biasa dalam abstract class!
  2. Kapan sebaiknya menggunakan abstract class dibandingkan dengan interface?
  3. Apa yang terjadi jika subclass tidak mengimplementasi semua abstract method dari parent class?
  4. Bisakah abstract class memiliki constructor? Jelaskan dengan contoh!
  5. Mengapa abstract method tidak boleh dideklarasikan sebagai private?

🎯 Soal 4: Studi Kasus

Studi Kasus: Sistem Pembayaran

Anda diminta membuat sistem pembayaran untuk aplikasi e-commerce. Buatlah desain menggunakan abstract class dengan ketentuan:

  • Abstract class Pembayaran dengan method abstract prosesPembayaran()
  • Method biasa tampilkanInfo() dan validasiJumlah()
  • Subclass: KartuKredit, Transfer, EWallet
  • Setiap subclass punya cara pembayaran yang berbeda

Tugas: Buatlah kode lengkap dan jelaskan mengapa menggunakan abstract class lebih tepat daripada interface untuk kasus ini!
