Package dalam Java

Belajar cara mengelompokkan class-class dengan rapi

📚

Apa itu Package?

Package adalah cara mengelompokkan class-class yang memiliki fungsi serupa ke dalam satu folder/direktori. Seperti mengorganisir buku-buku berdasarkan kategori di perpustakaan! 📚

📝 Cara Membuat Package:

package com.sekolah.model;

public class Siswa {
  private String nama;
  private int umur;
  // constructor, getter, setter...
}

⚠️ Penting: Deklarasi package harus di baris pertama file Java!

✅ Keuntungan Package:

  • • Menghindari konflik nama class
  • • Organisasi kode yang lebih baik
  • • Kontrol akses yang lebih fleksibel
  • • Memudahkan maintenance

📋 Aturan Penamaan:

  • • Gunakan huruf kecil semua
  • • Pisahkan dengan titik (.)
  • • Mulai dengan domain terbalik
  • • Contoh: com.perusahaan.aplikasi

🏗️ Contoh Struktur Package

📁 com.sekolah.aplikasi
📁 model
📄 Siswa.java
📄 Guru.java
📁 service
📄 SiswaService.java

Import Statement

Belajar cara menggunakan class dari package lain

🔗

Mengapa Perlu Import?

Ketika kita ingin menggunakan class dari package lain, kita perlu "mengimpor" class tersebut terlebih dahulu. Seperti meminjam buku dari perpustakaan lain - kita harus tahu di mana letaknya! 📚

📥 Import Specific Class:

import java.util.ArrayList;

public class Main {
  public static void main(String[] args) {
    ArrayList<String> list = new ArrayList<>();
  }
}

📦 Import Semua Class dari Package:

import java.util.*;

public class Main {
  public static void main(String[] args) {
    ArrayList<String> list = new ArrayList<>();
    HashMap<String, Integer> map = new HashMap<>();
  }
}

✅ Import Specific (Direkomendasikan):

  • • Lebih jelas class mana yang digunakan
  • • Menghindari konflik nama
  • • Compile time lebih cepat
  • • Kode lebih mudah dibaca

⚠️ Import Wildcard (*):

  • • Praktis untuk banyak class
  • • Bisa menyebabkan konflik nama
  • • Kurang jelas dependensi
  • • Gunakan dengan hati-hati

📋 Catatan Penting:

  • • Package java.lang tidak perlu di-import (otomatis)
  • • Import statement harus setelah package declaration
  • • Import statement harus sebelum class declaration
  • • Tidak bisa import class dengan nama yang sama dari package berbeda

Access Modifier

Belajar mengatur tingkat akses class, method, dan variabel

🏠

4 Jenis Access Modifier

🌍 public

Dapat diakses dari mana saja - class lain, package lain, bahkan project lain!

public class Siswa { }

📦 default (package-private)

Hanya dapat diakses dalam package yang sama. Tidak ada kata kunci khusus.

class Siswa { } // tanpa modifier

🏘️ protected

Dapat diakses dalam package yang sama + subclass (inheritance).

protected String nama;

🔒 private

Hanya dapat diakses dalam class yang sama. Paling ketat!

private int umur;

📊 Tabel Perbandingan Access Modifier

Access Modifier Same Class Same Package Subclass Different Package
private ✅ ❌ ❌ ❌
default ✅ ✅ ❌ ❌
protected ✅ ✅ ✅ ❌
public ✅ ✅ ✅ ✅

💡 Contoh Praktis Penggunaan

package com.sekolah.model;

public class Siswa {
  private String nama; // hanya dalam class ini
  protected int umur; // package + subclass
  String kelas; // default: hanya dalam package
  public String sekolah; // bisa diakses dari mana saja

  public getNama() { return nama; }
  public void setNama(String nama) { this.nama = nama; }
}

Struktur Project Java

Belajar mengorganisir project Java dengan baik dan benar

📁

Struktur Folder Standard

Seperti mengatur rumah, project Java juga perlu struktur yang rapi dan terorganisir. Mari pelajari struktur standard yang digunakan oleh programmer profesional! 🏠

🎯 Contoh Project: Sistem Perpustakaan

📁 perpustakaan-app/
📁 src/ (source code)
📁 com/perpustakaan/
📁 model/ (data classes)
📄 Buku.java
📄 Anggota.java
📄 Peminjaman.java
📁 service/ (business logic)
📄 PerpustakaanService.java
📄 BukuService.java
📁 util/ (helper classes)
📄 DateUtil.java
📄 ValidationUtil.java
📁 main/ (entry point)
📄 Main.java

📊 Package Model

Berisi class-class yang merepresentasikan data/entitas:

  • • Class dengan atribut dan method getter/setter
  • • Biasanya menggunakan access modifier private untuk atribut
  • • Contoh: Buku, Anggota, Peminjaman

⚙️ Package Service

Berisi logika bisnis dan operasi utama:

  • • Method untuk CRUD (Create, Read, Update, Delete)
  • • Validasi dan business rules
  • • Contoh: tambahBuku(), pinjamBuku(), kembaliBuku()

🔧 Package Util

Berisi class-class pembantu yang bisa digunakan berulang:

  • • Utility functions yang sering dipakai
  • • Helper methods untuk formatting, validation
  • • Contoh: formatTanggal(), validateEmail()

🚀 Package Main

Berisi entry point aplikasi:

  • • Class dengan method main()
  • • Menginisialisasi dan menjalankan aplikasi
  • • Mengatur alur program utama

Tugas Modularitas Java

Saatnya mempraktikkan semua yang sudah dipelajari!

🔍

Tugas: Analisis dan Implementasi

Buatlah struktur project Java untuk "Sistem Toko Online" dengan ketentuan:

Yang Harus Dibuat:

  1. 1. Buat struktur package yang sesuai (model, service, util)
  2. 2. Buat class Produk dengan atribut nama, harga, stok
  3. 3. Buat class Customer dengan atribut nama, email, alamat
  4. 4. Gunakan access modifier yang tepat
  5. 5. Buat class Main untuk menjalankan program

💡 Tips Pengerjaan:

  • • Gunakan package com.toko.namaanda
  • • Pisahkan class berdasarkan fungsinya
  • • Gunakan private untuk data sensitif
  • • Buat getter dan setter untuk akses data

📝 Contoh Implementasi

📦 com/toko/model/Produk.java

package com.toko.model;

public class Produk {
  private String nama;
  private double harga;
  private int stok;

  // Constructor
  public Produk(String nama, double harga, int stok) {
    this.nama = nama;
    this.harga = harga;
    this.stok = stok;
  }

  // Getter dan Setter
  public String getNama() { return nama; }
  public void setNama(String nama) { this.nama = nama; }
}

⚙️ com/toko/service/TokoService.java

package com.toko.service;

import com.toko.model.Produk;
import java.util.ArrayList;

public class TokoService {
  private ArrayList<Produk> daftarProduk;

  public void tambahProduk(Produk produk) {
    daftarProduk.add(produk);
    System.out.println("Produk berhasil ditambahkan!");
  }
}

🚀 com/toko/main/Main.java

package com.toko.main;

import com.toko.model.Produk;
import com.toko.service.TokoService;

public class Main {
  public static void main(String[] args) {
    Produk laptop = new Produk("Laptop", 5000000, 10);
    TokoService toko = new TokoService();
    toko.tambahProduk(laptop);
  }
}
