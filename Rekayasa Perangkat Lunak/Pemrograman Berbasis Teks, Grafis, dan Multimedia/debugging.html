Pengenalan Debugging

Mari kenali dunia debugging lebih dalam!

🤖 Apa itu Bug?

Bug adalah kesalahan atau cacat dalam program yang menyebabkan program tidak berjalan sesuai yang diharapkan. Istilah "bug" pertama kali digunakan oleh Grace Hopper pada tahun 1947 ketika menemukan seekor ngengat yang tersangkut di komputer!

💡 Fun Fact: Bug pertama dalam sejarah komputer adalah ngengat sungguhan yang ditemukan di Harvard Mark II computer!

🔧 Apa itu Debugging?

Debugging adalah proses menemukan, menganalisis, dan memperbaiki bug dalam program. Ini seperti menjadi detektif yang mencari petunjuk untuk memecahkan misteri mengapa program tidak bekerja dengan benar.

⚡ Mengapa Debugging Penting?

✓ Menghemat waktu development
✓ Meningkatkan kualitas software
✓ Memahami alur program lebih baik
✓ Mencegah bug di masa depan
✓ Meningkatkan skill programming
✓ Kepuasan menyelesaikan masalah

Jenis-jenis Bug

Kenali musuh sebelum berperang!

💥 1. Syntax Error (Kesalahan Sintaks)

Kesalahan penulisan kode yang tidak sesuai dengan aturan bahasa pemrograman.

Contoh Syntax Error:

// ❌ Salah - kurang titik koma
int angka = 10

// ❌ Salah - kurung kurawal tidak seimbang
public void method() {
    System.out.println("Hello");
// kurang }

// ❌ Salah - salah penulisan keyword
publc class Test {  // seharusnya "public"

// ✅ Benar
int angka = 10;
public void method() {
    System.out.println("Hello");
}

Ciri-ciri: Program tidak bisa di-compile, NetBeans menampilkan garis merah di bawah kode yang salah.

⚠️ 2. Runtime Error (Kesalahan Saat Berjalan)

Program bisa di-compile tapi error saat dijalankan.

Contoh Runtime Error:

// ❌ Akan error: ArithmeticException (pembagian dengan nol)
int pembagi = 0;
int hasil = 10 / pembagi;  // Runtime Error!

// ❌ Akan error: ArrayIndexOutOfBoundsException
int[] array = {1, 2, 3};  // index 0, 1, 2
int index = 5;
System.out.println(array[index]);  // index 5 tidak ada!

// ❌ Akan error: NullPointerException
String text = null;
System.out.println(text.length());  // text adalah null!

// ✅ Cara memperbaiki dengan validasi:
int pembagi = 5;  // atau input dari user
if (pembagi != 0) {
    int hasil = 10 / pembagi;
    System.out.println("Hasil: " + hasil);
} else {
    System.out.println("Error: Tidak bisa bagi dengan nol!");
}

int index = 2;  // atau input dari user
if (index >= 0 && index < array.length) {
    System.out.println("Nilai: " + array[index]);
} else {
    System.out.println("Error: Index di luar batas array!");
}

String text = "Hello World";  // atau input dari user
if (text != null && !text.isEmpty()) {
    System.out.println("Panjang: " + text.length());
} else {
    System.out.println("Error: Text kosong atau null!");
}

Ciri-ciri: Program crash saat berjalan, muncul Exception di console.

🤔 3. Logic Error (Kesalahan Logika)

Program berjalan tanpa error, tapi hasilnya tidak sesuai yang diharapkan.

Contoh Logic Error:

// ❌ Salah - seharusnya penjumlahan, bukan pengurangan
int totalHarga = harga1 - harga2;

// ❌ Salah - kondisi loop yang salah
for (int i = 0; i <= 10; i++) {  // seharusnya i < 10
    // akan loop 11 kali, bukan 10 kali
}

// ❌ Salah - rumus luas persegi yang salah
int luas = sisi + sisi;  // seharusnya sisi * sisi

// ❌ Salah - kondisi if yang terbalik
if (nilai < 60) {
    System.out.println("Lulus");  // seharusnya "Tidak Lulus"
}

// ✅ Benar
int totalHarga = harga1 + harga2;
for (int i = 0; i < 10; i++) {
    // loop 10 kali
}
int luas = sisi * sisi;
if (nilai >= 60) {
    System.out.println("Lulus");
}

Ciri-ciri: Program berjalan normal tapi output salah. Paling sulit dideteksi!

Tools Debugging di NetBeans

Senjata ampuh untuk melawan bug!

🎯 1. Debugger NetBeans

Fitur Utama:

  • ✓ Breakpoint management
  • ✓ Step-by-step execution
  • ✓ Variable inspection
  • ✓ Call stack viewing

Cara Mengakses:

Menu → Debug → Debug Project
Shortcut: Ctrl + F5
Klik kanan → Debug File

📊 2. Variables Window

Window ini menampilkan nilai semua variabel yang sedang aktif dalam scope saat program di-debug.

Kegunaan Variables Window:

  • • Melihat nilai variabel real-time saat eksekusi
  • • Mengubah nilai variabel saat debugging (klik kanan → Set Value)
  • • Memonitor perubahan nilai variabel step by step
  • • Melihat struktur object dan array secara detail
  • • Mengecek apakah variabel null atau memiliki nilai
  • • Melihat variabel lokal, parameter method, dan variabel instance

Cara Mengakses:

Menu → Window → Debugging → Variables atau otomatis muncul saat debugging dimulai

Tips Menggunakan Variables Window:

  • • Klik tanda + untuk expand object atau array
  • • Variabel yang berubah nilai akan di-highlight
  • • Klik kanan variabel untuk mengubah nilainya saat debugging
  • • Gunakan untuk memverifikasi apakah nilai sesuai ekspektasi

📋 3. Call Stack Window

Menampilkan urutan pemanggilan method/function yang sedang aktif. Seperti jejak kaki yang menunjukkan dari mana kita datang. 

// Contoh Call Stack saat debugging:
main() → hitungRata() → validasiArray()
                                    ↑
                              (sedang di sini)

// Artinya: program dimulai dari main(), lalu memanggil hitungRata(),
// kemudian hitungRata() memanggil validasiArray()
// Saat ini eksekusi sedang berhenti di dalam validasiArray()

Berguna untuk:

  • • Melacak alur eksekusi program
  • • Menemukan di mana error terjadi dalam rantai pemanggilan method
  • • Memahami bagaimana method saling memanggil
  • • Debugging recursive method

Cara Menggunakan:

Klik pada method di Call Stack untuk melihat kode dan variabel di level tersebut. Ini membantu memahami bagaimana data mengalir antar method.

Breakpoint

Titik henti untuk menganalisis program

🎯 Apa itu Breakpoint?

Breakpoint adalah titik henti yang kita tempatkan di kode untuk menghentikan eksekusi program sementara waktu. Ini memungkinkan kita untuk memeriksa kondisi program pada titik tertentu.

Analogi Sederhana:

Bayangkan breakpoint seperti rambu "STOP" di jalan. Ketika program "berkendara" dan sampai di rambu STOP (breakpoint), program akan berhenti sementara sehingga kita bisa "turun dari mobil" dan melihat kondisi sekitar (nilai variabel, status program, dll).

📍 Cara Membuat dan Mengelola Breakpoint

Metode 1: Klik di Line Number

  1. 1. Buka file Java di NetBeans
  2. 2. Klik di sebelah kiri nomor baris (margin kiri)
  3. 3. Akan muncul titik merah (breakpoint)
  4. 4. Klik lagi untuk menghapus breakpoint

Metode 2: Keyboard Shortcut

  1. 1. Letakkan cursor di baris yang diinginkan
  2. 2. Tekan Ctrl + F8
  3. 3. Breakpoint akan ditambahkan/dihapus
  4. 4. Shortcut yang sama untuk toggle on/off

Tips Menggunakan Breakpoint:

  • 💡 Letakkan breakpoint di baris yang mengandung kode, bukan di baris kosong atau komentar
  • 💡 Gunakan breakpoint di awal method untuk memeriksa parameter input
  • 💡 Letakkan breakpoint sebelum dan sesudah operasi penting untuk membandingkan nilai
  • 💡 Hapus breakpoint yang tidak diperlukan untuk menghindari kebingungan

Contoh Penempatan Breakpoint yang Efektif:

public static int bagi(int a, int b) {
    // ⭐ Breakpoint 1: Cek parameter input
    System.out.println("Input: a=" + a + ", b=" + b);
    
    // ⭐ Breakpoint 2: Sebelum operasi kritis
    if (b == 0) {
        throw new ArithmeticException("Pembagi tidak boleh nol");
    }
    
    int hasil = a / b;
    // ⭐ Breakpoint 3: Cek hasil sebelum return
    return hasil;
}

Strategi: Letakkan breakpoint di titik-titik kritis seperti awal method, sebelum operasi berisiko, dan sebelum return statement untuk memastikan alur program benar.

Step Debugging

Melangkah pelan-pelan melalui kode

⚡ Jenis-jenis Step

▶️ Step Over (F8)

Eksekusi baris saat ini dan pindah ke baris berikutnya.

Jika ada method call, akan dieksekusi sekaligus tanpa masuk ke dalam method.

⬇️ Step Into (F7)

Masuk ke dalam method yang dipanggil.

Berguna untuk debugging method yang kita buat sendiri.

⬆️ Step Out (Ctrl+F7)

Keluar dari method saat ini dan kembali ke method pemanggil.

Berguna ketika sudah selesai debugging method tertentu.

🏃 Continue (F5)

Lanjutkan eksekusi normal sampai breakpoint berikutnya.

Program akan berjalan normal sampai menemui breakpoint lain.

Contoh Skenario Step Debugging:

public static void main(String[] args) {
    int a = 10;                    // ⭐ Breakpoint di sini
    int b = 5;                     // F8: Step Over ke baris ini
    int hasil = tambah(a, b);      // F7: Step Into masuk ke method tambah()
                                    // F8: Step Over eksekusi method tanpa masuk
    System.out.println(hasil);    // F8: Step Over ke baris ini
}

public static int tambah(int x, int y) {
    int sum = x + y;             // Jika Step Into, akan berhenti di sini
    return sum;                  // Ctrl+F7: Step Out kembali ke main()
}

Tips: Gunakan Step Into hanya untuk method yang kamu buat sendiri. Untuk method bawaan Java (seperti System.out.println), gunakan Step Over.

Praktik Debugging

Saatnya praktek langsung!

🎯 Praktik 1: Debugging Program Sederhana

Struktur Project:

DebuggingPraktik/
└── src/
    └── debuggingpraktik/
        └── KalkulatorSederhana.java

File: KalkulatorSederhana.java

package debuggingpraktik;

public class KalkulatorSederhana {
    public static void main(String[] args) {
        int angka1 = 10;
        int angka2 = 5;
        
        System.out.println("=== KALKULATOR SEDERHANA ===");
        System.out.println("Angka 1: " + angka1);
        System.out.println("Angka 2: " + angka2);
        
        int penjumlahan = tambah(angka1, angka2);
        int pengurangan = kurang(angka1, angka2);
        int perkalian = kali(angka1, angka2);
        int pembagian = bagi(angka1, angka2);
        
        tampilkanHasil(penjumlahan, pengurangan, perkalian, pembagian);
    }
    
    public static int tambah(int a, int b) {
        return a + b;
    }
    
    public static int kurang(int a, int b) {
        return a - b;
    }
    
    public static int kali(int a, int b) {
        return a * b;
    }
    
    public static int bagi(int a, int b) {
        return a / b;
    }
    
    public static void tampilkanHasil(int tambah, int kurang, int kali, int bagi) {
        System.out.println("\n=== HASIL OPERASI ===");
        System.out.println("Penjumlahan: " + tambah);
        System.out.println("Pengurangan: " + kurang);
        System.out.println("Perkalian: " + kali);
        System.out.println("Pembagian: " + bagi);
    }
}

Langkah-langkah Debugging:

  1. 1. Buat project baru di NetBeans dengan nama "DebuggingPraktik"
  2. 2. Copy kode di atas ke file KalkulatorSederhana.java
  3. 3. Letakkan breakpoint di baris 5 (int angka1 = 10;)
  4. 4. Jalankan program dalam mode debug (Ctrl+F5)
  5. 5. Gunakan Step Over (F8) untuk melihat eksekusi baris per baris
  6. 6. Perhatikan nilai variabel di Variables window
  7. 7. Gunakan Step Into (F7) saat memanggil method tambah()
  8. 8. Amati bagaimana parameter diteruskan ke method
  9. 9. Gunakan Step Out (Ctrl+F7) untuk keluar dari method
  10. 10. Lanjutkan dengan Continue (F5) untuk menyelesaikan program

Praktik 2: Debugging Program dengan Bug

Coba debug program berikut yang memiliki bug:

package debuggingpraktik;

public class ProgramBermasalah {
    public static void main(String[] args) {
        int[] nilai = {85, 90, 78, 92, 88};
        
        System.out.println("=== PROGRAM HITUNG RATA-RATA ===");
        System.out.println("Jumlah nilai: " + nilai.length);
        
        // Hitung rata-rata (ada bug di method ini)
        double rata = hitungRata(nilai);
        System.out.println("Rata-rata: " + rata);
        
        // Bug 2: pembagian dengan nol
        int pembagi = 0;
        int hasil = 100 / pembagi;  // Runtime Error!
        System.out.println("Hasil pembagian: " + hasil);
        
        // Bug 3: akses array di luar batas
        System.out.println("Nilai ke-10: " + nilai[10]);  // Runtime Error!
    }
    
    public static double hitungRata(int[] arr) {
        int total = 0;
        
        // Bug 1: kondisi loop salah (Logic Error)
        for (int i = 0; i <= arr.length; i++) {  
            // Seharusnya i < arr.length, bukan i <= arr.length
            // Ini akan menyebabkan ArrayIndexOutOfBoundsException
            total += arr[i];
        }
        
        return (double) total / arr.length;
    }
}
🎯 Tugas Debugging:

Temukan dan perbaiki 3 bug dalam program ini menggunakan debugger NetBeans!

Langkah-langkah:

  1. Copy kode ke NetBeans dan jalankan tanpa debug dulu
  2. Perhatikan error yang muncul di console
  3. Letakkan breakpoint di baris pertama method main()
  4. Jalankan dalam mode debug (Ctrl+F5)
  5. Gunakan Step Over untuk menemukan di mana program crash
  6. Perbaiki bug satu per satu dan test kembali

Hint: Bug pertama ada di method hitungRata(), bug kedua dan ketiga ada di method main()
