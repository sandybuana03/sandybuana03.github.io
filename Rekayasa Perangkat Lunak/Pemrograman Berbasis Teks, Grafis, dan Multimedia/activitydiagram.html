Pengertian Diagram Activity

📖 Definisi

Diagram Activity adalah salah satu jenis diagram dalam UML (Unified Modeling Language) yang menggambarkan alur kerja (workflow) atau aktivitas dari sebuah sistem, proses bisnis, atau use case. Diagram ini menunjukkan urutan aktivitas dari awal hingga akhir secara berurutan, termasuk percabangan (decision), penggabungan alur (merge), dan aktivitas paralel (fork/join).

🔄

Alur Proses

Menunjukkan langkah-langkah berurutan dalam suatu proses

🌿

Percabangan

Menampilkan pilihan atau kondisi dalam alur

🔗

Penggabungan

Menunjukkan titik dimana alur bergabung kembali

🎭 Analogi Sederhana

Bayangkan diagram activity seperti resep masakan! 📝
• Bahan-bahan = Input
• Langkah memasak = Aktivitas
• Keputusan (matang/belum?) = Decision
• Makanan jadi = Output

🎯 Tujuan Utama

  • ✓ Memvisualisasikan alur kerja
  • ✓ Mengidentifikasi bottleneck
  • ✓ Memperbaiki proses bisnis
  • ✓ Dokumentasi sistem
  • ✓ Komunikasi tim
  • ✓ Analisis kebutuhan

Komponen Diagram Activity

🟢

Initial Node (Titik Awal)

Menandai dimana aktivitas dimulai. Digambarkan sebagai lingkaran hitam solid.

Initial Node

📦

Activity (Aktivitas)

Tindakan atau proses yang dilakukan. Digambarkan sebagai persegi panjang dengan sudut membulat.

Nama Aktivitas

💎

Decision Node (Titik Keputusan)

Menunjukkan percabangan berdasarkan kondisi tertentu. Digambarkan sebagai belah ketupat.

?

Decision

🔗

Merge Node (Titik Gabung)

Menggabungkan beberapa alur menjadi satu. Digambarkan sebagai belah ketupat kosong.

Merge

🍴

Fork Node (Titik Percabangan Paralel)

Membagi satu alur menjadi beberapa alur paralel yang berjalan bersamaan. Digambarkan sebagai garis tebal horizontal atau vertikal.

Fork Node

🤝

Join Node (Titik Penggabungan Paralel)

Menggabungkan beberapa alur paralel menjadi satu alur. Semua alur harus selesai sebelum melanjutkan. Digambarkan sama seperti Fork Node.

Join Node

🎯

Final Node (Titik Akhir)

Menandai berakhirnya aktivitas. Digambarkan sebagai lingkaran dengan lingkaran kecil di dalamnya.

Final Node

➡️

Control Flow (Alur Kontrol)

Panah yang menunjukkan arah alur dari satu aktivitas ke aktivitas lainnya.

Control Flow

Simbol-simbol Diagram Activity

📚 Panduan Simbol

Setiap simbol memiliki makna khusus. Mari kita pelajari satu per satu dengan contoh yang mudah dipahami!

🎮 Demo Interaktif Simbol

Initial Node (Start)

Fungsi: Menandai titik awal dari seluruh proses

Aturan: Hanya boleh ada satu dalam diagram

Contoh: "Mulai proses login"

Action
Activity Node

Fungsi: Menggambarkan tindakan atau proses yang dilakukan

Aturan: Gunakan kata kerja aktif

Contoh: "Validasi username", "Kirim email"

Decision Node

Fungsi: Menunjukkan titik dimana alur bercabang berdasarkan kondisi

Aturan: Harus memiliki minimal 2 cabang keluar

Contoh: "Password benar?", "Stok tersedia?"

Fork Node

Fungsi: Membagi satu alur menjadi beberapa alur paralel

Aturan: Semua cabang berjalan bersamaan (concurrent)

Contoh: "Proses pembayaran dan pengiriman bersamaan"

Join Node

Fungsi: Menggabungkan beberapa alur paralel menjadi satu

Aturan: Menunggu semua alur selesai sebelum melanjutkan

Contoh: "Setelah pembayaran dan pengiriman selesai"

Final Node (End)

Fungsi: Menandai berakhirnya seluruh proses

Aturan: Boleh ada lebih dari satu jika ada multiple ending

Contoh: "Proses selesai", "Login berhasil"

Tugas Praktik

🎯 Instruksi Tugas

Buatlah diagram activity untuk salah satu proses berikut ini. Gunakan simbol-simbol yang sudah dipelajari!

📱 Pilihan 1: Proses Daftar Akun Baru

Buat diagram untuk proses pendaftaran akun baru di aplikasi media sosial.

Hint: Mulai dari input data, validasi email, konfirmasi, hingga akun aktif

🍕 Pilihan 2: Proses Pesan Makanan Online

Buat diagram untuk proses memesan makanan melalui aplikasi delivery.

Hint: Pilih restoran, pilih menu, checkout, pembayaran, hingga makanan diantar

📝 Format Pengerjaan

1.

Identifikasi Aktivitas

Tuliskan semua aktivitas yang terlibat dalam proses

2.

Tentukan Urutan

Susun aktivitas sesuai urutan yang logis

3.

Identifikasi Decision Point

Tentukan dimana ada percabangan atau keputusan

4.

Gambar Diagram

Buat diagram menggunakan simbol-simbol yang benar

✅ Kriteria Penilaian

Aspek Teknis:
  • • Penggunaan simbol yang benar
  • • Alur logis dan berurutan
  • • Ada start dan end node
  • • Decision node memiliki cabang
Aspek Konten:
  • • Aktivitas sesuai dengan proses
  • • Nama aktivitas jelas
  • • Mencakup semua langkah penting
  • • Mudah dipahami

💡 Tips Sukses

• Mulai sederhana: Fokus pada aktivitas utama dulu

• Pikirkan user: Apa yang dilakukan pengguna di setiap langkah?

• Jangan lupa validasi: Setiap input biasanya perlu dicek

• Pertimbangkan error: Apa yang terjadi jika ada kesalahan?
