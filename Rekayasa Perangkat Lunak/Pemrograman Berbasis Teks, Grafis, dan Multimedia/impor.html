Pengenalan Library Java

📚 Apa itu Library?

Library (pustaka) adalah kumpulan kode program yang sudah jadi dan bisa kita gunakan untuk mempermudah pembuatan aplikasi. Bayangkan library seperti kotak peralatan yang berisi berbagai tools siap pakai! 🧰

✅ Keuntungan Library

  • • Menghemat waktu coding
  • • Kode lebih rapi dan terstruktur
  • • Mengurangi bug dan error
  • • Fitur yang sudah teruji

🎯 Contoh Penggunaan

  • • Menampilkan tanggal dan waktu
  • • Operasi matematika kompleks
  • • Membaca file dan database
  • • Membuat interface grafis

💭 Analogi Sederhana

Library itu seperti resep masakan yang sudah jadi. Daripada kita harus mencari tahu sendiri cara membuat rendang dari nol, kita bisa langsung pakai resep yang sudah terbukti enak! Begitu juga dengan programming - kita pakai library yang sudah terbukti bagus. 👨‍🍳

🧠

Konsep Dasar Library

🔍 Package dan Import

Di Java, library diorganisir dalam package (paket). Package seperti folder yang berisi kelas-kelas dengan fungsi tertentu. Untuk menggunakan library, kita perlu import (mengimpor) package tersebut. 

// Contoh import statement
import java.util.Scanner;  // Import kelas Scanner
import java.time.*;        // Import semua kelas dari package time

📦 Struktur Package

java.lang.* - Dasar Java
java.util.* - Utilitas
java.io.* - Input/Output
java.time.* - Tanggal & Waktu
javax.swing.* - GUI

⚡ Cara Kerja Import

  1. 1. Tulis statement import
  2. 2. Java mencari package
  3. 3. Kelas dimuat ke memory
  4. 4. Siap digunakan dalam kode

💡 Tips Best Practice

✅ Yang Benar:

  • • Import di bagian atas file (setelah package)
  • • Import spesifik kelas yang diperlukan
  • • Gunakan nama package lengkap
  • • Urutkan import secara alfabetis

❌ Yang Salah:

  • • Import di tengah atau akhir kode
  • • Terlalu banyak import dengan wildcard (*)
  • • Import yang tidak digunakan
  • • Lupa import yang diperlukan

Cara Mengimpor Library

📝 Sintaks Import Statement

1. Import Kelas Tertentu

import java.util.Scanner;
import java.time.LocalDate;

2. Import Semua Kelas dalam Package

import java.util.*;
import javax.swing.*;

3. Import Static (untuk method static)

import static java.lang.Math.*;
// Sekarang bisa langsung pakai sqrt() tanpa Math.sqrt()
double hasil = sqrt(25); // Tanpa Math.sqrt()

🎯 Langkah-Langkah di NetBeans

  1. 1. Buka file Java
  2. 2. Tulis import di atas class
  3. 3. NetBeans akan auto-suggest
  4. 4. Tekan Ctrl+Shift+I untuk auto-import
  5. 5. Gunakan kelas dalam kode

💡 Tips NetBeans

  • • Ctrl+Space: Auto-complete
  • • Ctrl+Shift+I: Auto-import
  • • Alt+Enter: Quick fix
  • • Lampu kuning = saran import
  • • Garis merah = error import

Tulis import statement sesuai dokumentasi library

Solusi: Cek nama package, pastikan library eksternal sudah di-add

Solusi: Hapus import yang duplikat atau gunakan import dengan wildcard (*)

📝 Praktik 1: Input dengan Scanner

Struktur Project:

📁 PraktikLibrary/
  📁 src/
    📄 InputData.java 
// File: InputData.java
import java.util.Scanner;

public class InputData {
    public static void main(String[] args) {
        // Membuat objek Scanner untuk input
        Scanner input = new Scanner(System.in);
        
        System.out.print("Masukkan nama Anda: ");
        String nama = input.nextLine();
        
        System.out.print("Masukkan umur Anda: ");
        int umur = input.nextInt();
        
        System.out.println("Halo " + nama + "!");
        System.out.println("Umur Anda: " + umur + " tahun");
        
        input.close(); // Tutup scanner
    }
}
Penjelasan:
  • • import java.util.Scanner; - Mengimpor kelas Scanner
  • • Scanner input = new Scanner(System.in); - Membuat objek Scanner
  • • nextLine() - Membaca input string
  • • nextInt() - Membaca input integer

📅 Praktik 2: Tanggal dan Waktu

Struktur Project:

📁 PraktikLibrary/
  📁 src/
    📄 TanggalWaktu.java 
// File: TanggalWaktu.java
import java.time.LocalDate;
import java.time.LocalTime;
import java.time.format.DateTimeFormatter;

public class TanggalWaktu {
    public static void main(String[] args) {
        // Mendapatkan tanggal hari ini
        LocalDate tanggalHariIni = LocalDate.now();
        
        // Mendapatkan waktu sekarang
        LocalTime waktuSekarang = LocalTime.now();
        
        // Format tanggal dan waktu
        DateTimeFormatter formatTanggal = DateTimeFormatter.ofPattern("dd-MM-yyyy");
        DateTimeFormatter formatWaktu = DateTimeFormatter.ofPattern("HH:mm:ss");
        
        System.out.println("Tanggal hari ini: " + tanggalHariIni.format(formatTanggal));
        System.out.println("Waktu sekarang: " + waktuSekarang.format(formatWaktu));
        
        // Menambah hari
        LocalDate besok = tanggalHariIni.plusDays(1);
        System.out.println("Besok: " + besok.format(formatTanggal));
    }
}
Penjelasan:
  • • LocalDate.now() - Mendapat tanggal hari ini
  • • LocalTime.now() - Mendapat waktu sekarang
  • • DateTimeFormatter - Memformat tampilan tanggal/waktu
  • • plusDays(1) - Menambah hari

🧮 Praktik 3: Operasi Matematika

Struktur Project:

📁 PraktikLibrary/
  📁 src/
    📄 KalkulatorMath.java 
// File: KalkulatorMath.java
// Tidak perlu import java.lang.* karena sudah otomatis

public class KalkulatorMath {
    public static void main(String[] args) {
        double angka = 25.0;
        
        // Operasi matematika menggunakan Math class
        System.out.println("Angka: " + angka);
        System.out.println("Akar kuadrat: " + Math.sqrt(angka));
        System.out.println("Pangkat 2: " + Math.pow(angka, 2));
        System.out.println("Nilai absolut: " + Math.abs(-angka));
        System.out.println("Pembulatan: " + Math.round(angka));
        
        // Konstanta matematika
        System.out.println("Nilai PI: " + Math.PI);
        System.out.println("Nilai E: " + Math.E);
        
        // Angka random (1-100)
        int randomAngka = (int)(Math.random() * 100) + 1;
        System.out.println("Angka random (1-100): " + randomAngka);
        
        // Trigonometri
        double sudut = 45; // dalam derajat
        double radian = Math.toRadians(sudut);
        System.out.println("Sin 45°: " + String.format("%.2f", Math.sin(radian)));
        System.out.println("Cos 45°: " + String.format("%.2f", Math.cos(radian)));
    }
}
Penjelasan:
  • • Math.sqrt() - Menghitung akar kuadrat
  • • Math.pow() - Menghitung pangkat
  • • Math.random() - Menghasilkan angka random
  • • Math.PI dan Math.E - Konstanta matematika

📋 Praktik 4: ArrayList

Struktur Project:

📁 PraktikLibrary/
  📁 src/
    📄 DaftarNama.java 
// File: DaftarNama.java
import java.util.ArrayList;
import java.util.Scanner;

public class DaftarNama {
    public static void main(String[] args) {
        // Membuat ArrayList untuk menyimpan nama
        ArrayList<String> daftarNama = new ArrayList<>();
        Scanner input = new Scanner(System.in);
        
        // Menambah beberapa nama
        daftarNama.add("Budi");
        daftarNama.add("Sari");
        daftarNama.add("Andi");
        
        System.out.println("=== DAFTAR NAMA ===");
        
        // Menampilkan semua nama
        for (int i = 0; i < daftarNama.size(); i++) {
            System.out.println((i+1) + ". " + daftarNama.get(i));
        }
        
        // Menambah nama baru
        System.out.print("\nTambah nama baru: ");
        String namaBaru = input.nextLine();
        daftarNama.add(namaBaru);
        
        System.out.println("\nDaftar nama setelah ditambah:");
        for (String nama : daftarNama) {
            System.out.println("- " + nama);
        }
        
        System.out.println("\nTotal nama: " + daftarNama.size());
        
        input.close();
    }
}
Penjelasan:
  • • ArrayList<String> - List dinamis untuk menyimpan string
  • • add() - Menambah elemen ke list
  • • get(i) - Mengambil elemen pada index i
  • • size() - Mendapat jumlah elemen

Troubleshooting Guide

Solusi untuk masalah umum saat menggunakan library Java!

🚨 Error Import Paling Sering

❌ "Cannot find symbol" Error

// Error ini muncul karena:
Scanner input = new Scanner(System.in); // Tidak ada import

✅ Solusi:

import java.util.Scanner; // Tambahkan import

public class MyClass {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in); // Sekarang OK
    }
}

⚠️ "Package does not exist" Error

Terjadi saat menggunakan library eksternal yang belum ditambahkan:

import com.mysql.cj.jdbc.Driver; // Error jika MySQL connector belum di-add

✅ Solusi:

  1. 1. Download file JAR library yang diperlukan
  2. 2. Klik kanan project → Properties
  3. 3. Libraries → Add JAR/Folder
  4. 4. Pilih file JAR yang sudah didownload

ℹ️ "Unused import" Warning

Import ada tapi tidak digunakan dalam kode:

import java.util.ArrayList; // Warning: tidak digunakan
import java.util.Scanner;

public class Test {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in); // Hanya Scanner yang dipakai
    }
}

✅ Solusi: Hapus import yang tidak digunakan atau gunakan Ctrl+Shift+I

🔍 Masalah NetBeans Umum

Auto-Import Tidak Bekerja

Kemungkinan Penyebab:

  • • NetBeans cache corrupt
  • • Project tidak di-build dengan benar
  • • Library path tidak ditemukan
  • • Settings auto-import dimatikan

Solusi:

  • • Clean and Build project (Shift+F11)
  • • Restart NetBeans
  • • Tools → Options → Editor → Code Completion
  • • Cek "Auto Popup Completion Window"

Program Tidak Bisa Dijalankan

Error: "Could not find or load main class"

Solusi: Pastikan ada method main dan class name sesuai dengan filename

Error: "Build failed"

Solusi: Cek error di Output window, biasanya ada syntax error atau import error

Hindari:

  • ❌ Copy-paste kode tanpa memahami
  • ❌ Mengabaikan warning NetBeans
  • ❌ Tidak membaca error message
  • ❌ Import library yang tidak diperlukan
