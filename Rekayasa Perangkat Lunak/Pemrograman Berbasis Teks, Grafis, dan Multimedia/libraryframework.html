Apa itu Library?

📚 Definisi Library

Library adalah kumpulan kode program yang sudah jadi dan bisa digunakan ulang untuk menyelesaikan tugas-tugas tertentu. Seperti perpustakaan buku, Library berisi "buku-buku kode" yang bisa kita "pinjam" untuk digunakan dalam project kita. Library menyediakan fungsi-fungsi siap pakai yang dapat dipanggil kapan saja dibutuhkan.

Contoh Sederhana:

Daripada menulis kode untuk menghitung akar kuadrat, kita bisa menggunakan Math.sqrt() dari Java Standard Library. Atau menggunakan JCalendar untuk date picker daripada membuat sendiri.

🔧 Karakteristik Library

✅ Spesifik

Menyelesaikan masalah tertentu

🔄 Reusable

Bisa digunakan berulang kali

🎯 Fokus

Satu Library untuk satu tujuan

📦 Modular

Bisa dikombinasikan dengan Library lain

Apa itu Framework?

🏗️ Definisi Framework

Framework adalah "kerangka kerja" atau struktur dasar yang sudah disiapkan untuk membangun aplikasi. Framework menyediakan arsitektur dan aturan main yang harus diikuti. Seperti kerangka rumah yang sudah ada, kita tinggal mengisi bagian-bagian yang dibutuhkan sesuai dengan pola yang sudah ditentukan.

Perbedaan dengan Library:

Library: Kita yang memanggil Library (kita kontrol alur program)
Framework: Framework yang memanggil kode kita (framework kontrol alur program)
Contoh: Saat pakai Library, kita panggil fungsinya. Saat pakai Framework, kita ikuti aturan dan struktur yang sudah ada.

⚡ Keunggulan Framework

🏃‍♂️ Cepat

Struktur sudah ada, tinggal isi konten

📏 Standar

Mengikuti pola yang sudah teruji

🔒 Aman

Keamanan sudah dipikirkan

🤝 Konsisten

Semua developer mengikuti aturan yang sama

📁 Jenis Library di NetBeans

1. Java Standard Library (Built-in)

Library yang sudah tersedia di Java/NetBeans:

  • • java.util (Collections, Date, Scanner, dll)
  • • java.io (File handling, Input/Output)
  • • javax.swing (GUI Components)
  • • java.sql (Database connectivity)

2. External Libraries (Third-party)

Library dari luar yang kita tambahkan:

  • • JAR files (.jar) - seperti JCalendar, Apache Commons
  • • Maven dependencies - dikelola otomatis
  • • Library khusus - sesuai kebutuhan project

⚙️ Cara Menambah Library

Metode 1: Manual JAR

  1. 1. Klik kanan pada project
  2. 2. Pilih "Properties"
  3. 3. Pilih "Libraries" di sidebar
  4. 4. Klik "Add JAR/Folder"
  5. 5. Pilih file JAR yang ingin ditambahkan

Metode 2: Maven Project

Untuk project Maven:

  1. 1. Buat Maven Project di NetBeans
  2. 2. Buka file pom.xml
  3. 3. Tambahkan dependency di dalam tag <dependencies>
  4. 4. NetBeans akan otomatis download Library

🎯 Project: Aplikasi Kalkulator dengan JCalendar

Kita akan membuat aplikasi sederhana yang menggunakan Library JCalendar untuk memilih tanggal.

Struktur Project:

📁 KalkulatorTanggal/
├── 📁 src/
│   └── 📁 main/
│       └── 📄 KalkulatorTanggal.java
├── 📁 lib/
│   └── 📄 jcalendar-1.4.jar
└── 📄 README.md

📥 Langkah 1: Download Library

  1. 1. Kunjungi website resmi JCalendar atau Maven Repository
  2. 2. Download file JAR (misal: jcalendar-1.4.jar)
  3. 3. Simpan file JAR di folder yang mudah diakses
  4. 4. Atau gunakan Maven dengan menambahkan dependency di pom.xml
Alternatif Maven Dependency:
<dependency>
    <groupId>com.toedter</groupId>
    <artifactId>jcalendar</artifactId>
    <version>1.4</version>
</dependency>

⚙️ Langkah 2: Setup Project di NetBeans

  1. 1. Buat New Project → Java Application
  2. 2. Nama project: KalkulatorTanggal
  3. 3. Klik kanan project → Properties
  4. 4. Pilih Libraries → Add JAR/Folder
  5. 5. Pilih file jcalendar-1.4.jar

💾 Langkah 3: Kode Program

File: src/main/KalkulatorTanggal.java

package main;

import javax.swing.*;
import java.awt.*;
import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;
import com.toedter.calendar.JDateChooser;
import java.util.Date;
import java.util.concurrent.TimeUnit;

public class KalkulatorTanggal extends JFrame {
    private JDateChooser tanggalAwal;
    private JDateChooser tanggalAkhir;
    private JLabel hasilLabel;
    private JButton hitungButton;
    
    public KalkulatorTanggal() {
        initComponents();
    }
    
    private void initComponents() {
        setTitle("Kalkulator Selisih Tanggal");
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setLayout(new GridBagLayout());
        GridBagConstraints gbc = new GridBagConstraints();
        
        // Komponen UI
        tanggalAwal = new JDateChooser();
        tanggalAkhir = new JDateChooser();
        hitungButton = new JButton("Hitung Selisih");
        hasilLabel = new JLabel("Pilih tanggal untuk menghitung selisih");
        
        // Layout
        gbc.insets = new Insets(10, 10, 10, 10);
        
        gbc.gridx = 0; gbc.gridy = 0;
        add(new JLabel("Tanggal Awal:"), gbc);
        
        gbc.gridx = 1;
        add(tanggalAwal, gbc);
        
        gbc.gridx = 0; gbc.gridy = 1;
        add(new JLabel("Tanggal Akhir:"), gbc);
        
        gbc.gridx = 1;
        add(tanggalAkhir, gbc);
        
        gbc.gridx = 0; gbc.gridy = 2; gbc.gridwidth = 2;
        add(hitungButton, gbc);
        
        gbc.gridy = 3;
        add(hasilLabel, gbc);
        
        // Event Handler
        hitungButton.addActionListener(new ActionListener() {
            @Override
            public void actionPerformed(ActionEvent e) {
                hitungSelisih();
            }
        });
        
        pack();
        setLocationRelativeTo(null);
    }
    
    private void hitungSelisih() {
        Date awal = tanggalAwal.getDate();
        Date akhir = tanggalAkhir.getDate();
        
        if (awal != null && akhir != null) {
            long selisihMilidetik = Math.abs(akhir.getTime() - awal.getTime());
            long selisihHari = TimeUnit.DAYS.convert(selisihMilidetik, TimeUnit.MILLISECONDS);
            
            hasilLabel.setText("Selisih: " + selisihHari + " hari");
        } else {
            hasilLabel.setText("Mohon pilih kedua tanggal!");
        }
    }
    
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            new KalkulatorTanggal().setVisible(true);
        });
    }
}

🚀 Langkah 4: Jalankan Program

  1. 1. Klik Run Project (F6) atau tombol hijau
  2. 2. Aplikasi akan terbuka dengan 2 date picker
  3. 3. Pilih tanggal awal dan akhir
  4. 4. Klik "Hitung Selisih" untuk melihat hasilnya
