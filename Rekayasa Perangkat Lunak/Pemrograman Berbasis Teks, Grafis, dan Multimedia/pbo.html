Inheritance (Pewarisan)

Belajar cara class mewarisi sifat dari class lain!

Apa itu Inheritance? 🤔

Inheritance adalah kemampuan sebuah class (child/subclass) untuk mewarisi properties dan methods dari class lain (parent/superclass). Ini seperti anak yang mewarisi sifat dari orangtuanya!

✨ Keuntungan Inheritance:

  • • Code Reusability: Tidak perlu menulis ulang kode yang sama
  • • Maintainability: Mudah mengubah dan memperbaiki kode
  • • Extensibility: Mudah menambah fitur baru

Contoh Inheritance 💻

// Parent Class (Superclass)
class Hewan {
    protected String nama;
    protected int umur;
    
    public Hewan(String nama, int umur) {
        this.nama = nama;
        this.umur = umur;
    }
    
    public void makan() {
        System.out.println(nama + " sedang makan");
    }
    
    public void tidur() {
        System.out.println(nama + " sedang tidur");
    }
}

// Child Class (Subclass)
class Kucing extends Hewan {
    private String ras;
    
    public Kucing(String nama, int umur, String ras) {
        super(nama, umur); // Memanggil constructor parent
        this.ras = ras;
    }
    
    public void meong() {
        System.out.println(nama + " berkata: Meong!");
    }
    
    // Override method dari parent
    @Override
    public void makan() {
        System.out.println(nama + " makan ikan");
    }
}

Polymorphism

Satu method, banyak bentuk implementasi!

Apa itu Polymorphism? 🎪

Polymorphism berarti "banyak bentuk". Dalam Java, ini memungkinkan satu method berperilaku berbeda tergantung object yang memanggilnya. Seperti tombol "play" yang bisa memutar musik, video, atau game!

🔄

Method Overriding

Subclass mengubah implementasi method parent

⚡

Dynamic Method Dispatch

Java memilih method yang tepat saat runtime

Contoh Polymorphism 🎨

// Parent class
class Bentuk {
    public void gambar() {
        System.out.println("Menggambar bentuk umum");
    }
    
    public double hitungLuas() {
        return 0;
    }
}

// Child classes
class Lingkaran extends Bentuk {
    private double radius;
    
    public Lingkaran(double radius) {
        this.radius = radius;
    }
    
    @Override
    public void gambar() {
        System.out.println("Menggambar lingkaran ⭕");
    }
    
    @Override
    public double hitungLuas() {
        return Math.PI * radius * radius;
    }
}

class Persegi extends Bentuk {
    private double sisi;
    
    public Persegi(double sisi) {
        this.sisi = sisi;
    }
    
    @Override
    public void gambar() {
        System.out.println("Menggambar persegi ⬜");
    }
    
    @Override
    public double hitungLuas() {
        return sisi * sisi;
    }
}

Abstraction

Menyembunyikan kompleksitas, menampilkan yang penting!

Apa itu Abstraction? 🎭

Abstraction adalah proses menyembunyikan detail implementasi yang rumit dan hanya menampilkan fitur penting kepada user. Seperti saat kamu menggunakan smartphone - kamu tidak perlu tahu cara kerja processor, tapi bisa menggunakan aplikasi!

🔍 Cara Implementasi Abstraction:

  • • Abstract Class: Class yang tidak bisa diinstansiasi langsung
  • • Abstract Method: Method tanpa implementasi (harus di-override)
  • • Interface: Kontrak yang harus dipenuhi class

Abstract Class Example 🏗️

// Abstract class
abstract class Kendaraan {
    protected String merk;
    protected int tahun;
    
    public Kendaraan(String merk, int tahun) {
        this.merk = merk;
        this.tahun = tahun;
    }
    
    // Method biasa (concrete method)
    public void info() {
        System.out.println("Kendaraan: " + merk + " (" + tahun + ")");
    }
    
    // Abstract method (harus diimplementasi di subclass)
    public abstract void nyalakanMesin();
    public abstract void bergerak();
}

// Concrete class
class Mobil extends Kendaraan {
    public Mobil(String merk, int tahun) {
        super(merk, tahun);
    }
    
    @Override
    public void nyalakanMesin() {
        System.out.println("Mobil " + merk + " mesin menyala: Vroom! 🚗");
    }
    
    @Override
    public void bergerak() {
        System.out.println("Mobil bergerak di jalan raya");
    }
}

class Motor extends Kendaraan {
    public Motor(String merk, int tahun) {
        super(merk, tahun);
    }
    
    @Override
    public void nyalakanMesin() {
        System.out.println("Motor " + merk + " mesin menyala: Brum! 🏍️");
    }
    
    @Override
    public void bergerak() {
        System.out.println("Motor bergerak lincah di jalanan");
    }
}

Demo Abstract Class:

📋

Aturan Abstract Class

  • • Tidak bisa diinstansiasi langsung (tidak bisa new AbstractClass())
  • • Bisa punya method biasa dan abstract method
  • • Subclass harus mengimplementasi semua abstract method
  • • Bisa punya constructor, field, dan method biasa
🔌

Interface

Kontrak yang harus dipenuhi oleh class!

Apa itu Interface? 📋

Interface adalah kontrak atau perjanjian yang harus dipenuhi oleh class yang mengimplementasinya. Seperti kontrak kerja - semua karyawan harus bisa "bekerja", "hadir tepat waktu", "menyelesaikan tugas", tapi cara implementasinya bisa berbeda untuk programmer, designer, atau manager!

✅

Keuntungan Interface

  • • Multiple inheritance
  • • Loose coupling
  • • Standardisasi
🎯

Karakteristik Interface

  • • Method abstract (Java 8+ bisa default)
  • • Variabel public static final
  • • Tidak ada constructor
  • • Bisa multiple inheritance

Contoh Interface 🎪

// Interface
interface Terbang {
    // Konstanta (otomatis public static final)
    int KETINGGIAN_MAKSIMAL = 10000;
    
    // Abstract methods (otomatis public abstract)
    void lepasLandas();
    void terbang();
    void mendarat();
    
    // Default method (Java 8+) - opsional untuk diimplementasi
    default void cekCuaca() {
        System.out.println("Mengecek kondisi cuaca sebelum terbang");
    }
}

interface Berenang {
    void menyelam();
    void berenang();
    void kePermukaan();
}

// Class yang implement interface
class Pesawat implements Terbang {
    private String jenis;
    
    public Pesawat(String jenis) {
        this.jenis = jenis;
    }
    
    @Override
    public void lepasLandas() {
        System.out.println(jenis + " lepas landas dari runway ✈️");
    }
    
    @Override
    public void terbang() {
        System.out.println(jenis + " terbang di ketinggian " + KETINGGIAN_MAKSIMAL + " meter");
    }
    
    @Override
    public void mendarat() {
        System.out.println(jenis + " mendarat dengan mulus");
    }
}

// Multiple interface implementation
class Bebek implements Terbang, Berenang {
    @Override
    public void lepasLandas() {
        System.out.println("Bebek mengepakkan sayap dan terbang 🦆");
    }
    
    @Override
    public void terbang() {
        System.out.println("Bebek terbang rendah di atas air");
    }
    
    @Override
    public void mendarat() {
        System.out.println("Bebek mendarat di permukaan air");
    }
    
    @Override
    public void menyelam() {
        System.out.println("Bebek menyelam mencari ikan");
    }
    
    @Override
    public void berenang() {
        System.out.println("Bebek berenang dengan tenang");
    }
    
    @Override
    public void kePermukaan() {
        System.out.println("Bebek naik ke permukaan air");
    }
}

Interface vs Abstract Class

Aspek Interface Abstract Class
Multiple Inheritance ✅ Bisa implement banyak ❌ Hanya extend satu
Method Implementation Semua abstract Bisa ada concrete method
Constructor ❌ Tidak ada ✅ Bisa ada
Variabel public static final Bisa berbagai modifier

Tugas 2: Sistem Kendaraan

  1. Buat class parent Kendaraan dengan atribut merk, tahun, dan method info()
