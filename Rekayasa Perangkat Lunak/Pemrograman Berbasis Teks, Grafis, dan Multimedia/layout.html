Pengenalan Layout UI

🖥️Apa itu User Interface (UI)?

User Interface atau antarmuka pengguna adalah bagian dari aplikasi yang berinteraksi langsung dengan pengguna. Seperti dashboard mobil yang memiliki tombol, layar, dan indikator.

Contoh UI: Tombol, text field, label, menu, dan lain-lain.

📐Apa itu Layout?

Layout adalah cara mengatur dan menempatkan komponen-komponen UI di dalam aplikasi. Seperti menata furniture di dalam ruangan agar terlihat rapi dan nyaman.

☕Java Swing di NetBeans

Java Swing adalah toolkit untuk membuat aplikasi desktop dengan GUI (Graphical User Interface). NetBeans menyediakan editor visual yang memudahkan kita mendesain layout tanpa coding manual.

Desain Form yang Menarik

🎨Prinsip Desain Form

✨ Konsistensi

Gunakan ukuran, warna, dan jarak yang sama untuk komponen sejenis.

📏 Alignment

Sejajarkan komponen dengan rapi, tidak berantakan.

🎯 Hierarki

Buat prioritas visual dengan ukuran dan warna yang berbeda.

🌈 Kontras

Pastikan teks mudah dibaca dengan kontras warna yang cukup.

Gunakan Label yang Jelas

Praktik Membuat Form

🎯Tujuan Praktik

Membuat form login sederhana menggunakan Java Swing di NetBeans dengan layout yang menarik.

📁Struktur Project

📁 FormLoginApp/
📁 src/

🔧Langkah 1: Membuat Project Baru

1. Buka NetBeans IDE

File → New Project → Java → Java Application

2. Atur Project Name

Project Name: FormLoginApp

3. Klik Finish

Project akan dibuat dengan main class otomatis

🎨Langkah 2: Membuat JFrame Form

1. Klik kanan pada package

Klik kanan pada package "formloginapp" → New → JFrame Form

2. Atur Class Name

Class Name: FormLogin

Package akan otomatis terisi: formloginapp

3. Klik Finish

Form designer akan terbuka dengan 2 tab: Design dan Source

💡 Tips: Pastikan tab "Design" aktif untuk mulai mendesain form secara visual.

🏗️Langkah 3: Mendesain Layout

Komponen yang Dibutuhkan:

  • • 3 JLabel (untuk judul "Form Login", "Username", dan "Password")
  • • 1 JTextField (untuk input username)
  • • 1 JPasswordField (untuk input password yang tersembunyi)
  • • 2 JButton (untuk "Login" dan "Cancel")

Langkah Mendesain:

  1. 1. Klik kanan pada JFrame → Set Layout → Absolute Layout (null)
  2. 2. Buka Palette (Window → Palette jika tidak terlihat)
  3. 3. Drag JLabel dari Palette untuk judul, atur text: "Form Login"
  4. 4. Drag JLabel untuk "Username:" dan "Password:"
  5. 5. Drag JTextField untuk username dan JPasswordField untuk password
  6. 6. Drag 2 JButton, atur text: "Login" dan "Cancel"
  7. 7. Atur posisi dan ukuran dengan drag & drop

Pengaturan Properties:

  • • Klik komponen → Properties window → ubah text, font, warna
  • • Atur Variable Name: txtUsername, txtPassword, btnLogin, btnCancel
  • • Atur ukuran form: klik JFrame → Properties → preferredSize

💻Langkah 4: Kode Program 

// File: FormLogin.java
public class FormLogin extends javax.swing.JFrame {
    
    // Constructor
    public FormLogin() {
        initComponents();
        setLocationRelativeTo(null); // Center window
        setTitle("Form Login Sederhana");
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setResizable(false); // Tidak bisa diubah ukurannya
    }
    
    // Event handler untuk tombol Login
    private void btnLoginActionPerformed(java.awt.event.ActionEvent evt) {
        String username = txtUsername.getText().trim();
        String password = new String(txtPassword.getPassword());
        
        // Validasi input kosong
        if(username.isEmpty() || password.isEmpty()) {
            javax.swing.JOptionPane.showMessageDialog(this, 
                "Username dan Password tidak boleh kosong!", 
                "Peringatan", 
                javax.swing.JOptionPane.WARNING_MESSAGE);
            return;
        }
        
        // Cek login
        if(username.equals("admin") && password.equals("123")) {
            javax.swing.JOptionPane.showMessageDialog(this, 
                "Login Berhasil!\nSelamat datang " + username,
                "Sukses",
                javax.swing.JOptionPane.INFORMATION_MESSAGE);
            // Bisa ditambahkan: buka form utama aplikasi
            // new FormUtama().setVisible(true);
            // this.dispose(); // tutup form login
        } else {
            javax.swing.JOptionPane.showMessageDialog(this, 
                "Username atau Password salah!\nSilakan coba lagi.", 
                "Login Gagal", 
                javax.swing.JOptionPane.ERROR_MESSAGE);
            txtPassword.setText(""); // Clear password
            txtUsername.requestFocus(); // Focus ke username
        }
    }
    
    // Event handler untuk tombol Cancel
    private void btnCancelActionPerformed(java.awt.event.ActionEvent evt) {
        txtUsername.setText("");
        txtPassword.setText("");
        txtUsername.requestFocus();
    }
    
    // Main method untuk menjalankan form
    public static void main(String args[]) {
        // Set Look and Feel
        try {
            javax.swing.UIManager.setLookAndFeel(
                javax.swing.UIManager.getSystemLookAndFeel());
        } catch (Exception ex) {
            ex.printStackTrace();
        }
        
        // Jalankan form
        java.awt.EventQueue.invokeLater(() -> {
            new FormLogin().setVisible(true);
        });
    }
}
