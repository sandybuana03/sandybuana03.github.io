Pengenalan UML

Mari mengenal Unified Modeling Language!

🎯 Apa itu UML?

UML (Unified Modeling Language) adalah bahasa pemodelan visual yang digunakan untuk merancang, mendokumentasikan, dan mengkomunikasikan sistem perangkat lunak.

"UML seperti bahasa gambar yang dipahami oleh semua programmer di dunia!"

🏆 Mengapa UML Penting?

💬 Komunikasi yang jelas antar tim
📋 Dokumentasi sistem yang baik
🔍 Analisis sistem yang mendalam
⚡ Pengembangan yang lebih efisien

📊 Jenis-jenis Diagram UML

Diagram Struktural

Menggambarkan struktur statis sistem

  • • Class Diagram - Struktur class dan hubungannya
  • • Object Diagram - Instance dari class pada waktu tertentu
  • • Component Diagram - Komponen sistem dan dependensinya
  • • Package Diagram - Organisasi elemen dalam paket

Diagram Behavioral

Menggambarkan perilaku dinamis sistem

  • • Use Case Diagram - Interaksi pengguna dengan sistem
  • • Activity Diagram - Alur kerja dan proses bisnis
  • • Sequence Diagram - Interaksi objek berdasarkan waktu
  • • State Diagram - Perubahan state objek

Use Case Diagram

Menggambarkan interaksi pengguna dengan sistem

🎯 Apa itu Use Case Diagram?

Use Case Diagram menggambarkan fungsi-fungsi yang dapat dilakukan oleh pengguna dalam sistem. Ini seperti daftar fitur yang bisa digunakan!

🧩 Komponen Use Case Diagram

👨‍💼 Actor (Aktor)

Pengguna atau sistem lain yang berinteraksi dengan sistem kita

⚡ Use Case

Fungsi atau fitur yang dapat dilakukan dalam sistem

🔗 Association

Garis yang menghubungkan actor dengan use case

📦 System Boundary

Kotak yang membatasi sistem yang kita buat

🎨 Contoh Use Case Diagram - Sistem E-Learning

Penjelasan: Diagram ini menunjukkan bahwa Siswa dan Guru sama-sama bisa Login, tetapi memiliki hak akses yang berbeda. Siswa bisa melihat materi, mengerjakan kuis, dan melihat nilai. Guru bisa upload materi, membuat kuis, dan juga melihat materi.

📝 Langkah Membuat Use Case Diagram

1

Identifikasi Actor

Siapa saja yang akan menggunakan sistem?

2

Tentukan Use Case

Apa saja yang bisa dilakukan di sistem?

3

Hubungkan dengan Garis

Tarik garis dari actor ke use case yang bisa mereka lakukan

4

Buat System Boundary

Kotak untuk membatasi sistem kita

Class Diagram

Struktur dan hubungan antar class dalam sistem

🎯 Apa itu Class Diagram?

Class Diagram menggambarkan struktur sistem dengan menunjukkan class, atribut, method, dan hubungan antar class. Ini seperti blueprint detail dari sistem kita!

🧩 Komponen Class Diagram

📦 Class Name

Nama class yang akan dibuat

📊 Attributes

Variabel atau data yang dimiliki class

⚙️ Methods

Fungsi atau aksi yang bisa dilakukan class

🔗 Relationships

Hubungan antar class (inheritance, association, dll)

🎨 Contoh Class Diagram - Sistem Perpustakaan

Penjelasan Multiplicity:

• 1 = Tepat satu

• * = Nol atau lebih (many)

• 1..* = Satu atau lebih

• 0..1 = Nol atau satu (optional)

👁️ Visibility Modifier

+ Public

Dapat diakses dari mana saja

Contoh: + getName(): string

- Private

Hanya dapat diakses dari class itu sendiri

Contoh: - id: int

# Protected

Dapat diakses oleh class turunan

Contoh: # password: string

~ Package

Dapat diakses dalam package yang sama

Contoh: ~ config: object

🔗 Jenis Hubungan dalam Class Diagram

Association

Hubungan "menggunakan" antar class

Contoh: Student → Course (garis biasa)

Inheritance

Hubungan "adalah" (is-a)

Contoh: Car → Vehicle (panah segitiga kosong)

Composition

Hubungan "bagian dari" yang kuat

Contoh: House → Room (diamond hitam)

Aggregation

Hubungan "memiliki" yang lemah

Contoh: Team → Player (diamond kosong)

Activity Diagram

Menggambarkan alur proses dan aktivitas dalam sistem

🎯 Apa itu Activity Diagram?

Activity Diagram menggambarkan alur kerja (workflow) atau proses bisnis dalam sistem. Seperti flowchart yang menunjukkan langkah-langkah yang harus dilakukan!

🧩 Komponen Activity Diagram

🟢 Start Node

Titik awal proses (lingkaran hitam)

📋 Activity

Kegiatan atau aksi yang dilakukan

💎 Decision

Titik keputusan (diamond)

🔄 Fork/Join

Pemisahan atau penggabungan alur

🔴 End Node

Titik akhir proses

➡️ Flow

Panah yang menunjukkan arah alur

🎨 Contoh Activity Diagram - Proses Login

📝 Tips Membuat Activity Diagram

1

Mulai dari Start Node

Setiap diagram harus dimulai dengan lingkaran hitam

2

Gunakan Kata Kerja

Activity harus menggunakan kata kerja aktif

3

Beri Label pada Decision

Setiap cabang dari decision harus diberi label

4

Akhiri dengan End Node

Setiap alur harus berakhir di end node

Sequence Diagram

Menggambarkan interaksi antar objek berdasarkan waktu

🎯 Apa itu Sequence Diagram?

Sequence Diagram menggambarkan bagaimana objek-objek berinteraksi satu sama lain dalam urutan waktu tertentu. Seperti percakapan antar objek!

🧩 Komponen Sequence Diagram

👤 Actor/Object

Entitas yang terlibat dalam interaksi

📏 Lifeline

Garis vertikal yang menunjukkan keberadaan objek

💬 Message

Panah yang menunjukkan komunikasi antar objek

⚡ Activation

Kotak yang menunjukkan objek sedang aktif

🎨 Contoh Sequence Diagram - Pembelian Online

🔄 Jenis Message dalam Sequence Diagram

Synchronous Message

Panah penuh - pengirim menunggu balasan

Asynchronous Message

Panah terbuka - pengirim tidak menunggu

Return Message

Garis putus-putus - balasan dari message

Self Message

Panah ke diri sendiri - objek memanggil method sendiri

Tugas Praktik UML

Saatnya menerapkan pengetahuan UML yang sudah dipelajari!

🎯 Tugas 1: Use Case Diagram

Skenario: Sistem Manajemen Sekolah

Buatlah Use Case Diagram untuk sistem manajemen sekolah dengan ketentuan berikut:

Actor:

  • Siswa: dapat melihat jadwal, nilai, dan absensi
  • Guru: dapat input nilai, absensi, dan materi
  • Admin: dapat kelola data siswa, guru, dan jadwal

Tugas: Gambar Use Case Diagram lengkap dengan system boundary dan hubungan antar actor dengan use case!

🏗️ Tugas 2: Class Diagram

Skenario: Sistem Rental Mobil

Buatlah Class Diagram untuk sistem rental mobil dengan class-class berikut:

Class Customer:

  • - id: int
  • - nama: string
  • - alamat: string
  • - telepon: string
  • + rentCar(): void
  • + returnCar(): void

Class Car:

  • - id: int
  • - merk: string
  • - model: string
  • - tahun: int
  • - hargaPerHari: double
  • + isAvailable(): boolean
  • + getInfo(): string

Class Rental:

  • - id: int
  • - tanggalMulai: Date
  • - tanggalSelesai: Date
  • - totalHarga: double
  • + hitungTotal(): double
  • + perpanjangRental(): void

Tugas:

  • Gambar ketiga class dengan format yang benar (nama class, attributes, methods)
  • Buat hubungan association antara Customer-Rental dan Car-Rental
  • Tambahkan multiplicity yang sesuai (1 Customer bisa punya banyak Rental, 1 Car bisa di-rental berkali-kali)
  • Gunakan visibility modifier yang tepat (+ untuk public, - untuk private)

⚡ Tugas 3: Activity Diagram

Skenario: Proses Peminjaman Buku Perpustakaan

Buatlah Activity Diagram untuk proses peminjaman buku dengan alur:

1. Siswa datang ke perpustakaan

2. Cari buku yang diinginkan

3. Cek ketersediaan buku

4. Jika tersedia: pinjam buku, jika tidak: cari buku lain

5. Daftar peminjaman

6. Selesai

Tugas: Gambar lengkap dengan start node, decision, dan end node!

📊 Tugas 4: Sequence Diagram

Skenario: Proses Registrasi User Baru

Buatlah Sequence Diagram dengan objek: User, Website, Database, Email Service

Alur interaksi:

1. User mengisi form registrasi

2. Website validasi data

3. Website simpan ke database

4. Database konfirmasi penyimpanan

5. Website kirim email verifikasi

6. Email service kirim email

7. Website tampilkan pesan sukses

Tugas: Gambar dengan lifeline, activation box, dan message yang benar!

📋 Petunjuk Pengerjaan

• Gunakan tools seperti Draw.io, Lucidchart, atau StarUML

• Pastikan diagram mudah dibaca dan rapi

• Berikan label yang jelas pada setiap elemen

• Ikuti standar notasi UML yang benar

• Kumpulkan dalam format PDF atau gambar (PNG/JPG)
