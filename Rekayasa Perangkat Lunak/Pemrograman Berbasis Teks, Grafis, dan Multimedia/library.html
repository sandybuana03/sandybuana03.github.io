📚 Pengenalan GUI Java

🤖 Apa itu GUI?

GUI (Graphical User Interface) adalah antarmuka grafis yang memungkinkan pengguna berinteraksi dengan komputer menggunakan elemen visual seperti tombol, menu, dan ikon.

🎨 Contoh GUI dalam Kehidupan Sehari-hari:

📱 Aplikasi smartphone
💻 Program komputer
🎮 Game interface
🌐 Website interaktif

☕ Java Swing Library

Java Swing adalah library GUI yang powerful untuk membuat aplikasi desktop. Swing menyediakan berbagai komponen siap pakai seperti button, textfield, dan label.

✨ Keunggulan Java Swing:

  • ✓ Cross-platform (bisa jalan di Windows, Mac, Linux)
  • ✓ Komponen yang lengkap dan customizable
  • ✓ Terintegrasi dengan NetBeans IDE
  • ✓ Mudah dipelajari untuk pemula

🧩 Komponen Swing

📦 Kategori Komponen Swing

🏠 Container Components

  • JFrame: Jendela utama aplikasi dengan title bar
  • JPanel: Panel untuk mengelompokkan komponen
  • JDialog: Jendela dialog untuk pesan atau input
  • JScrollPane: Panel dengan scroll bar otomatis
  • JTabbedPane: Panel dengan tab untuk navigasi

🎛️ Input Components

  • JTextField: Input teks satu baris
  • JTextArea: Input teks multi baris
  • JPasswordField: Input password tersembunyi
  • JButton: Tombol untuk memicu aksi
  • JCheckBox: Kotak centang untuk pilihan ya/tidak

📋 Selection Components

  • JRadioButton: Pilihan tunggal dalam grup
  • JComboBox: Dropdown list pilihan
  • JList: Daftar item yang bisa dipilih
  • JSlider: Slider untuk memilih nilai
  • JSpinner: Input angka dengan tombol +/-

📄 Display Components

  • JLabel: Menampilkan teks atau gambar
  • JTable: Tabel untuk menampilkan data
  • JTree: Struktur pohon hierarkis
  • JProgressBar: Bar progress untuk loading
  • JToolTip: Tooltip informasi tambahan

🎛️ Advanced Components

  • JMenuBar: Menu bar aplikasi
  • JToolBar: Toolbar dengan tombol aksi
  • JFileChooser: Dialog pemilihan file
  • JColorChooser: Dialog pemilihan warna
  • JSplitPane: Panel yang dapat dibagi

🔍 Detail Komponen Penting:

JFrame - Jendela Utama

Container utama untuk aplikasi desktop Swing

Fitur utama: Title bar, minimize/maximize/close buttons, menu bar, content pane
JTable - Tabel Data

Komponen untuk menampilkan data dalam format tabel

Fitur utama: Sorting, filtering, editing cell, custom renderer, scrollable
JTree - Struktur Hierarkis

Menampilkan data dalam struktur pohon (parent-child)

Fitur utama: Expand/collapse nodes, custom icons, drag & drop, selection
JFileChooser - Dialog File

Dialog untuk memilih file atau direktori

Fitur utama: File filtering, multiple selection, preview, custom accessory

⚡ Event Handling

Event Handling adalah cara program merespons aksi pengguna seperti klik tombol, ketik teks, atau gerakan mouse. Ini yang membuat aplikasi menjadi interaktif! 🎮

🎯 Jenis-jenis Event

👆 Mouse Events

  • • mouseClicked: Klik tombol mouse
  • • mousePressed: Tombol mouse ditekan
  • • mouseReleased: Tombol mouse dilepas
  • • mouseEntered: Mouse masuk area komponen
  • • mouseExited: Mouse keluar area komponen
  • • mouseMoved: Mouse bergerak
  • • mouseDragged: Seret dengan mouse

🎬 Action Events

  • • actionPerformed: Tombol diklik atau Enter ditekan
  • • itemStateChanged: Checkbox/Radio berubah
  • • valueChanged: Nilai komponen berubah
  • • stateChanged: State komponen berubah

⌨️ Keyboard Events

  • • keyPressed: Tombol keyboard ditekan
  • • keyReleased: Tombol keyboard dilepas
  • • keyTyped: Karakter diketik

🪟 Window Events

  • • windowOpened: Jendela dibuka
  • • windowClosing: Jendela akan ditutup
  • • windowClosed: Jendela sudah ditutup
  • • windowActivated: Jendela menjadi aktif

🔧 Contoh Implementasi Event

// Contoh ActionListener untuk JButton
JButton button = new JButton("Klik Saya");
button.addActionListener(new ActionListener() {
    public void actionPerformed(ActionEvent e) {
        JOptionPane.showMessageDialog(null, "Button diklik!");
    }
});

// Atau menggunakan Lambda Expression (Java 8+)
button.addActionListener(e -> {
    JOptionPane.showMessageDialog(null, "Button diklik!");
});

🎨 Langkah 2: Buat GUI Class

File: src/kalkulator/KalkulatorFrame.java

package kalkulator;

import javax.swing.*;
import java.awt.*;
import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;

public class KalkulatorFrame extends JFrame implements ActionListener {
    
    private JTextField txtAngka1, txtAngka2, txtHasil;
    private JButton btnTambah, btnKurang, btnKali, btnBagi, btnClear;
    
    public KalkulatorFrame() {
        initComponents();
    }
    
    private void initComponents() {
        setTitle("Kalkulator Sederhana");
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setLayout(new GridLayout(6, 2, 5, 5));
        
        // Inisialisasi komponen
        add(new JLabel("Angka 1:"));
        txtAngka1 = new JTextField();
        add(txtAngka1);
        
        add(new JLabel("Angka 2:"));
        txtAngka2 = new JTextField();
        add(txtAngka2);
        
        btnTambah = new JButton("+");
        btnTambah.addActionListener(this);
        add(btnTambah);
        
        btnKurang = new JButton("-");
        btnKurang.addActionListener(this);
        add(btnKurang);
        
        btnKali = new JButton("*");
        btnKali.addActionListener(this);
        add(btnKali);
        
        btnBagi = new JButton("/");
        btnBagi.addActionListener(this);
        add(btnBagi);
        
        add(new JLabel("Hasil:"));
        txtHasil = new JTextField();
        txtHasil.setEditable(false);
        add(txtHasil);
        
        btnClear = new JButton("Clear");
        btnClear.addActionListener(this);
        add(btnClear);
        
        pack();
        setLocationRelativeTo(null);
    }
    
    @Override
    public void actionPerformed(ActionEvent e) {
        try {
            double angka1 = Double.parseDouble(txtAngka1.getText());
            double angka2 = Double.parseDouble(txtAngka2.getText());
            double hasil = 0;
            
            if (e.getSource() == btnTambah) {
                hasil = angka1 + angka2;
            } else if (e.getSource() == btnKurang) {
                hasil = angka1 - angka2;
            } else if (e.getSource() == btnKali) {
                hasil = angka1 * angka2;
            } else if (e.getSource() == btnBagi) {
                if (angka2 != 0) {
                    hasil = angka1 / angka2;
                } else {
                    JOptionPane.showMessageDialog(this, "Tidak bisa bagi dengan nol!");
                    return;
                }
            } else if (e.getSource() == btnClear) {
                txtAngka1.setText("");
                txtAngka2.setText("");
                txtHasil.setText("");
                return;
            }
            
            txtHasil.setText(String.valueOf(hasil));
            
        } catch (NumberFormatException ex) {
            JOptionPane.showMessageDialog(this, "Masukkan angka yang valid!");
        }
    }
}
