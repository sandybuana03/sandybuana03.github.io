Struktur Kontrol Lanjutan

Menguasai Perulangan dalam Java

Apa itu Perulangan?

Perulangan (Loop) adalah struktur kontrol yang memungkinkan kita menjalankan blok kode berulang kali selama kondisi tertentu terpenuhi. Ini sangat berguna untuk mengotomatisasi tugas-tugas yang berulang!

For Loop

Digunakan ketika kita tahu berapa kali perulangan akan dilakukan

While Loop

Digunakan ketika perulangan bergantung pada kondisi tertentu

Do-While

Mirip while, tapi minimal dijalankan sekali

Nested Loop

Perulangan di dalam perulangan untuk kasus kompleks

Mengapa Perulangan Penting?

  • Menghemat waktu dan tenaga
  • Membuat kode lebih efisien
  • Mengurangi duplikasi kode
  • Memungkinkan pemrosesan data besar

🤔 Kapan Menggunakan Loop Mana?

Gunakan FOR jika:

  • • Tahu berapa kali akan berulang
  • • Butuh counter/indeks

Gunakan WHILE jika:

  • • Berulang sampai kondisi terpenuhi
  • • Tidak tahu pasti berapa kali

Contoh Sederhana - Menampilkan Angka 1-10

Mari kita mulai dengan contoh paling sederhana!

📁 ForLoopPraktik.java
import java.util.Scanner; public class ForLoopPraktik {     public static void main(String[] args) {         // Menampilkan angka 1 sampai 10         System.out.println("=== ANGKA 1-10 ===");                  for(int i = 1; i <= 10; i++) {             System.out.println("Angka ke-" + i);         }     } }

💡 Penjelasan Struktur For Loop:

for(inisialisasi; kondisi; increment/decrement)
  • int i = 1 → Inisialisasi: variabel i dimulai dari 1 (dijalankan sekali di awal)
  • i <= 10 → Kondisi: loop berjalan selama i kurang dari atau sama dengan 10
  • i++ → Increment: i bertambah 1 setiap selesai satu iterasi

Urutan eksekusi: Inisialisasi → Cek kondisi → Jalankan kode → Increment → Cek kondisi lagi...

import java.util.Scanner; public class ForLoopPraktik {     public static void main(String[] args) {         Scanner scanner = new Scanner(System.in);                  System.out.print("Masukkan batas atas (N): ");         int n = scanner.nextInt();                  int jumlah = 0;                  for(int i = 1; i <= n; i++) {             jumlah += i; // jumlah = jumlah + i             System.out.println("Langkah " + i + ": " + jumlah);         }                  System.out.println("\\nJumlah total 1 sampai " + n + " = " + jumlah);         scanner.close();     } }

Praktik While Loop

Menguasai perulangan berdasarkan kondisi

1

Konsep While Loop

While loop akan terus berjalan selama kondisi bernilai true. Berbeda dengan for loop, kita tidak tahu pasti berapa kali akan berulang.

Struktur: while(kondisi) { // kode }

⚠️ Penting: Pastikan ada cara untuk mengubah kondisi di dalam loop, jika tidak akan terjadi infinite loop!

2

Contoh Sederhana - Countdown

Mari buat program countdown sederhana!

Nama File: WhileLoopPraktik.java
📁 WhileLoopPraktik.java
import java.util.Scanner; public class WhileLoopPraktik {     public static void main(String[] args) {         // Countdown dari 10 ke 1         int countdown = 10;                  System.out.println("=== COUNTDOWN DIMULAI ===");                  while(countdown > 0) {             System.out.println("⏰ " + countdown);             countdown--; // countdown = countdown - 1         }                  System.out.println("🚀 SELESAI!");     } }

import java.util.Scanner; import java.util.Random; public class WhileLoopPraktik {     public static void main(String[] args) {         Scanner scanner = new Scanner(System.in);         Random random = new Random();                  // Generate angka random 1-100         int angkaRahasia = random.nextInt(100) + 1;         int tebakan = 0;         int percobaan = 0;                  System.out.println("🎯 GAME TEBAK ANGKA 1-100 🎯");         System.out.println("Saya sudah memikirkan angka 1-100!");                  while(tebakan != angkaRahasia) {             System.out.print("Tebak angkanya: ");             tebakan = scanner.nextInt();             percobaan++;                          if(tebakan < angkaRahasia) {                 System.out.println("📈 Terlalu kecil! Praktik Do-While Loop

Perulangan yang pasti dijalankan minimal sekali

1

Perbedaan Do-While dengan While

Do-While akan menjalankan kode terlebih dahulu, baru mengecek kondisi. Jadi minimal dijalankan 1 kali!

While Loop

Cek kondisi dulu → Jalankan kode

Do-While Loop

Jalankan kode dulu → Cek kondisi

2

Contoh Sederhana - Input Validation

Do-While sangat cocok untuk validasi input!

Nama File: DoWhilePraktik.java
📁 DoWhilePraktik.java
import java.util.Scanner; public class DoWhilePraktik {     public static void main(String[] args) {         Scanner scanner = new Scanner(System.in);         int angka;                  System.out.println("=== INPUT VALIDATION ===");                  do {             System.out.print("Masukkan angka 1-10: ");             angka = scanner.nextInt();                          if(angka < 1 || angka > 10) {                 System.out.println("❌ Angka harus antara 1-10!");             }         } while(angka < 1 || angka > 10);                  System.out.println("✅ Terima kasih! Angka " + angka + " valid.");         scanner.close();     } }

Program ATM Sederhana

Buat simulasi ATM dengan do-while untuk menu utama!

import java.util.Scanner; public class DoWhilePraktik {     public static void main(String[] args) {         Scanner scanner = new Scanner(System.in);         double saldo = 1000000; // Saldo awal 1 juta         int pilihan;                  System.out.println("🏧 SELAMAT DATANG DI ATM BANK JAVA 🏧");                  do {             System.out.println("\\n=== MENU UTAMA ===");             System.out.println("1. Cek Saldo");             System.out.println("2. Tarik Tunai");             System.out.println("3. Setor Tunai");             System.out.println("4. Keluar");             System.out.print("Pilih menu (1-4): ");                          pilihan = scanner.nextInt();                          switch(pilihan) {                 case 1:                     System.out.println("💰 Saldo Anda: Rp " + saldo);                     break;                                  case 2:                     System.out.print("Masukkan jumlah penarikan: Rp ");                     double tarik = scanner.nextDouble();                     if(tarik <= saldo) {                         saldo -= tarik;                         System.out.println("✅ Penarikan berhasil!");                         System.out.println("💰 Saldo tersisa: Rp " + saldo);                     } else {                         System.out.println("❌ Saldo tidak mencukupi!");                     }                     break;                                  case 3:                     System.out.print("Masukkan jumlah setoran: Rp ");                     double setor = scanner.nextDouble();                     saldo += setor;                     System.out.println("✅ Setoran berhasil!");                     System.out.println("💰 Saldo sekarang: Rp " + saldo);                     break;                                  case 4:                     System.out.println("👋 Terima kasih telah menggunakan ATM!");                     break;                                  default:                     System.out.println("❌ Pilihan tidak valid!");             }         } while(pilihan != 4);                  scanner.close();     } }

Praktik Nested Loop

Perulangan di dalam perulangan

1

Konsep Nested Loop

Nested Loop adalah perulangan di dalam perulangan. Sangat berguna untuk membuat pola, tabel, atau memproses data 2 dimensi!

Loop luar dijalankan 1 kali → Loop dalam dijalankan penuh
2

Membuat Pola Bintang

Mari buat pola bintang sederhana!

Nama File: NestedLoopPraktik.java
📁 NestedLoopPraktik.java
import java.util.Scanner; public class NestedLoopPraktik {     public static void main(String[] args) {         Scanner scanner = new Scanner(System.in);                  System.out.print("Masukkan tinggi pola: ");         int tinggi = scanner.nextInt();                  System.out.println("\\n⭐ POLA BINTANG ⭐");                  // Loop luar untuk baris         for(int i = 1; i <= tinggi; i++) {             // Loop dalam untuk kolom             for(int j = 1; j <= i; j++) {                 System.out.print("* ");             }             System.out.println(); // Pindah baris         }                  scanner.close();     } }

* * *

* * * * *

import java.util.Scanner; public class NestedLoopPraktik {     public static void main(String[] args) {         Scanner scanner = new Scanner(System.in);                  System.out.println("🎨 GENERATOR POLA 🎨");         System.out.println("1. Segitiga Siku-siku");         System.out.println("2. Persegi");         System.out.println("3. Segitiga Terbalik");         System.out.print("Pilih pola (1-3): ");                  int pilihan = scanner.nextInt();         System.out.print("Masukkan ukuran: ");         int ukuran = scanner.nextInt();                  System.out.println("\\nHasil:");                  switch(pilihan) {             case 1: // Segitiga siku-siku                 for(int i = 1; i <= ukuran; i++) {                     for(int j = 1; j <= i; j++) {                         System.out.print("⭐ ");                     }                     System.out.println();                 }                 break;                          case 2: // Persegi                 for(int i = 1; i <= ukuran; i++) {                     for(int j = 1; j <= ukuran; j++) {                         System.out.print("🔷 ");                     }                     System.out.println();                 }                 break;                          case 3: // Segitiga terbalik                 for(int i = ukuran; i >= 1; i--) {                     for(int j = 1; j <= i; j++) {                         System.out.print("🔻 ");                     }                     System.out.println();                 }                 break;                          default:                 System.out.println("❌ Pilihan tidak valid!");         }                  scanner.close();     } }

Break & Continue

Mengontrol alur perulangan

1

Perbedaan Break dan Continue

Break dan Continue adalah statement untuk mengontrol alur perulangan.

🛑 Break

Menghentikan perulangan sepenuhnya

⏭️ Continue

Melompat ke iterasi berikutnya

2

Contoh Break - Mencari Angka

Program untuk mencari angka tertentu dalam rentang!

Nama File: BreakContinuePraktik.java
📁 BreakContinuePraktik.java
import java.util.Scanner; public class BreakContinuePraktik {     public static void main(String[] args) {         Scanner scanner = new Scanner(System.in);                  System.out.print("Cari angka berapa? ");         int target = scanner.nextInt();                  System.out.println("🔍 Mencari angka " + target + " dari 1-100...");                  for(int i = 1; i <= 100; i++) {             System.out.println("Mengecek angka: " + i);                          if(i == target) {                 System.out.println("🎉 KETEMU! Angka " + target + " ditemukan!");                 break; // Keluar dari loop             }         }                  System.out.println("Program selesai!");         scanner.close();     } }
3

Contoh Continue - Bilangan Ganjil

Program untuk menampilkan hanya bilangan ganjil!

📁 BreakContinuePraktik.java
import java.util.Scanner; public class BreakContinuePraktik {     public static void main(String[] args) {         Scanner scanner = new Scanner(System.in);                  System.out.print("Tampilkan bilangan ganjil dari 1 sampai: ");         int batas = scanner.nextInt();                  System.out.println("\\n🔢 BILANGAN GANJIL:");                  for(int i = 1; i <= batas; i++) {             // Jika genap, lewati             if(i % 2 == 0) {                 continue; // Lompat ke iterasi berikutnya             }                          // Yang sampai sini pasti ganjil             System.out.println("✨ " + i + " (ganjil)");         }                  scanner.close();     } }

Program Kuis Interaktif

Buat kuis yang bisa dihentikan kapan saja dengan break!

import java.util.Scanner; public class BreakContinuePraktik {     public static void main(String[] args) {         Scanner scanner = new Scanner(System.in);         int skor = 0;         int soalKe = 1;                  System.out.println("🧠 KUIS MATEMATIKA 🧠");         System.out.println("Ketik 'quit' untuk keluar");                  while(true) { // Loop tak terbatas             System.out.println("\\n--- Soal " + soalKe + " ---");                          // Generate soal random             int a = (int)(Math.random() * 10) + 1;             int b = (int)(Math.random() * 10) + 1;             int jawaban = a + b;                          System.out.print(a + " + " + b + " = ? ");             String input = scanner.nextLine();                          // Cek jika user ingin keluar             if(input.equalsIgnoreCase("quit")) {                 System.out.println("👋 Terima kasih sudah bermain!");                 break; // Keluar dari loop             }                          // Cek jawaban             try {                 int jawabanUser = Integer.parseInt(input);                                  if(jawabanUser == jawaban) {                     System.out.println("✅ BENAR! +10 poin");                     skor += 10;                 } else {                     System.out.println("❌ Salah! Jawaban: " + jawaban);                 }             } catch(NumberFormatException e) {                 System.out.println("⚠️ Input tidak valid, dilewati...");                 continue; // Lompat ke soal berikutnya             }                          System.out.println("🏆 Skor saat ini: " + skor);             soalKe++;         }                  System.out.println("\\n🎯 SKOR AKHIR: " + skor);         scanner.close();     } }
