Pengenalan Fungsi Java

Mari belajar konsep dasar fungsi dalam pemrograman Java!

🤔 Apa itu Fungsi?

Fungsi (atau method dalam Java) adalah blok kode yang dapat dipanggil berulang kali untuk melakukan tugas tertentu. Seperti mesin yang menerima input, memproses, dan menghasilkan output!

✨ Mengapa Penting?

  • • Menghindari pengulangan kode - Tulis sekali, pakai berkali-kali
  • • Kode lebih terorganisir - Mudah dibaca dan dipahami
  • • Mudah di-debug - Error lebih mudah ditemukan
  • • Reusable - Bisa digunakan di project lain

🏗️ Struktur Dasar Fungsi Java

📄 StrukturFungsi.java Template Dasar 
public static tipeReturn namaFungsi(parameter) {
    // Isi fungsi di sini
    return nilai; // jika ada return
}

🎮 Analogi Sederhana

Bayangkan fungsi seperti mesin kopi:

  • • Input: Biji kopi + Air + Gula
  • • Proses: Grinding + Brewing + Mixing
  • • Output: Secangkir kopi siap minum ☕

Langkah 1: Membuat Fungsi Dasar

Mari buat fungsi sederhana tanpa parameter dan return value

📝 Langkah-langkah Praktik:

  1. 1. Buka IDE Java (NetBeans/Eclipse/IntelliJ)
  2. 2. Buat project baru dengan nama "BelajarFungsi"
  3. 3. Buat class baru dengan nama "FungsiDasar"
  4. 4. Ketik kode di bawah ini dengan teliti
📄 FungsiDasar.java Langkah 1 
public class FungsiDasar {
    
    // Fungsi untuk menyapa - tidak ada parameter dan return
    public static void sapa() {
        System.out.println("=================================");
        System.out.println("🎉 Halo! Selamat datang di Java!");
        System.out.println("📚 Mari belajar fungsi bersama!");
        System.out.println("=================================");
    }
    
    // Fungsi untuk menampilkan info
    public static void tampilkanInfo() {
        System.out.println("ℹ️  Ini adalah contoh fungsi dasar");
        System.out.println("✨ Fungsi ini tidak menerima input");
        System.out.println("🚀 Dan tidak mengembalikan nilai");
    }
    
    // Fungsi main untuk menjalankan program
    public static void main(String[] args) {
        System.out.println("🔥 Program Dimulai!\n");
        
        // Memanggil fungsi sapa
        sapa();
        
        System.out.println(); // Baris kosong
        
        // Memanggil fungsi tampilkanInfo
        tampilkanInfo();
        
        System.out.println("\n✅ Program Selesai!");
    }
}

🎯 Penjelasan Kode:

  • • public static void - Fungsi yang bisa dipanggil tanpa membuat object
  • • sapa() - Nama fungsi, kurung kosong berarti tidak ada parameter
  • • void - Tidak mengembalikan nilai apapun
  • • Fungsi dipanggil dengan menulis namaFungsi();

  1. 1. Klik kanan pada file → Run File
  2. 2. Atau tekan Shift + F6

Langkah 2: Fungsi dengan Parameter

Belajar membuat fungsi yang menerima input (parameter)

🎯 Apa itu Parameter?

Parameter adalah nilai yang dikirim ke fungsi untuk diproses. Seperti bahan-bahan yang kita masukkan ke mesin kopi!

📄 FungsiParameter.java Langkah 2 
public class FungsiParameter {
    
    // Fungsi dengan 1 parameter
    public static void sapaOrang(String nama) {
        System.out.println("🎉 Halo " + nama + "!");
        System.out.println("✨ Selamat datang di kelas Java!");
    }
    
    // Fungsi dengan 2 parameter
    public static void hitungLuasPersegiPanjang(int panjang, int lebar) {
        int luas = panjang * lebar;
        System.out.println("📐 Menghitung luas persegi panjang:");
        System.out.println("   Panjang: " + panjang + " cm");
        System.out.println("   Lebar: " + lebar + " cm");
        System.out.println("   Luas: " + luas + " cm²");
        System.out.println("   ✅ Perhitungan selesai!");
    }
    
    // Fungsi dengan 3 parameter
    public static void buatProfilSiswa(String nama, int umur, String kelas) {
        System.out.println("👤 === PROFIL SISWA ===");
        System.out.println("📝 Nama: " + nama);
        System.out.println("🎂 Umur: " + umur + " tahun");
        System.out.println("🏫 Kelas: " + kelas);
        System.out.println("========================");
    }
    
    // Fungsi dengan parameter berbeda tipe data
    public static void infoNilai(String matakuliah, double nilai, boolean lulus) {
        System.out.println("📊 === INFO NILAI ===");
        System.out.println("📚 Mata Kuliah: " + matakuliah);
        System.out.println("💯 Nilai: " + nilai);
        
        if (lulus) {
            System.out.println("🎉 Status: LULUS! Selamat!");
        } else {
            System.out.println("😔 Status: Belum Lulus, semangat!");
        }
        System.out.println("====================");
    }
    
    public static void main(String[] args) {
        System.out.println("🚀 Program Fungsi dengan Parameter\n");
        
        // Memanggil fungsi dengan 1 parameter
        sapaOrang("Budi");
        System.out.println();
        
        // Memanggil fungsi dengan 2 parameter
        hitungLuasPersegiPanjang(10, 5);
        System.out.println();
        
        // Memanggil fungsi dengan 3 parameter
        buatProfilSiswa("Siti", 17, "XII RPL 1");
        System.out.println();
        
        // Memanggil fungsi dengan parameter berbeda tipe
        infoNilai("Pemrograman Java", 85.5, true);
        System.out.println();
        
        infoNilai("Matematika", 65.0, false);
        
        System.out.println("\n✅ Program Selesai!");
    }
}

🔍 Penjelasan Detail:

  • • String nama - Parameter bertipe String
  • • int panjang, int lebar - Dua parameter bertipe integer
  • • Parameter dipisah dengan koma ,
  • • Saat memanggil, nilai harus sesuai urutan parameter
  • • Tipe data parameter harus sesuai saat pemanggilan

💡 Tips Penting:

  • • Urutan parameter penting! Harus sesuai saat pemanggilan
  • • Tipe data harus cocok - String untuk String, int untuk int
  • • Nama parameter bebas - yang penting tipe datanya
  • • Bisa campuran tipe data - String, int, double, boolean

  2. 2. Fungsi perkenalan(String nama, String hobi)

Langkah 3: Fungsi dengan Return

Belajar membuat fungsi yang mengembalikan nilai hasil perhitungan

🎯 Apa itu Return?

Return adalah nilai yang dikembalikan oleh fungsi setelah selesai diproses. Seperti kopi yang keluar dari mesin kopi setelah diproses!

📄 FungsiReturn.java Langkah 3 
public class FungsiReturn {
    
    // Fungsi return nilai integer
    public static int tambah(int a, int b) {
        int hasil = a + b;
        return hasil; // Mengembalikan hasil penjumlahan
    }
    
    // Fungsi return nilai double
    public static double hitungRataRata(double nilai1, double nilai2, double nilai3) {
        double total = nilai1 + nilai2 + nilai3;
        double rataRata = total / 3;
        return rataRata; // Mengembalikan rata-rata
    }
    
    // Fungsi return nilai String
    public static String buatSalam(String nama, String waktu) {
        String salam = "Selamat " + waktu + ", " + nama + "! 😊";
        return salam; // Mengembalikan string salam
    }
    
    // Fungsi return nilai boolean
    public static boolean cekKelulusan(double nilai) {
        if (nilai >= 75) {
            return true; // Lulus
        } else {
            return false; // Tidak lulus
        }
    }
    
    // Fungsi return dengan perhitungan langsung
    public static double hitungLuasLingkaran(double jariJari) {
        return 3.14159 * jariJari * jariJari; // Return langsung
    }
    
    // Fungsi return nilai maksimum
    public static int cariNilaiTerbesar(int a, int b, int c) {
        int terbesar = a;
        
        if (b > terbesar) {
            terbesar = b;
        }
        
        if (c > terbesar) {
            terbesar = c;
        }
        
        return terbesar;
    }
    
    public static void main(String[] args) {
        System.out.println("🚀 Program Fungsi dengan Return Value\n");
        
        // Menggunakan fungsi yang return integer
        int hasilTambah = tambah(15, 25);
        System.out.println("➕ 15 + 25 = " + hasilTambah);
        
        // Menggunakan fungsi yang return double
        double rataRata = hitungRataRata(80.5, 75.0, 90.5);
        System.out.println("📊 Rata-rata nilai: " + rataRata);
        
        // Menggunakan fungsi yang return String
        String salamPagi = buatSalam("Andi", "pagi");
        System.out.println("💬 " + salamPagi);
        
        String salamSore = buatSalam("Sari", "sore");
        System.out.println("💬 " + salamSore);
        
        // Menggunakan fungsi yang return boolean
        boolean lulus1 = cekKelulusan(85.0);
        boolean lulus2 = cekKelulusan(65.0);
        
        System.out.println("🎓 Nilai 85: " + (lulus1 ? "LULUS ✅" : "TIDAK LULUS ❌"));
        System.out.println("🎓 Nilai 65: " + (lulus2 ? "LULUS ✅" : "TIDAK LULUS ❌"));
        
        // Menggunakan return value langsung dalam perhitungan
        double luasLingkaran = hitungLuasLingkaran(7.0);
        System.out.println("🔵 Luas lingkaran (r=7): " + luasLingkaran + " cm²");
        
        // Menggunakan return value dalam kondisi
        int nilaiTerbesar = cariNilaiTerbesar(45, 78, 62);
        System.out.println("🏆 Nilai terbesar dari 45, 78, 62 adalah: " + nilaiTerbesar);
        
        // Menggunakan return value langsung dalam print
        System.out.println("🔢 10 + 20 = " + tambah(10, 20));
        System.out.println("📐 Luas lingkaran (r=5): " + hitungLuasLingkaran(5.0) + " cm²");
        
        System.out.println("\n✅ Program Selesai!");
    }
}

🔍 Penjelasan Return:

  • • int tambah(...) - Fungsi mengembalikan nilai integer
  • • return hasil; - Mengembalikan nilai variabel
  • • return 3.14 * r * r; - Return langsung hasil perhitungan
  • • Tipe return harus sesuai dengan deklarasi fungsi
  • • Setelah return, fungsi berhenti dan kembali ke pemanggil

💡 Cara Menggunakan Return Value:

1. Simpan dalam variabel:

int hasil = tambah(5, 3);

2. Gunakan langsung:

System.out.println(tambah(5, 3));

3. Gunakan dalam kondisi:

if (cekKelulusan(80)) { ... }

Coba buat fungsi return sendiri:

  1. 1. double hitungDiskon(double harga, int persen)
  2. 2. String gabungNama(String depan, String belakang)
  3. 3. boolean cekGanjilGenap(int angka) - true jika genap

Langkah 4: Method Overloading

Belajar membuat beberapa fungsi dengan nama sama tapi parameter berbeda

🎯 Apa itu Method Overloading?

Method Overloading adalah membuat beberapa fungsi dengan nama yang sama, tapi parameter yang berbeda (jumlah atau tipe). Java akan otomatis memilih fungsi yang tepat berdasarkan parameter yang diberikan!

📄 MethodOverloading.java Langkah 4 
public class MethodOverloading {
    
    // Overloading fungsi hitung - versi 1: 2 parameter integer
    public static int hitung(int a, int b) {
        System.out.println("🔢 Menggunakan hitung(int, int)");
        return a + b;
    }
    
    // Overloading fungsi hitung - versi 2: 3 parameter integer
    public static int hitung(int a, int b, int c) {
        System.out.println("🔢 Menggunakan hitung(int, int, int)");
        return a + b + c;
    }
    
    // Overloading fungsi hitung - versi 3: 2 parameter double
    public static double hitung(double a, double b) {
        System.out.println("🔢 Menggunakan hitung(double, double)");
        return a + b;
    }
    
    // Overloading fungsi hitung - versi 4: 1 parameter array
    public static int hitung(int[] angka) {
        System.out.println("🔢 Menggunakan hitung(int[])");
        int total = 0;
        for (int i = 0; i < angka.length; i++) {
            total += angka[i];
        }
        return total;
    }
    
    // Overloading fungsi tampilkanInfo - versi 1: hanya nama
    public static void tampilkanInfo(String nama) {
        System.out.println("👤 === INFO SINGKAT ===");
        System.out.println("📝 Nama: " + nama);
        System.out.println("ℹ️  Info lainnya tidak tersedia");
        System.out.println("======================");
    }
    
    // Overloading fungsi tampilkanInfo - versi 2: nama dan umur
    public static void tampilkanInfo(String nama, int umur) {
        System.out.println("👤 === INFO LENGKAP ===");
        System.out.println("📝 Nama: " + nama);
        System.out.println("🎂 Umur: " + umur + " tahun");
        System.out.println("======================");
    }
    
    // Overloading fungsi tampilkanInfo - versi 3: nama, umur, dan kelas
    public static void tampilkanInfo(String nama, int umur, String kelas) {
        System.out.println("👤 === INFO DETAIL ===");
        System.out.println("📝 Nama: " + nama);
        System.out.println("🎂 Umur: " + umur + " tahun");
        System.out.println("🏫 Kelas: " + kelas);
        System.out.println("======================");
    }
    
    // Overloading fungsi buatPesan - versi 1: pesan biasa
    public static String buatPesan(String pesan) {
        return "💬 " + pesan;
    }
    
    // Overloading fungsi buatPesan - versi 2: pesan dengan emoji
    public static String buatPesan(String pesan, String emoji) {
        return emoji + " " + pesan + " " + emoji;
    }
    
    // Overloading fungsi buatPesan - versi 3: pesan dengan repeat
    public static String buatPesan(String pesan, int repeat) {
        String hasil = "";
        for (int i = 0; i < repeat; i++) {
            hasil += pesan + " ";
        }
        return hasil.trim();
    }
    
    public static void main(String[] args) {
        System.out.println("🚀 Program Method Overloading\n");
        
        // Testing overloading fungsi hitung
        System.out.println("=== TESTING FUNGSI HITUNG ===");
        
        int hasil1 = hitung(10, 20);           // Memanggil versi (int, int)
        System.out.println("📊 Hasil: " + hasil1 + "\n");
        
        int hasil2 = hitung(10, 20, 30);       // Memanggil versi (int, int, int)
        System.out.println("📊 Hasil: " + hasil2 + "\n");
        
        double hasil3 = hitung(10.5, 20.3);    // Memanggil versi (double, double)
        System.out.println("📊 Hasil: " + hasil3 + "\n");
        
        int[] angka = {5, 10, 15, 20, 25};
        int hasil4 = hitung(angka);             // Memanggil versi (int[])
        System.out.println("📊 Hasil: " + hasil4 + "\n");
        
        // Testing overloading fungsi tampilkanInfo
        System.out.println("=== TESTING FUNGSI TAMPILKAN INFO ===");
        
        tampilkanInfo("Budi");                          // Versi 1 parameter
        System.out.println();
        
        tampilkanInfo("Sari", 17);                      // Versi 2 parameter
        System.out.println();
        
        tampilkanInfo("Andi", 18, "XII RPL 2");         // Versi 3 parameter
        System.out.println();
        
        // Testing overloading fungsi buatPesan
        System.out.println("=== TESTING FUNGSI BUAT PESAN ===");
        
        String pesan1 = buatPesan("Halo semua!");                    // Versi 1 parameter
        System.out.println(pesan1);
        
        String pesan2 = buatPesan("Selamat belajar!", "🎓");         // Versi 2 parameter
        System.out.println(pesan2);
        
        String pesan3 = buatPesan("Java!", 3);                       // Versi dengan repeat
        System.out.println(pesan3);
        
        System.out.println("\n✅ Program Selesai!");
    }
}

🔍 Aturan Method Overloading:

  • • Nama fungsi harus sama - contoh: semua bernama hitung
  • • Parameter harus berbeda - jumlah atau tipe data
  • • Return type boleh sama atau beda - tidak mempengaruhi overloading
  • • Java otomatis pilih - berdasarkan parameter yang diberikan
  • • Compile time - keputusan dibuat saat kompilasi

💡 Keuntungan Method Overloading:

  • • Nama fungsi konsisten - mudah diingat
  • • Fleksibilitas - bisa dipanggil dengan parameter berbeda
  • • Code reusability - satu nama untuk berbagai kebutuhan
  • • Mudah dipahami - fungsi sejenis punya nama sama

  2. 2. Fungsi salam - dengan nama saja, nama+waktu, nama+waktu+tempat
  3. 3. Fungsi konversi - celsius ke fahrenheit, fahrenheit ke celsius

Langkah 5: Praktik Lengkap

Gabungkan semua konsep fungsi dalam satu program aplikasi kalkulator

🎯 Project: Kalkulator Multi-Fungsi

Kita akan membuat aplikasi kalkulator yang menggunakan semua konsep fungsi yang sudah dipelajari: fungsi dasar, parameter, return value, dan method overloading!

📄 KalkulatorLengkap.java Project Final 
import java.util.Scanner;

public class KalkulatorLengkap {
    
    // Fungsi untuk menampilkan header aplikasi
    public static void tampilkanHeader() {
        System.out.println("╔══════════════════════════════════════╗");
        System.out.println("║        🧮 KALKULATOR JAVA 🧮        ║");
        System.out.println("║     Aplikasi Multi-Fungsi v1.0       ║");
        System.out.println("╚══════════════════════════════════════╝");
        System.out.println();
    }
    
    // Fungsi untuk menampilkan menu
    public static void tampilkanMenu() {
        System.out.println("📋 === MENU KALKULATOR ===");
        System.out.println("1️⃣  Penjumlahan");
        System.out.println("2️⃣  Pengurangan");
        System.out.println("3️⃣  Perkalian");
        System.out.println("4️⃣  Pembagian");
        System.out.println("5️⃣  Pangkat");
        System.out.println("6️⃣  Akar Kuadrat");
        System.out.println("7️⃣  Luas Bangun Datar");
        System.out.println("8️⃣  Konversi Suhu");
        System.out.println("0️⃣  Keluar");
        System.out.println("==========================");
        System.out.print("🎯 Pilih menu (0-8): ");
    }
    
    // Method overloading untuk operasi matematika dasar
    // Versi 1: 2 parameter
    public static double hitung(double a, double b, String operasi) {
        switch (operasi.toLowerCase()) {
            case "tambah":
            case "+":
                return a + b;
            case "kurang":
            case "-":
                return a - b;
            case "kali":
            case "*":
                return a * b;
            case "bagi":
            case "/":
                if (b != 0) {
                    return a / b;
                } else {
                    System.out.println("❌ Error: Tidak bisa dibagi dengan nol!");
                    return 0;
                }
            default:
                System.out.println("❌ Operasi tidak dikenal!");
                return 0;
        }
    }
    
    // Versi 2: untuk pangkat
    public static double hitung(double base, int pangkat) {
        double hasil = 1;
        for (int i = 0; i < pangkat; i++) {
            hasil *= base;
        }
        return hasil;
    }
    
    // Versi 3: untuk akar kuadrat
    public static double hitung(double angka) {
        if (angka < 0) {
            System.out.println("❌ Error: Tidak bisa akar kuadrat bilangan negatif!");
            return 0;
        }
        return Math.sqrt(angka);
    }
    
    // Fungsi untuk menghitung luas bangun datar
    public static double hitungLuas(String bangun, double... parameter) {
        switch (bangun.toLowerCase()) {
            case "persegi":
                if (parameter.length >= 1) {
                    return parameter[0] * parameter[0];
                }
                break;
            case "persegi panjang":
                if (parameter.length >= 2) {
                    return parameter[0] * parameter[1];
                }
                break;
            case "segitiga":
                if (parameter.length >= 2) {
                    return 0.5 * parameter[0] * parameter[1];
                }
                break;
            case "lingkaran":
                if (parameter.length >= 1) {
                    return 3.14159 * parameter[0] * parameter[0];
                }
                break;
        }
        System.out.println("❌ Parameter tidak sesuai untuk bangun " + bangun);
        return 0;
    }
    
    // Fungsi konversi suhu dengan method overloading
    public static double konversiSuhu(double suhu, String dari, String ke) {
        // Konversi ke Celsius dulu
        double celsius = suhu;
        
        if (dari.equalsIgnoreCase("fahrenheit")) {
            celsius = (suhu - 32) * 5.0 / 9.0;
        } else if (dari.equalsIgnoreCase("kelvin")) {
            celsius = suhu - 273.15;
        }
        
        // Konversi dari Celsius ke target
        if (ke.equalsIgnoreCase("fahrenheit")) {
            return (celsius * 9.0 / 5.0) + 32;
        } else if (ke.equalsIgnoreCase("kelvin")) {
            return celsius + 273.15;
        }
        
        return celsius; // Jika target adalah celsius
    }
    
    // Fungsi untuk input angka dengan validasi
    public static double inputAngka(Scanner scanner, String pesan) {
        System.out.print(pesan);
        while (!scanner.hasNextDouble()) {
            System.out.println("❌ Input harus berupa angka!");
            System.out.print(pesan);
            scanner.next(); // Clear invalid input
        }
        return scanner.nextDouble();
    }
    
    // Fungsi untuk menampilkan hasil dengan format cantik
    public static void tampilkanHasil(String operasi, double hasil) {
        System.out.println("\n🎉 === HASIL PERHITUNGAN ===");
        System.out.println("📊 Operasi: " + operasi);
        System.out.println("✨ Hasil: " + hasil);
        System.out.println("============================\n");
    }
    
    // Fungsi untuk pause program
    public static void pause(Scanner scanner) {
        System.out.print("⏸️  Tekan Enter untuk melanjutkan...");
        scanner.nextLine();
        scanner.nextLine();
    }
    
    // Fungsi untuk clear screen (simulasi)
    public static void clearScreen() {
        for (int i = 0; i < 3; i++) {
            System.out.println();
        }
    }
    
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int pilihan;
        
        tampilkanHeader();
        
        do {
            tampilkanMenu();
            pilihan = scanner.nextInt();
            clearScreen();
            
            switch (pilihan) {
                case 1: // Penjumlahan
                    double a1 = inputAngka(scanner, "🔢 Masukkan angka pertama: ");
                    double b1 = inputAngka(scanner, "🔢 Masukkan angka kedua: ");
                    double hasil1 = hitung(a1, b1, "tambah");
                    tampilkanHasil("Penjumlahan " + a1 + " + " + b1, hasil1);
                    pause(scanner);
                    break;
                    
                case 2: // Pengurangan
                    double a2 = inputAngka(scanner, "🔢 Masukkan angka pertama: ");
                    double b2 = inputAngka(scanner, "🔢 Masukkan angka kedua: ");
                    double hasil2 = hitung(a2, b2, "kurang");
                    tampilkanHasil("Pengurangan " + a2 + " - " + b2, hasil2);
                    pause(scanner);
                    break;
                    
                case 3: // Perkalian
                    double a3 = inputAngka(scanner, "🔢 Masukkan angka pertama: ");
                    double b3 = inputAngka(scanner, "🔢 Masukkan angka kedua: ");
                    double hasil3 = hitung(a3, b3, "kali");
                    tampilkanHasil("Perkalian " + a3 + " × " + b3, hasil3);
                    pause(scanner);
                    break;
                    
                case 4: // Pembagian
                    double a4 = inputAngka(scanner, "🔢 Masukkan angka pertama: ");
                    double b4 = inputAngka(scanner, "🔢 Masukkan angka kedua: ");
                    double hasil4 = hitung(a4, b4, "bagi");
                    tampilkanHasil("Pembagian " + a4 + " ÷ " + b4, hasil4);
                    pause(scanner);
                    break;
                    
                case 5: // Pangkat
                    double base = inputAngka(scanner, "🔢 Masukkan bilangan dasar: ");
                    System.out.print("🔢 Masukkan pangkat: ");
                    int pangkat = scanner.nextInt();
                    double hasil5 = hitung(base, pangkat);
                    tampilkanHasil(base + " pangkat " + pangkat, hasil5);
                    pause(scanner);
                    break;
                    
                case 6: // Akar Kuadrat
                    double angka = inputAngka(scanner, "🔢 Masukkan angka: ");
                    double hasil6 = hitung(angka);
                    tampilkanHasil("Akar kuadrat dari " + angka, hasil6);
                    pause(scanner);
                    break;
                    
                case 7: // Luas Bangun Datar
                    System.out.println("📐 Pilih bangun datar:");
                    System.out.println("1. Persegi");
                    System.out.println("2. Persegi Panjang");
                    System.out.println("3. Segitiga");
                    System.out.println("4. Lingkaran");
                    System.out.print("Pilih (1-4): ");
                    int pilihanBangun = scanner.nextInt();
                    
                    double luas = 0;
                    switch (pilihanBangun) {
                        case 1:
                            double sisi = inputAngka(scanner, "📏 Masukkan panjang sisi: ");
                            luas = hitungLuas("persegi", sisi);
                            tampilkanHasil("Luas Persegi (sisi=" + sisi + ")", luas);
                            break;
                        case 2:
                            double panjang = inputAngka(scanner, "📏 Masukkan panjang: ");
                            double lebar = inputAngka(scanner, "📏 Masukkan lebar: ");
                            luas = hitungLuas("persegi panjang", panjang, lebar);
                            tampilkanHasil("Luas Persegi Panjang (" + panjang + "×" + lebar + ")", luas);
                            break;
                        case 3:
                            double alas = inputAngka(scanner, "📏 Masukkan alas: ");
                            double tinggi = inputAngka(scanner, "📏 Masukkan tinggi: ");
                            luas = hitungLuas("segitiga", alas, tinggi);
                            tampilkanHasil("Luas Segitiga (alas=" + alas + ", tinggi=" + tinggi + ")", luas);
                            break;
                        case 4:
                            double jariJari = inputAngka(scanner, "📏 Masukkan jari-jari: ");
                            luas = hitungLuas("lingkaran", jariJari);
                            tampilkanHasil("Luas Lingkaran (r=" + jariJari + ")", luas);
                            break;
                    }
                    pause(scanner);
                    break;
                    
                case 8: // Konversi Suhu
                    System.out.println("🌡️ Konversi Suhu");
                    double suhu = inputAngka(scanner, "🔢 Masukkan suhu: ");
                    System.out.println("Dari satuan:");
                    System.out.println("1. Celsius");
                    System.out.println("2. Fahrenheit");
                    System.out.println("3. Kelvin");
                    System.out.print("Pilih (1-3): ");
                    int dari = scanner.nextInt();
                    
                    System.out.println("Ke satuan:");
                    System.out.println("1. Celsius");
                    System.out.println("2. Fahrenheit");
                    System.out.println("3. Kelvin");
                    System.out.print("Pilih (1-3): ");
                    int ke = scanner.nextInt();
                    
                    String[] satuan = {"", "celsius", "fahrenheit", "kelvin"};
                    double hasilKonversi = konversiSuhu(suhu, satuan[dari], satuan[ke]);
                    tampilkanHasil("Konversi " + suhu + "° " + satuan[dari] + " ke " + satuan[ke], hasilKonversi);
                    pause(scanner);
                    break;
                    
                case 0: // Keluar
                    System.out.println("👋 Terima kasih telah menggunakan Kalkulator Java!");
                    System.out.println("🎓 Semoga bermanfaat untuk belajar fungsi!");
                    break;
                    
                default:
                    System.out.println("❌ Pilihan tidak valid! Silakan pilih 0-8.");
                    pause(scanner);
            }
            
            clearScreen();
            
        } while (pilihan != 0);
        
        scanner.close();
    }
}
