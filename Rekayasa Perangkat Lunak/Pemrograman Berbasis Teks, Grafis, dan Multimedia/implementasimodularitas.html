Membuat Package

📁

Apa itu Package?

Package adalah seperti folder di komputer kamu. Dia digunakan untuk mengelompokkan class-class yang sejenis agar lebih rapi dan mudah dicari.

💡

Analogi Sederhana

Bayangkan kamu punya lemari baju. Package itu seperti laci-laci di lemari. Laci kaos kaki untuk menyimpan kaos kaki, laci baju untuk menyimpan baju. Begitu juga package: package matematika untuk class-class matematika, package database untuk class-class database.

🛠️ Langkah-langkah Membuat Package

1

Buka IDE Java (NetBeans/IntelliJ/Eclipse)

Pastikan kamu sudah punya project Java yang siap digunakan.

2

Klik kanan pada folder src

Pilih "New" → "Package" atau "Java Package"

3

Beri nama package

Contoh: com.sekolah.matematika

📝

Contoh Kode Package

📄 File: Kalkulator.java

// Deklarasi package - HARUS di baris pertama!
package com.sekolah.matematika;

// Sekarang class ini ada di dalam package matematika
public class Kalkulator {
// Isi class akan kita buat di langkah selanjutnya
}
⚠️

Aturan Penting Package

  • 1️⃣ Deklarasi package HARUS di baris pertama file
  • 2️⃣ Nama package menggunakan huruf kecil semua
  • 3️⃣ Gunakan titik (.) untuk memisahkan level folder
  • 4️⃣ Struktur folder harus sesuai dengan nama package

📝 Contoh Penamaan yang Benar:

✅ com.sekolah.matematika

✅ aplikasi.perpustakaan.buku

❌ Com.Sekolah.Matematika (huruf besar)

❌ sekolah-matematika (pakai dash)

📁

Struktur Folder Package

Package com.sekolah.matematika akan membuat struktur folder seperti ini:

📂 src/
📂 com/
📂 sekolah/
📂 matematika/
📄 Kalkulator.java

💡 Tips:

IDE akan otomatis membuat struktur folder ini saat kamu membuat package baru!

Membuat Class di Package

🏗️

Membuat Class Kalkulator

Sekarang kita akan membuat class Kalkulator di dalam package yang sudah dibuat. Class ini akan punya method untuk operasi matematika dasar.

📝

Kode Lengkap Class Kalkulator

📄 File: com/sekolah/matematika/Kalkulator.java

// Deklarasi package
package com.sekolah.matematika;

// Class Kalkulator dengan method-method matematika
public class Kalkulator {

// Method untuk penjumlahan
public int tambah(int a, int b) {
return a + b;
}

// Method untuk pengurangan
public int kurang(int a, int b) {
return a - b;
}

// Method untuk perkalian
public int kali(int a, int b) {
return a * b;
}

// Method untuk pembagian
public double bagi(double a, double b) {
if (b != 0) {
return a / b;
} else {
System.out.println("Error: Tidak bisa bagi dengan 0!");
return 0;
}
}

// Method untuk menampilkan info kalkulator
public void tampilkanInfo() {
System.out.println("=== KALKULATOR SEDERHANA ===");
System.out.println("Bisa melakukan: +, -, *, /");
System.out.println("Dibuat dengan ❤️ untuk belajar Java");
}
}
🔐

Penjelasan Access Modifier

🛡️ Konsep Encapsulation (Enkapsulasi)

Access modifier adalah cara Java melindungi data. Seperti kunci rumah - ada yang boleh masuk bebas (public), ada yang hanya keluarga (protected), ada yang hanya pemilik rumah (private).

🟢 public

Bisa diakses dari mana saja (class lain, package lain)

public class Kalkulator { }

💡 Gunakan untuk method/class yang memang perlu diakses dari luar

🟡 private

Hanya bisa diakses dari dalam class yang sama

private int angka;

💡 Gunakan untuk data internal yang tidak boleh diubah sembarangan

🔵 protected

Bisa diakses dari package yang sama atau subclass

protected void method() { }

💡 Gunakan untuk inheritance (akan dipelajari nanti)

⚪ default (package-private)

Bisa diakses dari package yang sama saja

void method() { } // tanpa modifier

💡 Jarang digunakan, biasanya pakai public atau private

🔍

Penjelasan Kode

  • • public class: Class bisa diakses dari package lain
  • • public method: Method bisa dipanggil dari luar class
  • • return: Mengembalikan hasil perhitungan
💡

Tips Penting

  • • Nama class harus sama dengan nama file
  • • Selalu cek pembagian dengan nol
  • • Gunakan nama method yang jelas dan mudah dipahami
🎯

Langkah Membuat Class

1. Buat File Baru

Klik kanan pada package → New → Java Class

2. Beri Nama

Ketik "Kalkulator" sebagai nama class

3. Tulis Kode

Copy-paste kode di atas ke dalam file

4. Save & Compile

Ctrl+S untuk save, pastikan tidak ada error

Import & Menggunakan Class

🔗

Apa itu Import?

Import adalah cara untuk "memanggil" atau menggunakan class yang ada di package lain. Seperti meminjam alat dari teman di kelas sebelah!

🎯

Mengapa Perlu Import?

Tanpa import, Java tidak tahu di mana mencari class yang kita butuhkan. Import memberitahu Java: "Hei, class yang saya butuhkan ada di package ini!"

📝

Membuat Class Main untuk Testing

📄 File: Main.java (di package utama/default)

// Import class Kalkulator dari package matematika
import com.sekolah.matematika.Kalkulator;

// Class utama untuk menjalankan program
public class Main {
public static void main(String[] args) {

// Membuat objek kalkulator
Kalkulator calc = new Kalkulator();

// Menampilkan info kalkulator
calc.tampilkanInfo();
System.out.println();

// Testing operasi matematika
int a = 15;
int b = 5;

System.out.println("=== TESTING KALKULATOR ===");
System.out.println("Angka pertama: " + a);
System.out.println("Angka kedua: " + b);
System.out.println();

// Melakukan operasi dan menampilkan hasil
System.out.println("Penjumlahan: " + a + " + " + b + " = " + calc.tambah(a, b));
System.out.println("Pengurangan: " + a + " - " + b + " = " + calc.kurang(a, b));
System.out.println("Perkalian: " + a + " × " + b + " = " + calc.kali(a, b));
System.out.println("Pembagian: " + a + " ÷ " + b + " = " + calc.bagi(a, b));

// Testing pembagian dengan nol
System.out.println();
System.out.println("=== TESTING ERROR ===");
calc.bagi(10, 0);
}
}

Jenis-jenis Import

Import Spesifik

import com.sekolah.matematika.Kalkulator;

Hanya import satu class tertentu

Import Semua (*)

import com.sekolah.matematika.*;

Import semua class dalam package

⚡

Tips Import

  • • Import harus di atas deklarasi class
  • • Gunakan import spesifik untuk kode yang lebih jelas
  • • IDE biasanya auto-import saat kita ketik nama class
  • • Hindari import * kecuali benar-benar perlu banyak class

🚀 Shortcut IDE:

Ctrl+Shift+O (Eclipse/IntelliJ) untuk organize imports otomatis!

⚠️

Error Umum & Solusinya

❌ "Package does not exist"

Penyebab: Salah ketik nama package atau package belum dibuat

Solusi: Cek ejaan nama package dan pastikan struktur folder benar

❌ "Cannot find symbol"

Penyebab: Lupa import class atau salah ketik nama class

Solusi: Tambahkan import statement atau perbaiki nama class

❌ "Class is not public"

Penyebab: Class tidak dibuat dengan modifier public

Solusi: Tambahkan kata kunci 'public' sebelum 'class'

1. Class Buku

📄 File: perpustakaan/buku/Buku.java

package perpustakaan.buku;

public class Buku {
// Atribut buku
private String judul;
private String pengarang;
private String isbn;
private boolean tersedia;

// Constructor
public Buku(String judul, String pengarang, String isbn) {
this.judul = judul;
this.pengarang = pengarang;
this.isbn = isbn;
this.tersedia = true; // Buku baru selalu tersedia
}

// Getter methods
public String getJudul() { return judul; }
public String getPengarang() { return pengarang; }
public String getIsbn() { return isbn; }
public boolean isTersedia() { return tersedia; }

// Method untuk meminjam buku
public boolean pinjam() {
if (tersedia) {
tersedia = false;
return true;
}
return false;
}

// Method untuk mengembalikan buku
public void kembalikan() {
tersedia = true;
}

// Method untuk menampilkan info buku
public void tampilkanInfo() {
System.out.println("📖 Judul: " + judul);
System.out.println("✍️ Pengarang: " + pengarang);
System.out.println("🔢 ISBN: " + isbn);
System.out.println("📋 Status: " + (tersedia ? "Tersedia ✅" : "Dipinjam ❌"));
}
}

2. Class Anggota

📄 File: perpustakaan/anggota/Anggota.java

package perpustakaan.anggota;

public class Anggota {
// Atribut anggota
private String nama;
private String nomorAnggota;
private String alamat;
private int jumlahPinjaman;

// Constructor
public Anggota(String nama, String nomorAnggota, String alamat) {
this.nama = nama;
this.nomorAnggota = nomorAnggota;
this.alamat = alamat;
this.jumlahPinjaman = 0;
}

// Getter methods
public String getNama() { return nama; }
public String getNomorAnggota() { return nomorAnggota; }
public int getJumlahPinjaman() { return jumlahPinjaman; }

// Method untuk menambah pinjaman
public void tambahPinjaman() {
jumlahPinjaman++;
}

// Method untuk mengurangi pinjaman
public void kurangiPinjaman() {
if (jumlahPinjaman > 0) {
jumlahPinjaman--;
}
}

// Method untuk cek apakah bisa pinjam (max 3 buku)
public boolean bisaPinjam() {
return jumlahPinjaman < 3;
}

// Method untuk menampilkan info anggota
public void tampilkanInfo() {
System.out.println("👤 Nama: " + nama);
System.out.println("🆔 No. Anggota: " + nomorAnggota);
System.out.println("🏠 Alamat: " + alamat);
System.out.println("📚 Jumlah Pinjaman: " + jumlahPinjaman + "/3");
}
}

3. Class Perpustakaan (Sistem Utama)

📄 File: perpustakaan/sistem/Perpustakaan.java

package perpustakaan.sistem;

// Import class dari package lain
import perpustakaan.buku.Buku;
import perpustakaan.anggota.Anggota;

public class Perpustakaan {
private String namaPerpustakaan;

// Constructor
public Perpustakaan(String nama) {
this.namaPerpustakaan = nama;
}

// Method untuk meminjam buku
public boolean pinjamBuku(Anggota anggota, Buku buku) {
if (!anggota.bisaPinjam()) {
System.out.println("❌ " + anggota.getNama() + " sudah mencapai batas maksimal pinjaman!");
return false;
}

if (!buku.isTersedia()) {
System.out.println("❌ Buku '" + buku.getJudul() + "' sedang dipinjam!");
return false;
}

// Proses peminjaman
buku.pinjam();
anggota.tambahPinjaman();
System.out.println("✅ " + anggota.getNama() + " berhasil meminjam '" + buku.getJudul() + "'");
return true;
}

// Method untuk mengembalikan buku
public void kembalikanBuku(Anggota anggota, Buku buku) {
buku.kembalikan();
anggota.kurangiPinjaman();
System.out.println("✅ " + anggota.getNama() + " berhasil mengembalikan '" + buku.getJudul() + "'");
}

// Method untuk menampilkan info perpustakaan
public void tampilkanInfo() {
System.out.println("🏛️ === " + namaPerpustakaan + " ===");
System.out.println("📚 Sistem Perpustakaan Digital");
System.out.println("✨ Selamat datang! ✨");
}
}

4. Main Class (Program Utama)

📄 File: Main.java

// Import semua class yang dibutuhkan
import perpustakaan.buku.Buku;
import perpustakaan.anggota.Anggota;
import perpustakaan.sistem.Perpustakaan;

public class Main {
public static void main(String[] args) {

// Membuat objek perpustakaan
Perpustakaan perpus = new Perpustakaan("Perpustakaan SMK Nusantara");
perpus.tampilkanInfo();
System.out.println();

// Membuat beberapa buku
Buku buku1 = new Buku("Pemrograman Java", "Budi Santoso", "978-123-456");
Buku buku2 = new Buku("Database MySQL", "Siti Aminah", "978-789-012");
Buku buku3 = new Buku("Web Development", "Ahmad Rizki", "978-345-678");

// Membuat anggota perpustakaan
Anggota siswa1 = new Anggota("Andi Pratama", "A001", "Jl. Merdeka No. 10");
Anggota siswa2 = new Anggota("Sari Dewi", "A002", "Jl. Sudirman No. 25");

// Menampilkan info buku dan anggota
System.out.println("=== DAFTAR BUKU ===");
buku1.tampilkanInfo(); System.out.println();
buku2.tampilkanInfo(); System.out.println();
buku3.tampilkanInfo(); System.out.println();

System.out.println("=== DAFTAR ANGGOTA ===");
siswa1.tampilkanInfo(); System.out.println();
siswa2.tampilkanInfo(); System.out.println();

// Simulasi peminjaman buku
System.out.println("=== SIMULASI PEMINJAMAN ===");
perpus.pinjamBuku(siswa1, buku1);
perpus.pinjamBuku(siswa1, buku2);
perpus.pinjamBuku(siswa2, buku1); // Buku sudah dipinjam
perpus.pinjamBuku(siswa2, buku3);
System.out.println();

// Cek status setelah peminjaman
System.out.println("=== STATUS SETELAH PEMINJAMAN ===");
siswa1.tampilkanInfo(); System.out.println();
siswa2.tampilkanInfo(); System.out.println();
buku1.tampilkanInfo(); System.out.println();

// Simulasi pengembalian
System.out.println("=== SIMULASI PENGEMBALIAN ===");
perpus.kembalikanBuku(siswa1, buku1);
System.out.println();

// Status akhir
System.out.println("=== STATUS AKHIR ===");
siswa1.tampilkanInfo();
buku1.tampilkanInfo();
}
}

Best Practices Modularitas Java

✅ Yang Harus Dilakukan:

  • • Gunakan nama package yang deskriptif
  • • Buat satu class per file
  • • Gunakan encapsulation (private + getter/setter)
  • • Dokumentasi dengan komentar yang jelas
  • • Konsisten dalam penamaan

❌ Yang Harus Dihindari:

  • • Package name dengan huruf besar
  • • Terlalu banyak class dalam satu package
  • • Membuat semua atribut public
  • • Import * tanpa alasan jelas
  • • Circular dependency antar package
