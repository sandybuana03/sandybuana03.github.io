📚 Pengenalan Object-Oriented Programming

Apa itu OOP?

Object-Oriented Programming (OOP) adalah paradigma pemrograman yang mengorganisir kode dalam bentuk objek-objek yang memiliki data (atribut) dan fungsi (metode).

"Bayangkan OOP seperti membuat cetakan kue. Kelas adalah cetakannya, dan objek adalah kue-kue yang dihasilkan dari cetakan tersebut."

🏗️ Konsep Utama OOP

  • • Kelas (Class) - Blueprint/cetakan
  • • Objek (Object) - Instance dari kelas
  • • Atribut - Data/properti objek
  • • Metode - Fungsi/perilaku objek

✨ Keuntungan OOP

  • • Kode lebih terorganisir
  • • Mudah dipahami dan dirawat
  • • Dapat digunakan kembali
  • • Mirip dengan dunia nyata

🏗️ Kelas (Class)

Apa itu Kelas?

Kelas adalah template atau blueprint untuk membuat objek. Kelas mendefinisikan atribut (data) dan metode (fungsi) yang akan dimiliki oleh objek-objek yang dibuat dari kelas tersebut.

"Kelas seperti cetakan kue - menentukan bentuk dan karakteristik kue yang akan dibuat"

💻 Sintaks Kelas dalam Java

public class NamaKelas { // Atribut (variabel) tipeData namaAtribut; // Konstruktor public NamaKelas() { // inisialisasi } // Metode public void namaMetode() { // kode metode } }

🎯 Contoh Kelas Siswa

public class Siswa { // Atribut String nama; int umur; String kelas; // Konstruktor public Siswa(String nama, int umur, String kelas) { this.nama = nama; this.umur = umur; this.kelas = kelas; } // Metode public void perkenalan() { System.out.println("Halo, nama saya " + nama); System.out.println("Umur saya " + umur + " tahun"); System.out.println("Saya kelas " + kelas); } public void belajar() { System.out.println(nama + " sedang belajar"); } }

Penjelasan:

  • • public class Siswa - Mendefinisikan kelas bernama Siswa
  • • String nama, int umur - Atribut kelas
  • • public Siswa(...) - Konstruktor untuk membuat objek
  • • public void perkenalan() - Metode kelas

📋 Komponen Kelas

  • • Atribut: Data yang dimiliki kelas
  • • Konstruktor: Metode khusus untuk membuat objek
  • • Metode: Fungsi yang dapat dilakukan kelas
  • • Access Modifier: public, private, protected

💡 Tips Membuat Kelas

  • • Gunakan nama yang jelas dan deskriptif
  • • Mulai dengan huruf kapital
  • • Kelompokkan atribut dan metode yang terkait
  • • Gunakan access modifier yang tepat

🎯 Objek (Object)

Apa itu Objek?

Objek adalah instance atau wujud nyata dari sebuah kelas. Jika kelas adalah cetakan, maka objek adalah hasil cetakan tersebut. Setiap objek memiliki identitas, state (nilai atribut), dan behavior (metode) yang unik.

"Objek adalah 'benda' nyata yang dibuat dari blueprint kelas"

🔨 Cara Membuat Objek

// Sintaks umum NamaKelas namaObjek = new NamaKelas(); // Contoh membuat objek Siswa Siswa siswa1 = new Siswa("Budi", 17, "XII RPL"); Siswa siswa2 = new Siswa("Sari", 16, "XI TKJ"); Siswa siswa3 = new Siswa("Andi", 18, "XII MM");

Penjelasan:

  • • Siswa siswa1 - Deklarasi variabel objek
  • • new Siswa(...) - Membuat objek baru dengan konstruktor
  • • siswa1, siswa2, siswa3 - Tiga objek berbeda dari kelas yang sama

🎮 Demo Interaktif: Membuat Objek

Objek yang dibuat:

🔍 Karakteristik Objek

  • • Identitas: Setiap objek unik
  • • State: Nilai atribut saat ini
  • • Behavior: Metode yang bisa dipanggil
  • • Lifecycle: Dibuat, digunakan, dihapus

📊 Perbedaan Kelas vs Objek

Kelas: Template/blueprint
Objek: Instance nyata
Kelas: Tidak menggunakan memori
Objek: Menggunakan memori

📝 Atribut (Attributes)

Apa itu Atribut?

Atribut adalah variabel yang menyimpan data atau informasi tentang objek. Atribut menggambarkan karakteristik atau properti yang dimiliki oleh objek tersebut.

"Atribut adalah 'ciri-ciri' atau 'sifat-sifat' yang dimiliki objek"

🏷️ Jenis-jenis Atribut

Atribut Instance

Setiap objek memiliki nilai yang berbeda

public class Mobil { String warna; // Setiap mobil bisa beda warna String merek; // Setiap mobil bisa beda merek int tahun; // Setiap mobil bisa beda tahun }

Atribut Static

Semua objek memiliki nilai yang sama

public class Siswa { String nama; // Instance static String sekolah = "SMK Negeri 1"; // Static static int jumlahSiswa = 0; // Static }

🔒 Access Modifier untuk Atribut

public

Dapat diakses dari mana saja

public String nama;

private

Hanya dapat diakses dalam kelas yang sama

private int umur;

protected

Dapat diakses dalam package dan subclass

protected String alamat;

💻 Contoh Lengkap Atribut

public class Smartphone { // Atribut public public String merek; public String model; // Atribut private private double harga; private int kapasitasBaterai; // Atribut static static String jenisPerangkat = "Smartphone"; static int jumlahSmartphone = 0; // Konstruktor public Smartphone(String merek, String model, double harga, int baterai) { this.merek = merek; this.model = model; this.harga = harga; this.kapasitasBaterai = baterai; jumlahSmartphone++; // Menambah jumlah smartphone } // Getter untuk atribut private public double getHarga() { return harga; } public int getKapasitasBaterai() { return kapasitasBaterai; } // Setter untuk atribut private public void setHarga(double harga) { if (harga > 0) { this.harga = harga; } } }

Penjelasan:

  • • public merek, model: Dapat diakses langsung dari luar kelas
  • • private harga, kapasitasBaterai: Hanya bisa diakses melalui getter/setter
  • • static jenisPerangkat: Sama untuk semua objek Smartphone
  • • Getter/Setter: Metode untuk mengakses atribut private dengan aman

🎮 Demo: Mengakses Atribut

Informasi Smartphone:

💡 Best Practices untuk Atribut

  • • Gunakan private untuk atribut yang sensitif
  • • Buat getter/setter untuk mengakses atribut private
  • • Gunakan static untuk data yang sama di semua objek
  • • Berikan nama atribut yang jelas dan deskriptif
  • • Inisialisasi atribut dengan nilai default yang masuk akal

⚙️ Metode (Methods)

Apa itu Metode?

Metode adalah fungsi atau prosedur yang mendefinisikan perilaku (behavior) dari objek. Metode menentukan apa yang bisa dilakukan oleh objek tersebut.

"Metode adalah 'kemampuan' atau 'aksi' yang bisa dilakukan objek"

📋 Struktur Metode

[access_modifier] [static] [return_type] namaMetode([parameter]) { // body metode [return value;] // jika ada return type } // Contoh: public void tampilkanInfo() { System.out.println("Ini adalah metode void"); } public int hitungUmur(int tahunLahir) { return 2024 - tahunLahir; }

Komponen Metode:

  • • Access Modifier: public, private, protected
  • • Return Type: void, int, String, dll
  • • Nama Metode: Identifier unik
  • • Parameter: Input untuk metode

Jenis Return Type:

  • • void: Tidak mengembalikan nilai
  • • int: Mengembalikan bilangan bulat
  • • String: Mengembalikan teks
  • • boolean: Mengembalikan true/false

🔧 Jenis-jenis Metode

Metode Instance

Dipanggil melalui objek

public void berjalan() { System.out.println("Sedang berjalan"); } // Pemanggilan: siswa1.berjalan();

Metode dengan Parameter

Menerima input dari luar

public void setNama(String namaBaru) { this.nama = namaBaru; } // Pemanggilan: siswa1.setNama("Budi");

Metode Static

Dipanggil melalui nama kelas

public static int hitungTotal() { return jumlahSiswa; } // Pemanggilan: Siswa.hitungTotal();

Metode dengan Return

Mengembalikan nilai

public String getNama() { return this.nama; } // Pemanggilan: String nama = siswa1.getNama();

💻 Contoh Lengkap Kelas dengan Metode

public class Kalkulator { private String merek; private static int jumlahKalkulator = 0; // Konstruktor public Kalkulator(String merek) { this.merek = merek; jumlahKalkulator++; } // Metode instance dengan return public double tambah(double a, double b) { return a + b; } public double kurang(double a, double b) { return a - b; } public double kali(double a, double b) { return a * b; } public double bagi(double a, double b) { if (b != 0) { return a / b; } else { System.out.println("Error: Tidak bisa dibagi dengan nol!"); return 0; } } // Metode void public void tampilkanInfo() { System.out.println("Kalkulator merek: " + merek); } // Metode static public static int getJumlahKalkulator() { return jumlahKalkulator; } // Getter public String getMerek() { return merek; } // Setter public void setMerek(String merek) { this.merek = merek; } }

💡 Best Practices untuk Metode

  • • Berikan nama metode yang jelas dan deskriptif
  • • Satu metode sebaiknya melakukan satu tugas saja
  • • Gunakan parameter untuk membuat metode lebih fleksibel
  • • Validasi input parameter sebelum diproses
  • • Gunakan return type yang sesuai dengan kebutuhan
  • • Dokumentasikan metode yang kompleks dengan komentar
