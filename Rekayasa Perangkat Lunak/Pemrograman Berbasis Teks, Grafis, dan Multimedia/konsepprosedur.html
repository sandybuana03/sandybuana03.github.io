Pengenalan Prosedur

🎭 Apa itu Prosedur?

Bayangkan kamu punya robot yang bisa melakukan tugas-tugas tertentu. Prosedur dalam Java seperti memberikan instruksi kepada robot tersebut. Sekali kamu beri tahu caranya, robot bisa melakukan tugas itu kapan saja kamu minta!

💡 Prosedur adalah sekumpulan instruksi yang dikemas dalam satu nama, sehingga bisa dipanggil berulang kali tanpa menulis ulang kodenya.

🏠 Analogi: Rutinitas Harian

Prosedur seperti rutinitas yang kamu lakukan setiap hari:

🌅

Rutinitas Pagi

Bangun → Mandi → Sarapan

🍳

Memasak Nasi

Cuci beras → Masak → Tunggu

🚗

Pergi Sekolah

Siap-siap → Berangkat → Sampai

🏗️ Mengapa Prosedur Penting?

🔄

Menghindari Pengulangan (DRY Principle)

Tidak perlu menulis kode yang sama berulang-ulang

Contoh: Daripada menulis kode "tampilkan menu" 10 kali, cukup buat 1 prosedur dan panggil 10 kali!
📖

Mudah Dibaca (Readability)

Kode menjadi lebih terstruktur dan mudah dipahami

Contoh: Nama prosedur yang jelas seperti hitungGaji() langsung menjelaskan fungsinya
🔧

Mudah Diperbaiki (Maintainability)

Jika ada error, cukup perbaiki di satu tempat

Contoh: Bug di perhitungan pajak? Perbaiki sekali di prosedur hitungPajak()
⚡

Efisien (Efficiency)

Menghemat waktu dan tenaga dalam coding

Contoh: Tim developer bisa bekerja parallel, masing-masing buat prosedur berbeda

📊 Perbandingan: Dengan vs Tanpa Prosedur

❌ Tanpa Prosedur
  • • Kode berulang-ulang
  • • Sulit dibaca dan dipahami
  • • Error di banyak tempat
  • • Waktu development lama
  • • File program besar
✅ Dengan Prosedur
  • • Kode bersih dan rapi
  • • Mudah dibaca dan dipahami
  • • Error mudah diperbaiki
  • • Development lebih cepat
  • • File program lebih kecil

Pengertian Prosedur dalam Java

🎯 Definisi Formal

Prosedur dalam Java adalah sebuah method (metode) yang tidak mengembalikan nilai (void). Prosedur digunakan untuk mengelompokkan sekumpulan instruksi yang akan dijalankan ketika prosedur tersebut dipanggil.

🔍 Karakteristik Prosedur:

  • • Menggunakan kata kunci void
  • • Tidak mengembalikan nilai (return value)
  • • Dapat menerima parameter (opsional)
  • • Dapat dipanggil berulang kali
  • • Memiliki nama yang deskriptif

🌟 Contoh Sederhana

Mari lihat contoh prosedur sederhana:

public static void sapaPengguna() {
    System.out.println("Halo! Selamat datang di program Java!");
    System.out.println("Semoga hari mu menyenangkan! 😊");
}

Penjelasan: Prosedur sapaPengguna() akan menampilkan pesan sapaan ketika dipanggil. Tidak mengembalikan nilai apapun (void).

🔄 Cara Kerja Prosedur:

📞

1. Pemanggilan

sapaPengguna();

⚙️

2. Eksekusi

Jalankan instruksi

✅

3. Selesai

Kembali ke pemanggil

⚖️ Prosedur vs Function

🔧 Prosedur (void) 

public static void tampilkanPesan() {
    System.out.println("Halo!");
}
  • • Tidak mengembalikan nilai
  • • Fokus pada aksi/tindakan
  • • Menggunakan kata kunci void
  • • Contoh: cetak, simpan, hapus

🔄 Function (return) 

public static int hitungLuas(int p, int l) {
    return p * l;
}
  • • Mengembalikan nilai
  • • Fokus pada perhitungan
  • • Menggunakan tipe data (int, String, dll)
  • • Contoh: hitung, cari, validasi

🤔 Kapan Menggunakan Prosedur?

✅ Gunakan Prosedur Untuk:

  • • Menampilkan output: menu, pesan, laporan
  • • Memproses data: sorting, validasi input
  • • Operasi file: simpan, baca, hapus file
  • • Inisialisasi: setup awal program

❌ Jangan Gunakan Prosedur Untuk:

  • • Perhitungan: gunakan function yang return nilai
  • • Pencarian data: lebih baik return hasil
  • • Validasi: return true/false lebih baik
  • • Konversi data: return hasil konversi
⚙️

Sintaks & Struktur Prosedur

📝 Struktur Dasar Prosedur 

public static void namaProsedur(parameter) {
    // Isi prosedur (instruksi-instruksi)
    // yang akan dijalankan
}

🔍 Penjelasan Setiap Bagian:

public Dapat diakses dari class lain
static Dapat dipanggil tanpa membuat objek
void Tidak mengembalikan nilai
namaProsedur Nama unik untuk prosedur
(parameter) Data input (opsional)
{ } Blok kode yang dijalankan

🎨 Contoh Prosedur Tanpa Parameter 

public static void tampilkanMenu() {
    System.out.println("=== MENU UTAMA ===");
    System.out.println("1. Tambah Data");
    System.out.println("2. Lihat Data");
    System.out.println("3. Keluar");
}

📋 Aturan Penamaan Prosedur

✅ Penamaan yang Baik:

  • • tampilkanMenu()
  • • hitungGaji()
  • • simpanData()
  • • cetakLaporan()
Tips: Gunakan kata kerja + objek, camelCase, deskriptif

❌ Penamaan yang Buruk:

  • • menu() - terlalu singkat
  • • prosedur1() - tidak deskriptif
  • • TampilkanMenu() - PascalCase
  • • tampilkan_menu() - snake_case
Hindari: Nama tidak jelas, konvensi salah, terlalu panjang

🔐 Access Modifier

🌍

public

Dapat diakses dari mana saja

Paling umum digunakan untuk prosedur utama
🏠

private

Hanya dalam class yang sama

Untuk prosedur helper internal
📦

protected

Dalam package dan subclass

Untuk inheritance (jarang digunakan)

Parameter dalam Prosedur

🎁 Apa itu Parameter?

Parameter adalah data yang dikirim ke prosedur untuk diproses. Seperti memberikan bahan-bahan kepada koki untuk dimasak sesuai resep.

🎨 Contoh dengan Parameter 

public static void sapaSiswa(String nama) {
    System.out.println("Halo " + nama + ", selamat belajar!");
    System.out.println("Semangat mengerjakan tugas ya! 💪");
}

Contoh Praktis Prosedur

🧮 Contoh 1: Kalkulator Sederhana 

public static void tampilkanHasil(String operasi, double a, double b, double hasil) {
    System.out.println("=== KALKULATOR ===");
    System.out.println("Operasi: " + operasi);
    System.out.println(a + " " + operasi + " " + b + " = " + hasil);
    System.out.println("==================");
}

📊 Contoh 2: Sistem Penilaian 

public static void tampilkanNilai(String nama, int nilai) {
    System.out.println("=== LAPORAN NILAI ===");
    System.out.println("Nama Siswa: " + nama);
    System.out.println("Nilai: " + nilai);
    
    if (nilai >= 90) {
        System.out.println("Grade: A (Excellent!) 🌟");
    } else if (nilai >= 80) {
        System.out.println("Grade: B (Good Job!) 👍");
    } else if (nilai >= 70) {
        System.out.println("Grade: C (Not Bad!) 👌");
    } else {
        System.out.println("Grade: D (Keep Trying!) 💪");
    }
}

public static void buatTabelPerkalian(int angka) {

🔍 Contoh 4: Validasi Data 

public static void validasiUmur(String nama, int umur) {
    System.out.println("=== VALIDASI DATA ===");
    System.out.println("Nama: " + nama);

💡 Tips Praktis Membuat Prosedur

🎯 Best Practices:

  • • Single Responsibility: Satu prosedur, satu tugas
  • • Nama Deskriptif: Jelaskan apa yang dilakukan
  • • Parameter Minimal: Jangan terlalu banyak parameter
  • • Komentar: Jelaskan tujuan prosedur

⚠️ Hindari:

  • • Prosedur terlalu panjang: Maksimal 20-30 baris
  • • Terlalu banyak parameter: Maksimal 3-4 parameter
  • • Nama tidak jelas: Hindari nama seperti "proses()"
  • • Duplikasi kode: Jika ada kode sama, buat prosedur
