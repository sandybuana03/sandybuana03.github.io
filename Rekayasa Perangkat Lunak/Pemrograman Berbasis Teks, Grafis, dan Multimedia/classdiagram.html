Pengenalan Diagram Class

🤷‍♂️ Apa itu Diagram Class?

Diagram Class adalah diagram yang menunjukkan struktur sistem dengan menampilkan class-class dalam sistem, atribut dan operasi dari setiap class, serta hubungan antar class. Bayangkan seperti denah rumah yang menunjukkan ruangan-ruangan dan bagaimana mereka terhubung - Diagram Class menunjukkan komponen-komponen program dan bagaimana mereka berinteraksi!

🏠

Analogi Rumah

Seperti denah rumah yang menunjukkan kamar, pintu, dan jendela, Diagram Class menunjukkan bagian-bagian program dan bagaimana mereka terhubung.

🧩

Puzzle Programming

Diagram Class membantu kita melihat bagaimana potongan-potongan kode saling berhubungan, seperti puzzle yang tersusun rapi.

Konsep Dasar Class

🎭 Apa itu Class?

Class adalah template atau blueprint yang mendefinisikan atribut (data) dan method (perilaku) yang akan dimiliki oleh objek-objek yang dibuat dari class tersebut. Bayangkan Class seperti cetakan kue - dari satu cetakan, kamu bisa membuat banyak kue dengan bentuk yang sama, tapi isinya bisa berbeda-beda!

Contoh Sederhana:

Class "Mobil" bisa digunakan untuk membuat objek mobil Toyota, Honda, atau Suzuki. Semua punya roda, mesin, dan pintu, tapi detailnya berbeda.

📦

Class = Template

  • • Berisi rancangan/blueprint
  • • Mendefinisikan struktur
  • • Belum bisa digunakan langsung
  • • Seperti denah rumah
🏠

Object = Hasil Jadi

  • • Hasil dari Class
  • • Bisa digunakan langsung
  • • Punya nilai/data spesifik
  • • Seperti rumah yang sudah jadi

Komponen Class

Setiap Class terdiri dari 3 bagian utama. Mari kita pelajari satu per satu! 🎯

🏷️

1. Nama Class

Nama Class adalah identitas unik yang menjelaskan apa yang diwakili oleh Class tersebut.

Mahasiswa

Tips Penamaan Class:

  • • Gunakan kata benda (Mahasiswa, Mobil, Buku)
  • • Huruf pertama kapital (PascalCase)
  • • Jelas dan mudah dipahami
  • • Hindari singkatan yang membingungkan
📋

2. Atribut (Properties)

Atribut adalah ciri-ciri atau karakteristik yang dimiliki oleh Class. Seperti data yang disimpan dalam objek. Atribut biasanya bersifat private (-) untuk menjaga enkapsulasi data.

Mahasiswa
- nim: String
- nama: String
- jurusan: String
- semester: Integer

Contoh Atribut:

  • • Mobil: warna, merk, tahun
  • • Buku: judul, penulis, halaman
  • • HP: merk, warna, storage

Tipe Data:

  • • String: teks (nama, alamat)
  • • Integer: angka bulat (umur, jumlah)
  • • Boolean: true/false
⚙️

3. Method (Fungsi)

Method adalah fungsi atau operasi yang dapat dilakukan oleh objek dari class tersebut. Method biasanya bersifat public (+) agar bisa diakses dari luar class untuk berinteraksi dengan objek.

Mahasiswa
- nim: String
- nama: String
- jurusan: String
- semester: Integer
+ daftar(): void
+ belajar(): void
+ ujian(): Boolean
+ lulus(): Boolean

Contoh Method:

  • • Mobil: nyalakan(), matikan(), bergerak()
  • • HP: telepon(), kirimSMS(), foto()
  • • Mahasiswa: daftar(), belajar(), ujian()

Relasi Antar Class

Class tidak berdiri sendiri! Mereka saling berhubungan seperti teman-teman dalam sebuah grup 👥

🤝

1. Association (Asosiasi)

Hubungan "menggunakan" atau "berinteraksi dengan" antara dua class. Kedua class dapat eksis secara independen. Contoh: Mahasiswa menggunakan Buku, tapi keduanya bisa ada tanpa yang lain.

Mahasiswa
→
Buku

Mahasiswa menggunakan Buku

👨‍👩‍👧‍👦

2. Inheritance (Pewarisan)

Hubungan "adalah" atau "turunan dari" dimana child class mewarisi atribut dan method dari parent class. Child class dapat menambah atau mengubah perilaku yang diwarisi. Contoh: Mobil adalah Kendaraan.

Kendaraan
+ bergerak()
Mobil
+ nyalakanMesin()
Sepeda
+ kayuh()

Mobil dan Sepeda mewarisi sifat dari Kendaraan

🧩

3. Composition (Komposisi)

Hubungan "bagian dari" yang sangat kuat dimana bagian tidak dapat eksis tanpa keseluruhan. Jika parent object dihancurkan, child object juga ikut hancur. Contoh: Rumah dan Kamar - jika rumah dihancurkan, kamar juga hilang.

Rumah
Kamar

Kamar adalah bagian dari Rumah

📦

4. Aggregation (Agregasi)

Hubungan "bagian dari" yang lemah dimana bagian masih bisa eksis tanpa keseluruhan. Seperti Tim dan Pemain - jika Tim dibubarkan, Pemain masih bisa ada dan bergabung dengan tim lain.

Tim
Pemain

Pemain adalah bagian dari Tim, tapi bisa pindah tim

Tugas Praktik

Saatnya menguji pemahamanmu tentang Diagram Class!

1

Analisis Sistem Perpustakaan

Buatlah Diagram Class untuk sistem perpustakaan sederhana yang memiliki komponen berikut:

  • • Anggota: memiliki ID, nama, alamat, dan bisa meminjam buku
  • • Buku: memiliki ISBN, judul, penulis, dan status ketersediaan
  • • Petugas: memiliki ID, nama, dan bisa mengelola peminjaman
2

Identifikasi Relasi

Berdasarkan skenario berikut, tentukan jenis relasi yang tepat:

Skenario A: Mobil memiliki Mesin. Jika Mobil dihancurkan, Mesin juga ikut hancur.

Skenario B: Mahasiswa menggunakan Laptop untuk mengerjakan tugas.

Skenario C: Kucing adalah jenis Hewan.
