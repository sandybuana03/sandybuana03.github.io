Pengenalan Fungsi

Mari berkenalan dengan konsep fungsi dalam Java!

🤖 Apa itu Fungsi?

Fungsi (atau method dalam Java) adalah blok kode yang dirancang untuk melakukan tugas tertentu. Bayangkan fungsi seperti mesin kecil yang menerima input, memproses input tersebut, dan menghasilkan output.

🏭 Analogi Pabrik:

Fungsi seperti pabrik yang menerima bahan mentah (input), memproses dengan mesin (algoritma), dan menghasilkan produk jadi (output).

🍳 Analogi Resep:

Seperti resep masakan yang bisa digunakan berulang kali dengan bahan yang berbeda untuk menghasilkan masakan yang sama.

💡 Konsep Dasar:

Fungsi memungkinkan kita untuk memecah program besar menjadi bagian-bagian kecil yang lebih mudah dikelola. Ini adalah prinsip "Divide and Conquer" dalam programming!

🎯 Mengapa Perlu Fungsi?

🚫 Tanpa Fungsi (Kode Berulang):

// Menghitung luas 3 persegi panjang
int luas1 = 5 * 3;
System.out.println("Luas 1: " + luas1);

int luas2 = 8 * 4;
System.out.println("Luas 2: " + luas2);

int luas3 = 10 * 6;
System.out.println("Luas 3: " + luas3);

✅ Dengan Fungsi (Kode Efisien):

public static void hitungDanTampilkanLuas(int p, int l) {
    int luas = p * l;
    System.out.println("Luas: " + luas);
}

// Penggunaan:
hitungDanTampilkanLuas(5, 3);
hitungDanTampilkanLuas(8, 4);
hitungDanTampilkanLuas(10, 6);

✨ Reusability

Kode bisa digunakan berulang kali tanpa menulis ulang

// Cara memanggil fungsi

  • • sapa: Nama fungsi (harus deskriptif)
  • • (): Parameter kosong
  • • { }: Body fungsi berisi kode yang dijalankan

Dasar-Dasar Fungsi

Pelajari struktur dan komponen fungsi dalam Java!

🏗️ Anatomi Fungsi Java

// Struktur lengkap fungsi Java
public static int hitungJumlah(int a, int b) {
    // Body fungsi - tempat logika dijalankan
    int hasil = a + b;
    return hasil; // Mengembalikan nilai
}

🔧 Access Modifier

  • • public: Bisa diakses dari mana saja
  • • private: Hanya dalam class yang sama
  • • protected: Dalam package dan subclass

📤 Return Type

  • • void: Tidak mengembalikan nilai
  • • int, double: Mengembalikan angka
  • • String: Mengembalikan teks
  • • boolean: Mengembalikan true/false

💡 Tips Penting:

Keyword static memungkinkan fungsi dipanggil tanpa membuat objek. Sangat berguna untuk fungsi utility!

🎯 Jenis-Jenis Modifier dalam Detail

🌐 Public Static

public static void main(String[] args) {
    // Fungsi utama program
}

Bisa diakses dari mana saja tanpa membuat objek. Cocok untuk fungsi utility.

🔒 Private Static

private static int hitungInternal() {
    // Hanya bisa dipanggil dalam class ini
    return 42;
}

Hanya bisa diakses dalam class yang sama. Cocok untuk helper function.

📋 Aturan Penamaan Fungsi (Naming Convention)

✅ Penamaan yang Benar

  • • hitungLuas() - camelCase
  • • tampilkanData() - deskriptif
  • • cekLogin() - verb + noun
  • • isValid() - boolean function
  • • getUserName() - getter function

❌ Penamaan yang Salah

  • • hitung luas() (ada spasi)
  • • 1hitungLuas() (dimulai angka)
  • • hitung-luas() (ada tanda -)
  • • class() (kata reserved)
  • • a() (tidak deskriptif)

💡 Tips Penamaan Fungsi:

  • • Gunakan verb untuk menunjukkan aksi: calculate, display, check
  • • Untuk boolean function, gunakan is/has/can: isValid(), hasPermission()
  • • Untuk getter, gunakan get: getName(), getAge()
  • • Untuk setter, gunakan set: setName(), setAge()
  • • Hindari singkatan yang tidak jelas: calc() → calculate()

🎯 Best Practices Fungsi Java

📏 Panjang Fungsi

Idealnya 20-30 baris. Jika lebih panjang, pertimbangkan untuk memecah menjadi fungsi yang lebih kecil.

🎯 Single Responsibility

Satu fungsi hanya melakukan satu tugas. Jangan gabungkan multiple logic dalam satu fungsi.

📝 Dokumentasi

Berikan komentar yang jelas tentang apa yang dilakukan fungsi, terutama untuk logic yang kompleks.

🔄 Reusability

Buat fungsi yang bisa digunakan di berbagai tempat, bukan hanya untuk satu kasus spesifik.

Jenis-Jenis Fungsi

Kenali berbagai jenis fungsi dalam Java!

🚫 Fungsi Void (Tanpa Return)

Fungsi yang tidak mengembalikan nilai, hanya melakukan aksi tertentu.

public static void tampilkanPesan() {
    System.out.println("Selamat datang di Java!");
    System.out.println("Semangat belajar!");
}

// Cara memanggil:
tampilkanPesan();

💡 Kapan Digunakan?

Untuk menampilkan informasi, menyimpan data, atau melakukan aksi yang tidak perlu mengembalikan nilai.

📤 Fungsi dengan Return Value

Fungsi yang mengembalikan nilai setelah melakukan perhitungan atau proses.

public static int tambah(int a, int b) {
    int hasil = a + b;
    return hasil;
}

// Cara memanggil:
int jumlah = tambah(5, 3);
System.out.println(jumlah); // Output: 8

🎯 Keuntungan Return Value:

  • • Hasil bisa disimpan dalam variabel
  • • Bisa digunakan dalam ekspresi lain
  • • Lebih fleksibel untuk digunakan

Parameter & Return Value

Pelajari cara mengirim dan menerima data dalam fungsi!

📥 Parameter (Input Fungsi)

Parameter adalah data yang dikirim ke fungsi untuk diproses.

// Fungsi dengan satu parameter
public static void sapaNama(String nama) {
    System.out.println("Halo, " + nama + "!");
}

// Fungsi dengan multiple parameter
public static void perkenalan(String nama, int umur) {
    System.out.println("Nama: " + nama);
    System.out.println("Umur: " + umur + " tahun");
}

📝 Aturan Parameter:

  • • Harus menentukan tipe data (int, String, double, dll)
  • • Bisa lebih dari satu, dipisah koma
  • • Urutan parameter harus sesuai saat pemanggilan
  • • Nama parameter bebas, tapi harus deskriptif

📤 Return Value (Output Fungsi)

Return value adalah hasil yang dikembalikan oleh fungsi.

// Fungsi yang mengembalikan String
public static String buatSalam(String nama) {
    return "Selamat pagi, " + nama + "!";
}

// Fungsi yang mengembalikan int
public static int hitungKuadrat(int angka) {
    return angka * angka;
}

// Cara menggunakan:
String pesan = buatSalam("Budi");
int hasil = hitungKuadrat(5); // hasil = 25

Method Overloading

Buat fungsi dengan nama sama tapi parameter berbeda!

🤔 Apa itu Method Overloading?

Method Overloading adalah kemampuan untuk membuat beberapa method dengan nama yang sama, tetapi dengan parameter yang berbeda (jumlah, tipe, atau urutan parameter).

🎯 Analogi Sederhana:

Seperti restoran yang punya menu "Nasi Goreng" dengan berbagai varian: Nasi Goreng Biasa, Nasi Goreng Ayam, Nasi Goreng Seafood. Nama sama, tapi isinya beda!

📝 Contoh Method Overloading

public class Kalkulator {

    // Method 1: tambah dengan 2 parameter int
    public static int tambah(int a, int b) {
        return a + b;
    }

    // Method 2: tambah dengan 3 parameter int
    public static int tambah(int a, int b, int c) {
        return a + b + c;
    }

    // Method 3: tambah dengan 2 parameter double
    public static double tambah(double a, double b) {
        return a + b;
    }
}

Tugas Praktik

Saatnya menguji pemahaman kamu tentang fungsi Java!

📋 Soal 1: Fungsi Sederhana

Buatlah sebuah fungsi bernama hitungRataRata yang menerima 3 parameter bertipe int (nilai1, nilai2, nilai3) dan mengembalikan nilai rata-rata dalam bentuk double.

Contoh: hitungRataRata(80, 90, 85) → return 85.0

📋 Soal 2: Fungsi dengan Kondisi

Buatlah fungsi bernama cekKelulusan yang menerima parameter nilai (int) dan mengembalikan String "LULUS" jika nilai >= 75, atau "TIDAK LULUS" jika nilai < 75.

Contoh: cekKelulusan(80) → return "LULUS"

📋 Soal 3: Method Overloading

Buatlah 2 fungsi overloading bernama hitungLuas:

  • • Fungsi 1: menerima parameter panjang dan lebar (double) untuk menghitung luas persegi panjang
  • • Fungsi 2: menerima parameter sisi (double) untuk menghitung luas persegi

Contoh: hitungLuas(5.0, 3.0) → return 15.0 | hitungLuas(4.0) → return 16.0
