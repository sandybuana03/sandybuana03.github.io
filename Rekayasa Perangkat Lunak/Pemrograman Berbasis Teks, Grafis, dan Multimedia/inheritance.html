Pengenalan Inheritance

Mari kenali konsep pewarisan dalam Java!

Apa itu Inheritance? 🤔

Inheritance (Pewarisan) adalah salah satu konsep fundamental dalam Object-Oriented Programming (OOP) yang memungkinkan sebuah class untuk mewarisi atribut dan method dari class lain.

"Bayangkan seperti keluarga: Anak mewarisi sifat dari orang tua, tapi tetap bisa punya keunikan sendiri!"

✅ Keuntungan Inheritance

  • • Reusability: Kode bisa digunakan ulang
  • • Maintainability: Mudah dirawat dan diupdate
  • • Extensibility: Mudah dikembangkan
  • • Efficiency: Menghemat waktu coding

🏗️ Istilah Penting

  • • Parent Class: Class induk/super class
  • • Child Class: Class anak/sub class
  • • extends: Keyword untuk inheritance
  • • super: Mengakses parent class

Konsep Dasar Inheritance

Memahami cara kerja pewarisan di Java

📝 Sintaks Dasar 

// Parent Class (Super Class)
class NamaParentClass {
    // atribut dan method
}

// Child Class (Sub Class)
class NamaChildClass extends NamaParentClass {
    // atribut dan method tambahan
    // bisa menggunakan atribut dan method dari parent
}

Keyword extends digunakan untuk membuat inheritance. Child class akan mewarisi semua atribut dan method public/protected dari parent class.

🎯 Demo Interaktif: Hewan dan Kucing

Parent Class: Hewan

class Hewan {
    String nama;
    int umur;
    
    void makan() {
        System.out.println(nama + " sedang makan");
    }
    
    void tidur() {
        System.out.println(nama + " sedang tidur");
    }
}

Child Class: Kucing

class Kucing extends Hewan {
    String ras;
    
    void meong() {
        System.out.println(nama + " berkata: Meong!");
    }
    
    // Kucing punya method makan() dan tidur()
    // dari class Hewan tanpa perlu ditulis ulang!
}

Simulasi:

🔍 Apa yang Diwarisi?

✅ Yang Diwarisi:

  • • Atribut public dan protected
  • • Method public dan protected
  • • Nested class public dan protected

❌ Yang Tidak Diwarisi:

  • • Atribut dan method private
  • • Constructor
  • • Static method (tapi bisa diakses)

Super Keyword

Mengakses parent class dari child class

🔑 Apa itu Super?

super adalah keyword khusus yang digunakan untuk mengakses atribut, method, dan constructor dari parent class.

"Seperti memanggil orang tua ketika butuh bantuan atau ingin menggunakan sesuatu milik mereka!"

1️⃣ Super untuk Memanggil Method Parent 

class Hewan {
    void suara() {
        System.out.println("Hewan bersuara");
    }
}

class Kucing extends Hewan {
    void suara() {
        super.suara(); // Panggil method parent
        System.out.println("Meong meong!");
    }
}

Output:

Hewan bersuara
Meong meong!

2️⃣ Super untuk Constructor 

class Kendaraan {
    String merk;
    
    Kendaraan(String merk) {
        this.merk = merk;
        System.out.println("Kendaraan dibuat: " + merk);
    }
}

class Mobil extends Kendaraan {
    int pintu;
    
    Mobil(String merk, int pintu) {
        super(merk); // Panggil constructor parent
        this.pintu = pintu;
        System.out.println("Mobil dengan " + pintu + " pintu");
    }
}

Penjelasan:

  • • super(merk) memanggil constructor parent
  • • Harus di baris pertama constructor
  • • Menginisialisasi atribut parent terlebih dahulu

3️⃣ Super untuk Mengakses Atribut Parent 

class Orang {
    String nama = "Orang Tua";
}

class Anak extends Orang {
    String nama = "Anak";
    
    void tampilkanNama() {
        System.out.println("Nama anak: " + nama);
        System.out.println("Nama parent: " + super.nama);
    }
}

Output:

Nama anak: Anak
Nama parent: Orang Tua

Method Overriding

Mengubah perilaku method dari parent class

🎯 Apa itu Method Overriding?

Method Overriding adalah kemampuan child class untuk memberikan implementasi spesifik dari method yang sudah ada di parent class.

"Seperti anak yang punya cara sendiri dalam melakukan sesuatu, meski sudah diajarkan orang tua!"

📋 Aturan Method Overriding

✅ Harus:

  • • Nama method sama persis
  • • Parameter sama (jumlah & tipe)
  • • Return type sama atau subtype
  • • Access modifier sama atau lebih luas

❌ Tidak Boleh:

  • • Mengubah nama method
  • • Mengubah parameter
  • • Access modifier lebih ketat
  • • Override method static/final

💡 Contoh Method Overriding 

class Hewan {
    void suara() {
        System.out.println("Hewan mengeluarkan suara");
    }
    
    void info() {
        System.out.println("Ini adalah hewan");
    }
}

class Kucing extends Hewan {
    @Override  // Annotation (opsional tapi direkomendasikan)
    void suara() {
        System.out.println("Meong meong!");
    }
    
    @Override
    void info() {
        System.out.println("Ini adalah kucing yang lucu");
    }
}

class Anjing extends Hewan {
    @Override
    void suara() {
        System.out.println("Guk guk!");
    }
}

Penjelasan @Override:

Annotation @Override memberitahu compiler bahwa method ini meng-override method parent. Membantu mendeteksi error jika ada kesalahan.

🎭 Polymorphism dengan Overriding 

public class Main {
    public static void main(String[] args) {
        Hewan[] hewan = {
            new Kucing(),
            new Anjing(),
            new Hewan()
        };
        
        for (Hewan h : hewan) {
            h.suara(); // Method yang dipanggil tergantung tipe objek
        }
    }
}

Output:

Meong meong!
Guk guk!
Hewan mengeluarkan suara

Praktik Inheritance

Mari praktik langsung membuat inheritance!

🎯 Studi Kasus: Sistem Kendaraan

Kita akan membuat sistem kendaraan dengan inheritance. Mulai dari class Kendaraan sebagai parent, lalu buat class Mobil dan Motor sebagai child class.

📁 Struktur File Java:

📄 Kendaraan.java - Class parent
📄 Mobil.java - Class child pertama
📄 Motor.java - Class child kedua
📄 Main.java - Class untuk testing

💡 Tips: Setiap class public harus disimpan dalam file terpisah dengan nama yang sama!

1️⃣ Langkah 1: Buat Parent Class

📄 File: Kendaraan.java

Buat file baru dengan nama ini untuk class parent

Buat class Kendaraan dengan atribut dan method dasar:

class Kendaraan {
    // Atribut
    protected String merk;
    protected String warna;
    protected int tahunProduksi;
    protected double harga;
    
    // Constructor
    public Kendaraan(String merk, String warna, int tahun, double harga) {
        this.merk = merk;
        this.warna = warna;
        this.tahunProduksi = tahun;
        this.harga = harga;
    }
    
    // Method
    public void nyalakanMesin() {
        System.out.println("Mesin " + merk + " menyala!");
    }
    
    public void matikanMesin() {
        System.out.println("Mesin " + merk + " dimatikan!");
    }
    
    public void tampilkanInfo() {
        System.out.println("=== Info Kendaraan ===");
        System.out.println("Merk: " + merk);
        System.out.println("Warna: " + warna);
        System.out.println("Tahun: " + tahunProduksi);
        System.out.println("Harga: Rp " + harga);
    }
}

2️⃣ Langkah 2: Buat Child Class Mobil

📄 File: Mobil.java

Buat file baru terpisah untuk class child pertama

Buat class Mobil yang extends dari Kendaraan:

class Mobil extends Kendaraan {
    // Atribut khusus mobil
    private int jumlahPintu;
    private String jenisBahanBakar;
    
    // Constructor
    public Mobil(String merk, String warna, int tahun, double harga, 
                 int jumlahPintu, String jenisBahanBakar) {
        super(merk, warna, tahun, harga); // Panggil constructor parent
        this.jumlahPintu = jumlahPintu;
        this.jenisBahanBakar = jenisBahanBakar;
    }
    
    // Method khusus mobil
    public void bukaPintu() {
        System.out.println("Pintu mobil " + merk + " terbuka!");
    }
    
    public void tutupPintu() {
        System.out.println("Pintu mobil " + merk + " tertutup!");
    }
    
    public void klakson() {
        System.out.println("Tin tin! Mobil " + merk + " membunyikan klakson!");
    }
    
    // Override method parent
    @Override
    public void tampilkanInfo() {
        super.tampilkanInfo(); // Panggil method parent
        System.out.println("Jumlah Pintu: " + jumlahPintu);
        System.out.println("Bahan Bakar: " + jenisBahanBakar);
        System.out.println("Jenis: Mobil");
    }
}

3️⃣ Langkah 3: Buat Child Class Motor

📄 File: Motor.java

Buat file baru terpisah untuk class child kedua

Buat class Motor yang juga extends dari Kendaraan:

class Motor extends Kendaraan {
    // Atribut khusus motor
    private String jenisMotor; // Sport, Matic, Manual
    private int kapasitasMesin;
    
    // Constructor
    public Motor(String merk, String warna, int tahun, double harga,
                 String jenisMotor, int kapasitasMesin) {
        super(merk, warna, tahun, harga);
        this.jenisMotor = jenisMotor;
        this.kapasitasMesin = kapasitasMesin;
    }
    
    // Method khusus motor
    public void gasHandel() {
        System.out.println("Ngeeeng! Motor " + merk + " melaju kencang!");
    }
    
    public void rem() {
        System.out.println("Motor " + merk + " berhenti dengan rem!");
    }
    
    // Override method parent
    @Override
    public void tampilkanInfo() {
        super.tampilkanInfo();
        System.out.println("Jenis Motor: " + jenisMotor);
        System.out.println("Kapasitas Mesin: " + kapasitasMesin + " cc");
        System.out.println("Jenis: Motor");
    }
}

4️⃣ Langkah 4: Test Program

📄 File: Main.java

Buat file baru untuk testing semua class yang sudah dibuat

Buat class Main untuk menguji inheritance:

public class Main {
    public static void main(String[] args) {
        // Buat objek Mobil
        Mobil mobil1 = new Mobil("Toyota", "Merah", 2023, 300000000, 4, "Bensin");
        
        // Buat objek Motor
        Motor motor1 = new Motor("Honda", "Hitam", 2023, 25000000, "Matic", 150);
        
        System.out.println("=== TEST MOBIL ===");
        mobil1.tampilkanInfo();
        mobil1.nyalakanMesin();
        mobil1.bukaPintu();
        mobil1.klakson();
        mobil1.tutupPintu();
        mobil1.matikanMesin();
        
        System.out.println("\n=== TEST MOTOR ===");
        motor1.tampilkanInfo();
        motor1.nyalakanMesin();
        motor1.gasHandel();
        motor1.rem();
        motor1.matikanMesin();
    }
}
