Pengenalan Polymorphism

🎭 Apa itu Polymorphism?

Polymorphism berasal dari bahasa Yunani yang berarti "banyak bentuk" (poly = banyak, morph = bentuk). Dalam Java, polymorphism adalah kemampuan suatu objek untuk berperilaku berbeda-beda tergantung pada konteksnya, meskipun dipanggil melalui interface atau reference yang sama.

"Satu interface, banyak implementasi"

🌟 Mengapa Polymorphism Penting?

Konsep Dasar Polymorphism

🏗️ Dasar-dasar Polymorphism

Polymorphism dalam Java dibangun atas konsep Inheritance (pewarisan). Tanpa inheritance, tidak ada polymorphism!

Syarat Runtime Polymorphism (Method Overriding):

  • ✅ Ada hubungan inheritance (parent-child class) atau implementasi interface
  • ✅ Ada method yang di-override di child class
  • ✅ Menggunakan reference variable dari parent class atau interface
  • ✅ Object yang dibuat adalah instance dari child class

🎯 Contoh Sederhana

Mari lihat contoh dengan class Hewan:

// Parent class
class Hewan {
    public void bersuara() {
        System.out.println("Hewan bersuara");
    }
}

// Child classes
class Kucing extends Hewan {
    @Override
    public void bersuara() {
        System.out.println("Meong meong!");
    }
}

class Anjing extends Hewan {
    @Override
    public void bersuara() {
        System.out.println("Guk guk!");
    }
}

🎮 Demo Interaktif

🔍 Cara Kerja Polymorphism

// Ini adalah polymorphism!
Hewan hewan1 = new Kucing();  // Reference Hewan, Object Kucing
Hewan hewan2 = new Anjing();  // Reference Hewan, Object Anjing

hewan1.bersuara(); // Output: "Meong meong!"
hewan2.bersuara(); // Output: "Guk guk!"

// Contoh dengan array - Dynamic Method Dispatch
Hewan[] kebunBinatang = {
    new Kucing(),
    new Anjing(),
    new Hewan()
};

for (Hewan h : kebunBinatang) {
    h.bersuara(); // Method yang dipanggil ditentukan saat runtime
}

// Polymorphism dengan Interface
interface Terbang {
    void terbang();
}

class Burung implements Terbang {
    public void terbang() { System.out.println("Burung terbang dengan sayap"); }
}

class Pesawat implements Terbang {
    public void terbang() { System.out.println("Pesawat terbang dengan mesin"); }
}

// Polymorphism dengan interface
Terbang[] objekTerbang = {new Burung(), new Pesawat()};
for (Terbang t : objekTerbang) {
    t.terbang(); // Polymorphism!
}

Kunci: Meskipun reference variable-nya bertipe Hewan, method yang dipanggil adalah method dari object yang sebenarnya (Kucing atau Anjing). Ini disebut Dynamic Method Dispatch - penentuan method terjadi saat runtime.

Jenis-jenis Polymorphism

⚡

Runtime Polymorphism

(Method Overriding)

Karakteristik:

  • • Terjadi saat runtime
  • • Menggunakan inheritance
  • • Method signature sama persis
  • • Menggunakan @Override
🔧

Compile-time Polymorphism

(Method Overloading)

Karakteristik:

  • • Terjadi saat compile time
  • • Dalam class yang sama
  • • Method name sama, parameter beda
  • • Tidak perlu inheritance

📊 Perbandingan Detail

Aspek Runtime (Overriding) Compile-time (Overloading)
Waktu Resolusi Saat program berjalan Saat kompilasi
Inheritance Wajib ada Tidak perlu
Method Signature Harus sama persis Parameter harus berbeda
Performance Sedikit lebih lambat (virtual method lookup) Lebih cepat (resolved saat compile)
Fleksibilitas Sangat fleksibel untuk extensibility Fleksibel untuk convenience methods

🎯 Kapan Menggunakan?

⚡ Gunakan Overriding ketika:

  • • Ingin mengubah behavior method parent
  • • Membuat implementasi spesifik untuk child class
  • • Membutuhkan polymorphism yang sesungguhnya

🔧 Gunakan Overloading ketika:

  • • Method sama tapi parameter berbeda
  • • Ingin memberikan fleksibilitas input
  • • Membuat convenience methods
⚡

Method Overriding

🎯 Apa itu Method Overriding?

Method Overriding adalah kemampuan child class untuk memberikan implementasi spesifik dari method yang sudah didefinisikan di parent class.

"Mengubah cara kerja method warisan sesuai kebutuhan"

📋 Aturan Method Overriding

✅ Harus:

  • • Method name sama persis
  • • Parameter sama persis (jumlah, tipe, urutan)
  • • Return type sama atau covariant return type
  • • Menggunakan @Override annotation (strongly recommended)
  • • Access modifier sama atau lebih luas (tidak boleh lebih restrictive)

❌ Tidak boleh:

  • • Access modifier lebih restrictive (public → protected/private)
  • • Throw checked exception baru yang tidak ada di parent
  • • Method static di-override (static method hiding, bukan overriding)
  • • Method final di-override (final = tidak bisa diubah)
  • • Method private di-override (private tidak diwariskan)

💻 Contoh Lengkap

// Parent class
class Kendaraan {
    protected String merk;
    protected int tahun;
    
    public Kendaraan(String merk, int tahun) {
        this.merk = merk;
        this.tahun = tahun;
    }
    
    public void info() {
        System.out.println("Kendaraan: " + merk + " (" + tahun + ")");
    }
    
    public void nyalakan() {
        System.out.println("Kendaraan dinyalakan");
    }
}

// Child class
class Mobil extends Kendaraan {
    private int jumlahPintu;
    
    public Mobil(String merk, int tahun, int jumlahPintu) {
        super(merk, tahun);
        this.jumlahPintu = jumlahPintu;
    }
    
    @Override
    public void info() {
        System.out.println("Mobil: " + merk + " (" + tahun + ") - " + jumlahPintu + " pintu");
    }
    
    @Override
    public void nyalakan() {
        System.out.println("Mobil " + merk + " dinyalakan dengan kunci");
    }
}

class Motor extends Kendaraan {
    private String jenisMotor;
    
    public Motor(String merk, int tahun, String jenisMotor) {
        super(merk, tahun);
        this.jenisMotor = jenisMotor;
    }
    
    @Override
    public void info() {
        System.out.println("Motor: " + merk + " (" + tahun + ") - " + jenisMotor);
    }
    
    @Override
    public void nyalakan() {
        System.out.println("Motor " + merk + " dinyalakan dengan starter");
    }
}

🎮 Demo Interaktif

🔍 Super Keyword

Keyword super digunakan untuk mengakses method atau constructor parent class. 

@Override
public void info() {
    super.info(); // Panggil method parent dulu
    System.out.println("Informasi tambahan dari child class");
}

// Contoh dalam constructor
public Mobil(String merk, int tahun, int jumlahPintu) {
    super(merk, tahun); // Panggil constructor parent
    this.jumlahPintu = jumlahPintu;
}

// Mengakses field parent yang di-hide
public void tampilkanMerk() {
    System.out.println("Merk dari parent: " + super.merk);
    System.out.println("Merk dari child: " + this.merk); // jika ada field merk di child
}

Method Overloading

🎯 Apa itu Method Overloading?

Method Overloading adalah kemampuan untuk membuat beberapa method dengan nama yang sama tapi parameter yang berbeda dalam satu class.

"Satu nama method, berbagai cara penggunaan"

📋 Cara Overloading Method

🔢

Jumlah Parameter

Berbeda jumlah parameter

🏷️

Tipe Parameter

Berbeda tipe data parameter

📝

Urutan Parameter

Berbeda urutan tipe parameter

💻 Contoh Lengkap

class Kalkulator {
    
    // Overloading berdasarkan jumlah parameter
    public int tambah(int a, int b) {
        return a + b;
    }
    
    public int tambah(int a, int b, int c) {
        return a + b + c;
    }
    
    // Overloading berdasarkan tipe parameter
    public double tambah(double a, double b) {
        return a + b;
    }
    
    public String tambah(String a, String b) {
        return a + " + " + b + " = " + a + b;
    }
    
    // Overloading berdasarkan urutan parameter
    public void info(String nama, int umur) {
        System.out.println("Nama: " + nama + ", Umur: " + umur);
    }
    
    public void info(int umur, String nama) {
        System.out.println("Umur: " + umur + ", Nama: " + nama);
    }
}

🎮 Demo Kalkulator

⚠️ Yang Tidak Bisa Overloading

❌ Tidak Valid:

// SALAH! Hanya berbeda return type
public int hitung(int a, int b) { return a + b; }
public double hitung(int a, int b) { return a + b; } // Compile Error!

// SALAH! Hanya berbeda nama parameter
public int tambah(int angka1, int angka2) { return angka1 + angka2; }
public int tambah(int x, int y) { return x + y; } // Compile Error!

// SALAH! Hanya berbeda access modifier
public int kali(int a, int b) { return a * b; }
private int kali(int a, int b) { return a * b; } // Compile Error!

// BENAR! Berbeda jumlah parameter
public int tambah(int a, int b) { return a + b; }
public int tambah(int a, int b, int c) { return a + b + c; } // OK!

Ingat: Yang membedakan overloading adalah signature method (nama + parameter), bukan return type atau nama parameter!

Praktik Polymorphism

🎯 Studi Kasus: Sistem Pembayaran

Mari buat sistem pembayaran yang mendukung berbagai metode pembayaran menggunakan polymorphism!

📂 Struktur Project:

📁 SistemPembayaran/
├── 📄 MetodePembayaran.java    (Abstract parent class)
├── 📄 KartuKredit.java         (Child class 1)
├── 📄 EWallet.java             (Child class 2)
├── 📄 SistemPembayaran.java    (Utility class)
└── 📄 Main.java                (Main class untuk testing)

📝 Langkah 1: Buat Parent Class

📁 Nama File: MetodePembayaran.java

File ini berisi abstract class sebagai parent dari semua metode pembayaran

abstract class MetodePembayaran {
    protected String nama;
    protected double saldo;
    
    public MetodePembayaran(String nama, double saldo) {
        this.nama = nama;
        this.saldo = saldo;
    }
    
    // Method yang akan di-override
    public abstract boolean bayar(double jumlah);
    
    // Method yang bisa di-overload
    public void info() {
        System.out.println("Metode: " + nama + ", Saldo: Rp" + saldo);
    }
    
    public void info(String detail) {
        System.out.println("Metode: " + nama + ", Saldo: Rp" + saldo + ", " + detail);
    }
}

📝 Langkah 2: Buat Child Classes

📁 Nama File:

  • • KartuKredit.java - Class untuk pembayaran kartu kredit
  • • EWallet.java - Class untuk pembayaran e-wallet
class KartuKredit extends MetodePembayaran {
    private double limit;
    
    public KartuKredit(String nama, double saldo, double limit) {
        super(nama, saldo);
        this.limit = limit;
    }
    
    @Override
    public boolean bayar(double jumlah) {
        if (jumlah <= saldo + limit) {
            saldo -= jumlah;
            System.out.println("Pembayaran Rp" + jumlah + " berhasil dengan Kartu Kredit");
            return true;
        }
        System.out.println("Pembayaran gagal: Melebihi limit");
        return false;
    }
    
    @Override
    public void info(String detail) {
        super.info("Limit: Rp" + limit + ", " + detail);
    }
}

class EWallet extends MetodePembayaran {
    private String provider;
    
    public EWallet(String nama, double saldo, String provider) {
        super(nama, saldo);
        this.provider = provider;
    }
    
    @Override
    public boolean bayar(double jumlah) {
        if (jumlah <= saldo) {
            saldo -= jumlah;
            System.out.println("Pembayaran Rp" + jumlah + " berhasil dengan " + provider);
            return true;
        }
        System.out.println("Pembayaran gagal: Saldo tidak cukup");
        return false;
    }
    
    // Method overloading
    public boolean bayar(double jumlah, String kodePromo) {
        double diskon = kodePromo.equals("HEMAT10") ? 0.1 : 0;
        double jumlahFinal = jumlah * (1 - diskon);
        
        if (jumlahFinal <= saldo) {
            saldo -= jumlahFinal;
            System.out.println("Pembayaran Rp" + jumlahFinal + " berhasil dengan " + provider + 
                             " (Diskon: " + (diskon * 100) + "%)");
            return true;
        }
        System.out.println("Pembayaran gagal: Saldo tidak cukup");
        return false;
    }
}

📝 Langkah 3: Implementasi Polymorphism

📁 Nama File: SistemPembayaran.java

File ini berisi class untuk mendemonstrasikan polymorphism dalam action

class SistemPembayaran {
    public static void prosesPembayaran(MetodePembayaran metode, double jumlah) {
        System.out.println("=== Memproses Pembayaran ===");
        metode.info();
        
        boolean berhasil = metode.bayar(jumlah);
        
        if (berhasil) {
            System.out.println("✅ Transaksi berhasil!");
        } else {
            System.out.println("❌ Transaksi gagal!");
        }
        
        metode.info("Setelah transaksi");
        System.out.println();
    }
}

🎮 Demo Sistem Pembayaran

📝 Langkah 4: Main Class untuk Testing

📁 Nama File: Main.java

File utama untuk menjalankan dan testing semua class

public class Main {
    public static void main(String[] args) {
        // Membuat objek dengan polymorphism
        MetodePembayaran kartu = new KartuKredit("Visa", 2000000, 5000000);
        MetodePembayaran gopay = new EWallet("GoPay", 1500000, "GoPay");
        
        // Array polymorphic
        MetodePembayaran[] metodePembayaran = {kartu, gopay};
        
        // Testing polymorphism
        for (MetodePembayaran metode : metodePembayaran) {
            SistemPembayaran.prosesPembayaran(metode, 500000);
        }
        
        // Testing method overloading pada EWallet
        EWallet ovo = new EWallet("OVO", 800000, "OVO");
        ovo.bayar(200000);           // Method biasa
        ovo.bayar(300000, "HEMAT10"); // Method overloading dengan promo
    }
}
