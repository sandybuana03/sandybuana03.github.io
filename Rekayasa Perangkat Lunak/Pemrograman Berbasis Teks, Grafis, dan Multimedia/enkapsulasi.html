🔒 Apa itu Encapsulation?

Encapsulation (Enkapsulasi) adalah salah satu prinsip dasar dalam Object-Oriented Programming (OOP). Bayangkan seperti kapsul obat yang melindungi isinya dari luar!

"Encapsulation adalah cara untuk menyembunyikan detail internal suatu objek dan hanya menampilkan fungsi-fungsi yang diperlukan untuk berinteraksi dengan objek tersebut."

✅ Keuntungan

  • 🛡️ Data lebih aman
  • 🔧 Mudah dipelihara
  • 🎯 Kontrol akses yang baik
  • 🚀 Kode lebih terorganisir

Konsep Dasar Encapsulation

Memahami prinsip-prinsip fundamental

🎯 Prinsip Data Hiding

Data Hiding adalah inti dari Encapsulation. Kita menyembunyikan data internal objek dan hanya memberikan akses melalui method yang sudah ditentukan.

❌ Tanpa Encapsulation

public class Siswa {
    public String nama;
    public int umur;
    public double nilai;
}

// Bisa diakses langsung
Siswa siswa = new Siswa();
siswa.umur = -5; // Nilai tidak valid!
siswa.nilai = 150; // Nilai tidak masuk akal!

✅ Dengan Encapsulation

public class Siswa {
    private String nama;
    private int umur;
    private double nilai;

    public void setUmur(int umur) {
        if (umur > 0) {
            this.umur = umur;
        }
    }
}

Getter & Setter Methods

Cara aman mengakses dan mengubah data

🎭 Analogi Resepsionis Hotel

Getter dan Setter seperti resepsionis hotel yang mengatur akses ke kamar:

📥 Getter Method

Seperti bertanya ke resepsionis: "Boleh saya tahu nomor kamar saya?"

public String getNama() { return nama; }

📤 Setter Method

Seperti meminta resepsionis: "Tolong ubah data saya"

public void setNama(String nama) { this.nama = nama; }

💻 Contoh Lengkap Class Siswa dengan Encapsulation

Perhatikan bagaimana semua field dibuat private dan diakses melalui method public:

public class Siswa {
    // Private fields - data tersembunyi
    private String nama;
    private int umur;
    private double nilai;

    // Constructor
    public Siswa(String nama, int umur, double nilai) {
        this.nama = nama;
        setUmur(umur); // Gunakan setter untuk validasi
        setNilai(nilai);
    }

    // Getter Methods
    public String getNama() {
        return nama;
    }

    public int getUmur() {
        return umur;
    }

    public double getNilai() {
        return nilai;
    }

    // Setter Methods dengan validasi
    public void setNama(String nama) {
        if (nama != null && !nama.isEmpty()) {
            this.nama = nama;
        }
    }

    public void setUmur(int umur) {
        if (umur > 0 && umur < 100) {
            this.umur = umur;
        }
    }

    public void setNilai(double nilai) {
        if (nilai >= 0 && nilai <= 100) {
            this.nilai = nilai;
        }
    }
}

🏦 Langkah 1: Buat Class BankAccount

File: BankAccount.java

public class BankAccount {
    // Private fields - data tersembunyi dan aman
    private String accountNumber;
    private String accountHolder;
    private double balance;
    private String pin;

    // Constructor
    public BankAccount(String accountNumber, String accountHolder, String pin) {
        this.accountNumber = accountNumber;
        this.accountHolder = accountHolder;
        this.pin = pin;
        this.balance = 0.0; // Saldo awal 0
    }

    // Getter Methods - untuk mengambil data
    public String getAccountNumber() {
        return accountNumber;
    }

    public String getAccountHolder() {
        return accountHolder;
    }

    public double getBalance() {
        return balance;
    }

    // Method untuk deposit dengan validasi
    public boolean deposit(double amount) {
        if (amount > 0) {
            balance += amount;
            return true;
        }
        return false;
    }

    // Method untuk withdraw dengan validasi PIN dan saldo
    public boolean withdraw(double amount, String inputPin) {
        if (!validatePin(inputPin)) {
            return false;
        }
        if (amount > 0 && amount <= balance) {
            balance -= amount;
            return true;
        }
        return false;
    }

    // Private method untuk validasi PIN
    private boolean validatePin(String inputPin) {
        return this.pin.equals(inputPin);
    }
}

🚀 Langkah 2: Buat Class Main untuk Testing

File: Main.java - Class ini akan menguji semua fitur BankAccount:

public class Main {
    public static void main(String[] args) {
        // Membuat objek BankAccount dengan constructor
        BankAccount rekening = new BankAccount("001234567890", "Budi Santoso", "1234");

        // Menampilkan info awal
        System.out.println("Pemegang: " + rekening.getAccountHolder());
        System.out.println("Saldo awal: " + rekening.getBalance());

        // Testing deposit
        if (rekening.deposit(500000)) {
            System.out.println("Deposit berhasil!");
        }

        // Testing withdraw dengan PIN benar
        if (rekening.withdraw(100000, "1234")) {
            System.out.println("Penarikan berhasil!");
        } else {
            System.out.println("Penarikan gagal!");
        }

        // Testing withdraw dengan PIN salah
        if (!rekening.withdraw(50000, "9999")) {
            System.out.println("PIN salah! Penarikan ditolak.");
        }

        // Menampilkan saldo akhir
        System.out.println("Saldo akhir: " + rekening.getBalance());
    }
}
