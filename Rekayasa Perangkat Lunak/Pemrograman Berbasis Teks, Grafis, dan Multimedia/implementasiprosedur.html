Pengenalan Prosedur Java

Halo teman-teman! 👋 Hari ini kita akan belajar tentang Prosedur dalam bahasa pemrograman Java. Prosedur adalah sekumpulan perintah yang dikemas dalam satu blok dan bisa dipanggil berulang kali.

🤔 Apa itu Prosedur?

Prosedur adalah seperti "resep masakan" dalam programming. Sekali kita buat resepnya, kita bisa menggunakannya berulang kali tanpa harus menulis ulang langkah-langkahnya!

Perbedaan Prosedur dan Function:
• Prosedur (void) - Melakukan aksi, tidak mengembalikan nilai
• Function - Melakukan perhitungan dan mengembalikan hasil

✅ Keuntungan Prosedur:

  • • Kode lebih rapi dan terorganisir
  • • Bisa digunakan berulang kali
  • • Mudah diperbaiki jika ada error
  • • Menghemat waktu coding

🎯 Yang Akan Kita Pelajari:

  • • Membuat prosedur sederhana
  • • Prosedur dengan parameter
  • • Prosedur yang mengembalikan nilai
  • • Praktik lengkap dengan contoh
💡

Tips Belajar & Debugging

Tips Belajar:

• Ikuti setiap langkah dengan teliti dan praktik langsung

• Jangan copy-paste, ketik manual untuk memahami lebih baik

Error Umum:

• Lupa titik koma (;) di akhir statement

• Salah penulisan nama prosedur (case sensitive)

• Kurung kurawal { } tidak seimbang

Langkah 1: Membuat Prosedur Sederhana

🎯 Tujuan Langkah Ini

Kita akan belajar membuat prosedur paling sederhana yang hanya menampilkan pesan ke layar.

📋 Langkah-langkah Praktik:

Step 1: Buat File Java Baru

Buka IDE Java favorit kalian (NetBeans, Eclipse, atau VS Code) dan buat file baru dengan nama ProsedurSederhana.java

Step 2: Tulis Kode Dasar

Ketik kode berikut dengan teliti:

📄 ProsedurSederhana.java ✨ Kode Lengkap 
public class ProsedurSederhana {
    
    // Ini adalah prosedur sederhana
    public static void tampilkanSalam() {
        System.out.println("=========================");
        System.out.println("   Selamat Datang! 🎉   ");
        System.out.println("   Belajar Java Yuk!     ");
        System.out.println("=========================");
    }
    
    // Method main untuk menjalankan program
    public static void main(String[] args) {
        System.out.println("Program Prosedur Sederhana");
        System.out.println("==========================");
        
        // Memanggil prosedur
        tampilkanSalam();
        
        System.out.println("\\nProsedur berhasil dipanggil! ✅");
    }
}

Step 3: Penjelasan Kode

• public static void tampilkanSalam() - Ini adalah prosedur kita!

• public - Bisa diakses dari mana saja

• static - Bisa dipanggil tanpa membuat objek

• void - Tidak mengembalikan nilai apapun

• tampilkanSalam() - Nama prosedur kita

📺 Output Program:

Program Prosedur Sederhana
==========================
=========================
Selamat Datang! 🎉
Belajar Java Yuk!
=========================
Prosedur berhasil dipanggil! ✅
🎯

Latihan 2: Buat prosedur tampilkanGaris() yang menampilkan garis pembatas "=========="

Latihan 3: Gabungkan kedua prosedur dalam program utama!

Langkah 2: Prosedur dengan Parameter

🎯 Tujuan Langkah Ini

Sekarang kita akan belajar membuat prosedur yang bisa menerima data dari luar (parameter). Ini membuat prosedur lebih fleksibel dan powerful!

📋 Langkah-langkah Praktik:

Step 1: Buat File Baru

Buat file baru dengan nama ProsedurParameter.java

Step 2: Kode dengan Parameter

Ketik kode berikut:

📄 ProsedurParameter.java ✨ Dengan Parameter 
public class ProsedurParameter {
    
    // Prosedur dengan 1 parameter
    public static void sapaNama(String nama) {
        System.out.println("╔══════════════════════════╗");
        System.out.println("║   Halo, " + nama + "! 👋        ║");
        System.out.println("║   Selamat Belajar Java!  ║");
        System.out.println("╚══════════════════════════╝");
    }
    
    // Prosedur dengan 2 parameter
    public static void tampilkanBiodata(String nama, int umur) {
        System.out.println("\\n📋 BIODATA SISWA");
        System.out.println("================");
        System.out.println("Nama  : " + nama);
        System.out.println("Umur  : " + umur + " tahun");
        System.out.println("Status: Siswa SMK Keren! 🎓");
    }
    
    public static void main(String[] args) {
        System.out.println("🎯 PROGRAM PROSEDUR DENGAN PARAMETER");
        System.out.println("====================================");
        
        // Memanggil prosedur dengan parameter
        sapaNama("Budi");
        sapaNama("Sari");
        
        // Memanggil prosedur dengan 2 parameter
        tampilkanBiodata("Ahmad", 17);
        tampilkanBiodata("Dewi", 16);
        
        System.out.println("\\n✅ Semua prosedur berhasil dijalankan!");
    }
}

Step 3: Penjelasan Parameter

• Parameter - Data yang dikirim ke prosedur

• String nama - Parameter bertipe String

• int umur - Parameter bertipe integer

• Urutan parameter harus sesuai saat pemanggilan!

📺 Output Program:

🎯 PROGRAM PROSEDUR DENGAN PARAMETER
====================================
╔══════════════════════════╗
║ Halo, Budi! 👋 ║
║ Selamat Belajar Java! ║
╚══════════════════════════╝
📋 BIODATA SISWA
================
Nama : Ahmad
Umur : 17 tahun
Status: Siswa SMK Keren! 🎓

Langkah 3: Prosedur dengan Return Value

🎯 Tujuan Langkah Ini

Sekarang kita akan belajar membuat prosedur yang tidak hanya menerima data, tapi juga mengembalikan hasil perhitungan (return value). Ini disebut juga Function!

📋 Langkah-langkah Praktik:

Step 1: Buat File Baru

Buat file baru dengan nama FunctionReturn.java

Step 2: Kode dengan Return Value

Ketik kode berikut:

📄 FunctionReturn.java ✨ Dengan Return Value 
public class FunctionReturn {
    
    // Function yang mengembalikan nilai String
    public static String buatSalam(String nama) {
        return "Halo " + nama + "! Selamat datang di Java! 🎉";
    }
    
    // Function untuk menghitung luas persegi panjang
    public static double hitungLuasPersegiPanjang(double panjang, double lebar) {
        double luas = panjang * lebar;
        return luas;
    }
    
    // Function untuk mengecek bilangan genap/ganjil
    public static boolean cekBilanganGenap(int angka) {
        return angka % 2 == 0;
    }
    
    public static void main(String[] args) {
        System.out.println("🎮 PROGRAM FUNCTION DENGAN RETURN VALUE");
        System.out.println("=======================================");
        
        // Menggunakan function yang return String
        String pesan1 = buatSalam("Andi");
        String pesan2 = buatSalam("Maya");
        System.out.println(pesan1);
        System.out.println(pesan2);
        
        // Menggunakan function untuk menghitung luas
        System.out.println("\\n📐 PERHITUNGAN LUAS PERSEGI PANJANG");
        System.out.println("===================================");
        double luas1 = hitungLuasPersegiPanjang(10.5, 7.2);
        System.out.println("Luas (10.5 x 7.2) = " + luas1 + " cm²");
        
        // Menggunakan function boolean
        System.out.println("\\n🔢 CEK BILANGAN GENAP/GANJIL");
        System.out.println("============================");
        int angka = 12;
        boolean genap = cekBilanganGenap(angka);
        String jenis = genap ? "Genap ✅" : "Ganjil ❌";
        System.out.println("Angka " + angka + " adalah " + jenis);
        
        System.out.println("\\n✅ Semua function berhasil dijalankan!");
    }
}

Step 3: Penjelasan Return Value

• return - Kata kunci untuk mengembalikan nilai

• String buatSalam() - Function yang return String

• double hitungLuas() - Function yang return double

• boolean cekGenap() - Function yang return boolean

• Ganti 'void' dengan tipe data yang akan dikembalikan!

📺 Output Program:

🎮 PROGRAM FUNCTION DENGAN RETURN VALUE
=======================================
Halo Andi! Selamat datang di Java! 🎉
Halo Maya! Selamat datang di Java! 🎉
📐 PERHITUNGAN LUAS PERSEGI PANJANG
===================================
Luas (10.5 x 7.2) = 75.6 cm²
🔢 CEK BILANGAN GENAP/GANJIL
============================
Angka 12 adalah Genap ✅
✅ Semua function berhasil dijalankan!

Langkah 4: Praktik Lengkap - Sistem Kasir

🎯 Tujuan Praktik Lengkap

Sekarang kita akan membuat program kasir sederhana yang menggunakan semua jenis prosedur yang sudah kita pelajari. Ini akan menjadi project mini yang keren! 🎉

📋 Langkah-langkah Praktik:

Step 1: Buat File Project

Buat file baru dengan nama SistemKasir.java

Step 2: Kode Sistem Kasir Lengkap

Ketik kode project lengkap berikut:

📄 SistemKasir.java 🚀 Project Lengkap 
public class SistemKasir {
    
    // Prosedur untuk menampilkan header toko
    public static void tampilkanHeader() {
        System.out.println("╔══════════════════════════════════════╗");
        System.out.println("║          🏪 TOKO SERBA ADA           ║");
        System.out.println("║        Sistem Kasir Digital         ║");
        System.out.println("╚══════════════════════════════════════╝");
        System.out.println();
    }
    
    // Function untuk mendapatkan harga barang
    public static double getHargaBarang(int kodeBarang) {
        switch (kodeBarang) {
            case 1: return 5000;  // Buku Tulis
            case 2: return 3000;  // Pulpen
            case 3: return 2500;  // Penggaris
            default: return 0;
        }
    }
    
    // Function untuk menghitung subtotal
    public static double hitungSubtotal(double harga, int jumlah) {
        return harga * jumlah;
    }
    
    // Function untuk menghitung diskon
    public static double hitungDiskon(double total) {
        if (total >= 25000) {
            return total * 0.10;  // Diskon 10%
        } else {
            return 0;  // Tidak ada diskon
        }
    }
    
    // Prosedur untuk menampilkan struk
    public static void tampilkanStruk(double total, double diskon, double bayar) {
        System.out.println("\\n" + "=".repeat(30));
        System.out.println("       📄 STRUK PEMBELIAN");
        System.out.println("=".repeat(30));
        System.out.println("Subtotal    : Rp " + (int)total);
        System.out.println("Diskon      : Rp " + (int)diskon);
        System.out.println("Total Bayar : Rp " + (int)bayar);
        System.out.println("=".repeat(30));
        System.out.println("   Terima kasih! 🙏");
    }
    
    public static void main(String[] args) {
        // Tampilkan header
        tampilkanHeader();
        
        System.out.println("📋 DAFTAR BARANG");
        System.out.println("1. Buku Tulis - Rp 5.000");
        System.out.println("2. Pulpen     - Rp 3.000");
        System.out.println("3. Penggaris  - Rp 2.500");
        
        // Simulasi pembelian
        System.out.println("\\n🛒 SIMULASI PEMBELIAN");
        System.out.println("====================");
        
        // Beli 2 buku tulis dan 3 pulpen
        double harga1 = getHargaBarang(1);  // Buku tulis
        double subtotal1 = hitungSubtotal(harga1, 2);
        
        double harga2 = getHargaBarang(2);  // Pulpen
        double subtotal2 = hitungSubtotal(harga2, 3);
        
        double totalBelanja = subtotal1 + subtotal2;
        double diskon = hitungDiskon(totalBelanja);
        double totalBayar = totalBelanja - diskon;
        
        System.out.println("Buku Tulis x2 = Rp " + (int)subtotal1);
        System.out.println("Pulpen x3     = Rp " + (int)subtotal2);
        
        // Tampilkan struk
        tampilkanStruk(totalBelanja, diskon, totalBayar);
        
        System.out.println("\\n🎓 Selamat! Project kasir berhasil!");
    }
}

Step 3: Penjelasan Project

• Prosedur void: tampilkanHeader(), tampilkanStruk()

• Function return: getHargaBarang(), hitungSubtotal(), hitungDiskon()

• Parameter: Semua function menerima parameter

• Modular: Setiap fungsi punya tugas spesifik

• Reusable: Bisa dipanggil berulang kali
