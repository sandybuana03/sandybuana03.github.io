📚 Pengenalan Event Handling

🎪 Apa itu Event Handling?

Event Handling adalah cara program komputer "mendengarkan" dan "merespons" tindakan yang dilakukan pengguna, seperti mengklik tombol, mengetik di keyboard, atau menggerakkan mouse.

🎭 Analogi Sederhana:

Bayangkan kamu sedang menonton TV dengan remote control:

  • • Event: Kamu menekan tombol "Volume +"
  • • Event Handler: TV "mendengar" sinyal dari remote
  • • Response: Volume TV naik

🎯 Mengapa Penting?

  • • Membuat aplikasi interaktif
  • • Merespons input pengguna
  • • Menciptakan pengalaman yang dinamis
  • • Dasar dari semua aplikasi modern

🔧 Di Java NetBeans

NetBeans menyediakan cara mudah untuk menangani event melalui:

  • • Visual editor yang user-friendly
  • • Auto-generate event handler
  • • Drag & drop components

Kode dalam event handler dijalankan

🎭 Jenis-Jenis Event

🖱️ Mouse Events

  • MouseClicked: Saat mouse diklik
  • MousePressed: Saat tombol mouse ditekan
  • MouseReleased: Saat tombol mouse dilepas
  • MouseEntered: Saat mouse masuk area komponen
  • MouseExited: Saat mouse keluar area komponen

⌨️ Keyboard Events

  • KeyPressed: Saat tombol keyboard ditekan
  • KeyReleased: Saat tombol keyboard dilepas
  • KeyTyped: Saat karakter diketik

🎯 Action Events

  • ActionPerformed: Saat tombol diklik atau Enter ditekan
  • Paling sering digunakan untuk Button, MenuItem

🪟 Window Events

  • WindowOpened: Saat window dibuka
  • WindowClosed: Saat window ditutup
  • WindowClosing: Saat window akan ditutup

👂 Event Listener

🎯 Apa itu Event Listener?

Event Listener adalah "pendengar" yang selalu siaga menunggu event tertentu terjadi, lalu menjalankan kode yang sudah kita siapkan.

📝 Contoh Sederhana:

// Event Listener untuk tombol
private void btnClickActionPerformed(ActionEvent evt) {
    // Kode yang dijalankan saat tombol diklik
    JOptionPane.showMessageDialog(this, "Tombol diklik!");
}

🔧 Cara Membuat di NetBeans

  1. 1. Klik kanan pada komponen (Button, dll)
  2. 2. Pilih "Events"
  3. 3. Pilih jenis event (Action, Mouse, dll)
  4. 4. NetBeans otomatis buat method handler
  5. 5. Tulis kode di dalam method tersebut

💡 Tips Praktis

  • • Gunakan nama method yang jelas
  • • Satu event listener untuk satu tugas
  • • Jangan lupa handle exception
  • • Test setiap event yang dibuat

📋 Interface Event Listener Umum

ActionListener

Untuk button, menu item, text field (Enter)

MouseListener

Untuk event mouse (click, press, release, enter, exit)

KeyListener

Untuk event keyboard (pressed, released, typed)

WindowListener

Untuk event window (opened, closed, closing)

⚠️ Exception Handling dalam Event

Selalu gunakan try-catch dalam event handler untuk menangani kemungkinan error: 

private void btnHitungActionPerformed(ActionEvent evt) {
    try {
        // Kode yang mungkin menimbulkan error
        double angka = Double.parseDouble(txtInput.getText());
        // Proses perhitungan...
    } catch (NumberFormatException e) {
        // Tangani error input bukan angka
        JOptionPane.showMessageDialog(this, "Input harus berupa angka!");
    } catch (ArithmeticException e) {
        // Tangani error pembagian dengan nol
        JOptionPane.showMessageDialog(this, "Tidak bisa membagi dengan nol!");
    }
}

⚡ Praktik Event Handling

🏗️ Struktur Project

EventHandlingDemo/
├── src/
│   └── eventhandlingdemo/
│       ├── EventHandlingDemo.java (Main Class - untuk menjalankan aplikasi)

📋 Langkah-Langkah Praktik

Langkah 1: Buat Project Baru

  1. 1. Buka NetBeans IDE
  2. 2. File → New Project → Java → Java Application
  3. 3. Project Name: "EventHandlingDemo"
  4. 4. Klik Finish

Langkah 2: Buat JFrame Form

  1. 1. Klik kanan pada package → New → JFrame Form
  2. 2. Class Name: "MainForm"
  3. 3. Klik Finish
  4. 4. Set MainForm sebagai main class: Klik kanan project → Properties → Run → Main Class: pilih MainForm

Langkah 3: Desain GUI

Tambahkan komponen berikut ke form:

  • • 3 JButton (btnHello, btnClear, btnExit)
  • • 1 JTextField (txtInput)
  • • 1 JLabel (lblOutput)

💻 Kode Event Handler

File: MainForm.java - Event Handler untuk Button Hello

// Import yang diperlukan:
// import javax.swing.JOptionPane;
// import java.awt.Color;

private void btnHelloActionPerformed(java.awt.event.ActionEvent evt) {
    // Ambil teks dari input field
    String nama = txtInput.getText();
    
    // Validasi input
    if (nama.trim().isEmpty()) {
        JOptionPane.showMessageDialog(this, 
            "Silakan masukkan nama Anda!", 
            "Peringatan", 
            JOptionPane.WARNING_MESSAGE);
        return;
    }
    
    // Tampilkan pesan hello
    lblOutput.setText("Hello, " + nama + "! Selamat belajar Event Handling!");
    lblOutput.setForeground(Color.BLUE);
}

File: MainForm.java - Event Handler untuk Button Clear

private void btnClearActionPerformed(java.awt.event.ActionEvent evt) {
    // Bersihkan semua field
    txtInput.setText("");
    lblOutput.setText("Output akan muncul di sini...");
    lblOutput.setForeground(Color.BLACK);
    
    // Focus ke input field
    txtInput.requestFocus();
}

File: MainForm.java - Event Handler untuk Button Exit

private void btnExitActionPerformed(java.awt.event.ActionEvent evt) {
    // Konfirmasi sebelum keluar
    int pilihan = JOptionPane.showConfirmDialog(this,
        "Apakah Anda yakin ingin keluar?",
        "Konfirmasi",
        JOptionPane.YES_NO_OPTION);
    
    if (pilihan == JOptionPane.YES_OPTION) {
        System.exit(0);
    }
}

File: MainForm.java - Event Handler untuk TextField (Enter Key)

// Import yang diperlukan:
// import java.awt.event.KeyEvent;

private void txtInputKeyPressed(java.awt.event.KeyEvent evt) {
    // Jika tombol Enter ditekan
    if (evt.getKeyCode() == KeyEvent.VK_ENTER) {
        // Panggil event handler button Hello
        btnHelloActionPerformed(null);
    }
}

💻 Contoh Kode Event Handler Kalkulator

Event Handler untuk Penjumlahan:

private void btnTambahActionPerformed(ActionEvent evt) {
    try {
        // Ambil input dari text field
        double angka1 = Double.parseDouble(txtAngka1.getText());
        double angka2 = Double.parseDouble(txtAngka2.getText());
        
        // Hitung hasil
        double hasil = angka1 + angka2;
        
        // Tampilkan hasil
        lblHasil.setText("Hasil: " + hasil);
        
    } catch (NumberFormatException e) {
        JOptionPane.showMessageDialog(this, 
            "Masukkan angka yang valid!", 
            "Error", 
            JOptionPane.ERROR_MESSAGE);
    }
}
