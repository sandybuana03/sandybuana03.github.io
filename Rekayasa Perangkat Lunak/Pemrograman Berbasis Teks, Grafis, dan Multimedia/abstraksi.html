Pengenalan Abstraksi

🤖 Apa itu Abstraksi?

Abstraksi adalah cara menyembunyikan detail implementasi yang rumit dan hanya menampilkan fitur-fitur penting kepada pengguna.

Contoh dalam Kehidupan Sehari-hari:

🚗

Mobil

Kamu tahu cara menyetir tanpa perlu tahu cara kerja mesin

📱

Smartphone

Tinggal tap aplikasi tanpa tahu kode di dalamnya

🏧

ATM

Ambil uang tanpa tahu sistem perbankan

🎯 Mengapa Abstraksi Penting?

🧹 Kode Lebih Bersih
🔄 Mudah Digunakan Ulang
🛡️ Lebih Aman
⚡ Mudah Dipelihara

🔧 Cara Implementasi di Java

Java menyediakan 2 cara utama untuk membuat abstraksi:

🏗️

Abstract Class

Class yang tidak bisa dibuat objeknya langsung

🔌

Interface

Kontrak yang harus diikuti oleh class

🧠

Konsep Dasar Abstraksi

🎭 Prinsip Abstraksi

1. Menyembunyikan Kompleksitas

Seperti menggunakan calculator tanpa tahu rumus matematika di dalamnya

2. Fokus pada Apa, Bukan Bagaimana

Kita tahu fungsinya, tidak perlu tahu cara kerjanya

3. Memberikan Interface yang Sederhana

Seperti tombol power yang sederhana untuk menyalakan TV

🔍 Contoh Sederhana

Bayangkan kamu punya berbagai jenis kendaraan:

// Tanpa Abstraksi - Ribet!
class Mobil {
    void nyalakanMesin() { /* kode rumit */ }
    void injeksiaBahan() { /* kode rumit */ }
    void putarRoda() { /* kode rumit */ }
}

class Motor {
    void startEngine() { /* kode rumit */ }
    void fuelInjection() { /* kode rumit */ }
    void wheelRotation() { /* kode rumit */ }
}
// Dengan Abstraksi - Simpel!
abstract class Kendaraan {
    abstract void jalan();  // Yang penting bisa jalan
    abstract void berhenti(); // Yang penting bisa berhenti
}

class Mobil extends Kendaraan {
    void jalan() { System.out.println("Mobil berjalan"); }
    void berhenti() { System.out.println("Mobil berhenti"); }
}

Abstract Class

📋 Apa itu Abstract Class?

Abstract class adalah class yang tidak bisa dibuat objeknya secara langsung. Seperti blueprint rumah - kamu tidak bisa tinggal di blueprint, tapi bisa membangun rumah dari blueprint tersebut.

Karakteristik Abstract Class:

  • ✅ Menggunakan keyword abstract
  • ✅ Tidak bisa dibuat objek langsung
  • ✅ Bisa punya method abstract dan concrete
  • ✅ Bisa punya constructor dan variabel

💻 Syntax Abstract Class

// Membuat Abstract Class
abstract class Hewan {
    // Variabel biasa
    String nama;
    int umur;
    
    // Constructor
    public Hewan(String nama, int umur) {
        this.nama = nama;
        this.umur = umur;
    }
    
    // Method concrete (sudah ada implementasi)
    public void tidur() {
        System.out.println(nama + " sedang tidur");
    }
    
    // Abstract method (harus diimplementasi di child class)
    abstract void bersuara();
    abstract void bergerak();
}
// Implementasi Abstract Class
class Kucing extends Hewan {
    public Kucing(String nama, int umur) {
        super(nama, umur);
    }
    
    // Wajib implement abstract method
    void bersuara() {
        System.out.println(nama + " berkata: Meow!");
    }
    
    void bergerak() {
        System.out.println(nama + " berlari dengan lincah");
    }
}

Interface

🤝 Apa itu Interface?

Interface adalah kontrak atau perjanjian yang harus diikuti oleh class. Seperti SIM - semua pengemudi harus bisa menyetir, rem, dan belok, tidak peduli jenis kendaraannya.

Karakteristik Interface:

  • ✅ Semua method secara default abstract
  • ✅ Tidak bisa punya constructor
  • ✅ Variabel otomatis public, static, final
  • ✅ Class bisa implement multiple interface

⚖️ Abstract Class vs Interface

Aspek Abstract Class Interface
Keyword abstract class interface
Method Abstract + Concrete Hanya Abstract
Constructor ✅ Bisa punya ❌ Tidak bisa
Multiple Inheritance ❌ Tidak bisa ✅ Bisa

💻 Syntax Interface

// Membuat Interface
interface Terbang {
    // Konstanta (otomatis public static final)
    int KECEPATAN_MAKSIMAL = 1000;
    
    // Abstract method (otomatis public abstract)
    void lepasLandas();
    void terbang();
    void mendarat();
}

interface Berenang {
    void menyelam();
    void berenang();
}
// Implementasi Interface
class Bebek implements Terbang, Berenang {
    public void lepasLandas() {
        System.out.println("Bebek mengepakkan sayap dan lepas landas");
    }
    
    public void terbang() {
        System.out.println("Bebek terbang rendah di atas air");
    }
    
    public void mendarat() {
        System.out.println("Bebek mendarat di permukaan air");
    }
    
    public void menyelam() {
        System.out.println("Bebek menyelam mencari ikan");
    }
    
    public void berenang() {
        System.out.println("Bebek berenang dengan tenang");
    }
}

📝 Langkah 1: Buat Abstract Class

File: Kendaraan.java

// File: Kendaraan.java
public abstract class Kendaraan {
    protected String nama;
    protected String warna;
    protected int kecepatan;
    
    // Constructor
    public Kendaraan(String nama, String warna) {
        this.nama = nama;
        this.warna = warna;
        this.kecepatan = 0;
    }
    
    // Method concrete
    public void info() {
        System.out.println("=== Info Kendaraan ===");
        System.out.println("Nama: " + nama);
        System.out.println("Warna: " + warna);
        System.out.println("Kecepatan: " + kecepatan + " km/h");
    }
    
    public void setKecepatan(int kecepatan) {
        this.kecepatan = kecepatan;
    }
    
    // Abstract methods - harus diimplementasi
    public abstract void nyalakan();
    public abstract void matikan();
    public abstract void bergerak();
}

🚗 Langkah 3: Implementasi Concrete Class

File: Mobil.java

// File: Mobil.java
public class Mobil extends Kendaraan {
    private boolean mesinHidup;
    
    public Mobil(String nama, String warna) {
        super(nama, warna);
        this.mesinHidup = false;
    }
    
    @Override
    public void nyalakan() {
        mesinHidup = true;
        System.out.println(nama + " dinyalakan. Mesin hidup!");
    }
    
    @Override
    public void matikan() {
        mesinHidup = false;
        kecepatan = 0;
        System.out.println(nama + " dimatikan. Mesin mati!");
    }
    
    @Override
    public void bergerak() {
        if (mesinHidup) {
            setKecepatan(60);
            System.out.println(nama + " bergerak di jalan raya dengan kecepatan " + kecepatan + " km/h");
        } else {
            System.out.println("Nyalakan mesin dulu!");
        }
    }
}

File: Pesawat.java

// File: Pesawat.java
public class Pesawat extends Kendaraan implements Terbang {
    private boolean mesinHidup;
    private boolean diUdara;
    
    public Pesawat(String nama, String warna) {
        super(nama, warna);
        this.mesinHidup = false;
        this.diUdara = false;
    }
    
    @Override
    public void nyalakan() {
        mesinHidup = true;
        System.out.println(nama + " dinyalakan. Mesin jet hidup!");
    }
    
    @Override
    public void matikan() {
        if (!diUdara) {
            mesinHidup = false;
            kecepatan = 0;
            System.out.println(nama + " dimatikan. Mesin jet mati!");
        } else {
            System.out.println("Tidak bisa matikan mesin saat terbang!");
        }
    }
    
    @Override
    public void bergerak() {
        if (diUdara) {
            terbang();
        } else {
            System.out.println(nama + " bergerak di landasan");
        }
    }
    
    @Override
    public void lepasLandas() {
        if (mesinHidup) {
            diUdara = true;
            setKecepatan(800);
            System.out.println(nama + " lepas landas! Naik ke udara dengan kecepatan " + kecepatan + " km/h");
        } else {
            System.out.println("Nyalakan mesin dulu!");
        }
    }
    
    @Override
    public void terbang() {
        if (diUdara) {
            System.out.println(nama + " terbang di ketinggian " + KETINGGIAN_MAKSIMAL + " meter");
        } else {
            System.out.println("Lepas landas dulu!");
        }
    }
    
    @Override
    public void mendarat() {
        if (diUdara) {
            diUdara = false;
            setKecepatan(0);
            System.out.println(nama + " mendarat dengan selamat!");
        } else {
            System.out.println(nama + " sudah di darat!");
        }
    }
}

🎯 Tugas 1: Analisis Kode

Perhatikan kode berikut dan jawab pertanyaan di bawahnya:

abstract class Bentuk {
    protected String warna;
    
    public Bentuk(String warna) {
        this.warna = warna;
    }
    
    public void setWarna(String warna) {
        this.warna = warna;
    }
    
    abstract double hitungLuas();
    abstract double hitungKeliling();
}

class Lingkaran extends Bentuk {
    private double radius;
    
    public Lingkaran(String warna, double radius) {
        super(warna);
        this.radius = radius;
    }
    
    double hitungLuas() {
        return 3.14 * radius * radius;
    }
    
    double hitungKeliling() {
        return 2 * 3.14 * radius;
    }
}

Pertanyaan:

1. Mengapa class Bentuk dibuat abstract?

2. Apa yang terjadi jika method hitungLuas() tidak diimplementasi di class Lingkaran?

3. Bisakah kita membuat objek dari class Bentuk langsung? Mengapa?
