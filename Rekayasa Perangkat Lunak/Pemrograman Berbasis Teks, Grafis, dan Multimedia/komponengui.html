Pengenalan NetBeans & Java Swing

Mengenal IDE dan framework untuk membuat GUI

🛠️ Apa itu NetBeans?

NetBeans adalah IDE (Integrated Development Environment) gratis untuk Java yang memudahkan kita membuat aplikasi. Seperti Microsoft Word untuk menulis, NetBeans adalah tempat kita "menulis" program Java dengan fitur drag-and-drop untuk GUI.

Keunggulan NetBeans:

  • • Visual editor untuk GUI (drag & drop)
  • • Auto-complete code
  • • Debugging tools
  • • Project management

🎨 Apa itu Java Swing?

Java Swing adalah library (kumpulan kode siap pakai) untuk membuat GUI di Java. Swing menyediakan komponen-komponen seperti tombol, kotak teks, dan menu yang bisa kita gunakan untuk membuat antarmuka aplikasi.

Komponen Utama:

  • • JFrame (Jendela)
  • • JButton (Tombol)
  • • JTextField (Input teks)
  • • JLabel (Label teks)

Keunggulan Swing:

  • • Cross-platform
  • • Ringan dan cepat
  • • Customizable
  • • Event-driven

JFrame & JPanel

Jendela utama dan container untuk komponen GUI

🏠 Apa itu JFrame?

JFrame adalah jendela utama aplikasi GUI Java. Seperti bingkai foto yang menampung gambar, JFrame menampung semua komponen GUI lainnya. Setiap aplikasi desktop Java minimal memiliki satu JFrame.

Contoh Kode JFrame Sederhana:

import javax.swing.*; import java.awt.*; public class MyFrame extends JFrame { public MyFrame() { // Set judul jendela setTitle("Aplikasi Pertamaku"); // Set ukuran jendela (lebar, tinggi) setSize(400, 300); // Set posisi di tengah layar setLocationRelativeTo(null); // Set operasi ketika tombol close diklik setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE); // Set layout manager (opsional) setLayout(new FlowLayout()); // Tampilkan jendela setVisible(true); } public static void main(String[] args) { // Jalankan di Event Dispatch Thread SwingUtilities.invokeLater(() -> new MyFrame()); } }

📦 Apa itu JPanel?

JPanel adalah container (wadah) untuk mengelompokkan komponen GUI. Seperti kotak organizer yang membantu mengatur barang-barang, JPanel membantu mengatur tata letak komponen dalam JFrame.

Contoh Penggunaan JPanel:

// Membuat JPanel dengan layout manager JPanel panel = new JPanel(new FlowLayout()); // Menambahkan komponen ke panel JButton button = new JButton("Klik"); JLabel label = new JLabel("Nama:"); JTextField textField = new JTextField(15); panel.add(label); panel.add(textField); panel.add(button); // Menambahkan panel ke frame frame.add(panel);

🎯 Layout Manager

Layout Manager mengatur posisi dan ukuran komponen secara otomatis. Seperti aturan main dalam permainan, layout manager menentukan bagaimana komponen disusun.

Layout Manager Umum:

  • • FlowLayout: Susun berurutan (default JPanel)
  • • BorderLayout: 5 area (N,S,E,W,Center) - default JFrame
  • • GridLayout: Tabel/grid dengan ukuran sama
  • • BoxLayout: Vertikal/horizontal fleksibel

Contoh Penggunaan:

// BorderLayout (default JFrame) frame.add(toolbar, BorderLayout.NORTH); frame.add(content, BorderLayout.CENTER); frame.add(status, BorderLayout.SOUTH); // GridLayout 2x3 panel.setLayout(new GridLayout(2, 3, 5, 5)); // FlowLayout dengan gap panel.setLayout(new FlowLayout(FlowLayout.CENTER, 10, 5));

💡 Tips Memilih Layout:

  • • BorderLayout: Untuk aplikasi dengan toolbar, content area, status bar
  • • GridLayout: Untuk kalkulator, keyboard, atau form terstruktur
  • • FlowLayout: Untuk toolbar dengan tombol-tombol
  • • BoxLayout: Untuk form vertikal atau horizontal yang fleksibel

⚡ Best Practices GUI Java

🎯 Tips Penting:

  • • Event Dispatch Thread: Gunakan SwingUtilities.invokeLater() untuk thread safety
  • • Layout Manager: Hindari null layout, gunakan layout manager yang sesuai
  • • Resource Management: Tutup resource seperti file dan database connection
  • • User Experience: Berikan feedback visual untuk aksi yang membutuhkan waktu
  • • Error Handling: Tangani exception dengan try-catch dan beri pesan yang jelas

JButton

Tombol interaktif untuk melakukan aksi

🎯 Apa itu JButton?

JButton adalah komponen tombol yang dapat diklik untuk melakukan suatu aksi. Seperti tombol pada remote TV atau tombol elevator, JButton memicu event ketika ditekan oleh pengguna.

Contoh Membuat JButton:

// Import yang diperlukan import javax.swing.*; import java.awt.event.*; // Membuat tombol dengan teks JButton button1 = new JButton("Klik Saya"); // Cara 1: Lambda Expression (Java 8+) button1.addActionListener(e -> { JOptionPane.showMessageDialog(null, "Tombol diklik!"); }); // Cara 2: Anonymous Inner Class JButton button2 = new JButton("Tombol 2"); button2.addActionListener(new ActionListener() { public void actionPerformed(ActionEvent e) { System.out.println("Button 2 clicked!"); } }); // Menambahkan ke panel atau frame panel.add(button1); panel.add(button2);

JTextField & JTextArea

Komponen untuk input dan tampilan teks

📝 JTextField vs JTextArea

JTextField:

  • • Input teks satu baris
  • • Cocok untuk nama, email, password
  • • Otomatis enter untuk submit
// Membuat JTextField dengan lebar 20 kolom JTextField nama = new JTextField(20); // Mengambil teks dari field String isiNama = nama.getText(); // Mengatur teks default nama.setText("Masukkan nama..."); // Menambahkan placeholder (hint text) nama.setToolTipText("Masukkan nama lengkap Anda"); // Event listener untuk Enter key nama.addActionListener(e -> { System.out.println("Enter ditekan: " + nama.getText()); });

JTextArea:

  • • Input teks multi-baris
  • • Cocok untuk komentar, deskripsi
  • • Bisa ditambah scroll pane
// Membuat JTextArea (5 baris, 20 kolom) JTextArea area = new JTextArea(5, 20); // Mengatur word wrap area.setLineWrap(true); area.setWrapStyleWord(true); // Menambahkan scroll pane JScrollPane scroll = new JScrollPane(area); // Mengatur scroll policy scroll.setVerticalScrollBarPolicy(JScrollPane.VERTICAL_SCROLLBAR_AS_NEEDED); scroll.setHorizontalScrollBarPolicy(JScrollPane.HORIZONTAL_SCROLLBAR_NEVER); // Menambahkan ke panel panel.add(scroll);

JLabel

Komponen untuk menampilkan teks dan gambar

🏷️ Apa itu JLabel?

JLabel adalah komponen untuk menampilkan teks atau gambar yang tidak dapat diedit oleh pengguna. Seperti label nama pada kemeja atau petunjuk arah, JLabel memberikan informasi kepada pengguna.

Contoh Membuat JLabel:

// Import yang diperlukan import javax.swing.*; import java.awt.*; // Membuat JLabel dengan teks JLabel label1 = new JLabel("Nama:"); // Membuat JLabel dengan teks dan alignment JLabel label2 = new JLabel("Judul", JLabel.CENTER); // Mengubah teks label label1.setText("Email:"); // Mengatur font dan warna label1.setFont(new Font("Arial", Font.BOLD, 14)); label1.setForeground(Color.BLUE); // Mengatur background (opsional) label2.setOpaque(true); label2.setBackground(Color.LIGHT_GRAY); // Menambahkan icon dari file (opsional) ImageIcon icon = new ImageIcon("icon.png"); JLabel labelIcon = new JLabel("Teks", icon, JLabel.LEFT);

JComboBox

Dropdown menu untuk pilihan

📋 Apa itu JComboBox?

JComboBox adalah komponen dropdown yang menampilkan daftar pilihan saat diklik. Seperti menu dropdown di website, JComboBox menghemat ruang dengan menyembunyikan opsi sampai dibutuhkan.

Contoh Membuat JComboBox:

// Membuat array pilihan String[] kota = {"Jakarta", "Surabaya", "Bandung"}; // Membuat JComboBox JComboBox<String> comboBox = new JComboBox<>(kota); // Menambahkan item baru comboBox.addItem("Medan"); // Mengatur item yang dipilih comboBox.setSelectedIndex(0); // Pilih item pertama // Menambahkan ActionListener comboBox.addActionListener(e -> { String selected = (String) comboBox.getSelectedItem(); int index = comboBox.getSelectedIndex(); System.out.println("Dipilih: " + selected + " (index: " + index + ")"); });

📝 Soal Essay

1. Analisis Komponen GUI (25 poin)

Jelaskan perbedaan antara JTextField dan JTextArea. Berikan contoh penggunaan yang tepat untuk masing-masing komponen dalam aplikasi nyata (minimal 3 contoh untuk setiap komponen).

2. Event Handling (25 poin)

Buatlah pseudocode (algoritma sederhana) untuk membuat kalkulator sederhana menggunakan JButton dan JTextField. Jelaskan bagaimana event handling bekerja ketika tombol angka dan operator diklik.

3. Studi Kasus Aplikasi (25 poin)

Rancang aplikasi "Sistem Pemesanan Makanan" sederhana menggunakan komponen GUI Java. Tentukan komponen apa saja yang dibutuhkan dan jelaskan fungsi setiap komponen.

4. Implementasi Sederhana (25 poin)

Tuliskan kode Java lengkap untuk membuat form registrasi sederhana dengan komponen berikut:

  • • JLabel untuk "Nama", "Email", dan "Kota"

  • • JComboBox untuk pilihan kota (Jakarta, Surabaya, Bandung)
  • • JButton "Daftar" dengan event handling
  • • Tampilkan hasil input dalam JOptionPane atau console

Sertakan import statement, class declaration, constructor, dan method main yang lengkap.

Masalah yang Sering Terjadi:

❌ Komponen tidak muncul

✅ Pastikan sudah memanggil setVisible(true) dan add() komponen ke container

❌ Layout berantakan

✅ Pilih layout manager yang tepat dan gunakan pack() atau setSize()

❌ Event tidak berfungsi

✅ Periksa apakah ActionListener sudah ditambahkan dengan benar

❌ Aplikasi freeze

✅ Jangan lakukan operasi berat di Event Dispatch Thread
