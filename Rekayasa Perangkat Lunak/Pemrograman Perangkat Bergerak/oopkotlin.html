👋 Pengenalan Object-Oriented Programming

🤖 Apa itu OOP?

Object-Oriented Programming (OOP) adalah cara menulis program dengan meniru cara kerja dunia nyata. Kita membuat "objek-objek" yang punya sifat dan bisa melakukan sesuatu, persis seperti benda-benda di sekitar kita!

🌟 Mengapa OOP Penting untuk Android?

🧩

Mudah Diorganisir

Kode jadi rapi dan mudah dipahami, seperti menyusun mainan di kotak-kotak terpisah!

🔄

Bisa Dipakai Ulang

Sekali buat, bisa dipakai berkali-kali! Hemat waktu dan tenaga!

👥

Kerja Tim Jadi Mudah

Banyak programmer bisa bekerja sama tanpa bingung!

🎭 Analogi Sederhana: Pabrik Mobil

Bayangkan kalian punya pabrik mobil:

  • 🏭 Blueprint/Desain Mobil = Class (rencana/template)
  • 🚗 Mobil yang Diproduksi = Object (hasil nyata)
  • 🎨 Warna, Merek, Tahun = Properties (ciri-ciri)
  • ⚡ Nyalakan Mesin, Rem, Klakson = Methods (aksi yang bisa dilakukan)

📱 Contoh dalam Aplikasi Android

// Contoh sederhana: Class Pengguna aplikasi class User { var nama: String = "" var umur: Int = 0 var email: String = "" fun login() { println("$nama berhasil login!") } fun logout() { println("$nama telah logout") } } // Membuat object dari class User val pengguna1 = User() pengguna1.nama = "Budi" pengguna1.umur = 17 pengguna1.email = "budi@gmail.com" pengguna1.login() // Output: Budi berhasil login!

🎯 Poin Penting

OOP membuat kode kita seperti LEGO! Kita bisa menyusun blok-blok kecil (class) menjadi aplikasi yang besar dan kompleks. Setiap blok punya fungsi spesifik dan bisa digabungkan dengan blok lain! 🧱✨

🏗️ Class & Object - Fondasi OOP

🎯 Apa itu Class?

Class adalah blueprint atau template untuk membuat object. Seperti cetakan kue - sekali buat cetakan, bisa bikin banyak kue dengan bentuk yang sama! 🍪

🎪 Apa itu Object?

Object adalah hasil nyata dari class. Seperti kue yang sudah jadi dari cetakan. Setiap kue (object) bisa punya rasa berbeda meski bentuknya sama! 🧁

📝 Cara Membuat Class di Kotlin

// Syntax dasar membuat class class NamaClass { // Properties (karakteristik) // Methods (perilaku/fungsi) } // Contoh: Class Smartphone class Smartphone { // Properties var merek: String = "" var model: String = "" var warna: String = "" var harga: Int = 0 // Methods fun nyalakan() { println("📱 Smartphone $merek $model menyala!") } fun matikan() { println("📱 Smartphone $merek $model dimatikan") } fun telepon(nomorTujuan: String) { println("📞 Menelepon ke $nomorTujuan...") } }

🎨 Membuat Object dari Class

// Membuat object dari class Smartphone val hp1 = Smartphone() val hp2 = Smartphone() // Mengisi properties hp1.merek = "Samsung" hp1.model = "Galaxy A54" hp1.warna = "Biru" hp1.harga = 5000000 hp2.merek = "iPhone" hp2.model = "15" hp2.warna = "Pink" hp2.harga = 15000000 // Menggunakan methods hp1.nyalakan() // Output: 📱 Smartphone Samsung Galaxy A54 menyala! hp2.telepon("081234567890") // Output: 📞 Menelepon ke 081234567890...

  • Class = Template/Blueprint (seperti resep masakan)
  • Object = Instance nyata (seperti masakan yang sudah jadi)

⚙️ Properties & Methods - Jiwa dari Object

🎨 Properties (Karakteristik)

Properties adalah ciri-ciri atau data yang dimiliki object. Seperti nama, warna, ukuran, dll.

📊

⚡ Methods (Perilaku)

Methods adalah aksi atau fungsi yang bisa dilakukan object. Seperti berjalan, berbicara, menghitung, dll.

🎬

📱 Contoh: Class Aplikasi Media Sosial

class PostInstagram { // Properties - Data yang dimiliki setiap post var username: String = "" var caption: String = "" var jumlahLike: Int = 0 var jumlahKomentar: Int = 0 var waktuPosting: String = "" // Methods - Aksi yang bisa dilakukan fun like() { jumlahLike++ println("❤️ Post di-like! Total like: $jumlahLike") } fun unlike() { if (jumlahLike > 0) { jumlahLike-- println("💔 Like dibatalkan. Total like: $jumlahLike") } } fun tambahKomentar(komentar: String) { jumlahKomentar++ println("💬 Komentar ditambahkan: '$komentar'") println("Total komentar: $jumlahKomentar") } fun tampilkanPost() { println(""" 📸 POST INSTAGRAM 👤 @$username 📝 $caption ❤️ $jumlahLike likes 💬 $jumlahKomentar comments 📅 $waktuPosting """.trimIndent()) } }

🔧 Constructor - Membangun Object dengan Gaya

🏗️ Apa itu Constructor?

Constructor adalah method khusus yang dipanggil saat object dibuat. Seperti setup awal saat kita beli HP baru - langsung diisi nama, password, dll! 📱✨

🎯 Primary Constructor

// Primary Constructor - langsung di header class class Siswa(val nama: String, val kelas: String, var umur: Int) { // Properties otomatis dibuat dari parameter constructor // Init block - dijalankan saat object dibuat init { println("🎓 Siswa baru: $nama dari kelas $kelas, umur $umur tahun") println("📚 Selamat datang di sekolah!") } fun belajar(mataPelajaran: String) { println("📖 $nama sedang belajar $mataPelajaran") } } // Cara membuat object dengan primary constructor val siswa1 = Siswa("Budi", "XII RPL 1", 17) val siswa2 = Siswa("Sari", "XII RPL 2", 16)

🔧 Secondary Constructor

// Class dengan Primary dan Secondary Constructor class Mahasiswa(val nama: String) { var nim: String = "" var jurusan: String = "" var semester: Int = 1 // Secondary Constructor constructor(nama: String, nim: String, jurusan: String) : this(nama) { this.nim = nim this.jurusan = jurusan println("🎓 Mahasiswa $nama ($nim) jurusan $jurusan terdaftar!") } fun daftar(mataKuliah: String) { println("📚 $nama mendaftar mata kuliah: $mataKuliah") } } // Penggunaan berbagai constructor val mhs1 = Mahasiswa("Andi") // Primary constructor val mhs2 = Mahasiswa("Siti", "2023001", "Informatika") // Secondary constructor

🌳 Inheritance - Pewarisan Sifat

👨‍👩‍👧‍👦 Apa itu Inheritance?

Inheritance adalah kemampuan class untuk mewarisi properties dan methods dari class lain. Seperti anak mewarisi sifat dari orang tua! 👶➡️👨

👨‍🏫

Parent Class (Superclass)

Class induk yang memberikan warisan sifat dan perilaku

👶

Child Class (Subclass)

Class anak yang menerima warisan dan bisa menambah sifat baru

🎯 Contoh Sederhana: Hewan

// Parent Class - Class induk open class Hewan(val nama: String, val jenis: String) { var umur: Int = 0 var berat: Double = 0.0 // Method yang bisa diwariskan open fun makan() { println("🍽️ $nama sedang makan") } open fun tidur() { println("😴 $nama sedang tidur") } open fun bersuara() { println("🔊 $nama mengeluarkan suara") } fun info() { println("📋 Nama: $nama, Jenis: $jenis, Umur: $umur tahun, Berat: $berat kg") } } // Child Class - Class anak class Kucing(nama: String) : Hewan(nama, "Kucing") { var ras: String = "Domestik" // Override method dari parent override fun bersuara() { println("🐱 $nama berkata: Meow meow!") } override fun makan() { println("🐱 $nama makan ikan dengan lahap") } // Method khusus kucing fun memanjat() { println("🌳 $nama memanjat pohon dengan lincah") } fun bermain() { println("🧶 $nama bermain dengan benang") } } class Anjing(nama: String) : Hewan(nama, "Anjing") { var ras: String = "Campuran" override fun bersuara() { println("🐕 $nama berkata: Woof woof!") } override fun makan() { println("🐕 $nama makan daging dan tulang") } fun menggonggong() { println("🔊 $nama menggonggong keras untuk menjaga rumah!") } fun berlari() { println("🏃 $nama berlari dengan cepat") } } // Contoh penggunaan val kucing = Kucing("Mimi") kucing.umur = 2 kucing.berat = 3.5 kucing.ras = "Persia" kucing.info() // Method dari parent class kucing.bersuara() // Override method kucing.memanjat() // Method khusus kucing

🎯 Poin Penting Inheritance

  • open keyword diperlukan untuk class dan method yang bisa diwariskan
  • override keyword untuk mengganti method parent
  • Child class mendapat semua properties dan methods dari parent
  • Child class bisa menambah properties dan methods baru

🔒 Encapsulation - Melindungi Data

🛡️ Apa itu Encapsulation?

Encapsulation adalah cara melindungi data dengan menyembunyikan detail internal dan hanya memberikan akses melalui method tertentu. Seperti brankas - isinya tersembunyi, hanya bisa diakses dengan kunci yang tepat! 🔐

🔓

Public

Bisa diakses dari mana saja - seperti pintu terbuka

🔒

Private

Hanya bisa diakses dari dalam class - seperti kamar pribadi

🏦 Contoh: Sistem Bank Account

class BankAccount(private val nomorRekening: String, private val namaPemilik: String) { // Private properties - tidak bisa diakses langsung dari luar private var saldo: Double = 0.0 private var pin: String = "1234" // Public methods - interface untuk berinteraksi dengan account fun cekSaldo(pinInput: String): String { return if (pinInput == pin) { "💰 Saldo Anda: Rp${String.format("%,.0f", saldo)}" } else { "❌ PIN salah!" } } fun setor(jumlah: Double, pinInput: String): String { return when { pinInput != pin -> "❌ PIN salah!" jumlah <= 0 -> "❌ Jumlah setor harus lebih dari 0!" else -> { saldo += jumlah "✅ Berhasil setor Rp${String.format("%,.0f", jumlah)}. Saldo: Rp${String.format("%,.0f", saldo)}" } } } fun tarik(jumlah: Double, pinInput: String): String { return when { pinInput != pin -> "❌ PIN salah!" jumlah <= 0 -> "❌ Jumlah tarik harus lebih dari 0!" jumlah > saldo -> "❌ Saldo tidak mencukupi!" else -> { saldo -= jumlah "✅ Berhasil tarik Rp${String.format("%,.0f", jumlah)}. Saldo: Rp${String.format("%,.0f", saldo)}" } } } }

🎯 Poin Penting Encapsulation

  • private = hanya dalam class itu sendiri
  • public = bisa diakses dari mana saja (default)
  • Encapsulation melindungi data dari perubahan yang tidak diinginkan
  • Memberikan interface yang aman untuk berinteraksi dengan object

🎭 Polymorphism - Satu Interface, Banyak Bentuk

🎪 Apa itu Polymorphism?

Polymorphism berarti "banyak bentuk". Ini memungkinkan object yang berbeda merespons method yang sama dengan cara yang berbeda. Seperti remote TV - tombol "play" bisa memutar film, musik, atau game tergantung perangkatnya! 📺🎮🎵

🎨 Contoh: Sistem Gambar

// Parent class dengan method yang akan di-override open class Bentuk { open fun gambar() { println("🎨 Menggambar bentuk umum") } open fun hitungLuas(): Double { return 0.0 } open fun hitungKeliling(): Double { return 0.0 } } // Child classes dengan implementasi berbeda class Lingkaran(private val radius: Double) : Bentuk() { override fun gambar() { println("⭕ Menggambar lingkaran dengan radius $radius cm") } override fun hitungLuas(): Double { return 3.14159 * radius * radius } override fun hitungKeliling(): Double { return 2 * 3.14159 * radius } } class Persegi(private val sisi: Double) : Bentuk() { override fun gambar() { println("⬜ Menggambar persegi dengan sisi $sisi cm") } override fun hitungLuas(): Double { return sisi * sisi } override fun hitungKeliling(): Double { return 4 * sisi } } class Segitiga(private val alas: Double, private val tinggi: Double) : Bentuk() { override fun gambar() { println("🔺 Menggambar segitiga dengan alas $alas cm dan tinggi $tinggi cm") } override fun hitungLuas(): Double { return 0.5 * alas * tinggi } override fun hitungKeliling(): Double { // Asumsi segitiga sama sisi untuk kemudahan return 3 * alas } } // Fungsi yang menggunakan polymorphism fun prosesGambar(bentuk: Bentuk) { bentuk.gambar() println("📏 Luas: ${String.format("%.2f", bentuk.hitungLuas())} cm²") println("📐 Keliling: ${String.format("%.2f", bentuk.hitungKeliling())} cm") println("---") } // Penggunaan polymorphism - satu fungsi untuk berbagai bentuk val bentukList = listOf( Lingkaran(5.0), Persegi(4.0), Segitiga(6.0, 8.0) ) println("🎨 Memproses berbagai bentuk:") bentukList.forEach { bentuk -> prosesGambar(bentuk) // Polymorphism in action! }

📱 Contoh Polymorphism dalam Android

// Contoh sederhana polymorphism dalam Android development open class View { open fun draw() { println("🎨 Menggambar view dasar") } open fun onClick() { println("👆 View diklik") } } class Button(private val text: String) : View() { override fun draw() { println("🔘 Menggambar button dengan text: '$text'") } override fun onClick() { println("🔘 Button '$text' ditekan!") } } class ImageView(private val imageName: String) : View() { override fun draw() { println("🖼️ Menggambar gambar: $imageName") } override fun onClick() { println("🖼️ Gambar $imageName diklik untuk zoom") } } // Fungsi yang menangani berbagai jenis View fun renderView(view: View) { view.draw() // Polymorphism - method yang dipanggil tergantung tipe object view.onClick() // Setiap view punya perilaku onClick yang berbeda } // Penggunaan dalam aplikasi Android val views = listOf( Button("Login"), Button("Register"), ImageView("profile.jpg") ) println("📱 Rendering UI components:") views.forEach { view -> renderView(view) // Satu fungsi untuk semua jenis view! println("---") }

🎯 Poin Penting Polymorphism

  • Method Overriding = child class mengubah implementasi method parent
  • Polymorphism memungkinkan kode yang fleksibel dan mudah diperluas
  • Satu interface, banyak implementasi berbeda
  • Membuat kode lebih modular dan mudah di-maintain
  • Runtime Polymorphism = method yang dipanggil ditentukan saat program berjalan
