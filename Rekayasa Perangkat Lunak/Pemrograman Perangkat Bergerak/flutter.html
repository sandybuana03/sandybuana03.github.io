Arsitektur Flutter

Bagaimana Flutter Bekerja di Balik Layar

🏢 Lapisan Arsitektur Flutter

🎨 Framework Layer (Dart)

Lapisan teratas tempat developer menulis kode. Berisi Material/Cupertino, Widget, Rendering, dan Animation API.

⚙️ Engine Layer (C++)

Inti Flutter yang menangani rendering (Skia), text layout, file I/O, accessibility, dan plugin architecture.

📱 Embedder Layer

Lapisan platform-specific yang mengintegrasikan Flutter dengan OS (Android, iOS, Windows, macOS, Linux, Web).

Widget Flutter

Blok Bangunan Aplikasi Flutter

🧩 Apa itu Widget?

Widget adalah blok bangunan dasar Flutter, seperti LEGO! Setiap elemen UI adalah widget - tombol, teks, gambar, bahkan layout dan padding. Widget mendeskripsikan bagaimana UI seharusnya terlihat.

"Everything is a Widget" - Widget adalah immutable description dari bagian UI!

📚 Jenis-jenis Widget

🏠 Stateless Widget

Widget yang tidak memiliki state internal yang berubah. Tampilannya hanya bergantung pada konfigurasi awal dan data dari parent.

Contoh: Text, Icon, Image, Container

🔄 Stateful Widget

Widget yang memiliki state internal yang bisa berubah selama lifetime widget. Bisa rebuild UI saat state berubah.

Contoh: TextField, Checkbox, Slider, AnimatedContainer

Bahasa Dart

Bahasa Pemrograman di Balik Flutter

💎 Apa itu Dart?

Dart adalah bahasa pemrograman yang dibuat Google pada 2011, awalnya untuk web development. Sekarang menjadi bahasa utama Flutter dengan sintaks yang mirip Java dan JavaScript!

🎯 Mudah Dipelajari

Sintaks familiar bagi programmer Java/JavaScript

⚡ Performa Tinggi

AOT compilation untuk production, JIT untuk development

🔒 Type Safe

Sound null safety mencegah runtime errors

🌐 Multi-Platform

Bisa compile ke ARM, x64, dan JavaScript

📝 Sintaks Dasar Dart

🔤 Variabel

String nama = 'Flutter';

int umur = 5;

bool isAwesome = true;

🔧 Fungsi

void sayHello() {

  print('Hello Flutter!');

}

🏗️ Class

class Student {

  String name;

  int age;

}
