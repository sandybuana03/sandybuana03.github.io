Praktik Integrasi API pada Android

Mari belajar cara mengintegrasikan API ke dalam aplikasi Android dengan mudah dan menyenangkan! 🚀

Apa itu API?

API (Application Programming Interface) adalah jembatan yang memungkinkan aplikasi Android kita berkomunikasi dengan server untuk mengambil atau mengirim data. Seperti pelayan di restoran yang mengantarkan pesanan kita ke dapur! 🍽️

Mengapa Penting?

Dengan API, aplikasi kita bisa menampilkan data real-time seperti cuaca, berita, atau media sosial. Aplikasi jadi lebih hidup dan berguna! ✨

Persiapan Project

Mari siapkan project Android kita untuk integrasi API! 🛠️

1

Buat Project Baru

Buka Android Studio dan buat project baru dengan konfigurasi berikut:

  • • Application Name: APILearning
  • • Language: Java atau Kotlin (pilih yang kamu kuasai)
  • • Minimum SDK: API 21 (Android 5.0)
  • • Template: Empty Activity
2

Tambahkan Dependencies

Buka file app/build.gradle dan tambahkan dependencies berikut:

app/build.gradle (Module: app)
// Di dalam dependencies block dependencies { // Dependencies yang sudah ada... // Retrofit untuk HTTP client implementation 'com.squareup.retrofit2:retrofit:2.9.0' implementation 'com.squareup.retrofit2:converter-gson:2.9.0' // OkHttp untuk logging (opsional, untuk debugging) implementation 'com.squareup.okhttp3:logging-interceptor:4.9.3' // RecyclerView untuk menampilkan list data implementation 'androidx.recyclerview:recyclerview:1.3.0' // CardView untuk tampilan yang cantik implementation 'androidx.cardview:cardview:1.0.0' }
3

Tambahkan Permission Internet

Buka file AndroidManifest.xml dan tambahkan permission:

app/src/main/AndroidManifest.xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android"> <!-- Tambahkan permission ini sebelum tag application --> <uses-permission android:name="android.permission.INTERNET" /> <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" /> <application android:usesCleartextTraffic="true" ... atribut lainnya ...> <!-- Activity dan komponen lainnya --> </application> </manifest>
4

Sync Project

Setelah menambahkan dependencies, klik tombol "Sync Now" yang muncul di bagian atas editor atau pilih menu File → Sync Project with Gradle Files.

Info:

Proses sync mungkin membutuhkan waktu beberapa menit tergantung koneksi internet kamu.

Setup Retrofit

Mari setup Retrofit sebagai HTTP client untuk komunikasi dengan API! 🔌

1

Buat Package untuk API

Buat struktur folder yang rapi untuk kode API kita:

  • • Klik kanan pada package utama (com.example.apilearning)
  • • Pilih New → Package
  • • Buat package: api
  • • Buat package: model
2

Buat ApiClient Class

Buat class ApiClient.java di package api:

api/ApiClient.java
package com.example.apilearning.api; import okhttp3.OkHttpClient; import okhttp3.logging.HttpLoggingInterceptor; import retrofit2.Retrofit; import retrofit2.converter.gson.GsonConverterFactory; public class ApiClient { // Base URL dari API yang akan kita gunakan private static final String BASE_URL = "https://jsonplaceholder.typicode.com/"; // Instance Retrofit yang akan digunakan private static Retrofit retrofit = null; // Method untuk mendapatkan instance Retrofit public static Retrofit getClient() { if (retrofit == null) { // Setup logging untuk debugging (opsional) HttpLoggingInterceptor logging = new HttpLoggingInterceptor(); logging.setLevel(HttpLoggingInterceptor.Level.BODY); // Setup OkHttp client OkHttpClient client = new OkHttpClient.Builder() .addInterceptor(logging) .build(); // Buat instance Retrofit retrofit = new Retrofit.Builder() .baseUrl(BASE_URL) .client(client) .addConverterFactory(GsonConverterFactory.create()) .build(); } return retrofit; } }

Penjelasan Kode

  • BASE_URL: Alamat dasar API yang akan kita gunakan
  • Singleton Pattern: Memastikan hanya ada satu instance Retrofit
  • HttpLoggingInterceptor: Untuk melihat request/response di log (debugging)
  • GsonConverterFactory: Mengubah JSON menjadi object Java secara otomatis
3

Test API yang Akan Digunakan

Kita akan menggunakan JSONPlaceholder sebagai API testing. Ini adalah API gratis yang menyediakan data dummy untuk belajar.

Endpoint yang akan kita gunakan:

  • • GET /posts - Mengambil semua post
  • • GET /posts/{id} - Mengambil post berdasarkan ID
  • • POST /posts - Membuat post baru

Membuat Model Data

Mari buat class model untuk menampung data dari API! 📦

1

Analisis Response API

Sebelum membuat model, mari lihat contoh response dari API JSONPlaceholder:

Contoh Response JSON dari /posts
[ { "userId": 1, "id": 1, "title": "sunt aut facere repellat provident", "body": "quia et suscipit\nsuscipit recusandae..." }, { "userId": 1, "id": 2, "title": "qui est esse", "body": "est rerum tempore vitae..." } ]
2

Buat Class Post Model

Buat class Post.java di package model:

model/Post.java
package com.example.apilearning.model; import com.google.gson.annotations.SerializedName; public class Post { // Annotation @SerializedName untuk mapping field JSON ke Java @SerializedName("userId") private int userId; @SerializedName("id") private int id; @SerializedName("title") private String title; @SerializedName("body") private String body; // Constructor kosong (diperlukan untuk Gson) public Post() { } // Constructor dengan parameter public Post(int userId, String title, String body) { this.userId = userId; this.title = title; this.body = body; } // Getter methods public int getUserId() { return userId; } public int getId() { return id; } public String getTitle() { return title; } public String getBody() { return body; } // Setter methods public void setUserId(int userId) { this.userId = userId; } public void setId(int id) { this.id = id; } public void setTitle(String title) { this.title = title; } public void setBody(String body) { this.body = body; } // Method toString untuk debugging @Override public String toString() { return "Post{" + "userId=" + userId + ", id=" + id + ", title='" + title + '\'' + ", body='" + body + '\'' + '}'; } }

Penjelasan Kode Model

  • @SerializedName: Menghubungkan field JSON dengan variable Java
  • Constructor kosong: Diperlukan oleh Gson untuk membuat object
  • Getter/Setter: Untuk mengakses dan mengubah data
  • toString(): Memudahkan debugging dengan menampilkan isi object
3

Tips Membuat Model yang Baik

✅ Yang Harus Dilakukan:

  • • Gunakan @SerializedName untuk mapping
  • • Buat constructor kosong
  • • Gunakan tipe data yang sesuai
  • • Buat getter dan setter

❌ Yang Harus Dihindari:

  • • Lupa constructor kosong
  • • Field private tanpa getter
  • • Nama field tidak sesuai JSON
  • • Tipe data yang salah

Membuat API Interface

Mari buat interface untuk mendefinisikan endpoint API! 🔗

1

Buat Interface ApiService

Buat interface ApiService.java di package api:

api/ApiService.java
package com.example.apilearning.api; import com.example.apilearning.model.Post; import java.util.List; import retrofit2.Call; import retrofit2.http.*; public interface ApiService { // GET request untuk mengambil semua posts @GET("posts") Call<List<Post>> getAllPosts(); // GET request untuk mengambil post berdasarkan ID @GET("posts/{id}") Call<Post> getPostById(@Path("id") int postId); // POST request untuk membuat post baru @POST("posts") Call<Post> createPost(@Body Post post); // PUT request untuk update post @PUT("posts/{id}") Call<Post> updatePost(@Path("id") int postId, @Body Post post); // DELETE request untuk menghapus post @DELETE("posts/{id}") Call<Void> deletePost(@Path("id") int postId); // GET request dengan query parameter @GET("posts") Call<List<Post>> getPostsByUserId(@Query("userId") int userId); }

Penjelasan Annotation HTTP

HTTP Methods:
  • @GET: Mengambil data
  • @POST: Mengirim data baru
  • @PUT: Update data
  • @DELETE: Hapus data
Parameter Types:
  • @Path: Parameter di URL
  • @Query: Query parameter (?key=value)
  • @Body: Data di request body
  • @Header: HTTP header
2

Contoh Penggunaan Annotation

Mari lihat contoh bagaimana annotation bekerja:

@Path Example:

@GET("posts/{id}") Call<Post> getPost(@Path("id") int id); // Memanggil: posts/123

@Query Example:

@GET("posts") Call<List<Post>> getPosts(@Query("userId") int userId); // Memanggil: posts?userId=1
3

Buat Helper Class untuk API Service

Buat class helper untuk memudahkan akses ke API service:

api/ApiHelper.java
package com.example.apilearning.api; public class ApiHelper { // Instance ApiService yang akan digunakan private static ApiService apiService; // Method untuk mendapatkan instance ApiService public static ApiService getApiService() { if (apiService == null) { apiService = ApiClient.getClient().create(ApiService.class); } return apiService; } }

Keuntungan Menggunakan Interface

  • • Clean Code: Kode lebih rapi dan terorganisir
  • • Type Safety: Retrofit akan generate implementasi otomatis
  • • Easy Testing: Mudah untuk membuat mock implementation
  • • Maintainable: Mudah menambah atau mengubah endpoint

Buat Adapter untuk RecyclerView

Buat class PostAdapter.java:

PostAdapter.java
package com.example.apilearning; import android.view.LayoutInflater; import android.view.View; import android.view.ViewGroup; import android.widget.TextView; import androidx.annotation.NonNull; import androidx.recyclerview.widget.RecyclerView; import com.example.apilearning.model.Post; import java.util.List; public class PostAdapter extends RecyclerView.Adapter<PostAdapter.PostViewHolder> { private List<Post> posts; public PostAdapter(List<Post> posts) { this.posts = posts; } @NonNull @Override public PostViewHolder onCreateViewHolder(@NonNull ViewGroup parent, int viewType) { View view = LayoutInflater.from(parent.getContext()) .inflate(R.layout.item_post, parent, false); return new PostViewHolder(view); } @Override public void onBindViewHolder(@NonNull PostViewHolder holder, int position) { Post post = posts.get(position); holder.bind(post); } @Override public int getItemCount() { return posts != null ? posts.size() : 0; } // Method untuk update data public void updatePosts(List<Post> newPosts) { this.posts = newPosts; notifyDataSetChanged(); } // ViewHolder class public static class PostViewHolder extends RecyclerView.ViewHolder { private TextView tvPostId, tvTitle, tvBody; public PostViewHolder(@NonNull View itemView) { super(itemView); tvPostId = itemView.findViewById(R.id.tvPostId); tvTitle = itemView.findViewById(R.id.tvTitle); tvBody = itemView.findViewById(R.id.tvBody); } public void bind(Post post) { tvPostId.setText("Post #" + post.getId()); tvTitle.setText(post.getTitle()); tvBody.setText(post.getBody()); } } }

Testing & Debug

Mari test aplikasi kita dan pelajari cara debugging! 🧪

1

Implementasi MainActivity

Update MainActivity.java dengan implementasi lengkap:

MainActivity.java
package com.example.apilearning; import android.os.Bundle; import android.util.Log; import android.view.View; import android.widget.Button; import android.widget.ProgressBar; import android.widget.Toast; import androidx.appcompat.app.AppCompatActivity; import androidx.recyclerview.widget.LinearLayoutManager; import androidx.recyclerview.widget.RecyclerView; import com.example.apilearning.api.ApiHelper; import com.example.apilearning.model.Post; import java.util.ArrayList; import java.util.List; import retrofit2.Call; import retrofit2.Callback; import retrofit2.Response; public class MainActivity extends AppCompatActivity { private static final String TAG = "MainActivity"; // UI Components private Button btnGetPosts, btnCreatePost; private ProgressBar progressBar; private RecyclerView recyclerView; private PostAdapter adapter; private List<Post> postList; @Override protected void onCreate(Bundle savedInstanceState) { super.onCreate(savedInstanceState); setContentView(R.layout.activity_main); // Initialize UI initViews(); setupRecyclerView(); setupClickListeners(); } private void initViews() { btnGetPosts = findViewById(R.id.btnGetPosts); btnCreatePost = findViewById(R.id.btnCreatePost); progressBar = findViewById(R.id.progressBar); recyclerView = findViewById(R.id.recyclerView); } private void setupRecyclerView() { postList = new ArrayList<>(); adapter = new PostAdapter(postList); recyclerView.setLayoutManager(new LinearLayoutManager(this)); recyclerView.setAdapter(adapter); } private void setupClickListeners() { btnGetPosts.setOnClickListener(new View.OnClickListener() { @Override public void onClick(View v) { getAllPosts(); } }); btnCreatePost.setOnClickListener(new View.OnClickListener() { @Override public void onClick(View v) { createNewPost(); } }); } private void getAllPosts() { // Show loading showLoading(true); // Make API call Call<List<Post>> call = ApiHelper.getApiService().getAllPosts(); call.enqueue(new Callback<List<Post>>() { @Override public void onResponse(Call<List<Post>> call, Response<List<Post>> response) { showLoading(false); if (response.isSuccessful() && response.body() != null) { List<Post> posts = response.body(); Log.d(TAG, "Posts loaded: " + posts.size()); // Update RecyclerView adapter.updatePosts(posts); // Show success message Toast.makeText(MainActivity.this, "Loaded " + posts.size() + " posts", Toast.LENGTH_SHORT).show(); } else { Log.e(TAG, "Response not successful: " + response.code()); showError("Failed to load posts"); } } @Override public void onFailure(Call<List<Post>> call, Throwable t) { showLoading(false); Log.e(TAG, "API call failed", t); showError("Network error: " + t.getMessage()); } }); } private void createNewPost() { // Create new post object Post newPost = new Post(1, "My New Post", "This is a test post created from Android app!"); showLoading(true); Call<Post> call = ApiHelper.getApiService().createPost(newPost); call.enqueue(new Callback<Post>() { @Override public void onResponse(Call<Post> call, Response<Post> response) { showLoading(false); if (response.isSuccessful() && response.body() != null) { Post createdPost = response.body(); Log.d(TAG, "Post created: " + createdPost.toString()); Toast.makeText(MainActivity.this, "Post created successfully!", Toast.LENGTH_SHORT).show(); } else { showError("Failed to create post"); } } @Override public void onFailure(Call<Post> call, Throwable t) { showLoading(false); Log.e(TAG, "Create post failed", t); showError("Network error: " + t.getMessage()); } }); } private void showLoading(boolean show) { progressBar.setVisibility(show ? View.VISIBLE : View.GONE); btnGetPosts.setEnabled(!show); btnCreatePost.setEnabled(!show); } private void showError(String message) { Toast.makeText(this, message, Toast.LENGTH_LONG).show(); } }

Tips Debugging

  • • Logcat: Gunakan Log.d(), Log.e() untuk melihat output di Logcat
  • • Network Inspector: Gunakan untuk melihat request/response HTTP
  • • Breakpoints: Set breakpoint di onResponse() dan onFailure()
  • • Toast Messages: Tampilkan pesan error yang user-friendly
2
