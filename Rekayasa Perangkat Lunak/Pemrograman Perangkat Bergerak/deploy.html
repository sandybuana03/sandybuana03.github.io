Pengenalan Deployment Aplikasi

🔍 Apa itu Deployment?

Deployment adalah proses mengunggah dan mempublikasikan aplikasi yang sudah selesai dibuat ke platform distribusi seperti App Store (iOS) atau Play Store (Android) agar bisa diunduh dan digunakan oleh pengguna.

💡 Analogi: Seperti menerbitkan buku - setelah menulis, kamu perlu mengirimnya ke penerbit agar bisa dijual di toko buku!

🍎 App Store (iOS)

  • • Platform resmi Apple
  • • Review ketat dari Apple
  • • Biaya developer $99/tahun
  • • Proses review 24-48 jam

🤖 Play Store (Android)

  • • Platform resmi Google
  • • Review otomatis + manual
  • • Biaya sekali $25
  • • Proses review 1-3 hari (bisa hingga 7 hari)

Deploy ke App Store (iOS)

📋 Persyaratan App Store

Developer Account
  • • Apple Developer Program ($99/tahun)
  • • Verifikasi identitas
  • • Akses ke development tools
Technical Requirements
  • • Xcode untuk build
  • • iOS SDK terbaru
  • • Code signing certificate

🔄 Langkah-langkah Deploy

1
Persiapan di Xcode

Build aplikasi, set bundle identifier, dan konfigurasi signing

2
App Store Connect

Buat app record, upload metadata, dan asset visual

3
Upload Binary

Archive dan upload aplikasi menggunakan Xcode atau Transporter

4
Submit for Review

Submit aplikasi untuk review Apple (1-7 hari)

⚠️ App Store Guidelines

Yang Harus Dihindari
  • • Konten tidak pantas
  • • Crash atau bug
  • • Plagiarisme design
  • • Metadata menyesatkan
Best Practices
  • • UI konsisten dengan iOS
  • • Performance optimal
  • • Privacy compliance
  • • Accessibility support

Deploy ke Play Store (Android)

📋 Persyaratan Play Store

Developer Account
  • • Google Play Console ($25 sekali)
  • • Verifikasi identitas
  • • Merchant account (untuk paid apps)
Technical Requirements
  • • Android Studio
  • • Signed APK/AAB
  • • Target SDK terbaru

🔄 Langkah-langkah Deploy

1
Generate Signed Bundle

Build signed APK/AAB menggunakan Android Studio

2
Play Console Setup

Buat aplikasi baru di Google Play Console

3
Upload & Configure

Upload APK/AAB, set metadata, dan konfigurasi store listing

4
Review & Publish

Submit untuk review dan publish (1-3 hari)

📱 Format File & Requirements

APK vs AAB
APK (Android Package)

File tradisional, ukuran lebih besar

AAB (Android App Bundle)

Format baru, optimasi otomatis

Size Limits
  • • APK: maksimal 100MB
  • • AAB: maksimal 150MB
  • • Expansion files: hingga 2GB
  • • Instant apps: maksimal 15MB

Optimasi & App Store Optimization (ASO)

🔍 Apa itu ASO?

App Store Optimization (ASO) adalah proses mengoptimalkan aplikasi mobile untuk mendapat ranking lebih tinggi di hasil pencarian app store. Seperti SEO untuk website, tapi khusus untuk aplikasi mobile.

📈
Visibility

Lebih mudah ditemukan

⬇️
Downloads

Meningkatkan unduhan

💰
Revenue

Potensi pendapatan lebih

🎯 Elemen Penting ASO

📝 App Title & Keywords
  • • Judul yang menarik dan deskriptif
  • • Keyword yang relevan
  • • Hindari keyword stuffing
📱 Screenshots & Videos
  • • Screenshot berkualitas tinggi
  • • Tunjukkan fitur utama
  • • Video preview menarik
⭐ Ratings & Reviews
  • • Encourage positive reviews
  • • Respond to user feedback
  • • Fix issues quickly
🎨 App Icon & Design
  • • Icon yang eye-catching
  • • Konsisten dengan brand
  • • Stand out dari kompetitor

Tugas Pembelajaran

Kerjakan tugas berikut untuk menguji pemahaman kamu!

1️⃣ Analisis Persiapan Deploy

Buatlah checklist lengkap untuk mempersiapkan aplikasi sebelum deploy ke App Store dan Play Store. Jelaskan mengapa setiap item penting!

2️⃣ Perbandingan Platform

Bandingkan proses deployment di App Store vs Play Store. Sebutkan minimal 5 perbedaan utama dan jelaskan kelebihan masing-masing platform!

3️⃣ Strategi ASO

Bayangkan kamu membuat aplikasi game puzzle. Buatlah strategi ASO lengkap termasuk: judul aplikasi, keywords, deskripsi singkat, dan ide untuk screenshot yang menarik!

4️⃣ Problem Solving

Aplikasi kamu ditolak saat review dengan alasan "crash saat startup". Jelaskan langkah-langkah yang akan kamu lakukan untuk mengatasi masalah ini dan mencegahnya terjadi lagi!

5️⃣ Rencana Deployment

Buatlah timeline deployment untuk aplikasi mobile dari tahap development selesai hingga live di store. Sertakan estimasi waktu dan milestone penting!
