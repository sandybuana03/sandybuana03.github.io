🔐 Multi-Factor Authentication (MFA)

Apa itu MFA?

Sistem keamanan berlapis yang membutuhkan 2 atau lebih faktor verifikasi:

🧠 Something you know - Password

📱 Something you have - Phone/Token

👤 Something you are - Biometric

Implementasi MFA

1️⃣ Login dengan password
2️⃣ Verifikasi SMS/Email OTP
3️⃣ Konfirmasi biometric (opsional)

Catatan: MFA wajib untuk aplikasi finansial dan data sensitif

🎯 Studi Kasus: Aplikasi Banking

Skenario: Mobile Banking BCA

📱
Step 1: Login

User ID + PIN 6 digit

📲
Step 2: OTP

SMS verification code

👆
Step 3: Biometric

Fingerprint untuk transaksi

Mengapa 3 layer? Jika password bocor, masih ada SMS OTP. Jika HP hilang, masih butuh biometric.

🏗️ RBAC (Role-Based Access Control)

Konsep RBAC

Sistem otorisasi berdasarkan peran (role) pengguna dalam organisasi. Setiap role memiliki kumpulan permission yang spesifik, sehingga mudah dikelola dan aman.

👤
User

Individu yang menggunakan sistem

🎭
Role

Kumpulan permission yang terkait

🔑
Permission

Hak akses spesifik ke resource

Contoh Implementasi E-Commerce

👑
Super Admin

Kelola user, produk, order, laporan

Full Access
🛍️
Store Manager

Kelola produk, stok, promo

Limited Access
🛒
Customer

Browse, beli, review produk

Basic Access

⚖️ Permission vs Intent di Android

🔐 Dangerous Permissions

Memerlukan persetujuan eksplisit pengguna:

⚠️ CAMERA, MICROPHONE
⚠️ LOCATION, CONTACTS
⚠️ READ_SMS, CALL_PHONE, WRITE_EXTERNAL_STORAGE

✅ Normal Permissions

Otomatis diberikan sistem:

✅ INTERNET, WIFI_STATE
✅ VIBRATE, FLASHLIGHT
✅ BLUETOOTH, NFC

📚 Tools & Library Populer

🔥 Firebase Auth

Solusi autentikasi lengkap dari Google dengan berbagai provider login (Google, Facebook, Email/Password, Phone)

🔐 Retrofit + JWT

Kombinasi untuk API calls dengan JSON Web Token authentication - standar industri untuk REST API

👆 BiometricPrompt

API Android untuk autentikasi biometrik (sidik jari, wajah, iris) - tersedia mulai Android 6.0+

🗄️ Room Database

Penyimpanan lokal yang aman untuk data pengguna dengan enkripsi SQLCipher untuk data sensitif

Keamanan & Best Practices

Implementasi praktis untuk menjaga keamanan aplikasi Android

⚠️ Ancaman Keamanan Umum

🎣 Phishing

Aplikasi palsu yang meniru aplikasi asli untuk mencuri data login

🕳️ SQL Injection

Serangan melalui input yang tidak divalidasi dengan baik

👨‍💻 Man in the Middle

Intersepsi komunikasi antara aplikasi dan server

📱 Malware

Aplikasi berbahaya yang dapat mengakses data tanpa izin

🛡️ Strategi Perlindungan

🔐

Enkripsi Data

Selalu enkripsi data sensitif sebelum disimpan atau dikirim

Contoh: Gunakan AES untuk enkripsi lokal, TLS untuk komunikasi

🔍

Input Validation

Validasi semua input dari pengguna untuk mencegah serangan injection

Contoh: Sanitasi input, gunakan prepared statements

🕐

Session Management

Kelola sesi pengguna dengan timeout dan refresh token

Contoh: Auto-logout setelah 30 menit tidak aktif

// Auto logout setelah 30 menit tidak aktif
public class SessionManager {
    private static final long SESSION_TIMEOUT = 30 * 60 * 1000; // 30 menit
    private long lastActivity;
    public void updateActivity() {
        lastActivity = System.currentTimeMillis();
    }
    private void checkSessionTimeout() {
        if (System.currentTimeMillis() - lastActivity > SESSION_TIMEOUT) {
            logout();
        }
    }

Implementasi session timeout untuk logout otomatis jika pengguna tidak aktif dalam periode tertentu. Penting untuk keamanan aplikasi banking dan e-commerce.

🔧 Tools Keamanan Android

🛡️ ProGuard/R8

Code obfuscation untuk menyembunyikan logika aplikasi dari reverse engineering.

Fungsi: Minifikasi, obfuskasi, optimasi kode

🔐 Android Keystore

Sistem penyimpanan kunci kriptografi yang aman di level hardware (TEE/SE).

Kegunaan: Simpan private keys, sertifikat, kunci enkripsi dengan perlindungan hardware

🔍 OWASP ZAP

Tool untuk testing keamanan aplikasi dan menemukan vulnerability.

Fitur: Penetration testing, security scanning

📱 App Bundle

Format distribusi yang lebih aman dengan signing key yang terpisah.

Benefit: Play App Signing, ukuran APK lebih kecil
