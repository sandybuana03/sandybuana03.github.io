Pengenalan Android Studio & Kotlin

🤖 Apa itu Android Studio?

Android Studio adalah IDE (Integrated Development Environment) resmi yang dibuat oleh Google khusus untuk mengembangkan aplikasi Android.

Fitur Utama:

  • • Editor kode yang canggih
  • • Emulator Android terintegrasi
  • • Debugging tools yang powerful
  • • Layout editor visual

🔤 Apa itu Kotlin?

Kotlin adalah bahasa pemrograman modern yang dikembangkan oleh JetBrains dan menjadi bahasa resmi untuk pengembangan Android sejak 2017.

Keunggulan Kotlin:

  • • Sintaks yang sederhana dan mudah dipahami
  • • 100% kompatibel dengan Java
  • • Null safety (aman dari error null)
  • • Lebih ringkas dari Java

Instalasi Android Studio

Mari install Android Studio step by step!

📥 Step 1: Download Android Studio

1. Buka browser dan kunjungi: developer.android.com/studio

2. Klik tombol "Download Android Studio"

3. Pilih versi sesuai sistem operasi kamu (Windows/Mac/Linux)

💡 Tips: Pastikan koneksi internet stabil karena file berukuran sekitar 1GB!

⚙️ Step 2: Instalasi

Windows:

  1. 1. Double-click file .exe
  2. 2. Ikuti wizard instalasi
  3. 3. Pilih "Standard" setup
  4. 4. Tunggu proses selesai

Mac:

  1. 1. Buka file .dmg
  2. 2. Drag ke Applications
  3. 3. Buka dari Launchpad
  4. 4. Ikuti setup wizard

🎯 Step 3: Setup Awal

Saat pertama kali membuka Android Studio:

  1. 1. Pilih "Do not import settings" (untuk pengguna baru)
  2. 2. Klik "Next" pada welcome screen
  3. 3. Pilih "Standard" install type
  4. 4. Pilih tema UI (Light/Dark) sesuai selera
  5. 5. Klik "Finish" dan tunggu download SDK

Dasar-dasar Kotlin

Mari belajar sintaks dasar Kotlin yang mudah!

📝 Variabel dan Tipe Data

// Variabel yang bisa diubah (mutable)
var nama = "Budi"
var umur: Int = 17
var tinggi: Double = 165.5

// Variabel yang tidak bisa diubah (immutable)
val sekolah = "SMK Negeri 1"
val PI = 3.14159

💡 Tips: Gunakan val untuk nilai yang tidak berubah, var untuk nilai yang bisa berubah.

🔧 Function (Fungsi)

// Fungsi sederhana tanpa parameter
fun sapa() {
println("Halo, selamat belajar Android!")
}

// Fungsi dengan parameter dan return value
fun tambah(a: Int, b: Int): Int {
return a + b
}

// Fungsi dengan expression body
fun kali(x: Int, y: Int) = x * y

🎯 Tipe Data Kotlin

Tipe Data Angka:

Int = 42
Double = 3.14
Float = 2.5f
Long = 1000L

Tipe Data Lainnya:

String = "Hello"
Boolean = true
Char = 'A'

🔄 Control Flow

// If-else statement
val nilai = 85
if (nilai >= 80) {
println("Nilai A")
} else {
println("Nilai B")
}

// For loop
for (i in 1..5) {
println("Angka: $i")
}

Konfigurasi Project Android

Pelajari cara mengatur project Android dengan benar!

📄 File build.gradle (Module: app)

android {
compileSdk 34
defaultConfig {
minSdk 24
targetSdk 34
versionCode 1
versionName "1.0"
}
}

💡 Penjelasan: compileSdk = versi SDK untuk kompilasi, minSdk = versi Android minimum, targetSdk = versi yang ditargetkan

📦 Dependencies (Library)

dependencies {
implementation 'androidx.core:core-ktx:1.12.0'
implementation 'androidx.appcompat:appcompat:1.6.1'
implementation 'com.google.android.material:material:1.11.0'
implementation 'androidx.constraintlayout:constraintlayout:2.1.4'
}

Library Utama:

  • • core-ktx: Ekstensi Kotlin untuk Android
  • • appcompat: Kompatibilitas dengan versi lama
  • • material: Material Design components

Layout & UI:

  • • constraintlayout: Layout yang fleksibel
  • • recyclerview: Untuk list data
  • • cardview: Untuk tampilan card

📁 Struktur Project Android

📁 app/
├── 📁 src/
│ ├── 📁 main/
│ │ ├── 📁 java/com/example/myapp/
│ │ │ └── 📄 MainActivity.kt
│ │ ├── 📁 res/
│ │ │ ├── 📁 layout/
│ │ │ │ └── 📄 activity_main.xml
│ │ │ ├── 📁 values/
│ │ │ │ ├── 📄 strings.xml
│ │ │ │ └── 📄 colors.xml
│ │ │ └── 📁 drawable/
│ │ └── 📄 AndroidManifest.xml
└── 📄 build.gradle

🔧 AndroidManifest.xml

File konfigurasi utama yang berisi:

  • • Package name: Identitas unik aplikasi
  • • Permissions: Izin yang dibutuhkan app
  • • Activities: Daftar semua Activity
  • • App icon & label: Icon dan nama aplikasi

Menggunakan Emulator Android

Belajar menjalankan aplikasi di emulator virtual!

🚀 Membuat AVD (Android Virtual Device)

  1. 1. Buka AVD Manager: Tools → AVD Manager atau klik icon 📱 di toolbar
  2. 2. Create Virtual Device: Klik tombol "Create Virtual Device"
  3. 3. Pilih Hardware: Pilih device (rekomendasi: Pixel 7 atau Pixel 4)
  4. 4. Pilih System Image: Download dan pilih Android API 34 (Android 14)
  5. 5. Verify Configuration: Beri nama AVD dan klik "Finish"

💡 Tips: Pilih system image dengan Google APIs untuk akses Google Play Store di emulator

▶️ Menjalankan Aplikasi di Emulator

Cara 1: Run dari Android Studio

  1. 1. Klik tombol ▶️ Run (atau Shift+F10)
  2. 2. Pilih emulator dari dropdown
  3. 3. Tunggu build selesai
  4. 4. App otomatis terbuka di emulator

Cara 2: Start Emulator Dulu

  1. 1. Buka AVD Manager
  2. 2. Klik ▶️ pada AVD yang diinginkan
  3. 3. Tunggu emulator boot up
  4. 4. Run aplikasi dari Android Studio

🎮 Kontrol Emulator

Kontrol Dasar:

  • • Click: Tap layar
  • • Drag: Swipe gesture
  • • Scroll: Mouse wheel
  • • Back: Tombol Back di panel
  • • Home: Tombol Home di panel

Fitur Lanjutan:

  • • Rotate: Ctrl+F11/F12
  • • Volume: Panel kontrol samping
  • • Screenshot: Ctrl+S
  • • Location: Extended controls (...)

🔧 Troubleshooting Emulator

Emulator Lambat?

Enable Hardware Acceleration (HAXM/Hyper-V) di BIOS

Emulator Tidak Muncul?

Cek Windows Defender, restart Android Studio

App Tidak Terinstall?

Clean Project (Build → Clean Project) lalu rebuild

📱 Alternatif: Device Fisik

Jika emulator terlalu lambat, gunakan device Android fisik:

  1. 1. Enable Developer Options: Settings → About Phone → tap Build Number 7x
  2. 2. Enable USB Debugging: Developer Options → USB Debugging
  3. 3. Connect via USB: Hubungkan phone ke komputer
  4. 4. Allow Debugging: Accept prompt di phone
  5. 5. Run App: Pilih device di Android Studio
