🤖 Apa itu Android SDK?

Android SDK (Software Development Kit) adalah kumpulan tools, library, dokumentasi, dan contoh kode yang dibutuhkan untuk membuat aplikasi Android.

Analogi Sederhana:

SDK seperti "dapur lengkap" untuk memasak aplikasi Android. Ada kompor (tools), bumbu (library), buku resep (dokumentasi), dan contoh masakan (sample code)! 👨‍🍳

Instalasi & Setup

💻 System Requirements

🖥️ Windows

  • • Windows 10/11 (64-bit)
  • • RAM minimum 8GB (16GB direkomendasikan)
  • • Storage 8GB+ tersedia
  • • Resolusi 1280x800 minimum
  • • JDK 8 atau yang lebih baru

🍎 macOS

  • • macOS 10.15+ (64-bit)
  • • RAM minimum 8GB (16GB direkomendasikan)
  • • Storage 8GB+ tersedia
  • • Resolusi 1280x800 minimum
  • • JDK 8 atau yang lebih baru

🐧 Linux

  • • Ubuntu 18.04+ atau distro setara
  • • RAM minimum 8GB (16GB direkomendasikan)
  • • Storage 8GB+ tersedia
  • • Resolusi 1280x800 minimum
  • • JDK 8 atau yang lebih baru

📁 Struktur Folder Utama

Project Structure
MyFirstApp/
├── 📁 app/
│   ├── 📁 src/
│   │   ├── 📁 main/
│   │   │   ├── 📁 java/          # Kode Java/Kotlin
│   │   │   ├── 📁 res/           # Resources (layout, gambar, dll)
│   │   │   └── 📄 AndroidManifest.xml
│   │   └── 📁 test/              # Unit tests
│   └── 📄 build.gradle           # Konfigurasi build
├── 📁 gradle/                    # Gradle wrapper
└── 📄 settings.gradle            # Pengaturan proyek

📂 Folder Resources (res/)

🎨 layout/

File XML untuk tampilan UI (activity_main.xml)

🖼️ drawable/

Gambar, icon, dan drawable resources

📝 values/

String, color, dimension, dan style

🌐 mipmap/

Icon aplikasi untuk berbagai resolusi

📋 AndroidManifest.xml

File penting yang berisi informasi tentang aplikasi seperti nama, permission, dan activity yang ada.

AndroidManifest.xml
<?xml version="1.0" encoding="utf-8"?>
<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    
    <application
        android:allowBackup="true"
        android:icon="@mipmap/ic_launcher"
        android:label="@string/app_name"
        android:theme="@style/AppTheme">
        
        <activity android:name=".MainActivity">
            <intent-filter>
                <action android:name="android.intent.action.MAIN" />
                <category android:name="android.intent.category.LAUNCHER" />
            </intent-filter>
        </activity>
        
    </application>
</manifest>

Layout mendefinisikan tampilan UI menggunakan file XML. Seperti blueprint rumah! 🏠

<androidx.constraintlayout.widget.ConstraintLayout
    xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:app="http://schemas.android.com/apk/res-auto"
    xmlns:tools="http://schemas.android.com/tools"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:padding="16dp"
    tools:context=".MainActivity">

        android:id="@+id/textView"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="Hello World!"
        android:textSize="24sp"
        android:textStyle="bold"
        app:layout_constraintTop_toTopOf="parent"
        app:layout_constraintStart_toStartOf="parent"
        app:layout_constraintEnd_toEndOf="parent"
        android:layout_marginTop="100dp" />

    <Button
        android:id="@+id/button"
        android:layout_width="0dp"
        android:layout_height="wrap_content"
        android:text="Click Me!"
        android:layout_marginTop="32dp"
        app:layout_constraintTop_toBottomOf="@+id/textView"
        app:layout_constraintStart_toStartOf="parent"
        app:layout_constraintEnd_toEndOf="parent" />

</androidx.constraintlayout.widget.ConstraintLayout>

🔗 Menghubungkan Activity & Layout

📌 Cara Tradisional (findViewById)

MainActivity.java (Traditional)
public class MainActivity extends AppCompatActivity {
    
    private TextView textView;
    private Button button;
    
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        
        // Menghubungkan dengan layout XML
        setContentView(R.layout.activity_main);
        
        // Inisialisasi UI components
        initViews();
        
        // Setup event listeners
        setupListeners();
    }
    
    private void initViews() {
        textView = findViewById(R.id.textView);
        button = findViewById(R.id.button);
    }
    
    private void setupListeners() {
        // Menggunakan lambda expression (Java 8+)
        button.setOnClickListener(v -> {
            textView.setText("Button diklik!");
            // Tambahkan animasi sederhana
            textView.animate().scaleX(1.1f).scaleY(1.1f)
                    .setDuration(200)
                    .withEndAction(() -> {
                        textView.animate().scaleX(1f).scaleY(1f).setDuration(200);
                    });
        });
    }
}

🚀 Cara Modern (View Binding)

Lebih aman dan efisien - direkomendasikan untuk proyek baru!

MainActivity.java (Modern View Binding)
public class MainActivity extends AppCompatActivity {
    
    private ActivityMainBinding binding;
    
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        
        // Menggunakan View Binding
        binding = ActivityMainBinding.inflate(getLayoutInflater());
        setContentView(binding.getRoot());
        
        // Setup listeners langsung dari binding
        binding.button.setOnClickListener(v -> {
            binding.textView.setText("Button diklik dengan View Binding!");
        });
    }
    
    @Override
    protected void onDestroy() {
        super.onDestroy();
        binding = null; // Hindari memory leak
    }
}

Tugas Pembelajaran

Uji pemahaman Anda tentang Android SDK

1️⃣ Analisis Struktur Proyek

Jelaskan fungsi dari masing-masing folder berikut dalam struktur proyek Android:

  • a) Folder app/src/main/java/
  • b) Folder app/src/main/res/layout/
  • c) File AndroidManifest.xml
  • d) File build.gradle

2️⃣ Lifecycle Activity

Urutkan lifecycle method Activity dari awal dibuat hingga dihancurkan, dan jelaskan kapan masing-masing method dipanggil!

Hint: Ada 6 method utama: onCreate(), onStart(), onResume(), onPause(), onStop(), onDestroy()

3️⃣ Desain Layout Sederhana

Buatlah rancangan layout XML untuk aplikasi "Biodata Siswa" yang berisi:

  • • TextView untuk judul "Biodata Siswa"
  • • EditText untuk input nama
  • • RadioButton untuk memilih jenis kelamin (Laki-laki/Perempuan)
  • • CheckBox untuk hobi (minimal 3 pilihan)
  • • Button untuk submit data

Catatan: Cukup tulis struktur XML-nya, tidak perlu kode Java/Kotlin

4️⃣ Perbedaan UI Components

Jelaskan perbedaan antara komponen UI berikut dan berikan contoh penggunaannya:

  • a) TextView vs EditText
  • b) CheckBox vs RadioButton
  • c) ListView vs RecyclerView
  • d) Button vs ImageButton

5️⃣ Studi Kasus

Anda diminta membuat aplikasi "Kalkulator Sederhana". Jelaskan:

  • a) UI Components apa saja yang dibutuhkan?
  • b) Layout apa yang cocok digunakan (LinearLayout/RelativeLayout)?
  • c) Method lifecycle mana yang tepat untuk inisialisasi UI?
  • d) Bagaimana cara menangani event click pada tombol angka?
