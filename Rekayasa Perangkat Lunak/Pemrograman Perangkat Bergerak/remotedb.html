Pengenalan Remote Database

🤷‍♂️ Apa itu Remote Database?

Remote Database adalah database (tempat penyimpanan data) yang berada di server jauh dan dapat diakses melalui internet. Bayangkan seperti lemari penyimpanan raksasa yang bisa kalian akses dari mana saja!

Contoh Sederhana:

Ketika kalian login Instagram, data username dan password kalian tidak disimpan di HP, tapi di server Instagram. Makanya kalian bisa login dari HP mana saja!

🆚 Local vs Remote Database

📱 Local Database

  • • Data disimpan di HP
  • • Akses cepat
  • • Tidak perlu internet
  • • Terbatas kapasitas HP

🌐 Remote Database

  • • Data disimpan di server
  • • Perlu internet
  • • Kapasitas besar
  • • Bisa diakses dari mana saja

✨ Keuntungan Remote Database

🔄 Data tersinkronisasi
👥 Multi-user access
💾 Backup otomatis
📈 Skalabilitas tinggi
🔒 Keamanan terpusat
⚡ Update real-time

Konsep Dasar Remote Database

🏗️ Arsitektur Client-Server

📱

CLIENT

Aplikasi Android

↔️

Internet

🖥️

SERVER

Database Server

Client (aplikasi Android) mengirim permintaan ke Server (database) melalui internet, kemudian server mengirim balasan kembali ke client.

🔄 Cara Kerja Remote Database

1️⃣

Request (Permintaan)

Aplikasi Android mengirim permintaan data

2️⃣

Processing (Pemrosesan)

Server memproses permintaan dan mengakses database

3️⃣

Response (Balasan)

Server mengirim data kembali ke aplikasi

4️⃣

Display (Tampilan)

Aplikasi menampilkan data ke pengguna

Teknologi Remote Database

🌐 Protokol Komunikasi

🔗 HTTP/HTTPS

Protokol standar untuk komunikasi web

  • • GET: Mengambil data
  • • POST: Mengirim data baru
  • • PUT: Update data
  • • DELETE: Hapus data

📡 WebSocket

Komunikasi real-time dua arah

  • • Chat aplikasi
  • • Live updates
  • • Gaming online
  • • Notifikasi real-time

📄 Format Data

📋 JSON (JavaScript Object Notation)

Format data paling populer untuk API modern

{
  "id": 1,
  "nama": "John Doe",
  "email": "john@example.com",
  "aktif": true
}

🏷️ XML (eXtensible Markup Language)

Format data dengan struktur tag

<user>
  <id>1</id>
  <nama>John Doe</nama>
  <email>john@example.com</email>
</user>

Implementasi di Android

📋 Langkah-langkah Implementasi

1️⃣

Setup Dependencies

Tambahkan library HTTP client ke build.gradle

2️⃣

Buat Model Data

Definisikan class untuk struktur data

3️⃣

Setup API Interface

Definisikan endpoint dan method HTTP

4️⃣

Implementasi Network Call

Buat fungsi untuk memanggil API

5️⃣

Handle Response

Proses data yang diterima dari server

💻 Contoh Implementasi Sederhana

📦 1. Dependencies (build.gradle)

implementation 'com.squareup.retrofit2:retrofit:2.9.0'
implementation 'com.squareup.retrofit2:converter-gson:2.9.0'

🏗️ 2. Model Data (User.java)

public class User {
    private int id;
    private String name;
    private String email;
    
    // Constructor, getter, setter
}

🌐 3. API Interface

public interface ApiService {
    @GET("users")
    Call<List<User>> getUsers();
    
    @POST("users")
    Call<User> createUser(@Body User user);
}

🎯 Best Practices

✅ Yang Harus Dilakukan

  • • Gunakan HTTPS untuk keamanan
  • • Implementasi error handling
  • • Tambahkan loading indicator
  • • Cache data untuk offline
  • • Validasi input data

❌ Yang Harus Dihindari

  • • Network call di Main Thread
  • • Hardcode URL di kode
  • • Tidak handle network error
  • • Kirim data sensitif tanpa enkripsi
  • • Tidak ada timeout setting

Keamanan Remote Database

⚠️ Ancaman Keamanan

🎯 Man-in-the-Middle Attack

Penyerang mencuri data saat transit

💉 SQL Injection

Penyerang memasukkan kode SQL berbahaya

🔓 Unauthorized Access

Akses tanpa izin ke data sensitif

📊 Data Breach

Kebocoran data pengguna

🛡️ Solusi Keamanan

🔐

HTTPS/SSL Encryption

Enkripsi data saat transit antara client dan server

🎫

Authentication & Authorization

Verifikasi identitas dan hak akses pengguna

🔑

API Key & Token

Kunci akses untuk mengidentifikasi aplikasi

✅

Input Validation

Validasi dan sanitasi semua input dari client

🔐 Implementasi Keamanan di Android

1. Network Security Config

<network-security-config>
    <domain-config cleartextTrafficPermitted="false">
        <domain includeSubdomains="true">api.example.com</domain>
    </domain-config>
</network-security-config>

2. Certificate Pinning

OkHttpClient client = new OkHttpClient.Builder()
    .certificatePinner(new CertificatePinner.Builder()
        .add("api.example.com", "sha256/AAAAAAA...")
        .build())
    .build();

3. Secure Storage

Simpan token/credential dengan aman:

  • • Android Keystore
  • • EncryptedSharedPreferences
  • • Biometric authentication
