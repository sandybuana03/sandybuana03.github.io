📖 Pengenalan Kotlin

🤖 Apa itu Kotlin?

Kotlin adalah bahasa pemrograman modern yang dikembangkan oleh JetBrains pada tahun 2011. Pada tahun 2017, Google mengumumkan Kotlin sebagai bahasa resmi untuk pengembangan Android! 🎉

🌟 Mengapa Kotlin Keren?

  • 📱 Official Android Language - Didukung penuh oleh Google
  • 🛡️ Null Safety - Mencegah NullPointerException yang sering terjadi
  • 🔄 Interoperable - Bisa bekerja sama dengan Java 100%
  • ✨ Concise - Kode lebih singkat dan mudah dibaca
  • 🚀 Modern - Fitur-fitur programming terkini

🏗️ Struktur Program Kotlin

Setiap program Kotlin dimulai dari fungsi main(). Mari lihat contohnya:

main.kt
1 fun main() {
2 println("Hello, Kotlin! 🎉")
3 println("Selamat datang di dunia Android!")
4 }

🎮 Demo Interaktif

Klik tombol di bawah untuk melihat output program Kotlin pertama!

📝 Aturan Penulisan Kotlin

  • 🔤 Case Sensitive - Hello berbeda dengan hello
  • 📏 Semicolon Optional - Tidak wajib pakai titik koma di akhir
  • 🏷️ Naming Convention - Gunakan camelCase untuk variabel dan fungsi
  • 📦 Package - Setiap file bisa punya package

📦 Variabel & Tipe Data

🏷️ Apa itu Variabel?

Variabel adalah tempat untuk menyimpan data dalam program. Bayangkan seperti kotak yang bisa kita beri label dan isi dengan berbagai macam barang! 📦

🔧 Cara Membuat Variabel

Di Kotlin, ada dua cara membuat variabel:

1. val - Immutable (Tidak bisa diubah)

variables.kt
1 val nama = "Budi"
2 val umur = 17
3 // nama = "Siti" // ❌ Error! val tidak bisa diubah

2. var - Mutable (Bisa diubah)

mutable.kt
1 var skor = 85
2 var level = "Beginner"
3 skor = 90 // ✅ OK! var bisa diubah
4 level = "Intermediate"

🔧 Apa itu Fungsi?

Fungsi adalah blok kode yang bisa digunakan berulang kali. Seperti mesin yang menerima input, memproses, dan menghasilkan output! 🏭

📝 Cara Membuat Fungsi

🔄 Kontrol Flow

🏗️ Object Oriented Programming Dasar

🎭 Apa itu OOP?

OOP adalah cara berpikir dalam programming dengan membuat "objek" yang memiliki sifat dan perilaku. Seperti dalam kehidupan nyata! 🌍

🏛️ Class dan Object

Class adalah blueprint/cetakan, sedangkan Object adalah hasil cetakannya:

📱 Contoh: Class Smartphone

Smartphone.kt
1 class Smartphone(
2 val merk: String,
3 val model: String,
4 var baterai: Int = 100
5 ) {
6 // Properties tambahan
7 var statusPower = true
8
9 // Methods (fungsi dalam class)
10 fun nyalakan() {
11 statusPower = true
12 println("📱 $merk $model menyala!")
13 }
14
15 fun matikan() {
16 statusPower = false
17 println("📱 $merk $model dimatikan!")
18 }
19
20 fun gunakanAplikasi(namaApp: String, waktu: Int) {
21 if (statusPower && baterai > 0) {
22 baterai -= waktu
23 println("🎮 Menggunakan $namaApp selama $waktu menit")
24 println("🔋 Baterai tersisa: $baterai%")
25 } else {
26 println("❌ HP mati atau baterai habis!")
27 }
28 }
29
30 fun chargeHP(durasi: Int) {
31 baterai = minOf(100, baterai + durasi * 10)
32 println("⚡ Charging... Baterai sekarang: $baterai%")
33 }
34 }

🎯 Membuat dan Menggunakan Object

usage.kt

🎨 Constructor dan Init

Constructor adalah fungsi khusus yang dipanggil saat object dibuat:

Siswa.kt
1 class Siswa(nama: String, kelas: String) {
2 val nama: String
3 val kelas: String
4 var nilai: MutableList<Int> = mutableListOf()
5
6 // Init block dijalankan saat object dibuat
7 init {
8 this.nama = nama.uppercase() // Nama selalu kapital
9 this.kelas = kelas
10 println("✅ Siswa $nama dari kelas $kelas berhasil didaftarkan!")
11 }
12
13 fun tambahNilai(nilai: Int) {
14 this.nilai.add(nilai)
15 println("📊 Nilai $nilai ditambahkan untuk $nama")
16 }
17
18 fun hitungRataRata(): Double {
19 return if (nilai.isNotEmpty()) {
20 nilai.average()
21 } else {
22 0.0
23 }
24 }
25 }

🔒 Visibility Modifiers

  • public - Bisa diakses dari mana saja (default)
  • private - Hanya bisa diakses dalam class yang sama
  • protected - Bisa diakses dalam class dan subclass
  • internal - Bisa diakses dalam module yang sama

📝 Tugas Praktik

Sekarang saatnya kalian menerapkan ilmu yang sudah dipelajari! Kerjakan tugas-tugas berikut dengan semangat! 💪

📦 Tugas 1: Variabel dan Tipe Data

Soal: Buatlah program yang menyimpan data diri kalian menggunakan berbagai tipe data yang sudah dipelajari!

Yang harus dibuat:

  • Variabel untuk nama (String)
  • Variabel untuk umur (Int)
  • Variabel untuk tinggi badan dalam meter (Double)
  • Variabel untuk status siswa aktif (Boolean)
  • Tampilkan semua data menggunakan string template

Contoh Output:
"Nama saya Andi, umur 17 tahun, tinggi 1.65 meter, dan saya adalah siswa aktif: true"

⚙️ Tugas 2: Fungsi

Soal: Buatlah fungsi kalkulator sederhana yang bisa melakukan operasi matematika dasar!

Yang harus dibuat:

  • Fungsi tambah(a: Int, b: Int): Int
  • Fungsi kurang(a: Int, b: Int): Int
  • Fungsi kali(a: Int, b: Int): Int
  • Fungsi bagi(a: Int, b: Int): Double
  • Fungsi main() yang menguji semua fungsi tersebut

🔄 Tugas 3: Kontrol Flow

Soal: Buatlah program untuk menentukan kategori BMI (Body Mass Index)!

Yang harus dibuat:

  • Fungsi untuk menghitung BMI: bmi = berat / (tinggi * tinggi)
  • Gunakan when expression untuk menentukan kategori:
    • BMI < 18.5: "Underweight"
    • BMI 18.5-24.9: "Normal"
    • BMI 25-29.9: "Overweight"
    • BMI ≥ 30: "Obese"

🏗️ Tugas 4: OOP

Soal: Buatlah class BankAccount untuk simulasi rekening bank sederhana!

Yang harus dibuat:

  • Properties: nomorRekening, namaPemilik, saldo
  • Method setor(jumlah: Double) untuk menambah saldo
  • Method tarik(jumlah: Double) untuk mengurangi saldo (cek saldo cukup)
  • Method cekSaldo() untuk melihat saldo
  • Buat 2 object dan lakukan beberapa transaksi

🎯 Tugas 5: Project Mini

Soal: Buatlah program "Sistem Nilai Siswa" yang menggabungkan semua konsep!

Yang harus dibuat:

  • Class Siswa dengan properties nama, kelas, dan list nilai
  • Method untuk menambah nilai
  • Method untuk menghitung rata-rata
  • Method untuk menentukan grade (A, B, C, D, E)
  • Fungsi main() yang membuat beberapa siswa dan menampilkan laporan
