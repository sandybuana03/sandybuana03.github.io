👋 Pengenalan Kotlin

🤖 Apa itu Kotlin?

Kotlin adalah bahasa pemrograman modern yang dikembangkan oleh JetBrains pada tahun 2011. Pada tahun 2017, Google mengumumkan Kotlin sebagai bahasa resmi untuk pengembangan aplikasi Android!

✨ Mengapa Kotlin Keren?

  • 🎯 Mudah dipelajari - Sintaks yang sederhana dan mirip bahasa manusia
  • 🛡️ Aman - Mencegah error yang sering terjadi
  • ⚡ Cepat - Performa yang excellent
  • 🔄 Kompatibel - Bisa digunakan bersama Java
  • 📱 Resmi Android - Didukung penuh oleh Google

🏗️ Struktur Program Kotlin

Program Kotlin yang paling sederhana terlihat seperti ini:

📦 Variabel & Tipe Data

🏷️ Apa itu Variabel?

Variabel adalah "kotak" untuk menyimpan data dalam program. Bayangkan seperti loker di sekolah yang bisa kita beri nama dan isi dengan barang-barang! 🏫

📝 Cara Membuat Variabel

Di Kotlin, ada dua cara membuat variabel:

  • val - untuk nilai yang tidak berubah (konstanta)
  • var - untuk nilai yang bisa berubah
// Variabel yang tidak berubah (val) val nama = "Budi" val umur = 17 // Variabel yang bisa berubah (var) var skor = 85 var level = 1 // Mengubah nilai var skor = 90 // ✅ Boleh level = 2 // ✅ Boleh // nama = "Siti" // ❌ Error! val tidak bisa diubah

🎨 Tipe Data Dasar

🔢 Angka (Numbers)

val bilangan = 42 // Int val desimal = 3.14 // Double val panjang = 100L // Long val pendek = 5.5f // Float

📝 Teks (String)

val pesan = "Hello Kotlin!" val multiline = """ Ini adalah teks multi baris """

✅ Boolean

val benar = true val salah = false val lulus = umur >= 17

🔤 Karakter

val huruf = 'A' val simbol = '@' val angka = '5'

🔗 String Template

Kotlin punya fitur keren untuk menggabungkan teks dengan variabel:

val nama = "Alice" val umur = 16 // Cara lama (tidak disarankan) val pesan1 = "Halo " + nama + ", umur kamu " + umur + " tahun" // Cara Kotlin (keren! 😎) val pesan2 = "Halo $nama, umur kamu $umur tahun" val pesan3 = "Tahun depan kamu ${umur + 1} tahun" println(pesan2) // Output: Halo Alice, umur kamu 16 tahun

⚙️ Fungsi dalam Kotlin

🔧 Apa itu Fungsi?

Fungsi adalah "mesin mini" dalam program yang melakukan tugas tertentu. Seperti mesin cuci yang tugasnya mencuci baju, fungsi punya tugas spesifik! 🧺

📋 Struktur Fungsi

fun namaFungsi(parameter: TipeData): TipeReturn { // kode yang dijalankan return hasil }

🎯 Contoh Fungsi Sederhana

// Fungsi tanpa parameter dan return fun sapaan() { println("Halo, selamat belajar Kotlin! 👋") } // Fungsi dengan parameter fun sapa(nama: String) { println("Halo $nama, semangat belajar! 💪") } // Fungsi dengan return value fun tambah(a: Int, b: Int): Int { return a + b } // Fungsi dengan expression body (singkat) fun kali(a: Int, b: Int) = a * b // Memanggil fungsi sapaan() // Output: Halo, selamat belajar Kotlin! 👋 sapa("Budi") // Output: Halo Budi, semangat belajar! 💪 val hasil = tambah(5, 3) // hasil = 8 val perkalian = kali(4, 6) // perkalian = 24

🎁 Parameter Default

Kotlin memungkinkan kita memberikan nilai default pada parameter:

fun buatProfil(nama: String, umur: Int = 17, kelas: String = "XII RPL") { println("Nama: $nama") println("Umur: $umur tahun") println("Kelas: $kelas") } // Cara memanggil: buatProfil("Alice") // Menggunakan default umur dan kelas buatProfil("Bob", 18) // Menggunakan default kelas buatProfil("Charlie", 16, "XI RPL") // Semua parameter diisi

🏷️ Named Arguments

Kita bisa menyebutkan nama parameter saat memanggil fungsi:

// Memanggil dengan named arguments buatProfil(nama = "Diana", kelas = "XII TKJ", umur = 17) // Lebih jelas dan tidak perlu urut sesuai definisi fungsi!

🔀 Kontrol Alur Program

🤔 Pengambilan Keputusan (if-else)

Seperti dalam kehidupan, program juga perlu membuat keputusan. Misalnya: "Jika hujan, bawa payung!" ☔

val nilai = 85 if (nilai >= 90) { println("Nilai A - Excellent! 🌟") } else if (nilai >= 80) { println("Nilai B - Good Job! 👍") } else if (nilai >= 70) { println("Nilai C - Not Bad! 😊") } else { println("Perlu belajar lebih giat! 💪") }

🎓 Cek Nilai Siswa

🎯 When Expression

Kotlin punya cara yang lebih elegan untuk multiple conditions:

val hari = 3 val namaHari = when (hari) { 1 -> "Senin" 2 -> "Selasa" 3 -> "Rabu" 4 -> "Kamis" 5 -> "Jumat" 6 -> "Sabtu" 7 -> "Minggu" else -> "Hari tidak valid" } println("Hari ke-$hari adalah $namaHari") // When dengan range val umur = 17 val kategori = when (umur) { in 0..12 -> "Anak-anak 👶" in 13..17 -> "Remaja 🧒" in 18..59 -> "Dewasa 👨" else -> "Lansia 👴" }

🔄 Perulangan (Loops)

📊 For Loop

// Loop dengan range for (i in 1..5) { println("Angka: $i") } // Loop dengan array/list val buah = listOf("Apel", "Jeruk", "Mangga") for (item in buah) { println("Buah: $item 🍎") } // Loop dengan index for (i in buah.indices) { println("${i + 1}. ${buah[i]}") }

🔁 While Loop

var countdown = 5 while (countdown > 0) { println("Countdown: $countdown") countdown-- } println("🚀 Blast off!") // Do-while (minimal 1x jalan) var input: String do { println("Ketik 'exit' untuk keluar:") input = readLine() ?: "" } while (input != "exit")

⏭️ Break dan Continue

// Break - keluar dari loop for (i in 1..10) { if (i == 6) break println("Angka: $i") } // Output: 1, 2, 3, 4, 5 // Continue - skip iterasi saat ini for (i in 1..10) { if (i % 2 == 0) continue // skip angka genap println("Angka ganjil: $i") } // Output: 1, 3, 5, 7, 9

🏗️ Kelas & Objek

🎭 Apa itu Kelas dan Objek?

Bayangkan kelas seperti "cetakan kue" 🍪, dan objek adalah "kue" yang dihasilkan dari cetakan tersebut. Satu cetakan bisa membuat banyak kue!

📝 Membuat Kelas Sederhana

class Siswa { var nama: String = "" var umur: Int = 0 var kelas: String = "" fun perkenalan() { println("Halo! Nama saya $nama, umur $umur tahun, kelas $kelas") } fun belajar(mapel: String) { println("$nama sedang belajar $mapel 📚") } } // Membuat objek (instance) val siswa1 = Siswa() siswa1.nama = "Budi" siswa1.umur = 17 siswa1.kelas = "XII RPL" siswa1.perkenalan() // Output: Halo! Nama saya Budi, umur 17 tahun, kelas XII RPL siswa1.belajar("Kotlin") // Output: Budi sedang belajar Kotlin 📚

🏗️ Constructor (Konstruktor)

Constructor adalah "fungsi khusus" yang dijalankan saat objek dibuat:

// Primary constructor class Smartphone(val merk: String, val model: String, var harga: Int) { // Init block - dijalankan saat objek dibuat init { println("Smartphone $merk $model telah dibuat! 📱") } fun info() { println("$merk $model - Rp ${harga}") } fun diskon(persen: Int) { val potongan = harga * persen / 100 harga -= potongan println("Diskon $persen%! Harga sekarang: Rp $harga") } } // Membuat objek dengan constructor val hp1 = Smartphone("Samsung", "Galaxy A54", 5000000) val hp2 = Smartphone("iPhone", "14", 15000000) hp1.info() // Samsung Galaxy A54 - Rp 5000000 hp1.diskon(10) // Diskon 10%! Harga sekarang: Rp 4500000

🎮 Buat Karakter Game

🎯 Data Class

Untuk kelas yang hanya menyimpan data, Kotlin punya data class:

data class Mahasiswa( val nim: String, val nama: String, val jurusan: String, var ipk: Double ) // Membuat objek val mhs1 = Mahasiswa("12345", "Alice", "Informatika", 3.75) val mhs2 = Mahasiswa("67890", "Bob", "Sistem Informasi", 3.50) // Data class otomatis punya fungsi: println(mhs1) // Mahasiswa(nim=12345, nama=Alice, jurusan=Informatika, ipk=3.75) // Copy dengan perubahan val mhs1Lulus = mhs1.copy(ipk = 3.80) println(mhs1Lulus) // IPK berubah, data lain sama

🔒 Visibility Modifiers

  • public - Bisa diakses dari mana saja (default)
  • private - Hanya bisa diakses dalam kelas yang sama
  • protected - Bisa diakses dalam kelas dan subclass
  • internal - Bisa diakses dalam module yang sama
class BankAccount(private var saldo: Double) { fun getSaldo(): Double { return saldo } fun setor(jumlah: Double) { if (jumlah > 0) { saldo += jumlah println("Setor Rp $jumlah berhasil! Saldo: Rp $saldo") } } private fun validasiPin(pin: String): Boolean { return pin == "1234" // Contoh sederhana } fun tarik(jumlah: Double, pin: String) { if (validasiPin(pin) && jumlah <= saldo) { saldo -= jumlah println("Tarik Rp $jumlah berhasil! Saldo: Rp $saldo") } else { println("Transaksi gagal! ❌") } } }

fun main() { val nama = "Sari" var nilai = 85 if (nilai >= 80) { println("$nama mendapat grade A") } else { println("$nama perlu belajar lebih giat") } nilai = 95 println("Nilai terbaru $nama: $nilai") }

🔧 Tugas 2: Membuat Fungsi

Buatlah fungsi Kotlin untuk menyelesaikan masalah berikut:

  1. Fungsi hitungLuasSegitiga yang menerima parameter alas dan tinggi, kemudian mengembalikan luas segitiga
  2. Fungsi cekGanjilGenap yang menerima parameter angka dan mengembalikan "Ganjil" atau "Genap"
  3. Fungsi sapaPengguna dengan parameter nama dan umur (default 17), yang mencetak sapaan

Contoh penggunaan:

val luas = hitungLuasSegitiga(10.0, 5.0) // Hasil: 25.0 val tipe = cekGanjilGenap(7) // Hasil: "Ganjil" sapaPengguna("Budi") // Output: sapaan dengan umur default sapaPengguna("Ani", 16) // Output: sapaan dengan umur 16

🏗️ Tugas 3: Membuat Kelas

Buatlah kelas Buku dengan spesifikasi berikut:

  • Properties: judul, penulis, tahunTerbit, harga
  • Constructor yang menerima semua parameter
  • Method info() yang menampilkan informasi lengkap buku
  • Method diskon(persen: Int) yang mengurangi harga sesuai persentase
  • Method isClassic() yang mengembalikan true jika buku terbit sebelum tahun 2000

Kemudian buat 2 objek buku dan demonstrasikan penggunaan semua method!

🔄 Tugas 4: Kontrol Alur

Buatlah program yang:

  1. Menggunakan loop untuk menampilkan angka 1-20
  2. Melewati (skip) angka yang habis dibagi 3 menggunakan continue
  3. Berhenti jika menemukan angka 15 menggunakan break
  4. Untuk setiap angka yang ditampilkan, gunakan when untuk menentukan:
    • Angka 1-5: "Kecil"
    • Angka 6-10: "Sedang"
    • Angka 11-15: "Besar"

  • Fungsi untuk mencari siswa berdasarkan nim
  • Fungsi untuk menghitung rata-rata nilai semua siswa
  • Fungsi untuk menampilkan siswa dengan nilai tertinggi
