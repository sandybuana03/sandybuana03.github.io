Pengenalan Android

Apa itu Android? 🤖

Android adalah sistem operasi mobile yang dikembangkan oleh Google, berbasis kernel Linux. Android bersifat open source dan gratis untuk digunakan oleh manufacturer perangkat.

🏗️ Arsitektur: Stack berlapis dengan Linux kernel sebagai fondasi

📱 Platform: Smartphone, tablet, TV, smartwatch, automotive

💻 Bahasa: Java, Kotlin, C/C++ untuk native development

Fun Fact: Nama Android diambil dari robot dalam novel sci-fi "Do Androids Dream of Electric Sheep?" oleh Philip K. Dick 🤖

Sejarah & Evolusi 📚

2003: Android Inc. didirikan oleh Andy Rubin, Rich Miner, Nick Sears, dan Chris White

2005: Google mengakuisisi Android Inc. seharga $50 juta

2007: Open Handset Alliance dibentuk dengan 84 perusahaan

2008: Android 1.0 (API level 1) diluncurkan di HTC Dream

2024: Android 14 (API level 34) dengan fitur AI dan privacy terbaru

📊 Statistik: Lebih dari 3 miliar perangkat aktif menggunakan Android di seluruh dunia!

🤓 Fakta Menarik Arsitektur Android

🚀

ART vs Dalvik: Android Runtime (ART) menggantikan Dalvik di Android 5.0, memberikan performa 2x lebih cepat!

🧠

Memory Management: Android menggunakan sistem "Low Memory Killer" untuk mengoptimalkan penggunaan RAM.

🔒

Sandbox: Setiap aplikasi berjalan dalam sandbox terpisah untuk keamanan maksimal.

⚡

Zygote Process: Proses khusus yang mempercepat startup aplikasi dengan pre-loading libraries.

Komponen Utama Android

🎭 Activity

Komponen yang mengelola satu layar dengan interface pengguna. Seperti halaman dalam aplikasi.

📱 Contoh: Layar login, beranda, profil, settings

🔄 Lifecycle: onCreate → onStart → onResume → onPause → onStop → onDestroy

📋 Manifest: Harus dideklarasikan di AndroidManifest.xml

⚙️ Service

Komponen yang berjalan di background tanpa interface pengguna.

🎵 Contoh: Pemutar musik, download, sync data, location tracking

🔧 Jenis: Started Service, Bound Service, Foreground Service

⏰ Lifecycle: onCreate → onStartCommand → onDestroy

📡 Broadcast Receiver

Komponen yang merespons pesan broadcast dari sistem atau aplikasi lain.

📢 Contoh: Baterai lemah, SMS masuk, WiFi connected, boot completed

📝 Registrasi: Manifest (static) atau Runtime (dynamic)

🎯 Method: onReceive() - harus selesai dalam 10 detik

🗄️ Content Provider

Komponen yang mengelola akses ke data terstruktur dan memungkinkan berbagi data antar aplikasi dengan aman.

📊 Contoh: Kontak, galeri, kalender, media storage, browser bookmarks

🔐 Keamanan: URI permissions, read/write permissions

🛠️ CRUD: query(), insert(), update(), delete()

🔗 Intent - Penghubung Komponen

📨 Explicit Intent

Memanggil komponen tertentu secara langsung

Contoh: Membuka Activity tertentu dalam aplikasi

🌐 Implicit Intent

Meminta sistem mencari komponen yang sesuai

Contoh: Membuka browser, kirim email, share foto

🧩 Fragment - Sub-komponen UI

Fragment adalah bagian dari Activity yang memiliki lifecycle sendiri dan dapat digunakan kembali.

✅ Keuntungan Fragment:

  • • Modular dan reusable
  • • Mendukung multi-pane UI
  • • Lifecycle management

📱 Contoh Penggunaan:

  • • Tab dalam aplikasi
  • • Dialog dan popup
  • • Navigation drawer

Tools Development Android

🛠️

Android Studio

IDE (Integrated Development Environment) resmi untuk pengembangan aplikasi Android.

Fitur: Code editor, debugger, emulator, layout editor

📱

Android SDK

Software Development Kit yang berisi tools, libraries, dan dokumentasi untuk development.

Komponen: Platform tools, build tools, API libraries

🎯

ADB (Android Debug Bridge)

Tool command-line untuk berkomunikasi dengan perangkat Android.

Fungsi: Install APK, debugging, file transfer

🔍

Gradle

Build system yang mengotomatisasi proses kompilasi, testing, dan packaging aplikasi Android.

Fungsi: Build automation, dependency management, multi-module support
