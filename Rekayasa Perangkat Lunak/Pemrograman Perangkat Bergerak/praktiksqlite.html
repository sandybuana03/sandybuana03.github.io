🤔 Apa itu SQLite?

SQLite adalah database engine yang ringan, cepat, dan tidak memerlukan server terpisah. Sangat cocok untuk aplikasi mobile karena:

  • 📱 Ringan - Ukuran kecil, cocok untuk perangkat mobile
  • ⚡ Cepat - Performa tinggi untuk operasi database
  • 🔒 Reliable - Data tersimpan aman di perangkat
  • 🆓 Gratis - Open source dan sudah built-in di Android
💡 Tahukah kamu?
SQLite sudah terpasang secara default di setiap perangkat Android! Jadi kamu tidak perlu menginstall apapun tambahan.

🛠️ Langkah 2: Membuat Database Helper Class

Sekarang mari buat class DatabaseHelper yang akan mengelola database SQLite:

DatabaseHelper.java
package com.example.sqlitestudent; import android.content.ContentValues; import android.content.Context; import android.database.Cursor; import android.database.sqlite.SQLiteDatabase; import android.database.sqlite.SQLiteOpenHelper; import java.util.ArrayList; import java.util.List; public class DatabaseHelper extends SQLiteOpenHelper { // Konstanta untuk database private static final String DATABASE_NAME = "student_database"; private static final int DATABASE_VERSION = 1; // Konstanta untuk tabel dan kolom private static final String TABLE_STUDENTS = "students"; private static final String COLUMN_ID = "id"; private static final String COLUMN_NAMA = "nama"; private static final String COLUMN_KELAS = "kelas"; private static final String COLUMN_NILAI = "nilai"; // SQL untuk membuat tabel private static final String CREATE_TABLE_STUDENTS = "CREATE TABLE " + TABLE_STUDENTS + " (" + COLUMN_ID + " INTEGER PRIMARY KEY AUTOINCREMENT, " + COLUMN_NAMA + " TEXT NOT NULL, " + COLUMN_KELAS + " TEXT NOT NULL, " + COLUMN_NILAI + " INTEGER NOT NULL)"; // Constructor public DatabaseHelper(Context context) { super(context, DATABASE_NAME, null, DATABASE_VERSION); } // Method yang dipanggil saat database pertama kali dibuat @Override public void onCreate(SQLiteDatabase db) { db.execSQL(CREATE_TABLE_STUDENTS); } // Method yang dipanggil saat database di-upgrade @Override public void onUpgrade(SQLiteDatabase db, int oldVersion, int newVersion) { db.execSQL("DROP TABLE IF EXISTS " + TABLE_STUDENTS); onCreate(db); } }
💡 Penjelasan Kode:
• SQLiteOpenHelper: Class parent yang memudahkan pengelolaan database
• onCreate(): Dipanggil saat database pertama kali dibuat
• onUpgrade(): Dipanggil saat versi database berubah
• PRIMARY KEY AUTOINCREMENT: ID otomatis bertambah

🔧 Langkah 3: Menambahkan Method CRUD Dasar

Mari tambahkan method untuk operasi database dasar:

DatabaseHelper.java (lanjutan)
// Method untuk menambah data siswa public long addStudent(Student student) { SQLiteDatabase db = this.getWritableDatabase(); ContentValues values = new ContentValues(); values.put(COLUMN_NAMA, student.getNama()); values.put(COLUMN_KELAS, student.getKelas()); values.put(COLUMN_NILAI, student.getNilai()); // Insert data dan return ID long id = db.insert(TABLE_STUDENTS, null, values); db.close(); return id; } // Method untuk mengambil semua data siswa public List<Student> getAllStudents() { List<Student> studentList = new ArrayList<>(); String selectQuery = "SELECT * FROM " + TABLE_STUDENTS; SQLiteDatabase db = this.getReadableDatabase(); Cursor cursor = db.rawQuery(selectQuery, null); // Loop melalui semua baris dan tambahkan ke list if (cursor.moveToFirst()) { do { Student student = new Student(); student.setId(cursor.getInt(cursor.getColumnIndexOrThrow(COLUMN_ID))); student.setNama(cursor.getString(cursor.getColumnIndexOrThrow(COLUMN_NAMA))); student.setKelas(cursor.getString(cursor.getColumnIndexOrThrow(COLUMN_KELAS))); student.setNilai(cursor.getInt(cursor.getColumnIndexOrThrow(COLUMN_NILAI))); studentList.add(student); } while (cursor.moveToNext()); } cursor.close(); db.close(); return studentList; }
🎯 Tips Best Practice:
• Selalu tutup database dan cursor setelah digunakan untuk menghemat memori
• Gunakan try-with-resources (Java 7+) untuk auto-close resources
• Hindari operasi database di UI thread untuk data besar
• Gunakan getColumnIndexOrThrow() untuk error handling yang lebih baik

// Method untuk update data siswa public int updateStudent(Student student) { SQLiteDatabase db = this.getWritableDatabase(); ContentValues values = new ContentValues(); values.put(COLUMN_NAMA, student.getNama()); values.put(COLUMN_KELAS, student.getKelas()); values.put(COLUMN_NILAI, student.getNilai()); // Update baris berdasarkan ID int rowsAffected = db.update(TABLE_STUDENTS, values, COLUMN_ID + " = ?", new String[]{String.valueOf(student.getId())}); db.close(); return rowsAffected; } // Method untuk menghapus data siswa berdasarkan ID public int deleteStudent(int id) { SQLiteDatabase db = this.getWritableDatabase(); int rowsDeleted = db.delete(TABLE_STUDENTS, COLUMN_ID + " = ?", new String[]{String.valueOf(id)}); db.close(); return rowsDeleted; } // Method untuk mengambil satu siswa berdasarkan ID public Student getStudent(int id) { SQLiteDatabase db = this.getReadableDatabase(); Cursor cursor = db.query(TABLE_STUDENTS, new String[]{COLUMN_ID, COLUMN_NAMA, COLUMN_KELAS, COLUMN_NILAI}, COLUMN_ID + " = ?", new String[]{String.valueOf(id)}, null, null, null); Student student = null; if (cursor != null && cursor.moveToFirst()) { student = new Student( cursor.getInt(cursor.getColumnIndexOrThrow(COLUMN_ID)), cursor.getString(cursor.getColumnIndexOrThrow(COLUMN_NAMA)), cursor.getString(cursor.getColumnIndexOrThrow(COLUMN_KELAS)), cursor.getInt(cursor.getColumnIndexOrThrow(COLUMN_NILAI)) ); cursor.close(); } db.close(); return student; } // Method untuk menghitung jumlah siswa public int getStudentCount() { String countQuery = "SELECT COUNT(*) FROM " + TABLE_STUDENTS; SQLiteDatabase db = this.getReadableDatabase(); Cursor cursor = db.rawQuery(countQuery, null); int count = 0; if (cursor.moveToFirst()) { count = cursor.getInt(0); } cursor.close(); db.close(); return count; }

❓ Troubleshooting & FAQ

❓ Database tidak terbuat?

Solusi: Pastikan DatabaseHelper dipanggil dengan benar dan cek Logcat untuk error. Database akan terbuat otomatis saat pertama kali diakses.

❓ Data tidak muncul di ListView?

Solusi: Cek apakah adapter sudah di-set ke ListView dan method loadStudentData() dipanggil setelah operasi CRUD.

❓ App crash saat operasi database?

Solusi: Pastikan semua cursor dan database di-close dengan benar. Gunakan try-catch untuk handle exception.

❓ Bagaimana melihat isi database?

Solusi: Gunakan Database Inspector di Android Studio atau export database ke external storage untuk dibuka dengan SQLite browser.
