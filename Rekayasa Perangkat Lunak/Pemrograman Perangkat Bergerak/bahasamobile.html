Pengenalan Mobile Programming

📱 Apa itu Mobile Programming?

Mobile Programming adalah proses membuat aplikasi yang berjalan di perangkat mobile seperti smartphone dan tablet. Aplikasi ini bisa berupa game, media sosial, e-commerce, atau tools produktivitas.

Contoh Aplikasi Mobile Populer:
📱 Native Apps:
  • • WhatsApp (Android: Java/Kotlin, iOS: Swift)
  • • Instagram (Native dengan komponen hybrid)
  • • Spotify (Native dengan web components)
  • • Google Maps (Native)
🌐 Cross-Platform Apps:
  • • Facebook (React Native)
  • • Alibaba (Flutter)
  • • Skype (React Native)
  • • Google Ads (Flutter)

🤖 Platform Android

  • • Sistem operasi Google
  • • Market share terbesar dunia
  • • Open source
  • • Beragam perangkat

🍎 Platform iOS

  • • Sistem operasi Apple
  • • Eksklusif untuk iPhone/iPad
  • • Keamanan tinggi
  • • User experience premium

Android Development

☕ Java untuk Android

Java adalah bahasa pemrograman utama untuk Android development sejak awal. Bahasa ini mudah dipelajari, memiliki sintaks yang jelas, dan didukung oleh komunitas yang besar.

Karakteristik Java:
  • • Object-Oriented Programming (OOP)
  • • Platform independent
  • • Strongly typed language
  • • Automatic memory management
  • • Rich API dan library
Komponen Android Java:
  • • Activity (UI screens)
  • • Service (background tasks)
  • • Broadcast Receiver
  • • Content Provider
  • • Intent (komunikasi antar komponen)
Contoh Kode Java Android:
public class MainActivity extends AppCompatActivity {
    private Button myButton;
    private TextView myTextView;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        myButton = findViewById(R.id.button);
        myTextView = findViewById(R.id.textView);

        myButton.setOnClickListener(new View.OnClickListener() {
            @Override
            public void onClick(View v) {
                myTextView.setText("Hello Android!");
            }
        });
    }
}

🎯 Kotlin - First Class Language

Kotlin adalah bahasa modern yang direkomendasikan Google untuk Android sejak 2019. Lebih ringkas, aman, dan 100% interoperable dengan Java.

Keunggulan Kotlin:
  • • Null Safety (menghindari NullPointerException)
  • • Extension Functions
  • • Data Classes
  • • Coroutines untuk async programming
  • • Smart Casts
  • • Lambda expressions
Kotlin vs Java:
  • • 40% lebih sedikit kode
  • • Lebih ekspresif dan readable
  • • Compile ke bytecode yang sama
  • • Dapat menggunakan Java libraries
  • • Mendukung functional programming
Contoh Kode Kotlin Android:
class MainActivity : AppCompatActivity() {
    private lateinit var myButton: Button
    private lateinit var myTextView: TextView

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        myButton = findViewById(R.id.button)
        myTextView = findViewById(R.id.textView)

        myButton.setOnClickListener {
            myTextView.text = "Hello Kotlin!"
        }
    }
}
🚀 Kotlin Multiplatform:

Kotlin tidak hanya untuk Android! Dengan Kotlin Multiplatform, Anda bisa berbagi kode business logic antara Android, iOS, Web, dan Desktop.

Kelebihan Java

  • • Mudah dipelajari
  • • Dokumentasi lengkap
  • • Komunitas besar
  • • Stabil dan mature

Kelebihan Kotlin

  • • Sintaks lebih ringkas
  • • Null safety
  • • Interoperability dengan Java
  • • Direkomendasikan Google

iOS Development

🦉 Swift - Apple's Modern Language

Swift adalah bahasa pemrograman modern yang dikembangkan Apple khusus untuk iOS, macOS, watchOS, dan tvOS. Diluncurkan 2014, Swift menggantikan Objective-C dengan sintaks yang lebih bersih dan performa tinggi.

Fitur Unggulan Swift:
  • • Type Safety & Type Inference
  • • Optional Types (nil safety)
  • • Closures & Higher-order functions
  • • Protocol-oriented programming
  • • Automatic Reference Counting (ARC)
  • • Generics & Pattern matching
Swift vs Objective-C:
  • • 2.6x lebih cepat dari Objective-C
  • • Sintaks lebih mudah dibaca
  • • Lebih sedikit kode boilerplate
  • • Memory management otomatis
  • • Interoperable dengan Objective-C
Contoh Kode Swift iOS:
import UIKit

class ViewController: UIViewController {
    @IBOutlet weak var myLabel: UILabel!
    @IBOutlet weak var myButton: UIButton!

    override func viewDidLoad() {
        super.viewDidLoad()
        setupUI()
    }

    func setupUI() {
        myLabel.text = "Welcome to iOS!"
        myButton.setTitle("Tap Me", for: .normal)
    }

    @IBAction func buttonTapped(_ sender: UIButton) {
        myLabel.text = "Hello Swift!"
    }
}
🎯 SwiftUI - Declarative UI:

SwiftUI adalah framework UI terbaru Apple yang memungkinkan pembuatan interface dengan kode yang lebih sedikit dan intuitif.

struct ContentView: View {
    var body: some View {
        VStack {
            Text("Hello SwiftUI!")
            Button("Tap Me") {
                print("Button tapped!")
            }
        }
    }
}

🔧 Objective-C (Legacy)

Objective-C adalah bahasa pemrograman yang digunakan Apple sebelum Swift. Masih digunakan untuk maintenance aplikasi lama dan beberapa library sistem iOS.

Contoh Kode Objective-C:
@interface ViewController : UIViewController
@end

@implementation ViewController
- (void)viewDidLoad {
    [super viewDidLoad];
    NSLog(@"Hello, iOS!");
}
@end

Kelebihan Swift

  • • Sintaks modern dan bersih
  • • Performance tinggi
  • • Type safety
  • • Playground untuk belajar

Fitur iOS Development

  • • Interface Builder
  • • Core Data
  • • CloudKit
  • • ARKit & Metal

💻 Persyaratan iOS Development

  • • Xcode IDE (gratis di App Store)

  • • iPhone/iPad untuk testing (opsional)

🎯 Bahasa Dart untuk Flutter

Dart adalah bahasa pemrograman yang dikembangkan Google khusus untuk Flutter. Mudah dipelajari dengan sintaks yang mirip Java/JavaScript.

Kelebihan Dart:

  • • Strongly typed
  • • Hot reload untuk development cepat
  • • Compile ke native code
Fitur Dart:
  • • Null safety
  • • Async/await support
  • • Rich standard library
  • • Package manager (pub.dev)

Cross Platform Development

🎯 Apa itu Cross Platform?

Cross Platform Development memungkinkan kita membuat satu aplikasi yang bisa berjalan di Android dan iOS sekaligus. Ini menghemat waktu dan biaya development.

⚛️ React Native

Framework dari Facebook menggunakan JavaScript dan React.

import React from 'react';
import { Text, View } from 'react-native';

const App = () => {
  return (
    <View>
      <Text>Hello World!</Text>
    </View>
  );
};

🎨 Flutter (Dart) - Google's UI Toolkit

Framework UI dari Google menggunakan bahasa Dart. Menghasilkan native code untuk performa optimal dan konsistensi UI di semua platform.

Keunggulan Flutter:
  • • Hot Reload untuk development cepat
  • • Single codebase untuk semua platform
  • • Custom rendering engine (Skia)
  • • Rich widget library
  • • Native performance
Platform Support:
  • • Android & iOS
  • • Web (Flutter Web)
  • • Desktop (Windows, macOS, Linux)
  • • Embedded devices
Contoh Flutter App dengan State Management:
import 'package:flutter/material.dart';

void main() => runApp(MyApp());

class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Flutter Demo',
      home: CounterPage(),
    );
  }
}

class CounterPage extends StatefulWidget {
  @override
  _CounterPageState createState() => _CounterPageState();
}

class _CounterPageState extends State<CounterPage> {
  int _counter = 0;

  void _incrementCounter() {
    setState(() { _counter++; });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Flutter Counter')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text('Counter: $_counter', style: TextStyle(fontSize: 24)),
            ElevatedButton(
              onPressed: _incrementCounter,
              child: Text('Increment'),
            ),
          ],
        ),
      ),
    );
  }
}

⚖️ Perbandingan Cross Platform vs Native

Kelebihan Cross Platform:
  • • Satu kode untuk dua platform
  • • Development lebih cepat
  • • Biaya lebih murah
  • • Maintenance lebih mudah
Kelebihan Native:
  • • Performance maksimal
  • • Akses penuh fitur platform
  • • UI/UX lebih natural
  • • Debugging lebih mudah

🏗️ Arsitektur Mobile App

MVC (Model-View-Controller)

Arsitektur klasik yang memisahkan data, tampilan, dan logika kontrol.

  • • Model: Data & business logic
  • • View: User interface
  • • Controller: Mediator
MVVM (Model-View-ViewModel)

Populer untuk Android (Data Binding) dan iOS (SwiftUI).

  • • Model: Data layer
  • • View: UI components
  • • ViewModel: Presentation logic
Clean Architecture

Arsitektur berlapis untuk aplikasi yang scalable dan testable.

  • • Presentation Layer
  • • Domain Layer
  • • Data Layer
