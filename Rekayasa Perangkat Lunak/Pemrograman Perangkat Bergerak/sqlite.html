📚 Pengenalan SQLite

🤖 Apa itu SQLite?

SQLite adalah sistem manajemen database relasional yang sangat ringan dan tidak memerlukan server terpisah. Database ini tersimpan dalam satu file dan cocok banget untuk aplikasi mobile karena ukurannya kecil tapi powerful!

💡 Fun Fact: SQLite digunakan oleh miliaran perangkat di seluruh dunia!

⭐ Keunggulan SQLite

  • ✓ Ringan & cepat
  • ✓ Tidak butuh server
  • ✓ Gratis & open source
  • ✓ Mudah digunakan

🏗️ SQLite vs Database Lain

Aspek SQLite MySQL
Server ❌ Tidak butuh ✅ Butuh server
Ukuran 🪶 Sangat ringan 🏋️ Lebih berat
Mobile 📱 Sangat cocok 💻 Untuk server

🧠 Konsep Dasar Database

🏠 Analogi Sederhana

Bayangkan database seperti perpustakaan:

📚

Database = Perpustakaan

📊 Komponen Database

  • 🗃️
    Tabel: Tempat menyimpan data sejenis
  • 📝
    Record/Row: Satu baris data lengkap
  • 🏷️
    Field/Column: Kategori data

🎯 Contoh Tabel Siswa

ID Nama Kelas Umur
1 Andi XII RPL 17
2 Sari XII TKJ 18

☝️ Setiap baris = 1 record siswa

🔑 Primary Key (Kunci Utama)

Primary Key adalah ID unik untuk setiap record. Seperti nomor induk siswa - tidak boleh ada yang sama!

💡 Tips: Biasanya menggunakan angka yang otomatis bertambah (AUTOINCREMENT)

📊 Tipe Data SQLite

Tipe Data Utama:

  • • INTEGER: Angka bulat (1, 2, 100)
  • • TEXT: Teks/string ("Nama", "Alamat")
  • • REAL: Angka desimal (3.14, 99.5)
  • • BLOB: Data binary (gambar, file)

Contoh Penggunaan:

id INTEGER PRIMARY KEY
nama TEXT NOT NULL
umur INTEGER
tinggi REAL

⚙️ Setup SQLite di Android

📱 Kabar Baik!

SQLite sudah built-in di Android! Kamu tidak perlu install apapun, tinggal pakai langsung. Android menyediakan class SQLiteOpenHelper untuk memudahkan kita.

🏗️ Langkah Setup

  1. 1
    Buat class DatabaseHelper
  2. 2
    Extend SQLiteOpenHelper
  3. 3
    Override method onCreate & onUpgrade
  4. 4
    Buat method CRUD

📋 Yang Dibutuhkan

  • ✓ Android Studio
  • ✓ Project Android
  • ✓ Pengetahuan Java/Kotlin
  • ✓ Semangat belajar! 🔥

💻 Contoh DatabaseHelper Class 

public class DatabaseHelper extends SQLiteOpenHelper {
    
    // Konstanta database
    private static final String DATABASE_NAME = "sekolah.db";
    private static final int DATABASE_VERSION = 1;
    
    // Nama tabel dan kolom
    private static final String TABLE_SISWA = "siswa";
    private static final String COLUMN_ID = "id";
    private static final String COLUMN_NAMA = "nama";
    private static final String COLUMN_KELAS = "kelas";
    private static final String COLUMN_UMUR = "umur";
    
    public DatabaseHelper(Context context) {
        super(context, DATABASE_NAME, null, DATABASE_VERSION);
    }
    
    @Override
    public void onCreate(SQLiteDatabase db) {
        // Buat tabel siswa
        String createTable = "CREATE TABLE " + TABLE_SISWA + "("
                + COLUMN_ID + " INTEGER PRIMARY KEY AUTOINCREMENT,"
                + COLUMN_NAMA + " TEXT NOT NULL,"
                + COLUMN_KELAS + " TEXT NOT NULL,"
                + COLUMN_UMUR + " INTEGER" + ")";
        db.execSQL(createTable);
    }
    
    @Override
    public void onUpgrade(SQLiteDatabase db, int oldVersion, int newVersion) {
        // Hapus tabel lama dan buat yang baru
        db.execSQL("DROP TABLE IF EXISTS " + TABLE_SISWA);
        onCreate(db);
    }
}

💡 Penjelasan:

  • • onCreate: Dipanggil saat database pertama kali dibuat
  • • onUpgrade: Dipanggil saat versi database berubah
  • • PRIMARY KEY AUTOINCREMENT: ID otomatis bertambah

🔧 Operasi CRUD

🎯 Apa itu CRUD?

CRUD adalah singkatan dari 4 operasi dasar database:

➕

CREATE

Tambah data

👀

READ

Baca data

✏️

UPDATE

Edit data

🗑️

DELETE

Hapus data

➕ CREATE - Menambah Data 

public long tambahSiswa(String nama, String kelas, int umur) {
    SQLiteDatabase db = this.getWritableDatabase();
    ContentValues values = new ContentValues();
    
    values.put(COLUMN_NAMA, nama);
    values.put(COLUMN_KELAS, kelas);
    values.put(COLUMN_UMUR, umur);
    
    long id = db.insert(TABLE_SISWA, null, values);
    db.close();
    
    return id; // Return ID siswa yang baru ditambah
}

💡 Cara pakai:

DatabaseHelper db = new DatabaseHelper(this);
long id = db.tambahSiswa("Budi", "XII RPL");

👀 READ - Membaca Data 

public List<Siswa> getAllSiswa() {
    List<Siswa> listSiswa = new ArrayList<>();
    SQLiteDatabase db = this.getReadableDatabase();
    
    // Query untuk mengambil semua data siswa
    Cursor cursor = db.query(TABLE_SISWA, null, null, null, null, null, null);
    
    if (cursor.moveToFirst()) {
        do {
            Siswa siswa = new Siswa();
            siswa.setId(cursor.getInt(cursor.getColumnIndex(COLUMN_ID)));
            siswa.setNama(cursor.getString(cursor.getColumnIndex(COLUMN_NAMA)));
            siswa.setKelas(cursor.getString(cursor.getColumnIndex(COLUMN_KELAS)));
            siswa.setUmur(cursor.getInt(cursor.getColumnIndex(COLUMN_UMUR)));
            listSiswa.add(siswa);
        } while (cursor.moveToNext());
    }
    
    cursor.close();
    db.close();
    return listSiswa;
}

💡 Cara pakai:

List<Siswa> daftarSiswa = db.getAllSiswa();

✏️ UPDATE - Mengubah Data 

public int updateSiswa(int id, String nama, String kelas, int umur) {
    SQLiteDatabase db = this.getWritableDatabase();
    ContentValues values = new ContentValues();
    
    values.put(COLUMN_NAMA, nama);
    values.put(COLUMN_KELAS, kelas);
    values.put(COLUMN_UMUR, umur);
    
    // Update data berdasarkan ID
    int result = db.update(TABLE_SISWA, values, 
                          COLUMN_ID + " = ?", 
                          new String[]{String.valueOf(id)});
    db.close();
    
    return result; // Return jumlah row yang diupdate
}

💡 Cara pakai:

int updated = db.updateSiswa(1, "Budi Santoso", "XII TKJ");

🗑️ DELETE - Menghapus Data 

public int deleteSiswa(int id) {
    SQLiteDatabase db = this.getWritableDatabase();
    
    int result = db.delete(TABLE_SISWA, 
                          COLUMN_ID + " = ?", 
                          new String[]{String.valueOf(id)});
    db.close();
    
    return result; // Return jumlah row yang dihapus
}

💡 Cara pakai:

int deleted = db.deleteSiswa(1);
if (deleted > 0) {
    // Data berhasil dihapus
}

⚠️ Error Handling & Best Practices

Tips Penting:

  • • Selalu tutup database dengan db.close()
  • • Gunakan try-catch untuk menangani error
  • • Validasi input sebelum menyimpan ke database
  • • Gunakan transaksi untuk operasi multiple

Contoh Error Handling:

try {
  long id = db.tambahSiswa(nama, kelas, umur);
  Log.d("DB", "Data tersimpan dengan ID: " + id);
} catch (Exception e) {
  Log.e("DB", "Error: " + e.getMessage());
}
