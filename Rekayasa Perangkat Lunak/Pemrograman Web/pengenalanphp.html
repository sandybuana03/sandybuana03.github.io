PHP: Hypertext Preprocessor

🤖 Apa itu PHP?

PHP adalah bahasa pemrograman yang berjalan di server (server-side). Bayangkan PHP seperti "dapur" di restoran - pelanggan tidak melihat prosesnya, tapi hasilnya (makanan/website) dikirim ke mereka!

⚡ Mengapa PHP?

  • • Mudah dipelajari
  • • Gratis dan open source
  • • Banyak tutorial online
  • • Digunakan Facebook, Wikipedia!

🏗️ PHP dalam Struktur HTML

PHP dapat disisipkan langsung ke dalam kode HTML. Ini yang membuat website menjadi dinamis!

📄 HTML Biasa (Statis)

<!DOCTYPE html>
<html>
<head>
  <title>Website Saya</title>
</head>
<body>
  <h1>Selamat Datang!</h1>
  <p>Nama: Budi</p>
</body>
</html>

⚡ HTML + PHP (Dinamis)

<!DOCTYPE html>
<html>
<head>
  <title>Website Saya</title>
</head>
<body>
  <h1>Selamat Datang!</h1>
  <p>Nama: <?php echo $nama; ?></p>
</body>
</html>

🎯 Contoh Lengkap: Halaman Profil Dinamis

<?php
// Data siswa
$nama = "Siti Aminah";
$kelas = "XI RPL";
$umur = 16;
$hobi = ["coding", "membaca", "musik"];
?>

<!DOCTYPE html>
<html>
<head>
  <title>Profil <?php echo $nama; ?></title>
</head>
<body>
  <h1>Profil Siswa</h1>
  <p>Nama: <?php echo $nama; ?></p>
  <p>Kelas: <?php echo $kelas; ?></p>
  <p>Umur: <?php echo $umur; ?> tahun</p>
  <h3>Hobi:</h3>
  <ul>
    <?php foreach($hobi as $h) { ?>
      <li><?php echo $h; ?></li>
    <?php } ?>
  </ul>
</body>
</html>

Sintaks Dasar PHP

Aturan penulisan kode PHP

🏷️ Tag PHP

Kode PHP harus ditulis di antara tag khusus. Seperti amplop surat, kode PHP harus "dibungkus" agar server tahu ini adalah kode PHP!

<?php
// Kode PHP ditulis di sini
echo "Halo Dunia!";
?>

💡 Tips Penting:

  • • Selalu mulai dengan <?php
  • • Akhiri dengan ?> (opsional di akhir file)
  • • Setiap baris diakhiri dengan ;

💬 Komentar

Komentar adalah catatan untuk programmer. Seperti sticky notes, komentar membantu kita mengingat apa yang dilakukan kode tersebut.

<?php
// Ini komentar satu baris
/* Ini komentar
   beberapa baris */
echo "Halo!"; // Komentar di samping kode
?>

🖨️ Menampilkan Output

Untuk menampilkan sesuatu di layar, kita gunakan echo atau print

Menggunakan echo:

<?php
echo "Halo Dunia!";
echo "Saya belajar PHP";
?>

Hasilnya:

Halo Dunia!Saya belajar PHP

🔧 Aturan Penulisan PHP (Best Practices)

✅ Yang Harus Dilakukan

  • • Gunakan indentasi yang konsisten (4 spasi)
  • • Beri nama variabel yang deskriptif
  • • Selalu tutup tag PHP di akhir file
  • • Gunakan komentar untuk kode kompleks
  • • Pisahkan logika dan tampilan
  • • Gunakan huruf kecil untuk nama file

❌ Yang Harus Dihindari

  • • Mencampur HTML dan PHP berlebihan
  • • Menggunakan nama variabel tidak jelas
  • • Lupa semicolon (;) di akhir statement
  • • Tidak menggunakan komentar sama sekali
  • • Menulis kode dalam satu baris panjang
  • • Menggunakan spasi tidak konsisten

Variabel PHP

Tempat menyimpan data

🏷️ Apa itu Variabel?

Variabel seperti kotak penyimpanan yang diberi label. Kita bisa memasukkan berbagai jenis data ke dalamnya dan menggunakannya kapan saja!

📦

Kotak

Variabel

🏷️

Label

Nama Variabel

💎

Isi

Nilai/Data

✍️ Cara Membuat Variabel

Di PHP, variabel selalu dimulai dengan tanda $

<?php
// Membuat variabel
$nama = "Budi";
$umur = 17;
$tinggi = 165.5;

// Menampilkan variabel
echo "Nama: " . $nama;
echo "Umur: " . $umur;
?>

📋 Aturan Penamaan Variabel:

✅ Boleh:

  • • $nama
  • • $umur_siswa
  • • $nilai2
  • • $_data

❌ Tidak Boleh:

  • • $2nama (dimulai angka)
  • • $nama-siswa (pakai -)
  • • $nama siswa (ada spasi)
  • • nama (tanpa $)

🔄 Mengubah Nilai Variabel

Variabel bisa diubah nilainya kapan saja, seperti mengganti isi kotak!

<?php
$skor = 80;
echo "Skor awal: " . $skor; // Output: 80

$skor = 95; // Mengubah nilai
echo "Skor baru: " . $skor; // Output: 95
?>

🌐 Scope Variabel

Scope menentukan di mana variabel bisa diakses dalam program

🏠 Variabel Lokal

<?php
function sapa() {
  $nama = "Budi"; // Lokal
  echo $nama;
}
// echo $nama; // Error!
?>

Hanya bisa diakses dalam fungsi

🌍 Variabel Global

<?php
$nama = "Siti"; // Global

function sapa() {
  global $nama;
  echo $nama;
}
?>

Bisa diakses di mana saja

🔄 Variabel Dinamis

PHP memiliki fitur unik: variabel dinamis (variable variables)

<?php
$nama_var = "umur";
$$nama_var = 17; // Sama dengan $umur = 17;

echo $umur; // Output: 17
echo $$nama_var; // Output: 17
?>

💡 Tips: Fitur ini powerful tapi jarang digunakan. Gunakan dengan hati-hati karena bisa membuat kode sulit dipahami.

Tipe Data PHP

Jenis-jenis data yang bisa disimpan

📝 String (Teks)

Untuk menyimpan teks atau kata-kata

$nama = "Budi Santoso";
$alamat = 'Jakarta';
$pesan = "Halo dunia!";

Tips: Gunakan tanda kutip (" ") atau kutip tunggal (' ')

🔢 Integer (Bilangan Bulat)

Untuk menyimpan angka tanpa koma

$umur = 17;
$jumlah_siswa = 30;
$tahun = 2024;

Contoh: 1, 25, -10, 1000

💰 Float (Bilangan Desimal)

Untuk menyimpan angka dengan koma

$tinggi = 165.5;
$harga = 25000.75;
$nilai = 87.5;

Contoh: 3.14, 25.5, -10.25

✅ Boolean (Benar/Salah)

Untuk menyimpan nilai benar atau salah

$lulus = true;
$hadir = false;
$aktif = true;

Nilai: true (benar) atau false (salah)

📋 Array (Daftar)

Array seperti daftar belanja - bisa menyimpan banyak item sekaligus!

Array Sederhana:

$buah = array("apel", "jeruk", "pisang");
// atau
$warna = ["merah", "biru", "hijau"];

Mengakses Array:

echo $buah[0]; // apel
echo $buah[1]; // jeruk
echo $buah[2]; // pisang

🔍 Mengecek Tipe Data

PHP punya fungsi untuk mengecek tipe data variabel

<?php
$nama = "Budi";
$umur = 17;

echo gettype($nama); // string
echo gettype($umur); // integer
?>

🗂️ Array Asosiatif

Array yang menggunakan key (kunci) untuk mengakses nilai, seperti kamus!

📚 Membuat Array Asosiatif

<?php
$siswa = array(
  "nama" => "Budi",
  "umur" => 17,
  "kelas" => "XI RPL"
);
// atau
$siswa = [
  "nama" => "Budi",
  "umur" => 17
];
?>

🔍 Mengakses Array Asosiatif

<?php
echo $siswa["nama"]; // Budi
echo $siswa["umur"]; // 17

// Menambah data baru
$siswa["hobi"] = "coding";
?>

🔢 Tipe Data Khusus

🚫 NULL

<?php
$kosong = null;
var_dump($kosong); // NULL

if (is_null($kosong)) {
  echo "Variabel kosong";
}
?>

Menunjukkan tidak ada nilai

📦 Resource

<?php
$file = fopen("data.txt", "r");
echo gettype($file); // resource
fclose($file);
?>

Referensi ke sumber eksternal

🔄 Konversi Tipe Data (Type Casting)

PHP bisa mengubah tipe data secara otomatis atau manual

🤖 Otomatis (Implicit)

<?php
$angka = "10"; // string
$hasil = $angka + 5; // 15 (int)
echo $hasil;
?>

✋ Manual (Explicit)

<?php
$angka = "10.5";
$int = (int)$angka; // 10
$float = (float)$angka; // 10.5
?>

⚠️ Hati-hati: Konversi otomatis bisa menghasilkan hasil yang tidak diharapkan. Selalu periksa tipe data jika diperlukan!

Operator PHP

Simbol untuk melakukan operasi

🧮 Operator Aritmatika

Untuk operasi matematika

+ Penjumlahan 5 + 3 = 8
- Pengurangan 5 - 3 = 2
* Perkalian 5 * 3 = 15
/ Pembagian 6 / 3 = 2
% Sisa Bagi 7 % 3 = 1

🔗 Operator Penggabungan

Untuk menggabungkan string

$nama_depan = "Budi";
$nama_belakang = "Santoso";

$nama_lengkap = $nama_depan . " " . $nama_belakang;
echo $nama_lengkap; // Budi Santoso

Operator: . (titik) untuk menggabungkan string

⚖️ Operator Perbandingan

Untuk membandingkan nilai

== Sama dengan 5 == 5 → true
!= Tidak sama 5 != 3 → true
> Lebih besar 5 > 3 → true
< Lebih kecil 3 < 5 → true

🔄 Operator Assignment

Untuk memberikan nilai

$x = 10;
$x += 5; // $x = $x + 5 = 15
$x -= 3; // $x = $x - 3 = 12
$x *= 2; // $x = $x * 2 = 24

Singkatan: +=, -=, *=, /= untuk operasi cepat

📊 Contoh Penggunaan Operator

Mari lihat operator dalam aksi!

<?php
// Kalkulator sederhana
$angka1 = 10;
$angka2 = 3;

$tambah = $angka1 + $angka2;
$kurang = $angka1 - $angka2;
$kali = $angka1 * $angka2;
$bagi = $angka1 / $angka2;

echo "Hasil penjumlahan: " . $tambah;
echo "Hasil pengurangan: " . $kurang;
?>

🧠 Operator Logika

Operator untuk menggabungkan kondisi boolean

🤝 AND (&&)

<?php
$umur = 17;
$lulus = true;

if ($umur >= 17 && $lulus) {
  echo "Bisa daftar kuliah";
}
?>

Kedua kondisi harus benar

🔀 OR (||)

<?php
$hari = "Sabtu";

if ($hari == "Sabtu" || $hari == "Minggu") {
  echo "Weekend!";
}
?>

Salah satu kondisi benar

🚫 NOT (!)

<?php
$hujan = false;

if (!$hujan) {
  echo "Bisa main di luar";
}
?>

Membalik nilai boolean

🔢 Operator Increment/Decrement

Operator untuk menambah atau mengurangi nilai dengan 1

⬆️ Increment (++)

<?php
$x = 5;

// Pre-increment
echo ++$x; // 6, x menjadi 6

// Post-increment
echo $x++; // 6, lalu x menjadi 7
?>

⬇️ Decrement (--)

<?php
$y = 10;

// Pre-decrement
echo --$y; // 9, y menjadi 9

// Post-decrement
echo $y--; // 9, lalu y menjadi 8
?>

💡 Perbedaan: Pre (++$x) mengubah nilai dulu baru digunakan. Post ($x++) menggunakan nilai dulu baru diubah.

🎯 Operator Ternary

Cara singkat menulis if-else dalam satu baris

📝 Cara Panjang (if-else)

<?php
$nilai = 85;

if ($nilai >= 75) {
  $status = "Lulus";
} else {
  $status = "Tidak Lulus";
}
?>

⚡ Cara Singkat (Ternary)

<?php
$nilai = 85;

$status = ($nilai >= 75) ? "Lulus" : "Tidak Lulus";

echo $status; // Lulus
?>

📖 Format: (kondisi) ? nilai_jika_benar : nilai_jika_salah

🎯 Praktik 1: Biodata Siswa

Mari buat program untuk menampilkan biodata siswa menggunakan variabel dan operator!

📋 Langkah-langkah:

  1. Buat variabel untuk nama, umur, kelas, dan hobi
  2. Hitung tahun lahir berdasarkan umur
  3. Gabungkan semua informasi menjadi kalimat
  4. Tampilkan hasilnya dengan echo
<?php
// Praktik 1: Biodata Siswa
$nama = "Siti Aminah";
$umur = 16;
$kelas = "XI RPL";
$hobi = "coding";

// Hitung tahun lahir
$tahun_sekarang = 2024;
$tahun_lahir = $tahun_sekarang - $umur;

// Tampilkan biodata
echo "=== BIODATA SISWA ===";
echo "Nama: " . $nama;
echo "Umur: " . $umur . " tahun";
echo "Kelas: " . $kelas;
echo "Hobi: " . $hobi;
echo "Tahun Lahir: " . $tahun_lahir;
?>

Output:

🧮 Praktik 2: Kalkulator Nilai

Buat program untuk menghitung rata-rata nilai dan menentukan grade!

📋 Langkah-langkah:

  1. Buat variabel untuk 3 nilai mata pelajaran
  2. Hitung total dan rata-rata nilai
  3. Tentukan grade berdasarkan rata-rata
  4. Tampilkan semua informasi
<?php
// Praktik 2: Kalkulator Nilai
$matematika = 85;
$bahasa_indonesia = 90;
$pemrograman = 95;

// Hitung total dan rata-rata
$total = $matematika + $bahasa_indonesia + $pemrograman;
$rata_rata = $total / 3;

// Tentukan grade
$grade = "A"; // Asumsi nilai bagus

// Tampilkan hasil
echo "=== LAPORAN NILAI ===";
echo "Matematika: " . $matematika;
echo "Bahasa Indonesia: " . $bahasa_indonesia;
echo "Pemrograman: " . $pemrograman;
echo "Total: " . $total;
echo "Rata-rata: " . $rata_rata;
echo "Grade: " . $grade;
?>

Output:

🔧 Praktik 3: Fungsi Sederhana

Mari belajar membuat fungsi untuk mengorganisir kode dengan lebih baik!

📋 Langkah-langkah:

  1. Buat fungsi untuk menghitung luas persegi panjang
  2. Buat fungsi untuk mengkonversi Celsius ke Fahrenheit
  3. Buat fungsi untuk menyapa dengan nama
  4. Panggil semua fungsi dan tampilkan hasilnya
<?php
// Praktik 3: Fungsi Sederhana

// Fungsi menghitung luas persegi panjang
function hitungLuas($panjang, $lebar) {
  return $panjang * $lebar;
}

// Fungsi konversi suhu
function celsiusToFahrenheit($celsius) {
  return ($celsius * 9/5) + 32;
}

// Fungsi sapa
function sapa($nama) {
  return "Halo, " . $nama . "! Selamat belajar PHP!";
}

// Menggunakan fungsi
$luas = hitungLuas(10, 5);
$suhu = celsiusToFahrenheit(25);
$sapaan = sapa("Budi");

echo "Luas persegi panjang: " . $luas . " cm²";
echo "25°C = " . $suhu . "°F";
echo $sapaan;
?>
