Pengenalan Dokumentasi Kode

📚 Apa itu Dokumentasi?

Dokumentasi kode adalah penjelasan tertulis yang menjelaskan apa yang dilakukan oleh kode program. Seperti manual instruksi untuk memahami cara kerja program.

🎯 Mengapa Penting?

  • • Memudahkan pemahaman kode
  • • Mempercepat debugging
  • • Membantu kerja tim
  • • Maintenance lebih mudah

🌟 Analogi Sederhana

🍳 Resep Masakan:

"Tumis bawang hingga harum (sekitar 3 menit)"

⬇️

💻 Kode Program:

"// Hitung total harga dengan pajak 10%"

💡 Fun Fact!

Tahukah kamu? Programmer profesional menghabiskan 60% waktu untuk membaca kode, dan hanya 40% waktu untuk menulis kode baru! Makanya dokumentasi yang baik sangat penting! 🤓

Pengertian Inline Comments

📝 Apa itu Inline Comments?

Inline Comments adalah teks penjelasan yang ditulis di dalam kode program untuk menjelaskan fungsi, tujuan, atau cara kerja bagian tertentu dari kode. Comments tidak dieksekusi oleh komputer, hanya untuk dibaca manusia! 🤖➡️👨‍💻

✅ Karakteristik Comments

  • • Tidak dieksekusi oleh program
  • • Hanya untuk manusia baca
  • • Menjelaskan kode di sekitarnya
  • • Memudahkan pemahaman

🎯 Tujuan Comments

  • • Menjelaskan logika yang rumit
  • • Memberikan konteks
  • • Memperingatkan hal penting
  • • Dokumentasi untuk tim

👀 Contoh Sederhana

// Ini adalah comment - menjelaskan kode di bawahnya
let harga = 50000;

// Hitung diskon 20% untuk member
let diskon = harga * 0.2;

// Total yang harus dibayar
let total = harga - diskon;

🤔 Bandingkan: Dengan vs Tanpa Comments

❌ Tanpa Comments

let x = 50000;
let y = x * 0.2;
let z = x - y;

Susah dipahami! 😵

✅ Dengan Comments

// Harga barang
let x = 50000;
// Diskon 20%
let y = x * 0.2;
// Total bayar
let z = x - y;

Jelas dan mudah! 😊

Jenis-Jenis Comments

1️⃣ Single Line Comments (Komentar Satu Baris)

Digunakan untuk menjelaskan satu baris kode atau memberikan keterangan singkat.

JavaScript / Java / C++:

// Ini adalah single line comment
let nama = "Budi";

let umur = 17; // Umur siswa

Python:

# Ini adalah single line comment
nama = "Budi"

umur = 17 # Umur siswa

2️⃣ Multi Line Comments (Komentar Banyak Baris)

Digunakan untuk penjelasan yang panjang atau dokumentasi detail.

JavaScript / Java / C++:

/*
  Program Kalkulator Sederhana
  Dibuat oleh: Tim SMK
  Tanggal: 2024
  Fungsi: Menghitung operasi dasar
*/

function tambah(a, b) {
  return a + b;
}

Python:

"""
Program Kalkulator Sederhana
Dibuat oleh: Tim SMK
Tanggal: 2024
Fungsi: Menghitung operasi dasar
"""

def tambah(a, b):
    return a + b

3️⃣ Documentation Comments (Komentar Dokumentasi)

Komentar khusus untuk dokumentasi fungsi, class, atau modul yang bisa dibaca oleh tools dokumentasi.

/**
 * Menghitung luas lingkaran
 * @param {number} radius - Jari-jari lingkaran
 * @returns {number} Luas lingkaran
 * @example
 * // Menghitung luas lingkaran dengan radius 5
 * const luas = hitungLuasLingkaran(5);
 */
function hitungLuasLingkaran(radius) {
  // Rumus: π × r²
  return 3.14159 * radius * radius;
}

🤔 Kapan Menggunakan Jenis Comment?

Single Line

  • • Penjelasan singkat
  • • Keterangan variabel
  • • Catatan cepat
  • • TODO items

Multi Line

  • • Header program
  • • Penjelasan algoritma
  • • Lisensi & copyright
  • • Instruksi panjang

Documentation

  • • Dokumentasi fungsi
  • • Parameter & return
  • • Contoh penggunaan
  • • API documentation

Praktik Baik Menulis Comments

✅ Yang HARUS Dilakukan (Do's)

💡 1. Jelaskan MENGAPA, bukan APA

❌ Buruk:

// Tambah 1 ke i
i++;

✅ Baik:

// Pindah ke data berikutnya
i++;

🎯 2. Gunakan bahasa yang jelas dan sederhana

❌ Buruk:

// Implementasi algoritma sorting
// dengan kompleksitas O(n²)

✅ Baik:

// Urutkan data dari kecil ke besar
// menggunakan bubble sort

⚠️ 3. Beri peringatan untuk kode yang tricky

// HATI-HATI: Jangan ubah urutan ini!
// Database harus diinisialisasi dulu sebelum koneksi
initDatabase();
connectToDatabase();

❌ Yang TIDAK Boleh Dilakukan (Don'ts)

🚫 1. Jangan tulis comment yang obvious

// Buruk: Mendeklarasikan variabel nama
let nama = "Budi";

// Buruk: Increment i
i++;

📝 2. Jangan biarkan comment menjadi usang

// Hitung diskon 10% - SALAH! Sekarang 15%
let diskon = harga * 0.15;

💬 3. Jangan gunakan comment untuk debugging

// console.log("debug: nilai x = " + x);
// alert("masuk ke fungsi ini");
// TODO: hapus ini nanti

🏆 Tips Menulis Comment yang Profesional

📋 Format Konsisten

Gunakan format yang sama di seluruh project

🔄 Update Berkala

Selalu update comment saat mengubah kode

🎯 Fokus pada Konteks

Jelaskan konteks dan alasan keputusan

✨ Singkat tapi Jelas

Tidak perlu panjang, yang penting mudah dipahami

🌍 Bahasa Tim

Gunakan bahasa yang dipahami seluruh tim

📚 Dokumentasi Lengkap

Untuk fungsi penting, buat dokumentasi lengkap

🔍 Pemeriksa Kualitas Comments

Hasil Analisis:

🔄 Contoh: Sebelum vs Sesudah

❌ Sebelum (Buruk)

function calc(x, y, z) {
  let a = x * 0.1;
  let b = y + z;
  let c = b - a;
  return c;
}

✅ Sesudah (Baik)

// Hitung total belanja setelah diskon
function hitungTotalBelanja(harga, ongkir, admin) {
  // Diskon 10% dari harga barang
  let diskon = harga * 0.1;
  // Total biaya tambahan
  let biayaTambahan = ongkir + admin;
  // Total yang harus dibayar
  let totalBayar = biayaTambahan - diskon;
  return totalBayar;
}

📊 Perbedaan:

  • • Nama fungsi: calc → hitungTotalBelanja (lebih deskriptif)
  • • Parameter: x, y, z → harga, ongkir, admin (lebih jelas)
  • • Variabel: a, b, c → diskon, biayaTambahan, totalBayar (bermakna)
  • • Comments: Menjelaskan tujuan setiap langkah perhitungan

Tugas Praktik

Kerjakan tugas berikut untuk menguji pemahaman kamu!

1️⃣ Analisis Kode Tanpa Comments

Perhatikan kode berikut yang tidak memiliki comments:

function proses(n) {
  let hasil = 0;
  for (let i = 1; i <= n; i++) {
    hasil += i;
  }
  return hasil;
}

2️⃣ Perbaiki Comments yang Buruk

Kode berikut memiliki comments yang buruk. Perbaiki comments-nya!

// Deklarasi variabel
let harga = 100000;
let jumlah = 3;

// Perkalian
let subtotal = harga * jumlah;

// Tambah pajak
let pajak = subtotal * 0.1;
let total = subtotal + pajak;

// Print hasil
console.log(total);

3️⃣ Buat Program dengan Dokumentasi Lengkap

Buat program sederhana untuk menghitung nilai akhir siswa dengan ketentuan:

Spesifikasi:

  • • Input: Nilai tugas (40%), UTS (30%), UAS (30%)
  • • Output: Nilai akhir dan grade (A/B/C/D/E)
  • • Grade: A(≥85), B(70-84), C(55-69), D(40-54), E(<40)

4️⃣ Refleksi dan Evaluasi

📝 Petunjuk Pengerjaan

  • • Kerjakan semua tugas dengan teliti dan jujur
  • • Gunakan bahasa yang mudah dipahami dalam comments
  • • Pastikan comments menjelaskan MENGAPA, bukan hanya APA
  • • Jika ada yang tidak dipahami, tanyakan kepada guru
  • • Setelah selesai, review kembali jawaban kamu
