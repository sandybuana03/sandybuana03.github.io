👋 Pengenalan JavaScript

🌟 Apa itu JavaScript?

JavaScript adalah bahasa pemrograman yang digunakan untuk membuat website menjadi interaktif. Bayangkan website seperti rumah - HTML adalah strukturnya, CSS adalah cat dan dekorasinya, sedangkan JavaScript adalah listrik yang membuat semuanya hidup!

🚀 Mengapa Penting?

  • • Membuat website interaktif
  • • Validasi form secara real-time
  • • Animasi dan efek visual
  • • Komunikasi dengan server
  • • Membuat aplikasi web modern

📍 Cara Meletakkan JavaScript di HTML

JavaScript bisa ditempatkan di berbagai lokasi dalam file HTML. Mari pelajari cara yang benar!

🏠 Internal JavaScript (Dalam HTML)

JavaScript ditulis langsung di dalam file HTML menggunakan tag <script>

<!DOCTYPE html>
<html lang="id">
<head>
  <title>Contoh JavaScript</title>
</head>
<body>
  <h1>Halo Dunia!</h1>
  <script>
    // JavaScript di sini
    let nama = "Budi";
    console.log("Halo, " + nama);
  </script>
</body>
</html>

📁 External JavaScript (File Terpisah)

JavaScript ditulis di file terpisah (.js) dan dihubungkan ke HTML

File: index.html

<!DOCTYPE html>
<html>
<head>
  <title>Contoh</title>
</head>
<body>
  <h1>Halo!</h1>
  <script src="script.js"></script>
</body>
</html>

File: script.js

// File JavaScript terpisah
let nama = "Siti";
console.log("Halo, " + nama);

📍 Lokasi Penempatan JavaScript

Di <head>

Dimuat sebelum body

✅ Untuk script yang perlu dimuat dulu
❌ Bisa memperlambat loading halaman

Di akhir <body>

Setelah semua HTML

✅ Halaman loading lebih cepat
✅ Paling direkomendasikan

Di tengah <body>

Di antara elemen HTML

⚠️ Jarang digunakan
⚠️ Bisa mengganggu struktur

🎯 Contoh Praktik Terbaik

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Belajar JavaScript</title>
</head>
<body>
  <h1>Selamat Datang!</h1>
  <p id="pesan">Halo Dunia!</p>

    // Ini adalah komentar
    let nama = "Budi";
    console.log("Halo, " + nama);
    
    // Mengubah isi elemen HTML
    document.getElementById("pesan").textContent = "Halo, " + nama + "!";
  </script>
</body>
</html>

📊 Tipe Data JavaScript

Tipe data adalah jenis informasi yang bisa disimpan dalam program. Seperti kotak-kotak dengan label yang berbeda!

🔢 Number (Angka)

Untuk menyimpan angka, baik bulat maupun desimal.

let umur = 17;
let tinggi = 165.5;
let suhu = -5;

📝 String (Teks)

Untuk menyimpan teks atau kata-kata.

let nama = "Siti";
let kelas = 'XII RPL';
let pesan = `Halo ${nama}!`;

✅ Boolean (Benar/Salah)

Hanya memiliki dua nilai: true (benar) atau false (salah).

let sudahLulus = true;
let masihSekolah = false;
let aktif = true;

📋 Array (Daftar)

Untuk menyimpan banyak data dalam satu variabel.

let hobi = ["coding", "gaming", "musik"];
let nilai = [85, 90, 78];

🔍 Mengecek Tipe Data

Gunakan typeof untuk mengetahui tipe data:

console.log(typeof 25); // "number"
console.log(typeof "Halo"); // "string"
console.log(typeof true); // "boolean"

📦 Variabel JavaScript

Variabel adalah wadah untuk menyimpan data. Seperti kotak dengan label yang bisa diisi dan diganti isinya!

🔄 let

Variabel yang bisa diubah nilainya.

let skor = 80;
skor = 90; // Bisa diubah

🔒 const

Variabel yang tidak bisa diubah (konstanta).

const PI = 3.14159;
// PI = 3.14; // Error!

⚠️ var

Cara lama membuat variabel (tidak disarankan).

var nama = "Andi";
// Lebih baik pakai let

💡 Gunakan let atau const saja!

📝 Aturan Penamaan Variabel

✅ Boleh:

  • • Dimulai dengan huruf: nama
  • • Dimulai dengan _: _private
  • • Dimulai dengan $: $element
  • • Menggunakan camelCase: namaLengkap

❌ Tidak Boleh:

  • • Dimulai dengan angka: 1nama
  • • Menggunakan spasi: nama lengkap
  • • Kata kunci JS: let, if
  • • Karakter khusus: nama-siswa

🎯 Praktik Variabel

Mari coba membuat program sederhana dengan variabel:

let namaSiswa = "Budi";
let nilaiMatematika = 85;
let nilaiBahasaInggris = 78;
let rataRata = (nilaiMatematika + nilaiBahasaInggris) / 2;
console.log(`${namaSiswa} memiliki rata-rata: ${rataRata}`);

🔢 Operator JavaScript

Operator adalah simbol yang digunakan untuk melakukan operasi pada data. Seperti kalkulator dalam programming!

➕ Operator Aritmatika

let a = 10;
let b = 3;
console.log(a + b); // Penjumlahan: 13
console.log(a - b); // Pengurangan: 7
console.log(a * b); // Perkalian: 30
console.log(a / b); // Pembagian: 3.33
console.log(a % b); // Sisa bagi: 1

Simbol Operator:

  • + Penjumlahan
  • - Pengurangan
  • * Perkalian
  • / Pembagian
  • % Sisa Bagi (Modulo)

⚖️ Operator Perbandingan

let x = 5;
let y = 10;
console.log(x == y); // false
console.log(x != y); // true
console.log(x < y); // true
console.log(x > y); // false

Simbol Operator:

  • == Sama dengan
  • != Tidak sama dengan
  • < Lebih kecil
  • > Lebih besar
  • <= Lebih kecil sama dengan
  • >= Lebih besar sama dengan

🧠 Operator Logika

let benar = true;
let salah = false;
console.log(benar && salah); // false
console.log(benar || salah); // true
console.log(!benar); // false

Simbol Operator:

  • && AND (Dan)
  • || OR (Atau)
  • ! NOT (Tidak)

AND: Benar jika kedua kondisi benar

OR: Benar jika salah satu benar

NOT: Membalik nilai boolean

📝 Operator Assignment

let skor = 80;
skor += 10; // skor = skor + 10
skor -= 5; // skor = skor - 5
skor *= 2; // skor = skor * 2
console.log(skor); // 170

Simbol Operator:

  • = Assignment biasa
  • += Tambah dan assign
  • -= Kurang dan assign
  • *= Kali dan assign
  • /= Bagi dan assign

🔄 Control Flow JavaScript

Control Flow mengontrol alur jalannya program. Seperti rambu lalu lintas yang menentukan arah perjalanan kode!

🤔 If Statement (Jika)

Menjalankan kode jika kondisi tertentu terpenuhi.

// Input dari pengguna
let input = prompt("Masukkan nilai Anda:");
let nilai = parseInt(input);
if (nilai >= 80) {
  console.log("Selamat! Kamu lulus!");
} else if (nilai >= 60) {
  console.log("Cukup, tapi bisa lebih baik!");
} else {
  console.log("Belajar lebih giat ya!");
}

🎯 Coba Sendiri:

Kondisi:

• nilai >= 80 (Lulus)

• nilai >= 60 (Cukup)

• Selainnya (Tidak Lulus)

🔁 For Loop (Perulangan)

Mengulangi kode sejumlah tertentu.

// Input batas dari pengguna
let input = prompt("Masukkan batas hitungan:");
let batas = parseInt(input);
for (let i = 1; i <= batas; i++) {
  console.log("Hitungan ke-" + i);
}

🎯 Coba Sendiri:

Cara Kerja:

1. Set i = 1

2. Cek i <= batas?

3. Jalankan kode

4. i++ (tambah 1)

5. Ulangi dari step 2

🔄 While Loop

Mengulangi kode selama kondisi masih benar.

// Input countdown dari pengguna
let input = prompt("Masukkan angka countdown:");
let countdown = parseInt(input);
while (countdown > 0) {
  console.log("Countdown: " + countdown);
  countdown--; // Kurangi 1
}
console.log("Selesai!");

🎯 Coba Sendiri:

⚠️ Hati-hati: Pastikan kondisi bisa menjadi false, jika tidak akan loop terus!

🧮 Praktik 1: Kalkulator Sederhana

Buat kalkulator yang bisa menjumlahkan, mengurangkan, mengalikan, dan membagi dua angka.

📝 Langkah-langkah:

  1. Buat variabel untuk menyimpan dua angka
  2. Buat variabel untuk operator (+, -, *, /)
  3. Gunakan if/switch untuk memilih operasi
  4. Tampilkan hasil perhitungan

🎯 Input:

💻 Contoh Kode Lengkap dengan HTML:

<!-- HTML Structure -->
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Kalkulator Sederhana</title>
</head>
<body>
  <h1>🧮 Kalkulator Sederhana</h1>
  <button onclick="jalankanKalkulator()">Mulai Kalkulator</button>
  <script>
    // Fungsi utama kalkulator
    function jalankanKalkulator() {
      // Input dari pengguna menggunakan prompt
      let input1 = prompt("Masukkan angka pertama:");
      let angka1 = parseFloat(input1);
      let operator = prompt("Masukkan operator (+, -, *, /):");
      let input2 = prompt("Masukkan angka kedua:");
      let angka2 = parseFloat(input2);
      // Validasi input
      if (isNaN(angka1) || isNaN(angka2)) {
        alert("Error: Masukkan angka yang valid!");
        return;
      }
      // Proses perhitungan
      let hasil = hitungKalkulator(angka1, operator, angka2);
      // Tampilkan hasil
      alert(`Hasil: ${hasil}`);
      console.log(`Hasil: ${hasil}`);
    }
    // Fungsi untuk melakukan perhitungan
    function hitungKalkulator(angka1, operator, angka2) {
      let hasil;
      if (operator === "+") {
        hasil = angka1 + angka2;
      } else if (operator === "-") {
        hasil = angka1 - angka2;
      } else if (operator === "*") {
        hasil = angka1 * angka2;
      } else if (operator === "/") {
        if (angka2 !== 0) {
          hasil = angka1 / angka2;
        } else {
          return "Error: Tidak bisa bagi nol!";
        }
      } else {
        return "Error: Operator tidak valid!";
      }
      return `${angka1} ${operator} ${angka2} = ${hasil}`;
    }
  </script>
</body>
</html>
🎯 Cara Kerja:
  1. User klik tombol "Mulai Kalkulator"
  2. Muncul prompt untuk input angka pertama
  3. Muncul prompt untuk input operator (+, -, *, /)
  4. Muncul prompt untuk input angka kedua
  5. Program validasi input dan hitung hasil
  6. Tampilkan hasil dengan alert() dan console.log()

📊 Praktik 2: Sistem Penilaian

Buat program yang menentukan grade berdasarkan nilai siswa.

📋 Kriteria Grade:

  • • 90-100: A (Sangat Baik)
  • • 80-89: B (Baik)
  • • 70-79: C (Cukup)
  • • 60-69: D (Kurang)
  • • 0-59: E (Sangat Kurang)

🎯 Input Nilai:

💻 Contoh Kode Lengkap dengan HTML:

<!-- HTML Structure -->
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Sistem Penilaian</title>
</head>
<body>
  <h1>📊 Sistem Penilaian</h1>
  <button onclick="jalankanSistemNilai()">Cek Grade Siswa</button>
  <script>
    // Fungsi utama sistem penilaian
    function jalankanSistemNilai() {
      // Input nama siswa
      let namaSiswa = prompt("Masukkan nama siswa:");
      if (namaSiswa === null || namaSiswa.trim() === "") {
        alert("Nama siswa harus diisi!");
        return;
      }
      // Input nilai dari pengguna
      let inputNilai = prompt("Masukkan nilai siswa (0-100):");
      let nilai = parseFloat(inputNilai);
      // Validasi input
      if (isNaN(nilai) || nilai < 0 || nilai > 100) {
        alert("Error: Masukkan nilai antara 0-100!");
        return;
      }
      // Proses penentuan grade
      let hasilGrade = tentukanGrade(nilai);
      // Tampilkan hasil
      let pesan = `Hasil Penilaian:\nNama: ${namaSiswa}\n${hasilGrade.detail}\n\n${hasilGrade.motivasi}`;
      alert(pesan);
      console.log(pesan);
    }
    // Fungsi untuk menentukan grade
    function tentukanGrade(nilai) {
      let grade, keterangan, motivasi;
      if (nilai >= 90 && nilai <= 100) {
        grade = "A";
        keterangan = "Sangat Baik";
        motivasi = "🌟 Luar biasa! Pertahankan prestasi ini!";
      } else if (nilai >= 80) {
        grade = "B";
        keterangan = "Baik";
        motivasi = "👍 Bagus! Sedikit lagi mencapai nilai A!";
      } else if (nilai >= 70) {
        grade = "C";
        keterangan = "Cukup";
        motivasi = "📚 Cukup baik, tingkatkan lagi belajarnya!";
      } else if (nilai >= 60) {
        grade = "D";
        keterangan = "Kurang";
        motivasi = "⚠️ Perlu belajar lebih giat lagi!";
      } else if (nilai >= 0) {
        grade = "E";
        keterangan = "Sangat Kurang";
        motivasi = "💪 Jangan menyerah! Minta bantuan guru ya!";
      } else {
        return {
          detail: "Nilai tidak valid!",
          motivasi: ""
        };
      }
      return {
        detail: `Nilai: ${nilai} | Grade: ${grade} (${keterangan})`,
        motivasi: motivasi
      };
    }
  </script>
</body>
</html>
🎯 Cara Kerja:
  1. User klik tombol "Cek Grade Siswa"
  2. Muncul prompt untuk input nama siswa
  3. Muncul prompt untuk input nilai (0-100)
  4. Program validasi input dan tentukan grade
  5. Tampilkan hasil dengan grade, keterangan, dan motivasi
  6. Output ditampilkan dengan alert() dan console.log()

✖️ Praktik 3: Tabel Perkalian

Buat program yang menampilkan tabel perkalian menggunakan loop.

🔢 Contoh Output:

5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
...
5 x 10 = 50

🎯 Input:

💻 Contoh Kode:

// Praktik 3: Tabel Perkalian
function buatTabelPerkalian(angka) {
  let hasil = "";
  // Menggunakan for loop untuk perulangan
  for (let i = 1; i <= 10; i++) {
    let perkalian = angka * i;
    hasil += `${angka} x ${i} = ${perkalian}\n`;
  }
  return hasil;
}
// Alternatif dengan while loop:
function tabelPerkalianWhile(angka) {
  let hasil = "";
  let i = 1;
  while (i <= 10) {
    hasil += `${angka} x ${i} = ${angka * i}\n`;
    i++; // Increment i
  }
  return hasil;
}
// Contoh penggunaan:
console.log(buatTabelPerkalian(7));
