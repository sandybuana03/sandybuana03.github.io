Apa itu CSS?

CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan dan gaya halaman web. Bayangkan HTML sebagai kerangka rumah, maka CSS adalah cat, wallpaper, dan dekorasi yang membuatnya indah!

📦 CSS Box Model

Setiap elemen HTML adalah sebuah kotak yang terdiri dari:

  • Content: Isi dari elemen
  • Padding: Ruang di dalam border
  • Border: Garis tepi elemen
  • Margin: Ruang di luar border

🎯 Praktik CSS Selector

Belajar cara memilih elemen HTML dengan tepat!

📋 Langkah-langkah Praktik Selector

1. Element Selector

Memilih semua elemen dengan tag yang sama.

📄HTML:
<h1>Judul Utama</h1>
<p>Ini adalah paragraf</p>
h1 {
  color: blue;
  font-size: 24px;
}

🎮 Demo Interaktif:

Ini adalah heading yang diberi gaya!

Paragraf ini tidak terpengaruh selector h1

2. Class Selector

Memilih elemen berdasarkan nama class (diawali dengan titik).

📄HTML:
<p class="highlight">Teks dengan class highlight</p>
<p>Teks tanpa class</p>
.highlight {
  background-color: yellow;
  padding: 10px;
}

🎮 Demo Interaktif:

Teks ini bisa di-highlight!

Teks ini tidak punya class highlight

3. ID Selector

Memilih elemen berdasarkan ID unik (diawali dengan #).

📄HTML:
<p id="special">Teks dengan ID special</p>
<p>Teks tanpa ID</p>
#special {
  color: red;
  font-weight: bold;
}

🎮 Demo Interaktif:

Teks dengan ID special

Teks biasa tanpa ID

💡 Tips Penting!

  • 🎯 Element selector mempengaruhi SEMUA elemen dengan tag yang sama
  • 🏷️ Class bisa digunakan berkali-kali di berbagai elemen
  • 🆔 ID harus unik, hanya boleh ada satu di seluruh halaman

🌈 Praktik CSS Warna

Belajar bermain dengan warna di CSS!

🎨 Cara Menulis Warna di CSS

1. Nama Warna

📄HTML:
<div class="my-text">Teks berwarna</div>
.my-text {
  color: red;
  background-color: lightblue;
}
Teks merah dengan background biru muda

2. Kode Hex

📄HTML:
<div class="hex-color">Teks dengan hex</div>
.hex-color {
  color: #FF0000;
  background-color: #90EE90;
}
Teks dengan kode hex

3. RGB

📄HTML:
<div class="rgb-color">Teks dengan RGB</div>
.rgb-color {
  color: rgb(255, 0, 0);
  background-color: rgb(144, 238, 144);
}
Teks dengan RGB

4. RGBA (dengan transparansi)

📄HTML:
<div class="rgba-color">Background transparan</div>
.rgba-color {
  background-color: rgba(255, 0, 0, 0.5);
  padding: 10px;
}
Background semi-transparan

📐 Praktik CSS Layout

Belajar mengatur tata letak elemen!

📦 Flexbox - Layout Modern

1. Display Flex

📄HTML:
<div class="container">
  <div class="item">Item 1</div>
  <div class="item">Item 2</div>
  <div class="item">Item 3</div>
</div>
.container {
  display: flex;
  justify-content: center;
  align-items: center;
}
.item {
  padding: 10px;
  margin: 5px;
  background-color: #007bff;
  color: white;
}

2. Grid Layout

📄HTML:
<div class="grid-container">
  <div class="grid-item">1</div>
  <div class="grid-item">2</div>
  <div class="grid-item">3</div>
  <div class="grid-item">4</div>
  <div class="grid-item">5</div>
  <div class="grid-item">6</div>
</div>
.grid-container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 10px;
}
.grid-item {
  padding: 20px;
  text-align: center;
  background-color: #28a745;
  color: white;
}

💡 Tips Layout

  • 🔧 Flexbox cocok untuk layout 1 dimensi (baris atau kolom)
  • 🎯 Grid cocok untuk layout 2 dimensi (baris dan kolom sekaligus)
  • 📱 Selalu pikirkan tampilan di mobile dan desktop

✨ Praktik CSS Animasi

Buat website jadi hidup dengan animasi!

🎭 Jenis-jenis Animasi CSS

1. Transition (Transisi)

📄HTML:
<button class="my-button">Hover Saya!</button>
.my-button {
  background-color: #007bff;
  color: white;
  padding: 10px 20px;
  border: none;
  border-radius: 5px;
  transition: all 0.3s ease;
}
.my-button:hover {
  transform: scale(1.1);
  background-color: #0056b3;
}

🎮 Demo Transition:

2. Animation (Animasi Berulang)

📄HTML:
<div class="bounce-ball"></div>
<div class="spin-star">⭐</div>
<div class="pulse-heart">❤️</div>
@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-20px); }
}
.bounce-ball {
  width: 50px;
  height: 50px;
  background-color: red;
  border-radius: 50%;
  animation: bounce 2s infinite;
}

🎮 Demo Animation:

❤️

3. Transform (Transformasi)

📄HTML:
<div class="transform-box">📦</div>
.transform-box {
  width: 80px;
  height: 80px;
  background: linear-gradient(45deg, #9c27b0, #e91e63);
  border-radius: 10px;
  display: flex;
  align-items: center;
  justify-content: center;
  transition: transform 0.5s;
}
.transform-box:hover {
  transform: rotate(45deg) scale(1.2);
}

🎯 Tips Animasi yang Baik

  • ⚡ Jangan terlalu cepat atau terlalu lambat (0.2s - 0.5s ideal untuk transisi)
  • 🎨 Gunakan animasi untuk memberikan feedback kepada user
  • 📱 Pastikan animasi tidak mengganggu performa di mobile
  • ♿ Berikan opsi untuk mematikan animasi (accessibility)
