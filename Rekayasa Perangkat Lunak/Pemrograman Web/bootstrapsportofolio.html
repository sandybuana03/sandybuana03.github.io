🤔Apa itu Bootstrap?

Bootstrap adalah framework CSS yang membantu kita membuat website dengan cepat dan mudah. Bayangkan Bootstrap seperti "kotak peralatan" yang sudah berisi berbagai komponen siap pakai seperti tombol, navbar, cards, dan sistem grid yang responsif. Dengan Bootstrap, kamu tidak perlu menulis CSS dari nol!

🎨Mengapa Menggunakan Bootstrap?

Hemat Waktu

Tidak perlu menulis CSS dari nol. Tinggal pakai class yang sudah tersedia!

Responsif Otomatis

Website otomatis menyesuaikan tampilan di berbagai ukuran layar.

Konsisten

Tampilan website akan konsisten di semua browser.

Komponen Lengkap

Tersedia banyak komponen siap pakai seperti navbar, cards, buttons, dll.

📋Yang Perlu Kamu Siapkan

  • 💻 Komputer atau laptop
  • 🌐 Koneksi internet
  • 📝 Text editor (VS Code, Sublime Text, atau Notepad++)
  • 🔍 Browser (Chrome, Firefox, atau Edge)
  • ☕ Semangat belajar dan secangkir kopi/teh!
  • 🎯 Kemauan untuk berlatih

📁Langkah 1: Buat Folder Project

1
Buat folder baru di komputer kamu

💡 Tips: Pilih lokasi yang mudah diingat seperti Desktop atau Documents. Nama folder sebaiknya tidak menggunakan spasi atau karakter khusus.

2

Cara di Mac:
  1. Buka Terminal
  2. Navigasi ke folder project
  3. Ketik: touch index.html

🧭 Membuat Navbar Responsif

Buat menu navigasi yang keren, responsif, dan mudah digunakan!

🎯Apa itu Navbar dan Mengapa Penting?

Navbar (Navigation Bar) adalah menu navigasi yang biasanya ada di bagian atas website. Navbar membantu pengunjung untuk berpindah antar halaman atau section dengan mudah. Di Bootstrap, navbar sudah responsif otomatis - artinya di HP akan jadi hamburger menu! 🍔

🖥️ Di Desktop:
  • Menu horizontal
  • Semua menu terlihat
  • Hover effects
📱 Di Mobile:
  • Hamburger menu (☰)
  • Menu collapse/expand
  • Touch-friendly

1
Ganti navbar sederhana dengan yang lebih keren

  • me-1, me-2: Margin kanan untuk spacing ikon

🎮Langkah 3: Tambahkan JavaScript untuk Interaktivitas

3
Buat navbar yang interaktif dan smart

Tambahkan script ini sebelum tag </body> (setelah Bootstrap JavaScript):

JavaScript - Navbar Interaktif
<script> // Navbar scroll effect window.addEventListener('scroll', function() { const navbar = document.querySelector('.navbar'); if (window.scrollY > 50) { navbar.classList.add('scrolled'); } else { navbar.classList.remove('scrolled'); } }); // Active menu berdasarkan scroll position window.addEventListener('scroll', function() { let current = ''; const sections = document.querySelectorAll('section'); sections.forEach(section => { const sectionTop = section.offsetTop; const sectionHeight = section.clientHeight; if (scrollY >= (sectionTop - 200)) { current = section.getAttribute('id'); } }); // Update active menu const navLinks = document.querySelectorAll('.navbar-nav .nav-link'); navLinks.forEach(link => { link.classList.remove('active'); if (link.getAttribute('href') === '#' + current) { link.classList.add('active'); } }); }); // Auto close navbar saat klik menu di mobile const navLinks = document.querySelectorAll('.nav-link'); const navbarCollapse = document.querySelector('.navbar-collapse'); navLinks.forEach(link => { link.addEventListener('click', () => { if (navbarCollapse.classList.contains('show')) { const bsCollapse = new bootstrap.Collapse(navbarCollapse); bsCollapse.hide(); } }); }); // Smooth scroll untuk semua anchor links document.querySelectorAll('a[href^="#"]').forEach(anchor => { anchor.addEventListener('click', function (e) { e.preventDefault(); const target = document.querySelector(this.getAttribute('href')); if (target) { target.scrollIntoView({ behavior: 'smooth', block: 'start' }); } }); }); </script>
