📚 Pengenalan Bootstrap

🤖 Apa itu Bootstrap?

Bootstrap adalah framework CSS yang paling populer di dunia untuk membuat website yang responsif dan mobile-first. Framework ini dikembangkan oleh Twitter dan sekarang digunakan oleh jutaan developer.

🎯 Keunggulan Bootstrap:

  • Responsif: Otomatis menyesuaikan tampilan di berbagai ukuran layar
  • Mudah digunakan: Cukup tambahkan class CSS
  • Komponen lengkap: Button, navbar, card, modal, dll
  • Dokumentasi lengkap: Mudah dipelajari
  • Komunitas besar: Banyak tutorial dan bantuan

🛠️ Cara Menggunakan Bootstrap

Ada beberapa cara untuk menggunakan Bootstrap:

1. CDN (Content Delivery Network) - Cara Termudah

📐 Sistem Grid Bootstrap

🧩 Apa itu Grid System?

Grid system adalah sistem layout Bootstrap yang membagi layar menjadi 12 kolom. Sistem ini memungkinkan kita membuat layout yang responsif dengan mudah.

📏 Konsep Dasar Grid:

  • Container: Pembungkus utama (.container atau .container-fluid)
  • Row: Baris horizontal (.row)
  • Column: Kolom vertikal (.col-*)
  • 12 Kolom: Setiap baris dibagi menjadi maksimal 12 kolom

📱 Breakpoint Responsif

bootstrap-breakpoints.css
1xs (extra small): < 576px 2sm (small): ≥ 576px 3md (medium): ≥ 768px 4lg (large): ≥ 992px 5xl (extra large): ≥ 1200px 6xxl (extra extra large): ≥ 1400px

🎨 Utility Classes Bootstrap

⚡ Apa itu Utility Classes?

Utility classes adalah class CSS siap pakai untuk styling cepat. Dengan utility classes, kita bisa mengatur margin, padding, warna, text alignment, dan lainnya tanpa menulis CSS custom.

📏 Spacing (Jarak)

Format: {property}{sides}-{size}

  • Property: m (margin), p (padding)
  • Sides: t (top), b (bottom), s (start/left), e (end/right), x (horizontal), y (vertical)
  • Size: 0, 1, 2, 3, 4, 5 (semakin besar semakin lebar)

Contoh Spacing:

.p-3 - Padding sedang di semua sisi
.px-5 .py-2 - Padding horizontal besar, vertikal kecil

🎨 Colors (Warna)

.text-primary .text-success .text-danger .text-warning

📝 Text Utilities

.text-start - Teks rata kiri

.text-center - Teks rata tengah

.text-end - Teks rata kanan

.fw-bold - Teks tebal

.fst-italic - Teks miring

📝 Tugas Bootstrap

🎯 Instruksi Tugas

Buatlah website portfolio pribadi menggunakan Bootstrap dengan ketentuan berikut:

📋 Soal 1: Struktur Dasar (25 poin)

Buatlah struktur HTML dasar dengan:

  • DOCTYPE HTML5 yang benar
  • Meta viewport untuk responsif
  • Link CDN Bootstrap CSS dan JS
  • Title yang sesuai

Jelaskan mengapa meta viewport penting untuk website responsif!

🧭 Soal 2: Navbar Responsif (25 poin)

Buatlah navbar dengan fitur:

  • Brand/logo di sebelah kiri
  • Menu navigasi di sebelah kanan
  • Hamburger menu untuk mobile
  • Minimal 4 menu item

Apa perbedaan antara navbar-expand-lg dan navbar-expand-md?

📐 Soal 3: Layout Grid (25 poin)

Buatlah section "Tentang Saya" dengan layout:

  • Di desktop: foto profil (4 kolom) + deskripsi (8 kolom)
  • Di tablet: foto profil (6 kolom) + deskripsi (6 kolom)
  • Di mobile: foto dan deskripsi full width (12 kolom)

Tuliskan class Bootstrap yang tepat untuk layout ini!

🃏 Soal 4: Komponen dan Styling (25 poin)

Tambahkan komponen berikut:

  • 3 buah card untuk menampilkan skill/hobi
  • Button dengan berbagai varian warna
  • Alert untuk menampilkan informasi penting
  • Form kontak sederhana

Sebutkan 5 class utility Bootstrap yang kalian gunakan dan fungsinya!

📤 Cara Pengumpulan:

  1. Buat file HTML dengan nama: portfolio_[nama_kalian].html
  2. Pastikan website bisa dibuka dan responsif
  3. Jawab semua pertanyaan essay dalam file terpisah
  4. Kumpulkan kedua file tersebut

🏆 Kriteria Penilaian:

  • Fungsionalitas (40%): Website berjalan dengan baik
  • Responsivitas (30%): Tampil baik di berbagai ukuran layar
  • Kode (20%): Struktur HTML dan penggunaan Bootstrap yang benar
  • Kreativitas (10%): Desain menarik dan konten original
