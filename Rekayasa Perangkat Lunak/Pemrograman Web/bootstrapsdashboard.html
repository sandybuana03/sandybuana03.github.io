Bootstrap Dashboard Admin

Tutorial Lengkap untuk Siswa SMK - Step by Step

🎯

Selamat Datang di Tutorial Bootstrap Dashboard!

Halo teman-teman! Kali ini kita akan belajar membuat Dashboard Admin yang keren menggunakan Bootstrap. Dashboard ini akan terlihat profesional dan bisa digunakan untuk berbagai keperluan seperti sistem manajemen sekolah, toko online, atau aplikasi web lainnya.

Apa itu Dashboard Admin?
Dashboard Admin adalah halaman utama yang digunakan administrator untuk mengelola sistem. Biasanya berisi menu navigasi, statistik, dan berbagai fitur pengelolaan data.
📚

Apa yang Akan Kita Pelajari?

  • Struktur HTML untuk dashboard yang rapi
  • Bootstrap Components seperti navbar, sidebar, cards
  • Layout Responsif yang bagus di HP dan komputer
  • Styling CSS untuk tampilan yang menarik
  • JavaScript untuk interaksi menu mobile
🎨

Hasil Akhir yang Akan Kita Buat

Dashboard yang akan kita buat memiliki fitur-fitur berikut:

Navbar atas dengan logo dan menu user
Sidebar kiri dengan menu navigasi
Area konten untuk menampilkan data
Responsif untuk semua ukuran layar
Persiapan Belajar:
Pastikan kalian sudah memahami dasar-dasar HTML, CSS, dan sedikit JavaScript. Jika belum, tidak masalah! Tutorial ini akan dijelaskan step by step dengan bahasa yang mudah dipahami.
Mulai Belajar
1

Membuat Struktur Folder Project

Pertama-tama, kita buat folder untuk project kita. Struktur folder yang rapi akan memudahkan kita dalam mengorganisir file-file project.

Buat struktur folder seperti ini:
Struktur Folder Project
dashboard-admin/ ├── index.html ├── css/ │ └── style.css ├── js/ │ └── script.js └── img/ └── (gambar-gambar jika ada)
2

Membuat File HTML Dasar

Sekarang kita buat file index.html dengan struktur HTML dasar dan link ke Bootstrap CDN.

index.html
<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Dashboard Admin</title> <!-- Bootstrap CSS --> <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet"> <!-- Font Awesome untuk ikon --> <link href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css" rel="stylesheet"> <!-- Custom CSS --> <link href="css/style.css" rel="stylesheet"> </head> <body> <div class="wrapper"> <!-- Konten dashboard akan kita tambahkan di sini --> <h1>Dashboard Admin</h1> <p>Selamat datang di dashboard admin!</p> </div> <!-- Bootstrap JS --> <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script> <!-- Custom JS --> <script src="js/script.js"></script> </body> </html>
Penjelasan Kode:
• Bootstrap CDN: Kita pakai Bootstrap 5.3.0 dari internet, jadi tidak perlu download file
• Font Awesome CDN: Library ikon gratis untuk membuat dashboard lebih menarik
• viewport meta tag: Agar website responsif dan terlihat bagus di HP
• lang="id": Menandakan bahasa Indonesia untuk SEO dan accessibility

• dropdown: Menu dropdown untuk notifikasi dan user dengan Bootstrap JS
• badge: Indikator jumlah notifikasi dengan positioning absolute
• navbar-toggler: Tombol hamburger untuk mobile sidebar toggle

Membuat Toggle Sidebar untuk Mobile

Sekarang kita akan membuat fungsi JavaScript untuk menampilkan/menyembunyikan sidebar di perangkat mobile.

js/script.js - Tambahkan fungsi toggle sidebar
// JavaScript untuk Dashboard Admin document.addEventListener('DOMContentLoaded', function() { console.log('Dashboard Admin siap digunakan!'); // Toggle Sidebar untuk Mobile const sidebarToggle = document.getElementById('sidebarToggle'); const sidebar = document.getElementById('sidebar'); const mainContent = document.querySelector('.main-content'); // Fungsi untuk toggle sidebar function toggleSidebar() { sidebar.classList.toggle('show'); // Tambahkan overlay untuk mobile if (sidebar.classList.contains('show')) { createOverlay(); } else { removeOverlay(); } } // Event listener untuk tombol toggle if (sidebarToggle) { sidebarToggle.addEventListener('click', toggleSidebar); } // Fungsi untuk membuat overlay function createOverlay() { const overlay = document.createElement('div'); overlay.className = 'sidebar-overlay'; overlay.addEventListener('click', function() { sidebar.classList.remove('show'); removeOverlay(); }); document.body.appendChild(overlay); } // Fungsi untuk menghapus overlay function removeOverlay() { const overlay = document.querySelector('.sidebar-overlay'); if (overlay) { overlay.remove(); } } // Tutup sidebar saat window di-resize ke desktop window.addEventListener('resize', function() { if (window.innerWidth > 768) { sidebar.classList.remove('show'); removeOverlay(); } }); // Active menu highlighting const menuLinks = document.querySelectorAll('.menu-link'); menuLinks.forEach(link => { link.addEventListener('click', function(e) { e.preventDefault(); // Remove active class from all menu items document.querySelectorAll('.menu-item').forEach(item => { item.classList.remove('active'); }); // Add active class to clicked menu item this.parentElement.classList.add('active'); // Close sidebar on mobile after clicking menu if (window.innerWidth <= 768) { sidebar.classList.remove('show'); removeOverlay(); } }); }); });
