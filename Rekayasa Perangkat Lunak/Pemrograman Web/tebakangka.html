Konsep Game

Game tebak angka adalah permainan sederhana dimana:

  • 🎯 Komputer memilih angka rahasia (1-100)
  • 🤔 Pemain menebak angka tersebut
  • 💡 Sistem memberi petunjuk "terlalu besar" atau "terlalu kecil"
  • 🏆 Pemain menang jika berhasil menebak!

Prasyarat

Pastikan kamu sudah memahami dasar-dasar HTML dan memiliki web server (XAMPP/WAMP) yang sudah terinstall.

Struktur Dasar Game

Mari buat file utama dan struktur dasar game kita!

Langkah 1: Buat File index.php

Buat file baru bernama index.php dan ketik kode berikut:

📄 index.php 
<?php
// Memulai session untuk menyimpan data game
session_start();

// Jika belum ada angka rahasia, buat yang baru
if (!isset($_SESSION['angka_rahasia'])) {
    $_SESSION['angka_rahasia'] = rand(1, 100);
    $_SESSION['percobaan'] = 0;
    $_SESSION['pesan'] = 'Selamat datang! Tebak angka antara 1-100';
}

$pesan = $_SESSION['pesan'];
$percobaan = $_SESSION['percobaan'];
?>

💡 Penjelasan Kode:

  • session_start(): Memulai session PHP untuk menyimpan data
  • $_SESSION: Array untuk menyimpan data yang persisten
  • rand(1, 100): Membuat angka acak antara 1-100

Logika Game

Sekarang mari tambahkan logika untuk menebak angka!

Langkah 1: Tambahkan Logika PHP

Ganti bagian PHP di awal file dengan kode berikut:

📄 index.php (bagian PHP) 
<?php
session_start();

// Inisialisasi game baru
if (!isset($_SESSION['angka_rahasia'])) {
    $_SESSION['angka_rahasia'] = rand(1, 100);
    $_SESSION['percobaan'] = 0;
    $_SESSION['pesan'] = 'Selamat datang! Tebak angka antara 1-100';
    $_SESSION['status'] = 'playing';
}

// Proses tebakan pemain
if (isset($_POST['tebakan']) && $_SESSION['status'] == 'playing') {
    $tebakan = (int)$_POST['tebakan'];
    $angka_rahasia = $_SESSION['angka_rahasia'];
    
    // Validasi input
    if ($tebakan < 1 || $tebakan > 100) {
        $_SESSION['pesan'] = "❌ Masukkan angka antara 1-100!";
    } else {
        $_SESSION['percobaan']++;
        
        if ($tebakan == $angka_rahasia) {
            $_SESSION['pesan'] = "🎉 Selamat! Kamu berhasil menebak angka " . $angka_rahasia . " dalam " . $_SESSION['percobaan'] . " percobaan!";
            $_SESSION['status'] = 'won';
        } elseif ($tebakan < $angka_rahasia) {
            $_SESSION['pesan'] = "📈 Terlalu kecil! Coba angka yang lebih besar.";
        } else {
            $_SESSION['pesan'] = "📉 Terlalu besar! Coba angka yang lebih kecil.";
        }
    }
}

// Reset game
if (isset($_POST['reset'])) {
    session_destroy();
    header('Location: index.php');
    exit();
}

$pesan = $_SESSION['pesan'];
$percobaan = $_SESSION['percobaan'];
$status = $_SESSION['status'];
?>

💡 Penjelasan Logika:

  • Kondisi menang: Jika tebakan sama dengan angka rahasia
  • Petunjuk: Memberikan clue "terlalu besar" atau "terlalu kecil"
  • Counter: Menghitung jumlah percobaan
  • Reset: Menghapus session untuk game baru

Langkah 2: Tambahkan Form Input

Ganti bagian HTML body dengan kode berikut:

📄 index.php (bagian body) 
<body>
    <div class="container">
        <h1>🎯 Game Tebak Angka</h1>
        
        <div class="info">
            <p class="message"><?php echo $pesan; ?></p>
            <p>Percobaan: <strong><?php echo $percobaan; ?></strong></p>
        </div>
        
        <?php if ($status == 'playing'): ?>
        <form method="POST">
            <input type="number" name="tebakan" min="1" max="100" 
                   placeholder="Masukkan angka (1-100)" required>
            <button type="submit">🎯 Tebak!</button>
        </form>
        <?php else: ?>
        <form method="POST">
            <button type="submit" name="reset">🔄 Main Lagi</button>
        </form>
        <?php endif; ?>
    </div>
</body>

Langkah 3: Troubleshooting & Tips

🔧 Masalah Umum & Solusi:

Error "session_start()":
Pastikan tidak ada output (echo/HTML) sebelum session_start()
Halaman blank/kosong:
Cek error di browser (F12 → Console) atau aktifkan error reporting PHP
Form tidak submit:
Pastikan method="POST" dan name attribute sudah benar

🚀 Tips Optimasi:

  • • Tambahkan validasi input untuk mencegah error
  • • Gunakan htmlspecialchars() untuk keamanan
  • • Tambahkan komentar pada kode untuk dokumentasi
  • • Test di berbagai browser dan perangkat
  • • Buat backup kode sebelum modifikasi besar
