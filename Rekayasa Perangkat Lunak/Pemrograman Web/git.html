Apa itu Git?

🤖 Definisi Git

Git adalah sistem kontrol versi (version control system) yang membantu kamu melacak perubahan pada file-file dalam proyekmu. Seperti diary untuk kode kamu! 📖

Analogi Sederhana:

Bayangkan kamu menulis novel. Setiap kali kamu selesai menulis satu bab, kamu menyimpan salinannya dengan nama "Novel_Bab1.docx", "Novel_Bab2.docx", dst. Git melakukan hal yang sama, tapi lebih pintar! 🧠

⭐ Mengapa Git Penting?

🔄

Tracking Changes

Melacak setiap perubahan yang kamu buat

👥

Collaboration

Bekerja sama dengan tim tanpa konflik

⏰

Time Machine

Kembali ke versi sebelumnya kapan saja

🛡️

Backup

Instalasi Git

🪟 Windows

  1. 1 Kunjungi git-scm.com/download/win
  2. 2 Download installer sesuai sistem (32-bit/64-bit)
  3. 3 Jalankan installer dan ikuti petunjuk
  4. 4 Pilih "Git Bash Here" saat instalasi

🐧 Linux/Mac

Terminal
# Ubuntu/Debian
sudo apt-get install git

# Mac (dengan Homebrew)
brew install git

✅ Verifikasi Instalasi

Buka terminal/command prompt dan ketik:

Command Prompt / Terminal
$ git --version
git version 2.34.1

Jika muncul versi Git, berarti instalasi berhasil! 🎉

👤 Konfigurasi Awal

Setelah instalasi, kamu perlu mengatur identitas:

Terminal
$ git config --global user.name "Nama Kamu"
$ git config --global user.email "email@kamu.com"

💡 Tips: Gunakan nama dan email yang sama dengan akun GitHub kamu!

📁

Repository Git

🏠 Apa itu Repository?

Repository (atau "repo") adalah folder khusus yang menyimpan proyekmu beserta seluruh history perubahannya. Seperti rumah untuk kode kamu! 🏠

Analogi:

Bayangkan repository seperti album foto. Setiap foto adalah commit (snapshot), dan album menyimpan semua foto dengan urutan waktu yang jelas! 📸

🆕 Membuat Repository Baru

Metode 1: Dari Folder Kosong

Terminal
$ mkdir proyek-saya
$ cd proyek-saya
$ git init

Metode 2: Clone dari GitHub

Terminal
$ git clone https://github.com/username/repo-name.git

🔍 Struktur Repository

proyek-saya/
├── .git/ (folder tersembunyi - jangan dihapus!)
├── index.html
├── style.css
└── script.js

⚠️ Penting: Folder .git berisi semua data Git. Jangan pernah dihapus!

📊 Status Repository

Untuk melihat status file dalam repository:

Terminal
$ git status

On branch main
Your branch is up to date with 'origin/main'.

nothing to commit, working tree clean
Untracked files (file baru)
Modified files (file yang diubah)
Staged files (siap di-commit)

🎮 Demo Interaktif

Klik tombol di atas untuk melihat demo! 👆
💾

Git Commit

📸 Apa itu Commit?

Commit adalah seperti mengambil foto (snapshot) dari proyekmu pada saat tertentu. Setiap commit menyimpan perubahan yang kamu buat beserta pesan yang menjelaskan apa yang berubah.

Analogi:

Seperti save game! Setiap kali kamu mencapai checkpoint penting, kamu save. Kalau ada masalah, kamu bisa load dari save point terakhir! 🎮

📋 Langkah-langkah Commit

1

Add (Staging)

Pilih file yang ingin di-commit

Terminal
$ git add nama-file.txt
# atau untuk semua file:
$ git add .
2

Commit

Simpan perubahan dengan pesan

Terminal
$ git commit -m "Pesan commit yang jelas"

✍️ Tips Pesan Commit yang Baik

✅ Contoh Baik:

  • • "Tambah fitur login"
  • • "Perbaiki bug pada navbar"
  • • "Update styling homepage"
  • • "Hapus file yang tidak terpakai"

❌ Contoh Buruk:

  • • "update"
  • • "fix"
  • • "asdfgh"
  • • "commit lagi"

💡 Tips: Tulis pesan seolah-olah melengkapi kalimat "Commit ini akan..."

Git Push

🚀 Apa itu Push?

Push adalah proses mengirim commit dari komputer lokal kamu ke server remote (seperti GitHub). Seperti upload file, tapi lebih pintar! 📤

Analogi:

Bayangkan kamu menulis diary di buku. Push seperti memfotokopi halaman diary kamu dan menyimpannya di brankas bank yang aman! 🏦

🔗 Menghubungkan ke Remote

1. Tambah Remote Origin

Terminal
$ git remote add origin https://github.com/username/repo-name.git

2. Cek Remote

Terminal
$ git remote -v
origin https://github.com/username/repo-name.git (fetch)
origin https://github.com/username/repo-name.git (push)

📤 Cara Push

Push Pertama Kali

Terminal
$ git push -u origin main

Flag -u mengatur upstream, jadi next time cukup git push

Push Selanjutnya

Terminal
$ git push

🔄 Workflow Lengkap

1
Edit file di komputer
2
git add . - staging file
3
git commit -m "pesan" - simpan perubahan
4
git push - kirim ke GitHub

Contoh Lengkap:

Terminal
$ git add .
$ git commit -m "Tambah halaman about"
$ git push

Enumerating objects: 5, done.
Counting objects: 100% (5/5), done.
Writing objects: 100% (3/3), 285 bytes | 285.00 KiB/s, done.
Total 3 (delta 0), reused 0 (delta 0)
To https://github.com/username/repo-name.git
abc1234..def5678 main -> main

⚠️ Troubleshooting Push

Error: "Updates were rejected"

Artinya ada perubahan di remote yang belum kamu pull.

Solusi
$ git pull origin main
$ git push

Error: "Authentication failed"

Masalah login GitHub. Gunakan Personal Access Token.

Buat token di GitHub Settings → Developer settings → Personal access tokens

Tugas Praktik

Saatnya mempraktikkan apa yang sudah kamu pelajari!

🎯 Tugas 1: Membuat Repository Pertama

Langkah-langkah:

  1. 1 Buat folder baru bernama "proyek-git-saya"
  2. 2 Inisialisasi Git dengan perintah git init
  3. 3 Buat file "README.md" dan tulis perkenalan diri kamu
  4. 4 Add dan commit file tersebut dengan pesan yang jelas

💡 Tips:

Gunakan pesan commit yang deskriptif seperti "Tambah file README dengan perkenalan diri"

🌐 Tugas 2: Push ke GitHub

Langkah-langkah:

  1. 1 Buat repository baru di GitHub dengan nama "proyek-git-saya"
  2. 2 Hubungkan repository lokal dengan GitHub menggunakan git remote add origin
  3. 3 Push commit pertama kamu ke GitHub
  4. 4 Verifikasi bahwa file README.md muncul di halaman GitHub repository kamu

🔄 Tugas 3: Workflow Lengkap

Skenario:

Kamu diminta membuat website sederhana dengan 3 file: index.html, style.css, dan script.js

Yang harus kamu lakukan:

  1. 1 Buat file index.html dengan struktur HTML dasar
  2. 2 Commit dengan pesan "Tambah struktur HTML dasar"
  3. 3 Buat file style.css dengan styling sederhana
  4. 4 Commit dengan pesan "Tambah styling CSS"
  5. 5 Buat file script.js dengan JavaScript sederhana
  6. 6 Commit dengan pesan "Tambah interaktivitas JavaScript"
  7. 7 Push semua commit ke GitHub
