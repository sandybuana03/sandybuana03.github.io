Apa itu Shopping Cart?

Shopping Cart atau keranjang belanja adalah fitur di website toko online yang memungkinkan pembeli untuk menyimpan produk sementara sebelum melakukan pembelian.

Analogi Sederhana:

Seperti keranjang di supermarket! Kamu ambil barang, masukkan ke keranjang, bisa tambah atau kurangi, lalu bayar di kasir. 🛒

Langkah 1: Persiapan Project

Buat Struktur Folder

Pertama, kita buat folder project dan struktur file yang rapi:

📁 Struktur Folder
shopping-cart/ ├── index.php (halaman utama) ├── cart.php (halaman keranjang) ├── config.php (konfigurasi database) ├── functions.php (fungsi-fungsi PHP) ├── css/ │ └── style.css (file CSS) └── images/ (folder gambar produk)

Buat File config.php

File ini untuk koneksi ke database MySQL:

config.php
<?php // Konfigurasi database $host = 'localhost'; // Server database $username = 'root'; // Username MySQL $password = ''; // Password MySQL (kosong di XAMPP) $database = 'shopping_cart'; // Nama database // Buat koneksi $conn = new mysqli($host, $username, $password, $database); // Cek koneksi if ($conn->connect_error) { die("Koneksi gagal: " . $conn->connect_error); } // Set charset UTF-8 untuk bahasa Indonesia $conn->set_charset("utf8"); echo "Koneksi berhasil! 🎉"; ?>

Langkah Praktik

  1. 1 Buka XAMPP dan nyalakan Apache + MySQL
  2. 2 Buat folder "shopping-cart" di htdocs
  3. 3 Buat file config.php dan copy kode di atas
  4. 4 Test dengan buka: localhost/shopping-cart/config.php

Langkah 2: Setup Database

Buat Database dan Tabel

Kita perlu database untuk menyimpan data produk:

database.sql
-- Buat database baru CREATE DATABASE shopping_cart; -- Gunakan database USE shopping_cart; -- Buat tabel produk CREATE TABLE products ( id INT AUTO_INCREMENT PRIMARY KEY, name VARCHAR(100) NOT NULL, price DECIMAL(10,2) NOT NULL, image VARCHAR(255), description TEXT, stock INT DEFAULT 0, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ); -- Insert data contoh produk INSERT INTO products (name, price, image, description, stock) VALUES ('Laptop Gaming', 15000000, 'laptop.jpg', 'Laptop gaming dengan spek tinggi', 10), ('Mouse Wireless', 250000, 'mouse.jpg', 'Mouse wireless ergonomis', 25), ('Keyboard Mechanical', 800000, 'keyboard.jpg', 'Keyboard mechanical RGB', 15), ('Headset Gaming', 500000, 'headset.jpg', 'Headset gaming dengan mic', 20);

Struktur Tabel Products

Field Type Keterangan
id INT ID unik produk (auto increment)
name VARCHAR(100) Nama produk
price DECIMAL(10,2) Harga produk
image VARCHAR(255) Nama file gambar
stock INT Jumlah stok tersedia

Langkah Praktik

  1. 1 Buka phpMyAdmin di browser: localhost/phpmyadmin
  2. 2 Klik tab "SQL" di phpMyAdmin
  3. 3 Copy-paste kode SQL di atas
  4. 4 Klik "Go" untuk menjalankan
  5. 5 Cek apakah database dan tabel sudah terbuat

Langkah 4: Fungsi Keranjang

Buat File functions.php

File untuk fungsi-fungsi keranjang belanja:

functions.php
<?php // Fungsi untuk menambah produk ke keranjang function addToCart($product_id, $quantity = 1) { // Jika keranjang belum ada, buat array kosong if (!isset($_SESSION['cart'])) { $_SESSION['cart'] = array(); } // Jika produk sudah ada di keranjang, tambah quantity if (isset($_SESSION['cart'][$product_id])) { $_SESSION['cart'][$product_id] += $quantity; } else { // Jika produk belum ada, tambah baru $_SESSION['cart'][$product_id] = $quantity; } return true; } // Fungsi untuk menghitung total item di keranjang function getCartCount() { if (!isset($_SESSION['cart'])) { return 0; } $count = 0; foreach ($_SESSION['cart'] as $quantity) { $count += $quantity; } return $count; } // Fungsi untuk menghitung total harga function getCartTotal($conn) { if (!isset($_SESSION['cart']) || empty($_SESSION['cart'])) { return 0; } $total = 0; $product_ids = implode(',', array_keys($_SESSION['cart'])); $query = "SELECT id, price FROM products WHERE id IN ($product_ids)"; $result = $conn->query($query); while ($product = $result->fetch_assoc()) { $quantity = $_SESSION['cart'][$product['id']]; $total += $product['price'] * $quantity; } return $total; } // Fungsi untuk menghapus item dari keranjang function removeFromCart($product_id) { if (isset($_SESSION['cart'][$product_id])) { unset($_SESSION['cart'][$product_id]); return true; } return false; } ?>

Buat File add_to_cart.php

File untuk memproses penambahan produk ke keranjang:

add_to_cart.php
<?php session_start(); include 'config.php'; include 'functions.php'; // Cek apakah ada data POST if ($_POST['product_id']) { $product_id = (int)$_POST['product_id']; $quantity = isset($_POST['quantity']) ? (int)$_POST['quantity'] : 1; // Cek apakah produk ada dan stok cukup $query = "SELECT * FROM products WHERE id = $product_id AND stock >= $quantity"; $result = $conn->query($query); if ($result->num_rows > 0) { // Tambah ke keranjang if (addToCart($product_id, $quantity)) { $response = array( 'success' => true, 'message' => 'Produk berhasil ditambahkan ke keranjang!', 'cart_count' => getCartCount() ); } else { $response = array( 'success' => false, 'message' => 'Gagal menambahkan produk ke keranjang!' ); } } else { $response = array( 'success' => false, 'message' => 'Produk tidak tersedia atau stok tidak cukup!' ); } } else { $response = array( 'success' => false, 'message' => 'Data tidak valid!' ); } // Return response dalam format JSON header('Content-Type: application/json'); echo json_encode($response); ?>

Tambah JavaScript di index.php

Tambahkan kode JavaScript ini sebelum </body> di index.php:

JavaScript untuk index.php
<script> // Fungsi untuk menambah produk ke keranjang function addToCart(productId) { // Buat form data const formData = new FormData(); formData.append('product_id', productId); formData.append('quantity', 1); // Kirim request ke server fetch('add_to_cart.php', { method: 'POST', body: formData }) .then(response => response.json()) .then(data => { if (data.success) { // Update jumlah item di keranjang document.getElementById('cart-count').textContent = data.cart_count; // Tampilkan pesan sukses alert('✅ ' + data.message); } else { // Tampilkan pesan error alert('❌ ' + data.message); } }) .catch(error => { console.error('Error:', error); alert('❌ Terjadi kesalahan!'); }); } // Update jumlah keranjang saat halaman dimuat window.onload = function() { fetch('get_cart_count.php') .then(response => response.json()) .then(data => { document.getElementById('cart-count').textContent = data.count; }); } </script>
