Error Handling PHP

Try-Catch & Debugging untuk Pemula

🤔 Pertanyaan Pemantik

  • • Pernah program PHP kamu error?
  • • Bagaimana cara menangani error?
  • • Apa itu debugging?

🎯 Tujuan Pembelajaran

  • • Memahami konsep error handling
  • • Menguasai try-catch statement
  • • Mampu melakukan debugging

💡 Pemahaman Bermakna

Error handling adalah seperti sistem keamanan dalam program. Bayangkan kamu sedang mengendarai mobil - kamu butuh rem untuk berhenti saat ada bahaya. Begitu juga program, butuh cara untuk menangani masalah yang muncul!

🌟

Motivasi

"Programmer yang hebat bukan yang tidak pernah membuat error, tapi yang tahu cara menangani error dengan baik!"

📚 Pengenalan Error Handling

❌ Tanpa Error Handling

🔴 🟡 🟢 ❌ Tanpa Error Handling
<?php $angka = 10; $pembagi = 0; $hasil = $angka / $pembagi; // Error! echo "Hasil: " . $hasil; ?>

Program akan crash dan berhenti!

✅ Dengan Error Handling

🔴 🟡 🟢 ✅ Dengan Error Handling
<?php try { $angka = 10; $pembagi = 0; if ($pembagi == 0) { throw new Exception("Tidak bisa bagi nol!"); } $hasil = $angka / $pembagi; echo "Hasil: " . $hasil; } catch (Exception $e) { echo "Error: " . $e->getMessage(); } ?>

Program tetap berjalan dengan pesan error yang jelas!

🎯 Apa itu Error Handling?

Error handling adalah teknik untuk menangani kesalahan yang mungkin terjadi saat program berjalan. Tujuannya adalah:

  • 🛡️ Mencegah program crash
  • 📝 Memberikan pesan error yang jelas
  • 🔄 Memungkinkan program tetap berjalan
  • 🎯 Meningkatkan user experience

🎯 Try-Catch Statement

📖 Struktur Dasar

🔴 🟡 🟢 📖 Struktur Try-Catch
try { // Kode yang mungkin error // Jika ada error, akan loncat ke catch } catch (Exception $e) { // Kode untuk menangani error // $e berisi informasi error } finally { // Kode yang selalu dijalankan (opsional) }

🔍 Try Block

Tempat kode yang mungkin error

🔴 🟡 🟢 🔍 Try Block Example
try { $file = fopen("data.txt", "r"); $content = fread($file, 100); fclose($file); }

🚨 Catch Block

Tempat menangani error

🔴 🟡 🟢 🚨 Catch Block Example
catch (Exception $e) { echo "Error: " . $e->getMessage(); // Log error ke file error_log($e->getMessage()); }

🎮 Demo Interaktif

Coba masukkan angka untuk pembagian:

✨ Finally Block

Kode yang selalu dijalankan, error atau tidak

🔴 🟡 🟢 ✨ Finally Block Example
try { $db = new PDO("mysql:host=localhost;dbname=test", $user, $pass); // Query database } catch (Exception $e) { echo "Database error: " . $e->getMessage(); } finally { // Tutup koneksi database $db = null; echo "Koneksi ditutup"; }

⚠️ Jenis-Jenis Error

🔥 Fatal Error

Error yang menghentikan program

🔴 🟡 🟢 🔥 Fatal Error Example
<?php // Memanggil function yang tidak ada nonExistentFunction(); // Fatal error! ?>

Program berhenti total!

⚠️ Warning

Error yang tidak menghentikan program

🔴 🟡 🟢 ⚠️ Warning Example
<?php // Membuka file yang tidak ada $file = fopen("tidak_ada.txt", "r"); // Warning echo "Program tetap jalan"; ?>

Program tetap berjalan!

ℹ️ Notice

Peringatan ringan

🔴 🟡 🟢 ℹ️ Notice Example
<?php // Menggunakan variabel yang belum didefinisi echo $variabel_belum_ada; // Notice ?>

Hanya peringatan kecil

🎯 Exception

Error yang bisa ditangani dengan try-catch

🔴 🟡 🟢 🎯 Exception Example
<?php try { throw new Exception("Custom error!"); } catch (Exception $e) { echo $e->getMessage(); } ?>

Bisa ditangani dengan baik!

🛠️ Custom Exception

Kamu bisa membuat exception sendiri!

🔴 🟡 🟢 🛠️ Custom Exception
<?php class CustomException extends Exception { public function errorMessage() { return "Error di baris " . $this->getLine() . " file " . $this->getFile() . ": " . $this->getMessage(); } } try { throw new CustomException("Ini error custom!"); } catch (CustomException $e) { echo $e->errorMessage(); } ?>

🔍 Debugging PHP

🎯 Apa itu Debugging?

Debugging adalah proses mencari dan memperbaiki bug (kesalahan) dalam program. Seperti detektif yang mencari petunjuk!

🖨️ var_dump()

Menampilkan detail variabel

🔴 🟡 🟢 🖨️ var_dump() Example
<?php $data = ["nama" => "Budi", "umur" => 17]; var_dump($data); // Output: array(2) { ["nama"]=> string(4) "Budi" ... ?>

📝 print_r()

Menampilkan variabel lebih rapi

🔴 🟡 🟢 📝 print_r() Example
<?php $data = ["nama" => "Budi", "umur" => 17]; print_r($data); // Output: Array ( [nama] => Budi [umur] => 17 ) ?>

📋 error_log()

Menyimpan error ke file log

🔴 🟡 🟢 📋 error_log() Example
<?php error_log("Debug: Nilai x = " . $x); error_log("Error terjadi di function login()"); ?>

⚙️ error_reporting()

Mengatur level error yang ditampilkan

🔴 🟡 🟢 ⚙️ error_reporting() Example
<?php // Tampilkan semua error error_reporting(E_ALL); // Sembunyikan semua error error_reporting(0); ?>

<?php echo "<h2>Praktik Error Handling PHP</h2>"; // Praktik 1: Pembagian dengan nol echo "<h3>Praktik 1: Pembagian</h3>"; try { $a = 10; $b = 0; if ($b == 0) { throw new Exception("Tidak bisa membagi dengan nol!"); } $hasil = $a / $b; echo "Hasil: " . $hasil; } catch (Exception $e) { echo "<p style='color: red;'>Error: " . $e->getMessage() . "</p>"; } echo "<hr>"; // Praktik 2: File handling echo "<h3>Praktik 2: Baca File</h3>"; try { $namaFile = "data.txt"; if (!file_exists($namaFile)) { throw new Exception("File $namaFile tidak ditemukan!"); } $isi = file_get_contents($namaFile); echo "<p>Isi file: " . $isi . "</p>"; } catch (Exception $e) { echo "<p style='color: red;'>Error: " . $e->getMessage() . "</p>"; } ?>

🚀 Langkah 4: Challenge

Buat program kalkulator sederhana dengan error handling:

🔴 🟡 🟢 🚀 Kalkulator Challenge
<?php // Challenge: Kalkulator dengan Error Handling echo "<h3>🧮 Kalkulator PHP</h3>"; // Simulasi input (dalam praktik nyata bisa dari form) $angka1 = 15; $angka2 = 3; $operator = "/"; echo "<p><strong>Input:</strong> $angka1 $operator $angka2</p>"; try { // Validasi input angka if (!is_numeric($angka1) || !is_numeric($angka2)) { throw new Exception("Input harus berupa angka!"); } // Validasi operator $operatorValid = ['+', '-', '*', '/']; if (!in_array($operator, $operatorValid)) { throw new Exception("Operator tidak valid! Gunakan: +, -, *, /"); } // Operasi kalkulator switch ($operator) { case '+': $hasil = $angka1 + $angka2; break; case '-': $hasil = $angka1 - $angka2; break; case '*': $hasil = $angka1 * $angka2; break; case '/': if ($angka2 == 0) { throw new Exception("Tidak bisa membagi dengan nol!"); } $hasil = $angka1 / $angka2; break; } echo "<p style='color: green;'><strong>✅ Hasil:</strong> $hasil</p>"; } catch (Exception $e) { echo "<p style='color: red;'><strong>❌ Error:</strong> " . $e->getMessage() . "</p>"; // Log error untuk debugging error_log("Kalkulator Error: " . $e->getMessage()); } finally { echo "<p><em>Operasi kalkulator selesai.</em></p>"; } // Bonus: Function kalkulator yang bisa digunakan ulang function kalkulator($a, $b, $op) { try { if (!is_numeric($a) || !is_numeric($b)) { throw new Exception("Input harus angka!"); } switch ($op) { case '+': return $a + $b; case '-': return $a - $b; case '*': return $a * $b; case '/': if ($b == 0) throw new Exception("Pembagian nol!"); return $a / $b; default: throw new Exception("Operator tidak valid!"); } } catch (Exception $e) { return "Error: " . $e->getMessage(); } } // Test function echo "<hr><h4>Test Function:</h4>"; echo "kalkulator(10, 2, '*') = " . kalkulator(10, 2, '*') . "<br>"; echo "kalkulator(10, 0, '/') = " . kalkulator(10, 0, '/') . "<br>"; ?>
