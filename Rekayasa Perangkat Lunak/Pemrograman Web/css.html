📚 Pengenalan CSS

🤖Apa itu CSS?

CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan dan layout halaman web. CSS bekerja sama dengan HTML untuk membuat website yang indah dan menarik.

🏗️Analogi Sederhana

Bayangkan HTML sebagai kerangka rumah, dan CSS sebagai cat, wallpaper, dan dekorasi. HTML memberikan struktur, CSS memberikan keindahan!

⚡Cara Kerja CSS

1️⃣

Pilih Elemen

Gunakan selector untuk memilih elemen HTML

2️⃣

Atur Style

Tentukan warna, ukuran, posisi, dll

3️⃣

Lihat Hasil

Browser menampilkan styling yang sudah dibuat

📝Struktur Dasar CSS

CSS Structure 
selector {
    property: value;
    property: value;
}

Selector

Memilih elemen HTML

Property

Apa yang ingin diubah

Value

Nilai yang diberikan

🎯 CSS Selector

🔍Apa itu Selector?

Selector adalah cara untuk "menunjuk" elemen HTML mana yang ingin kita beri style. Seperti menunjuk teman di kelas untuk memberikan tugas!

1️⃣Element Selector

Memilih semua elemen dengan tag yang sama

Contoh CSS:
style.css 
h1 {
    color: red;
    font-size: 24px;
}
Hasil:

Judul Merah

2️⃣Class Selector

Memilih elemen dengan class tertentu (pakai titik .)

Contoh CSS:
style.css 
.highlight {
    background: yellow;
    padding: 10px;
}
Hasil:
Teks Highlight

3️⃣ID Selector

Memilih elemen dengan ID tertentu (pakai pagar #)

Contoh CSS:
style.css 
#header {
    background: blue;
    color: white;
    text-align: center;
}
Hasil:
Header Biru

💡Tips Penting!

Element Selector

Untuk styling umum semua elemen sejenis

Class Selector

Untuk styling beberapa elemen yang sama

ID Selector

Untuk styling satu elemen unik saja

📦 CSS Flexbox

🤔Apa itu Flexbox?

Flexbox adalah cara super mudah untuk mengatur layout elemen! Bayangkan seperti mengatur barang-barang di dalam kotak - kamu bisa atur mereka berjajar, ditengah, atau diujung dengan mudah.

flexbox.css

🔲 CSS Grid

🧩Apa itu CSS Grid?

CSS Grid adalah sistem layout 2D yang memungkinkan kita membuat baris dan kolom seperti tabel, tapi jauh lebih fleksibel! Bayangkan seperti membuat puzzle dengan kotak-kotak yang bisa diatur sesuka hati.

1️⃣Membuat Grid Container

grid.css 
.grid-container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 10px;
}

1fr = 1 bagian yang sama besar

⚡Flexbox vs Grid

📦Flexbox

  • ✅ Layout 1 dimensi (baris ATAU kolom)
  • ✅ Bagus untuk navbar, button group
  • ✅ Mudah untuk center elemen

🔲Grid

  • ✅ Layout 2 dimensi (baris DAN kolom)
  • ✅ Bagus untuk layout website lengkap
  • ✅ Kontrol penuh atas posisi elemen

⚡ Praktik CSS

🎯Proyek: Membuat Card Profile

Kita akan membuat card profile yang keren menggunakan semua yang sudah dipelajari: selector, styling, flexbox, dan grid!

1️⃣Langkah 1: HTML Structure

index.html 
<div class="profile-card">
    <div class="profile-header">
        <div class="avatar">👨‍💻</div>
        <h2 class="name">John Doe</h2>
        <p class="title">Web Developer</p>
    </div>
    <div class="profile-body">
        <div class="stats">
            <div class="stat">
                <span class="number">150</span>
                <span class="label">Projects</span>
            </div>
            <div class="stat">
                <span class="number">50</span>
                <span class="label">Clients</span>
            </div>
        </div>
    </div>
</div>

2️⃣Langkah 2: Basic Styling

profile.css 
.profile-card {
    background: white;
    border-radius: 20px;
    box-shadow: 0 10px 30px rgba(0,0,0,0.1);
    padding: 30px;
    max-width: 300px;
    margin: 0 auto;
}

.avatar {
    font-size: 60px;
    text-align: center;
    margin-bottom: 15px;
}

.name {
    font-size: 24px;
    font-weight: bold;
    color: #333;
    text-align: center;
    margin: 0 0 5px 0;
}

.title {
    color: #666;
    text-align: center;
    margin: 0 0 20px 0;
}

3️⃣Langkah 3: Flexbox untuk Stats 

.stats {
    display: flex;
    justify-content: space-around;
    border-top: 1px solid #eee;
    padding-top: 20px;
}

.stat {
    text-align: center;
}

.number {
    display: block;
    font-size: 24px;
    font-weight: bold;
    color: #4f46e5;
}

.label {
    font-size: 14px;
    color: #666;
    text-transform: uppercase;
}

📝 Tugas CSS

📋Petunjuk Pengerjaan

  • • Jawab semua pertanyaan dengan lengkap dan jelas
  • • Berikan contoh kode CSS jika diminta
  • • Jelaskan dengan bahasa sendiri
  • • Waktu pengerjaan: 45 menit

1️⃣Soal 1 (Skor: 15)

Jelaskan perbedaan antara Element Selector, Class Selector, dan ID Selector dalam CSS! Berikan contoh penggunaan masing-masing dan kapan sebaiknya digunakan.

💡 Tips:

Ingat simbol yang digunakan: tanpa simbol, titik (.), dan pagar (#)

2️⃣Soal 2 (Skor: 20)

Buatlah kode CSS untuk membuat sebuah button dengan spesifikasi berikut:

  • • Background warna biru (#3b82f6)
  • • Teks berwarna putih
  • • Padding 12px horizontal, 8px vertikal
  • • Border radius 8px
  • • Tidak ada border
  • • Ketika di-hover, background berubah jadi biru gelap (#1d4ed8)

3️⃣Soal 3 (Skor: 25)

Jelaskan konsep Flexbox dan berikan contoh kode CSS untuk membuat layout berikut:

Logo
Home About Contact

Navbar dengan logo di kiri dan menu di kanan, semuanya center vertikal.

4️⃣Soal 4 (Skor: 25)

Buatlah kode CSS Grid untuk membuat layout website sederhana dengan struktur:

Header (2 kolom)
Sidebar
Main Content
Footer (2 kolom)

Header dan Footer memanjang 2 kolom, Sidebar dan Main Content masing-masing 1 kolom.

5️⃣Soal 5 (Skor: 15)

Mengapa CSS penting dalam pengembangan website? Jelaskan minimal 3 keuntungan menggunakan CSS dan bagaimana CSS membantu dalam membuat website yang responsif!
