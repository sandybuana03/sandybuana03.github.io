Pengenalan CodeIgniter 3 📚

🤖 Apa itu CodeIgniter?

CodeIgniter adalah framework PHP yang ringan dan mudah dipelajari. Framework ini membantu developer membuat aplikasi web dengan lebih cepat dan terstruktur.

Analogi Sederhana:

Bayangkan kamu mau masak nasi goreng. Daripada mulai dari nol (beli beras, cuci, masak), lebih mudah kalau sudah ada nasi putih yang tinggal digoreng kan? Nah, CodeIgniter itu seperti "nasi putih" untuk membuat website!

✅ Kelebihan CodeIgniter

  • • Mudah dipelajari - Cocok untuk pemula
  • • Ringan - Tidak berat saat dijalankan
  • • Dokumentasi lengkap - Mudah dicari tutorialnya
  • • Fleksibel - Bisa dikustomisasi sesuai kebutuhan

🏗️ Fitur Utama

  • • MVC Pattern - Kode terorganisir rapi
  • • Database Support - Mudah kelola database
  • • Security - Perlindungan dari serangan
  • • URL Routing - URL yang SEO friendly

Konsep MVC 🏗️

🤔 Apa itu MVC?

MVC adalah singkatan dari Model-View-Controller. Ini adalah pola arsitektur yang memisahkan kode menjadi 3 bagian berbeda agar lebih terorganisir.

🏠 Analogi Rumah Makan:

  • • Model = Dapur (tempat masak/olah data)
  • • View = Meja makan (tempat pelanggan melihat makanan)
  • • Controller = Pelayan (penghubung dapur dan pelanggan)

Model

Bertugas mengolah data dan berkomunikasi dengan database

Contoh:
• Ambil data siswa
• Simpan data baru
• Update data
• Hapus data

View

Bertugas menampilkan data ke user (tampilan website)

Contoh:
• Halaman login
• Tabel data siswa
• Form input
• Dashboard

Controller

Bertugas mengatur alur aplikasi dan menghubungkan Model & View

Contoh:
• Proses login
• Validasi form
• Routing halaman
• Logic bisnis

URL Routing 🛣️

🗺️ Apa itu Routing?

Routing adalah cara CodeIgniter menentukan controller dan method mana yang akan dijalankan berdasarkan URL yang diakses user.

🚗 Analogi GPS:

Routing seperti GPS di mobil. Ketika kamu mau ke suatu tempat, GPS akan menentukan jalan mana yang harus dilalui. Begitu juga routing, ketika user akses URL tertentu, CodeIgniter akan tahu harus menjalankan kode yang mana.

📐 Pola URL CodeIgniter

📄 Pola URL Standar
http://localhost/project/controller/method/parameter

Contoh URL:

http://localhost/belajar-ci/siswa/tampil/1

Artinya:

  • • Controller: Siswa
  • • Method: tampil
  • • Parameter: 1

Controller 🎮

🎯 Apa itu Controller?

Controller adalah "otak" dari aplikasi yang mengatur alur program. Controller menerima input dari user, memproses data (dengan bantuan Model), dan menentukan tampilan apa yang akan ditampilkan (View).

📝 Membuat Controller Pertama

📄 application/controllers/Siswa.php
<?php class Siswa extends CI_Controller { // Method default (index) public function index() { echo "Halaman Daftar Siswa"; } // Method untuk menampilkan detail siswa public function detail($id) { echo "Detail siswa dengan ID: " . $id; } }

View 👁️

🎨 Apa itu View?

View adalah bagian yang bertugas menampilkan data ke user. View berisi kode HTML, CSS, dan JavaScript yang membentuk tampilan website yang dilihat pengunjung.

📁 Membuat View Pertama

📄 application/views/siswa/index.php
<!DOCTYPE html> <html> <head> <title>Daftar Siswa</title> </head> <body> <h1>Daftar Siswa SMK</h1> <table border="1"> <tr> <th>No</th> <th>Nama</th> <th>Kelas</th> </tr> <tr> <td>1</td> <td>Budi Santoso</td> <td>XII RPL 1</td> </tr> </table> </body> </html>

Model 🗄️

💾 Apa itu Model?

Model adalah bagian yang bertugas mengelola data dan berkomunikasi dengan database. Model berisi fungsi-fungsi untuk Create, Read, Update, Delete (CRUD) data.

📝 Membuat Model Pertama

📄 application/models/Siswa_model.php
<?php class Siswa_model extends CI_Model { // Nama tabel private $table = 'siswa'; // Ambil semua data siswa public function get_all() { return $this->db->get($this->table)->result(); } // Ambil data berdasarkan ID public function get_by_id($id) { return $this->db->get_where($this->table, ['id' => $id])->row(); } }

Praktik Membuat Aplikasi 💻

🎯 Project: Sistem Data Siswa

Kita akan membuat aplikasi sederhana untuk mengelola data siswa dengan fitur CRUD (Create, Read, Update, Delete).

🗄️ Langkah 1: Buat Database

📄 SQL untuk membuat database dan tabel
CREATE DATABASE sekolah; USE sekolah; CREATE TABLE siswa ( id INT AUTO_INCREMENT PRIMARY KEY, nama VARCHAR(100) NOT NULL, kelas VARCHAR(20) NOT NULL, alamat TEXT, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP );

⚙️ Langkah 2: Konfigurasi Database

📄 application/config/database.php
$db['default'] = array( 'dsn'=> '', 'hostname' => 'localhost', 'username' => 'root', 'password' => '', 'database' => 'sekolah', 'dbdriver' => 'mysqli', // ... konfigurasi lainnya );

📝 Langkah 3: Membuat Model

📄 application/models/Siswa_model.php
<?php class Siswa_model extends CI_Model { private $table = 'siswa'; // Ambil semua data siswa public function get_all() { return $this->db->get($this->table)->result(); } // Ambil data berdasarkan ID public function get_by_id($id) { return $this->db->get_where($this->table, ['id' => $id])->row(); } // Tambah data siswa public function insert($data) { return $this->db->insert($this->table, $data); } }

🎮 Langkah 4: Membuat Controller

📄 application/controllers/Siswa.php
<?php class Siswa extends CI_Controller { public function __construct() { parent::__construct(); $this->load->model('Siswa_model'); } // Halaman utama - tampilkan daftar siswa public function index() { $data['siswa'] = $this->Siswa_model->get_all(); $this->load->view('siswa/index', $data); } // Form tambah siswa public function tambah() { $this->load->view('siswa/tambah'); } }

👁️ Langkah 5: Membuat View

📄 application/views/siswa/index.php
<!DOCTYPE html> <html> <head> <title>Data Siswa</title> </head> <body> <h1>Daftar Siswa</h1> <a href="<?= base_url('siswa/tambah') ?>">Tambah Siswa</a> <table border="1"> <tr> <th>No</th> <th>Nama</th> <th>Kelas</th> <th>Alamat</th> </tr> <?php $no = 1; foreach($siswa as $s): ?> <tr> <td><?= $no++ ?></td> <td><?= $s->nama ?></td> <td><?= $s->kelas ?></td> <td><?= $s->alamat ?></td> </tr> <?php endforeach; ?> </table> </body> </html>

🧪 Langkah 6: Testing Aplikasi

1. Akses URL: http://localhost/belajar-ci/siswa

2. Pastikan: Tidak ada error dan halaman tampil dengan baik

3. Cek database: Tambahkan beberapa data sample untuk testing

4. Validasi: Data dari database tampil di halaman web

💡 Tips Debugging

• Error 404: Cek nama controller dan method

• Database error: Cek konfigurasi database.php

• View tidak tampil: Cek path file view

• Data kosong: Cek apakah ada data di tabel database
