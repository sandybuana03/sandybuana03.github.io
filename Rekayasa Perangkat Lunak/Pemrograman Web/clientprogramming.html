Pengenalan Client-Side Programming

🤖 Apa itu Client-Side Programming?

Client-side programming adalah pemrograman yang berjalan di sisi klien (browser pengguna). Berbeda dengan server-side yang berjalan di server, client-side berjalan langsung di komputer atau HP kamu!

💡 Analogi Sederhana

Bayangkan website seperti restoran:

  • 🏢 Server-side = Dapur (memasak di belakang)
  • 👨‍🍳 Client-side = Pelayan & dekorasi (berinteraksi langsung dengan kamu)

🌍 Sejarah Singkat Web Development

📄

1990s

Website statis dengan HTML sederhana

🎨

2000s

CSS untuk styling, JavaScript mulai populer

⚡

2010s+

Web apps interaktif, mobile-first

🔄 Proses Kerja Client-Side

1

User membuka website

Browser meminta file HTML, CSS, JS dari server

2

Browser memproses file

HTML dibaca, CSS diterapkan, JavaScript dijalankan

3

Website menjadi interaktif

User bisa klik, scroll, input data tanpa reload

✅ Keuntungan Client-Side

  • • Respon cepat
  • • Interaksi smooth
  • • Mengurangi beban server
  • • Pengalaman user lebih baik

⚠️ Keterbatasan

  • • Tergantung browser
  • • Bisa dimatikan user
  • • Keamanan terbatas
  • • Tidak bisa akses database langsung

HTML - Fondasi Website

🏗️ Apa itu HTML?

HTML (HyperText Markup Language) adalah bahasa markup untuk membuat struktur halaman web. Seperti kerangka rumah, HTML memberikan struktur dasar website.

🏠 Analogi Rumah

  • 🏗️ HTML = Kerangka & struktur rumah
  • 🎨 CSS = Cat, wallpaper, dekorasi
  • ⚡ JavaScript = Listrik, AC, smart home

🏷️ Tag HTML Dasar

Struktur Dasar

<html>
  <head>
    <title>Judul</title>
  </head>
  <body>
    <h1>Halo Dunia!</h1>
  </body>
</html>

Tag Penting

  • <h1> - Judul besar
  • <p> - Paragraf
  • <a> - Link
  • <img> - Gambar
  • <div> - Container

🏷️ Semantic HTML

Semantic HTML menggunakan tag yang memiliki makna, bukan hanya untuk tampilan. Ini penting untuk SEO dan accessibility!

❌ Non-Semantic

<div class="header">
  <div class="nav">Menu</div>
</div>
<div class="content">
  <div class="article">Konten</div>
</div>

✅ Semantic

<header>
  <nav>Menu</nav>
</header>
<main>
  <article>Konten</article>
</main>

🎯 Tag Semantic Penting

  • <header> - Bagian atas halaman
  • <nav> - Menu navigasi
  • <main> - Konten utama
  • <article> - Artikel/konten
  • <section> - Bagian halaman
  • <aside> - Sidebar
  • <footer> - Bagian bawah
  • <figure> - Gambar + caption

📐 CSS Layout: Flexbox & Grid

Layout adalah cara mengatur posisi elemen di halaman. Flexbox dan Grid adalah teknik modern yang powerful!

🔄 Flexbox

Untuk layout 1 dimensi (baris atau kolom)

.container {
  display: flex;
  justify-content: center;
  align-items: center;
}

🎯 Grid

Untuk layout 2 dimensi (baris dan kolom)

.container {
  display: grid;
  grid-template-columns:
    1fr 1fr 1fr;
}

JavaScript - Membuat Website Hidup

JavaScript adalah bahasa pemrograman yang membuat website menjadi interaktif. Seperti memberikan "otak" pada website!

🤖 Analogi Robot

  • 🏗️ HTML = Kerangka robot
  • 🎨 CSS = Warna & desain robot
  • 🧠 JavaScript = Otak robot (bisa bergerak & berpikir!)

🎯 Apa yang Bisa Dilakukan JavaScript?

Interaksi User

  • • Klik tombol
  • • Hover efek
  • • Form validation
  • • Pop-up & alert

Manipulasi Halaman

  • • Ubah konten
  • • Animasi
  • • Slide show
  • • Dynamic content

💡 Tips JavaScript Best Practices

  • ✅ Gunakan const dan let, hindari var
  • ✅ Berikan nama variabel dan fungsi yang deskriptif
  • ✅ Gunakan addEventListener untuk event
  • ✅ Selalu handle error dengan try-catch
  • ✅ Test kode di browser console (F12)
  • ✅ Gunakan console.log() untuk debugging
  • ✅ Pisahkan JavaScript dari HTML (external file)
  • ✅ Jangan takut error - belajar dari pesan error!

Responsive Design - Website untuk Semua Device

🌐 Apa itu Responsive Design?

Responsive design adalah teknik membuat website yang tampil bagus di semua ukuran layar - dari HP kecil sampai monitor besar!

📏 Ukuran Layar yang Berbeda

📱 Mobile
320-768px

💻 Tablet
768-1024px

🖥️ Desktop
1024px+

🛠️ Teknik Responsive

Media Queries

@media (max-width: 768px) {
  .container {
    width: 100%;
  }
}

Flexible Grid

.grid {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(300px, 1fr));
}

🌟 Best Practices Responsive

  • ✅ Mobile-first approach (desain dari HP dulu)
  • ✅ Gunakan unit relatif (%, em, rem)
  • ✅ Test di berbagai device
  • ✅ Optimasi gambar untuk mobile
  • ✅ Touch-friendly button size (min 44px)

Tugas Pemrograman Web Sisi Klien

Saatnya menguji pemahamanmu!

📝 Soal 1: Konsep Dasar

Jelaskan perbedaan antara client-side programming dan server-side programming! Berikan contoh teknologi yang digunakan pada masing-masing sisi.

🏗️ Soal 2: HTML Structure

Buatlah struktur HTML sederhana untuk halaman profil siswa yang berisi: judul halaman, nama siswa, foto profil, deskripsi singkat, dan daftar hobi. Gunakan tag HTML yang sesuai!
