Apa itu CRUD?

CRUD adalah singkatan dari 4 operasi dasar dalam database yang merupakan fondasi dari hampir semua aplikasi web:

➕

CREATE (Buat)

Menambah data baru ke database

Contoh: Mendaftarkan siswa baru, membuat postingan blog

👀

READ (Baca)

Membaca/menampilkan data dari database

Contoh: Melihat daftar siswa, menampilkan artikel

✏️

UPDATE (Perbarui)

Mengubah data yang sudah ada

Contoh: Edit profil siswa, update harga produk

🗑️

DELETE (Hapus)

Menghapus data dari database

Contoh: Hapus akun siswa, delete komentar spam

Langkah 1: Koneksi Database

Mari hubungkan PHP dengan MySQL!

📋

Persiapan Database

Pertama, buat database dan tabel di MySQL:

SQL Query
CREATE DATABASE sekolah_db; USE sekolah_db; CREATE TABLE siswa ( id INT AUTO_INCREMENT PRIMARY KEY, nama VARCHAR(100) NOT NULL, kelas VARCHAR(10) NOT NULL, umur INT NOT NULL );
🔗

File Koneksi PHP

Buat file koneksi.php untuk menghubungkan ke database:

koneksi.php
<?php $host = "localhost"; $username = "root"; $password = ""; $database = "sekolah_db"; // Membuat koneksi $conn = new mysqli($host, $username, $password, $database); // Cek koneksi if ($conn->connect_error) { die("Koneksi gagal: " . $conn->connect_error); } echo "Koneksi berhasil! 🎉"; ?>
✅

Penjelasan Kode

$host: Alamat server database (biasanya "localhost")
$username: Username MySQL (default: "root")
$password: Password MySQL (kosong jika default)
$database: Nama database yang akan digunakan

Proses PHP untuk Menyimpan Data

Tambahkan kode PHP di atas form HTML:

PHP Code
<?php include 'koneksi.php'; if (isset($_POST['submit'])) { $nama = $_POST['nama']; $kelas = $_POST['kelas']; $umur = $_POST['umur']; $sql = "INSERT INTO siswa (nama, kelas, umur) VALUES ('$nama', '$kelas', '$umur')"; if ($conn->query($sql) === TRUE) { echo "Data siswa berhasil ditambahkan! 🎉"; } else { echo "Error: " . $sql . "<br>" . $conn->error; } } ?>
🔍

Penjelasan Langkah demi Langkah

1 Include koneksi.php

Menghubungkan file ini dengan database

2 Cek tombol submit

Mengecek apakah form sudah dikirim

3 Ambil data dari form

Mengambil nilai dari input nama, kelas, dan umur

4 Jalankan query INSERT

Menyimpan data ke tabel siswa

Langkah 3: READ - Baca Data

Menampilkan data siswa dalam tabel!

📊

Menampilkan Data dalam Tabel

Buat file lihat_siswa.php untuk menampilkan data:

lihat_siswa.php
<?php include 'koneksi.php'; $sql = "SELECT * FROM siswa"; $result = $conn->query($sql); ?> <!DOCTYPE html> <html> <head> <title>Data Siswa</title> <style> table { border-collapse: collapse; width: 100%; } th, td { border: 1px solid #ddd; padding: 8px; text-align: left; } th { background-color: #f2f2f2; } </style> </head> <body> <h2>Data Siswa</h2> <table> <tr> <th>ID</th> <th>Nama</th> <th>Kelas</th> <th>Umur</th> </tr>
🔄

Loop untuk Menampilkan Data

Lanjutkan kode di atas dengan loop PHP:

PHP Loop
<?php if ($result->num_rows > 0) { // Tampilkan data setiap baris while($row = $result->fetch_assoc()) { echo "<tr>"; echo "<td>" . $row["id"] . "</td>"; echo "<td>" . $row["nama"] . "</td>"; echo "<td>" . $row["kelas"] . "</td>"; echo "<td>" . $row["umur"] . "</td>"; echo "</tr>"; } } else { echo "<tr><td colspan='4'>Tidak ada data siswa</td></tr>"; } ?> </table> </body> </html>
💡

Penjelasan Kode READ

SELECT * FROM siswa:

Mengambil semua data dari tabel siswa

$result->num_rows:

Mengecek apakah ada data yang ditemukan

fetch_assoc():

Mengambil data satu per satu dalam bentuk array

while loop:

Mengulangi proses untuk setiap baris data

Mengubah data siswa yang sudah ada!

🔍

Form Edit Data

Buat file edit_siswa.php untuk mengedit data:

edit_siswa.php
<?php include 'koneksi.php'; // Ambil ID siswa dari URL $id = $_GET['id']; // Ambil data siswa berdasarkan ID $sql = "SELECT * FROM siswa WHERE id = $id"; $result = $conn->query($sql); $row = $result->fetch_assoc(); // Proses update data if (isset($_POST['update'])) { $nama = $_POST['nama']; $kelas = $_POST['kelas']; $umur = $_POST['umur']; $sql_update = "UPDATE siswa SET nama='$nama', kelas='$kelas', umur='$umur' WHERE id=$id"; if ($conn->query($sql_update) === TRUE) { echo "Data berhasil diupdate! 🎉"; } else { echo "Error: " . $conn->error; } } ?>
📝

Form HTML untuk Edit

Lanjutkan kode di file edit_siswa.php yang sama dengan menambahkan HTML form di bawah kode PHP:

HTML Form
<!DOCTYPE html> <html> <head> <title>Edit Siswa</title> </head> <body> <h2>Edit Data Siswa</h2> <form method="POST" action=""> <label>Nama Siswa:</label><br> <input type="text" name="nama" value="<?php echo $row['nama']; ?>" required><br><br> <label>Kelas:</label><br> <input type="text" name="kelas" value="<?php echo $row['kelas']; ?>" required><br><br> <label>Umur:</label><br> <input type="number" name="umur" value="<?php echo $row['umur']; ?>" required><br><br> <button type="submit" name="update">Update Data</button> </form> </body> </html>

Langkah 5: DELETE - Hapus Data

Menghapus data siswa dengan aman!

⚠️

File Hapus Data

Buat file hapus_siswa.php untuk menghapus data:

hapus_siswa.php
<?php include 'koneksi.php'; // Ambil ID siswa dari URL $id = $_GET['id']; // Query untuk menghapus data $sql = "DELETE FROM siswa WHERE id = $id"; if ($conn->query($sql) === TRUE) { echo "Data siswa berhasil dihapus! 🗑️"; echo "<br><a href='lihat_siswa.php'>Kembali ke daftar siswa</a>"; } else { echo "Error: " . $conn->error; } $conn->close(); ?>
