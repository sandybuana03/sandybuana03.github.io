📋 Apa itu Array?

Array adalah struktur data yang dapat menyimpan multiple nilai dalam satu variabel. Bayangkan seperti lemari dengan banyak laci - setiap laci bisa menyimpan barang yang berbeda, dan setiap laci punya nomor atau label khusus.

Contoh nyata: Daftar nama siswa, koleksi foto, data produk toko

⚙️ Apa itu Fungsi?

Fungsi adalah blok kode yang dirancang untuk melakukan tugas tertentu dan dapat dipanggil berulang kali. Seperti mesin cuci - kamu masukkan baju kotor, tekan tombol, dan keluar baju bersih. Prosesnya sama setiap kali!

Keuntungan: Kode lebih rapi, mudah maintenance, bisa digunakan berulang

📋 Array Dasar di PHP - Panduan Lengkap

🎯 Konsep Dasar Array

Array adalah variabel yang dapat menyimpan lebih dari satu nilai sekaligus. Dalam PHP, ada dua jenis array utama:

📊 Indexed Array

Array dengan index numerik (0, 1, 2, ...)

Contoh: daftar nama, nilai ujian

🏷️ Associative Array

Array dengan key berupa string

Contoh: data profil, pengaturan

🎯 Membuat Array - Berbagai Cara

PHP menyediakan beberapa cara untuk membuat array. Mari pelajari satu per satu:

<?php // ========== INDEXED ARRAY ========== // Cara 1: Menggunakan array() - Cara lama tapi masih valid $buah = array("apel", "jeruk", "mangga", "pisang"); // Cara 2: Menggunakan [] - Cara modern (PHP 5.4+) $warna = ["merah", "biru", "hijau", "kuning"]; // Cara 3: Membuat array kosong lalu isi satu per satu $angka = array(); $angka[0] = 10; $angka[1] = 20; $angka[2] = 30; // Cara 4: Auto-increment index $nilai = []; $nilai[] = 85; // index 0 $nilai[] = 90; // index 1 $nilai[] = 78; // index 2 // ========== ASSOCIATIVE ARRAY ========== // Menggunakan key => value $siswa = array( "nama" => "Andi Pratama", "kelas" => "XII RPL", "umur" => 17, "alamat" => "Jakarta" ); // Cara modern dengan [] $produk = [ "nama" => "Laptop Gaming", "harga" => 15000000, "stok" => 5, "kategori" => "Elektronik" ]; // Mixed array - bisa kombinasi index dan key $campuran = [ 0 => "Nilai pertama", "nama" => "John Doe", 1 => "Nilai kedua", "status" => "aktif" ]; ?>

🔍 Mengakses Data Array - Detail

Setelah membuat array, kita perlu tahu cara mengambil datanya:

<?php // ========== MENGAKSES INDEXED ARRAY ========== $buah = ["apel", "jeruk", "mangga", "pisang"]; echo $buah[0]; // Output: apel (index pertama) echo $buah[1]; // Output: jeruk echo $buah[3]; // Output: pisang (index terakhir) // Mengecek apakah index ada if (isset($buah[5])) { echo $buah[5]; } else { echo "Index 5 tidak ada!"; } // ========== MENGAKSES ASSOCIATIVE ARRAY ========== $siswa = [ "nama" => "Andi Pratama", "kelas" => "XII RPL", "umur" => 17 ]; echo $siswa["nama"]; // Output: Andi Pratama echo $siswa["kelas"]; // Output: XII RPL // Mengecek apakah key ada if (array_key_exists("alamat", $siswa)) { echo $siswa["alamat"]; } else { echo "Key 'alamat' tidak ditemukan!"; } // ========== MENGAKSES DENGAN VARIABEL ========== $key = "nama"; echo $siswa[$key]; // Output: Andi Pratama $index = 2; echo $buah[$index]; // Output: mangga ?>

➕ Manipulasi Array - CRUD Operations

CRUD = Create, Read, Update, Delete. Mari pelajari cara memanipulasi array:

<?php $buah = ["apel", "jeruk"]; // ========== CREATE (Menambah Data) ========== // Menambah di akhir array $buah[] = "mangga"; // Cara 1 array_push($buah, "pisang", "anggur"); // Cara 2 - bisa multiple // Menambah di awal array array_unshift($buah, "strawberry"); // Menambah di posisi tertentu array_splice($buah, 2, 0, ["kiwi", "melon"]); // ========== UPDATE (Mengubah Data) ========== $buah[0] = "strawberry segar"; // Ubah index 0 $buah[1] = "jeruk manis"; // Ubah index 1 // ========== DELETE (Menghapus Data) ========== unset($buah[2]); // Hapus index tertentu $terakhir = array_pop($buah); // Hapus & ambil elemen terakhir $pertama = array_shift($buah); // Hapus & ambil elemen pertama // Hapus beberapa elemen sekaligus array_splice($buah, 1, 2); // Hapus 2 elemen mulai index 1 // ========== ASSOCIATIVE ARRAY MANIPULATION ========== $siswa = ["nama" => "Andi", "kelas" => "XII RPL"]; // Tambah key baru $siswa["umur"] = 17; $siswa["alamat"] = "Jakarta"; // Update value $siswa["kelas"] = "XII TKJ"; // Hapus key unset($siswa["alamat"]); print_r($buah); print_r($siswa); ?>

🔄 Looping Array - Semua Cara

Ada beberapa cara untuk mengulang/loop array di PHP:

<?php $buah = ["apel", "jeruk", "mangga", "pisang"]; $siswa = ["nama" => "Andi", "kelas" => "XII RPL", "umur" => 17]; // ========== UNTUK INDEXED ARRAY ========== // 1. For loop - hanya untuk indexed array echo "<h3>Menggunakan For Loop:</h3>"; for ($i = 0; $i < count($buah); $i++) { echo ($i + 1) . ". " . $buah[$i] . "<br>"; } // 2. Foreach - cara paling umum dan fleksibel echo "<h3>Menggunakan Foreach (value only):</h3>"; foreach ($buah as $item) { echo "- " . $item . "<br>"; } // 3. Foreach dengan index echo "<h3>Menggunakan Foreach (index + value):</h3>"; foreach ($buah as $index => $item) { echo "Index $index: $item<br>"; } // ========== UNTUK ASSOCIATIVE ARRAY ========== // Foreach dengan key dan value echo "<h3>Associative Array:</h3>"; foreach ($siswa as $key => $value) { echo "$key: $value<br>"; } // ========== WHILE LOOP DENGAN ARRAY ========== echo "<h3>Menggunakan While Loop:</h3>"; $i = 0; while ($i < count($buah)) { echo $buah[$i] . " "; $i++; } ?>

🔧 Fungsi Array Built-in yang Penting

PHP menyediakan banyak fungsi siap pakai untuk mengelola array:

<?php $angka = [3, 1, 4, 1, 5, 9, 2, 6]; $buah = ["apel", "jeruk", "mangga"]; // ========== INFORMASI ARRAY ========== echo "Jumlah elemen: " . count($angka) . "<br>"; // 8 echo "Jumlah elemen: " . sizeof($angka) . "<br>"; // sama dengan count() // Cek apakah variabel adalah array if (is_array($angka)) { echo "Ini adalah array<br>"; } // ========== PENCARIAN ========== // Cek apakah nilai ada dalam array if (in_array(5, $angka)) { echo "Angka 5 ditemukan!<br>"; } // Cari posisi/index dari nilai $posisi = array_search(4, $angka); echo "Angka 4 ada di index: $posisi<br>"; // ========== SORTING (PENGURUTAN) ========== $angka_copy = $angka; // Buat copy untuk demo sort($angka_copy); // Urutkan ascending print_r($angka_copy); rsort($angka_copy); // Urutkan descending print_r($angka_copy); // Untuk associative array $nilai = ["Andi" => 85, "Budi" => 92, "Cici" => 78]; asort($nilai); // Urutkan berdasarkan value ksort($nilai); // Urutkan berdasarkan key // ========== MANIPULASI ARRAY ========== // Gabungkan array $sayur = ["wortel", "bayam"]; $makanan = array_merge($buah, $sayur); // Balik urutan array $terbalik = array_reverse($buah); // Ambil sebagian array $sebagian = array_slice($angka, 2, 3); // Mulai index 2, ambil 3 elemen // Hapus duplikat $unik = array_unique($angka); // ========== KONVERSI ========== // Array ke string $string = implode(", ", $buah); // "apel, jeruk, mangga" $string2 = join(" - ", $buah); // sama dengan implode // String ke array $kalimat = "Belajar PHP itu mudah"; $kata = explode(" ", $kalimat); // ["Belajar", "PHP", "itu", "mudah"] echo "<br>String: $string<br>"; print_r($kata); ?>

💡 Tips & Best Practices:

✅ Yang Harus Dilakukan:

  • Selalu cek apakah index/key ada sebelum mengakses
  • Gunakan foreach untuk loop array (lebih aman)
  • Beri nama array yang deskriptif ($daftarSiswa, bukan $data)
  • Gunakan array functions built-in PHP

❌ Yang Harus Dihindari:

  • Mengakses index yang tidak ada (error)
  • Lupa bahwa index dimulai dari 0
  • Menggunakan for loop untuk associative array
  • Tidak memvalidasi input array

🏗️ Array Multidimensi - Panduan Mendalam

🎯 Konsep Array Multidimensi

Array multidimensi adalah array yang berisi array lain sebagai elemennya. Bayangkan seperti:

📊 2D Array

Seperti tabel Excel dengan baris dan kolom

Contoh: data siswa, matriks

🏢 3D Array

Seperti gedung bertingkat dengan ruangan

Contoh: data per bulan/tahun

🌐 N-Dimensional

Array dengan kedalaman tak terbatas

Contoh: struktur data kompleks

🎯 Membuat Array Multidimensi

Ada beberapa cara untuk membuat array multidimensi sesuai kebutuhan:

<?php // ========== ARRAY 2 DIMENSI - INDEXED ========== // Cara 1: Array numerik 2D (seperti tabel) $siswa = array( array("Andi Pratama", 17, "Jakarta", "XII RPL"), array("Budi Santoso", 18, "Bandung", "XII TKJ"), array("Cici Amelia", 16, "Surabaya", "XII MM"), array("Dedi Rahman", 17, "Medan", "XII RPL") ); // Cara 2: Menggunakan [] syntax modern $nilai_ujian = [ [85, 90, 78, 88], // Nilai Andi [92, 85, 90, 87], // Nilai Budi [78, 88, 85, 90], // Nilai Cici [88, 92, 85, 89] // Nilai Dedi ]; // ========== ARRAY 2 DIMENSI - ASSOCIATIVE ========== // Lebih mudah dibaca dan dipahami $data_siswa = array( "siswa_001" => array( "nama" => "Andi Pratama", "umur" => 17, "kota" => "Jakarta", "jurusan" => "RPL", "nilai" => array(85, 90, 78, 88), "hobi" => array("Gaming", "Coding", "Musik") ), "siswa_002" => array( "nama" => "Budi Santoso", "umur" => 18, "kota" => "Bandung", "jurusan" => "TKJ", "nilai" => array(92, 85, 90, 87), "hobi" => array("Futsal", "Fotografi") ), "siswa_003" => array( "nama" => "Cici Amelia", "umur" => 16, "kota" => "Surabaya", "jurusan" => "MM", "nilai" => array(78, 88, 85, 90), "hobi" => array("Menari", "Menyanyi", "Melukis") ) ); // ========== ARRAY 3 DIMENSI ========== // Data per kelas, per siswa, per mata pelajaran $sekolah = array( "XII_RPL" => array( "Andi" => array("Matematika" => 85, "Fisika" => 90, "Kimia" => 78), "Dedi" => array("Matematika" => 88, "Fisika" => 92, "Kimia" => 85) ), "XII_TKJ" => array( "Budi" => array("Matematika" => 92, "Fisika" => 85, "Kimia" => 90) ), "XII_MM" => array( "Cici" => array("Matematika" => 78, "Fisika" => 88, "Kimia" => 85) ) ); ?>

🔍 Mengakses Array Multidimensi - Detail

Untuk mengakses data dalam array multidimensi, kita menggunakan multiple index/key:

<?php // Data sample $siswa = array( array("Andi", 17, "Jakarta", "XII RPL"), array("Budi", 18, "Bandung", "XII TKJ") ); $data_siswa = array( "siswa_001" => array( "nama" => "Andi Pratama", "biodata" => array( "umur" => 17, "alamat" => array( "jalan" => "Jl. Merdeka No. 123", "kota" => "Jakarta", "kodepos" => "12345" ) ), "nilai" => array(85, 90, 78) ) ); // ========== MENGAKSES INDEXED ARRAY 2D ========== echo $siswa[0][0]; // Output: Andi (baris 0, kolom 0) echo $siswa[0][1]; // Output: 17 (baris 0, kolom 1) echo $siswa[1][2]; // Output: Bandung (baris 1, kolom 2) // Menggunakan variabel untuk index $baris = 0; $kolom = 3; echo $siswa[$baris][$kolom]; // Output: XII RPL // ========== MENGAKSES ASSOCIATIVE ARRAY MULTIDIMENSI ========== // Level 1 echo $data_siswa["siswa_001"]["nama"]; // Output: Andi Pratama // Level 2 (nested) echo $data_siswa["siswa_001"]["biodata"]["umur"]; // Output: 17 // Level 3 (deeply nested) echo $data_siswa["siswa_001"]["biodata"]["alamat"]["kota"]; // Output: Jakarta // Mengakses array dalam array echo $data_siswa["siswa_001"]["nilai"][0]; // Output: 85 (nilai pertama) echo $data_siswa["siswa_001"]["nilai"][2]; // Output: 78 (nilai ketiga) // ========== MENGECEK KEBERADAAN DATA ========== // Cek apakah key ada di level pertama if (isset($data_siswa["siswa_001"])) { echo "Data siswa_001 ada!"; } // Cek nested key if (isset($data_siswa["siswa_001"]["biodata"]["alamat"]["kota"])) { echo "Data kota tersedia!"; } // Alternatif dengan array_key_exists untuk associative if (array_key_exists("siswa_001", $data_siswa)) { echo "Key siswa_001 ditemukan!"; } ?>

➕ Manipulasi Array Multidimensi

Cara menambah, mengubah, dan menghapus data dalam array multidimensi:

<?php // Inisialisasi data $sekolah = array( "XII_RPL" => array( "Andi" => array("nama" => "Andi Pratama", "nilai" => 85) ) ); // ========== MENAMBAH DATA ========== // Tambah siswa baru di kelas yang sudah ada $sekolah["XII_RPL"]["Dedi"] = array( "nama" => "Dedi Rahman", "nilai" => 88 ); // Tambah kelas baru dengan siswa $sekolah["XII_TKJ"] = array( "Budi" => array("nama" => "Budi Santoso", "nilai" => 92) ); // Tambah data nested (nilai mata pelajaran) $sekolah["XII_RPL"]["Andi"]["mata_pelajaran"] = array( "Matematika" => 85, "Fisika" => 90, "Kimia" => 78 ); // ========== MENGUBAH DATA ========== // Update nilai siswa $sekolah["XII_RPL"]["Andi"]["nilai"] = 90; // Update data nested $sekolah["XII_RPL"]["Andi"]["mata_pelajaran"]["Matematika"] = 95; // ========== MENGHAPUS DATA ========== // Hapus mata pelajaran tertentu unset($sekolah["XII_RPL"]["Andi"]["mata_pelajaran"]["Kimia"]); // Hapus siswa unset($sekolah["XII_RPL"]["Dedi"]); // Hapus seluruh kelas unset($sekolah["XII_TKJ"]); // ========== MENAMBAH ELEMEN KE ARRAY DALAM ARRAY ========== $siswa_baru = array( "nama" => "Eva Sari", "nilai" => array() // Array kosong untuk nilai ); // Tambah nilai satu per satu $siswa_baru["nilai"][] = 88; // Tambah nilai pertama $siswa_baru["nilai"][] = 92; // Tambah nilai kedua // Atau gunakan array_push array_push($siswa_baru["nilai"], 85, 90); print_r($sekolah); print_r($siswa_baru); ?>

🔄 Looping Array Multidimensi - Semua Teknik

Berbagai cara untuk mengiterasi array multidimensi:

<?php // Data sample $sekolah = array( "XII_RPL" => array( "Andi" => array("nama" => "Andi Pratama", "nilai" => 85), "Dedi" => array("nama" => "Dedi Rahman", "nilai" => 88) ), "XII_TKJ" => array( "Budi" => array("nama" => "Budi Santoso", "nilai" => 92) ) ); $nilai_matrix = array( array(85, 90, 78), array(92, 85, 90), array(78, 88, 85) ); // ========== NESTED FOREACH - ASSOCIATIVE ========== echo "<h3>Data Sekolah per Kelas:</h3>"; foreach ($sekolah as $kelas => $daftar_siswa) { echo "<h4>Kelas: $kelas</h4>"; foreach ($daftar_siswa as $id_siswa => $data_siswa) { echo "ID: $id_siswa - "; echo "Nama: " . $data_siswa["nama"] . " - "; echo "Nilai: " . $data_siswa["nilai"] . "<br>"; } echo "<br>"; } // ========== NESTED FOR LOOP - INDEXED ========== echo "<h3>Matrix Nilai (For Loop):</h3>"; for ($i = 0; $i < count($nilai_matrix); $i++) { echo "Siswa " . ($i + 1) . ": "; for ($j = 0; $j < count($nilai_matrix[$i]); $j++) { echo $nilai_matrix[$i][$j] . " "; } echo "<br>"; } // ========== KOMBINASI FOREACH DAN FOR ========== echo "<h3>Matrix Nilai (Foreach + For):</h3>"; $no_siswa = 1; foreach ($nilai_matrix as $nilai_siswa) { echo "Siswa $no_siswa: "; for ($i = 0; $i < count($nilai_siswa); $i++) { echo $nilai_siswa[$i] . " "; } echo "<br>"; $no_siswa++; } // ========== FOREACH DENGAN REFERENSI (UNTUK MODIFIKASI) ========== echo "<h3>Menambah Bonus Nilai:</h3>"; foreach ($sekolah as $kelas => &$daftar_siswa) { foreach ($daftar_siswa as $id => &$siswa) { $siswa["nilai"] += 5; // Tambah bonus 5 poin echo $siswa["nama"] . " - Nilai baru: " . $siswa["nilai"] . "<br>"; } } // ========== RECURSIVE FUNCTION UNTUK ARRAY SANGAT DALAM ========== function tampilkan_array_recursive($array, $level = 0) { $indent = str_repeat("    ", $level); foreach ($array as $key => $value) { if (is_array($value)) { echo $indent . "$key: <br>"; tampilkan_array_recursive($value, $level + 1); } else { echo $indent . "$key: $value<br>"; } } } echo "<h3>Tampilan Recursive:</h3>"; tampilkan_array_recursive($sekolah); ?>

🔧 Fungsi Khusus untuk Array Multidimensi

PHP menyediakan fungsi-fungsi khusus untuk mengelola array multidimensi:

<?php // Data sample $siswa = array( array("nama" => "Andi", "nilai" => 85, "kelas" => "XII RPL"), array("nama" => "Budi", "nilai" => 92, "kelas" => "XII TKJ"), array("nama" => "Cici", "nilai" => 78, "kelas" => "XII MM"), array("nama" => "Dedi", "nilai" => 88, "kelas" => "XII RPL") ); // ========== ARRAY_COLUMN - EKSTRAK KOLOM ========== // Ambil semua nama siswa $daftar_nama = array_column($siswa, 'nama'); print_r($daftar_nama); // ["Andi", "Budi", "Cici", "Dedi"] // Ambil nilai dengan nama sebagai key $nilai_per_nama = array_column($siswa, 'nilai', 'nama'); print_r($nilai_per_nama); // ["Andi" => 85, "Budi" => 92, ...] // ========== ARRAY_MULTISORT - SORTING MULTIDIMENSI ========== // Urutkan berdasarkan nilai (descending) $nilai = array_column($siswa, 'nilai'); $nama = array_column($siswa, 'nama'); array_multisort($nilai, SORT_DESC, $nama, SORT_ASC, $siswa); print_r($siswa); // Diurutkan berdasarkan nilai tertinggi // ========== ARRAY_WALK_RECURSIVE - MODIFIKASI RECURSIVE ========== $data = array( "kelas_a" => array( "siswa1" => array("nama" => "andi", "kota" => "jakarta"), "siswa2" => array("nama" => "budi", "kota" => "bandung") ) ); // Ubah semua string menjadi uppercase array_walk_recursive($data, function(&$value, $key) { if (is_string($value)) { $value = strtoupper($value); } }); print_r($data); // ========== ARRAY_FILTER UNTUK MULTIDIMENSI ========== // Filter siswa dengan nilai >= 85 $siswa_berprestasi = array_filter($siswa, function($siswa) { return $siswa['nilai'] >= 85; }); print_r($siswa_berprestasi); // ========== ARRAY_MAP UNTUK TRANSFORMASI ========== // Tambahkan grade berdasarkan nilai $siswa_dengan_grade = array_map(function($siswa) { if ($siswa['nilai'] >= 90) { $siswa['grade'] = 'A'; } elseif ($siswa['nilai'] >= 80) { $siswa['grade'] = 'B'; } else { $siswa['grade'] = 'C'; } return $siswa; }, $siswa); print_r($siswa_dengan_grade); // ========== CUSTOM FUNCTION - CARI DALAM MULTIDIMENSI ========== function cari_siswa_by_nama($array, $nama_dicari) { foreach ($array as $siswa) { if (strtolower($siswa['nama']) == strtolower($nama_dicari)) { return $siswa; } } return null; } $hasil_cari = cari_siswa_by_nama($siswa, "Andi"); if ($hasil_cari) { echo "Ditemukan: " . $hasil_cari['nama'] . " - Nilai: " . $hasil_cari['nilai']; } ?>

💡 Tips & Best Practices Array Multidimensi:

✅ Yang Harus Dilakukan:

  • Gunakan struktur yang konsisten dan logis
  • Beri nama key yang deskriptif dan mudah dipahami
  • Selalu validasi keberadaan key sebelum akses
  • Gunakan fungsi built-in PHP untuk manipulasi
  • Dokumentasikan struktur array yang kompleks

❌ Yang Harus Dihindari:

  • Membuat struktur terlalu dalam (>4 level)
  • Menggunakan index numerik untuk data kompleks
  • Tidak konsisten dalam penamaan key
  • Mengakses nested array tanpa validasi
  • Membuat struktur yang sulit dipahami

⚙️ Fungsi di PHP - Panduan Komprehensif

🎯 Konsep Dasar Fungsi

Fungsi adalah blok kode yang dirancang untuk melakukan tugas tertentu dan dapat dipanggil berulang kali. Dalam PHP, ada dua jenis fungsi:

🏗️ Built-in Functions

Fungsi yang sudah disediakan PHP

Contoh: strlen(), count(), array_push()

👨‍💻 User-defined Functions

Fungsi yang kita buat sendiri

Contoh: hitungLuas(), validasiEmail()

💡 Tips & Best Practices Fungsi:

✅ Yang Harus Dilakukan:

  • Beri nama fungsi yang deskriptif dan jelas
  • Satu fungsi untuk satu tugas spesifik
  • Gunakan parameter dan return value dengan tepat
  • Validasi input parameter
  • Dokumentasikan fungsi kompleks dengan komentar
  • Gunakan type hinting untuk parameter (PHP 7+)

❌ Yang Harus Dihindari:

  • Membuat fungsi yang terlalu panjang (>50 baris)
  • Menggunakan variabel global berlebihan
  • Nama fungsi yang tidak jelas (func1, doSomething)
  • Fungsi dengan terlalu banyak parameter (>5)
  • Tidak menangani error atau edge cases
  • Duplikasi kode yang bisa dijadikan fungsi
