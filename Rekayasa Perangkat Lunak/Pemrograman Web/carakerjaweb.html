Pengenalan Web

🌍 Apa itu Web?

Web (World Wide Web) adalah sistem informasi global yang memungkinkan kita mengakses berbagai halaman website melalui internet. Bayangkan web seperti perpustakaan raksasa di dunia maya yang berisi miliaran halaman informasi!

💡 Analogi: Jika internet adalah jalan raya, maka web adalah kendaraan yang membawa informasi dari satu tempat ke tempat lain.

📊 Fakta Menarik Web:

  • • Web diciptakan tahun 1989 oleh Tim Berners-Lee
  • • Ada lebih dari 1.7 miliar website di dunia
  • • Setiap hari, 4.6 miliar orang menggunakan internet
  • • Google memproses 8.5 miliar pencarian per hari

🌟 Manfaat Web:

  • • Akses informasi global 24/7
  • • Komunikasi tanpa batas geografis
  • • E-commerce dan bisnis online
  • • Pendidikan dan pembelajaran jarak jauh

Arsitektur Client-Server

🤝 Apa itu Client-Server?

Client-Server adalah model komunikasi dimana client (seperti browser di HP-mu) meminta layanan dari server (komputer yang menyimpan website).

🍕 Analogi: Client seperti kamu yang pesan pizza, Server seperti restoran yang masak dan kirim pizza ke rumahmu!

📱 Client (Klien)

Client adalah perangkat yang meminta informasi atau layanan dari server.

🔍 Contoh Client:

  • • Browser (Chrome, Firefox, Safari, Edge)
  • • Aplikasi mobile (Instagram, WhatsApp, TikTok)
  • • Smart TV (Netflix, YouTube)
  • • Game online (Mobile Legends, PUBG)
  • • IoT devices (Smart speaker, smartwatch)

⚡ Tugas Client:

  • • Mengirim permintaan (HTTP request)
  • • Menampilkan data yang diterima
  • • Berinteraksi dengan user interface
  • • Memproses input user (klik, ketik, swipe)
  • • Caching data untuk performa

🎯 Contoh Nyata Client Bekerja:

📱 Buka Instagram:

  1. 1. Kamu tap ikon Instagram
  2. 2. App kirim request ke server Instagram
  3. 3. Server kirim data feed terbaru
  4. 4. App tampilkan foto & video di layar

🌐 Browsing Google:

  1. 1. Ketik "resep nasi goreng" di Chrome
  2. 2. Browser kirim query ke server Google
  3. 3. Server Google cari & kirim hasil
  4. 4. Browser tampilkan halaman hasil pencarian

🖥️ Server

Server adalah komputer khusus yang menyediakan layanan dan data untuk client 24/7.

🏢 Jenis Server:

  • • Web Server (Apache, Nginx, IIS)
  • • Database Server (MySQL, PostgreSQL, MongoDB)
  • • File Server (Google Drive, Dropbox)
  • • Game Server (Steam, Garena)
  • • Email Server (Gmail, Outlook)
  • • CDN Server (Cloudflare, AWS)

🔧 Tugas Server:

  • • Menerima ribuan request bersamaan
  • • Memproses logika bisnis aplikasi
  • • Mengirim response dalam milidetik
  • • Menyimpan & backup data penting
  • • Autentikasi & autorisasi user
  • • Load balancing & scaling

🏭 Contoh Server Besar di Indonesia:

💪 Hardware Powerful:

  • • CPU: 64-128 cores
  • • RAM: 256GB - 1TB
  • • Storage: SSD NVMe multi-TB
  • • Network: 10-100 Gbps

🛡️ Keamanan Tinggi:

  • • Firewall & DDoS protection
  • • SSL/TLS encryption
  • • Regular security updates
  • • 24/7 monitoring

HTTP vs HTTPS

📡 Apa itu HTTP?

HTTP (HyperText Transfer Protocol) adalah aturan komunikasi antara client dan server di web. Seperti bahasa yang digunakan browser dan server untuk "ngobrol".

📞 Analogi: HTTP seperti aturan telepon - ada cara tertentu untuk memulai percakapan, menyampaikan pesan, dan mengakhiri panggilan.

⚠️ HTTP (Tidak Aman)

🔓 Karakteristik:

  • • Data tidak dienkripsi
  • • Port default: 80
  • • Mudah disadap
  • • Tidak ada verifikasi identitas

⚠️ Bahaya:

  • • Password bisa dicuri
  • • Data pribadi terlihat
  • • Rentan serangan hacker

🔒 HTTPS (Aman)

🛡️ Karakteristik:

  • • Data dienkripsi (SSL/TLS)
  • • Port default: 443
  • • Sulit disadap
  • • Ada sertifikat keamanan

✅ Keuntungan:

  • • Data aman dari hacker
  • • Identitas server terverifikasi
  • • Dipercaya search engine

🔐 Cara Kerja Enkripsi HTTPS

HTTPS menggunakan enkripsi SSL/TLS untuk mengacak data sehingga hanya client dan server yang bisa membacanya. Seperti kotak rahasia dengan kunci khusus!

🔄 Proses SSL/TLS Handshake:

1

Client Hello

Browser kirim daftar algoritma enkripsi yang didukung

2

Server Hello + Certificate

Server pilih algoritma & kirim sertifikat digital

3

Certificate Verification

Browser cek sertifikat dengan Certificate Authority (CA)

4

Key Exchange

Buat session key unik untuk enkripsi komunikasi

5

Secure Communication

Semua data dienkripsi dengan AES-256 atau algoritma kuat lainnya

🛡️ Jenis Enkripsi Modern:

🔑 Symmetric Encryption:

  • • AES-256: Standar militer AS
  • • ChaCha20: Cepat di mobile
  • • Kunci sama untuk enkripsi & dekripsi
  • • Sangat cepat untuk data besar

🔐 Asymmetric Encryption:

  • • RSA-2048/4096: Paling populer
  • • ECDSA: Lebih efisien
  • • Public key & private key berbeda
  • • Untuk pertukaran kunci awal

⚡ Fakta Menarik Enkripsi:

  • • AES-256 butuh 2^256 kombinasi untuk dipecahkan (lebih banyak dari atom di alam semesta!)
  • • Komputer super tercepat butuh miliaran tahun untuk crack enkripsi modern
  • • Quantum computer masa depan bisa ancam RSA, tapi belum AES

🔍 Cara Mengenali Website Aman

✅ Website Aman (HTTPS):

  • • URL dimulai dengan https://
  • • Ada ikon gembok 🔒 di address bar
  • • Sertifikat valid (klik gembok untuk cek)
  • • Browser tidak tampilkan peringatan

⚠️ Website Tidak Aman (HTTP):

  • • URL dimulai dengan http://
  • • Tidak ada ikon gembok
  • • Browser tampilkan "Not Secure"
  • • Peringatan keamanan muncul

Tugas Pembelajaran

📋 Petunjuk Pengerjaan

  • • Jawab semua pertanyaan dengan lengkap dan jelas
  • • Gunakan bahasa sendiri, jangan copy-paste
  • • Berikan contoh jika diminta
  • • Tulis jawaban di buku tugas atau ketik di komputer

Soal 1: Pemahaman Dasar

Jelaskan dengan kata-kata sendiri apa yang dimaksud dengan arsitektur client-server! Berikan analogi sederhana yang mudah dipahami teman-temanmu.

💡 Tips: Pikirkan aktivitas sehari-hari yang mirip dengan client-server, seperti pesan makanan, kirim surat, atau aktivitas lainnya.

Soal 2: Identifikasi Komponen

Sebutkan 5 contoh client dan 5 contoh server yang kamu ketahui! Jelaskan fungsi masing-masing dalam 1-2 kalimat.

💡 Contoh format jawaban:
Client: Browser Chrome - berfungsi untuk menampilkan halaman web kepada user

Soal 3: HTTP vs HTTPS

Buatlah tabel perbandingan antara HTTP dan HTTPS! Minimal 5 perbedaan. Kemudian jelaskan mengapa HTTPS lebih aman daripada HTTP.

💡 Format tabel: Aspek | HTTP | HTTPS
Contoh: Keamanan | Tidak aman | Aman dengan enkripsi

Soal 4: Studi Kasus

Kamu ingin membuat toko online untuk menjual produk buatan sendiri. Jelaskan bagaimana arsitektur client-server akan bekerja dalam website toko onlinemu! Sebutkan juga mengapa harus menggunakan HTTPS.

💡 Yang perlu dijelaskan: Peran client, peran server, alur transaksi, dan pentingnya keamanan data pelanggan.

Soal 5: Analisis Keamanan

Bagaimana cara kamu mengecek apakah sebuah website aman atau tidak? Sebutkan minimal 4 cara dan jelaskan langkah-langkahnya!

💡 Petunjuk: Pikirkan tanda-tanda visual di browser, cara cek sertifikat, dan hal-hal yang perlu diwaspadai.

⏰ Informasi Pengumpulan

  • Deadline: 1 minggu setelah pembelajaran
  • Format: Tulis tangan di buku tugas atau ketik (PDF/Word)
  • Penilaian: Kelengkapan jawaban, pemahaman konsep, kreativitas
  • Bonus: Tambahan nilai untuk jawaban yang kreatif dan inovatif!
