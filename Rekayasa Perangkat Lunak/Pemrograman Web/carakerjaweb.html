Pengenalan Web

🌍 Apa itu Web?

Web (World Wide Web) adalah sistem informasi global yang memungkinkan kita mengakses berbagai halaman website melalui internet. Bayangkan web seperti perpustakaan raksasa di dunia maya!

💡 Analogi: Jika internet adalah jalan raya, maka web adalah kendaraan yang membawa informasi dari satu tempat ke tempat lain.

Arsitektur Client-Server

🤝 Apa itu Client-Server?

Client-Server adalah model komunikasi dimana client (seperti browser di HP-mu) meminta layanan dari server (komputer yang menyimpan website).

🍕 Analogi: Client seperti kamu yang pesan pizza, Server seperti restoran yang masak dan kirim pizza ke rumahmu!

📱 Client (Klien)

Client adalah perangkat yang meminta informasi atau layanan.

🔍 Contoh Client:

  • • Browser (Chrome, Firefox, Safari)
  • • Aplikasi mobile (Instagram, WhatsApp)
  • • Smart TV
  • • Game online

⚡ Tugas Client:

  • • Mengirim permintaan (request)
  • • Menampilkan data yang diterima
  • • Berinteraksi dengan user
  • • Memproses input user

🖥️ Server

Server adalah komputer yang menyediakan layanan dan data untuk client.

🏢 Jenis Server:

  • • Web Server (Apache, Nginx)
  • • Database Server (MySQL, PostgreSQL)
  • • File Server
  • • Game Server

🔧 Tugas Server:

  • • Menerima permintaan client
  • • Memproses permintaan
  • • Mengirim response/jawaban
  • • Menyimpan dan mengelola data

HTTP vs HTTPS

📡 Apa itu HTTP?

HTTP (HyperText Transfer Protocol) adalah aturan komunikasi antara client dan server di web. Seperti bahasa yang digunakan browser dan server untuk "ngobrol".

📞 Analogi: HTTP seperti aturan telepon - ada cara tertentu untuk memulai percakapan, menyampaikan pesan, dan mengakhiri panggilan.

⚠️ HTTP (Tidak Aman)

🔓 Karakteristik:

  • • Data tidak dienkripsi
  • • Port default: 80
  • • Mudah disadap
  • • Tidak ada verifikasi identitas

⚠️ Bahaya:

  • • Password bisa dicuri
  • • Data pribadi terlihat
  • • Rentan serangan hacker

🔒 HTTPS (Aman)

🛡️ Karakteristik:

  • • Data dienkripsi (SSL/TLS)
  • • Port default: 443
  • • Sulit disadap
  • • Ada sertifikat keamanan

✅ Keuntungan:

  • • Data aman dari hacker
  • • Identitas server terverifikasi
  • • Dipercaya search engine

🔐 Cara Kerja Enkripsi HTTPS

HTTPS menggunakan enkripsi untuk mengacak data sehingga hanya client dan server yang bisa membacanya.

🔄 Proses Enkripsi:

1

Client minta koneksi aman ke server

2

Server kirim sertifikat SSL/TLS

3

Client verifikasi sertifikat

4

Buat kunci enkripsi bersama

5

Semua data dienkripsi dengan kunci tersebut

🔍 Cara Mengenali Website Aman

✅ Website Aman (HTTPS):

  • • URL dimulai dengan https://
  • • Ada ikon gembok 🔒 di address bar
  • • Sertifikat valid (klik gembok untuk cek)
  • • Browser tidak tampilkan peringatan

⚠️ Website Tidak Aman (HTTP):

  • • URL dimulai dengan http://
  • • Tidak ada ikon gembok
  • • Browser tampilkan "Not Secure"
  • • Peringatan keamanan muncul

Tugas Pembelajaran

📋 Petunjuk Pengerjaan

  • • Jawab semua pertanyaan dengan lengkap dan jelas
  • • Gunakan bahasa sendiri, jangan copy-paste
  • • Berikan contoh jika diminta
  • • Tulis jawaban di buku tugas atau ketik di komputer

Soal 1: Pemahaman Dasar

Jelaskan dengan kata-kata sendiri apa yang dimaksud dengan arsitektur client-server! Berikan analogi sederhana yang mudah dipahami teman-temanmu.

💡 Tips: Pikirkan aktivitas sehari-hari yang mirip dengan client-server, seperti pesan makanan, kirim surat, atau aktivitas lainnya.

Soal 2: Identifikasi Komponen

Sebutkan 5 contoh client dan 5 contoh server yang kamu ketahui! Jelaskan fungsi masing-masing dalam 1-2 kalimat.

💡 Contoh format jawaban:
Client: Browser Chrome - berfungsi untuk menampilkan halaman web kepada user

Soal 3: HTTP vs HTTPS

Buatlah tabel perbandingan antara HTTP dan HTTPS! Minimal 5 perbedaan. Kemudian jelaskan mengapa HTTPS lebih aman daripada HTTP.

💡 Format tabel: Aspek | HTTP | HTTPS
Contoh: Keamanan | Tidak aman | Aman dengan enkripsi

Soal 4: Studi Kasus

Kamu ingin membuat toko online untuk menjual produk buatan sendiri. Jelaskan bagaimana arsitektur client-server akan bekerja dalam website toko onlinemu! Sebutkan juga mengapa harus menggunakan HTTPS.

💡 Yang perlu dijelaskan: Peran client, peran server, alur transaksi, dan pentingnya keamanan data pelanggan.

Soal 5: Analisis Keamanan

Bagaimana cara kamu mengecek apakah sebuah website aman atau tidak? Sebutkan minimal 4 cara dan jelaskan langkah-langkahnya!

💡 Petunjuk: Pikirkan tanda-tanda visual di browser, cara cek sertifikat, dan hal-hal yang perlu diwaspadai.
