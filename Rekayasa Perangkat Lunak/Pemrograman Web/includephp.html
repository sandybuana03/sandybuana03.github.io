Pengenalan Include & Require

Apa itu Include & Require?

Include dan Require adalah perintah PHP yang digunakan untuk menggabungkan atau menyisipkan isi dari satu file PHP ke dalam file PHP lainnya. Bayangkan seperti menyalin-tempel otomatis! 📋✨

Include

  • Jika file tidak ditemukan, hanya muncul warning
  • Script tetap berjalan meskipun ada error
  • Lebih fleksibel untuk file opsional

Require

  • Jika file tidak ditemukan, muncul fatal error
  • Script berhenti jika ada error
  • Lebih ketat untuk file penting

Mengapa Perlu Include/Require?

Menghindari pengulangan kode
Membuat kode lebih modular
Mudah maintenance
Kerja tim lebih efisien

Perbedaan Detail Include vs Require

Aspek Include Require
Jika File Tidak Ada ⚠️ Warning saja, script lanjut ❌ Fatal Error, script berhenti
Kapan Digunakan File opsional (sidebar, ads, dll) File penting (config, functions)
Performance Lebih cepat (tidak fatal) Sedikit lambat (check ketat)
Keamanan Kurang aman untuk file kritis Lebih aman untuk file kritis

Include_once vs Require_once

include_once

<?php
include_once 'config.php';
include_once 'config.php'; // Tidak dijalankan lagi
?>

File hanya di-include sekali, meskipun dipanggil berkali-kali

require_once

<?php
require_once 'functions.php';
require_once 'functions.php'; // Tidak dijalankan lagi
?>

File hanya di-require sekali, mencegah duplikasi fungsi

Contoh Error yang Terjadi

❌ Error dengan REQUIRE:

Fatal error: require(): Failed opening required 'file_tidak_ada.php'
(include_path='.;C:\xampp\php\PEAR') in C:\xampp\htdocs\test.php on line 2

Script berhenti total, halaman tidak tampil sama sekali

⚠️ Warning dengan INCLUDE:

Warning: include(file_tidak_ada.php): failed to open stream:
No such file or directory in C:\xampp\htdocs\test.php on line 2

Muncul warning tapi script tetap jalan, halaman tetap tampil

Contoh Kasus Real World

Kasus 1: Website E-commerce

🔒 File yang WAJIB (require):

  • database.php - Koneksi DB
  • security.php - Fungsi keamanan
  • auth.php - Login system

📱 File yang OPSIONAL (include):

  • ads.php - Banner iklan
  • chat.php - Live chat
  • analytics.php - Google Analytics

Mengapa? Jika database.php error, toko online tidak bisa jalan sama sekali. Tapi jika ads.php error, toko tetap bisa berjalan normal tanpa iklan.

Kasus 2: Sistem Blog

<?php
// File: artikel.php
// File penting - harus ada
require_once 'config.php'; // Konfigurasi database
require_once 'functions.php'; // Fungsi-fungsi penting
// File opsional - boleh tidak ada
include 'sidebar.php'; // Sidebar bisa kosong
include 'related-posts.php'; // Artikel terkait
include 'comments.php'; // Sistem komentar
?>

Kasus 3: Website Multi-bahasa

<?php
// File: index.php
$bahasa = $_GET['lang'] ?? 'id';
// File bahasa - gunakan include karena ada fallback
if (file_exists("lang/{$bahasa}.php")) {
include "lang/{$bahasa}.php";
} else {
include 'lang/id.php'; // Default bahasa Indonesia
}
?>

Keuntungan: Jika file bahasa tertentu tidak ada, website tetap tampil dalam bahasa default (Indonesia).

Langkah-langkah Praktik

1
Persiapan Folder dan File

Pertama, kita buat struktur folder yang rapi untuk project kita:

📁 Struktur Folder:
project-php/
├── index.php
├── header.php
├── footer.php
└── config.php
Tips:

Buat folder baru di htdocs (jika pakai XAMPP) atau di server lokal kamu dengan nama "project-php"

2
Membuat File config.php

File ini berisi konfigurasi website kita:

<?php
// File: config.php
// Konfigurasi website
$site_name = "Belajar PHP Yuk!";
$site_url = "http://localhost/project-php";
$author = "Siswa SMK Keren";
// Fungsi untuk menampilkan tanggal
function getTanggalHariIni() {
return date("d F Y");
}
?>

3
Membuat File header.php

File header yang berisi bagian atas website (tanpa tag HTML utama):

<?php
// File: header.php
// Header yang akan muncul di semua halaman
?>
<div class="header">
<h1>🌟 <?php echo $site_name; ?> 🌟</h1>
<p>Selamat datang di website keren! Hari ini: <?php echo getTanggalHariIni(); ?></p>
</div>
<div class="container">

4
Membuat File footer.php

File footer yang berisi bagian bawah website (tanpa tag penutup HTML):

<?php
// File: footer.php
// Footer yang akan muncul di semua halaman
?>
</div> <!-- Tutup container -->
<footer style="background: #333; color: white; text-align: center; padding: 20px; margin-top: 40px;">
<p>© 2024 <?php echo $author; ?> | Dibuat dengan ❤️ menggunakan PHP</p>
<p>🚀 Belajar PHP itu Menyenangkan! 🚀</p>
</footer>

5
Membuat File index.php (File Utama Lengkap)

File utama yang berisi struktur HTML lengkap dan menggabungkan semua file:

<?php
// File: index.php
// File utama dengan struktur HTML lengkap
// 1. Wajib include config dulu (pakai require karena penting)
require 'config.php';
?>
<!DOCTYPE html>
<html lang="id">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title><?php echo $site_name; ?></title>
<style>
body { font-family: Arial; margin: 0; background: #f0f8ff; }
.header { background: linear-gradient(45deg, #667eea, #764ba2); color: white; padding: 20px; text-align: center; }
.container { max-width: 800px; margin: 20px auto; padding: 20px; }
</style>
</head>
<body>
<?php
// 2. Include header (bagian atas website)
require 'header.php';
?>
<h2>🎉 Selamat Datang di Halaman Utama! 🎉</h2>
<div style="background: linear-gradient(45deg, #ff9a9e, #fecfef); padding: 20px; border-radius: 10px; margin: 20px 0;">
<h3>✨ Informasi Website ✨</h3>
<p><strong>Nama Website:</strong> <?php echo $site_name; ?></p>
<p><strong>URL Website:</strong> <?php echo $site_url; ?></p>
<p><strong>Dibuat oleh:</strong> <?php echo $author; ?></p>
</div>
<div style="background: #e3f2fd; padding: 15px; border-radius: 8px; border-left: 4px solid #2196f3;">
<h4>🎯 Yang Kamu Pelajari Hari Ini:</h4>
<ul>
<li>✅ Cara menggunakan require untuk file penting</li>
<li>✅ Cara menggunakan include untuk file opsional</li>
<li>✅ Membuat struktur website yang modular</li>
<li>✅ Menghindari pengulangan kode</li>
</ul>
</div>
<?php
// 3. Include footer di bagian akhir
require 'footer.php';
?>
</body>
</html>

6
Menjalankan dan Testing

Sekarang saatnya menjalankan project kita!

Cara Menjalankan:

  1. Pastikan XAMPP sudah running (Apache)
  2. Buka browser dan ketik: http://localhost/project-php
  3. Kamu akan melihat website yang cantik dengan header, konten, dan footer!

Coba Eksperimen:

  • Ubah nama website di config.php
  • Tambah warna baru di header.php
  • Coba ganti require dengan include dan lihat perbedaannya
  • Buat file baru dan include ke index.php

Selamat! Kamu Sudah Berhasil! 🎉

Yang Sudah Kamu Kuasai:

  • Membuat file modular
  • Menggunakan require & include
  • Struktur website yang rapi

Keuntungan yang Didapat:

  • Kode tidak berulang
  • Mudah maintenance
  • Website lebih profesional

Tips & Tricks Pro Developer

Best Practices yang Wajib Diikuti

1. Gunakan Path yang Benar

// ✅ Bagus - path relatif
require_once '../config/database.php';
// ✅ Lebih bagus - path absolut
require_once __DIR__ . '/config/database.php';

2. Selalu Cek File Exists

if (file_exists('optional.php')) {
include 'optional.php';
}

3. Buat Konstanta untuk Path

define('ROOT_PATH', __DIR__);
require_once ROOT_PATH . '/config.php';

4. Gunakan Autoloader

spl_autoload_register(function($class) {
include "classes/{$class}.php";
});

Kesalahan yang Sering Terjadi

❌ Jangan Lakukan Ini:

// Buruk - path hardcode
include 'C:\xampp\htdocs\project\config.php';
// Buruk - include di dalam loop
for($i=0; $i<10; $i++) {
include 'functions.php'; // Duplikasi!
}

Path hardcode tidak portable, include dalam loop menyebabkan error duplikasi fungsi

✅ Lakukan Ini:

// Bagus - path relatif
include_once dirname(__FILE__) . '/config.php';
// Bagus - include_once untuk fungsi
require_once 'functions.php';
for($i=0; $i<10; $i++) {
doSomething(); // Panggil fungsi saja
}

Tips Performance & Keamanan

Performance

  • • Gunakan require_once untuk file besar
  • • Hindari include dalam loop
  • • Cache hasil include jika perlu
  • • Gunakan opcode cache (OPcache)

Keamanan

  • • Validasi path sebelum include
  • • Jangan include dari user input
  • • Gunakan whitelist file yang boleh di-include
  • • Set proper file permissions

Debugging

  • • Gunakan get_included_files()
  • • Check dengan file_exists()
  • • Log error include/require
  • • Gunakan absolute path untuk debug

Teknik Advanced

🎯 Dynamic Include dengan Keamanan

<?php
// Whitelist file yang boleh di-include
$allowed_files = ['home', 'about', 'contact'];
$page = $_GET['page'] ?? 'home';
if (in_array($page, $allowed_files)) {
$file = "pages/{$page}.php";
if (file_exists($file)) {
include $file;
} else {
include 'pages/404.php';
}
} else {
include 'pages/home.php';
}
?>

🔧 Include dengan Return Value

// File: config.php
return [
'db_host' => 'localhost',
'db_name' => 'myapp',
'version' => '1.0.0'
];
// File: index.php
$config = include 'config.php';
echo $config['version']; // Output: 1.0.0
