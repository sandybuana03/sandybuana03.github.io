Pengenalan Include & Require

🔗 Apa itu Include & Require?

Include dan Require adalah perintah PHP yang digunakan untuk menggabungkan atau menyisipkan isi dari satu file PHP ke dalam file PHP lainnya. Ini seperti "copy-paste" otomatis yang sangat powerful!

🎭 Analogi Mudah:

Seperti puzzle - setiap file adalah potongan puzzle yang ketika digabungkan membentuk website yang utuh dan indah!

🏛️ Sejarah & Filosofi

📜 Sejarah Singkat

Include/require sudah ada sejak PHP versi awal (1995). Diciptakan untuk mengatasi masalah duplikasi kode yang sering terjadi dalam pengembangan web.

🎯 Filosofi DRY

Don't Repeat Yourself - Prinsip fundamental dalam programming. Tulis sekali, gunakan berkali-kali!

🎯 Mengapa Sangat Penting?

✅ Keuntungan Luar Biasa:

  • • Modularitas: Kode terpisah per fungsi
  • • Reusability: Pakai ulang tanpa batas
  • • Maintainability: Update sekali, berlaku semua
  • • Collaboration: Tim bisa kerja parallel
  • • Performance: Loading lebih efisien
  • • Security: Isolasi kode sensitif

❌ Tanpa Include/Require:

  • • Spaghetti Code: Kode berantakan
  • • Copy-Paste Hell: Duplikasi dimana-mana
  • • Bug Nightmare: Error di banyak tempat
  • • Update Horror: Ubah satu, ubah semua
  • • File Monster: File raksasa sulit dibaca
  • • Team Chaos: Konflik kode terus-menerus

🧠 Konsep Fundamental

🔄 Proses Include/Require

  1. PHP parser menemukan perintah include/require
  2. Mencari file yang diminta di lokasi yang ditentukan
  3. Membaca isi file dan "menyalin" ke posisi perintah
  4. Melanjutkan eksekusi seolah kode ada di file asli
  5. Variabel dan fungsi dari file yang di-include bisa digunakan

🎯 Scope & Context

File yang di-include/require memiliki akses ke semua variabel yang sudah didefinisikan sebelumnya, dan sebaliknya - variabel dari file yang di-include bisa digunakan setelahnya.

🔬 Konsep Lanjutan

🌐 Include Path & Stream Wrappers

PHP mencari file include/require berdasarkan include_path yang dikonfigurasi:

// Cek include path saat ini

echo get_include_path();


// Set include path baru

set_include_path('/path/to/includes');


// Include dari URL (jika allow_url_include = On)

include 'http://example.com/config.php';

🔄 Return Values dari Include

File yang di-include dapat mengembalikan nilai:

File: data.php

<?php

$data = ['name' => 'SMK', 'year' => 2024];

return $data;

?>

File: main.php

<?php

$result = include 'data.php';

echo $result['name']; // SMK

?>

🛡️ Security Considerations

⚠️ Path Traversal Attack

Jangan include file berdasarkan input user tanpa validasi!

// BAHAYA! Jangan lakukan ini:

include $_GET['page'] . '.php';

// User bisa input: ../../etc/passwd

✅ Safe Practice

// Validasi input dengan whitelist

$allowed = ['home', 'about', 'contact'];

if (in_array($_GET['page'], $allowed)) {

include $_GET['page'] . '.php';

}

⚡ Performance & Optimization

🚀 OPcache & Include

OPcache menyimpan bytecode file yang di-include untuk performa lebih baik:

// Cek status OPcache

if (function_exists('opcache_get_status')) {

$status = opcache_get_status();

echo $status['opcache_enabled'] ? 'Enabled' : 'Disabled';

}

📊 Monitoring Include Performance

// Ukur waktu include

$start = microtime(true);

include 'heavy_file.php';

$end = microtime(true);

echo "Include time: " . ($end - $start) . " seconds";

💡 Best Practices untuk Performance

  • Gunakan absolute path untuk menghindari pencarian file
  • Minimize jumlah include/require dalam loop
  • Gunakan autoloading untuk class files
  • Cache hasil include jika memungkinkan

Perintah Include

📖 Sintaks Include

// Cara 1: Include biasa

include 'nama_file.php';


// Cara 2: Include dengan kurung

include('nama_file.php');


// Cara 3: Include dengan path

include './folder/file.php';

include '../config/db.php';

📍 Path Options

  • • Relative: './folder/file.php'
  • • Absolute: '/var/www/file.php'
  • • Parent: '../config/file.php'
  • • Root: $_SERVER['DOCUMENT_ROOT']

🎭 Karakteristik Include

😊 Sifat "Santai"

Jika file tidak ditemukan, include hanya memberikan WARNING dan script tetap berjalan.

Warning: include(missing.php): failed to open stream

🔄 Bisa Berulang

File yang sama bisa di-include berkali-kali dalam satu script.

Berguna untuk template yang perlu dipanggil berulang

🔍 Include vs Include_once

include

include 'functions.php';

include 'functions.php'; // Dijalankan lagi

include 'functions.php'; // Dan lagi!

File di-include setiap kali dipanggil

include_once

include_once 'functions.php';

include_once 'functions.php'; // Diabaikan

include_once 'functions.php'; // Diabaikan

File hanya di-include sekali saja

💻 Contoh Praktis Lengkap

File: config.php

<?php

// Konfigurasi website

$site_title = "SMK Teknologi";

$site_description = "Sekolah Terbaik";

$admin_email = "admin@smk.com";

?>

File: header.php

<!DOCTYPE html>

<html lang="id">

<head>

<meta charset="UTF-8">

<title><?php echo $site_title; ?></title>

<meta name="description" content="<?php echo $site_description; ?>">

</head>

<body>

<header>

<h1><?php echo $site_title; ?></h1>

</header>

File: navigation.php

<nav>

<ul>

<li><a href="index.php">Beranda</a></li>

<li><a href="about.php">Tentang</a></li>

<li><a href="contact.php">Kontak</a></li>

</ul>

</nav>

File: index.php

<?php

// Include konfigurasi terlebih dahulu

include_once 'config.php';


// Include header (menggunakan variabel dari config)

include 'header.php';


// Include navigasi

include 'navigation.php';

?>


<main>

<h2>Selamat Datang di <?php echo $site_title; ?></h2>

<p><?php echo $site_description; ?></p>

<p>Hubungi: <?php echo $admin_email; ?></p>

</main>


<?php include 'footer.php'; ?>

⚠️ Error Handling Include

Contoh Error Include

<?php

include 'file_tidak_ada.php'; // Warning!

echo "Script tetap berjalan";

?>

Output: Warning: include(file_tidak_ada.php): failed to open stream: No such file or directory

Script tetap berjalan

💡 Best Practices Include

✅ Do's

  • • Gunakan untuk file template/UI
  • • Gunakan include_once untuk functions
  • • Cek file existence dengan file_exists()
  • • Gunakan path yang konsisten

❌ Don'ts

  • • Jangan untuk file konfigurasi penting
  • • Jangan include file yang sama berulang
  • • Hindari path yang terlalu kompleks
  • • Jangan abaikan warning messages

🏗️ Design Patterns dengan Include/Require

🎨 Template Pattern

Pisahkan logic dan presentation:

controller.php

<?php

// Business logic

$users = getUsersFromDB();

$title = "Daftar Pengguna";


// Load template

include 'views/users.php';

?>

views/users.php

<h1><?= $title ?></h1>

<ul>

<?php foreach($users as $user): ?>

<li><?= $user['name'] ?></li>

<?php endforeach; ?>

</ul>

🏭 Factory Pattern

Include file berdasarkan kondisi:

<?php

// Dynamic include berdasarkan database type

$db_type = $_ENV['DB_TYPE'] ?? 'mysql';


switch($db_type) {

case 'mysql':

require_once 'drivers/mysql_driver.php';

break;

case 'postgresql':

require_once 'drivers/pgsql_driver.php';

break;

}

?>

🔧 Configuration Pattern

Include konfigurasi berdasarkan environment:

<?php

// Load environment-specific config

$env = $_SERVER['APP_ENV'] ?? 'production';

$config_file = "config/{$env}.php";


if (file_exists($config_file)) {

require_once $config_file;

} else {

require_once 'config/default.php';

}

?>

🔄 Advanced Techniques

🎯 Conditional Include

<?php

// Include berdasarkan user role

if ($user['role'] === 'admin') {

include 'admin/dashboard.php';

} elseif ($user['role'] === 'teacher') {

include 'teacher/dashboard.php';

} else {

include 'student/dashboard.php';

}

?>

🔁 Dynamic Include dengan Loop

<?php

// Include multiple widgets

$widgets = ['weather', 'news', 'calendar', 'todo'];


foreach ($widgets as $widget) {

$widget_file = "widgets/{$widget}.php";

if (file_exists($widget_file)) {

echo "<div class='widget'>";

include $widget_file;

echo "</div>";

}

}

?>

📦 Include dengan Buffer

<?php

// Capture include output

ob_start();

include 'template.php';

$content = ob_get_clean();


// Process atau modify content

$content = str_replace('{{YEAR}}', date('Y'), $content);

echo $content;

?>

Perintah Require

📖 Sintaks Require

// Cara 1: Require biasa

require 'nama_file.php';


// Cara 2: Require dengan kurung

require('nama_file.php');

🚨 Karakteristik Require

😤 Sifat "Tegas"

Jika file tidak ditemukan, require memberikan FATAL ERROR dan script berhenti total!

🛡️ Lebih Aman

Cocok untuk file yang sangat penting, seperti konfigurasi database atau fungsi utama.

💻 Contoh Praktis

File: config.php (File Penting!)

<?php

$host = 'localhost';

$username = 'root';

$password = '';

$database = 'sekolah';

?>

File: koneksi.php

<?php

require 'config.php'; // HARUS ada!


$conn = mysqli_connect($host, $username, $password, $database);

// Jika config.php tidak ada, script berhenti di sini

?>

💡 Tips Penggunaan

  • Gunakan require untuk: File konfigurasi, koneksi database, fungsi penting
  • Gunakan include untuk: Header, footer, sidebar yang bersifat opsional
⚖️

Perbedaan Include vs Require

Aspek Include 📥 Require ⚡
Jika file tidak ada ⚠️ Warning, script lanjut 💥 Fatal Error, script berhenti
Tingkat kepentingan 😊 Opsional 🚨 Wajib/Kritis
Penggunaan berulang ✅ Bisa berkali-kali ✅ Bisa berkali-kali
Cocok untuk Header, Footer, Sidebar Config, Database, Functions

📥 Include_once & Require_once

Varian yang hanya menyertakan file sekali saja, meskipun dipanggil berkali-kali.

include_once 'header.php';

require_once 'config.php';

🎯 Kapan Menggunakan?

  • include: File template, komponen UI
  • require: File sistem, konfigurasi
  • *_once: Mencegah duplikasi

🎭 Simulasi Error

Include (File tidak ada)

⚠️ Warning: include(file_tidak_ada.php): failed to open stream

✅ Script tetap berjalan...

Require (File tidak ada)

💥 Fatal error: require(): Failed opening required 'file_tidak_ada.php'

❌ Script berhenti total!

Praktik Langkah demi Langkah

📁 Langkah 1: Persiapan Folder

Buat struktur folder seperti ini:

📁 website/

📄 index.php

📄 header.php

📄 footer.php

📄 config.php

📝 Langkah 2: Buat File Header

Buat file header.php:

<!DOCTYPE html>

<html lang="id">

<head>

<meta charset="UTF-8">

<title>Website SMK Keren</title>

<style>

body { font-family: Arial; margin: 0; }

header { background: #4CAF50; color: white; padding: 20px; }

</style>

</head>

<body>

<header>

<h1>🎓 SMK Teknologi Informasi</h1>

</header>

📝 Langkah 3: Buat File Footer

Buat file footer.php:

<footer style="background: #333; color: white; text-align: center; padding: 20px; margin-top: 50px;">

<p>© 2024 SMK Teknologi Informasi. Semua hak dilindungi.</p>

</footer>

</body>

</html>

⚙️ Langkah 4: Buat File Config

Buat file config.php:

<?php

// Konfigurasi Website

$site_name = "SMK Teknologi Informasi";

$site_url = "https://smk-ti.sch.id";

$admin_email = "admin@smk-ti.sch.id";


// Konfigurasi Database

$db_host = "localhost";

$db_user = "root";

$db_pass = "";

$db_name = "sekolah";

?>

🏠 Langkah 5: Buat File Utama

Buat file index.php:

<?php

// Sertakan konfigurasi (WAJIB ada)

require_once 'config.php';


// Sertakan header

include 'header.php';

?>


<main style="padding: 20px; max-width: 800px; margin: 0 auto;">

<h2>Selamat Datang di <?php echo $site_name; ?></h2>

<p>Website resmi: <a href="<?php echo $site_url; ?>"><?php echo $site_url; ?></a></p>

<p>Hubungi admin: <?php echo $admin_email; ?></p>

</main>


<?php

// Sertakan footer

include 'footer.php';

?>

🚀 Langkah 6: Jalankan & Test

  1. Buka XAMPP dan start Apache
  2. Simpan semua file di folder htdocs/website/
  3. Buka browser dan akses localhost/website/
  4. Lihat hasilnya! 🎉

Tugas Praktik

🎯 Tugas 1: Website Profil Sekolah

Instruksi: Buat website profil sekolah dengan struktur modular menggunakan include/require.

File yang harus dibuat:

  • config.php - Berisi data sekolah (nama, alamat, telepon, email)
  • header.php - Header dengan logo dan nama sekolah
  • navbar.php - Menu navigasi (Beranda, Profil, Jurusan, Kontak)
  • footer.php - Footer dengan informasi kontak
  • index.php - Halaman utama yang menggabungkan semua

💡 Tips:

  • Gunakan require_once untuk config.php
  • Gunakan include untuk header, navbar, footer
  • Tampilkan data dari config.php di berbagai halaman

🔧 Tugas 2: Sistem Modular

Instruksi: Buat sistem yang menunjukkan perbedaan include vs require.

Yang harus dilakukan:

  1. Buat file penting.php berisi fungsi vital
  2. Buat file opsional.php berisi konten tambahan
  3. Buat test_include.php yang include file yang tidak ada
  4. Buat test_require.php yang require file yang tidak ada
  5. Bandingkan hasilnya dan buat laporan
