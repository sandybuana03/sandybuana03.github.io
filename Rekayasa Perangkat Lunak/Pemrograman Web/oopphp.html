📚 Pengenalan OOP dalam PHP

🤖 Apa itu OOP?

Object-Oriented Programming (OOP) adalah cara menulis program dengan mengorganisir kode dalam bentuk "objek". Bayangkan seperti membuat cetakan kue (class) yang bisa digunakan untuk membuat banyak kue (object) dengan bentuk yang sama!

🏗️

Class

Blueprint atau cetakan untuk membuat object

🎭

Object

Hasil dari class yang sudah dibuat (instance)

⚡

Method

Fungsi atau aksi yang bisa dilakukan object

🌟 Mengapa Belajar OOP?

✨ Keuntungan OOP:

  • • Kode lebih teratur dan mudah dibaca
  • • Mudah untuk maintenance
  • • Bisa digunakan ulang (reusable)
  • • Lebih aman dan terkontrol

🚀 Contoh Penggunaan:

  • • Sistem login user
  • • Aplikasi e-commerce
  • • Game sederhana
  • • Website dinamis

🏗️ Memahami Class dalam PHP

🎯 Apa itu Class?

Class adalah template atau blueprint untuk membuat object. Seperti denah rumah yang digunakan untuk membangun banyak rumah dengan desain yang sama!

💡 Analogi: Class = Cetakan Kue, Object = Kue yang dihasilkan

📝 Struktur Class dalam PHP

<?php class NamaClass { // Properties (variabel dalam class) public $property1; private $property2; // Methods (fungsi dalam class) public function namaMethod() { // kode di sini } } ?>

🚗 Contoh Class Sederhana: Mobil

<?php class Mobil { // Properties - Ciri-ciri mobil public $merk; public $warna; public $kecepatan = 0; // Method untuk menyalakan mesin public function nyalakanMesin() { return "Mesin mobil " . $this->merk . " menyala!"; } // Method untuk menambah kecepatan public function gas($tambahKecepatan) { $this->kecepatan += $tambahKecepatan; return "Kecepatan sekarang: " . $this->kecepatan . " km/jam"; } } ?>

Penjelasan:

  • • $merk, $warna, $kecepatan = Properties (ciri-ciri mobil)
  • • nyalakanMesin(), gas() = Methods (aksi yang bisa dilakukan mobil)
  • • $this = Merujuk ke object yang sedang aktif

🔑 Properties

Variabel yang menyimpan data dalam class

  • • public: Bisa diakses dari mana saja
  • • private: Hanya bisa diakses dalam class
  • • protected: Bisa diakses class turunan

⚡ Methods

Fungsi yang ada dalam class

  • • Bisa menerima parameter
  • • Bisa mengembalikan nilai
  • • Menggunakan $this untuk akses properties

🎭 Memahami Object dalam PHP

🎯 Apa itu Object?

Object adalah instance atau hasil dari class yang sudah dibuat. Jika class adalah cetakan kue, maka object adalah kue yang sudah jadi!

💡 Satu class bisa membuat banyak object dengan karakteristik berbeda

🔨 Cara Membuat Object

<?php // Membuat object dari class Mobil $mobil1 = new Mobil(); $mobil2 = new Mobil(); // Mengisi properties mobil pertama $mobil1->merk = "Toyota"; $mobil1->warna = "Merah"; // Mengisi properties mobil kedua $mobil2->merk = "Honda"; $mobil2->warna = "Biru"; ?>

⚡ Memahami Method dalam PHP

🎯 Apa itu Method?

Method adalah fungsi yang ada dalam class. Method menentukan apa yang bisa dilakukan oleh object tersebut, seperti aksi atau perilaku!

💡 Analogi: Jika object adalah robot, method adalah perintah yang bisa dilakukan robot

📝 Jenis-jenis Method

🔓 Public Method

Bisa diakses dari luar class

public function namaMethod() { // kode di sini }

🔒 Private Method

Hanya bisa diakses dalam class

private function namaMethod() { // kode di sini }

🎮 Contoh Method dengan Parameter

<?php class Kalkulator { // Method tanpa parameter public function sapa() { return "Halo! Saya kalkulator pintar! 🤖"; } // Method dengan parameter public function tambah($angka1, $angka2) { $hasil = $angka1 + $angka2; return "Hasil: " . $angka1 . " + " . $angka2 . " = " . $hasil; } // Method dengan default parameter public function pangkat($angka, $eksponen = 2) { $hasil = pow($angka, $eksponen); return $angka . " pangkat " . $eksponen . " = " . $hasil; } } ?>

🔍 Perbedaan Method dan Function Biasa

✅ Method (dalam Class)

  • • Bagian dari class
  • • Bisa akses properties dengan $this
  • • Lebih terorganisir
  • • Bisa diwariskan ke class lain

📝 Function Biasa

  • • Berdiri sendiri
  • • Tidak bisa akses properties class
  • • Lebih sederhana
  • • Langsung bisa dipanggil

💻 Praktik Langsung OOP PHP

🎯 Tujuan Praktik

Sekarang saatnya praktik langsung! Kita akan membuat class Siswa yang bisa menyimpan data siswa dan melakukan berbagai aksi.

📋 Langkah-langkah Praktik

1

Buat Class Siswa

Dengan properties: nama, kelas, nilai

2

Tambahkan Method

perkenalan(), hitungRataRata(), cekKelulusan()

3

Buat Object dan Test

Buat beberapa object siswa dan coba semua method

📝 Langkah 1: Membuat Class Siswa

<?php class Siswa { // Properties - Data siswa public $nama; public $kelas; public $nilai = []; // Constructor untuk inisialisasi public function __construct($nama, $kelas) { $this->nama = $nama; $this->kelas = $kelas; } // Method perkenalan public function perkenalan() { return "Halo! Nama saya " . $this->nama . ", saya dari kelas " . $this->kelas . " 😊"; } // Method tambah nilai public function tambahNilai($mataPelajaran, $nilai) { $this->nilai[$mataPelajaran] = $nilai; return "Nilai " . $mataPelajaran . ": " . $nilai . " berhasil ditambahkan!"; } // Method hitung rata-rata public function hitungRataRata() { if (empty($this->nilai)) { return "Belum ada nilai yang dimasukkan"; } $total = array_sum($this->nilai); $jumlahMapel = count($this->nilai); $rataRata = $total / $jumlahMapel; return "Rata-rata nilai: " . round($rataRata, 2); } // Method cek kelulusan public function cekKelulusan() { if (empty($this->nilai)) { return "Belum bisa dicek, nilai masih kosong"; } $total = array_sum($this->nilai); $rataRata = $total / count($this->nilai); if ($rataRata >= 75) { return "🎉 Selamat! " . $this->nama . " LULUS dengan rata-rata " . round($rataRata, 2); } else { return "😔 " . $this->nama . " belum lulus. Rata-rata: " . round($rataRata, 2) . ". Semangat belajar lagi!"; } } } ?>

📝 Tugas OOP PHP

🎯 Petunjuk Tugas

Jawablah pertanyaan-pertanyaan berikut dengan lengkap dan jelas. Tugas ini akan menguji pemahaman kamu tentang konsep OOP dasar dalam PHP.

💡 Tips: Berikan contoh kode untuk memperjelas jawaban kamu!

📚 Soal 1: Konsep Dasar

Jelaskan dengan bahasa sendiri apa yang dimaksud dengan Class, Object, dan Method dalam OOP PHP! Berikan analogi sederhana untuk masing-masing konsep tersebut.

💻 Soal 2: Membuat Class

Buatlah sebuah class bernama Buku yang memiliki properties: judul, pengarang, tahunTerbit, dan harga. Tambahkan method infoLengkap() yang menampilkan semua informasi buku, dan method hitungDiskon($persen) yang menghitung harga setelah diskon.

🎭 Soal 3: Menggunakan Object

Dari class Buku yang sudah kamu buat di soal 2, buatlah 2 object buku dengan data yang berbeda. Kemudian panggil method infoLengkap() dan hitungDiskon(20) untuk masing-masing object. Tuliskan kode lengkapnya!

⚡ Soal 4: Method dengan Parameter

Jelaskan perbedaan antara method yang memiliki parameter dan method yang tidak memiliki parameter! Berikan contoh masing-masing dan kapan sebaiknya menggunakan keduanya.

🔧 Soal 5: Studi Kasus

Kamu diminta membuat sistem sederhana untuk mengelola data karyawan. Buatlah class Karyawan dengan properties yang sesuai dan minimal 3 method yang berguna. Jelaskan mengapa kamu memilih properties dan method tersebut!
