📚 Pengenalan PHP Superglobals

🌟

🤖 Apa itu Superglobals?

Superglobals adalah variabel khusus dalam PHP yang bisa diakses dari mana saja dalam script, tanpa perlu kata kunci global.

Bayangkan superglobals seperti kotak surat ajaib yang bisa kamu buka dari ruangan mana pun di rumah! 📮

✨ Keunggulan Superglobals

  • • Bisa diakses dari mana saja
  • • Tidak perlu deklarasi global
  • • Otomatis tersedia
  • • Sangat praktis untuk web development

📋 Jenis-jenis Superglobals

  • 🔹 $_GET - Data dari URL
  • 🔹 $_POST - Data dari form
  • 🔹 $_SESSION - Data sesi
  • 🔹 $_COOKIE - Data cookie
  • 🔹 $_SERVER - Info server
  • 🔹 $_FILES - File upload

📥 $_GET - Mengambil Data dari URL

🔗

🤔 Apa itu $_GET?

$_GET adalah superglobal yang digunakan untuk mengambil data yang dikirim melalui URL (query string).

Seperti amplop yang ditempel di luar surat - semua orang bisa melihatnya! 📮

✅ Kapan Menggunakan $_GET

  • • Pencarian data
  • • Filter produk
  • • Pagination
  • • Sharing link dengan parameter

❌ Jangan Gunakan untuk

  • • Password atau data sensitif
  • • Data yang panjang
  • • Data yang mengubah database
  • • Informasi pribadi

💻 Contoh Penggunaan

// URL: website.com/search.php?nama=John&umur=25

// Mengambil data dari URL
$nama = $_GET['nama'];  // Hasil: "John"
$umur = $_GET['umur'];  // Hasil: "25"

// Cek apakah data ada
if (isset($_GET['nama'])) {
    echo "Halo " . $_GET['nama'];
} else {
    echo "Nama tidak ditemukan";
}

📤 $_POST - Mengirim Data Form

📋

🤔 Apa itu $_POST?

$_POST adalah superglobal yang digunakan untuk mengambil data yang dikirim melalui form HTML dengan method POST.

Seperti surat dalam amplop tertutup - lebih aman dan privat! 💌

🆚 $_GET vs $_POST

$_GET: Terlihat di URL, untuk data publik
$_POST: Tersembunyi, untuk data sensitif

✨ Keunggulan $_POST

  • • Lebih aman untuk data sensitif
  • • Bisa mengirim data besar
  • • Tidak terlihat di URL
  • • Cocok untuk form login

💻 Contoh Form dan PHP

// HTML Form
<form method="POST" action="proses.php">
    <input type="text" name="username" placeholder="Username">
    <input type="password" name="password" placeholder="Password">
    <button type="submit">Login</button>
</form>

// PHP (proses.php)
if ($_POST) {
    $username = $_POST['username'];
    $password = $_POST['password'];
    
    if ($username == "admin" && $password == "123") {
        echo "Login berhasil!";
    } else {
        echo "Login gagal!";
    }
}

🔐 $_SESSION - Menyimpan Data Sesi

💾

🤔 Apa itu $_SESSION?

$_SESSION adalah superglobal yang menyimpan data selama user masih aktif di website (sampai browser ditutup atau logout).

Seperti loker sementara yang bisa kamu akses selama masih di mall! 🏪

✨ Kegunaan $_SESSION

  • • Menyimpan info login user
  • • Keranjang belanja
  • • Preferensi user
  • • Data sementara antar halaman

⏰ Kapan Session Berakhir

  • • Browser ditutup
  • • User logout
  • • Timeout (tidak aktif lama)
  • • Server restart

💻 Cara Menggunakan Session

// Mulai session (wajib di awal file)
session_start();

// Menyimpan data ke session
$_SESSION['username'] = 'john_doe';
$_SESSION['role'] = 'admin';
$_SESSION['login_time'] = date('Y-m-d H:i:s');

// Mengambil data dari session
echo "Halo " . $_SESSION['username'];

// Cek apakah session ada
if (isset($_SESSION['username'])) {
    echo "User sudah login";
} else {
    echo "User belum login";
}

// Menghapus session tertentu
unset($_SESSION['username']);

// Menghapus semua session
session_destroy();

🍪 $_COOKIE - Data Permanen

🗂️

🤔 Apa itu $_COOKIE?

$_COOKIE adalah superglobal yang menyimpan data di browser user dan bertahan bahkan setelah browser ditutup.

Seperti stiker nama yang ditempel di laptop - selalu ada sampai kamu hapus! 🏷️

✨ Kegunaan Cookie

  • • "Remember me" di login
  • • Preferensi bahasa
  • • Theme (dark/light mode)
  • • Riwayat kunjungan

⚠️ Hal yang Perlu Diingat

  • • User bisa menghapus cookie
  • • Ada batas ukuran (4KB)
  • • Jangan simpan data sensitif
  • • Bisa dimatikan user

💻 Cara Menggunakan Cookie

// Membuat cookie (berlaku 30 hari)
setcookie("username", "john_doe", time() + (30 * 24 * 60 * 60));
setcookie("theme", "dark", time() + (30 * 24 * 60 * 60));

// Membaca cookie
if (isset($_COOKIE['username'])) {
    echo "Halo " . $_COOKIE['username'];
} else {
    echo "Cookie tidak ditemukan";
}

// Cookie dengan path dan domain
setcookie("pref", "value", time() + 3600, "/", "example.com");

// Menghapus cookie (set waktu ke masa lalu)
setcookie("username", "", time() - 3600);

Langkah 2: Proses Pencarian

📄 File: search.php

<!DOCTYPE html>
<html>
<head>
    <title>Hasil Pencarian</title>
</head>
<body>
    <h2>Hasil Pencarian</h2>
    
<?php
if (isset($_GET['keyword'])) {
    $keyword = $_GET['keyword'];
    echo "<p>Hasil pencarian untuk: <strong>" . htmlspecialchars($keyword) . "</strong></p>";
    
    // Simulasi database produk
    $products = ["Laptop Gaming", "Mouse Wireless", "Keyboard Mechanical", "Monitor 4K"];
    $found = false;
    
    echo "<ul>";
    foreach ($products as $product) {
        if (stripos($product, $keyword) !== false) {
            echo "<li>" . $product . "</li>";
            $found = true;
        }
    }
    echo "</ul>";
    
    if (!$found) {
        echo "<p>Tidak ada produk yang ditemukan.</p>";
    }
} else {
    echo "<p>Tidak ada kata kunci pencarian.</p>";
}
?>

    <a href="index.html">Kembali ke Pencarian</a>
</body>
</html>

🔐 Praktik 3: Sistem Login dengan $_SESSION

Langkah 1: Halaman Login

📄 File: login.php

<?php
session_start();

// Proses login jika form dikirim
if ($_POST) {
    $username = $_POST['username'];
    $password = $_POST['password'];
    
    // Validasi login (dalam praktik nyata, cek ke database)
    if ($username == "admin" && $password == "123") {
        $_SESSION['logged_in'] = true;
        $_SESSION['username'] = $username;
        $_SESSION['login_time'] = date('Y-m-d H:i:s');
        header("Location: dashboard.php");
        exit();
    } else {
        $error = "Username atau password salah!";
    }
}
?>

<!DOCTYPE html>
<html>
<head>
    <title>Login System</title>
    <style>
        body { font-family: Arial, sans-serif; margin: 50px; }
        .login-form { max-width: 300px; margin: 0 auto; }
        input { width: 100%; padding: 10px; margin: 5px 0; }
        button { background: #007cba; color: white; padding: 10px; width: 100%; }
        .error { color: red; background: #ffe6e6; padding: 10px; }
    </style>
</head>
<body>
    <div class="login-form">
        <h2>Login System</h2>
        
        <?php if (isset($error)): ?>
            <div class="error"><?php echo $error; ?></div>
        <?php endif; ?>
        
        <form method="POST">
            <input type="text" name="username" placeholder="Username" required>
            <input type="password" name="password" placeholder="Password" required>
            <button type="submit">Login</button>
        </form>
        
        <p><small>Demo: username = admin, password = 123</small></p>
    </div>
</body>
</html>

📥 Tugas 1: Kalkulator Sederhana dengan $_GET

Instruksi:

Buatlah kalkulator sederhana yang menerima dua angka dan operasi melalui URL menggunakan $_GET.

Contoh URL: calculator.php?num1=10&num2=5&operation=add

Yang harus dibuat:

  • Form input untuk memasukkan angka 1, angka 2, dan pilihan operasi
  • PHP script yang memproses $_GET dan menampilkan hasil
  • Operasi yang didukung: tambah, kurang, kali, bagi
  • Validasi input (pastikan angka valid dan tidak bagi dengan nol)

📤 Tugas 2: Form Pendaftaran dengan $_POST

Instruksi:

Buatlah form pendaftaran siswa yang lengkap menggunakan $_POST.

Field yang diperlukan:

  • Nama lengkap (wajib)

🍪 Tugas 4: Sistem Preferensi dengan $_COOKIE

Instruksi:

Buatlah sistem yang menyimpan preferensi user menggunakan cookie.

Preferensi yang disimpan:

  • Nama panggilan user
  • Warna tema favorit
  • Bahasa (Indonesia/English)
  • Font size (kecil/sedang/besar)

Fitur yang harus ada:

  • Form untuk mengatur preferensi
  • Halaman yang menerapkan preferensi tersebut
  • Cookie berlaku selama 30 hari
  • Opsi untuk reset preferensi
