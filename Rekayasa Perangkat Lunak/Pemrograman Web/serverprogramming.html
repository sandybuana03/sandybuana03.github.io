Pengenalan Server-Side Programming

🌐 Apa itu Server-Side Programming?

Server-side programming adalah pemrograman yang berjalan di server (komputer yang melayani website). Berbeda dengan client-side yang berjalan di browser pengguna, server-side bekerja di "belakang layar" untuk memproses data dan memberikan respons.

🔄 Analogi Sederhana:

Bayangkan kamu pesan makanan online. Client-side adalah aplikasi di HP kamu (tampilan, tombol). Server-side adalah sistem di belakang yang memproses pesanan, cek stok, hitung harga, dan kirim notifikasi ke restoran.

👤 Client-Side

  • • Berjalan di browser pengguna
  • • HTML, CSS, JavaScript
  • • Tampilan dan interaksi
  • • Tidak bisa akses database

🖥️ Server-Side

  • • Berjalan di server
  • • PHP, Python, Node.js, dll
  • • Logika bisnis dan data
  • • Bisa akses database

⚡ Mengapa Server-Side Penting?

🔒 Keamanan

Data sensitif seperti password dan informasi pribadi diproses dengan aman di server

🗄️ Database

Menyimpan dan mengambil data dari database dengan efisien

🎯 Logika Bisnis

Memproses aturan bisnis yang kompleks seperti perhitungan harga, diskon, dll

🌍 Skalabilitas

Melayani banyak pengguna secara bersamaan dengan efisien

🌟 Contoh Nyata dalam Kehidupan Sehari-hari

🛒 E-Commerce (Shopee, Tokopedia)
  • • Client-side: Tampilan produk, keranjang belanja, animasi
  • • Server-side: Cek stok, proses pembayaran, kirim notifikasi
📱 Media Sosial (Instagram, TikTok)
  • • Client-side: Scroll feed, like button, filter foto
  • • Server-side: Simpan post, algoritma feed, moderasi konten
🎓 E-Learning (Google Classroom)
  • • Client-side: Interface kelas, upload file, chat
  • • Server-side: Simpan tugas, hitung nilai, kirim pengumuman

🔒 Keamanan dalam Server-Side Programming

⚠️ Ancaman Keamanan Umum:

💉 SQL Injection

Penyerang memasukkan kode SQL berbahaya melalui input form

🎭 XSS Attack

Menyisipkan script jahat ke halaman web

🔓 Broken Authentication

Kelemahan sistem login dan session

📊 Data Exposure

Data sensitif tidak dienkripsi dengan baik

🛡️ Cara Melindungi Aplikasi:

✅ Input Validation

Selalu validasi dan sanitasi input user

🔐 Password Hashing

Gunakan bcrypt atau algoritma hash yang kuat

🔑 HTTPS/SSL

Enkripsi komunikasi antara client dan server

🎫 JWT Token

Sistem autentikasi yang aman dan stateless

🔌 API dan REST dalam Database

🤝 Apa itu API?

API (Application Programming Interface) adalah "jembatan" yang memungkinkan aplikasi berbeda berkomunikasi. Seperti pelayan di restoran yang menerima pesanan dan mengantarkan makanan.

📱 Contoh Penggunaan:
  • • Login dengan Google/Facebook
  • • Cek cuaca di aplikasi
  • • Payment gateway
  • • Maps integration
🔄 REST Methods:
  • • GET: Ambil data
  • • POST: Buat data baru
  • • PUT: Update data
  • • DELETE: Hapus data

📋 Contoh REST API Endpoint:

// Endpoint untuk data siswa
GET /api/siswa // Ambil semua siswa
GET /api/siswa/1 // Ambil siswa ID 1
POST /api/siswa // Tambah siswa baru
PUT /api/siswa/1 // Update siswa ID 1
DELETE /api/siswa/1 // Hapus siswa ID 1

Framework Server-Side

🧱 Apa itu Framework?

Framework adalah "kerangka kerja" yang menyediakan struktur dasar untuk membangun aplikasi. Seperti rumah yang sudah ada fondasinya, kamu tinggal menambahkan dinding dan atap!

✅ Keuntungan Framework

  • • Kode lebih terorganisir
  • • Keamanan sudah built-in
  • • Banyak fitur siap pakai

  • • Django (Python)
