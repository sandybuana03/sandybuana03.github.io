👋 Pengenalan Web

🌍 Apa itu Web?

Web (World Wide Web) adalah sistem informasi global yang memungkinkan kita mengakses berbagai halaman website melalui internet. Bayangkan web seperti perpustakaan raksasa yang bisa diakses dari mana saja!

📱 Smartphone → 🌐 Internet → 💻 Website

🏛️ Sejarah Singkat

Web diciptakan oleh Tim Berners-Lee pada tahun 1989 di CERN. Awalnya hanya untuk berbagi dokumen ilmiah!

📊 Fakta Menarik

Saat ini ada lebih dari 1.7 miliar website di dunia, dan setiap hari bertambah ribuan website baru!

📝 HTML - Struktur Website

🏗️ Apa itu HTML?

HTML (HyperText Markup Language) adalah bahasa markup yang digunakan untuk membuat struktur halaman web. Bayangkan HTML seperti kerangka rumah - dia menentukan di mana letak pintu, jendela, dan ruangan.

HTML = Kerangka 🏗️ + Konten 📄 = Website 🌐

📋 Fungsi HTML

  • • Membuat struktur halaman
  • • Menampilkan teks dan gambar
  • • Membuat link antar halaman
  • • Membuat form input

🎯 Karakteristik

  • • Menggunakan tag pembuka & penutup
  • • Case insensitive
  • • Bisa dibuka di browser
  • • File berekstensi .html

🏷️ Tag HTML Dasar

<h1> - <h6>

Heading (Judul)

<h1>Judul Besar</h1>

<p>

Paragraf

<p>Ini paragraf</p>

<a>

Link

<a href="#">Link</a>

<div>

Container

<div>Konten</div>

📚 Tag Lainnya:

<img> <ul> <li> <table> <form> <input> <button> <span> <br>

🎮 Demo HTML Interaktif

Struktur HTML Lengkap:

<!DOCTYPE html> <!-- Deklarasi HTML5 -->
<html lang="id"> <!-- Bahasa Indonesia -->
  <head>
    <meta charset="UTF-8"> <!-- Encoding karakter -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Website SMK Keren</title>
    <meta name="description" content="Website sekolah terbaik">
  </head>
  <body>
    <header>
      <h1>SMK Teknologi Maju</h1>
      <nav>
        <ul>
          <li><a href="#home">Beranda</a></li>
          <li><a href="#about">Tentang</a></li>
        </ul>
      </nav>
    </header>
    <main>
      <section id="home">
        <h2>Selamat Datang!</h2>
        <p>Bergabunglah dengan sekolah teknologi terdepan.</p>
      </section>
    </main>
    <footer>
      <p>© 2024 SMK Teknologi Maju</p>
    </footer>
  </body>
</html>

🎨 CSS - Styling Website

✨ Apa itu CSS?

CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan website. Jika HTML adalah kerangka rumah, maka CSS adalah cat, wallpaper, dan dekorasi yang membuatnya indah!

HTML 🏗️ + CSS 🎨 = Website Cantik ✨

🎯

Selector

Memilih elemen HTML

🔧

Property

Apa yang diubah

💎

Value

Nilai perubahan

🎯 Properti CSS Dasar

color

Warna teks

color: blue;

background-color

Warna latar

background-color: yellow;

font-size

Ukuran font

font-size: 20px;

margin & padding

Jarak luar & dalam

margin: 10px;

📐 Box Model:

Content
Padding (hijau) → Border (biru) → Margin (luar)

🎮 Demo CSS Interaktif

CSS Lengkap dengan Animasi:

/* Reset dan Base Styles */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

/* Typography */
h1 {
  color: #ff6b6b;
  font-size: clamp(24px, 5vw, 48px); /* Responsive font */
  text-align: center;
  text-shadow: 2px 2px 4px rgba(0,0,0,0.3);
  font-family: 'Arial', sans-serif;
  margin-bottom: 20px;
  animation: slideInDown 1s ease-out;
}

/* Card Styling */
.card {
  background: linear-gradient(135deg, #ffe66d, #ff9a9e);
  padding: 20px;
  border-radius: 15px;
  box-shadow: 0 8px 32px rgba(0,0,0,0.1);
  backdrop-filter: blur(10px);
  border: 1px solid rgba(255,255,255,0.2);
  transition: all 0.3s ease;
}

/* Hover Effects */
.card:hover {
  transform: translateY(-10px) scale(1.02);
  box-shadow: 0 20px 40px rgba(0,0,0,0.2);
}

/* Animations */
@keyframes slideInDown {
  from {
    opacity: 0;
    transform: translateY(-50px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

/* Responsive Design */
@media (max-width: 768px) {
  .card {
    padding: 15px;
    margin: 10px;
  }
}

⚡ JavaScript - Interaksi Website

🚀 Apa itu JavaScript?

JavaScript adalah bahasa pemrograman yang membuat website menjadi interaktif dan dinamis. Jika HTML adalah kerangka dan CSS adalah dekorasi, maka JavaScript adalah "jiwa" yang membuat website hidup!

HTML 🏗️ + CSS 🎨 + JavaScript ⚡ = Website Interaktif 🎮

🎯 Kegunaan JS

  • • Membuat animasi
  • • Validasi form
  • • Interaksi user
  • • Mengubah konten dinamis

💡 Fun Fact

JavaScript dibuat hanya dalam 10 hari oleh Brendan Eich pada tahun 1995!

🔧 Konsep Dasar JavaScript

📦 Variabel & Tipe Data

Menyimpan berbagai jenis data

let nama = "Budi"; // String
let umur = 17; // Number
let aktif = true; // Boolean
const sekolah = "SMK Tech"; // Constant
💡 let = bisa diubah, const = tetap

🔄 Function

Blok kode yang bisa dijalankan berulang

function sapa(nama) {
  return "Halo " + nama + "!";
}

// Arrow function (ES6)
const sapa2 = (nama) => `Halo ${nama}!`;
💡 Arrow function lebih modern

🎯 Event Handling

Merespon aksi user

// Cara 1: HTML attribute
onclick="fungsi()"

// Cara 2: addEventListener
button.addEventListener('click', function() {
  alert('Diklik!');
});
💡 addEventListener lebih fleksibel

🏠 DOM Manipulation

Mengubah elemen HTML

// Ambil elemen
let judul = document.getElementById('judul');
let tombol = document.querySelector('.btn');

// Ubah konten
judul.textContent = 'Judul Baru';
judul.style.color = 'red';
💡 querySelector lebih powerful

🔁 Array & Object

Struktur data kompleks

// Array
let hobi = ['coding', 'gaming', 'musik'];
hobi.push('olahraga'); // Tambah item

// Object
let siswa = {
  nama: 'Budi',
  kelas: '12 RPL',
  sapa: function() { return 'Halo!'; }
};
💡 Object seperti data siswa lengkap

⚡ Async Programming

Operasi tidak sinkron

// Promise
fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data));

// Async/Await (modern)
async function getData() {
  const response = await fetch('/api/data');
  const data = await response.json();
  return data;
}
💡 Untuk mengambil data dari server

🚀 JavaScript Modern (ES6+):

Template Literals: `Hello ${nama}!`
Destructuring: const {nama, umur} = siswa;
Spread Operator: [...array1, ...array2]
Arrow Functions: const add = (a, b) => a + b;
Classes: class Siswa { constructor() {} }
Modules: import/export
Let/Const: Block scope variables
Default Parameters: function(a = 5) {}

📱 Responsive Design

🌐 Apa itu Responsive Design?

Responsive design adalah pendekatan desain web yang membuat halaman web tampil dengan baik di berbagai perangkat dan ukuran layar - dari desktop hingga smartphone!

💻

Desktop

1920px+

📱

Tablet

768px - 1024px

📲

Mobile

320px - 767px

🔧 Teknik Responsive Design

📐 Flexible Grid

Layout yang fleksibel

display: grid;
grid-template-columns: 1fr 1fr;

🖼️ Flexible Images

Gambar yang menyesuaikan

img { max-width: 100%; }

📱 Media Queries

CSS untuk ukuran layar berbeda

@media (max-width: 768px)

📏 Viewport Meta

Pengaturan viewport

<meta name="viewport">

📋 Tugas Pembelajaran

✍️ Soal 1: Pemahaman Konsep

Jelaskan dengan kata-kata sendiri apa perbedaan antara HTML, CSS, dan JavaScript dalam pembuatan website! Berikan analogi sederhana untuk masing-masing dan sebutkan 3 contoh penggunaan nyata.

🏗️ Soal 2: Struktur HTML Lengkap

Buatlah struktur HTML lengkap untuk halaman "Profil Siswa" yang berisi:
• Header dengan judul dan navigasi
• Section profil (nama, kelas, foto, biodata)
• Section hobi (dalam bentuk list)
• Footer dengan kontak

🎨 Soal 3: Styling CSS Kreatif

Dari struktur HTML yang sudah kamu buat di soal 2, tuliskan kode CSS untuk membuat tampilan yang menarik!
Minimal gunakan: warna gradien, hover effects, responsive design, dan animasi sederhana.

⚡ Soal 4: Interaksi JavaScript

Buatlah 3 fungsi JavaScript untuk halaman profil:
1. Fungsi untuk mengubah tema (light/dark mode)
2. Fungsi untuk menampilkan/menyembunyikan detail hobi
3. Fungsi untuk validasi form kontak sederhana
