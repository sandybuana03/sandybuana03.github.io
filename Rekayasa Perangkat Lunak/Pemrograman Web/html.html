Pengenalan HTML

🌐 Apa itu HTML?

HTML (HyperText Markup Language) adalah bahasa markup yang digunakan untuk membuat struktur halaman web. Bayangkan HTML seperti kerangka rumah - dia yang menentukan di mana letak pintu, jendela, dan ruangan.

Contoh Sederhana:

<html>
  <head>
    <title>Website Pertamaku</title>
  </head>
  <body>
    <h1>Halo Dunia!</h1>
    <p>Ini adalah website pertamaku</p>
  </body>
</html>

Struktur Dasar HTML

📋 Struktur Wajib HTML

Setiap dokumen HTML harus memiliki struktur dasar ini:

<!DOCTYPE html>
<html lang="id">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Judul Halaman</title>
  </head>
  <body>
    <!-- Konten website di sini -->
  </body>
</html>

🔖 <!DOCTYPE html>

Memberitahu browser bahwa ini adalah HTML5

🌐 <html>

Elemen root yang membungkus semua konten

🧠 <head>

Berisi informasi tentang halaman (tidak terlihat)

👁️ <body>

Berisi konten yang terlihat di halaman

Form HTML

📋 Apa itu Form?

Form adalah cara untuk mengumpulkan data dari pengguna. Seperti formulir pendaftaran, login, atau survei.

Struktur Dasar Form:

<form>
  <label for="nama">Nama:</label>
  <input type="text" id="nama" name="nama">
  
  <button type="submit">Kirim</button>
</form>

Praktik HTML

🎯 Langkah-langkah Praktik

Langkah 1: Buat File HTML

Buka text editor (Notepad, VS Code, atau Sublime Text) dan buat file baru dengan nama index.html

Langkah 2: Tulis Struktur Dasar

<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Website Pertamaku</title>
</head>
<body>
    <!-- Konten akan ditambahkan di sini -->
</body>
</html>

Langkah 3: Tambahkan Konten

<body>
    <h1>Selamat Datang di Website Saya</h1>
    <p>Nama saya [Nama Kamu]. Saya siswa SMK yang sedang belajar HTML.</p>
    
    <h2>Tentang Saya</h2>
    <ul>
        <li>Umur: 17 tahun</li>
        <li>Hobi: Coding dan Gaming</li>
        <li>Cita-cita: Web Developer</li>
    </ul>
    
    <h2>Kontak Saya</h2>
    <p>Email: <a href="mailto:email@contoh.com">email@contoh.com</a></p>
</body>

Langkah 4: Tambahkan Form

<h2>Hubungi Saya</h2>
<form>
    <label for="nama">Nama:</label><br>
    <input type="text" id="nama" name="nama"><br><br>
    
    <label for="email">Email:</label><br>
    <input type="email" id="email" name="email"><br><br>
    
    <label for="pesan">Pesan:</label><br>
    <textarea id="pesan" name="pesan"></textarea><br><br>
    
    <button type="submit">Kirim</button>
</form>

Langkah 5: Simpan dan Buka

Simpan file dengan ekstensi .html dan buka di browser dengan double-click atau drag & drop ke browser.

🏆 Tantangan Tambahan

🎨 Level 1: Pemula

  • • Tambahkan 3 heading berbeda
  • • Buat list hobi dengan 5 item
  • • Tambahkan link ke media sosial

🚀 Level 2: Menengah

  • • Buat tabel jadwal pelajaran
  • • Tambahkan form dengan 5 jenis input
  • • Buat halaman "About Me" lengkap

Tugas HTML

📝 Tugas Utama

Buat Website Portfolio Pribadi

Buatlah sebuah website portfolio pribadi yang berisi informasi tentang diri kamu. Website harus memiliki komponen-komponen berikut:

1. Header dengan Judul

Gunakan tag <h1> untuk nama kamu dan <h2> untuk tagline/motto

2. Bagian "Tentang Saya"

Minimal 2 paragraf tentang diri kamu, hobi, dan cita-cita

3. Daftar Keahlian

Gunakan <ul> atau <ol> untuk membuat list keahlian/skill yang kamu miliki

4. Tabel Jadwal Kegiatan

Buat tabel jadwal kegiatan harian atau mingguan kamu

5. Form Kontak

Form dengan minimal: nama, email, subjek, pesan, dan tombol kirim

6. Link Media Sosial

Tambahkan link ke media sosial atau email kamu

✅ Kriteria Penilaian

Struktur HTML (30%)

  • • Struktur HTML5 yang benar
  • • Penggunaan tag yang sesuai
  • • Kode yang rapi dan terorganisir

Kelengkapan Konten (40%)

  • • Semua komponen wajib ada
  • • Konten informatif dan relevan
  • • Form yang lengkap dan fungsional

Kreativitas (20%)

  • • Ide kreatif dalam penyajian
  • • Konten yang menarik
  • • Penggunaan elemen tambahan

Kerapian (10%)

  • • Indentasi yang konsisten
  • • Penamaan yang jelas
  • • Tidak ada error syntax
