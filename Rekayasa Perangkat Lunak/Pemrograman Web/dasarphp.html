Apa itu PHP?

📝 Sintaks Dasar PHP

Setiap kode PHP harus dimulai dengan tag pembuka dan ditutup dengan tag penutup:

<?php
  // Kode PHP kamu di sini
  echo "Halo Dunia!";
?>

💡 Tips Penting:

  • • Setiap statement PHP diakhiri dengan semicolon (;)
  • • PHP case-sensitive untuk nama variabel
  • • Komentar menggunakan // atau /* */
  • • File PHP harus berekstensi .php

Praktik Variabel PHP

Variabel adalah tempat menyimpan data. Seperti kotak untuk menyimpan barang!

🎯 Langkah 1: Membuat Variabel

Di PHP, variabel dimulai dengan tanda $ (dollar). Contoh:

<?php
  $nama = "Budi";
  $umur = 17;
  $tinggi = 165.5;
?>

📋 Aturan Penamaan Variabel:

  • • Harus dimulai dengan $ (dollar)
  • • Setelah $ harus huruf atau underscore (_)
  • • Tidak boleh ada spasi
  • • Case-sensitive ($nama ≠ $Nama)
  • • Tidak boleh dimulai dengan angka

✅ Contoh Nama Variabel yang Benar dan Salah

✅ Benar

$nama
$umur_siswa
$nilaiMatematika
$_data
$kelas12RPL

❌ Salah

// nama (tanpa $)
// $2nama (dimulai angka)
// $nama siswa (ada spasi)
// $nama-siswa (ada tanda -)
// $class (kata reserved)

🖨️ Langkah 2: Menampilkan Variabel

Gunakan echo untuk menampilkan isi variabel:

<?php
  $nama = "Siti";
  echo "Nama saya: " . $nama;
?>

🎉 Hasil Output:

Nama saya: Siti

🔗 Menggabungkan String (Concatenation)

Ada beberapa cara untuk menggabungkan teks dengan variabel:

Menggunakan Titik (.)

$nama = "Andi";
$umur = 16;
echo "Halo " . $nama . ", umur " . $umur;

Menggunakan Double Quote

$nama = "Andi";
$umur = 16;
echo "Halo $nama, umur $umur";

Praktik Tipe Data PHP

PHP punya berbagai jenis tipe data. Mari kita pelajari satu per satu!

📝 String (Teks)

Untuk menyimpan teks, gunakan tanda kutip:

$pesan = "Halo!";
$kelas = '12 RPL';

🔢 Integer (Bilangan Bulat)

Untuk angka tanpa koma:

$umur = 17;
$jumlah = 100;

💰 Float (Bilangan Desimal)

Untuk angka dengan koma:

$tinggi = 165.5;
$harga = 25000.75;

✅ Boolean (Benar/Salah)

Hanya punya 2 nilai:

$aktif = true;
$selesai = false;

🧪 Demo Tipe Data

<?php
  $nama = "Andi";        // String
  $umur = 16;           // Integer
  $tinggi = 170.5;     // Float
  $lulus = true;        // Boolean

  echo "Nama: " . $nama . "<br>";
  echo "Umur: " . $umur . " tahun<br>";
  echo "Tinggi: " . $tinggi . " cm<br>";
  echo "Status: " . ($lulus ? "Lulus" : "Belum Lulus");
?>

🎉 Hasil Output:

Nama: Andi
Umur: 16 tahun
Tinggi: 170.5 cm
Status: Lulus

Praktik Operator PHP

Operator digunakan untuk melakukan operasi pada variabel dan nilai!

🧮 Operator Aritmatika

Penjumlahan: +
Pengurangan: -
Perkalian: *
Pembagian: /
Sisa Bagi: %
Pangkat: **

⚖️ Operator Perbandingan

Sama dengan: ==
Identik: ===
Tidak sama: !=
Lebih besar: >
Lebih kecil: <
Lebih besar sama: >=
Lebih kecil sama: <=

🔗 Operator Logika

Dan (AND): &&
Atau (OR): ||
Tidak (NOT): !
XOR: xor

📈 Operator Assignment

Assign: =
Tambah assign: +=
Kurang assign: -=
Kali assign: *=
Bagi assign: /=

📚 Contoh Penggunaan Operator

<?php
  // Operator Aritmatika
  $a = 10;
  $b = 3;
  echo $a + $b;  // 13
  echo $a % $b;  // 1 (sisa bagi)

  // Operator Perbandingan
  $x = 5;
  $y = "5";
  var_dump($x == $y);  // true (nilai sama)
  var_dump($x === $y); // false (tipe berbeda)

  // Operator Assignment
  $score = 80;
  $score += 10;  // $score = $score + 10 = 90
?>

Hasil Perhitungan:

Praktik Kondisi (If-Else)

Kondisi memungkinkan program membuat keputusan berdasarkan situasi tertentu!

🎯 Struktur If-Else

<?php
  if (kondisi) {
    // Kode jika kondisi benar
  } else {
    // Kode jika kondisi salah
  }
?>

📊 Contoh: Sistem Penilaian

<?php
  $nilai = 85;

  if ($nilai >= 90) {
    echo "Grade: A - Sangat Baik!";
  } elseif ($nilai >= 80) {
    echo "Grade: B - Baik!";
  } elseif ($nilai >= 70) {
    echo "Grade: C - Cukup!";
  } else {
    echo "Grade: D - Perlu Belajar Lagi!";
  }
?>

🎉 Hasil Output:

Grade: B - Baik!

Praktik Perulangan (Loop)

Perulangan memungkinkan kita menjalankan kode berulang kali dengan mudah!

🔢 For Loop

Digunakan ketika kita tahu berapa kali akan mengulang:

for ($i = 1; $i <= 5; $i++) {
  echo "Angka: " . $i;
}

🔄 While Loop

Digunakan ketika kondisi masih benar:

$i = 1;
while ($i <= 5) {
  echo "Angka: " . $i;
  $i++;
}

🎯 Contoh: Tabel Perkalian

<?php
  $angka = 5;
  echo "Tabel Perkalian " . $angka . ":<br>";

  for ($i = 1; $i <= 10; $i++) {
    $hasil = $angka * $i;
    echo $angka . " x " . $i . " = " . $hasil . "<br>";
  }
?>
