PHP Login System dengan Session

Mari belajar membuat sistem login yang aman dan profesional! 🚀

Apa itu Login System?

Login system adalah sistem keamanan yang memungkinkan pengguna untuk masuk ke dalam aplikasi web dengan menggunakan username dan password. Sistem ini menggunakan session untuk menjaga status login pengguna.

🎯 Yang akan kita pelajari:

  • Membuat database untuk menyimpan data user
  • Membuat form registrasi dan login
  • Menggunakan session untuk menjaga status login
  • Membuat dashboard khusus user yang sudah login
  • Sistem logout yang aman

Mengapa Session Penting?

Session memungkinkan server untuk "mengingat" siapa yang sudah login. Tanpa session, pengguna harus login ulang setiap kali pindah halaman! Session menyimpan data sementara di server dan menggunakan cookie untuk mengenali pengguna.

Persiapan Database

Langkah 1: Buat Database

Pertama, kita buat database baru untuk menyimpan data pengguna. Buka phpMyAdmin dan jalankan SQL berikut:

create_database.sql
CREATE DATABASE login_system; USE login_system;

Langkah 2: Buat Tabel Users

Sekarang kita buat tabel untuk menyimpan data pengguna:

create_table.sql
CREATE TABLE users ( id INT AUTO_INCREMENT PRIMARY KEY, username VARCHAR(50) UNIQUE NOT NULL, email VARCHAR(100) UNIQUE NOT NULL, password VARCHAR(255) NOT NULL, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP );

📝 Penjelasan Struktur Tabel:

  • id: Primary key, auto increment
  • username: Nama pengguna (unik)
  • email: Email pengguna (unik)
  • password: Password yang sudah di-hash
  • created_at: Waktu pembuatan akun

Koneksi Database

Langkah 3: Buat File Koneksi

Kita buat file khusus untuk koneksi database yang bisa digunakan di semua file PHP:

config/database.php
<?php // Konfigurasi database $host = 'localhost'; $dbname = 'login_system'; $username = 'root'; $password = ''; try { // Membuat koneksi PDO $pdo = new PDO("mysql:host=$host;dbname=$dbname", $username, $password); // Set error mode ke exception $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION); // Set charset ke utf8 $pdo->setAttribute(PDO::MYSQL_ATTR_INIT_COMMAND, "SET NAMES utf8"); echo "Koneksi berhasil!"; } catch(PDOException $e) { die("Koneksi gagal: " . $e->getMessage()); } ?>

🔧 Penjelasan Kode:

  • PDO: PHP Data Objects, cara modern untuk koneksi database
  • ERRMODE_EXCEPTION: Menampilkan error jika ada masalah
  • SET NAMES utf8: Mendukung karakter Indonesia

Langkah 4: Test Koneksi

Buat file untuk test apakah koneksi database berhasil:

test_connection.php
<?php require_once 'config/database.php'; // Test query sederhana try { $stmt = $pdo->query("SELECT 1"); echo "<h2 style='color: green;'>✅ Database siap digunakan!</h2>"; } catch(PDOException $e) { echo "<h2 style='color: red;'>❌ Error: " . $e->getMessage() . "</h2>"; } ?>

Kelola Session

Langkah 7: Buat File Auth Check

Kita buat file khusus untuk mengecek apakah user sudah login atau belum:

includes/auth_check.php
<?php session_start(); // Fungsi untuk cek apakah user sudah login function isLoggedIn() { return isset($_SESSION['user_id']); } // Fungsi untuk redirect jika belum login function requireLogin() { if (!isLoggedIn()) { header('Location: login.php'); exit(); } } // Fungsi untuk redirect jika sudah login function requireGuest() { if (isLoggedIn()) { header('Location: dashboard.php'); exit(); } } // Fungsi untuk mendapatkan data user yang sedang login function getCurrentUser() { if (isLoggedIn()) { return [ 'id' => $_SESSION['user_id'], 'username' => $_SESSION['username'], 'email' => $_SESSION['email'] ]; } return null; } ?>

🔧 Penjelasan Fungsi:

  • isLoggedIn(): Cek apakah ada session user_id
  • requireLogin(): Paksa user untuk login dulu
  • requireGuest(): Redirect jika sudah login
  • getCurrentUser(): Ambil data user yang login

Session Timeout (Opsional)

Untuk keamanan ekstra, kita bisa tambahkan session timeout:

includes/session_timeout.php
<?php // Set timeout 30 menit (1800 detik) $timeout_duration = 1800; // Cek apakah ada session last_activity if (isset($_SESSION['last_activity'])) { // Hitung selisih waktu $elapsed_time = time() - $_SESSION['last_activity']; // Jika sudah timeout, hapus session if ($elapsed_time > $timeout_duration) { session_destroy(); header('Location: login.php?timeout=1'); exit(); } } // Update last_activity $_SESSION['last_activity'] = time(); ?>

Logout System

Langkah 9: Buat Sistem Logout

Logout yang aman harus menghapus semua session dan redirect ke halaman login:

logout.php
<?php session_start(); // Hapus semua session variables $_SESSION = array(); // Hapus session cookie jika ada if (ini_get("session.use_cookies")) { $params = session_get_cookie_params(); setcookie(session_name(), '', time() - 42000, $params["path"], $params["domain"], $params["secure"], $params["httponly"] ); } // Hancurkan session session_destroy(); // Redirect ke login dengan pesan header('Location: login.php?logout=success'); exit(); ?>

🔒 Proses Logout yang Aman:

  • Hapus semua data session
  • Hapus cookie session dari browser
  • Hancurkan session di server
  • Redirect ke halaman login
