Pengenalan Deployment

🤖 Apa itu Deployment?

Deployment adalah proses memindahkan website atau aplikasi yang sudah kamu buat dari komputer lokal ke server agar bisa diakses oleh orang lain melalui internet.

📖 Definisi Teknis:

Deployment melibatkan transfer file, konfigurasi server, setup database, dan memastikan semua komponen website berfungsi dengan baik di lingkungan production.

🏠 Analogi Sederhana

Bayangkan kamu punya toko kue buatan sendiri di rumah. Untuk bisa dijual ke banyak orang, kamu perlu pindahkan toko itu ke mall (server) agar semua orang bisa datang dan membeli kue kamu!

🏠
Rumah (Localhost)

Tempat kamu develop website

🚚
Pindahan (Upload)

Proses memindahkan file

🏬
Mall (Server)

Tempat website bisa diakses publik

🔄 Siklus Development ke Production

1

Development

Coding di komputer lokal (localhost:3000)

2

Testing

Uji coba fitur dan perbaiki bug

3

Staging

Test di environment yang mirip production

4

Production

Website live dan bisa diakses publik

🏠 Sebelum Deployment

  • • Website hanya bisa diakses di komputer kamu
  • • Menggunakan localhost (127.0.0.1)
  • • Tidak ada yang bisa melihat karya kamu
  • • File tersimpan di hard disk lokal
  • • Tidak perlu internet untuk akses

🌍 Setelah Deployment

  • • Website bisa diakses dari mana saja
  • • Punya alamat website (domain)
  • • Semua orang bisa melihat karya kamu
  • • File tersimpan di server hosting
  • • Butuh internet untuk akses

Apa itu Hosting?

🏢 Definisi Hosting

Hosting adalah layanan yang menyediakan tempat untuk menyimpan file-file website kamu di server yang terhubung ke internet 24/7.

🏠

Shared Hosting

Seperti kos-kosan, berbagi server dengan website lain. Murah tapi terbatas.

🏘️

VPS Hosting

Seperti apartemen, punya ruang sendiri tapi masih dalam satu gedung.

🏰

Dedicated Server

Seperti rumah pribadi, server khusus untuk website kamu saja.

🔧 Komponen Hosting

📁 Storage (Penyimpanan)

Tempat menyimpan file HTML, CSS, JS, gambar, dll.

• SSD: Lebih cepat, lebih mahal

• HDD: Lebih lambat, lebih murah

🚀 Bandwidth

Jumlah data yang bisa ditransfer per bulan.

• 1GB = 1000 pengunjung/bulan (rata-rata)

• Unlimited = Biasanya ada fair usage policy

🗄️ Database

Tempat menyimpan data dinamis website.

• MySQL: Paling populer untuk web

• PostgreSQL: Lebih advanced

📧 Email

Layanan email dengan domain sendiri.

• Professional: nama@domain.com

• Webmail: Akses via browser

⚡ Spesifikasi Tambahan

🖥️ CPU & RAM

Menentukan kecepatan pemrosesan website

🔒 SSL Certificate

Enkripsi data untuk keamanan (HTTPS)

🔄 Backup

Cadangan otomatis untuk recovery data

🏆 Provider Hosting Populer

🇮🇩 Lokal Indonesia

Mulai Rp 10rb/bulan, support 24/7

Hostinger

Murah, performa baik, global

IDCloudHost

Server Indonesia, cepat untuk lokal

🌍 Internasional

Netlify

Gratis untuk static site, CI/CD

Vercel

Optimal untuk React/Next.js

GitHub Pages

Gratis untuk project open source

CPanel Dasar

🎛️ Apa itu CPanel?

CPanel adalah dashboard berbasis web yang memudahkan kamu mengelola hosting tanpa perlu mengetik kode yang rumit. Seperti remote control untuk hosting kamu!

📁 File Manager

  • • Upload file website (drag & drop)
  • • Edit file langsung di browser
  • • Buat folder dan atur struktur
  • • Hapus file yang tidak diperlukan
  • • Compress/extract file ZIP
  • • Set permission file (chmod)
💡 Tips:

File website utama harus di folder public_html

🗄️ Database MySQL

  • • Buat database MySQL baru
  • • Kelola user database & password
  • • Import/export data (.sql)
  • • Backup database otomatis
  • • phpMyAdmin untuk manage data
  • • Monitor penggunaan storage DB
💡 Tips:

Selalu backup database sebelum update

📧 Email Accounts

  • • Buat email dengan domain sendiri
  • • Atur forwarder email
  • • Kelola autoresponder
  • • Akses webmail (RoundCube/Horde)
  • • Setup email client (Outlook, Gmail)
  • • Spam filter & virus protection
💡 Tips:

Email profesional: info@domain.com

🔒 Security & SSL

  • • SSL Certificate (Let's Encrypt gratis)
  • • Password protect directory
  • • IP Blocker untuk blokir IP jahat
  • • Hotlink protection
  • • Two-factor authentication
  • • Security scan & malware detection
💡 Tips:

SSL wajib untuk website modern (HTTPS)

🛠️ Fitur CPanel Lainnya

📊 Statistics
  • • Visitor statistics
  • • Bandwidth usage
  • • Error logs
  • • Access logs
🔄 Backup & Restore
  • • Full backup website
  • • Partial backup
  • • Restore from backup
  • • Schedule backup
⚙️ Advanced
  • • Cron Jobs (scheduled tasks)
  • • PHP version selector
  • • .htaccess editor
  • • DNS Zone editor

Terminal Dasar

⌨️ Apa itu Terminal?

Terminal adalah antarmuka teks yang memungkinkan kamu berkomunikasi langsung dengan komputer atau server menggunakan perintah-perintah khusus.

🔧 Perintah Dasar Terminal

ls

Melihat daftar file dan folder

ls -la = detail lengkap dengan permission
cd nama_folder

Masuk ke folder tertentu

cd .. = naik satu level folder
mkdir nama_folder

Membuat folder baru

mkdir -p path/to/folder = buat nested folder
pwd

Melihat lokasi folder saat ini

Print Working Directory
cp file1 file2

Menyalin file

cp -r folder1 folder2 = copy folder
mv file1 file2

Memindah/rename file

Bisa untuk rename atau pindah lokasi
rm nama_file

Menghapus file

rm -rf folder = hapus folder & isinya
chmod 755 file

Mengatur permission file

755 = owner: rwx, group: rx, other: rx

📋 Perintah Tambahan yang Berguna

cat file.txt - Lihat isi file
nano file.txt - Edit file dengan nano
grep "text" file - Cari text dalam file
find . -name "*.html" - Cari file HTML
tar -czf backup.tar.gz folder - Compress folder
tar -xzf backup.tar.gz - Extract file
wget url - Download file dari URL
history - Lihat riwayat perintah

🚀 Perintah untuk Deployment

📥 Git Commands
git clone https://github.com/username/repo.git

Mengunduh kode dari repository Git

git pull origin main

Update kode ke versi terbaru

📦 Node.js/NPM Commands
npm install

Install dependencies dari package.json

npm run build

Build project untuk production

npm start

Menjalankan aplikasi

🐳 Docker Commands (Advanced)
docker build -t myapp .

Build Docker image

docker run -p 80:3000 myapp

Jalankan container

🔧 Server Management
systemctl restart nginx

Restart web server Nginx

pm2 start app.js

Jalankan Node.js app dengan PM2

htop

Monitor resource server

🎯 Tips Terminal untuk Pemula

⌨️ Keyboard Shortcuts
  • • Tab - Auto complete
  • • Ctrl+C - Stop proses
  • • Ctrl+L - Clear screen
  • • ↑↓ - History perintah
💡 Best Practices
  • • Selalu backup sebelum hapus file
  • • Gunakan ls sebelum cd
  • • Hati-hati dengan rm -rf
  • • Test perintah di folder test dulu

Domain & DNS

🏷️ Apa itu Domain?

Domain adalah alamat website yang mudah diingat manusia, seperti google.com atau facebook.com. Domain menggantikan alamat IP yang sulit diingat seperti 192.168.1.1.

🔗 Struktur Domain

subdomain
nama-domain
.com
Subdomain

www, blog, shop

Second Level Domain

Nama unik pilihan kamu

Top Level Domain

.com, .id, .org, .net

🏆 Jenis-jenis Domain

🌐 Generic TLD (gTLD)

  • • .com - Commercial (paling populer)
  • • .org - Organization
  • • .net - Network
  • • .info - Information
  • • .biz - Business

🇮🇩 Country Code TLD (ccTLD)

  • • .id - Indonesia
  • • .co.id - Company Indonesia
  • • .ac.id - Academic Indonesia
  • • .my.id - Personal Indonesia
  • • .web.id - Website Indonesia

🔍 Apa itu DNS?

DNS (Domain Name System) adalah sistem yang menerjemahkan nama domain menjadi alamat IP. Seperti buku telepon internet!

🔄 Cara Kerja DNS

1
User ketik domain

Kamu ketik "google.com" di browser

2
DNS Lookup

DNS server cari alamat IP untuk google.com

3
Return IP Address

DNS return IP: 172.217.194.100

4
Connect to Server

Browser connect ke server Google

📋 DNS Records Penting

  • • A Record - Point domain ke IP address
  • • CNAME - Alias untuk domain lain
  • • MX Record - Mail server settings
  • • NS Record - Name server info

⚡ DNS Providers

  • • Cloudflare - Gratis, cepat, secure
  • • Google DNS - 8.8.8.8, reliable
  • • AWS Route 53 - Enterprise level
  • • Domain Provider - Default DNS

💰 Membeli Domain

💡 Tips Memilih Domain

  • • Pilih nama yang mudah diingat
  • • Hindari angka dan tanda hubung
  • • Pertimbangkan SEO dan branding
  • • Cek ketersediaan di social media
  • • .com masih yang terbaik untuk bisnis
  • • Perpanjang otomatis untuk avoid kehilangan

Proses Deployment

📋 Langkah-langkah Deployment

Mari ikuti langkah-langkah untuk membuat website kamu bisa diakses oleh semua orang!

1

Persiapan File

  • • Pastikan semua file website sudah lengkap
  • • Test website di localhost terlebih dahulu
  • • Compress file menjadi ZIP jika perlu
  • • Siapkan database jika menggunakan database
2

Pilih Hosting & Domain

  • • Pilih provider hosting yang sesuai budget
  • • Beli domain atau gunakan subdomain gratis
  • • Catat informasi login hosting
  • • Tunggu proses aktivasi (biasanya 1-24 jam)
3

Upload File

  • • Login ke CPanel atau File Manager
  • • Masuk ke folder public_html
  • • Upload file website kamu
  • • Extract file ZIP jika diperlukan
4

Konfigurasi Database

  • • Buat database MySQL di CPanel
  • • Import file database (.sql)
  • • Update konfigurasi koneksi database
  • • Test koneksi database
5

Testing & Go Live!

  • • Akses website melalui domain
  • • Test semua fitur website
  • • Perbaiki error jika ada
  • • Website siap digunakan! 🎉
