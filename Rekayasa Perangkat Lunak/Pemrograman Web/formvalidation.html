PHP Form Processing

Belajar membuat form yang aman dan interaktif dengan mudah! 🚀

Apa itu Form Processing? 🤔

Form Processing adalah proses mengolah data yang dikirim dari form HTML menggunakan PHP. Bayangkan seperti kotak surat digital - user mengisi form (menulis surat), lalu PHP yang bertugas membaca dan memproses surat tersebut! 📮

Yang Akan Kita Pelajari:

Membuat form HTML yang cantik
Memproses data dengan PHP
Validasi input untuk keamanan
Menampilkan pesan error yang baik

Langkah 1: Membuat Form HTML

Membuat struktur form yang cantik dan fungsional

🎯 Tujuan Langkah Ini

Kita akan membuat form HTML yang cantik untuk mengumpulkan data dari user. Form ini seperti formulir pendaftaran yang sering kamu lihat di website!

Langkah-langkah:

  1. Buat file HTML baru
  2. Tambahkan struktur form
  3. Buat input fields yang dibutuhkan
  4. Tambahkan styling agar cantik

Langkah 3: Validasi Input

Memastikan data yang masuk aman dan sesuai

🎯 Mengapa Perlu Validasi?

Validasi itu seperti security guard di mall - mereka cek apakah yang masuk itu aman atau tidak. Kita perlu validasi untuk memastikan data yang masuk sesuai dengan yang kita harapkan! 🛡️

🔒 proses_validasi.php
<?php // Cek apakah form sudah di-submit if ($_POST) { // Array untuk menyimpan error $errors = array(); // Ambil dan bersihkan data $nama = trim($_POST['nama']); $email = trim($_POST['email']); $umur = $_POST['umur']; $jurusan = $_POST['jurusan']; $pesan = trim($_POST['pesan']); // Validasi Nama if (empty($nama)) { $errors[] = "Nama tidak boleh kosong! 😅"; } elseif (strlen($nama) < 3) { $errors[] = "Nama minimal 3 karakter ya! 📝"; } elseif (strlen($nama) > 50) { $errors[] = "Nama maksimal 50 karakter! 📏"; } // Validasi Email if (empty($email)) { $errors[] = "Email tidak boleh kosong! 📧"; } elseif (!filter_var($email, FILTER_VALIDATE_EMAIL)) { $errors[] = "Format email tidak valid! Contoh: nama@email.com 📮"; } // Validasi Umur if (empty($umur)) { $errors[] = "Umur tidak boleh kosong! 🎂"; } elseif ($umur < 15 || $umur > 25) { $errors[] = "Umur harus antara 15-25 tahun! 📅"; } // Validasi Jurusan $jurusan_valid = array('RPL', 'TKJ', 'MM'); if (empty($jurusan)) { $errors[] = "Pilih jurusan dulu ya! 🎓"; } elseif (!in_array($jurusan, $jurusan_valid)) { $errors[] = "Jurusan yang dipilih tidak valid! 🚫"; } // Validasi Pesan (opsional, tapi kalau diisi harus valid) if (!empty($pesan) && strlen($pesan) > 500) { $errors[] = "Pesan maksimal 500 karakter! ✂️"; } // Tampilkan hasil echo "<!DOCTYPE html>"; echo "<html lang='id'>"; echo "<head>"; echo "<meta charset='UTF-8'>"; echo "<meta name='viewport' content='width=device-width, initial-scale=1.0'>"; echo "<title>Hasil Validasi</title>"; echo "<style>"; echo "body { font-family: 'Segoe UI', sans-serif; background-color: #f8fafc; margin: 0; padding: 20px; color: #334155; }"; echo ".container { max-width: 600px; margin: 0 auto; background: white; padding: 30px; border-radius: 12px; box-shadow: 0 4px 20px rgba(0,0,0,0.08); border: 1px solid #e2e8f0; }"; echo ".success { background: #dcfce7; color: #166534; padding: 15px; border-radius: 8px; margin-bottom: 20px; border: 1px solid #bbf7d0; }"; echo ".error { background: #fef2f2; color: #dc2626; padding: 15px; border-radius: 8px; margin-bottom: 20px; border: 1px solid #fecaca; }"; echo ".info-box { background: #f8fafc; padding: 15px; border-radius: 8px; margin: 10px 0; border-left: 4px solid #3b82f6; }"; echo ".btn { background-color: #3b82f6; color: white; padding: 12px 25px; text-decoration: none; border-radius: 8px; display: inline-block; margin-top: 20px; font-weight: 600; }"; echo ".btn:hover { background-color: #2563eb; }"; echo "</style>"; echo "</head>"; echo "<body>"; echo "<div class='container'>"; // Jika ada error, tampilkan error if (!empty($errors)) { echo "<h1 style='text-align: center; color: #1e293b;'>❌ Oops! Ada Kesalahan</h1>"; echo "<div class='error'>"; echo "<strong>🚨 Mohon perbaiki kesalahan berikut:</strong><br><br>"; foreach ($errors as $error) { echo "• " . $error . "<br>"; } echo "</div>"; echo "<a href='index.html' class='btn'>🔙 Perbaiki Data</a>"; } else { // Jika tidak ada error, tampilkan sukses echo "<h1 style='text-align: center; color: #1e293b;'>✅ Pendaftaran Berhasil!</h1>"; echo "<div class='success'>"; echo "<strong>🎉 Selamat! Data kamu sudah berhasil divalidasi dan diterima.</strong>"; echo "</div>"; echo "<h2 style='color: #374151;'>📋 Data yang Diterima:</h2>"; echo "<div class='info-box'>"; echo "<strong>👤 Nama:</strong> " . htmlspecialchars($nama); echo "</div>"; echo "<div class='info-box'>"; echo "<strong>📧 Email:</strong> " . htmlspecialchars($email); echo "</div>"; echo "<div class='info-box'>"; echo "<strong>🎂 Umur:</strong> " . htmlspecialchars($umur) . " tahun"; echo "</div>"; echo "<div class='info-box'>"; echo "<strong>🎓 Jurusan:</strong> " . htmlspecialchars($jurusan); echo "</div>"; if (!empty($pesan)) { echo "<div class='info-box'>"; echo "<strong>💬 Pesan:</strong> " . htmlspecialchars($pesan); echo "</div>"; } echo "<a href='index.html' class='btn'>🔙 Kembali ke Form</a>"; } echo "</div>"; echo "</body>"; echo "</html>"; } else { // Jika tidak ada data POST, redirect ke form header("Location: index.html"); exit(); } ?>

Fungsi Validasi Penting:

trim() Menghapus spasi di awal dan akhir
empty() Cek apakah variabel kosong
strlen() Menghitung panjang string
filter_var() Validasi format email
in_array() Cek nilai ada dalam array
htmlspecialchars() Mencegah XSS attack
