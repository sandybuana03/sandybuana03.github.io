Konsep Routing

🎯 Apa itu Routing?

Routing adalah proses menentukan bagaimana aplikasi merespons permintaan client untuk endpoint tertentu. Endpoint adalah kombinasi dari path (jalur URL) dan method HTTP tertentu.

Analogi Sederhana:

Routing seperti peta jalan yang memberitahu aplikasi web kemana harus pergi ketika user mengklik link atau mengetik URL tertentu.

🔧 Routing Sederhana di PHP

Mari kita lihat contoh routing sederhana menggunakan PHP:

<?php
// index.php - Router sederhana
$request = $_SERVER['REQUEST_URI'];

switch ($request) {
    case '/':
    case '/home':
        echo "Selamat datang di halaman beranda! 🏠";
        break;
    case '/about':
        echo "Ini halaman tentang kami 📖";
        break;
    case '/contact':
        echo "Hubungi kami di sini 📞";
        break;
    default:
        echo "Halaman tidak ditemukan 😢";
        break;
}
?>

Penjelasan Kode:

  • • $_SERVER['REQUEST_URI'] mengambil URL yang diminta
  • • switch statement untuk mencocokkan URL
  • • Setiap case menangani URL yang berbeda
  • • default untuk halaman yang tidak ditemukan

⚡ Routing dengan Function

Untuk aplikasi yang lebih besar, kita bisa menggunakan function:

<?php
// Definisi function untuk setiap halaman
function homePage() {
    return "Selamat datang di beranda! 🏠";
}

function aboutPage() {
    return "Tentang perusahaan kami 📖";
}

function contactPage() {
    return "Kontak: email@example.com 📧";
}

// Router dengan function
$request = $_SERVER['REQUEST_URI'];
$routes = [
    '/' => 'homePage',
    '/home' => 'homePage',
    '/about' => 'aboutPage',
    '/contact' => 'contactPage'
];

if (array_key_exists($request, $routes)) {
    echo $routes[$request]();
} else {
    echo "Halaman tidak ditemukan 😢";
}
?>

HTTP Request

🤔 Apa itu Request?

Request adalah permintaan yang dikirim dari browser (client) ke server. Setiap kali kamu mengklik link, submit form, atau mengetik URL, kamu mengirim request!

Komponen Request:

  • 🎯 Method: GET, POST, PUT, DELETE
  • 🌐 URL: Alamat yang dituju
  • 📋 Headers: Informasi tambahan
  • 📦 Body: Data yang dikirim (untuk POST)

🔍 Method HTTP

GET Method 📖

Digunakan untuk mengambil data dari server

GET /products HTTP/1.1
Host: example.com

POST Method 📝

Digunakan untuk mengirim data ke server

POST /login HTTP/1.1
Content-Type: application/json

💻 Mengakses Request di PHP

<?php
// Mengambil method HTTP
$method = $_SERVER['REQUEST_METHOD'];
echo "Method: " . $method;

// Mengambil URL
$url = $_SERVER['REQUEST_URI'];
echo "URL: " . $url;

// Mengambil data GET
if (isset($_GET['name'])) {
    echo "Nama: " . $_GET['name'];
}

// Mengambil data POST
if (isset($_POST['email'])) {
    echo "Email: " . $_POST['email'];
}

// Mengambil semua headers
$headers = getallheaders();
foreach ($headers as $key => $value) {
    echo "$key: $value\n";
}
?>

HTTP Response

🎯 Apa itu Response?

Response adalah jawaban yang dikirim server kembali ke browser setelah menerima request. Ini seperti pelayan restoran yang membawa pesanan kamu ke meja!

Komponen Response:

  • 🔢 Status Code: 200 (OK), 404 (Not Found), 500 (Error)
  • 📋 Headers: Informasi tentang response
  • 📄 Body: Konten yang ditampilkan (HTML, JSON, dll)

📊 Status Code HTTP

2xx - Sukses ✅

200: OK - Request berhasil

201: Created - Data berhasil dibuat

3xx - Redirect 🔄

301: Moved Permanently

302: Found (Temporary)

4xx - Client Error ❌

400: Bad Request

404: Not Found

5xx - Server Error 💥

500: Internal Server Error

503: Service Unavailable

💻 Membuat Response di PHP

<?php
// Set status code
http_response_code(200);

// Set headers
header('Content-Type: application/json');
header('Access-Control-Allow-Origin: *');

// Kirim response JSON
$response = [
    'status' => 'success',
    'message' => 'Data berhasil diambil',
    'data' => [
        'name' => 'John Doe',
        'email' => 'john@example.com'
    ]
];

echo json_encode($response);

// Atau response HTML sederhana
echo "<h1>Selamat datang!</h1>";
echo "<p>Request kamu berhasil diproses</p>";
?>

Praktik Langsung

Mari buat aplikasi web sederhana dengan routing!

🎯 Tujuan Praktik

Kita akan membuat aplikasi web sederhana dengan fitur:

  • ✅ Routing untuk multiple halaman
  • ✅ Form handling dengan POST method
  • ✅ Response dalam format JSON dan HTML
  • ✅ Error handling untuk halaman tidak ditemukan

📝 Langkah 1: Buat File index.php

<?php
// index.php
session_start();

// Ambil URL yang diminta
$request = $_SERVER['REQUEST_URI'];
$method = $_SERVER['REQUEST_METHOD'];

// Definisi routes
$routes = [
    'GET' => [
        '/' => 'homePage',
        '/home' => 'homePage',
        '/about' => 'aboutPage',
        '/contact' => 'contactPage',
        '/users' => 'usersPage'
    ],
    'POST' => [
        '/contact' => 'handleContact',
        '/users' => 'createUser'
    ]
];

// Function untuk setiap halaman
function homePage() {
    return "
    <h1>🏠 Selamat Datang!</h1>
    <p>Ini adalah halaman beranda aplikasi kita.</p>
    <nav>
        <a href='/about'>Tentang Kami</a> | 
        <a href='/contact'>Kontak</a> | 
        <a href='/users'>Users</a>
    </nav>
    ";
}

function aboutPage() {
    return "
    <h1>📖 Tentang Kami</h1>
    <p>Kami adalah tim developer yang passionate!</p>
    <a href='/'>← Kembali ke Beranda</a>
    ";
}

function contactPage() {
    return "
    <h1>📞 Kontak Kami</h1>
    <form method='POST' action='/contact'>
        <input type='text' name='name' placeholder='Nama' required><br><br>
        <input type='email' name='email' placeholder='Email' required><br><br>
        <textarea name='message' placeholder='Pesan' required></textarea><br><br>
        <button type='submit'>Kirim Pesan</button>
    </form>
    <a href='/'>← Kembali ke Beranda</a>
    ";
}

function usersPage() {
    $users = $_SESSION['users'] ?? [];
    $html = "<h1>👥 Daftar Users</h1>";
    
    if (empty($users)) {
        $html .= "<p>Belum ada user yang terdaftar.</p>";
    } else {
        $html .= "<ul>";
        foreach ($users as $user) {
            $html .= "<li>{$user['name']} - {$user['email']}</li>";
        }
        $html .= "</ul>";
    }
    
    $html .= "
    <h3>Tambah User Baru:</h3>
    <form method='POST' action='/users'>
        <input type='text' name='name' placeholder='Nama' required><br><br>
        <input type='email' name='email' placeholder='Email' required><br><br>
        <button type='submit'>Tambah User</button>
    </form>
    <a href='/'>← Kembali ke Beranda</a>
    ";
    
    return $html;
}

function handleContact() {
    $name = $_POST['name'] ?? '';
    $email = $_POST['email'] ?? '';
    $message = $_POST['message'] ?? '';
    
    // Simpan pesan (dalam aplikasi nyata, simpan ke database)
    $_SESSION['messages'][] = [
        'name' => $name,
        'email' => $email,
        'message' => $message,
        'time' => date('Y-m-d H:i:s')
    ];
    
    return "
    <h1>✅ Pesan Terkirim!</h1>
    <p>Terima kasih <strong>$name</strong>, pesan kamu sudah kami terima!</p>
    <a href='/contact'>← Kirim Pesan Lagi</a> | 
    <a href='/'>Ke Beranda</a>
    ";
}

function createUser() {
    $name = $_POST['name'] ?? '';
    $email = $_POST['email'] ?? '';
    
    if (!isset($_SESSION['users'])) {
        $_SESSION['users'] = [];
    }
    
    $_SESSION['users'][] = [
        'name' => $name,
        'email' => $email,
        'created_at' => date('Y-m-d H:i:s')
    ];
    
    return "
    <h1>✅ User Berhasil Ditambahkan!</h1>
    <p>User <strong>$name</strong> telah ditambahkan ke sistem.</p>
    <a href='/users'>← Lihat Semua Users</a> | 
    <a href='/'>Ke Beranda</a>
    ";
}

// Router logic
if (isset($routes[$method][$request])) {
    $handler = $routes[$method][$request];
    $content = $handler();
} else {
    http_response_code(404);
    $content = "
    <h1>😢 Halaman Tidak Ditemukan</h1>
    <p>Maaf, halaman yang kamu cari tidak ada.</p>
    <a href='/'>← Kembali ke Beranda</a>
    ";
}

// Template HTML
echo "
<!DOCTYPE html>
<html>
<head>
    <title>Aplikasi PHP Routing</title>
    <style>
        body { font-family: Arial, sans-serif; margin: 40px; }
        input, textarea, button { 
            padding: 10px; margin: 5px 0; 
            border: 1px solid #ddd; border-radius: 5px; 
        }
        button { background: #007cba; color: white; cursor: pointer; }
        a { color: #007cba; text-decoration: none; }
    </style>
</head>
<body>
    $content
</body>
</html>
";
?>

  3. 3. Navigasi ke folder tempat file disimpan

  5. 5. Buka browser dan akses: http://localhost:8000

URL yang Bisa Diakses:
