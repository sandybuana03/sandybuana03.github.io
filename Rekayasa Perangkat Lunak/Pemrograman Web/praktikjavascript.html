Praktik Variabel

Variabel adalah kotak untuk menyimpan data! 📝

🧠 Apa itu Variabel?

Variabel adalah tempat penyimpanan data dalam program. Bayangkan seperti kotak yang diberi label untuk menyimpan berbagai jenis barang!

📝

let

Untuk data yang bisa berubah

🔒

const

Untuk data yang tetap

⚠️

var

Cara lama (tidak disarankan)

💡 Contoh dalam kehidupan sehari-hari:

• let umur = 17 → Umur bisa bertambah setiap tahun

• const nama = "Budi" → Nama biasanya tidak berubah

🎯 Langkah 1: Membuat Variabel

Ada 3 cara membuat variabel di JavaScript:

<!DOCTYPE html> <html> <head> <title>Belajar Variabel</title> </head> <body> <h1>Praktik Variabel JavaScript</h1> <script> // Membuat variabel dengan let (bisa diubah) let nama = "Budi"; let umur = 17; // Membuat variabel dengan const (tidak bisa diubah) const sekolah = "SMK Hebat"; // Menampilkan ke halaman HTML document.write("Nama: " + nama + "<br>"); document.write("Umur: " + umur + "<br>"); document.write("Sekolah: " + sekolah); </script> </body> </html>

💡 Tips: Gunakan let untuk data yang bisa berubah, const untuk data tetap!

Praktik Operator

Operator adalah simbol untuk melakukan operasi! ➕➖✖️➗

🧠 Apa itu Operator?

Operator adalah simbol khusus yang digunakan untuk melakukan operasi pada data. Seperti kalkulator yang bisa menghitung, membandingkan, dan mengolah data!

🧮 Operator Aritmatika

+ Penjumlahan (5 + 3 = 8)

- Pengurangan (5 - 3 = 2)

* Perkalian (5 * 3 = 15)

/ Pembagian (6 / 3 = 2)

% Modulus/Sisa bagi (7 % 3 = 1)

** Pangkat (2 ** 3 = 8)

🔍 Operator Perbandingan

== Sama dengan (5 == 5 → true)

!= Tidak sama (5 != 3 → true)

> Lebih besar (5 > 3 → true)

< Lebih kecil (3 < 5 → true)

>= Lebih besar sama dengan

<= Lebih kecil sama dengan

💡 Kenapa penting?

Operator memungkinkan program melakukan perhitungan, membuat keputusan, dan memproses data secara otomatis!

🎯 Langkah 1: Operator Aritmatika

🧮 Contoh HTML Lengkap - Operator Aritmatika

<!DOCTYPE html> <html> <head> <title>Operator Aritmatika</title> </head> <body> <h2>Kalkulator Sederhana</h2> <input type="number" id="angka1" placeholder="Angka 1"> <input type="number" id="angka2" placeholder="Angka 2"> <button onclick="hitung()">Hitung Semua</button> <div id="hasil"></div> <script> function hitung() { // Ambil nilai dari input let a = parseFloat(document.getElementById("angka1").value); let b = parseFloat(document.getElementById("angka2").value); // Operasi aritmatika let tambah = a + b; // Penjumlahan let kurang = a - b; // Pengurangan let kali = a * b; // Perkalian let bagi = a / b; // Pembagian let modulus = a % b; // Sisa bagi let pangkat = a ** b; // Pangkat // Tampilkan hasil document.getElementById("hasil").innerHTML = ` <h3>Hasil Perhitungan:</h3> <p>${a} + ${b} = ${tambah}</p> <p>${a} - ${b} = ${kurang}</p> <p>${a} × ${b} = ${kali}</p> <p>${a} ÷ ${b} = ${bagi}</p> <p>${a} % ${b} = ${modulus}</p> <p>${a} ^ ${b} = ${pangkat}</p> `; } </script> </body> </html>

🎯 Langkah 2: Operator Perbandingan

🔍 Contoh HTML Lengkap - Operator Perbandingan

<!DOCTYPE html> <html> <head> <title>Operator Perbandingan</title> </head> <body> <h2>Tes Perbandingan Nilai</h2> <input type="text" id="nilai1" placeholder="Nilai 1"> <input type="text" id="nilai2" placeholder="Nilai 2"> <button onclick="bandingkan()">Bandingkan</button> <div id="hasil"></div> <script> function bandingkan() { let a = document.getElementById("nilai1").value; let b = document.getElementById("nilai2").value; // Konversi ke angka untuk perbandingan numerik let numA = parseFloat(a); let numB = parseFloat(b); // Operator perbandingan let samaLonggar = (a == b); // == (sama nilai) let samaKetat = (a === b); // === (sama nilai & tipe) let tidakSama = (a != b); // != (tidak sama) let lebihBesar = (numA > numB); // > (lebih besar) let lebihKecil = (numA < numB); // < (lebih kecil) let lebihBesarSama = (numA >= numB); // >= (lebih besar sama dengan) document.getElementById("hasil").innerHTML = ` <h3>Hasil Perbandingan:</h3> <p>"${a}" == "${b}" = ${samaLonggar}</p> <p>"${a}" === "${b}" = ${samaKetat}</p> <p>"${a}" != "${b}" = ${tidakSama}</p> <p>${numA} > ${numB} = ${lebihBesar}</p> <p>${numA} < ${numB} = ${lebihKecil}</p> <p>${numA} >= ${numB} = ${lebihBesarSama}</p> `; } </script> </body> </html>

Praktik Fungsi

Fungsi adalah mesin yang mengolah data! 🔧

🧠 Apa itu Fungsi?

Fungsi adalah blok kode yang dapat digunakan berulang kali. Seperti mesin yang menerima input, memproses, dan menghasilkan output!

🏭 Analogi Pabrik:

📥

Input
(Parameter)

⚙️

Proses
(Kode Fungsi)

📤

Output
(Return)

📝 Fungsi Biasa

function sapa(nama) {
  return "Halo " + nama;
}

🏹 Arrow Function

const sapa = (nama) => {
  return "Halo " + nama;
}

💡 Keuntungan Fungsi:

  • Kode bisa digunakan berulang kali
  • Membuat program lebih terorganisir
  • Mudah untuk debug dan maintenance
  • Memecah masalah besar jadi bagian kecil

🎯 Langkah 1: Membuat Fungsi

<!DOCTYPE html> <html> <head> <title>Belajar Fungsi JavaScript</title> </head> <body> <h2>Generator Sapaan</h2> <input type="text" id="inputNama" placeholder="Masukkan nama"> <button onclick="tampilkanSapaan()">Sapa!</button> <div id="hasil"></div> <script> // Membuat fungsi sapa function sapa(nama) { return "Halo " + nama + "! 👋 Selamat datang!"; } // Fungsi untuk menampilkan sapaan ke HTML function tampilkanSapaan() { let nama = document.getElementById("inputNama").value; if (nama.trim() === "") { alert("Masukkan nama terlebih dahulu!"); return; } // Memanggil fungsi sapa let pesanSapaan = sapa(nama); // Tampilkan hasil ke HTML document.getElementById("hasil").innerHTML = `<h3 style="color: green;">${pesanSapaan}</h3>`; } // Fungsi kalkulator sederhana function tambah(a, b) { return a + b; } function kali(a, b) { return a * b; } // Contoh pemanggilan fungsi console.log(tambah(5, 3)); // Output: 8 console.log(kali(4, 6)); // Output: 24 </script> </body> </html>

🎯 Langkah 2: Arrow Function (Cara Modern)

<!DOCTYPE html> <html> <head> <title>Arrow Function Modern</title> </head> <body> <h2>Kalkulator dengan Arrow Function</h2> <input type="number" id="num1" placeholder="Angka 1"> <input type="number" id="num2" placeholder="Angka 2"> <button onclick="hitungSemua()">Hitung dengan Arrow Function</button> <div id="hasil"></div> <script> // Arrow function versi lengkap const tambah = (a, b) => { return a + b; }; // Arrow function versi singkat const kurang = (a, b) => a - b; const kali = (a, b) => a * b; const bagi = (a, b) => a / b; // Arrow function dengan satu parameter const kuadrat = x => x * x; // Arrow function tanpa parameter const salamPagi = () => "Selamat pagi! ☀️"; function hitungSemua() { let a = parseFloat(document.getElementById("num1").value); let b = parseFloat(document.getElementById("num2").value); document.getElementById("hasil").innerHTML = ` <h3>Hasil Arrow Function:</h3> <p>${a} + ${b} = ${tambah(a, b)}</p> <p>${a} - ${b} = ${kurang(a, b)}</p> <p>${a} × ${b} = ${kali(a, b)}</p> <p>${a} ÷ ${b} = ${bagi(a, b)}</p> <p>${a}² = ${kuadrat(a)}</p> <p>Pesan: ${salamPagi()}</p> `; } </script> </body> </html>

Praktik Perulangan

Buat program yang bisa mengulang tugas! 🔁

🧠 Apa itu Perulangan?

Perulangan (Loop) memungkinkan program menjalankan kode yang sama berulang kali. Seperti mesin cuci yang berputar berkali-kali sampai bersih!

🔄 Analogi Mesin Cuci:

🌀

Mesin berputar terus sampai kondisi terpenuhi

Kondisi: "Selama baju belum bersih, terus putar!"

Aksi: Putar → Cek → Putar → Cek → ...

🔢 For Loop

for (let i = 1; i <= 5; i++) {
  console.log(i);
}

Untuk jumlah perulangan yang pasti

⏳ While Loop

while (kondisi) {
  // kode
}

Selama kondisi masih benar

📋 forEach

array.forEach(item => {
  console.log(item);
});

Untuk setiap elemen array

💡 Contoh penggunaan:

  • Menampilkan daftar data
  • Menghitung total dari banyak angka
  • Membuat countdown timer
  • Memproses setiap item dalam keranjang belanja

🎯 Langkah 1: For Loop

<!DOCTYPE html> <html> <head> <title>Belajar For Loop</title> </head> <body> <h2>Generator Daftar Angka</h2> <input type="number" id="batasAngka" placeholder="Sampai angka berapa?" min="1" max="20"> <button onclick="buatDaftarAngka()">Buat Daftar!</button> <div id="hasilLoop"></div> <script> function buatDaftarAngka() { let batas = parseInt(document.getElementById("batasAngka").value); let hasil = document.getElementById("hasilLoop"); if (batas < 1 || batas > 20) { hasil.innerHTML = "❌ Masukkan angka antara 1-20!"; return; } let daftar = "<h3>📋 Daftar Angka 1 sampai " + batas + ":</h3><ul>"; // For loop untuk membuat daftar for (let i = 1; i <= batas; i++) { daftar += `<li>Angka ke-${i}: ${i * i} (kuadrat)</li>`; } daftar += "</ul>"; hasil.innerHTML = daftar; } // Contoh for loop sederhana for (let i = 1; i <= 5; i++) { console.log("Perulangan ke-" + i); } </script> </body> </html>

💡 Penjelasan:

  • • let i = 1 → Mulai dari 1
  • • i <= 5 → Selama i kurang dari atau sama dengan 5
  • • i++ → Tambah i sebanyak 1 setiap kali

Praktik Array

Array adalah daftar yang bisa menyimpan banyak data! 📝

🧠 Apa itu Array?

Array adalah struktur data yang dapat menyimpan banyak nilai dalam satu variabel. Seperti rak buku yang memiliki banyak slot untuk menyimpan buku!

📚 Analogi Rak Buku:

📚
Index 0
"Apel"
Index 1
"Jeruk"
Index 2
"Pisang"
Index 3
"Anggur"
Index 4
kosong

Array dimulai dari index 0!

📝 Membuat Array

let buah = ["apel", "jeruk", "pisang"];
let angka = [1, 2, 3, 4, 5];
let campuran = ["teks", 123, true];

🔧 Method Array

push() - Tambah di akhir

pop() - Hapus dari akhir

shift() - Hapus dari awal

unshift() - Tambah di awal

💡 Kegunaan Array:

  • Menyimpan daftar nama siswa
  • Menyimpan item belanja
  • Menyimpan nilai ujian
  • Menyimpan menu makanan

🎯 Langkah 1: Membuat dan Mengakses Array

<!DOCTYPE html> <html> <head> <title>Belajar Array JavaScript</title> </head> <body> <h2>Pengelola Data Siswa</h2> <button onclick="tampilkanArray()">Tampilkan Array</button> <button onclick="aksesElemen()">Akses Elemen Tertentu</button> <div id="hasilArray"></div> <script> // Membuat berbagai jenis array let namaSiswa = ["Budi", "Sari", "Andi", "Maya"]; let nilaiMatematika = [85, 92, 78, 96]; let statusLulus = [true, true, false, true]; function tampilkanArray() { let hasil = document.getElementById("hasilArray"); hasil.innerHTML = ` <h3>📋 Data Array:</h3> <p><strong>Nama Siswa:</strong> [${namaSiswa.join(', ')}]</p> <p><strong>Nilai Matematika:</strong> [${nilaiMatematika.join(', ')}]</p> <p><strong>Status Lulus:</strong> [${statusLulus.join(', ')}]</p> <p><strong>Jumlah Siswa:</strong> ${namaSiswa.length} orang</p> `; } function aksesElemen() { let hasil = document.getElementById("hasilArray"); // Mengakses elemen berdasarkan index (dimulai dari 0) hasil.innerHTML = ` <h3>🔍 Akses Elemen Array:</h3> <p><strong>Siswa pertama (index 0):</strong> ${namaSiswa[0]}</p> <p><strong>Siswa kedua (index 1):</strong> ${namaSiswa[1]}</p> <p><strong>Siswa terakhir:</strong> ${namaSiswa[namaSiswa.length - 1]}</p> <p><strong>Nilai tertinggi:</strong> ${Math.max(...nilaiMatematika)}</p> `; } </script> </body> </html>

Praktik Objek

Objek adalah wadah untuk menyimpan data yang saling berhubungan! 🗂️

🧠 Apa itu Objek?

Objek adalah struktur data yang menyimpan informasi dalam bentuk pasangan key-value. Seperti kartu identitas yang berisi berbagai informasi tentang seseorang!

🆔 Analogi Kartu Identitas:

👤
KARTU SISWA
Nama: Budi Santoso
Umur: 17 tahun
Kelas: XII RPL
Hobi: Coding, Game

📝 Membuat Objek

let siswa = {
  nama: "Budi",
  umur: 17,
  kelas: "XII RPL"
};

🔧 Objek dengan Method

let mobil = {
  merk: "Toyota",
  nyalakan() {
    return "Mesin hidup!";
  }
};

💡 Perbedaan Array vs Objek:

📋 Array:

Menyimpan data berurutan dengan index angka

["apel", "jeruk", "pisang"]

🏗️ Objek:

Menyimpan data dengan nama properti

{nama: "Budi", umur: 17}

🎯 Langkah 1: Membuat dan Mengakses Objek

<!DOCTYPE html> <html> <head> <title>Belajar Objek JavaScript</title> </head> <body> <h2>Database Siswa Sederhana</h2> <button onclick="tampilkanSiswa()">Tampilkan Data Siswa</button> <button onclick="ubahNilai()">Update Nilai</button> <button onclick="tambahHobi()">Tambah Hobi</button> <div id="hasilObjek"></div> <script> // Membuat objek siswa let siswa = { nama: "Budi Santoso", umur: 17, kelas: "XII RPL", nilai: { matematika: 85, bahasa: 90, pemrograman: 95 }, hobi: ["coding", "game", "musik"], aktif: true }; function tampilkanSiswa() { let hasil = document.getElementById("hasilObjek"); // Mengakses properti objek hasil.innerHTML = ` <h3>👤 Data Siswa:</h3> <p><strong>Nama:</strong> ${siswa.nama}</p> <p><strong>Umur:</strong> ${siswa.umur} tahun</p> <p><strong>Kelas:</strong> ${siswa.kelas}</p> <p><strong>Nilai Matematika:</strong> ${siswa.nilai.matematika}</p> <p><strong>Nilai Bahasa:</strong> ${siswa.nilai.bahasa}</p> <p><strong>Nilai Pemrograman:</strong> ${siswa.nilai.pemrograman}</p> <p><strong>Hobi:</strong> ${siswa.hobi.join(', ')}</p> <p><strong>Status:</strong> ${siswa.aktif ? 'Aktif' : 'Tidak Aktif'}</p> `; } function ubahNilai() { // Mengubah properti objek siswa.nilai.matematika = 95; siswa.nilai.bahasa = 88; alert("Nilai berhasil diupdate!"); tampilkanSiswa(); } function tambahHobi() { // Menambah elemen ke array dalam objek siswa.hobi.push("olahraga"); alert("Hobi baru ditambahkan!"); tampilkanSiswa(); } // Contoh akses properti console.log(siswa.nama); // "Budi Santoso" console.log(siswa["umur"]); // 17 console.log(siswa.nilai.matematika); // 85 </script> </body> </html>

<!DOCTYPE html> <html> <head> <title>Method dalam Objek</title> </head> <body> <h2>Simulasi Mobil Virtual</h2> <button onclick="tampilkanInfoMobil()">Info Mobil</button> <button onclick="nyalakanMobil()">Nyalakan Mesin</button> <button onclick="ubahWarnaMobil()">Ubah Warna</button> <button onclick="tambahBensin()">Isi Bensin</button> <div id="hasilMobil"></div> <script> // Objek mobil dengan method let mobil = { merk: "Toyota", model: "Avanza", tahun: 2020, warna: "putih", bensin: 50, mesinHidup: false, // Method untuk menampilkan info info: function() { return `Mobil ${this.merk} ${this.model} tahun ${this.tahun} berwarna ${this.warna}`; }, // Method untuk menyalakan mesin nyalakan: function() { if (this.bensin > 0) { this.mesinHidup = true; return "🚗 Mesin menyala! Siap berkendara!"; } else { return "⛽ Bensin habis! Praktik DOM Manipulation

Kontrol elemen HTML dengan JavaScript! ✨

🧠 Apa itu DOM?

DOM (Document Object Model) adalah cara JavaScript berinteraksi dengan elemen HTML. Seperti remote control yang bisa mengubah channel, volume, dan tampilan TV!

📺 Analogi Remote TV:

📺
🔍 Cari
getElementById()
✏️ Ubah
textContent
🎨 Style
style.color
➕ Tambah
createElement()
🗑️ Hapus
remove()
👂 Event
addEventListener()

🔍 Mengambil Elemen

getElementById("id")

querySelector(".class")

querySelectorAll("tag")

✏️ Mengubah Elemen

textContent = "teks"

innerHTML = "<b>html</b>"

style.color = "red"

💡 Apa yang bisa dilakukan DOM?

  • Mengubah teks dan warna elemen
  • Menambah atau menghapus elemen
  • Merespons klik, hover, dan input user
  • Membuat animasi dan efek interaktif

🎯 Langkah 1: Mengambil Elemen

<!DOCTYPE html> <html> <head> <title>DOM Manipulation</title> </head> <body> <h1 id="judulUtama">Judul Asli</h1> <p class="paragraf">Paragraf pertama</p> <p class="paragraf">Paragraf kedua</p> <button onclick="ubahJudul()">Ubah Judul</button> <button onclick="ubahParagraf()">Ubah Paragraf</button> <button onclick="tambahElemen()">Tambah Elemen</button> <div id="kontainer"></div> <script> // Mengambil elemen berdasarkan ID function ubahJudul() { let judul = document.getElementById("judulUtama"); judul.textContent = "Judul Sudah Berubah! ✨"; judul.style.color = "blue"; } // Mengambil elemen berdasarkan class function ubahParagraf() { let paragrafSemua = document.querySelectorAll(".paragraf"); paragrafSemua.forEach((p, index) => { p.innerHTML = `<strong>Paragraf ${index + 1} telah diubah! 🎉</strong>`; p.style.backgroundColor = "yellow"; p.style.padding = "10px"; }); } // Membuat elemen baru function tambahElemen() { let kontainer = document.getElementById("kontainer"); // Buat elemen div baru let divBaru = document.createElement("div"); divBaru.innerHTML = ` <h3>Elemen Baru! 🆕</h3> <p>Dibuat dengan JavaScript pada: ${new Date().toLocaleTimeString()}</p> `; divBaru.style.border = "2px solid green"; divBaru.style.padding = "15px"; divBaru.style.margin = "10px 0"; divBaru.style.borderRadius = "10px"; // Tambahkan ke kontainer kontainer.appendChild(divBaru); } // Contoh penggunaan querySelector let tombolPertama = document.querySelector("button"); console.log("Tombol pertama:", tombolPertama); </script> </body> </html>

🎯 Langkah 2: Event Listener

<!DOCTYPE html> <html> <head> <title>Event Listener JavaScript</title> </head> <body> <h2>Aplikasi To-Do List</h2> <input type="text" id="inputTugas" placeholder="Masukkan tugas baru..."> <button id="tombolTambah">Tambah Tugas</button> <button id="tombolHapusSemua">Hapus Semua</button> <ul id="daftarTugas"></ul> <p id="jumlahTugas">Total tugas: 0</p> <script> // Ambil elemen-elemen yang diperlukan let inputTugas = document.getElementById("inputTugas"); let tombolTambah = document.getElementById("tombolTambah"); let tombolHapusSemua = document.getElementById("tombolHapusSemua"); let daftarTugas = document.getElementById("daftarTugas"); let jumlahTugas = document.getElementById("jumlahTugas"); let tugasArray = []; // Event listener untuk tombol tambah tombolTambah.addEventListener("click", function() { let tugasBaru = inputTugas.value.trim(); if (tugasBaru !== "") { tugasArray.push(tugasBaru); inputTugas.value = ""; tampilkanTugas(); } else { alert("Masukkan tugas terlebih dahulu!"); } }); // Event listener untuk tombol hapus semua tombolHapusSemua.addEventListener("click", () => { if (confirm("Yakin ingin hapus semua tugas?")) { tugasArray = []; tampilkanTugas(); } }); // Event listener untuk Enter key inputTugas.addEventListener("keypress", function(event) { if (event.key === "Enter") { tombolTambah.click(); } }); // Fungsi untuk menampilkan tugas function tampilkanTugas() { daftarTugas.innerHTML = ""; tugasArray.forEach((tugas, index) => { let li = document.createElement("li"); li.innerHTML = ` ${index + 1}. ${tugas} <button onclick="hapusTugas(${index})">Hapus</button> `; daftarTugas.appendChild(li); }); jumlahTugas.textContent = `Total tugas: ${tugasArray.length}`; } // Fungsi untuk hapus tugas individual function hapusTugas(index) { tugasArray.splice(index, 1); tampilkanTugas(); } // Event listener untuk hover effect tombolTambah.addEventListener("mouseenter", () => { tombolTambah.style.backgroundColor = "green"; }); tombolTambah.addEventListener("mouseleave", () => { tombolTambah.style.backgroundColor = ""; }); </script> </body> </html>
