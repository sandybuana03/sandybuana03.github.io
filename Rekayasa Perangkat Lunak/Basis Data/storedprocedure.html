Pengenalan Stored Procedures

🤖 Apa itu Stored Procedures?

Stored Procedures (SP) adalah sekumpulan perintah SQL yang disimpan di dalam database dan dapat dipanggil berulang kali. Bayangkan seperti "resep masakan" yang sudah ditulis dan disimpan, tinggal dipanggil saat dibutuhkan! 👨‍🍳

"Stored Procedure = Kumpulan perintah SQL yang dikemas menjadi satu fungsi yang bisa dipanggil kapan saja!"

⭐ Keuntungan Menggunakan Stored Procedures

🚀 Performa lebih cepat
🔒 Keamanan tinggi
♻️ Dapat digunakan berulang
🎯 Logika terpusat
🛠️ Mudah maintenance
📊 Mengurangi network traffic

Konsep Dasar Stored Procedures

🏗️ Komponen Utama Stored Procedures

📝

Nama Procedure

Identitas unik untuk memanggil SP

⚙️

Parameter

Input/output data ke SP

💻

Body/Isi

Kumpulan perintah SQL

🔄 Jenis-jenis Stored Procedures

📥 System Stored Procedures

SP bawaan database untuk administrasi sistem (contoh: sp_help, sp_who)

👨‍💻 User-Defined Stored Procedures

SP yang kita buat sendiri sesuai kebutuhan aplikasi

🔧 Extended Stored Procedures

SP yang memanggil fungsi dari luar database (DLL)

⚡ Kapan Menggunakan Stored Procedures?

✅ Gunakan ketika:
  • • Operasi kompleks berulang
  • • Butuh performa tinggi
  • • Keamanan data penting
  • • Logika bisnis di database
❌ Hindari ketika:
  • • Query sederhana
  • • Butuh fleksibilitas tinggi
  • • Debugging kompleks
  • • Portabilitas database

Sintaks & Struktur

📋 Struktur Dasar Stored Procedure 

CREATE PROCEDURE nama_procedure
    @parameter1 tipe_data,
    @parameter2 tipe_data OUTPUT
AS
BEGIN
    -- Deklarasi variabel
    DECLARE @variabel tipe_data
    
    -- Logika procedure
    SELECT * FROM tabel WHERE kondisi = @parameter1
    
    -- Set output parameter
    SET @parameter2 = nilai
END

🔍 Penjelasan Setiap Bagian

CREATE PROCEDURE

Perintah untuk membuat stored procedure baru

Parameter (@parameter)

Input/output data yang diterima procedure. Dimulai dengan @ di SQL Server

AS BEGIN...END

Blok yang berisi semua perintah SQL yang akan dijalankan

DECLARE

Mendeklarasikan variabel lokal dalam procedure

💡 Contoh Sederhana

Mari buat SP untuk mencari data siswa berdasarkan nama:

CREATE PROCEDURE CariSiswa
    @NamaSiswa VARCHAR(50)
AS
BEGIN
    SELECT 
        NIS,
        Nama,
        Kelas,
        Jurusan
    FROM Siswa 
    WHERE Nama LIKE '%' + @NamaSiswa + '%'
END

💡 Cara Memanggil:

EXEC CariSiswa 'Ahmad'

Parameter dalam Stored Procedures

📥 Jenis-jenis Parameter

⬇️

INPUT

Data yang dikirim ke SP

@param INT
⬆️

OUTPUT

Data yang dikembalikan SP

@param INT OUTPUT
🔄

INPUT/OUTPUT

Data masuk & keluar

@param INT OUTPUT

💡 Contoh Parameter INPUT 

CREATE PROCEDURE TambahSiswa
    @NIS VARCHAR(10),
    @Nama VARCHAR(50),
    @Kelas VARCHAR(10),
    @Jurusan VARCHAR(30)
AS
BEGIN
    INSERT INTO Siswa (NIS, Nama, Kelas, Jurusan)
    VALUES (@NIS, @Nama, @Kelas, @Jurusan)
    
    PRINT 'Siswa berhasil ditambahkan!'
END

🚀 Cara Memanggil:

EXEC TambahSiswa '2024001', 'Budi Santoso', 'XII RPL 1', 'Rekayasa Perangkat Lunak'

📤 Contoh Parameter OUTPUT 

CREATE PROCEDURE HitungJumlahSiswa
    @Jurusan VARCHAR(30),
    @JumlahSiswa INT OUTPUT
AS
BEGIN
    SELECT @JumlahSiswa = COUNT(*)
    FROM Siswa
    WHERE Jurusan = @Jurusan
END

🎯 Cara Memanggil:

DECLARE @Hasil INT
EXEC HitungJumlahSiswa 'RPL', @Hasil OUTPUT
PRINT 'Jumlah siswa RPL: ' + CAST(@Hasil AS VARCHAR)

🎨 Parameter dengan Nilai Default 

CREATE PROCEDURE CariSiswaByKelas
    @Kelas VARCHAR(10) = 'XII RPL 1',  -- Nilai default
    @Jurusan VARCHAR(30) = 'RPL'       -- Nilai default
AS
BEGIN
    SELECT NIS, Nama, Kelas, Jurusan
    FROM Siswa
    WHERE Kelas = @Kelas AND Jurusan = @Jurusan
END

✅ Dengan parameter:

EXEC CariSiswaByKelas 'XII TKJ 1', 'TKJ'

✅ Tanpa parameter (pakai default):

EXEC CariSiswaByKelas

⚠️ Tips Penting Parameter

✅ Do:
  • • Gunakan nama parameter yang jelas
  • • Tentukan tipe data yang tepat
  • • Validasi input parameter
  • • Gunakan nilai default jika perlu
❌ Don't:
  • • Terlalu banyak parameter
  • • Nama parameter ambigu
  • • Lupa OUTPUT keyword
  • • Tidak validasi input

Kontrol Flow dalam Stored Procedures

🤔 IF-ELSE Statement

Untuk membuat keputusan dalam SP berdasarkan kondisi tertentu:

CREATE PROCEDURE CekKelulusan
    @NIS VARCHAR(10),
    @Status VARCHAR(20) OUTPUT
AS
BEGIN
    DECLARE @RataRata FLOAT
    
    SELECT @RataRata = AVG(Nilai)
    FROM Nilai
    WHERE NIS = @NIS
    
    IF @RataRata >= 75
        SET @Status = 'LULUS'
    ELSE IF @RataRata >= 60
        SET @Status = 'REMEDIAL'
    ELSE
        SET @Status = 'TIDAK LULUS'
END

💡 Penjelasan:

SP ini mengecek rata-rata nilai siswa dan menentukan status kelulusan berdasarkan kondisi yang berbeda.

🔁 WHILE Loop

Untuk mengulang perintah selama kondisi tertentu terpenuhi:

CREATE PROCEDURE GenerateNIS
    @JumlahSiswa INT
AS
BEGIN
    DECLARE @Counter INT = 1
    DECLARE @NIS VARCHAR(10)
    
    WHILE @Counter <= @JumlahSiswa
    BEGIN
        SET @NIS = '2024' + RIGHT('000' + CAST(@Counter AS VARCHAR), 3)
        
        PRINT 'NIS yang dibuat: ' + @NIS
        
        SET @Counter = @Counter + 1
    END
END

🎯 Hasil:

SP ini akan membuat NIS secara otomatis: 2024001, 2024002, 2024003, dst.

🎛️ CASE Statement

Untuk membuat keputusan dengan banyak pilihan:

CREATE PROCEDURE KonversiNilai
    @NilaiAngka INT,
    @NilaiHuruf VARCHAR(2) OUTPUT
AS
BEGIN
    SET @NilaiHuruf = 
        CASE 
            WHEN @NilaiAngka >= 90 THEN 'A'
            WHEN @NilaiAngka >= 80 THEN 'B'
            WHEN @NilaiAngka >= 70 THEN 'C'
            WHEN @NilaiAngka >= 60 THEN 'D'
            ELSE 'E'
        END
END

🌟 Kegunaan:

Mengkonversi nilai angka menjadi huruf sesuai standar penilaian sekolah.

🚨 TRY-CATCH (Error Handling)

Untuk menangani error yang mungkin terjadi:

CREATE PROCEDURE TambahSiswaAman
    @NIS VARCHAR(10),
    @Nama VARCHAR(50),
    @Kelas VARCHAR(10)
AS
BEGIN
    BEGIN TRY
        INSERT INTO Siswa (NIS, Nama, Kelas)
        VALUES (@NIS, @Nama, @Kelas)
        
        PRINT 'Siswa berhasil ditambahkan!'
    END TRY
    BEGIN CATCH
        PRINT 'Error: ' + ERROR_MESSAGE()
        PRINT 'NIS mungkin sudah ada atau data tidak valid'
    END CATCH
END

🛡️ Manfaat:

SP tidak akan crash jika ada error, dan memberikan pesan yang informatif kepada user.

🎪 Contoh Kombinasi Lengkap 

CREATE PROCEDURE ProsesPenilaian
    @NIS VARCHAR(10),
    @MataPelajaran VARCHAR(30),
    @NilaiUjian INT
AS
BEGIN
    BEGIN TRY
        DECLARE @Grade VARCHAR(2)
        DECLARE @Status VARCHAR(20)
        
        -- Validasi input
        IF @NilaiUjian < 0 OR @NilaiUjian > 100
        BEGIN
            PRINT 'Error: Nilai harus antara 0-100'
            RETURN
        END
        
        -- Konversi ke grade
        SET @Grade = 
            CASE 
                WHEN @NilaiUjian >= 90 THEN 'A'
                WHEN @NilaiUjian >= 80 THEN 'B'
                WHEN @NilaiUjian >= 70 THEN 'C'
                WHEN @NilaiUjian >= 60 THEN 'D'
                ELSE 'E'
            END
        
        -- Tentukan status
        IF @NilaiUjian >= 75
            SET @Status = 'LULUS'
        ELSE
            SET @Status = 'REMEDIAL'
        
        -- Simpan ke database
        INSERT INTO Nilai (NIS, MataPelajaran, Nilai, Grade, Status)
        VALUES (@NIS, @MataPelajaran, @NilaiUjian, @Grade, @Status)
        
        PRINT 'Nilai berhasil diproses!'
        PRINT 'Grade: ' + @Grade + ', Status: ' + @Status
        
    END TRY
    BEGIN CATCH
        PRINT 'Terjadi kesalahan: ' + ERROR_MESSAGE()
    END CATCH
END

Praktik Stored Procedures

Mari praktik langsung membuat dan menggunakan Stored Procedures! 🚀

1 Persiapan Database

Pertama, kita buat database dan tabel untuk praktik:

-- Buat database
CREATE DATABASE SekolahDB
GO

USE SekolahDB
GO

-- Buat tabel Siswa
CREATE TABLE Siswa (
    NIS VARCHAR(10) PRIMARY KEY,
    Nama VARCHAR(50) NOT NULL,
    Kelas VARCHAR(10),
    Jurusan VARCHAR(30),
    TanggalLahir DATE,
    Alamat TEXT
)

-- Buat tabel Nilai
CREATE TABLE Nilai (
    ID INT IDENTITY(1,1) PRIMARY KEY,
    NIS VARCHAR(10),
    MataPelajaran VARCHAR(30),
    Nilai INT,
    Grade VARCHAR(2),
    Status VARCHAR(20),
    FOREIGN KEY (NIS) REFERENCES Siswa(NIS)
)

📝 Tugas:

Jalankan script di atas di SQL Server Management Studio atau tool database lainnya.

2 SP untuk Menambah Siswa

Buat stored procedure untuk menambah data siswa baru:

CREATE PROCEDURE TambahSiswa
    @NIS VARCHAR(10),
    @Nama VARCHAR(50),
    @Kelas VARCHAR(10),
    @Jurusan VARCHAR(30),
    @TanggalLahir DATE,
    @Alamat TEXT
AS
BEGIN
    BEGIN TRY
        -- Cek apakah NIS sudah ada
        IF EXISTS (SELECT 1 FROM Siswa WHERE NIS = @NIS)
        BEGIN
            PRINT 'Error: NIS ' + @NIS + ' sudah terdaftar!'
            RETURN
        END
        
        -- Insert data siswa baru
        INSERT INTO Siswa (NIS, Nama, Kelas, Jurusan, TanggalLahir, Alamat)
        VALUES (@NIS, @Nama, @Kelas, @Jurusan, @TanggalLahir, @Alamat)
        
        PRINT 'Siswa ' + @Nama + ' berhasil ditambahkan dengan NIS: ' + @NIS
        
    END TRY
    BEGIN CATCH
        PRINT 'Terjadi kesalahan: ' + ERROR_MESSAGE()
    END CATCH
END

🎯 Test SP:

EXEC TambahSiswa '2024001', 'Ahmad Rizki', 'XII RPL 1', 'Rekayasa Perangkat Lunak', '2006-05-15', 'Jl. Merdeka No. 123'

3 SP untuk Mencari Siswa

Buat SP untuk mencari siswa berdasarkan berbagai kriteria:

CREATE PROCEDURE CariSiswa
    @Kriteria VARCHAR(20) = 'NAMA',  -- NAMA, NIS, KELAS, JURUSAN
    @NilaiCari VARCHAR(50)
AS
BEGIN
    IF @Kriteria = 'NAMA'
    BEGIN
        SELECT * FROM Siswa 
        WHERE Nama LIKE '%' + @NilaiCari + '%'
    END
    ELSE IF @Kriteria = 'NIS'
    BEGIN
        SELECT * FROM Siswa 
        WHERE NIS = @NilaiCari
    END
    ELSE IF @Kriteria = 'KELAS'
    BEGIN
        SELECT * FROM Siswa 
        WHERE Kelas = @NilaiCari
    END
    ELSE IF @Kriteria = 'JURUSAN'
    BEGIN
        SELECT * FROM Siswa 
        WHERE Jurusan LIKE '%' + @NilaiCari + '%'
    END
    ELSE
    BEGIN
        PRINT 'Kriteria tidak valid! Gunakan: NAMA, NIS, KELAS, atau JURUSAN'
    END
END

🔍 Contoh Penggunaan:

EXEC CariSiswa 'NAMA', 'Ahmad' EXEC CariSiswa 'KELAS', 'XII RPL 1'

4 SP untuk Input Nilai

Buat SP untuk input nilai dengan konversi otomatis ke grade:

CREATE PROCEDURE InputNilai
    @NIS VARCHAR(10),
    @MataPelajaran VARCHAR(30),
    @NilaiAngka INT
AS
BEGIN
    BEGIN TRY
        DECLARE @Grade VARCHAR(2)
        DECLARE @Status VARCHAR(20)
        
        -- Validasi siswa ada
        IF NOT EXISTS (SELECT 1 FROM Siswa WHERE NIS = @NIS)
        BEGIN
            PRINT 'Error: Siswa dengan NIS ' + @NIS + ' tidak ditemukan!'
            RETURN
        END
        
        -- Validasi nilai
        IF @NilaiAngka < 0 OR @NilaiAngka > 100
        BEGIN
            PRINT 'Error: Nilai harus antara 0-100'
            RETURN
        END
        
        -- Konversi ke grade
        SET @Grade = 
            CASE 
                WHEN @NilaiAngka >= 90 THEN 'A'
                WHEN @NilaiAngka >= 80 THEN 'B'
                WHEN @NilaiAngka >= 70 THEN 'C'
                WHEN @NilaiAngka >= 60 THEN 'D'
                ELSE 'E'
            END
        
        -- Tentukan status
        SET @Status = 
            CASE 
                WHEN @NilaiAngka >= 75 THEN 'LULUS'
                WHEN @NilaiAngka >= 60 THEN 'REMEDIAL'
                ELSE 'TIDAK LULUS'
            END
        
        -- Insert nilai
        INSERT INTO Nilai (NIS, MataPelajaran, Nilai, Grade, Status)
        VALUES (@NIS, @MataPelajaran, @NilaiAngka, @Grade, @Status)
        
        PRINT 'Nilai berhasil diinput!'
        PRINT 'Mata Pelajaran: ' + @MataPelajaran
        PRINT 'Nilai: ' + CAST(@NilaiAngka AS VARCHAR) + ' (Grade: ' + @Grade + ')'
        PRINT 'Status: ' + @Status
        
    END TRY
    BEGIN CATCH
        PRINT 'Terjadi kesalahan: ' + ERROR_MESSAGE()
    END CATCH
END

5 SP untuk Laporan Nilai

Buat SP untuk menampilkan laporan nilai siswa:

CREATE PROCEDURE LaporanNilai
    @NIS VARCHAR(10) = NULL,
    @Kelas VARCHAR(10) = NULL
AS
BEGIN
    IF @NIS IS NOT NULL
    BEGIN
        -- Laporan untuk siswa tertentu
        SELECT 
            s.NIS,
            s.Nama,
            s.Kelas,
            n.MataPelajaran,
            n.Nilai,
            n.Grade,
            n.Status
        FROM Siswa s
        INNER JOIN Nilai n ON s.NIS = n.NIS
        WHERE s.NIS = @NIS
        ORDER BY n.MataPelajaran
        
        -- Hitung rata-rata
        DECLARE @RataRata FLOAT
        SELECT @RataRata = AVG(CAST(Nilai AS FLOAT))
        FROM Nilai
        WHERE NIS = @NIS
        
        PRINT 'Rata-rata nilai: ' + CAST(ROUND(@RataRata, 2) AS VARCHAR)
    END
    ELSE IF @Kelas IS NOT NULL
    BEGIN
        -- Laporan untuk kelas tertentu
        SELECT 
            s.NIS,
            s.Nama,
            AVG(CAST(n.Nilai AS FLOAT)) as RataRata,
            COUNT(n.ID) as JumlahMapel
        FROM Siswa s
        LEFT JOIN Nilai n ON s.NIS = n.NIS
        WHERE s.Kelas = @Kelas
        GROUP BY s.NIS, s.Nama
        ORDER BY RataRata DESC
    END
    ELSE
    BEGIN
        PRINT 'Masukkan NIS atau Kelas untuk melihat laporan'
    END
END

📈 Contoh Laporan:

EXEC LaporanNilai @NIS = '2024001' EXEC LaporanNilai @Kelas = 'XII RPL 1'
