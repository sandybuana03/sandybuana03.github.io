Pengantar Belajar SQL

💭 Pertanyaan Pemantik

🤔 Bagaimana cara mencari data tertentu dari ribuan data?

+

Dengan menggunakan klausa WHERE! Seperti mencari buku di perpustakaan berdasarkan judul atau pengarang. WHERE membantu kita menyaring data sesuai kriteria yang diinginkan. 📚

📊 Mengapa data perlu diurutkan?

+

Data yang terurut lebih mudah dibaca dan dianalisis! Bayangkan daftar nilai siswa yang diurutkan dari tertinggi ke terendah - langsung terlihat siapa yang berprestasi terbaik. ORDER BY membuat data lebih bermakna! 🏆

📦 Kapan kita perlu mengelompokkan data?

+

Saat ingin melihat ringkasan atau statistik! Misalnya berapa jumlah siswa per kelas, rata-rata penjualan per bulan, atau total gaji per departemen. GROUP BY membantu membuat laporan yang informatif! 📈

✨ Apa bedanya WHERE dan HAVING?

+

WHERE menyaring data mentah, HAVING menyaring hasil kelompok! Seperti WHERE memilih siswa berdasarkan umur, sedangkan HAVING memilih kelas berdasarkan rata-rata nilai. Keduanya penting untuk analisis yang tepat! 🎯

Klausa WHERE

🎯 Apa itu WHERE?

WHERE adalah klausa yang digunakan untuk menyaring data berdasarkan kondisi tertentu. Bayangkan seperti filter di Instagram - kamu pilih foto mana yang mau ditampilkan! 📸

📝 Sintaks Dasar

-- Format dasar WHERE
SELECT kolom1, kolom2
FROM nama_tabel
WHERE kondisi;

🔢 Operator Perbandingan

= Sama dengan
!= Tidak sama dengan
> Lebih besar
< Lebih kecil

🔗 Operator Logika

AND Kedua kondisi harus benar
OR Salah satu kondisi benar
NOT Kebalikan kondisi

💡 Contoh Praktis

-- Cari siswa dengan umur 17 tahun
SELECT nama, kelas
FROM siswa
WHERE umur = 17;
-- Cari siswa kelas XII dengan nilai > 80
SELECT nama, nilai
FROM siswa
WHERE kelas = 'XII' AND nilai > 80;
📊

Klausa ORDER BY

🎯 Apa itu ORDER BY?

ORDER BY digunakan untuk mengurutkan hasil query. Seperti menyusun buku di rak - bisa berdasarkan abjad, tanggal, atau kriteria lainnya! 📚

📝 Sintaks Dasar

-- Format dasar ORDER BY
SELECT kolom1, kolom2
FROM nama_tabel
ORDER BY kolom ASC|DESC;

⬆️ ASC (Ascending)

Urutan naik (kecil ke besar)

A → B → C → D
1 → 2 → 3 → 4
2020 → 2021 → 2022

⬇️ DESC (Descending)

Urutan turun (besar ke kecil)

Z → Y → X → W
10 → 9 → 8 → 7
2022 → 2021 → 2020

💡 Contoh Praktis

-- Urutkan siswa berdasarkan nama (A-Z)
SELECT nama, kelas
FROM siswa
ORDER BY nama ASC;
-- Urutkan berdasarkan nilai tertinggi
SELECT nama, nilai
FROM siswa
ORDER BY nilai DESC;
-- Urutkan berdasarkan kelas, lalu nama
SELECT nama, kelas, nilai
FROM siswa
ORDER BY kelas ASC, nama ASC;
📦

Klausa GROUP BY

🎯 Apa itu GROUP BY?

GROUP BY digunakan untuk mengelompokkan data berdasarkan nilai yang sama. Seperti mengelompokkan permen berdasarkan warna atau rasa! 🍭

📝 Sintaks Dasar

-- Format dasar GROUP BY
SELECT kolom, fungsi_agregasi(kolom)
FROM nama_tabel
GROUP BY kolom;

🧮 Fungsi Agregasi yang Sering Dipakai

COUNT() Menghitung jumlah
SUM() Menjumlahkan
AVG() Rata-rata
MAX() Nilai maksimum

💡 Contoh Praktis

-- Hitung jumlah siswa per kelas
SELECT kelas, COUNT(*) AS jumlah_siswa
FROM siswa
GROUP BY kelas;
-- Rata-rata nilai per mata pelajaran
SELECT mata_pelajaran, AVG(nilai) AS rata_rata
FROM nilai_siswa
GROUP BY mata_pelajaran;
-- Nilai tertinggi per kelas
SELECT kelas, MAX(nilai) AS nilai_tertinggi
FROM siswa
GROUP BY kelas;

⚠️ Penting untuk Diingat!

Aturan GROUP BY: Semua kolom yang ada di SELECT (kecuali fungsi agregasi) harus ada juga di GROUP BY! 📋

✨

Klausa HAVING

🎯 Apa itu HAVING?

HAVING adalah WHERE untuk hasil GROUP BY! Digunakan untuk menyaring kelompok data setelah pengelompokan. Seperti memilih kotak permen yang isinya lebih dari 10! 🍬

📝 Sintaks Dasar

-- Format dasar HAVING
SELECT kolom, fungsi_agregasi(kolom)
FROM nama_tabel
GROUP BY kolom
HAVING kondisi_agregasi;

🤔 Perbedaan WHERE vs HAVING

🔍 WHERE
  • • Filter data sebelum GROUP BY
  • • Tidak bisa pakai fungsi agregasi
  • • Filter baris individual
✨ HAVING
  • • Filter data setelah GROUP BY
  • • Bisa pakai fungsi agregasi
  • • Filter kelompok data

💡 Contoh Praktis

-- Kelas dengan lebih dari 30 siswa
SELECT kelas, COUNT(*) AS jumlah
FROM siswa
GROUP BY kelas
HAVING COUNT(*) > 30;
-- Mata pelajaran dengan rata-rata nilai >= 80
SELECT mata_pelajaran, AVG(nilai) AS rata_rata
FROM nilai_siswa
GROUP BY mata_pelajaran
HAVING AVG(nilai) >= 80;
-- Kombinasi WHERE dan HAVING
SELECT kelas, AVG(nilai) AS rata_rata
FROM siswa
WHERE umur >= 16
GROUP BY kelas
HAVING AVG(nilai) > 75;

Operator SQL

🎯 Apa itu Operator SQL?

Operator SQL adalah simbol atau kata kunci yang digunakan untuk melakukan operasi pada data. Seperti kalkulator yang punya tombol +, -, ×, ÷ untuk menghitung! 🧮

🧮 Operator Aritmatika

Untuk melakukan perhitungan matematika

+ Penjumlahan
- Pengurangan
* Perkalian
/ Pembagian
-- Contoh operator aritmatika
SELECT nama, gaji, gaji * 12 AS gaji_tahunan
FROM karyawan;
SELECT nama, (nilai1 + nilai2 + nilai3) / 3 AS rata_rata
FROM siswa;

⚖️ Operator Perbandingan

Untuk membandingkan nilai

= Sama dengan
!= Tidak sama dengan
> Lebih besar dari
< Lebih kecil dari
>= Lebih besar sama dengan
<= Lebih kecil sama dengan
-- Contoh operator perbandingan
SELECT nama, umur
FROM siswa
WHERE umur >= 17;
SELECT nama, nilai
FROM siswa
WHERE nilai != 100;

🔗 Operator Logika

Untuk menggabungkan atau memodifikasi kondisi

AND Kedua kondisi harus benar

Seperti: "Umur >= 17 DAN Nilai >= 80"

OR Salah satu kondisi benar

Seperti: "Kelas = 'XI' ATAU Kelas = 'XII'"

NOT Kebalikan dari kondisi

Seperti: "BUKAN Kelas = 'X'"

-- Contoh operator logika
SELECT nama
FROM siswa
WHERE umur >= 17 AND nilai >= 80;
SELECT nama
FROM siswa
WHERE kelas = 'XI' OR kelas = 'XII';

✨ Operator Khusus

Operator dengan fungsi spesial

LIKE - Pencarian pola teks
% = karakter apapun (banyak)
_ = satu karakter apapun
-- Cari nama yang diawali 'A'
WHERE nama LIKE 'A%';
-- Cari nama yang berakhiran 'i'
WHERE nama LIKE '%i';
IN - Cek apakah nilai ada dalam daftar
-- Cari siswa kelas XI atau XII
WHERE kelas IN ('XI', 'XII');
-- Sama dengan: kelas = 'XI' OR kelas = 'XII'
BETWEEN - Cek nilai dalam rentang
-- Cari nilai antara 70-90
WHERE nilai BETWEEN 70 AND 90;
-- Sama dengan: nilai >= 70 AND nilai <= 90
IS NULL - Cek nilai kosong
-- Cari data yang kosong
WHERE email IS NULL;
-- Cari data yang tidak kosong
WHERE email IS NOT NULL;

🎯 Contoh Kombinasi Operator

-- Query kompleks dengan berbagai operator
SELECT nama, kelas, nilai, gaji * 12 AS gaji_tahunan
FROM karyawan
WHERE (umur BETWEEN 25 AND 40)
AND nama LIKE 'A%'
AND departemen IN ('IT', 'Marketing')
AND email IS NOT NULL
ORDER BY gaji DESC;

Praktik Klausa WHERE 🔍

📋 Langkah 3: Coba berbagai kondisi WHERE

-- 3a. Cari siswa kelas XII-A
SELECT * FROM siswa WHERE kelas = 'XII-A';
-- 3b. Cari siswa dengan nilai > 85
SELECT nama, nilai FROM siswa WHERE nilai > 85;
-- 3c. Cari siswa umur 17 DAN nilai >= 80
SELECT nama, umur, nilai FROM siswa
WHERE umur = 17 AND nilai >= 80;
-- 3d. Cari siswa kelas XI-A ATAU XI-B
SELECT nama, kelas FROM siswa
WHERE kelas = 'XI-A' OR kelas = 'XI-B';
4

Praktik ORDER BY 📊

📋 Langkah 4: Urutkan data dengan berbagai cara

-- 4a. Urutkan siswa berdasarkan nama (A-Z)
SELECT nama, kelas FROM siswa ORDER BY nama ASC;
-- 4b. Urutkan berdasarkan nilai tertinggi
SELECT nama, nilai FROM siswa ORDER BY nilai DESC;
-- 4c. Urutkan berdasarkan kelas, lalu nama
SELECT nama, kelas, nilai FROM siswa
ORDER BY kelas ASC, nama ASC;
-- 4d. Kombinasi WHERE dan ORDER BY
SELECT nama, kelas, nilai FROM siswa
WHERE nilai >= 80 ORDER BY nilai DESC;
5

Praktik GROUP BY 📦

📋 Langkah 5: Kelompokkan data dan gunakan fungsi agregasi

-- 5a. Hitung jumlah siswa per kelas
SELECT kelas, COUNT(*) AS jumlah_siswa
FROM siswa GROUP BY kelas;
-- 5b. Rata-rata nilai per kelas
SELECT kelas, AVG(nilai) AS rata_rata_nilai
FROM siswa GROUP BY kelas;
-- 5c. Nilai tertinggi dan terendah per kelas
SELECT kelas, MAX(nilai) AS nilai_tertinggi,
MIN(nilai) AS nilai_terendah
FROM siswa GROUP BY kelas;
-- 5d. Jumlah siswa per umur
SELECT umur, COUNT(*) AS jumlah
FROM siswa GROUP BY umur ORDER BY umur;
6

Praktik HAVING ✨

📋 Langkah 6: Filter hasil GROUP BY dengan HAVING

-- 6a. Kelas dengan lebih dari 2 siswa
SELECT kelas, COUNT(*) AS jumlah
FROM siswa GROUP BY kelas
HAVING COUNT(*) > 2;
-- 6b. Kelas dengan rata-rata nilai >= 80
SELECT kelas, AVG(nilai) AS rata_rata
FROM siswa GROUP BY kelas
HAVING AVG(nilai) >= 80;
-- 6c. Kombinasi WHERE, GROUP BY, dan HAVING
SELECT kelas, AVG(nilai) AS rata_rata
FROM siswa
WHERE umur >= 17
GROUP BY kelas
HAVING AVG(nilai) > 75;
7

Praktik Operator SQL ⚡

📋 Langkah 7: Gunakan berbagai operator SQL

-- 7a. Operator LIKE - nama yang diawali 'A'
SELECT nama, kelas FROM siswa WHERE nama LIKE 'A%';
-- 7b. Operator IN - siswa kelas XI atau XII
SELECT nama, kelas FROM siswa
WHERE kelas IN ('XI-A', 'XI-B', 'XII-A', 'XII-B');
-- 7c. Operator BETWEEN - nilai antara 75-90
SELECT nama, nilai FROM siswa
WHERE nilai BETWEEN 75 AND 90;
-- 7d. Operator IS NULL - siswa tanpa email
SELECT nama, email FROM siswa WHERE email IS NULL;
-- 7e. Operator IS NOT NULL - siswa dengan email
SELECT nama, email FROM siswa WHERE email IS NOT NULL;
8

Query Kompleks 🎯

📋 Langkah 8: Gabungkan semua yang sudah dipelajari

-- 8a. Query kompleks dengan semua klausa
SELECT kelas, COUNT(*) AS jumlah_siswa,
AVG(nilai) AS rata_rata_nilai,
MAX(nilai) AS nilai_tertinggi
FROM siswa
WHERE umur >= 16 AND email IS NOT NULL
GROUP BY kelas
HAVING COUNT(*) >= 2
ORDER BY rata_rata_nilai DESC;
-- 8b. Ranking siswa berdasarkan nilai
SELECT nama, kelas, nilai,
CASE
WHEN nilai >= 90 THEN 'Sangat Baik'
WHEN nilai >= 80 THEN 'Baik'
WHEN nilai >= 70 THEN 'Cukup'
ELSE 'Perlu Perbaikan'
END AS kategori
FROM siswa
ORDER BY nilai DESC;
