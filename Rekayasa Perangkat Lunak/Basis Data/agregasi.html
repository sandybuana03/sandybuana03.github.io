Pengenalan Fungsi Agregasi

🔍

Apa itu Fungsi Agregasi?

Fungsi agregasi adalah fungsi khusus dalam SQL yang memungkinkan kita untuk melakukan perhitungan pada sekumpulan data dan menghasilkan satu nilai hasil. Bayangkan seperti mesin ajaib yang bisa menghitung ribuan data dalam sekejap! ⚡

🎯

Kegunaan Utama

  • • Analisis data bisnis
  • • Pembuatan laporan
  • • Statistik dan metrik
  • • Pengambilan keputusan
⭐

5 Fungsi Utama

  • • COUNT - Menghitung jumlah
  • • SUM - Menjumlahkan nilai
  • • AVG - Menghitung rata-rata
  • • MIN - Mencari nilai minimum
  • • MAX - Mencari nilai maksimum

Fungsi COUNT

Menghitung jumlah baris data

📝

Penjelasan COUNT

Fungsi COUNT digunakan untuk menghitung jumlah baris dalam tabel atau jumlah nilai yang tidak NULL dalam kolom tertentu. Seperti menghitung berapa banyak siswa di kelas! 👥

Sintaks Dasar

SQL Query:
COUNT(*)
COUNT(nama_kolom)

Perbedaan

  • • COUNT(*) - Menghitung semua baris
  • • COUNT(kolom) - Menghitung nilai non-NULL
  • • COUNT(DISTINCT kolom) - Menghitung nilai unik
📊

Contoh Tabel: siswa

id nama kelas umur email
1 Andi XII RPL 17 andi@email.com
2 Budi XII TKJ 18 NULL
3 Citra XII RPL 17 citra@email.com
4 Dina XII MM 16 dina@email.com

🔍 Query 1: Hitung Semua Siswa

SQL Query:
SELECT COUNT(*) AS total_siswa
FROM siswa;
📋 Hasil:
total_siswa
4

📧 Query 2: Hitung Email Valid

SQL Query:
SELECT COUNT(email) AS email_valid
FROM siswa;
📋 Hasil:
email_valid
3

💡 NULL tidak dihitung!

➕

Fungsi SUM

Menjumlahkan nilai numerik

🧮

Penjelasan SUM

Fungsi SUM digunakan untuk menjumlahkan semua nilai numerik dalam kolom tertentu. Seperti kalkulator raksasa yang bisa menjumlahkan ribuan angka sekaligus! 🔢✨

📌 Penting Diingat

  • • Hanya bisa digunakan pada kolom numerik
  • • Nilai NULL diabaikan dalam perhitungan
  • • Hasil berupa satu nilai total
  • • Sangat berguna untuk laporan keuangan
🛒

Contoh Tabel: penjualan

id produk harga jumlah total
1 Laptop 8000000 2 16000000
2 Mouse 150000 5 750000
3 Keyboard 300000 3 900000
4 Monitor 2500000 1 2500000

💰 Query 1: Total Penjualan

SQL Query:
SELECT SUM(total) AS total_penjualan
FROM penjualan;
💵 Hasil:
total_penjualan
20,150,000

📦 Query 2: Total Barang Terjual

SQL Query:
SELECT SUM(jumlah) AS total_barang
FROM penjualan;
📊 Hasil:
total_barang
11

📈 Total unit terjual!

📊

Fungsi AVG

Menghitung nilai rata-rata

📈

Penjelasan AVG

Fungsi AVG (Average) digunakan untuk menghitung nilai rata-rata dari kolom numerik. Seperti menghitung rata-rata nilai ujian di kelas! 🎓

🔢 Cara Kerja

AVG = SUM(nilai) / COUNT(nilai)

  • • Menjumlahkan semua nilai
  • • Membagi dengan jumlah data
  • • Mengabaikan nilai NULL

💡 Kegunaan

  • • Analisis performa
  • • Benchmarking
  • • Perencanaan budget
  • • Evaluasi kualitas
🎯

Contoh Tabel: nilai_siswa

id nama matematika bahasa_inggris pemrograman
1 Andi 85 78 92
2 Budi 90 82 88
3 Citra 75 85 95
4 Dina 88 90 85

📚 Query 1: Rata-rata Matematika

SQL Query:
SELECT AVG(matematika) AS rata_matematika
FROM nilai_siswa;
📊 Hasil:
rata_matematika
84.5

🎯 (85+90+75+88)/4 = 84.5

💻 Query 2: Rata-rata Pemrograman

SQL Query:
SELECT AVG(pemrograman) AS rata_pemrograman
FROM nilai_siswa;
📈 Hasil:
rata_pemrograman
90.0

🚀 Nilai pemrograman paling tinggi!

⬇️

Fungsi MIN

Mencari nilai terkecil

🔍

Penjelasan MIN

Fungsi MIN digunakan untuk mencari nilai terkecil (minimum) dalam kolom tertentu. Seperti mencari siswa termuda di kelas atau harga produk termurah! 🏆

🎯 Kegunaan MIN

  • • Mencari harga termurah
  • • Menemukan nilai terendah
  • • Analisis performa minimum
  • • Quality control
  • • Benchmark batas bawah
🏪

Contoh Tabel: produk

id nama_produk harga stok rating
1 Smartphone A 3500000 15 4.5
2 Smartphone B 2800000 8 4.2
3 Smartphone C 4200000 12 4.8
4 Smartphone D 1950000 20 3.9

💰 Query 1: Harga Termurah

SQL Query:
SELECT MIN(harga) AS harga_termurah
FROM produk;
💵 Hasil:
harga_termurah
1,950,000

🏷️ Smartphone D paling murah!

⭐ Query 2: Rating Terendah

SQL Query:
SELECT MIN(rating) AS rating_terendah
FROM produk;
📊 Hasil:
rating_terendah
3.9

⚠️ Perlu perbaikan kualitas!

⬆️

Fungsi MAX

Mencari nilai terbesar

🏆

Penjelasan MAX

Fungsi MAX digunakan untuk mencari nilai terbesar (maksimum) dalam kolom tertentu. Seperti mencari siswa tertua di kelas atau produk termahal di toko! 🥇

🎯 Kegunaan MAX

  • • Mencari harga tertinggi
  • • Menemukan nilai terbaik
  • • Analisis performa maksimum
  • • Benchmark target
  • • Identifikasi outlier
👨‍💼

Contoh Tabel: karyawan

id nama departemen gaji pengalaman
1 Ahmad IT 8500000 5
2 Sari Marketing 7200000 3
3 Budi Finance 9800000 8
4 Dewi HR 6800000 2

💰 Query 1: Gaji Tertinggi

SQL Query:
SELECT MAX(gaji) AS gaji_tertinggi
FROM karyawan;
💵 Hasil:
gaji_tertinggi
9,800,000

🏆 Budi mendapat gaji tertinggi!

📅 Query 2: Pengalaman Terlama

SQL Query:
SELECT MAX(pengalaman) AS pengalaman_terlama
FROM karyawan;
📊 Hasil:
pengalaman_terlama
8

🎖️ 8 tahun pengalaman!

Step 1: Membuat Database

Langkah pertama adalah membuat database baru untuk menyimpan semua data kita. Database seperti rumah besar yang akan menampung berbagai tabel! 🏠

SQL Command - Membuat Database:
-- Membuat database baru
CREATE DATABASE sekolah_smk;

-- Menggunakan database yang sudah dibuat
USE sekolah_smk;
💡

Penjelasan:

  • • CREATE DATABASE - Membuat database baru bernama "sekolah_smk"
  • • USE - Memilih database yang akan digunakan untuk operasi selanjutnya
  • • Nama database sebaiknya deskriptif dan mudah diingat
  • • Setelah USE, semua tabel akan dibuat di database ini
🗄️

Step 2: Membuat Struktur Tabel

Sekarang kita buat 2 tabel: siswa dan penjualan. Tabel seperti lemari dengan laci-laci yang terorganisir untuk menyimpan data! 📋

📚 Tabel Siswa

CREATE TABLE siswa:
CREATE TABLE siswa (
  id INT PRIMARY KEY AUTO_INCREMENT,
  nama VARCHAR(50) NOT NULL,
  kelas VARCHAR(20) NOT NULL,
  umur INT NOT NULL,
  nilai_rata DECIMAL(5,2),
  email VARCHAR(100),
  tanggal_daftar DATE DEFAULT CURRENT_DATE
);
Penjelasan Kolom:
• id: Nomor unik siswa (auto increment)
• nama: Nama lengkap siswa
• kelas: Kelas siswa (XII RPL, XII TKJ, dll)
• umur: Umur siswa dalam tahun
• nilai_rata: Nilai rata-rata (0.00-100.00)
• email: Email siswa (boleh kosong)
• tanggal_daftar: Tanggal pendaftaran

🛒 Tabel Penjualan

CREATE TABLE penjualan:
CREATE TABLE penjualan (
  id INT PRIMARY KEY AUTO_INCREMENT,
  produk VARCHAR(100) NOT NULL,
  kategori VARCHAR(50),
  harga DECIMAL(12,2) NOT NULL,
  jumlah INT NOT NULL,
  total DECIMAL(15,2) AS (harga * jumlah),
  tanggal_jual DATE NOT NULL,
  sales VARCHAR(50)
);
Penjelasan Kolom:
• id: ID transaksi unik
• produk: Nama produk yang dijual
• kategori: Kategori produk
• harga: Harga per unit
• jumlah: Quantity yang dibeli
• total: Otomatis hitung (harga × jumlah)
• tanggal_jual: Tanggal transaksi
• sales: Nama sales yang melayani
👥

Step 5: Verifikasi Data

Sebelum mulai latihan agregasi, mari kita cek apakah data sudah masuk dengan benar! 🔍

📋 Cek Data Siswa

Query Verifikasi:
-- Lihat semua data siswa
SELECT * FROM siswa;

-- Hitung total siswa
SELECT COUNT(*) AS total_siswa FROM siswa;
Expected Result: 12 siswa terdaftar

🛒 Cek Data Penjualan

Query Verifikasi:
-- Lihat semua data penjualan
SELECT * FROM penjualan;

-- Hitung total transaksi
SELECT COUNT(*) AS total_transaksi FROM penjualan;
Expected Result: 15 transaksi tercatat
🔢

Latihan COUNT - 4 Variasi

1️⃣ Hitung Total Siswa

SELECT COUNT(*) AS total_siswa FROM siswa;
Hasil: 10 siswa

2️⃣ Hitung Siswa RPL

SELECT COUNT(*) FROM siswa WHERE kelas = 'XII RPL';
Hasil: 4 siswa RPL

3️⃣ Hitung Produk Berbeda

SELECT COUNT(DISTINCT produk) FROM penjualan;
Hasil: 10 jenis produk

4️⃣ Hitung Transaksi > 1 Juta

SELECT COUNT(*) FROM penjualan WHERE harga > 1000000;
Hasil: 5 transaksi
➕

Latihan SUM - 4 Contoh Berbeda

1️⃣ Total Pendapatan

SELECT SUM(harga * jumlah) AS total_pendapatan FROM penjualan;
Hasil: Rp 45,875,000

2️⃣ Total Barang Terjual

SELECT SUM(jumlah) AS total_barang FROM penjualan;
Hasil: 103 unit

3️⃣ Total Nilai Siswa RPL

SELECT SUM(nilai_rata) FROM siswa WHERE kelas = 'XII RPL';
Hasil: 344.5 poin

4️⃣ Pendapatan Elektronik

SELECT SUM(harga * jumlah) FROM penjualan WHERE produk LIKE '%top%';
Hasil: Rp 17,000,000
📈

Latihan AVG - Analisis Rata-rata

📊 Rata-rata Nilai Siswa

SELECT AVG(nilai_rata) AS rata_nilai FROM siswa;
Hasil: 85.47 (Baik!)

💰 Rata-rata Harga Produk

SELECT AVG(harga) AS rata_harga FROM penjualan;
Hasil: Rp 1,440,500

👥 Rata-rata Umur per Kelas

SELECT kelas, AVG(umur) FROM siswa GROUP BY kelas;
RPL: 16.75 th, TKJ: 18 th, MM: 16.67 th

📦 Rata-rata Quantity

SELECT AVG(jumlah) AS rata_qty FROM penjualan;
Hasil: 10.3 unit per transaksi
⬆️⬇️

Latihan MIN & MAX - Nilai Ekstrem

🏆 Nilai Tertinggi & Terendah

SELECT MAX(nilai_rata) AS tertinggi, MIN(nilai_rata) AS terendah FROM siswa;
Tertinggi: 94.2 | Terendah: 75.3

💎 Produk Termahal & Termurah

SELECT MAX(harga) AS termahal, MIN(harga) AS termurah FROM penjualan;
Termahal: Rp 8,500,000 | Termurah: Rp 75,000

👶👴 Umur Termuda & Tertua

SELECT MIN(umur) AS termuda, MAX(umur) AS tertua FROM siswa;
Termuda: 16 tahun | Tertua: 18 tahun

📊 Range Penjualan

SELECT MAX(jumlah) AS terbanyak, MIN(jumlah) AS tersedikit FROM penjualan;
Terbanyak: 25 unit | Tersedikit: 2 unit
🚀

Query Advanced - Kombinasi Semua Fungsi

📈 Analisis Komprehensif Penjualan

Advanced Query:
SELECT
  COUNT(*) AS total_transaksi,
  SUM(harga * jumlah) AS total_pendapatan,
  AVG(harga * jumlah) AS rata_per_transaksi,
  MIN(harga * jumlah) AS transaksi_terkecil,
  MAX(harga * jumlah) AS transaksi_terbesar
FROM penjualan;
Total Transaksi: 10
Total Pendapatan: Rp 45,875,000
Rata-rata per Transaksi: Rp 4,587,500
Transaksi Terkecil: Rp 1,875,000
Transaksi Terbesar: Rp 17,000,000

🎓 Statistik Siswa per Kelas

Group Analysis:
SELECT
  kelas,
  COUNT(*) AS jumlah_siswa,
  AVG(nilai_rata) AS rata_nilai,
  MIN(nilai_rata) AS nilai_terendah,
  MAX(nilai_rata) AS nilai_tertinggi
FROM siswa
GROUP BY kelas;
XII RPL: 4 siswa, rata-rata 86.13, range 83.4-92.1
XII TKJ: 3 siswa, rata-rata 77.7, range 75.3-79.6
XII MM: 3 siswa, rata-rata 92.37, range 90.8-94.2
