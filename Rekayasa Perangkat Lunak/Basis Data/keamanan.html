📚 Pengenalan Keamanan Basis Data

Apa itu Keamanan Basis Data?

Keamanan basis data adalah serangkaian tindakan dan mekanisme yang dirancang untuk melindungi database dari ancaman, akses yang tidak sah, dan kerusakan data. Ini mencakup perlindungan terhadap data, aplikasi database, dan infrastruktur yang mendukungnya.

🔒 Aspek Keamanan

  • • Confidentiality (Kerahasiaan)
  • • Integrity (Integritas)
  • • Availability (Ketersediaan)
  • • Authentication (Autentikasi)
  • • Authorization (Otorisasi)

⚠️ Ancaman Umum

  • • SQL Injection
  • • Akses tidak sah
  • • Kebocoran data
  • • Malware dan virus
  • • Human error

⚖️

🎯 Konsep Dasar Keamanan Database

Prinsip CIA Triad

🔐

Confidentiality

Memastikan data hanya dapat diakses oleh pihak yang berwenang

✅

Integrity

Menjaga keutuhan dan akurasi data dari perubahan yang tidak sah

🌐

Availability

Memastikan data tersedia saat dibutuhkan oleh pengguna yang sah

Komponen Keamanan Database

👤 Authentication

Proses verifikasi identitas pengguna sebelum memberikan akses ke database

🔑 Authorization

Menentukan hak akses dan privilege yang dimiliki pengguna setelah berhasil login

📊 Auditing

Pencatatan dan monitoring aktivitas database untuk deteksi anomali

🔒 Encryption

Enkripsi data untuk melindungi informasi sensitif dari akses tidak sah

👥 Pengelolaan Pengguna Database

Konsep User Management

Pengelolaan pengguna database melibatkan proses pembuatan, modifikasi, dan penghapusan akun pengguna, serta pengaturan kredensial dan profil keamanan mereka.

📋 Jenis-jenis Pengguna

  • •Database Administrator (DBA): Akses penuh
  • •Application User: Akses terbatas untuk aplikasi
  • •End User: Akses melalui aplikasi
  • •Guest User: Akses minimal/read-only

🔧 Operasi User Management

  • •CREATE USER - Membuat pengguna baru
  • •ALTER USER - Mengubah properti pengguna
  • •DROP USER - Menghapus pengguna
  • •GRANT/REVOKE - Memberikan/mencabut hak akses

Best Practices Pengelolaan Pengguna

🔐

Password Policy

  • • Minimal 8 karakter
  • • Kombinasi huruf, angka, simbol
  • • Pergantian berkala
  • • Tidak menggunakan password default
⏰

Account Lifecycle

  • • Provisioning otomatis
  • • Review berkala
  • • Deaktivasi akun tidak aktif
  • • Audit trail lengkap
🎯

Principle of Least Privilege

  • • Akses minimal yang diperlukan
  • • Role-based access control
  • • Segregation of duties
  • • Regular access review

🔐 Sistem Hak Akses Database

Jenis-jenis Privilege

📊 System Privileges

  • • CREATE SESSION - Login ke database
  • • CREATE TABLE - Membuat tabel
  • • CREATE USER - Membuat pengguna baru
  • • ALTER SYSTEM - Mengubah parameter sistem
  • • BACKUP DATABASE - Melakukan backup

🎭 Roles

  • • DBA - Database Administrator
  • • CONNECT - Koneksi dasar
  • • RESOURCE - Membuat objek
  • • SELECT_CATALOG_ROLE - Akses katalog

🗂️ Object Privileges

  • • SELECT - Membaca data
  • • INSERT - Menambah data
  • • UPDATE - Mengubah data
  • • DELETE - Menghapus data
  • • EXECUTE - Menjalankan prosedur

🔄 Grant Options

  • • WITH GRANT OPTION - Dapat memberikan hak
  • • WITH ADMIN OPTION - Admin privilege
  • • CASCADE - Pencabutan berantai

Model Kontrol Akses

🎯

DAC

Discretionary Access Control

Pemilik objek menentukan akses

🏛️

MAC

Mandatory Access Control

Sistem menentukan akses berdasarkan label

👥

RBAC

Role-Based Access Control

Akses berdasarkan peran pengguna

⚙️ Implementasi Keamanan Database

Contoh SQL Commands

Membuat User Baru

CREATE USER 'aplikasi_user'@'localhost' IDENTIFIED BY 'password123!';
CREATE USER 'readonly_user'@'%' IDENTIFIED BY 'readpass456!';

Memberikan Hak Akses

GRANT SELECT, INSERT, UPDATE ON database_sekolah.* TO 'aplikasi_user'@'localhost';
GRANT SELECT ON database_sekolah.siswa TO 'readonly_user'@'%';

Membuat dan Menggunakan Role

CREATE ROLE 'guru_role';
GRANT SELECT, INSERT, UPDATE ON database_sekolah.nilai TO 'guru_role';
GRANT 'guru_role' TO 'pak_budi'@'localhost';

💻 Praktik Keamanan Database

Langkah-langkah Praktik

1 Persiapan Environment

  • • Install MySQL/PostgreSQL/Oracle
  • • Pastikan service database berjalan
  • • Siapkan client tool (MySQL Workbench, pgAdmin, dll)
  • • Login sebagai administrator database

2 Membuat Database dan Tabel Sample

CREATE DATABASE sekolah_db;
USE sekolah_db;

CREATE TABLE siswa (
  id INT PRIMARY KEY AUTO_INCREMENT,
  nama VARCHAR(100) NOT NULL,
  kelas VARCHAR(10),
  email VARCHAR(100)
);

INSERT INTO siswa VALUES
(1, 'Ahmad Rizki', '12 IPA 1', 'ahmad@email.com'),
(2, 'Siti Nurhaliza', '12 IPA 2', 'siti@email.com');

3 Membuat User dengan Berbagai Level Akses

-- User untuk aplikasi dengan akses penuh
CREATE USER 'app_user'@'localhost' IDENTIFIED BY 'AppPass123!';

-- User untuk guru dengan akses terbatas
CREATE USER 'guru_user'@'localhost' IDENTIFIED BY 'GuruPass123!';

-- User untuk siswa dengan akses read-only
CREATE USER 'siswa_user'@'localhost' IDENTIFIED BY 'SiswaPass123!';

4 Memberikan Hak Akses Sesuai Role

-- Hak akses penuh untuk aplikasi
GRANT SELECT, INSERT, UPDATE, DELETE ON sekolah_db.* TO 'app_user'@'localhost';

-- Hak akses terbatas untuk guru
GRANT SELECT, INSERT, UPDATE ON sekolah_db.siswa TO 'guru_user'@'localhost';

-- Hak akses read-only untuk siswa
GRANT SELECT ON sekolah_db.siswa TO 'siswa_user'@'localhost';

FLUSH PRIVILEGES;

5 Testing Hak Akses

Lakukan testing dengan login menggunakan setiap user:

-- Test login sebagai siswa_user
mysql -u siswa_user -p

-- Coba operasi SELECT (harus berhasil)
SELECT * FROM sekolah_db.siswa;

-- Coba operasi INSERT (harus gagal)
INSERT INTO sekolah_db.siswa VALUES (3, 'Test', '12 IPA 3', 'test@email.com');

6 Implementasi Role-Based Access Control

-- Membuat role
CREATE ROLE 'guru_role';
CREATE ROLE 'siswa_role';

-- Memberikan privilege ke role
GRANT SELECT, INSERT, UPDATE ON sekolah_db.siswa TO 'guru_role';
GRANT SELECT ON sekolah_db.siswa TO 'siswa_role';

-- Assign role ke user
GRANT 'guru_role' TO 'guru_user'@'localhost';
GRANT 'siswa_role' TO 'siswa_user'@'localhost';

7 Monitoring dan Audit

-- Melihat user yang ada
SELECT User, Host FROM mysql.user;

-- Melihat privilege user
SHOW GRANTS FOR 'guru_user'@'localhost';

-- Enable general log untuk monitoring
SET GLOBAL general_log = 'ON';
SET GLOBAL general_log_file = '/var/log/mysql/general.log';
