Apa itu DDL?

DDL (Data Definition Language) adalah bagian dari SQL yang digunakan untuk mendefinisikan struktur database. Bayangkan DDL seperti arsitek yang merancang rumah! 🏠

🎯 Fungsi Utama DDL:

  • ✨ Membuat database dan tabel
  • 🔧 Mengubah struktur tabel
  • 🗑️ Menghapus database/tabel
  • 📋 Mendefinisikan constraint

🚀 Perintah Utama DDL:

  • CREATE - Membuat
  • ALTER - Mengubah
  • DROP - Menghapus
  • TRUNCATE - Mengosongkan
🏗️

Perintah CREATE

🏢 CREATE DATABASE

Membuat database baru - seperti membangun gedung baru untuk menyimpan data!

CREATE DATABASE nama_database;

-- Contoh:
CREATE DATABASE sekolah_smk;
CREATE DATABASE toko_online;

💡 Tips: Gunakan nama yang deskriptif dan mudah diingat!

📋 CREATE TABLE

Membuat tabel baru - seperti membuat lemari dengan berbagai laci untuk menyimpan barang!

CREATE TABLE nama_tabel (
    kolom1 tipe_data constraint,
    kolom2 tipe_data constraint,
    ...
);

-- Contoh Tabel Siswa:
CREATE TABLE siswa (
    id_siswa INT PRIMARY KEY AUTO_INCREMENT,
    nama VARCHAR(100) NOT NULL,
    kelas VARCHAR(10),
    umur INT,
    email VARCHAR(100) UNIQUE
);

📊 Tipe Data Umum:

  • INT - Angka bulat
  • VARCHAR(n) - Teks variabel
  • DATE - Tanggal
  • DECIMAL - Angka desimal

🔒 Constraint Umum:

  • PRIMARY KEY - Kunci utama
  • NOT NULL - Tidak boleh kosong
  • UNIQUE - Harus unik
  • AUTO_INCREMENT - Otomatis naik

📚 Tabel Referensi Tipe Data & Constraint

Panduan lengkap untuk membuat tabel dengan berbagai tipe data dan constraint:

🔢 Tipe Data Umum

Tipe Data Deskripsi Contoh
INT Angka bulat 123, -456
VARCHAR(n) Teks variabel "Nama Siswa"
DATE Tanggal 2024-01-15
DECIMAL(m,n) Angka desimal 15000.50
BOOLEAN True/False TRUE, FALSE

🔒 Constraint Umum

Constraint Fungsi Contoh
PRIMARY KEY Kunci utama id_siswa
NOT NULL Tidak boleh kosong nama
UNIQUE Harus unik email
AUTO_INCREMENT Otomatis naik id (1,2,3...)
DEFAULT Nilai default status='aktif'

Perintah ALTER

ALTER digunakan untuk mengubah struktur tabel yang sudah ada. Seperti renovasi rumah - bisa menambah kamar, mengubah ukuran, atau mengganti pintu! 🏠🔨

➕ Menambah Kolom (ADD COLUMN)

-- Menambah kolom baru
ALTER TABLE nama_tabel ADD COLUMN nama_kolom tipe_data;

-- Contoh:
ALTER TABLE siswa ADD COLUMN alamat VARCHAR(200);
ALTER TABLE siswa ADD COLUMN no_hp VARCHAR(15);
ALTER TABLE produk ADD COLUMN stok INT DEFAULT 0;

💡 Tips: Gunakan DEFAULT untuk memberikan nilai awal pada kolom baru!

🔄 Mengubah Kolom (MODIFY/ALTER COLUMN)

-- MySQL
ALTER TABLE nama_tabel MODIFY COLUMN nama_kolom tipe_data_baru;

-- PostgreSQL/SQL Server
ALTER TABLE nama_tabel ALTER COLUMN nama_kolom TYPE tipe_data_baru;

-- Contoh:
ALTER TABLE siswa MODIFY COLUMN nama VARCHAR(150);
ALTER TABLE produk MODIFY COLUMN harga DECIMAL(10,2);

🗑️ Menghapus Kolom (DROP COLUMN)

-- Menghapus kolom
ALTER TABLE nama_tabel DROP COLUMN nama_kolom;

-- Contoh:
ALTER TABLE siswa DROP COLUMN umur;
ALTER TABLE produk DROP COLUMN kategori_lama;

⚠️ Hati-hati: Data dalam kolom yang dihapus akan hilang permanen!

🏷️ Mengubah Nama (RENAME)

Mengubah nama tabel, kolom, atau database - seperti mengganti nama papan di depan rumah!

📋 Rename Tabel:

-- MySQL
RENAME TABLE nama_lama TO nama_baru;
ALTER TABLE nama_lama RENAME TO nama_baru;

-- Contoh:
RENAME TABLE siswa TO mahasiswa;
ALTER TABLE produk_lama RENAME TO produk;

📝 Rename Kolom:

-- MySQL
ALTER TABLE nama_tabel CHANGE nama_lama nama_baru tipe_data;

-- PostgreSQL/SQL Server
ALTER TABLE nama_tabel RENAME COLUMN nama_lama TO nama_baru;

-- Contoh:
ALTER TABLE siswa CHANGE nama nama_lengkap VARCHAR(100);
ALTER TABLE produk RENAME COLUMN harga TO harga_jual;

🏢 Rename Database:

-- Cara aman: Backup → Create → Import → Drop
-- 1. Backup database lama
mysqldump database_lama > backup.sql

-- 2. Buat database baru
CREATE DATABASE database_baru;

-- 3. Import data
mysql database_baru < backup.sql

-- 4. Hapus database lama (opsional)
DROP DATABASE database_lama;

⚠️ Tidak ada perintah langsung untuk rename database. Gunakan cara backup-restore!

Perintah DROP

⚠️ PERINGATAN: DROP akan menghapus secara permanen! Seperti menghancurkan bangunan - tidak bisa dikembalikan lagi!

🏢 DROP TABLE

Menghapus tabel beserta seluruh data di dalamnya.

-- Menghapus tabel
DROP TABLE nama_tabel;

-- Contoh:
DROP TABLE siswa_lama;
DROP TABLE temp_data;

-- Menghapus jika tabel ada (aman)
DROP TABLE IF EXISTS nama_tabel;

🏢 DROP DATABASE

Menghapus seluruh database beserta semua tabel di dalamnya.

-- Menghapus database
DROP DATABASE nama_database;

-- Contoh:
DROP DATABASE test_db;
DROP DATABASE backup_lama;

-- Menghapus jika database ada (aman)
DROP DATABASE IF EXISTS nama_database;

🚨 SUPER HATI-HATI: Ini akan menghapus SEMUA data dalam database!

🧹 TRUNCATE TABLE

Mengosongkan tabel (menghapus semua data) tapi struktur tabel tetap ada.

-- Mengosongkan tabel
TRUNCATE TABLE nama_tabel;

-- Contoh:
TRUNCATE TABLE log_aktivitas;
TRUNCATE TABLE data_sementara;

✅ Kelebihan TRUNCATE:

  • • Lebih cepat dari DELETE
  • • Reset AUTO_INCREMENT
  • • Struktur tabel tetap ada

⚠️ Perbedaan dengan DROP:

  • • DROP: Hapus tabel + data
  • • TRUNCATE: Hapus data saja
  • • DELETE: Hapus data tertentu

🛡️ Tips Keamanan

✅ Yang Harus Dilakukan:

  • ✓ Backup data sebelum DROP
  • ✓ Gunakan IF EXISTS
  • ✓ Test di database percobaan
  • ✓ Double-check nama tabel

❌ Yang Harus Dihindari:

  • ✗ DROP tanpa backup
  • ✗ DROP di production langsung
  • ✗ Tidak konfirmasi nama
  • ✗ Terburu-buru eksekusi

Praktik 1: DDL Sistematis

🎯 Mari praktik DDL secara sistematis dari awal sampai akhir! Kita akan membuat sistem database sekolah lengkap.

🏢 Langkah 1: Membuat Database

Aktif

Pertama, kita buat database untuk sistem sekolah. Database ini akan menyimpan semua data siswa, guru, dan mata pelajaran.

-- Langkah 1: Membuat Database Sekolah
CREATE DATABASE sekolah_smk;

-- Menggunakan database yang baru dibuat
USE sekolah_smk;

-- Cek database yang sedang digunakan
SELECT DATABASE();

💡 Tips: Gunakan nama database yang deskriptif!

📋 Langkah 2: Membuat Tabel-Tabel

Menunggu

Sekarang kita buat tabel-tabel yang diperlukan: siswa, guru, mata_pelajaran, dan kelas.

👨‍🎓 Tabel Siswa:

CREATE TABLE siswa (
    id_siswa INT PRIMARY KEY AUTO_INCREMENT,
    nis VARCHAR(10) UNIQUE NOT NULL,
    nama_lengkap VARCHAR(100) NOT NULL,
    tanggal_lahir DATE,
    jenis_kelamin ENUM('L', 'P') NOT NULL,
    alamat TEXT,
    no_hp VARCHAR(15),
    email VARCHAR(100) UNIQUE,
    tanggal_masuk DATE DEFAULT CURRENT_DATE
);

👨‍🏫 Tabel Guru:

CREATE TABLE guru (
    id_guru INT PRIMARY KEY AUTO_INCREMENT,
    nip VARCHAR(20) UNIQUE NOT NULL,
    nama_lengkap VARCHAR(100) NOT NULL,
    mata_pelajaran VARCHAR(50),
    no_hp VARCHAR(15),
    email VARCHAR(100) UNIQUE,
    status ENUM('aktif', 'nonaktif') DEFAULT 'aktif'
);

🏫 Tabel Kelas:

CREATE TABLE kelas (
    id_kelas INT PRIMARY KEY AUTO_INCREMENT,
    nama_kelas VARCHAR(20) NOT NULL,
    tingkat INT CHECK (tingkat BETWEEN 10 AND 12),
    jurusan VARCHAR(50),
    wali_kelas INT,
    kapasitas INT DEFAULT 36
);

💡 Tips: Perhatikan constraint dan tipe data yang sesuai!

🔧 Langkah 3: Memodifikasi Tabel

Menunggu

Setelah tabel dibuat, kita akan melakukan beberapa modifikasi untuk menyempurnakan struktur database.

➕ Menambah Kolom:

-- Menambah kolom foto ke tabel siswa
ALTER TABLE siswa ADD COLUMN foto VARCHAR(255);

-- Menambah kolom gaji ke tabel guru
ALTER TABLE guru ADD COLUMN gaji DECIMAL(10,2);

-- Menambah kolom ruang_kelas ke tabel kelas
ALTER TABLE kelas ADD COLUMN ruang_kelas VARCHAR(10);

🔄 Mengubah Kolom:

-- Memperbesar ukuran kolom alamat
ALTER TABLE siswa MODIFY COLUMN alamat VARCHAR(500);

-- Mengubah tipe data mata_pelajaran
ALTER TABLE guru MODIFY COLUMN mata_pelajaran VARCHAR(100);

🔗 Menambah Foreign Key:

-- Menambah foreign key ke tabel kelas
ALTER TABLE kelas ADD CONSTRAINT fk_wali_kelas
FOREIGN KEY (wali_kelas) REFERENCES guru(id_guru);

-- Menambah kolom id_kelas ke tabel siswa
ALTER TABLE siswa ADD COLUMN id_kelas INT;
ALTER TABLE siswa ADD CONSTRAINT fk_siswa_kelas
FOREIGN KEY (id_kelas) REFERENCES kelas(id_kelas);

💡 Tips: Foreign key membantu menjaga integritas data!

🗑️ Langkah 4: Operasi Penghapusan

Menunggu

Terakhir, kita akan belajar cara menghapus kolom, tabel, dan database dengan aman.

🗑️ Menghapus Kolom:

-- Menghapus kolom foto (jika tidak diperlukan)
ALTER TABLE siswa DROP COLUMN foto;

-- Menghapus kolom ruang_kelas
ALTER TABLE kelas DROP COLUMN ruang_kelas;

💾 Membuat Tabel Backup:

-- Membuat tabel backup sebelum menghapus
CREATE TABLE siswa_backup AS SELECT * FROM siswa;
CREATE TABLE guru_backup AS SELECT * FROM guru;

🧹 Mengosongkan Tabel (TRUNCATE):

-- Mengosongkan tabel backup (menghapus data, struktur tetap)
TRUNCATE TABLE siswa_backup;
TRUNCATE TABLE guru_backup;

-- Cek apakah tabel kosong
SELECT COUNT(*) FROM siswa_backup;
SELECT COUNT(*) FROM guru_backup;

💡 TRUNCATE menghapus semua data tapi struktur tabel tetap ada!

🗑️ Menghapus Tabel:

-- Menghapus tabel backup (contoh aman)
DROP TABLE IF EXISTS siswa_backup;
DROP TABLE IF EXISTS guru_backup;

-- Cek apakah tabel masih ada
SHOW TABLES LIKE '%backup%';

🏢 Menghapus Database:

-- SUPER HATI-HATI: Menghapus seluruh database!
-- Pastikan sudah backup terlebih dahulu

-- Buat database test untuk dihapus
CREATE DATABASE test_database;

-- Hapus database test (contoh aman)
DROP DATABASE IF EXISTS test_database;

-- Cek database yang tersedia
SHOW DATABASES;

-- JANGAN JALANKAN INI di production:
-- DROP DATABASE sekolah_smk;

🚨 PERINGATAN: DROP DATABASE menghapus SEMUA data dan tabel!

⚠️ Peringatan: Selalu backup sebelum DROP!

🛒 Mari praktik DDL dengan studi kasus toko online! Kita akan membuat sistem database untuk e-commerce lengkap.

🏢 Langkah 1: Membuat Database Toko Online

Aktif

Pertama, kita buat database untuk sistem toko online. Database ini akan menyimpan data produk, pelanggan, dan transaksi.

-- Langkah 1: Membuat Database Toko Online
CREATE DATABASE toko_online;

-- Menggunakan database yang baru dibuat
USE toko_online;

-- Cek database yang sedang digunakan
SELECT DATABASE();

💡 Tips: Database toko online butuh struktur yang terorganisir!

📋 Langkah 2: Membuat Tabel-Tabel E-Commerce

Menunggu

Sekarang kita buat tabel-tabel yang diperlukan: pelanggan, produk, kategori, dan pesanan.

👥 Tabel Pelanggan:

CREATE TABLE pelanggan (
    id_pelanggan INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,
    nama_lengkap VARCHAR(100) NOT NULL,
    no_hp VARCHAR(15),
    alamat TEXT,
    tanggal_daftar TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    status ENUM('aktif', 'nonaktif') DEFAULT 'aktif'
);

📂 Tabel Kategori:

CREATE TABLE kategori (
    id_kategori INT PRIMARY KEY AUTO_INCREMENT,
    nama_kategori VARCHAR(100) NOT NULL,
    deskripsi TEXT,
    gambar VARCHAR(255),
    status ENUM('aktif', 'nonaktif') DEFAULT 'aktif'
);

🛍️ Tabel Produk:

CREATE TABLE produk (
    id_produk INT PRIMARY KEY AUTO_INCREMENT,
    nama_produk VARCHAR(200) NOT NULL,
    deskripsi TEXT,
    harga DECIMAL(12,2) NOT NULL,
    stok INT DEFAULT 0,
    id_kategori INT,
    gambar VARCHAR(255),
    berat DECIMAL(8,2),
    tanggal_dibuat TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    status ENUM('aktif', 'nonaktif') DEFAULT 'aktif'
);

📦 Tabel Pesanan:

CREATE TABLE pesanan (
    id_pesanan INT PRIMARY KEY AUTO_INCREMENT,
    id_pelanggan INT NOT NULL,
    tanggal_pesanan TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    total_harga DECIMAL(15,2) NOT NULL,
    status_pesanan ENUM('pending', 'dikonfirmasi', 'dikirim', 'selesai', 'dibatalkan') DEFAULT 'pending',
    alamat_pengiriman TEXT NOT NULL,
    metode_pembayaran VARCHAR(50),
    catatan TEXT
);

💡 Tips: Perhatikan relasi antar tabel untuk e-commerce!

🔧 Langkah 3: Memodifikasi Tabel E-Commerce

Menunggu

Setelah tabel dibuat, kita akan melakukan beberapa modifikasi untuk menyempurnakan sistem toko online.

➕ Menambah Kolom:

-- Menambah kolom diskon ke tabel produk
ALTER TABLE produk ADD COLUMN diskon DECIMAL(5,2) DEFAULT 0;

-- Menambah kolom rating ke tabel produk
ALTER TABLE produk ADD COLUMN rating DECIMAL(3,2) DEFAULT 0;

-- Menambah kolom kode_pos ke tabel pelanggan
ALTER TABLE pelanggan ADD COLUMN kode_pos VARCHAR(10);

-- Menambah kolom ongkir ke tabel pesanan
ALTER TABLE pesanan ADD COLUMN ongkir DECIMAL(10,2) DEFAULT 0;

🔄 Mengubah Kolom:

-- Memperbesar ukuran kolom deskripsi produk
ALTER TABLE produk MODIFY COLUMN deskripsi LONGTEXT;

-- Mengubah tipe data berat produk
ALTER TABLE produk MODIFY COLUMN berat DECIMAL(10,3);

-- Memperbesar kolom alamat pelanggan
ALTER TABLE pelanggan MODIFY COLUMN alamat LONGTEXT;

🔗 Menambah Foreign Key:

-- Menambah foreign key produk ke kategori
ALTER TABLE produk ADD CONSTRAINT fk_produk_kategori
FOREIGN KEY (id_kategori) REFERENCES kategori(id_kategori);

-- Menambah foreign key pesanan ke pelanggan
ALTER TABLE pesanan ADD CONSTRAINT fk_pesanan_pelanggan
FOREIGN KEY (id_pelanggan) REFERENCES pelanggan(id_pelanggan);

-- Membuat tabel detail_pesanan
CREATE TABLE detail_pesanan (
    id_detail INT PRIMARY KEY AUTO_INCREMENT,
    id_pesanan INT,
    id_produk INT,
    jumlah INT NOT NULL,
    harga_satuan DECIMAL(12,2) NOT NULL,
    FOREIGN KEY (id_pesanan) REFERENCES pesanan(id_pesanan),
    FOREIGN KEY (id_produk) REFERENCES produk(id_produk)
);

💡 Tips: Foreign key penting untuk integritas data e-commerce!

🗑️ Langkah 4: Operasi Penghapusan Toko Online

Menunggu

Terakhir, kita akan belajar cara menghapus dan membersihkan data dalam sistem toko online.

🗑️ Menghapus Kolom:

-- Menghapus kolom gambar dari kategori (jika tidak diperlukan)
ALTER TABLE kategori DROP COLUMN gambar;

-- Menghapus kolom catatan dari pesanan
ALTER TABLE pesanan DROP COLUMN catatan;

💾 Membuat Tabel Backup:

-- Membuat tabel backup sebelum menghapus
CREATE TABLE pelanggan_backup AS SELECT * FROM pelanggan;
CREATE TABLE produk_backup AS SELECT * FROM produk;
CREATE TABLE pesanan_backup AS SELECT * FROM pesanan;

🧹 Mengosongkan Tabel (TRUNCATE):

-- Mengosongkan tabel backup (menghapus data, struktur tetap)
TRUNCATE TABLE pelanggan_backup;
TRUNCATE TABLE produk_backup;
TRUNCATE TABLE pesanan_backup;

-- Cek apakah tabel kosong
SELECT COUNT(*) FROM pelanggan_backup;
SELECT COUNT(*) FROM produk_backup;
SELECT COUNT(*) FROM pesanan_backup;

💡 TRUNCATE berguna untuk membersihkan data testing!

🗑️ Menghapus Tabel:

-- Menghapus tabel backup (contoh aman)
DROP TABLE IF EXISTS pelanggan_backup;
DROP TABLE IF EXISTS produk_backup;
DROP TABLE IF EXISTS pesanan_backup;

-- Cek apakah tabel masih ada
SHOW TABLES LIKE '%backup%';

🏢 Menghapus Database:

-- SUPER HATI-HATI: Menghapus seluruh database!
-- Pastikan sudah backup terlebih dahulu

-- Buat database test untuk dihapus
CREATE DATABASE test_toko_online;

-- Hapus database test (contoh aman)
DROP DATABASE IF EXISTS test_toko_online;

-- Cek database yang tersedia
SHOW DATABASES;

-- JANGAN JALANKAN INI di production:
-- DROP DATABASE toko_online;

🚨 PERINGATAN: Backup data pelanggan dan transaksi sangat penting!

⚠️ Peringatan: Data e-commerce sangat berharga, selalu backup!
