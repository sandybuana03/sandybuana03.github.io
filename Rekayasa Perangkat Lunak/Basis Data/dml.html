🔍 Perintah SELECT - Si Pencari Data 🔍

🕵️‍♂️

🎯 Apa itu SELECT?

SELECT adalah perintah untuk melihat atau mengambil data dari tabel database. Seperti kamu yang mengintip isi kotak mainan! 👀

Analogi: Bayangkan database seperti perpustakaan raksasa 📚. SELECT adalah seperti katalog yang membantu kamu mencari dan melihat buku yang kamu inginkan!

📝 Struktur Dasar SELECT

-- Struktur dasar SELECT
SELECT kolom1, kolom2, kolom3
FROM nama_tabel
WHERE kondisi;

🌟 SELECT Semua Kolom

SELECT * FROM siswa;

Tanda * artinya "semua kolom"

🎯 SELECT Kolom Tertentu

SELECT nama, kelas FROM siswa;

Hanya ambil kolom nama dan kelas

🔧 Clause Penting dalam SELECT

🔍

WHERE - Filter Data

SELECT * FROM siswa
WHERE kelas = '12';

Hanya tampilkan siswa kelas 12

📊

ORDER BY - Urutkan

SELECT * FROM siswa
ORDER BY nama ASC;

Urutkan berdasarkan nama A-Z

🔢

LIMIT - Batasi Hasil

SELECT * FROM siswa
LIMIT 5;

Hanya tampilkan 5 data pertama

🎯

DISTINCT - Unik Saja

SELECT DISTINCT jurusan
FROM siswa;

Tampilkan jurusan tanpa duplikat

🎮 Playground SELECT Interaktif!

Pilih jenis query SELECT yang ingin kamu coba! 👇

💡 Tips & Trik SELECT

⚡ Performance Tip

Hindari SELECT * pada tabel besar! Pilih kolom yang benar-benar dibutuhkan saja untuk performa yang lebih cepat.

🔍 WHERE Clause

Gunakan WHERE untuk filter data. Contoh: WHERE umur > 18 AND kelas = '12'

📊 ORDER BY

ASC = naik (A-Z, 1-9), DESC = turun (Z-A, 9-1). Default adalah ASC.

➕ Perintah INSERT - Si Penambah Data ➕

📦

🎯 Apa itu INSERT?

INSERT adalah perintah untuk menambahkan data baru ke dalam tabel database. Seperti kamu memasukkan mainan baru ke dalam kotak! 📦✨

Analogi: Bayangkan tabel database seperti buku catatan 📝. INSERT adalah seperti menulis baris baru di halaman kosong!

📝 Struktur Dasar INSERT

-- Struktur dasar INSERT
INSERT INTO nama_tabel (kolom1, kolom2, kolom3)
VALUES (nilai1, nilai2, nilai3);

📝 INSERT Satu Data

INSERT INTO siswa (nama, kelas, jurusan)
VALUES ('Andi', '11', 'RPL');

Menambah satu siswa baru

📝 INSERT Banyak Data

INSERT INTO siswa (nama, kelas, jurusan)
VALUES ('Andi', '11', 'RPL'),
       ('Sari', '12', 'TKJ');

Menambah beberapa siswa sekaligus

🔧 Variasi INSERT

🎯

INSERT Sebagian Kolom

INSERT INTO siswa (nama, kelas)
VALUES ('Budi', '10');

Kolom jurusan akan NULL atau default

🔄

INSERT dari SELECT

INSERT INTO siswa_lulus
SELECT * FROM siswa
WHERE kelas = '12';

Copy data dari tabel lain

🎮 Playground INSERT Interaktif!

Isi form di bawah untuk mencoba INSERT data siswa baru! 👇

⚠️ Hal Penting dalam INSERT

🔑 Primary Key

Pastikan nilai primary key (biasanya ID) unik! Jika sudah ada, INSERT akan gagal.

📝 Tipe Data

Pastikan tipe data sesuai! Angka untuk kolom integer, teks untuk varchar, dll.

✅ Validasi

Selalu validasi data sebelum INSERT untuk menghindari data yang tidak valid.

✏️ Perintah UPDATE - Si Pengubah Data ✏️

🔄

🎯 Apa itu UPDATE?

UPDATE adalah perintah untuk mengubah atau memperbarui data yang sudah ada di tabel. Seperti kamu mengedit postingan di media sosial! 🔄✨

Analogi: Bayangkan UPDATE seperti correction tape atau penghapus 🖊️. Kamu bisa mengubah tulisan yang salah tanpa menulis ulang seluruh halaman!

📝 Struktur Dasar UPDATE

-- Struktur dasar UPDATE
UPDATE nama_tabel
SET kolom1 = nilai_baru1, kolom2 = nilai_baru2
WHERE kondisi;

✏️ UPDATE Satu Kolom

UPDATE siswa
SET kelas = '12'
WHERE nama = 'Andi';

Mengubah kelas Andi menjadi 12

✏️ UPDATE Banyak Kolom

UPDATE siswa
SET kelas = '12', jurusan = 'RPL'
WHERE nama = 'Andi';

Mengubah kelas dan jurusan Andi

🔧 Variasi UPDATE

🎯

UPDATE dengan Kondisi

UPDATE siswa
SET status = 'Lulus'
WHERE kelas = '12' AND nilai >= 75;

Update siswa kelas 12 yang nilainya >= 75

🔢

UPDATE dengan Operasi

UPDATE siswa
SET nilai = nilai + 5
WHERE jurusan = 'RPL';

Tambah 5 poin untuk semua siswa RPL

🎮 Playground UPDATE Interaktif!

Pilih siswa dan ubah datanya! 👇

⚠️ BAHAYA! Hal Penting dalam UPDATE

🚨 WAJIB Pakai WHERE!

JANGAN PERNAH lupa WHERE clause! Tanpa WHERE, SEMUA data akan berubah!

❌ BAHAYA: UPDATE siswa SET kelas = '12';
✅ AMAN: UPDATE siswa SET kelas = '12' WHERE nama = 'Andi';

💾 Backup Dulu!

Selalu backup data penting sebelum UPDATE besar-besaran. Better safe than sorry!

🔍 Test dengan SELECT

Sebelum UPDATE, coba SELECT dulu dengan WHERE yang sama untuk memastikan data yang tepat.

🗑️ Perintah DELETE - Si Penghapus Data 🗑️

🚮

🎯 Apa itu DELETE?

DELETE adalah perintah untuk menghapus data dari tabel database. Seperti kamu menghapus foto di galeri HP yang sudah tidak dibutuhkan! 🗑️💨

Analogi: Bayangkan DELETE seperti shredder atau mesin penghancur kertas 🗂️. Sekali dihapus, data hilang PERMANEN (kecuali ada backup)!

📝 Struktur Dasar DELETE

-- Struktur dasar DELETE
DELETE FROM nama_tabel
WHERE kondisi;

🗑️ DELETE Satu Data

DELETE FROM siswa
WHERE nama = 'Andi';

Menghapus data siswa bernama Andi

🗑️ DELETE Banyak Data

DELETE FROM siswa
WHERE kelas = '12';

Menghapus semua siswa kelas 12

🔧 Variasi DELETE

🎯

DELETE dengan Kondisi

DELETE FROM siswa
WHERE nilai < 60 AND status = 'Tidak Aktif';

Hapus siswa nilai < 60 dan tidak aktif

🔢

DELETE dengan LIMIT

DELETE FROM siswa
WHERE status = 'Pindah'
LIMIT 5;

Hapus maksimal 5 siswa yang pindah

🎮 Simulasi DELETE (Aman!)

Pilih siswa yang akan "dihapus" (hanya simulasi!) 👇

🚨 SUPER BAHAYA! Hal Kritis dalam DELETE

💀 JANGAN LUPA WHERE!

DELETE tanpa WHERE = BENCANA! Semua data akan terhapus PERMANEN!

💀 BENCANA: DELETE FROM siswa;
✅ AMAN: DELETE FROM siswa WHERE nama = 'Andi';

💾 BACKUP WAJIB!

SELALU backup sebelum DELETE! Data yang terhapus tidak bisa dikembalikan tanpa backup.

🔍 Test dengan SELECT

Sebelum DELETE, jalankan SELECT dengan WHERE yang sama untuk memastikan data yang tepat.

🔄 Pertimbangkan Soft Delete

Untuk data penting, gunakan "soft delete" (UPDATE status = 'deleted') daripada DELETE permanen.
