📚 Pengenalan SQL Join

🤝 Apa itu JOIN?

JOIN adalah operasi dalam SQL yang digunakan untuk menggabungkan data dari dua atau lebih tabel berdasarkan kolom yang saling berhubungan. Bayangkan seperti menghubungkan dua puzzle yang berbeda untuk membuat gambar yang lengkap!

🎯 Mengapa JOIN Penting?

  • • Menghindari duplikasi data (normalisasi database)
  • • Menghemat ruang penyimpanan
  • • Memudahkan maintenance data
  • • Membuat query yang lebih efisien

🔍 Jenis-jenis JOIN

🔗 INNER JOIN

Menampilkan data yang ada di kedua tabel

⬅️ LEFT JOIN

Menampilkan semua data dari tabel kiri

➡️ RIGHT JOIN

Menampilkan semua data dari tabel kanan

🔄 FULL JOIN

Menampilkan semua data dari kedua tabel

📝 Sintaks Dasar JOIN 

SELECT kolom1, kolom2, ...
FROM tabel1
JOIN tabel2 ON tabel1.kolom = tabel2.kolom;

💡 Tips: Kolom yang digunakan untuk JOIN biasanya adalah Primary Key dan Foreign Key!

🔗 INNER JOIN

📖 Apa itu INNER JOIN?

INNER JOIN menampilkan hanya baris yang memiliki kecocokan di kedua tabel. Seperti mencari teman yang sama-sama suka pizza - hanya yang cocok yang akan muncul! 🍕

🎯 Kapan Menggunakan INNER JOIN?

  • • Ketika hanya ingin data yang ada di kedua tabel
  • • Untuk menghindari data NULL
  • • Saat membutuhkan data yang lengkap dan valid

📝 Sintaks INNER JOIN

🔧 Sintaks Dasar:

SELECT kolom1, kolom2, ...
FROM tabel1
INNER JOIN tabel2 ON tabel1.kolom = tabel2.kolom;

🔧 Sintaks dengan Alias:

SELECT t1.kolom1, t2.kolom2
FROM tabel1 t1
INNER JOIN tabel2 t2 ON t1.id = t2.tabel1_id;

🔧 Multiple INNER JOIN:

SELECT t1.kolom1, t2.kolom2, t3.kolom3
FROM tabel1 t1
INNER JOIN tabel2 t2 ON t1.id = t2.tabel1_id
INNER JOIN tabel3 t3 ON t2.id = t3.tabel2_id;

💡 Tips Sintaks:

  • • Gunakan alias tabel untuk mempermudah penulisan
  • • Kondisi ON harus menggunakan kolom yang berelasi
  • • Bisa menambahkan WHERE untuk filter tambahan

📊 Contoh Praktis

Mari kita lihat contoh dengan tabel siswa dan kelas:

📋 Tabel Siswa

ID Nama Kelas_ID
1 Andi 101
2 Budi 102
3 Citra 103
4 Dina 104

🏫 Tabel Kelas

ID Nama_Kelas Jurusan
101 XII RPL 1 RPL
102 XII TKJ 1 TKJ
103 XII MM 1 MM

🔍 Query INNER JOIN:

SELECT s.nama, k.nama_kelas, k.jurusan
FROM siswa s
INNER JOIN kelas k ON s.kelas_id = k.id;

✨ Hasil Query:

Nama Nama_Kelas Jurusan
Andi XII RPL 1 RPL
Budi XII TKJ 1 TKJ
Citra XII MM 1 MM

📝 Perhatikan: Dina tidak muncul karena kelas_id 104 tidak ada di tabel kelas!

⬅️ LEFT JOIN

📖 Apa itu LEFT JOIN?

LEFT JOIN menampilkan SEMUA baris dari tabel kiri, meskipun tidak ada kecocokan di tabel kanan. Seperti daftar hadir - semua siswa tetap dicatat meskipun ada yang tidak masuk kelas! 📝

🎯 Kapan Menggunakan LEFT JOIN?

  • • Ketika ingin semua data dari tabel utama (kiri)
  • • Untuk melihat data yang tidak memiliki relasi
  • • Saat membuat laporan lengkap

📝 Sintaks LEFT JOIN

🔧 Sintaks Dasar:

SELECT kolom1, kolom2, ...
FROM tabel1
LEFT JOIN tabel2 ON tabel1.kolom = tabel2.kolom;

🔧 Sintaks dengan Alias:

SELECT t1.kolom1, t2.kolom2
FROM tabel1 t1
LEFT JOIN tabel2 t2 ON t1.id = t2.tabel1_id;

🔧 LEFT JOIN dengan Filter NULL:

SELECT t1.kolom1
FROM tabel1 t1
LEFT JOIN tabel2 t2 ON t1.id = t2.tabel1_id
WHERE t2.id IS NULL;

💡 Tips Sintaks:

  • • LEFT JOIN = LEFT OUTER JOIN (sama saja)
  • • Gunakan WHERE IS NULL untuk mencari data tanpa relasi
  • • Tabel kiri akan selalu ditampilkan semua

📊 Contoh Praktis

Menggunakan tabel yang sama, mari lihat perbedaannya:

🔍 Query LEFT JOIN:

SELECT s.nama, k.nama_kelas, k.jurusan
FROM siswa s
LEFT JOIN kelas k ON s.kelas_id = k.id;

✨ Hasil Query:

Nama Nama_Kelas Jurusan
Andi XII RPL 1 RPL
Budi XII TKJ 1 TKJ
Citra XII MM 1 MM
Dina NULL NULL

🎉 Lihat! Sekarang Dina muncul dengan nilai NULL untuk kolom dari tabel kelas!

💡 Contoh Praktis Lainnya

Mencari siswa yang belum memiliki kelas:

SELECT s.nama
FROM siswa s
LEFT JOIN kelas k ON s.kelas_id = k.id
WHERE k.id IS NULL;

🔍 Hasil: Query ini akan menampilkan "Dina" - siswa yang belum memiliki kelas!

➡️ RIGHT JOIN

📖 Apa itu RIGHT JOIN?

RIGHT JOIN adalah kebalikan dari LEFT JOIN. Menampilkan SEMUA baris dari tabel kanan, meskipun tidak ada kecocokan di tabel kiri. Seperti daftar kelas - semua kelas ditampilkan meskipun ada yang kosong! 🏫

🎯 Kapan Menggunakan RIGHT JOIN?

  • • Ketika ingin semua data dari tabel kedua (kanan)
  • • Untuk melihat item yang tidak terpakai
  • • Saat fokus pada tabel referensi

📝 Sintaks RIGHT JOIN

🔧 Sintaks Dasar:

SELECT kolom1, kolom2, ...
FROM tabel1
RIGHT JOIN tabel2 ON tabel1.kolom = tabel2.kolom;

🔧 Sintaks dengan Alias:

SELECT t1.kolom1, t2.kolom2
FROM tabel1 t1
RIGHT JOIN tabel2 t2 ON t1.id = t2.tabel1_id;

🔧 RIGHT JOIN dengan Filter NULL:

SELECT t2.kolom2
FROM tabel1 t1
RIGHT JOIN tabel2 t2 ON t1.id = t2.tabel1_id
WHERE t1.id IS NULL;

💡 Tips Sintaks:

  • • RIGHT JOIN = RIGHT OUTER JOIN (sama saja)
  • • Gunakan WHERE IS NULL untuk mencari data tanpa relasi
  • • Tabel kanan akan selalu ditampilkan semua
  • • Bisa diganti dengan LEFT JOIN dengan menukar posisi tabel

📊 Contoh Praktis

Mari tambahkan kelas kosong untuk melihat perbedaannya:

🏫 Tabel Kelas (Updated)

ID Nama_Kelas Jurusan
101 XII RPL 1 RPL
102 XII TKJ 1 TKJ
103 XII MM 1 MM
105 XII AK 1 AK

🔍 Query RIGHT JOIN:

SELECT s.nama, k.nama_kelas, k.jurusan
FROM siswa s
RIGHT JOIN kelas k ON s.kelas_id = k.id;

✨ Hasil Query:

Nama Nama_Kelas Jurusan
Andi XII RPL 1 RPL
Budi XII TKJ 1 TKJ
Citra XII MM 1 MM
NULL XII AK 1 AK

🎉 Lihat! Kelas XII AK 1 muncul meskipun tidak ada siswa yang terdaftar!

💡 Mencari Kelas Kosong 

SELECT k.nama_kelas, k.jurusan
FROM siswa s
RIGHT JOIN kelas k ON s.kelas_id = k.id
WHERE s.id IS NULL;

🔍 Hasil: Query ini akan menampilkan kelas yang belum memiliki siswa!

🔄 FULL OUTER JOIN

📖 Apa itu FULL OUTER JOIN?

FULL OUTER JOIN menggabungkan LEFT JOIN dan RIGHT JOIN. Menampilkan SEMUA baris dari kedua tabel, baik yang cocok maupun tidak. Seperti gabungan daftar siswa dan daftar kelas - semuanya ditampilkan! 📋✨

🎯 Kapan Menggunakan FULL OUTER JOIN?

  • • Ketika ingin melihat semua data dari kedua tabel
  • • Untuk analisis data yang komprehensif
  • • Saat membuat laporan lengkap dengan semua kemungkinan

📝 Sintaks FULL OUTER JOIN

🔧 Sintaks Dasar (Database yang mendukung):

SELECT kolom1, kolom2, ...
FROM tabel1
FULL OUTER JOIN tabel2 ON tabel1.kolom = tabel2.kolom;

🔧 Sintaks untuk MySQL (menggunakan UNION):

SELECT t1.kolom1, t2.kolom2
FROM tabel1 t1
LEFT JOIN tabel2 t2 ON t1.id = t2.tabel1_id
UNION
SELECT t1.kolom1, t2.kolom2
FROM tabel1 t1
RIGHT JOIN tabel2 t2 ON t1.id = t2.tabel1_id;

🔧 Mencari data yang tidak berelasi:

SELECT t1.kolom1, t2.kolom2
FROM tabel1 t1
FULL OUTER JOIN tabel2 t2 ON t1.id = t2.tabel1_id
WHERE t1.id IS NULL OR t2.tabel1_id IS NULL;

💡 Tips Sintaks:

  • • Tidak semua database mendukung FULL OUTER JOIN
  • • MySQL tidak mendukung, gunakan UNION sebagai alternatif
  • • PostgreSQL, SQL Server, Oracle mendukung
  • • Menggabungkan hasil LEFT JOIN dan RIGHT JOIN

📊 Contoh Praktis

🔍 Query FULL OUTER JOIN:

SELECT s.nama, k.nama_kelas, k.jurusan
FROM siswa s
FULL OUTER JOIN kelas k ON s.kelas_id = k.id;

✨ Hasil Query:

Nama Nama_Kelas Jurusan
Andi XII RPL 1 RPL
Budi XII TKJ 1 TKJ
Citra XII MM 1 MM
Dina NULL NULL
NULL XII AK 1 AK

🎉 Sempurna! Semua data muncul: siswa tanpa kelas (Dina) dan kelas tanpa siswa (XII AK 1)!

⚠️ Catatan Penting

📝 Perhatikan:

  • • Tidak semua database mendukung FULL OUTER JOIN
  • • MySQL tidak mendukung FULL OUTER JOIN secara langsung
  • • Bisa diganti dengan UNION dari LEFT JOIN dan RIGHT JOIN

🔧 Alternatif untuk MySQL:

SELECT s.nama, k.nama_kelas, k.jurusan
FROM siswa s LEFT JOIN kelas k ON s.kelas_id = k.id
UNION
SELECT s.nama, k.nama_kelas, k.jurusan
FROM siswa s RIGHT JOIN kelas k ON s.kelas_id = k.id;

🤝 UNION

📖 Apa itu UNION?

UNION digunakan untuk menggabungkan hasil dari dua atau lebih query SELECT. Seperti menggabungkan dua daftar menjadi satu, tapi duplikat akan dihilangkan! 📝➕📝

🎯 Kapan Menggunakan UNION?

  • • Menggabungkan data dari tabel yang struktur sama
  • • Membuat laporan gabungan
  • • Menggabungkan data historis dengan data terkini

📝 Sintaks UNION

🔧 Sintaks UNION (menghilangkan duplikat):

SELECT kolom1, kolom2, ...
FROM tabel1
WHERE kondisi1
UNION
SELECT kolom1, kolom2, ...
FROM tabel2
WHERE kondisi2;

🔧 Sintaks UNION ALL (mempertahankan duplikat):

SELECT kolom1, kolom2, ...
FROM tabel1
WHERE kondisi1
UNION ALL
SELECT kolom1, kolom2, ...
FROM tabel2
WHERE kondisi2;

🔧 UNION dengan ORDER BY:

SELECT nama, 'Siswa' as kategori FROM siswa
UNION
SELECT nama, 'Guru' as kategori FROM guru
ORDER BY nama;

💡 Tips Sintaks:

  • • Jumlah kolom harus sama di semua SELECT
  • • Tipe data kolom harus kompatibel
  • • ORDER BY hanya di akhir query
  • • UNION ALL lebih cepat dari UNION

📊 Contoh Praktis

Mari buat tabel alumni dan gabungkan dengan siswa aktif:

👨‍🎓 Tabel Alumni

Nama Jurusan Tahun_Lulus
Eko RPL 2023
Fani TKJ 2023
Gita MM 2022

👨‍🎓 Tabel Siswa Aktif

Nama Jurusan Status
Andi RPL Aktif
Budi TKJ Aktif
Citra MM Aktif

🔍 Query UNION:

SELECT nama, jurusan, 'Alumni' as status
FROM alumni
UNION
SELECT nama, jurusan, 'Siswa Aktif' as status
FROM siswa_aktif;

✨ Hasil Query:

Nama Jurusan Status
Eko RPL Alumni
Fani TKJ Alumni
Gita MM Alumni
Andi RPL Siswa Aktif
Budi TKJ Siswa Aktif
Citra MM Siswa Aktif

🔍 UNION vs UNION ALL

🔗 UNION

  • • Menghilangkan duplikat
  • • Lebih lambat (karena cek duplikat)
  • • Hasil unik

🔗 UNION ALL

  • • Mempertahankan duplikat
  • • Lebih cepat
  • • Semua baris ditampilkan

💡 Tips: Gunakan UNION ALL jika yakin tidak ada duplikat untuk performa yang lebih baik!

🏗️ Langkah 2: Membuat Tabel

📋 Tabel Kelas:

CREATE TABLE kelas (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nama_kelas VARCHAR(50) NOT NULL,
    jurusan VARCHAR(20) NOT NULL,
    wali_kelas VARCHAR(50)
);

👨‍🎓 Tabel Siswa:

CREATE TABLE siswa (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nama VARCHAR(50) NOT NULL,
    nis VARCHAR(20) UNIQUE NOT NULL,
    kelas_id INT,
    tanggal_lahir DATE,
    alamat TEXT,
    FOREIGN KEY (kelas_id) REFERENCES kelas(id)
);

📚 Tabel Mata Pelajaran:

CREATE TABLE mata_pelajaran (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nama_mapel VARCHAR(50) NOT NULL,
    kode_mapel VARCHAR(10) UNIQUE NOT NULL,
    sks INT DEFAULT 2
);

📊 Tabel Nilai:

CREATE TABLE nilai (
    id INT PRIMARY KEY AUTO_INCREMENT,
    siswa_id INT,
    mapel_id INT,
    nilai_uts DECIMAL(5,2),
    nilai_uas DECIMAL(5,2),
    nilai_tugas DECIMAL(5,2),
    FOREIGN KEY (siswa_id) REFERENCES siswa(id),
    FOREIGN KEY (mapel_id) REFERENCES mata_pelajaran(id)
);

🔗 Langkah 4: Praktik INNER JOIN

🎯 Menampilkan siswa dengan kelasnya:

SELECT s.nama, s.nis, k.nama_kelas, k.jurusan
FROM siswa s
INNER JOIN kelas k ON s.kelas_id = k.id;

📊 Menampilkan nilai siswa dengan detail:

SELECT s.nama, mp.nama_mapel, n.nilai_uts, n.nilai_uas, n.nilai_tugas
FROM siswa s
INNER JOIN nilai n ON s.id = n.siswa_id
INNER JOIN mata_pelajaran mp ON n.mapel_id = mp.id;

⬅️ Langkah 5: Praktik LEFT JOIN

👥 Menampilkan semua siswa (termasuk yang belum punya kelas):

SELECT s.nama, s.nis, k.nama_kelas, k.jurusan
FROM siswa s
LEFT JOIN kelas k ON s.kelas_id = k.id;

🔍 Mencari siswa yang belum memiliki kelas:

SELECT s.nama, s.nis
FROM siswa s
LEFT JOIN kelas k ON s.kelas_id = k.id
WHERE k.id IS NULL;

➡️ Langkah 6: Praktik RIGHT JOIN

🏫 Menampilkan semua kelas (termasuk yang kosong):

SELECT k.nama_kelas, k.jurusan, s.nama
FROM siswa s
RIGHT JOIN kelas k ON s.kelas_id = k.id;

🔍 Mencari kelas yang belum memiliki siswa:

SELECT k.nama_kelas, k.jurusan
FROM siswa s
RIGHT JOIN kelas k ON s.kelas_id = k.id
WHERE s.id IS NULL;

🔄 Langkah 7: Praktik FULL OUTER JOIN

🌟 Menampilkan semua siswa dan semua kelas:

-- Untuk MySQL (karena tidak mendukung FULL OUTER JOIN langsung)
SELECT s.nama, s.nis, k.nama_kelas, k.jurusan
FROM siswa s
LEFT JOIN kelas k ON s.kelas_id = k.id
UNION
SELECT s.nama, s.nis, k.nama_kelas, k.jurusan
FROM siswa s
RIGHT JOIN kelas k ON s.kelas_id = k.id;

🔍 Untuk database yang mendukung FULL OUTER JOIN:

SELECT s.nama, s.nis, k.nama_kelas, k.jurusan
FROM siswa s
FULL OUTER JOIN kelas k ON s.kelas_id = k.id;

💡 Hasil: Query ini akan menampilkan semua siswa (termasuk yang belum punya kelas) dan semua kelas (termasuk yang kosong)!

🤝 Langkah 8: Praktik UNION

📋 Menggabungkan daftar siswa RPL dan TKJ:

SELECT s.nama, 'RPL' as jurusan
FROM siswa s
INNER JOIN kelas k ON s.kelas_id = k.id
WHERE k.jurusan = 'RPL'
UNION
SELECT s.nama, 'TKJ' as jurusan
FROM siswa s
INNER JOIN kelas k ON s.kelas_id = k.id
WHERE k.jurusan = 'TKJ';

📊 Contoh UNION ALL (dengan duplikat):

SELECT nama, 'Siswa Aktif' as kategori
FROM siswa
WHERE kelas_id IS NOT NULL
UNION ALL
SELECT nama, 'Perlu Penempatan Kelas' as kategori
FROM siswa
WHERE kelas_id IS NULL;
