Pengenalan Database Triggers

🤖 Apa itu Database Trigger?

Database Trigger adalah sebuah program khusus yang berjalan secara otomatis (triggered) ketika terjadi event tertentu dalam database. Seperti alarm yang berbunyi ketika ada yang masuk ke rumah, trigger akan "bereaksi" ketika ada perubahan data.

🎯 Analogi Sederhana:

Trigger seperti penjaga otomatis yang selalu mengawasi database. Ketika ada yang INSERT, UPDATE, atau DELETE data, penjaga ini langsung bertindak sesuai instruksi yang sudah diberikan.

⚡ Karakteristik Trigger

✅ Otomatis

Berjalan sendiri tanpa dipanggil manual

⚡ Cepat

Eksekusi langsung saat event terjadi

🔒 Transparan

User tidak perlu tahu trigger berjalan

🎯 Spesifik

Terikat pada tabel dan event tertentu

🎪 Kapan Trigger Digunakan?

📊 Audit Trail

Mencatat siapa, kapan, dan apa yang diubah dalam database

🔄 Sinkronisasi Data

Update otomatis tabel lain ketika data berubah

✅ Validasi Kompleks

Cek aturan bisnis yang rumit sebelum data disimpan

📈 Kalkulasi Otomatis

Hitung total, rata-rata, atau statistik lainnya

Konsep Dasar Triggers

🏗️ Komponen Utama Trigger

⚡

EVENT

Pemicu yang mengaktifkan trigger

INSERT, UPDATE, DELETE
⏰

TIMING

Kapan trigger dijalankan

BEFORE, AFTER, INSTEAD OF
🎯

ACTION

Aksi yang dilakukan trigger

SQL statements, procedures

🔄 Alur Kerja Trigger

1

User melakukan operasi SQL

INSERT, UPDATE, atau DELETE pada tabel

2

Database mendeteksi event

Sistem mengecek apakah ada trigger untuk event ini

3

Trigger dieksekusi

Kode dalam trigger body dijalankan otomatis

4

Operasi selesai

Operasi SQL asli dilanjutkan atau dibatalkan

Jenis-Jenis Trigger

⏰ Berdasarkan Timing (Waktu Eksekusi)

⏪

BEFORE

Dijalankan SEBELUM operasi SQL dilakukan

Kegunaan:
  • • Validasi data
  • • Modifikasi nilai
  • • Cek constraint
⏩

AFTER

Dijalankan SETELAH operasi SQL berhasil

Kegunaan:
  • • Audit logging
  • • Update tabel lain
  • • Notifikasi
🔄

INSTEAD OF

MENGGANTIKAN operasi SQL asli

Kegunaan:
  • • Update view
  • • Custom logic
  • • Complex operations

⚡ Berdasarkan Event (Pemicu)

➕

INSERT Trigger

Dipicu ketika ada data baru yang ditambahkan ke tabel

Contoh Penggunaan:
  • • Auto-generate ID atau timestamp
  • • Validasi data sebelum insert
  • • Update counter atau statistik
  • • Log aktivitas penambahan data
✏️

UPDATE Trigger

Dipicu ketika ada data yang dimodifikasi dalam tabel

Contoh Penggunaan:
  • • Track perubahan data (audit trail)
  • • Update timestamp last_modified
  • • Sinkronisasi dengan tabel lain
  • • Validasi perubahan data
🗑️

DELETE Trigger

Dipicu ketika ada data yang dihapus dari tabel

Contoh Penggunaan:
  • • Backup data sebelum dihapus
  • • Cascade delete ke tabel terkait
  • • Log aktivitas penghapusan
  • • Prevent delete dengan kondisi tertentu

📊 Berdasarkan Level Eksekusi

📝

ROW-LEVEL

Dieksekusi untuk SETIAP baris yang terpengaruh

Karakteristik:
  • • Akses ke OLD dan NEW values
  • • Lebih detail dan spesifik
  • • Cocok untuk validasi per record
📋

STATEMENT-LEVEL

Dieksekusi SEKALI per statement SQL

Karakteristik:
  • • Lebih efisien untuk bulk operations
  • • Tidak akses individual row data
  • • Cocok untuk logging dan statistik

Sintaks & Struktur Trigger

📝 Sintaks Dasar Trigger 

CREATE TRIGGER nama_trigger
    {BEFORE | AFTER | INSTEAD OF} {INSERT | UPDATE | DELETE}
    ON nama_tabel
    [FOR EACH ROW | FOR EACH STATEMENT]
BEGIN
    -- Kode trigger di sini
    -- Logika yang akan dieksekusi
END;

🏷️ nama_trigger

Nama unik untuk trigger (gunakan nama yang deskriptif)

⏰ TIMING

Kapan trigger dijalankan (BEFORE/AFTER/INSTEAD OF)

⚡ EVENT

Operasi yang memicu trigger (INSERT/UPDATE/DELETE)

📊 LEVEL

Level eksekusi (FOR EACH ROW/STATEMENT)

🎯 Contoh Trigger Sederhana

⏪ BEFORE INSERT Trigger

Trigger untuk auto-generate timestamp sebelum data diinsert:

CREATE TRIGGER tr_before_insert_user
    BEFORE INSERT ON users
    FOR EACH ROW
BEGIN
    -- Set created_at dengan timestamp saat ini
    SET NEW.created_at = NOW();
    
    -- Set default status jika kosong
    IF NEW.status IS NULL THEN
        SET NEW.status = 'active';
    END IF;
END;

⏩ AFTER UPDATE Trigger

Trigger untuk audit trail setelah data diupdate:

CREATE TRIGGER tr_after_update_user
    AFTER UPDATE ON users
    FOR EACH ROW
BEGIN
    -- Insert ke tabel audit
    INSERT INTO user_audit (
        user_id, 
        old_email, 
        new_email, 
        changed_at, 
        changed_by
    ) VALUES (
        NEW.id, 
        OLD.email, 
        NEW.email, 
        NOW(), 
        USER()
    );
END;

🗑️ BEFORE DELETE Trigger

Trigger untuk backup data sebelum dihapus:

CREATE TRIGGER tr_before_delete_user
    BEFORE DELETE ON users
    FOR EACH ROW
BEGIN
    -- Backup ke tabel deleted_users
    INSERT INTO deleted_users (
        original_id, 
        username, 
        email, 
        deleted_at
    ) VALUES (
        OLD.id, 
        OLD.username, 
        OLD.email, 
        NOW()
    );
END;

🔄 Menggunakan OLD dan NEW

📜 OLD Values

Nilai data SEBELUM operasi dilakukan

Tersedia pada:
  • • UPDATE triggers
  • • DELETE triggers
OLD.column_name

✨ NEW Values

Nilai data SETELAH operasi dilakukan

Tersedia pada:
  • • INSERT triggers
  • • UPDATE triggers
NEW.column_name

💡 Contoh Penggunaan OLD dan NEW

CREATE TRIGGER tr_salary_change
    AFTER UPDATE ON employees
    FOR EACH ROW
BEGIN
    -- Cek apakah salary berubah
    IF OLD.salary != NEW.salary THEN
        INSERT INTO salary_history (
            employee_id,
            old_salary,
            new_salary,
            change_date,
            change_amount
        ) VALUES (
            NEW.id,
            OLD.salary,
            NEW.salary,
            NOW(),
            NEW.salary - OLD.salary
        );
    END IF;
END;

Implementasi Trigger

🛒 Studi Kasus: Sistem E-commerce

📦 Auto Update Stock

Ketika ada order baru, stok produk otomatis berkurang:

CREATE TRIGGER tr_update_stock
    AFTER INSERT ON order_items
    FOR EACH ROW
BEGIN
    -- Kurangi stok produk
    UPDATE products 
    SET stock = stock - NEW.quantity
    WHERE id = NEW.product_id;
    
    -- Cek jika stok habis
    IF (SELECT stock FROM products WHERE id = NEW.product_id) <= 0 THEN
        UPDATE products 
        SET status = 'out_of_stock'
        WHERE id = NEW.product_id;
    END IF;
END;
✅ Manfaat:
  • • Stok selalu akurat real-time
  • • Mencegah overselling
  • • Otomatis update status produk

💰 Calculate Order Total

Otomatis hitung total order ketika item ditambah/diubah:

CREATE TRIGGER tr_calculate_order_total
    AFTER INSERT ON order_items
    FOR EACH ROW
BEGIN
    -- Update total order
    UPDATE orders 
    SET total_amount = (
        SELECT SUM(price * quantity) 
        FROM order_items 
        WHERE order_id = NEW.order_id
    )
    WHERE id = NEW.order_id;
END;

📚 Studi Kasus: Sistem Perpustakaan

📖 Auto Due Date

Set tanggal kembali otomatis saat buku dipinjam:

CREATE TRIGGER tr_set_due_date
    BEFORE INSERT ON borrowings
    FOR EACH ROW
BEGIN
    -- Set tanggal pinjam hari ini
    SET NEW.borrow_date = CURDATE();
    
    -- Set tanggal kembali 14 hari dari sekarang
    SET NEW.due_date = DATE_ADD(CURDATE(), INTERVAL 14 DAY);
    
    -- Set status awal
    SET NEW.status = 'borrowed';
END;

📋 Update Book Status

Update status buku ketika dipinjam atau dikembalikan:

CREATE TRIGGER tr_update_book_status
    AFTER INSERT ON borrowings
    FOR EACH ROW
BEGIN
    -- Update status buku menjadi 'borrowed'
    UPDATE books 
    SET status = 'borrowed', 
        available_copies = available_copies - 1
    WHERE id = NEW.book_id;
END;

CREATE TRIGGER tr_return_book
    AFTER UPDATE ON borrowings
    FOR EACH ROW
BEGIN
    -- Jika status berubah menjadi 'returned'
    IF OLD.status = 'borrowed' AND NEW.status = 'returned' THEN
        UPDATE books 
        SET status = 'available', 
            available_copies = available_copies + 1
        WHERE id = NEW.book_id;
    END IF;
END;

⭐ Best Practices

✅ DO (Lakukan)

  • • Gunakan nama trigger yang deskriptif
  • • Tambahkan komentar untuk logika kompleks
  • • Test trigger dengan berbagai skenario
  • • Dokumentasikan tujuan trigger
  • • Gunakan error handling yang baik

❌ DON'T (Jangan)

  • • Jangan buat trigger yang terlalu kompleks
  • • Hindari recursive triggers
  • • Jangan lakukan operasi yang lama
  • • Hindari trigger yang saling bergantung
  • • Jangan abaikan error handling

🏗️ Step 1: Setup Database

📊 Buat Database dan Tabel

Pertama, kita buat database untuk sistem toko online sederhana:

-- Buat database
CREATE DATABASE toko_online;
USE toko_online;

-- Tabel products
CREATE TABLE products (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    price DECIMAL(10,2) NOT NULL,
    stock INT NOT NULL DEFAULT 0,
    status ENUM('available', 'out_of_stock') DEFAULT 'available',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Tabel orders
CREATE TABLE orders (
    id INT PRIMARY KEY AUTO_INCREMENT,
    customer_name VARCHAR(100) NOT NULL,
    total_amount DECIMAL(10,2) DEFAULT 0,
    order_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    status ENUM('pending', 'completed', 'cancelled') DEFAULT 'pending'
);

-- Tabel order_items
CREATE TABLE order_items (
    id INT PRIMARY KEY AUTO_INCREMENT,
    order_id INT,
    product_id INT,
    quantity INT NOT NULL,
    price DECIMAL(10,2) NOT NULL,
    FOREIGN KEY (order_id) REFERENCES orders(id),
    FOREIGN KEY (product_id) REFERENCES products(id)
);

-- Tabel audit_log
CREATE TABLE audit_log (
    id INT PRIMARY KEY AUTO_INCREMENT,
    table_name VARCHAR(50),
    operation VARCHAR(10),
    old_values JSON,
    new_values JSON,
    changed_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    changed_by VARCHAR(100)
);
📝 Penjelasan Struktur:
  • • products: Menyimpan data produk dan stok
  • • orders: Menyimpan data pesanan
  • • order_items: Detail item dalam pesanan
  • • audit_log: Log untuk tracking perubahan

⚡ Step 3: Buat Trigger Auto Update Stock

📉 Trigger Kurangi Stok

Ketika ada item baru di order, stok produk otomatis berkurang:

DELIMITER //

CREATE TRIGGER tr_update_stock_after_order
    AFTER INSERT ON order_items
    FOR EACH ROW
BEGIN
    -- Kurangi stok produk
    UPDATE products 
    SET stock = stock - NEW.quantity
    WHERE id = NEW.product_id;
    
    -- Update status jika stok habis
    UPDATE products 
    SET status = CASE 
        WHEN stock <= 0 THEN 'out_of_stock'
        ELSE 'available'
    END
    WHERE id = NEW.product_id;
    
    -- Log ke audit
    INSERT INTO audit_log (table_name, operation, new_values, changed_by)
    VALUES ('products', 'STOCK_UPDATE', 
            JSON_OBJECT('product_id', NEW.product_id, 'quantity_sold', NEW.quantity),
            USER());
END//

DELIMITER ;

💰 Step 4: Trigger Hitung Total Order

🧮 Auto Calculate Total

Otomatis hitung total order setiap kali ada item baru:

DELIMITER //

CREATE TRIGGER tr_calculate_order_total
    AFTER INSERT ON order_items
    FOR EACH ROW
BEGIN
    -- Hitung total order
    UPDATE orders 
    SET total_amount = (
        SELECT COALESCE(SUM(quantity * price), 0)
        FROM order_items 
        WHERE order_id = NEW.order_id
    )
    WHERE id = NEW.order_id;
END//

-- Trigger untuk UPDATE order_items
CREATE TRIGGER tr_recalculate_on_update
    AFTER UPDATE ON order_items
    FOR EACH ROW
BEGIN
    UPDATE orders 
    SET total_amount = (
        SELECT COALESCE(SUM(quantity * price), 0)
        FROM order_items 
        WHERE order_id = NEW.order_id
    )
    WHERE id = NEW.order_id;
END//

-- Trigger untuk DELETE order_items
CREATE TRIGGER tr_recalculate_on_delete
    AFTER DELETE ON order_items
    FOR EACH ROW
BEGIN
    UPDATE orders 
    SET total_amount = (
        SELECT COALESCE(SUM(quantity * price), 0)
        FROM order_items 
        WHERE order_id = OLD.order_id
    )
    WHERE id = OLD.order_id;
END//

DELIMITER ;

📋 Step 5: Trigger Audit Trail

🔍 Track Semua Perubahan

Catat semua perubahan pada tabel products:

DELIMITER //

-- Audit untuk INSERT
CREATE TRIGGER tr_audit_products_insert
    AFTER INSERT ON products
    FOR EACH ROW
BEGIN
    INSERT INTO audit_log (table_name, operation, new_values, changed_by)
    VALUES ('products', 'INSERT', 
            JSON_OBJECT('id', NEW.id, 'name', NEW.name, 'price', NEW.price, 'stock', NEW.stock),
            USER());
END//

-- Audit untuk UPDATE
CREATE TRIGGER tr_audit_products_update
    AFTER UPDATE ON products
    FOR EACH ROW
BEGIN
    INSERT INTO audit_log (table_name, operation, old_values, new_values, changed_by)
    VALUES ('products', 'UPDATE',
            JSON_OBJECT('id', OLD.id, 'name', OLD.name, 'price', OLD.price, 'stock', OLD.stock, 'status', OLD.status),
            JSON_OBJECT('id', NEW.id, 'name', NEW.name, 'price', NEW.price, 'stock', NEW.stock, 'status', NEW.status),
            USER());
END//

-- Audit untuk DELETE
CREATE TRIGGER tr_audit_products_delete
    BEFORE DELETE ON products
    FOR EACH ROW
BEGIN
    INSERT INTO audit_log (table_name, operation, old_values, changed_by)
    VALUES ('products', 'DELETE',
            JSON_OBJECT('id', OLD.id, 'name', OLD.name, 'price', OLD.price, 'stock', OLD.stock),
            USER());
END//

DELIMITER ;
