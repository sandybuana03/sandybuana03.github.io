Pengenalan Sub Query SQL

🔍 Apa itu Sub Query?

Sub Query (atau Subquery) adalah query SQL yang berada di dalam query SQL lainnya. Sub query juga dikenal sebagai nested query atau inner query.

💡 Analogi Sederhana:

Bayangkan kamu ingin mencari "siswa terpintar di kelas". Pertama kamu harus tahu "nilai tertinggi di kelas", baru kemudian mencari "siapa yang mendapat nilai tertinggi tersebut". Itulah konsep sub query!

🏗️ Struktur Dasar Sub Query

SELECT kolom1, kolom2 FROM tabel1 WHERE kolom3 = ( SELECT kolom4 FROM tabel2 WHERE kondisi );

🔵 Outer Query (Query Luar)

Query utama yang menggunakan hasil dari sub query

🟢 Inner Query (Query Dalam)

Sub query yang dieksekusi terlebih dahulu

📊 Contoh Sederhana

Mari lihat contoh dengan tabel siswa:

ID Nama Nilai Kelas
1 Andi 85 XII RPL
2 Budi 92 XII RPL
3 Citra 78 XII RPL
4 Dina 88 XII TKJ

Pertanyaan: Siapa siswa yang mendapat nilai di atas rata-rata?

SELECT nama, nilai FROM siswa WHERE nilai > ( SELECT AVG(nilai) FROM siswa );

📋 Hasil Query:

Nama Nilai
Budi 92
Dina 88

Rata-rata nilai: (85+92+78+88)/4 = 85.75

Jenis-Jenis Sub Query

📊

Scalar Sub Query

Mengembalikan satu nilai tunggal

📋

Multiple Row

Mengembalikan beberapa baris data

🔗

Correlated

Bergantung pada query luar

📍 Berdasarkan Posisi

🎯 Sub Query di WHERE

Digunakan untuk filtering data

SELECT * FROM siswa WHERE nilai > (SELECT AVG(nilai) FROM siswa);

📝 Sub Query di SELECT

Digunakan untuk menambah kolom

SELECT nama, nilai, (SELECT AVG(nilai) FROM siswa) as rata_rata FROM siswa;

📊 Sub Query di FROM

Digunakan sebagai tabel virtual

SELECT * FROM ( SELECT nama, nilai FROM siswa WHERE nilai > 80 ) AS siswa_pintar;

🔄 Sub Query di HAVING

Digunakan untuk filtering grup

SELECT kelas, AVG(nilai) FROM siswa GROUP BY kelas HAVING AVG(nilai) > (SELECT AVG(nilai) FROM siswa);
📊

Scalar Sub Query

🎯 Pengertian

Scalar Sub Query adalah sub query yang mengembalikan tepat satu nilai (satu baris, satu kolom). Biasanya menggunakan fungsi agregat seperti COUNT, MAX, MIN, AVG, SUM.

💡 Karakteristik:

  • Mengembalikan satu nilai saja
  • Dapat digunakan di mana saja nilai tunggal diperlukan
  • Sering menggunakan operator perbandingan (=, >, <, >=, <=)

📋 Contoh dengan Tabel Produk

ID Nama Produk Harga Kategori
1 Laptop Gaming 15000000 Elektronik
2 Mouse Wireless 250000 Elektronik
3 Meja Kantor 1200000 Furniture
4 Kursi Gaming 2500000 Furniture

🔍 Contoh 1: Produk dengan Harga Tertinggi

SELECT nama_produk, harga FROM produk WHERE harga = ( SELECT MAX(harga) FROM produk );

📋 Hasil:

Nama Produk Harga
Laptop Gaming 15000000

🔍 Contoh 2: Produk dengan Harga di Atas Rata-rata

SELECT nama_produk, harga, (SELECT AVG(harga) FROM produk) as rata_rata_harga FROM produk WHERE harga > ( SELECT AVG(harga) FROM produk );

📋 Hasil:

Nama Produk Harga Rata-rata Harga
Laptop Gaming 15000000 4737500

Rata-rata: (15000000+250000+1200000+2500000)/4 = 4737500

📋

Multiple Row Sub Query

🎯 Pengertian

Multiple Row Sub Query adalah sub query yang mengembalikan lebih dari satu baris data. Karena mengembalikan banyak nilai, tidak bisa menggunakan operator perbandingan biasa (=, >, <).

⚠️ Operator Khusus yang Digunakan:

  • IN - nilai ada dalam daftar hasil sub query
  • NOT IN - nilai tidak ada dalam daftar hasil sub query
  • ANY/SOME - memenuhi kondisi dengan salah satu nilai
  • ALL - memenuhi kondisi dengan semua nilai

📊 Contoh dengan Tabel Karyawan dan Departemen

Tabel Karyawan

ID Nama Gaji Dept_ID
1 Andi 8000000 1
2 Budi 12000000 2
3 Citra 9000000 1
4 Dina 7000000 3

Tabel Departemen

ID Nama Dept Lokasi
1 IT Jakarta
2 Marketing Bandung
3 Finance Surabaya

🔍 Contoh 1: Menggunakan IN

Cari karyawan yang bekerja di departemen yang berlokasi di Jakarta atau Bandung:

SELECT nama, gaji FROM karyawan WHERE dept_id IN ( SELECT id FROM departemen WHERE lokasi IN ('Jakarta', 'Bandung') );

📋 Hasil:

Nama Gaji
Andi 8000000
Budi 12000000
Citra 9000000

🔍 Contoh 2: Menggunakan ANY

Cari karyawan yang gajinya lebih besar dari gaji karyawan manapun di departemen Finance:

SELECT nama, gaji FROM karyawan WHERE gaji > ANY ( SELECT gaji FROM karyawan WHERE dept_id = ( SELECT id FROM departemen WHERE nama_dept = 'Finance' ) );

📋 Hasil:

Nama Gaji
Andi 8000000
Budi 12000000
Citra 9000000

Gaji di Finance: 7000000. Semua yang > 7000000 akan muncul.

Correlated Sub Query

🎯 Pengertian

Correlated Sub Query adalah sub query yang bergantung pada nilai dari query luar. Sub query ini dieksekusi berulang kali untuk setiap baris dari query luar.

🔄 Karakteristik:

  • Sub query menggunakan kolom dari tabel query luar
  • Dieksekusi berulang untuk setiap baris outer query
  • Tidak bisa dijalankan secara terpisah
  • Biasanya lebih lambat dari non-correlated sub query

❌ Non-Correlated

Sub query independen, dieksekusi sekali

SELECT * FROM siswa WHERE nilai > ( SELECT AVG(nilai) FROM siswa );

✅ Correlated

Sub query bergantung outer query

SELECT * FROM siswa s1 WHERE nilai > ( SELECT AVG(nilai) FROM siswa s2 WHERE s2.kelas = s1.kelas );

📊 Contoh dengan Tabel Penjualan

ID Salesperson Jumlah Bulan Tahun
1 Andi 5000000 1 2024
2 Budi 7000000 1 2024
3 Andi 6000000 2 2024
4 Citra 4000000 1 2024
5 Budi 8000000 2 2024

🔍 Contoh 1: Penjualan di Atas Rata-rata per Salesperson

Cari transaksi yang nilainya di atas rata-rata penjualan masing-masing salesperson:

SELECT salesperson, jumlah, bulan FROM penjualan p1 WHERE jumlah > ( SELECT AVG(jumlah) FROM penjualan p2 WHERE p2.salesperson = p1.salesperson );

📋 Hasil:

Salesperson Jumlah Bulan
Andi 6000000 2
Budi 8000000 2

Rata-rata Andi: (5000000+6000000)/2 = 5500000
Rata-rata Budi: (7000000+8000000)/2 = 7500000
Rata-rata Citra: 4000000

🔍 Contoh 2: Menggunakan EXISTS

Cari salesperson yang pernah melakukan penjualan di atas 6 juta:

SELECT DISTINCT salesperson FROM penjualan p1 WHERE EXISTS ( SELECT 1 FROM penjualan p2 WHERE p2.salesperson = p1.salesperson AND p2.jumlah > 6000000 );

📋 Hasil:

Salesperson
Budi
Andi

Praktik Sub Query SQL

🏗️ Langkah 1: Membuat Database dan Tabel

1.1 Membuat Database

CREATE DATABASE sekolah_db;
USE sekolah_db;

1.2 Membuat Tabel Siswa

CREATE TABLE siswa ( id INT PRIMARY KEY AUTO_INCREMENT, nama VARCHAR(50) NOT NULL, nilai INT NOT NULL, kelas VARCHAR(10) NOT NULL, umur INT NOT NULL );

1.3 Membuat Tabel Mata Pelajaran

CREATE TABLE mata_pelajaran ( id INT PRIMARY KEY AUTO_INCREMENT, nama_mapel VARCHAR(50) NOT NULL, guru VARCHAR(50) NOT NULL, sks INT NOT NULL );

1.4 Membuat Tabel Nilai

CREATE TABLE nilai ( id INT PRIMARY KEY AUTO_INCREMENT, siswa_id INT, mapel_id INT, nilai INT NOT NULL, semester VARCHAR(10), FOREIGN KEY (siswa_id) REFERENCES siswa(id), FOREIGN KEY (mapel_id) REFERENCES mata_pelajaran(id) );

🔍 Langkah 3: Praktik Scalar Sub Query

3.1 Siswa dengan Nilai Tertinggi

SELECT nama, nilai FROM siswa WHERE nilai = (SELECT MAX(nilai) FROM siswa);

Coba jalankan query ini untuk melihat siapa siswa dengan nilai tertinggi!

3.2 Siswa dengan Nilai di Atas Rata-rata

SELECT nama, nilai, kelas, (SELECT AVG(nilai) FROM siswa) as rata_rata FROM siswa WHERE nilai > (SELECT AVG(nilai) FROM siswa) ORDER BY nilai DESC;

Query ini menampilkan siswa yang nilainya di atas rata-rata beserta nilai rata-ratanya.

3.3 Jumlah Siswa per Kelas vs Total Siswa

SELECT kelas, COUNT(*) as jumlah_siswa, (SELECT COUNT(*) FROM siswa) as total_siswa, ROUND(COUNT(*) * 100.0 / (SELECT COUNT(*) FROM siswa), 2) as persentase FROM siswa GROUP BY kelas;

Melihat distribusi siswa per kelas dengan persentase.

📋 Langkah 4: Praktik Multiple Row Sub Query

4.1 Siswa dari Kelas Tertentu (IN)

SELECT nama, kelas, nilai FROM siswa WHERE kelas IN ( SELECT kelas FROM siswa GROUP BY kelas HAVING AVG(nilai) > 85 );

Menampilkan siswa dari kelas yang rata-rata nilainya > 85.

4.2 Siswa yang Mengambil Mata Pelajaran Tertentu

SELECT s.nama, s.kelas FROM siswa s WHERE s.id IN ( SELECT n.siswa_id FROM nilai n JOIN mata_pelajaran mp ON n.mapel_id = mp.id WHERE mp.nama_mapel IN ('Pemrograman Web', 'Database') );

Mencari siswa yang mengambil mata pelajaran Pemrograman Web atau Database.

4.3 Menggunakan ANY dan ALL

-- Siswa yang nilainya lebih tinggi dari nilai terendah di kelas XII RPL SELECT nama, nilai, kelas FROM siswa WHERE nilai > ANY ( SELECT nilai FROM siswa WHERE kelas = 'XII RPL' ) AND kelas != 'XII RPL'; -- Siswa yang nilainya lebih tinggi dari semua siswa di kelas XII TKJ SELECT nama, nilai, kelas FROM siswa WHERE nilai > ALL ( SELECT nilai FROM siswa WHERE kelas = 'XII TKJ' );

Contoh penggunaan ANY dan ALL dalam sub query.

🔗 Langkah 5: Praktik Correlated Sub Query

5.1 Siswa Terbaik per Kelas

SELECT nama, nilai, kelas FROM siswa s1 WHERE nilai = ( SELECT MAX(nilai) FROM siswa s2 WHERE s2.kelas = s1.kelas ) ORDER BY kelas;

Menampilkan siswa dengan nilai tertinggi di setiap kelas.

5.2 Siswa di Atas Rata-rata Kelasnya

SELECT nama, nilai, kelas, (SELECT AVG(nilai) FROM siswa s2 WHERE s2.kelas = s1.kelas) as rata_rata_kelas FROM siswa s1 WHERE nilai > ( SELECT AVG(nilai) FROM siswa s2 WHERE s2.kelas = s1.kelas ) ORDER BY kelas, nilai DESC;

Siswa yang nilainya di atas rata-rata kelas masing-masing.

5.3 Menggunakan EXISTS

-- Siswa yang pernah mendapat nilai di atas 90 SELECT nama, kelas FROM siswa s WHERE EXISTS ( SELECT 1 FROM nilai n WHERE n.siswa_id = s.id AND n.nilai > 90 ); -- Mata pelajaran yang tidak diambil siswa kelas XII MM SELECT nama_mapel, guru FROM mata_pelajaran mp WHERE NOT EXISTS ( SELECT 1 FROM nilai n JOIN siswa s ON n.siswa_id = s.id WHERE n.mapel_id = mp.id AND s.kelas = 'XII MM' );

Contoh penggunaan EXISTS dan NOT EXISTS.
