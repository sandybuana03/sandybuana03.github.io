🏗️ Apa itu Entity Relationship Diagram (ERD)?

Entity Relationship Diagram (ERD) adalah diagram yang menunjukkan hubungan antara entitas-entitas dalam sebuah database. ERD membantu kita memvisualisasikan struktur data sebelum membuat database yang sesungguhnya.

Analogi: ERD seperti denah rumah sebelum dibangun. Denah menunjukkan di mana letak kamar, dapur, dan bagaimana mereka terhubung. Begitu juga ERD menunjukkan entitas dan bagaimana mereka saling berhubungan! 🏠

🧩 Komponen Utama ERD

📦 1. Entity (Entitas)

Entity adalah objek atau "benda" yang datanya ingin kita simpan dalam database.

Contoh Entity:
  • 👨‍🎓 Siswa
  • 👩‍🏫 Guru
  • 📚 Mata Pelajaran
  • 🏫 Kelas
  • 📝 Nilai
Simbol Entity:
SISWA

Persegi panjang

🏷️ 2. Attribute (Atribut)

Attribute adalah karakteristik atau sifat dari sebuah entity. Ini adalah data yang ingin kita simpan tentang entity tersebut.

Contoh Attribute untuk Entity SISWA:
  • 🆔 NIS (Primary Key)
  • 👤 Nama
  • 📅 Tanggal Lahir
  • 📍 Alamat
  • 📱 No. Telepon
Simbol Attribute:
Nama

Oval/Elips

Primary Key: Attribute yang unik untuk setiap record, seperti NIS untuk siswa. Digambar dengan oval yang digarisbawahi atau diberi tanda khusus! 🔑

Foreign Key: Attribute yang merujuk ke Primary Key di entity lain untuk membuat hubungan. Misalnya ID_Kelas di entity SISWA yang merujuk ke Primary Key di entity KELAS! 🔗

🔗 3. Relationship (Hubungan)

Relationship menunjukkan bagaimana entity-entity saling berhubungan satu sama lain.

Contoh Relationship:
  • 👨‍🎓 Siswa mengambil 📚 Mata Pelajaran
  • 👩‍🏫 Guru mengajar 📚 Mata Pelajaran
  • 👨‍🎓 Siswa berada di 🏫 Kelas
Simbol Relationship:
mengambil

Belah ketupat

🔢 Jenis-Jenis Hubungan (Cardinality)

1️⃣ One-to-One (1:1)

Satu entity berhubungan dengan tepat satu entity lainnya.

Contoh:

👨‍🎓 Satu Siswa memiliki satu Kartu Pelajar 🆔

🆔 Satu Kartu Pelajar dimiliki oleh satu Siswa 👨‍🎓

2️⃣ One-to-Many (1:M)

Satu entity berhubungan dengan banyak entity lainnya.

Contoh:

🏫 Satu Kelas memiliki banyak Siswa 👨‍🎓👩‍🎓👨‍🎓

👩‍🏫 Satu Guru mengajar banyak Siswa 👨‍🎓👩‍🎓👨‍🎓

3️⃣ Many-to-Many (M:N)

Banyak entity berhubungan dengan banyak entity lainnya.

Contoh:

👨‍🎓👩‍🎓 Banyak Siswa mengambil banyak Mata Pelajaran 📚📖📝

📚📖 Banyak Mata Pelajaran diambil oleh banyak Siswa 👨‍🎓👩‍🎓

📝 Langkah-Langkah Membuat ERD

1

Identifikasi Entity

Tentukan objek-objek apa saja yang datanya ingin disimpan

2

Tentukan Attribute

Untuk setiap entity, tentukan data apa saja yang ingin disimpan

3

Identifikasi Primary Key

Tentukan attribute yang unik untuk setiap entity

4

Tentukan Relationship

Identifikasi bagaimana entity-entity saling berhubungan

5

Gambar ERD

Buat diagram dengan simbol-simbol yang benar

💡 Contoh Kasus: Sistem Perpustakaan

Mari kita buat ERD untuk sistem perpustakaan sekolah! 📚

🏷️ Entity yang diidentifikasi:

  • 📚 BUKU
  • 👨‍🎓 ANGGOTA
  • 📋 PEMINJAMAN

🔗 Relationship:

  • 👨‍🎓 ANGGOTA meminjam 📚 BUKU
  • Hubungan: Many-to-Many (M:N)
  • Melalui entity PEMINJAMAN

📝 Attribute untuk setiap Entity:

BUKU:
  • 🆔 ID_Buku (PK)
  • 📖 Judul
  • ✍️ Pengarang
  • 🏢 Penerbit
  • 📅 Tahun_Terbit
ANGGOTA:
  • 🆔 ID_Anggota (PK)
  • 👤 Nama
  • 🏫 Kelas
  • 📍 Alamat
  • 📱 No_Telepon
PEMINJAMAN:
  • 🆔 ID_Peminjaman (PK)
  • 📅 Tanggal_Pinjam
  • 📅 Tanggal_Kembali
  • 💰 Denda

🎨 Visualisasi ERD Sistem Perpustakaan

📖 Penjelasan ERD:
  • • Entity ANGGOTA: Menyimpan data anggota perpustakaan dengan ID_Anggota sebagai primary key
  • • Entity BUKU: Menyimpan data buku dengan ID_Buku sebagai primary key
  • • Entity PEMINJAMAN: Entity penghubung untuk relationship Many-to-Many antara ANGGOTA dan BUKU
  • • Relationship: Satu anggota bisa meminjam banyak buku, dan satu buku bisa dipinjam oleh banyak anggota (dalam waktu berbeda)
  • • Cardinality M:N: Diselesaikan dengan entity PEMINJAMAN yang memiliki foreign key dari kedua entity

Praktik 1: ERDPlus

Mari buat ERD menggunakan tools online ERDPlus!

🌐 Mengenal ERDPlus

ERDPlus adalah tools online gratis untuk membuat Entity Relationship Diagram. Tools ini sangat mudah digunakan dan cocok untuk pemula! 🎯

Website: https://erdplus.com

📋 Langkah-Langkah Praktik

1

Akses ERDPlus

• Buka browser di HP kamu

• Ketik: erdplus.com

• Klik "ER Diagram" untuk mulai membuat ERD

💡 Tips: ERDPlus bisa digunakan tanpa registrasi, tapi lebih baik buat akun untuk menyimpan hasil kerja!

2

Mengenal Interface ERDPlus

• Toolbar kiri: Berisi tools untuk menggambar (Entity, Attribute, Relationship)

• Canvas tengah: Area untuk menggambar ERD

• Panel kanan: Properties untuk mengatur objek yang dipilih

📱 Untuk HP: Interface akan menyesuaikan ukuran layar. Gunakan zoom untuk detail yang lebih baik!

3

Membuat Entity Pertama

• Klik icon "Entity" (kotak) di toolbar kiri

• Klik di canvas untuk menempatkan entity

• Double-click entity untuk memberi nama, misalnya: "SISWA"

• Ulangi untuk entity lain: "MATA_PELAJARAN", "NILAI"

4

Menambahkan Attribute

• Klik icon "Attribute" (oval) di toolbar kiri

• Klik di dekat entity untuk menempatkan attribute

• Drag dari attribute ke entity untuk menghubungkan

• Double-click attribute untuk memberi nama

🔑 Primary Key: Klik kanan attribute → pilih "Key" untuk menandai sebagai primary key!

5

Membuat Relationship

• Klik icon "Relationship" (belah ketupat) di toolbar kiri

• Tempatkan relationship di antara entity yang berhubungan

• Drag dari entity ke relationship untuk menghubungkan

• Double-click relationship untuk memberi nama

6

Mengatur Cardinality

• Klik garis penghubung antara entity dan relationship

• Di panel kanan, atur "Cardinality"

• Pilih: 1 (One), N (Many), atau M (Many)

• Atur juga "Participation": Total atau Partial

🎯 Tugas Praktik

Sekarang saatnya kamu praktik! Buat ERD untuk Sistem Akademik Sekolah dengan spesifikasi berikut:

📋 Entity yang harus dibuat:

  • 👨‍🎓 SISWA
  • 📚 MATA_PELAJARAN
  • 📝 NILAI

✨ Lebih Sederhana: Hanya 3 entity untuk fokus pada konsep dasar!

🔗 Relationship yang harus dibuat:

  • SISWA mengambil MATA_PELAJARAN (M:N)
  • Diselesaikan dengan entity NILAI

🎯 Fokus: Memahami hubungan Many-to-Many dengan entity penghubung!

📝 Attribute minimum untuk setiap Entity:

SISWA:
  • 🆔 NIS (PK)
  • 👤 Nama_Siswa
  • 🏫 Kelas
  • 📅 Tanggal_Lahir
MATA_PELAJARAN:
  • 🆔 Kode_Mapel (PK)
  • 📖 Nama_Mapel
  • 👩‍🏫 Guru_Pengampu
  • 🕐 SKS
NILAI (Entity Penghubung):
  • 🆔 ID_Nilai (PK)
  • 📊 Nilai_Angka
  • 🔤 Nilai_Huruf
  • 📅 Tanggal_Input
  • 🔗 NIS_Siswa (FK)
  • 🔗 Kode_Mapel (FK)
🔗 Penjelasan Foreign Key (FK) dan Entity Penghubung:
  • • Entity NILAI sebagai penghubung: Menyelesaikan hubungan M:N antara SISWA dan MATA_PELAJARAN
  • • NIS_Siswa (FK) di NILAI: Menghubungkan nilai dengan siswa yang bersangkutan
  • • Kode_Mapel (FK) di NILAI: Menghubungkan nilai dengan mata pelajaran yang diambil
  • • Kombinasi kedua FK: Membuat hubungan unik antara siswa dan mata pelajaran
💡 Mengapa Perlu Entity NILAI?

Hubungan M:N antara SISWA dan MATA_PELAJARAN tidak bisa langsung dihubungkan karena:

  • • Satu siswa bisa mengambil banyak mata pelajaran
  • • Satu mata pelajaran bisa diambil banyak siswa
  • • Kita perlu menyimpan data tambahan seperti nilai dan tanggal input
  • • Entity NILAI menjadi "jembatan" yang menghubungkan keduanya

🎯 Target: Selesaikan ERD dalam 20 menit! Dengan hanya 3 entity, ini akan lebih mudah dan fokus. Jangan lupa save hasil kerja kamu di ERDPlus.

💡 Tips dan Trik ERDPlus

⚡ Shortcut Berguna:

  • • Ctrl + Z: Undo
  • • Ctrl + Y: Redo
  • • Delete: Hapus objek terpilih
  • • Ctrl + S: Save diagram

🎨 Tips Desain:

  • • Atur layout yang rapi dan mudah dibaca
  • • Gunakan warna berbeda untuk entity
  • • Beri jarak yang cukup antar objek
  • • Pastikan garis tidak saling bersilangan

Praktik 2: Draw.io

Belajar membuat ERD dengan Draw.io yang lebih fleksibel!

🎨 Mengenal Draw.io (Diagrams.net)

Draw.io (sekarang bernama Diagrams.net) adalah tools diagram online yang sangat powerful dan gratis! Berbeda dengan ERDPlus, Draw.io lebih fleksibel dan bisa digunakan untuk berbagai jenis diagram. 🎯

✨ Kelebihan Draw.io:

  • • Lebih banyak pilihan shape dan style
  • • Bisa export ke berbagai format
  • • Integrasi dengan Google Drive
  • • Template ERD yang beragam
  • • Gratis dan open source

Website: https://app.diagrams.net

Alternatif: https://draw.io

📋 Langkah-Langkah Praktik dengan Draw.io

1

Akses Draw.io

• Buka browser dan ketik: app.diagrams.net

• Pilih "Create New Diagram"

• Pilih template "Entity Relation" atau "Blank Diagram"

• Beri nama file, misalnya: "ERD_Sekolah"

💡 Tips: Pilih "Save to Device" untuk menyimpan di HP kamu, atau "Google Drive" jika punya akun Google!

2

Mengenal Interface Draw.io

• Panel kiri: Shape library (Entity Relation, General, dll)

• Canvas tengah: Area kerja untuk menggambar

• Panel kanan: Format dan style properties

• Toolbar atas: File operations dan tools

📱 Untuk HP: Gunakan zoom dan pan untuk navigasi yang lebih mudah. Pinch to zoom works!

3

Menggunakan Entity Relation Shapes

• Di panel kiri, cari "Entity Relation" di shape library

• Drag "Entity" (kotak) ke canvas untuk membuat entity

• Drag "Relationship" (diamond) untuk hubungan

• Gunakan "Attribute" (oval) untuk atribut

🎨 Styling: Klik kanan shape → Format untuk mengubah warna, border, dan font!

4

Menghubungkan Shapes

• Hover di tepi shape sampai muncul panah biru

• Drag dari panah biru ke shape tujuan

• Atau gunakan "Connector" tool di toolbar

• Double-click connector untuk menambah label

5

Formatting dan Styling

• Pilih shape → Panel kanan untuk mengatur style

• Ubah warna fill, border, dan text

• Atur font size dan style untuk readability

• Gunakan "Arrange" untuk layering

6

Export dan Save

• File → Export as untuk export ke PNG, PDF, SVG

• File → Save untuk menyimpan project

• Pilih kualitas export sesuai kebutuhan

• Download hasil ke device kamu

🎯 Tugas Praktik 2: Sistem Toko Buku Sederhana

Sekarang buat ERD sederhana untuk Sistem Toko Buku menggunakan Draw.io! Ini lebih mudah dari sistem perpustakaan yang sudah kita pelajari. 📚

📚 Entity yang harus dibuat:

  • 👤 PELANGGAN
  • 📖 BUKU
  • 🛒 PEMBELIAN

💡 Tips: Hanya 3 entity saja! Lebih sederhana dari sistem perpustakaan.

🔗 Relationship yang harus dibuat:

  • PELANGGAN melakukan PEMBELIAN (1:M)
  • BUKU dibeli_dalam PEMBELIAN (M:N)

📝 Catatan: Satu pelanggan bisa beli berkali-kali, satu pembelian bisa banyak buku!

📝 Attribute minimum untuk setiap Entity:

PELANGGAN:
  • 🆔 ID_Pelanggan (PK)
  • 👤 Nama
  • 📧 Email
  • 📱 No_HP
BUKU:
  • 🆔 ID_Buku (PK)
  • 📖 Judul
  • ✍️ Pengarang
  • 💰 Harga
  • 📊 Stok
PEMBELIAN:
  • 🆔 ID_Pembelian (PK)
  • 📅 Tanggal_Beli
  • 🔢 Jumlah_Buku
  • 💰 Total_Harga
  • 🔗 ID_Pelanggan (FK)
  • 🔗 ID_Buku (FK)
🎨 Tugas Styling (Opsional):
  • • Beri warna berbeda untuk setiap entity
  • • Atur layout yang rapi
  • • Pastikan text mudah dibaca
  • • Gunakan garis yang jelas
📤 Yang Harus Diselesaikan:
  • • Buat 3 entity dengan attributnya
  • • Hubungkan dengan relationship yang benar
  • • Tandai Primary Key (PK) dan Foreign Key (FK)
  • • Save hasil kerja di Draw.io

🎯 Target: Selesaikan ERD Toko Buku dalam 20 menit! Fokus pada pemahaman konsep, styling bisa dikerjakan nanti. Semangat! 💪

🤔 Bantuan Pemikiran:
  • • Siapa yang membeli? → PELANGGAN
  • • Apa yang dibeli? → BUKU
  • • Kapan dan berapa banyak? → PEMBELIAN (sebagai penghubung)
  • • Hubungan: Pelanggan bisa beli berkali-kali, setiap pembelian bisa banyak buku

⚖️ Perbandingan ERDPlus vs Draw.io

🟢 ERDPlus

Kelebihan:
  • • Khusus untuk ERD
  • • Mudah untuk pemula
  • • Auto-validation
  • • Generate SQL
Kekurangan:
  • • Terbatas styling
  • • Tidak bisa diagram lain
  • • Export options terbatas

🔵 Draw.io

Kelebihan:
  • • Sangat fleksibel
  • • Banyak template
  • • Export ke banyak format
  • • Gratis dan powerful
Kekurangan:
  • • Learning curve lebih tinggi
  • • Tidak ada auto-validation
  • • Bisa overwhelming
💡 Rekomendasi Penggunaan:

Gunakan ERDPlus jika:

  • • Baru belajar ERD
  • • Butuh validasi otomatis
  • • Fokus pada accuracy

Gunakan Draw.io jika:

  • • Butuh design yang menarik
  • • Perlu export ke berbagai format
  • • Ingin fleksibilitas tinggi

🚀 Tips Advanced Draw.io

⌨️ Keyboard Shortcuts:

  • • Ctrl + D: Duplicate shape
  • • Ctrl + G: Group shapes
  • • Ctrl + Shift + G: Ungroup
  • • Ctrl + A: Select all
  • • Delete: Remove selected
  • • F2: Edit text

🎨 Pro Design Tips:

  • • Gunakan grid untuk alignment
  • • Konsisten dengan color scheme
  • • Beri spacing yang cukup
  • • Gunakan layers untuk organization
  • • Save template untuk reuse
  • • Test readability di zoom out
