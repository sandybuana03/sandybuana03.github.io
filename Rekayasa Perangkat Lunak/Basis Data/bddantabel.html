Persiapan Tools MySQL

Langkah pertama sebelum praktik

1

Download dan Install XAMPP

XAMPP adalah paket software yang berisi Apache (web server), MySQL (database), PHP (bahasa pemrograman), dan phpMyAdmin (interface web untuk MySQL).

Langkah Install XAMPP:

  1. Kunjungi apachefriends.org (website resmi XAMPP)
  2. Download XAMPP sesuai sistem operasi (Windows/Mac/Linux)
  3. Jalankan file installer yang sudah didownload
  4. Ikuti wizard instalasi (pilih komponen: Apache, MySQL, PHP, phpMyAdmin)
  5. Pilih folder instalasi (default: C:\xampp di Windows)
  6. Tunggu proses instalasi selesai

💡 Tips: Pastikan antivirus tidak memblokir XAMPP selama instalasi

2

Menjalankan XAMPP

Setelah install, buka XAMPP Control Panel dan start service berikut:

Cara Menjalankan:

  1. Buka XAMPP Control Panel (cari di Start Menu Windows)
  2. Klik tombol "Start" pada baris Apache
  3. Klik tombol "Start" pada baris MySQL
  4. Tunggu hingga status berubah menjadi hijau dan running
  • Apache - Web server untuk menjalankan phpMyAdmin (Port 80)
  • MySQL - Database server untuk menyimpan data (Port 3306)

⚠️ Troubleshooting: Jika port 80 atau 3306 sudah digunakan, ubah port di Config atau matikan aplikasi yang menggunakan port tersebut

3

Akses MySQL Shell

Setelah MySQL running, buka Command Prompt (CMD) atau Terminal untuk mengakses MySQL shell:

Cara Membuka MySQL Shell:

  1. Buka Command Prompt (Windows + R, ketik "cmd", Enter)
  2. Navigasi ke folder MySQL XAMPP:
Command Prompt
cd C:\xampp\mysql\bin

Login ke MySQL:

Ketik perintah berikut untuk masuk ke MySQL:

MySQL Login
mysql -u root -p

💡 Default Login: Username: root, Password: (kosong - langsung tekan Enter)

Jika berhasil, akan muncul prompt: mysql>

Alternatif: Gunakan XAMPP Shell

  1. Buka XAMPP Control Panel
  2. Klik tombol "Shell" di sebelah kanan
  3. Ketik: mysql -u root -p
  4. Tekan Enter untuk password (kosong)

Membuat Tabel

Struktur untuk menyimpan data secara terorganisir

1

Tabel Buku

Pertama, kita buat tabel untuk menyimpan data buku:

tabel_buku.sql
CREATE TABLE buku ( id_buku INT AUTO_INCREMENT PRIMARY KEY, judul VARCHAR(200) NOT NULL, pengarang VARCHAR(100) NOT NULL, penerbit VARCHAR(100), tahun_terbit YEAR, kategori ENUM('Novel', 'Pelajaran', 'Referensi', 'Komik', 'Biografi') DEFAULT 'Pelajaran', stok INT DEFAULT 0 CHECK (stok >= 0), created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP );

Penjelasan Struktur:

  • id_buku: Nomor unik untuk setiap buku (otomatis bertambah, primary key)
  • judul: Judul buku (maksimal 200 karakter, wajib diisi)
  • pengarang: Nama pengarang (maksimal 100 karakter, wajib diisi)
  • penerbit: Nama penerbit (maksimal 100 karakter, opsional)
  • tahun_terbit: Tahun terbit buku (format YYYY)
  • kategori: Kategori buku (pilihan terbatas: Novel, Pelajaran, Referensi, Komik, Biografi)
  • stok: Jumlah buku tersedia (default 0, tidak boleh negatif)
  • created_at: Waktu pembuatan record (otomatis diisi)
2

Tabel Siswa

Selanjutnya, buat tabel untuk data siswa:

tabel_siswa.sql
CREATE TABLE siswa ( id_siswa INT AUTO_INCREMENT PRIMARY KEY, nis VARCHAR(20) UNIQUE NOT NULL, nama VARCHAR(100) NOT NULL, kelas VARCHAR(15) NOT NULL, alamat TEXT, no_hp VARCHAR(15), email VARCHAR(100), status ENUM('aktif', 'lulus', 'pindah') DEFAULT 'aktif', created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP );
3

Tabel Peminjaman

Terakhir, buat tabel untuk mencatat peminjaman:

tabel_peminjaman.sql
CREATE TABLE peminjaman ( id_pinjam INT AUTO_INCREMENT PRIMARY KEY, id_siswa INT NOT NULL, id_buku INT NOT NULL, tanggal_pinjam DATE NOT NULL DEFAULT (CURDATE()), tanggal_harus_kembali DATE NOT NULL, tanggal_kembali DATE, denda DECIMAL(10,2) DEFAULT 0, status ENUM('dipinjam', 'dikembalikan', 'terlambat') DEFAULT 'dipinjam', created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, FOREIGN KEY (id_siswa) REFERENCES siswa(id_siswa) ON DELETE CASCADE, FOREIGN KEY (id_buku) REFERENCES buku(id_buku) ON DELETE CASCADE );
4

Verifikasi Tabel yang Dibuat

Setelah membuat semua tabel, pastikan tabel berhasil dibuat:

verifikasi_tabel.sql
-- Melihat semua tabel dalam database SHOW TABLES; -- Melihat struktur tabel buku DESCRIBE buku; -- Melihat struktur tabel siswa DESCRIBE siswa; -- Melihat struktur tabel peminjaman DESCRIBE peminjaman;

Yang Harus Terlihat:

  • SHOW TABLES menampilkan: buku, siswa, peminjaman
  • DESCRIBE menampilkan struktur kolom, tipe data, dan constraint
  • Pastikan PRIMARY KEY dan FOREIGN KEY sudah benar

Penjelasan Tipe Data MySQL

INT: Angka bulat (-2 miliar hingga +2 miliar)

VARCHAR(n): Teks dengan panjang maksimal n karakter

TEXT: Teks panjang (hingga 65,535 karakter)

DECIMAL(m,d): Angka desimal (m=total digit, d=digit desimal)

TIMESTAMP: Tanggal dan waktu otomatis

DATE: Tanggal saja (YYYY-MM-DD)

YEAR: Tahun 4 digit (YYYY)

ENUM: Pilihan nilai tertentu yang sudah ditentukan

AUTO_INCREMENT: Nomor otomatis bertambah

PRIMARY KEY: Kunci utama (unik, tidak boleh kosong)

Constraint Penting:

  • • NOT NULL: Kolom wajib diisi
  • • UNIQUE: Nilai harus unik (tidak boleh sama)
  • • DEFAULT: Nilai default jika tidak diisi
  • • CHECK: Validasi kondisi tertentu
  • • FOREIGN KEY: Referensi ke tabel lain

Input Data ke Tabel

Mengisi tabel dengan data menggunakan INSERT

1

Input Data Buku

Mari input beberapa data buku ke dalam tabel:

insert_buku.sql
INSERT INTO buku (judul, pengarang, penerbit, tahun_terbit, kategori, stok) VALUES ('Laskar Pelangi', 'Andrea Hirata', 'Bentang Pustaka', 2005, 'Novel', 5), ('Bumi Manusia', 'Pramoedya Ananta Toer', 'Hasta Mitra', 1980, 'Novel', 3), ('Matematika SMK Kelas X', 'Tim Penulis', 'Erlangga', 2020, 'Pelajaran', 10);

Penjelasan Perintah INSERT:

  • INSERT INTO buku: Menentukan tabel tujuan
  • (judul, pengarang, ...): Daftar kolom yang akan diisi
  • VALUES: Kata kunci untuk menentukan nilai data
  • (...), (...): Setiap kurung adalah satu record/baris data
  • Kolom id_buku dan created_at tidak perlu diisi karena AUTO_INCREMENT dan DEFAULT

Menampilkan Data

Menggunakan SELECT untuk melihat data dalam tabel

1

SELECT Dasar

Menampilkan semua data dari tabel buku:

select_all_buku.sql
SELECT * FROM buku;

Tanda * artinya semua kolom akan ditampilkan.

2

SELECT Kolom Tertentu

Menampilkan kolom tertentu saja:

select_kolom_tertentu.sql
-- Menampilkan kolom tertentu saja SELECT judul, pengarang, stok FROM buku; -- Menampilkan nama dan kelas siswa saja SELECT nama, kelas FROM siswa;

Keuntungan SELECT Kolom Tertentu:

  • Lebih cepat karena data yang diambil lebih sedikit
  • Tampilan lebih rapi dan fokus pada data yang dibutuhkan
  • Menghemat bandwidth dan memori
3

SELECT dengan WHERE

Menampilkan data dengan kondisi tertentu:

select_with_where.sql
-- Menampilkan buku dengan kategori 'Novel' SELECT * FROM buku WHERE kategori = 'Novel'; -- Menampilkan buku dengan stok lebih dari 5 SELECT judul, pengarang, stok FROM buku WHERE stok > 5; -- Menampilkan siswa dari kelas XII RPL 1 SELECT nama, nis, no_hp FROM siswa WHERE kelas = 'XII RPL 1'; -- Mencari buku berdasarkan pengarang (menggunakan LIKE) SELECT * FROM buku WHERE pengarang LIKE '%Andrea%'; -- Menampilkan buku yang diterbitkan setelah tahun 2000 SELECT judul, tahun_terbit FROM buku WHERE tahun_terbit > 2000;
4

JOIN Tabel

Menggabungkan data dari beberapa tabel:

select_join.sql
-- Menampilkan data peminjaman lengkap SELECT s.nama AS nama_siswa, s.kelas, b.judul AS judul_buku, p.tanggal_pinjam, p.status FROM peminjaman p JOIN siswa s ON p.id_siswa = s.id_siswa JOIN buku b ON p.id_buku = b.id_buku;
5

ORDER BY dan LIMIT

Mengurutkan dan membatasi hasil query:

select_order_limit.sql
-- Mengurutkan buku berdasarkan judul A-Z SELECT * FROM buku ORDER BY judul ASC; -- Mengurutkan buku berdasarkan stok terbanyak SELECT judul, stok FROM buku ORDER BY stok DESC; -- Menampilkan 3 buku terbaru SELECT * FROM buku ORDER BY created_at DESC LIMIT 3; -- Menampilkan siswa dengan nama diurutkan A-Z SELECT nama, kelas FROM siswa ORDER BY nama ASC;
6

Fungsi COUNT dan Agregat

Menghitung jumlah data dan statistik dasar:

select_count_agregat.sql
-- Menghitung total jumlah buku SELECT COUNT(*) AS total_buku FROM buku; -- Menghitung total stok semua buku SELECT SUM(stok) AS total_stok FROM buku; -- Menghitung rata-rata stok buku SELECT AVG(stok) AS rata_rata_stok FROM buku; -- Menghitung jumlah siswa per kelas SELECT kelas, COUNT(*) AS jumlah_siswa FROM siswa GROUP BY kelas;

Fungsi Agregat Penting:

  • COUNT(*): Menghitung jumlah baris/record
  • SUM(kolom): Menjumlahkan nilai dalam kolom
  • AVG(kolom): Menghitung rata-rata nilai
  • MAX(kolom): Mencari nilai terbesar
  • MIN(kolom): Mencari nilai terkecil
  • GROUP BY: Mengelompokkan data berdasarkan kolom tertentu

Operator dan Fungsi Penting

= : Sama dengan

> : Lebih besar dari

< : Lebih kecil dari

>= : Lebih besar sama dengan

<= : Lebih kecil sama dengan

!= : Tidak sama dengan

LIKE '%text%' : Mengandung text

IN (1,2,3) : Dalam daftar nilai

BETWEEN : Antara dua nilai

ORDER BY ASC : Urut naik A-Z

ORDER BY DESC : Urut turun Z-A

LIMIT n : Batasi n record

Update Data

Mengubah data yang sudah ada dalam tabel

1

UPDATE Dasar

Mengubah stok buku tertentu:

update_stok_buku.sql
-- LANGKAH 1: Cek data sebelum diubah SELECT judul, stok FROM buku WHERE id_buku = 1; -- LANGKAH 2: Mengubah stok buku dengan id_buku = 1 UPDATE buku SET stok = 8 WHERE id_buku = 1; -- LANGKAH 3: Verifikasi perubahan SELECT judul, stok FROM buku WHERE id_buku = 1;

💡 Tips UPDATE yang Aman:

  • Selalu gunakan SELECT dulu untuk melihat data yang akan diubah
  • Pastikan WHERE clause sudah benar sebelum menjalankan UPDATE
  • Verifikasi hasil dengan SELECT setelah UPDATE
  • Jika ragu, backup data terlebih dahulu
2

UPDATE Multiple Kolom

Mengubah beberapa kolom sekaligus:

update_multiple_kolom.sql
-- Mengubah data siswa UPDATE siswa SET alamat = 'Jl. Pemuda No. 100', no_hp = '081234567999' WHERE nis = '2024001';
3

UPDATE Status Peminjaman

Mengubah status peminjaman ketika buku dikembalikan:

update_status_kembali.sql
-- Mengubah status menjadi 'dikembalikan' dan set tanggal kembali UPDATE peminjaman SET status = 'dikembalikan', tanggal_kembali = '2024-01-25' WHERE id_pinjam = 1;
4

UPDATE dengan Kondisi

Mengubah data berdasarkan kondisi tertentu:

update_dengan_kondisi.sql
-- Menambah stok semua buku kategori 'Pelajaran' sebanyak 5 UPDATE buku SET stok = stok + 5 WHERE kategori = 'Pelajaran'; -- Mengubah kelas semua siswa dari 'XII RPL 1' menjadi 'XII RPL A' UPDATE siswa SET kelas = 'XII RPL A' WHERE kelas = 'XII RPL 1';

⚠️ Peringatan Penting

  • • SELALU gunakan WHERE dalam UPDATE untuk menghindari mengubah semua data
  • • Lakukan SELECT terlebih dahulu untuk memastikan data yang akan diubah
  • • Backup data penting sebelum melakukan UPDATE besar-besaran
  • • Periksa hasil UPDATE dengan SELECT setelahnya

Hapus Data

Menghapus data dari tabel dengan perintah DELETE

1

DELETE dengan WHERE

Menghapus data tertentu berdasarkan kondisi:

delete_data_tertentu.sql
-- Menghapus buku dengan id_buku = 3 DELETE FROM buku WHERE id_buku = 3; -- Menghapus siswa dengan NIS tertentu DELETE FROM siswa WHERE nis = '2024003';
2

DELETE dengan Kondisi Multiple

Menghapus data berdasarkan beberapa kondisi:

delete_multiple_kondisi.sql
-- Menghapus buku dengan stok 0 dan kategori tertentu DELETE FROM buku WHERE stok = 0 AND kategori = 'Novel'; -- Menghapus peminjaman yang sudah dikembalikan lebih dari 1 bulan DELETE FROM peminjaman WHERE status = 'dikembalikan' AND tanggal_kembali < '2024-01-01';
3

Langkah Aman Sebelum DELETE

Selalu lakukan SELECT terlebih dahulu untuk memastikan data yang akan dihapus:

safe_delete_process.sql
-- LANGKAH 1: Cek data yang akan dihapus SELECT * FROM buku WHERE stok = 0; -- LANGKAH 2: Jika yakin, baru hapus DELETE FROM buku WHERE stok = 0; -- LANGKAH 3: Verifikasi hasil SELECT COUNT(*) FROM buku;
4

Menghapus Semua Data (TRUNCATE)

Untuk menghapus semua data dalam tabel:

truncate_table.sql
-- Menghapus semua data peminjaman (HATI-HATI!) TRUNCATE TABLE peminjaman; -- Alternatif dengan DELETE (lebih lambat tapi bisa di-rollback) DELETE FROM peminjaman;

Perbedaan TRUNCATE vs DELETE:

  • TRUNCATE: Lebih cepat, reset AUTO_INCREMENT, tidak bisa pakai WHERE
  • DELETE: Lebih lambat, bisa pakai WHERE, bisa di-rollback

🚨 PERINGATAN KERAS!

  • • JANGAN PERNAH jalankan DELETE tanpa WHERE di data production!
  • • Selalu backup database sebelum operasi DELETE besar
  • • Gunakan SELECT dulu untuk memastikan data yang akan dihapus
  • • Pertimbangkan menggunakan soft delete (menandai sebagai deleted) daripada hard delete
  • • Hati-hati dengan foreign key constraints saat menghapus data
