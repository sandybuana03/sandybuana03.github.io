Pengenalan Views

Apa itu Views? 🤔

Views adalah sebuah "jendela virtual" yang memungkinkan kita melihat data dari satu atau lebih tabel dalam database. Bayangkan Views seperti kacamata khusus yang hanya menampilkan informasi tertentu yang kita butuhkan!

Analogi Sederhana

Views seperti jendela rumah - kamu bisa melihat pemandangan di luar, tapi tidak bisa mengubah apa yang ada di luar. Views menampilkan data, tapi data asli tetap tersimpan di tabel utama.

Keamanan Data

Views membantu melindungi data sensitif. Misalnya, karyawan HR hanya bisa melihat data gaji, sedangkan karyawan IT hanya melihat data teknis.

Contoh Nyata dalam Kehidupan

🏥

Jenis-Jenis Views

Simple Views

Views yang dibuat dari satu tabel saja. Paling mudah dipahami dan digunakan.

Contoh Penggunaan:

  • • Menampilkan data siswa tanpa nomor telepon
  • • Menampilkan produk yang masih tersedia
  • • Menampilkan karyawan aktif saja
Tingkat Kesulitan:

Complex Views

Views yang dibuat dari beberapa tabel dengan JOIN, GROUP BY, atau fungsi agregat.

Contoh Penggunaan:

  • • Laporan penjualan per bulan
  • • Data siswa dengan nilai rata-rata
  • • Ringkasan stok produk per kategori
Tingkat Kesulitan:

Berdasarkan Fungsi Keamanan

🔒

Restricted Views

Membatasi akses kolom atau baris tertentu

👁️

Read-Only Views

Hanya untuk melihat, tidak bisa edit

✏️

Updatable Views

Bisa digunakan untuk update data

Berdasarkan Kompleksitas Data

Filter Views

Menampilkan data dengan kondisi tertentu (WHERE)

Aggregate Views

Menampilkan hasil perhitungan (SUM, COUNT, AVG)

Join Views

Menggabungkan data dari beberapa tabel

Sintaks Views

Membuat Views (CREATE VIEW)

-- Sintaks Dasar
CREATE VIEW nama_view AS
SELECT kolom1, kolom2, ...
FROM nama_tabel
WHERE kondisi;

Contoh Simple View:

CREATE VIEW siswa_aktif AS
SELECT nama, kelas, jurusan
FROM siswa
WHERE status = 'aktif';

Contoh Complex View:

CREATE VIEW nilai_rata AS
SELECT s.nama, AVG(n.nilai) as rata
FROM siswa s JOIN nilai n
ON s.id = n.siswa_id
GROUP BY s.nama;

Menggunakan Views (SELECT)

-- Menggunakan Views seperti tabel biasa
SELECT * FROM nama_view;
SELECT kolom FROM nama_view WHERE kondisi;

Contoh Penggunaan:

SELECT * FROM siswa_aktif; → Menampilkan semua siswa aktif
SELECT nama FROM nilai_rata WHERE rata > 80; → Siswa dengan rata-rata > 80

Mengubah Views (ALTER VIEW)

-- Mengubah definisi Views
ALTER VIEW nama_view AS
SELECT kolom_baru1, kolom_baru2
FROM tabel_baru
WHERE kondisi_baru;

Contoh: Views Awal

CREATE VIEW siswa_aktif AS
SELECT nama, kelas
FROM siswa
WHERE status = 'aktif';

Contoh: Mengubah Views

ALTER VIEW siswa_aktif AS
SELECT nama, kelas, jurusan, tanggal_lahir
FROM siswa
WHERE status = 'aktif';

Contoh Kasus Nyata:

Situasi: Awalnya Views hanya menampilkan nama dan kelas, tapi sekarang butuh tambahan kolom jurusan
ALTER VIEW siswa_aktif AS SELECT nama, kelas, jurusan FROM siswa WHERE status = 'aktif';
Hasil: Views sekarang menampilkan 3 kolom: nama, kelas, dan jurusan
!

Penting Diingat:

ALTER VIEW akan mengganti seluruh definisi Views. Pastikan sintaks baru sudah benar dan tidak ada aplikasi yang bergantung pada struktur Views lama!

Menghapus Views (DROP VIEW)

-- Menghapus Views
DROP VIEW nama_view;
-- Menghapus jika Views ada
DROP VIEW IF EXISTS nama_view;

Contoh: Menghapus Views Tunggal

-- Menghapus Views siswa_aktif
DROP VIEW siswa_aktif;

-- Cek apakah berhasil dihapus
SHOW TABLES;

Contoh: Menghapus Multiple Views

-- Menghapus beberapa Views sekaligus
DROP VIEW IF EXISTS siswa_rpl, laporan_nilai, statistik_siswa;

Contoh Kasus Praktis:

Situasi 1: Views tidak digunakan lagi
DROP VIEW views_lama;
Situasi 2: Cleanup Views sementara
DROP VIEW IF EXISTS temp_view1, temp_view2, temp_view3;
Situasi 3: Sebelum membuat ulang Views
DROP VIEW IF EXISTS siswa_aktif;
CREATE VIEW siswa_aktif AS SELECT ...;

Langkah Aman Sebelum DROP VIEW:

  1. 1 Cek apakah ada aplikasi yang menggunakan Views tersebut
  2. 2 Backup definisi Views dengan SHOW CREATE VIEW nama_view;
  3. 3 Gunakan IF EXISTS untuk menghindari error
⚠

Hati-hati!

DROP VIEW akan menghapus Views secara permanen. Pastikan tidak ada aplikasi yang masih menggunakannya dan selalu backup definisi Views sebelum menghapus!

Tips Menulis Sintaks Views

Gunakan nama Views yang deskriptif
Tambahkan komentar untuk Views kompleks
Test query sebelum membuat Views
Jangan gunakan SELECT * untuk Views
Hindari Views yang terlalu kompleks
Jangan buat Views dari Views lain

Keuntungan Views

Keamanan Data

  • Menyembunyikan Data Sensitif

    Kolom seperti password atau gaji bisa disembunyikan

  • Kontrol Akses Pengguna

    Setiap user hanya melihat data yang diizinkan

  • Menyembunyikan Struktur Tabel

    User tidak perlu tahu struktur database asli

Kemudahan Penggunaan

  • Menyederhanakan Query Kompleks

    Query panjang jadi satu nama Views saja

  • Dapat Digunakan Berulang

    Sekali buat, bisa dipakai berkali-kali

  • Seperti Tabel Virtual

    Bisa di-SELECT, JOIN, bahkan di-UPDATE

Performa & Efisiensi

  • Tidak Menyimpan Data Duplikat

    Menghemat ruang penyimpanan database

  • Selalu Data Terbaru

    Otomatis update saat tabel asli berubah

  • Optimasi Query

    Database bisa mengoptimalkan Views secara otomatis

Maintenance & Development

  • Konsistensi Logika Bisnis

    Aturan bisnis terpusat dalam Views

  • Mudah Maintenance

    Ubah Views tanpa mengubah aplikasi

  • Kolaborasi Tim

    Developer bisa fokus pada logika aplikasi

Praktik Views Database

Mari praktik langsung membuat dan menggunakan Views!

Langkah 1: Persiapan Database

Buat Database dan Tabel Sample

-- Membuat database
CREATE DATABASE sekolah_db;
USE sekolah_db;
-- Membuat tabel siswa
CREATE TABLE siswa (
  id INT PRIMARY KEY AUTO_INCREMENT,
  nama VARCHAR(100),
  kelas VARCHAR(10),
  jurusan VARCHAR(50),
  status ENUM('aktif', 'nonaktif'),
  tanggal_lahir DATE
);

Insert Data Sample

INSERT INTO siswa VALUES
(1, 'Ahmad Rizki', 'XII', 'RPL', 'aktif', '2005-03-15'),
(2, 'Siti Nurhaliza', 'XI', 'TKJ', 'aktif', '2006-07-22'),
(3, 'Budi Santoso', 'X', 'MM', 'nonaktif', '2007-01-10'),
(4, 'Dewi Sartika', 'XII', 'RPL', 'aktif', '2005-11-08'),
(5, 'Eko Prasetyo', 'XI', 'TKJ', 'aktif', '2006-09-30');

Langkah 2: Membuat Simple View

🎯 Tujuan: Buat Views untuk siswa aktif saja

-- Membuat Views siswa aktif
CREATE VIEW siswa_aktif AS
SELECT id, nama, kelas, jurusan
FROM siswa
WHERE status = 'aktif';

✅ Test Views yang sudah dibuat

SELECT * FROM siswa_aktif;

Hasil yang diharapkan: Hanya menampilkan 4 siswa dengan status aktif (Ahmad, Siti, Dewi, Eko)

Langkah 3: Membuat Views dengan Filter

🎯 Tujuan: Buat Views untuk siswa jurusan RPL

-- Views siswa jurusan RPL
CREATE VIEW siswa_rpl AS
SELECT nama, kelas,
  YEAR(CURDATE()) - YEAR(tanggal_lahir) AS umur
FROM siswa
WHERE jurusan = 'RPL' AND status = 'aktif';

✅ Test dan analisis hasil

SELECT * FROM siswa_rpl;
-- Coba filter lebih lanjut
SELECT * FROM siswa_rpl WHERE kelas = 'XII';

Langkah 4: Buat Tabel Nilai dan Complex View

Buat tabel nilai terlebih dahulu

CREATE TABLE nilai (
  id INT PRIMARY KEY AUTO_INCREMENT,
  siswa_id INT,
  mata_pelajaran VARCHAR(50),
  nilai DECIMAL(5,2),
  FOREIGN KEY (siswa_id) REFERENCES siswa(id)
);
-- Insert data nilai
INSERT INTO nilai VALUES
(1, 1, 'Pemrograman Web', 85.5),
(2, 1, 'Database', 90.0),
(3, 2, 'Jaringan', 78.5),
(4, 2, 'Sistem Operasi', 82.0),
(5, 4, 'Pemrograman Web', 88.0);

🎯 Buat Complex View dengan JOIN

-- Views laporan nilai siswa
CREATE VIEW laporan_nilai AS
SELECT
  s.nama,
  s.kelas,
  s.jurusan,
  n.mata_pelajaran,
  n.nilai,
  CASE
    WHEN n.nilai >= 85 THEN 'A'
    WHEN n.nilai >= 75 THEN 'B'
    WHEN n.nilai >= 65 THEN 'C'
    ELSE 'D'
  END AS grade
FROM siswa s
JOIN nilai n ON s.id = n.siswa_id
WHERE s.status = 'aktif';

Langkah 5: Views dengan Agregasi

🎯 Buat Views untuk statistik nilai

-- Views statistik nilai per siswa
CREATE VIEW statistik_siswa AS
SELECT
  s.nama,
  s.kelas,
  COUNT(n.nilai) AS jumlah_mapel,
  AVG(n.nilai) AS rata_rata,
  MAX(n.nilai) AS nilai_tertinggi,
  MIN(n.nilai) AS nilai_terendah
FROM siswa s
LEFT JOIN nilai n ON s.id = n.siswa_id
WHERE s.status = 'aktif'
GROUP BY s.id, s.nama, s.kelas;

✅ Test semua Views yang sudah dibuat

SELECT * FROM laporan_nilai;

→ Lihat semua nilai dengan grade

SELECT * FROM statistik_siswa;

→ Lihat statistik per siswa

SELECT nama FROM statistik_siswa WHERE rata_rata > 80;

→ Siswa dengan rata-rata > 80

Langkah 6: Mengelola Views

Melihat semua Views yang ada

SHOW TABLES;
-- atau khusus Views saja
SELECT TABLE_NAME FROM information_schema.VIEWS
WHERE TABLE_SCHEMA = 'sekolah_db';

Mengubah dan menghapus Views

-- Mengubah Views
ALTER VIEW siswa_aktif AS
SELECT id, nama, kelas, jurusan, tanggal_lahir
FROM siswa
WHERE status = 'aktif';
