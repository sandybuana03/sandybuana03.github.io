📚 Pengenalan Model Basis Data

🤖 Apa itu Model Basis Data?

Model basis data adalah cara atau struktur untuk mengorganisir dan menyimpan data dalam database. Bayangkan seperti cara kita mengatur buku di perpustakaan - ada yang diatur berdasarkan subjek, ada yang berdasarkan abjad, atau berdasarkan tahun terbit.

🏗️ Analogi Sederhana

• Berapa kamar yang dibutuhkan?

• Bagaimana cara mengakses setiap ruangan?

🏗️ Evolusi Model Basis Data

📅

1960-an: Era Hierarkis & Jaringan

IBM mengembangkan IMS (Information Management System) dengan model hierarkis. Kemudian muncul model jaringan yang lebih fleksibel.

🚀

1970-an: Revolusi Relasional

Dr. Edgar F. Codd memperkenalkan model relasional yang mengubah dunia database. SQL lahir dan menjadi standar hingga sekarang!

🎯

1980-an: Era Object-Oriented

Seiring berkembangnya pemrograman berorientasi objek, muncul database yang mendukung konsep OOP.

☁️

2000-an: Era NoSQL & Cloud

Big Data membutuhkan solusi baru. Muncul NoSQL, NewSQL, dan database cloud yang scalable.

🌳 Model Hierarkis

🌲 Apa itu Model Hierarkis?

Model hierarkis mengorganisir data seperti pohon keluarga atau struktur organisasi perusahaan. Ada satu "induk" di atas, dan di bawahnya ada "anak-anak" yang bercabang.

🏗️ Karakteristik Model Hierarkis

✅ Aturan Dasar:

  • • Setiap node hanya punya SATU parent
  • • Satu root node di puncak
  • • Hubungan one-to-many saja
  • • Tidak boleh ada siklus

📚 Istilah Penting:

  • • Root: Node paling atas
  • • Parent: Node induk
  • • Child: Node anak
  • • Leaf: Node tanpa anak
  • • Level: Tingkatan dalam pohon

🕸️ Model Jaringan

🌐 Apa itu Model Jaringan?

Model jaringan seperti jaring laba-laba atau peta jalan kota. Setiap titik bisa terhubung dengan banyak titik lainnya. Tidak seperti pohon yang hanya punya satu induk, di sini satu "anak" bisa punya banyak "induk"!

🔗 Karakteristik Model Jaringan

🌟 Keunggulan Struktur:

  • • Mendukung hubungan Many-to-Many
  • • Satu record bisa punya banyak parent
  • • Lebih fleksibel dari hierarkis
  • • Mirip dengan dunia nyata

⚙️ Cara Kerja:

  • • Menggunakan Set dan pointer
  • • Set = kumpulan record sejenis
  • • Pointer = penunjuk ke record lain
  • • Navigasi mengikuti pointer

🏫 Contoh Nyata: Sistem Universitas

Bayangkan sistem universitas yang kompleks:

👨‍🎓 Mahasiswa

• Bisa ambil banyak mata kuliah

• Bisa ikut banyak organisasi

📚 Mata Kuliah

• Diambil banyak mahasiswa

• Diajar banyak dosen

👨‍🏫 Dosen

• Mengajar banyak mata kuliah

• Membimbing banyak mahasiswa

📊 Model Relasional

📋 Apa itu Model Relasional?

Model relasional seperti tabel Excel yang saling terhubung! Data disimpan dalam bentuk tabel dengan baris dan kolom. Setiap tabel punya kunci untuk menghubungkan dengan tabel lain. Ini adalah model yang paling populer saat ini!

🏗️ Konsep Dasar Struktur

📊 Komponen Tabel:

  • • Table: Kumpulan data sejenis
  • • Row/Record: Satu baris data
  • • Column/Field: Satu kolom atribut
  • • Cell: Perpotongan baris & kolom

🔑 Jenis-jenis Kunci:

  • • Primary Key: Kunci utama unik
  • • Foreign Key: Kunci asing penghubung
  • • Composite Key: Gabungan beberapa field
  • • Candidate Key: Calon primary key

📐 Aturan Normalisasi (Penyederhanaan)

1NF (First Normal Form)

• Setiap cell hanya satu nilai

• Tidak ada data berulang

• Setiap baris unik

2NF (Second Normal Form)

• Sudah memenuhi 1NF

• Tidak ada partial dependency

• Semua field tergantung penuh pada primary key

3NF (Third Normal Form)

• Sudah memenuhi 2NF

• Tidak ada transitive dependency

• Field non-key tidak saling bergantung

🎯 Model Berorientasi Objek

🎮 Apa itu Model Berorientasi Objek?

Model ini seperti game RPG! Setiap data adalah "objek" yang punya karakteristik (atribut) dan kemampuan (method). Misalnya, objek "Mobil" punya warna, merk, tahun (atribut) dan bisa jalan, rem, klakson (method).

🎯 Konsep Dasar OOP

📦 Encapsulation

Data dan method dibungkus jadi satu. Seperti kapsul obat yang melindungi isinya!

🧬 Inheritance

Anak mewarisi sifat orangtua. Class anak dapat atribut & method dari class parent!

🎭 Polymorphism

Satu method, banyak bentuk. Method yang sama bisa berperilaku berbeda!

👨‍👩‍👧‍👦 Penjelasan Inheritance dengan Analogi Keluarga

Inheritance seperti pewarisan dalam keluarga! Anak mewarisi ciri-ciri orangtua, tapi juga bisa punya ciri unik sendiri.

👨 Parent Class: "Manusia"

Atribut: nama, umur, tinggi, berat

Method: makan(), tidur(), berjalan()

👨‍🎓 Child Class: "Mahasiswa"

Warisan: semua dari "Manusia"

Tambahan: nim, jurusan, belajar(), ujian()
