Pengenalan XAMPP & MySQL

🖥️ Apa itu XAMPP?

XAMPP adalah paket software gratis yang berisi:

  • ❌X - Cross Platform
  • 🅰️A - Apache Web Server
  • 🐘M - MySQL Database
  • 🐍P - PHP Programming
  • 💎P - Perl Programming

🗄️ Apa itu MySQL?

MySQL adalah sistem manajemen database yang:

  • 💾Menyimpan data terstruktur
  • ⚡Cepat dan efisien
  • 🔒Aman dan terpercaya
  • 🆓Gratis untuk digunakan

Instalasi XAMPP

📥 Langkah 1: Download XAMPP

Kunjungi website resmi XAMPP:

https://www.apachefriends.org
🪟

Windows

File .exe

🍎

macOS

File .dmg

🐧

Linux

File .run

🔧 Langkah 2: Proses Instalasi

1

Jalankan File Installer

Klik kanan → "Run as Administrator" (Windows)

2

Pilih Komponen

Pastikan Apache, MySQL, PHP, dan phpMyAdmin tercentang

3

Tentukan Folder Instalasi

Default: C:\xampp (Windows) atau /Applications/XAMPP (Mac)

4

Tunggu Proses Selesai

Biasanya memakan waktu 5-10 menit

🚀 Langkah 3: Menjalankan XAMPP

Buka XAMPP Control Panel dan start service:

✅ Apache

Web server untuk menjalankan website

✅ MySQL

Database server untuk menyimpan data

🎛️ Mengenal XAMPP Control Panel

Panel Utama XAMPP:

🌐
Apache

Web server untuk menjalankan website PHP

Port: 80, 443

🗄️
MySQL

Database server untuk menyimpan data

Port: 3306

Tombol-tombol Penting:

Start

Klik untuk menjalankan service. Warna hijau = aktif! 🟢

Stop

Klik untuk menghentikan service. Warna merah = tidak aktif. 🔴

Config

Untuk mengatur konfigurasi service (advanced). ⚙️

🔧 Troubleshooting Umum

❌

Port 80 sudah digunakan

Apache tidak bisa start karena port 80 dipakai aplikasi lain

Solusi: Matikan Skype, IIS, atau aplikasi web server lain

❌

MySQL tidak start

Port 3306 bentrok atau service MySQL lain aktif

Solusi: Matikan MySQL service lain di Windows Services

⚠️

Antivirus memblokir

Antivirus menganggap XAMPP sebagai ancaman

Solusi: Tambahkan folder C:\xampp ke whitelist antivirus

🗄️

Cara Akses MySQL

🌐 Metode 1: Menggunakan phpMyAdmin

1. Pastikan Apache & MySQL Aktif

Di XAMPP Control Panel, pastikan kedua service berwarna hijau (Running)

2. Buka Browser

Ketik alamat berikut di address bar:

http://localhost/phpmyadmin

3. Login ke phpMyAdmin

Username:

root

Password:

(kosong/tidak diisi)

💡 Tip: Untuk keamanan, sebaiknya set password setelah instalasi

💻 Metode 2: Menggunakan Command Line

1. Buka Command Prompt/Terminal

Navigasi ke folder MySQL:

# Windows
cd C:\xampp\mysql\bin

# Mac/Linux
cd /Applications/XAMPP/xamppfiles/bin

2. Login ke MySQL

mysql -u root -p

💡 Jika password kosong, tekan Enter saja

3. Keluar dari MySQL

exit;

🔧 Metode 3: Menggunakan MySQL Workbench (Opsional)

1. Download MySQL Workbench

https://dev.mysql.com/downloads/workbench/

2. Koneksi ke XAMPP MySQL

Hostname:

localhost

Port:

3306

Username:

root

Password:

(kosong)
