Pengenalan DBMS

Mari berkenalan dengan Database Management System!

🗃️ Apa itu Database?

Database adalah kumpulan data yang terorganisir dan tersimpan secara sistematis dalam komputer. Bayangkan seperti lemari arsip digital yang sangat rapi dan teratur!

💡 Contoh: Data siswa di sekolah, data produk di toko online, data lagu di Spotify

⚙️ Apa itu DBMS?

DBMS (Database Management System) adalah software yang digunakan untuk mengelola database. Seperti manajer yang mengatur semua data agar mudah dicari, disimpan, dan digunakan.

🔍 Fungsi Utama:

  • • Menyimpan data
  • • Mengambil data
  • • Mengubah data
  • • Menghapus data

🛡️ Keamanan:

  • • Kontrol akses
  • • Backup data
  • • Recovery data
  • • Enkripsi

Konsep Dasar Database

Memahami istilah-istilah penting dalam database

📋 Tabel (Table)

Tabel adalah struktur dasar dalam database yang menyimpan data dalam bentuk baris dan kolom, seperti tabel Excel.

Contoh Tabel Siswa:

ID Nama Kelas Umur
001 Andi XII RPL 17
002 Sari XII TKJ 18

📊 Field/Kolom

Field adalah kolom dalam tabel yang menyimpan jenis data tertentu.

Contoh: Nama, Kelas, Umur

📝 Record/Baris

Record adalah baris dalam tabel yang berisi data lengkap satu item.

Contoh: Data lengkap satu siswa

🔑 Primary Key

Primary Key adalah field yang unik untuk setiap record, seperti nomor ID yang tidak boleh sama.

Karakteristik Primary Key:

  • • Unik (tidak boleh sama)
  • • Tidak boleh kosong (NULL)
  • • Tidak berubah-ubah
  • • Mengidentifikasi setiap record

🔗 Relasi Antar Tabel

Tabel-tabel dalam database bisa saling berhubungan untuk menghindari duplikasi data.

1️⃣➡️1️⃣

One to One

1️⃣➡️🔢

Many to Many

Banyak ke banyak

Jenis-jenis DBMS

Mengenal berbagai macam sistem manajemen database

🗂️ Relational DBMS (RDBMS)

RDBMS menyimpan data dalam bentuk tabel yang saling berhubungan. Ini adalah jenis DBMS yang paling populer!

✨ Keunggulan:

  • • Data terstruktur rapi
  • • Mudah dipahami
  • • Standar SQL
  • • Konsistensi data terjaga

🏢 Contoh RDBMS:

  • • Oracle Database
  • • Microsoft SQL Server

🤔 Kapan Menggunakan Yang Mana?

🗂️ Gunakan RDBMS jika:

  • • Data terstruktur (tabel)
  • • Butuh konsistensi tinggi
  • • Transaksi kompleks
  • • Aplikasi bisnis tradisional

📄 Gunakan NoSQL jika:

  • • Data tidak terstruktur
  • • Butuh skalabilitas tinggi
  • • Data besar (Big Data)
  • • Aplikasi real-time

Komponen DBMS

Bagian-bagian penting dalam sistem manajemen database

🗄️ Database Engine

Inti dari DBMS yang bertugas menyimpan, mengambil, dan memproses data. Seperti mesin mobil yang menggerakkan semua komponen.

🔧 Fungsi Database Engine:

  • • Mengeksekusi query
  • • Mengelola memori
  • • Mengoptimalkan performa
  • • Menangani transaksi
  • • Backup & recovery

SQL Dasar

Structured Query Language - Bahasa untuk berkomunikasi dengan database

🔍 SELECT - Mengambil Data

Perintah SELECT digunakan untuk mengambil data dari tabel. Ini adalah perintah yang paling sering digunakan!

💡 Contoh Penggunaan:

SELECT * FROM siswa;

Mengambil semua data dari tabel siswa

SELECT nama, kelas FROM siswa;

Mengambil hanya kolom nama dan kelas

SELECT * FROM siswa WHERE kelas = 'XII RPL';

Mengambil siswa yang kelasnya XII RPL

➕ INSERT - Menambah Data

Perintah INSERT digunakan untuk menambahkan data baru ke dalam tabel.

💡 Contoh Penggunaan:

INSERT INTO siswa (nama, kelas, umur)

VALUES ('Budi', 'XII TKJ', 17);

Menambahkan siswa baru bernama Budi

✏️ UPDATE - Mengubah Data

Perintah UPDATE digunakan untuk mengubah data yang sudah ada dalam tabel.

💡 Contoh Penggunaan:

UPDATE siswa

SET kelas = 'XII MM'

WHERE nama = 'Budi';

Mengubah kelas Budi menjadi XII MM

🗑️ DELETE - Menghapus Data

Perintah DELETE digunakan untuk menghapus data dari tabel. Hati-hati menggunakannya!

💡 Contoh Penggunaan:

DELETE FROM siswa

WHERE nama = 'Budi';

Menghapus data siswa bernama Budi

⚠️ Peringatan: Selalu gunakan WHERE clause agar tidak menghapus semua data!

Tugas Pembelajaran

Uji pemahamanmu tentang DBMS dengan tugas-tugas berikut

1️⃣ Analisis Kebutuhan Database

Bayangkan kamu diminta membuat sistem database untuk perpustakaan sekolah. Jelaskan:

  • a) Tabel apa saja yang dibutuhkan? (minimal 3 tabel)
  • b) Field apa saja dalam setiap tabel?
  • c) Tentukan primary key untuk setiap tabel
  • d) Bagaimana relasi antar tabel tersebut?

2️⃣ Perbandingan DBMS

Buatlah tabel perbandingan antara RDBMS dan NoSQL berdasarkan kriteria berikut:

  • • Struktur data
  • • Skalabilitas
  • • Konsistensi data
  • • Contoh penggunaan
  • • Kelebihan dan kekurangan masing-masing

3️⃣ Praktik SQL

Berdasarkan tabel siswa berikut, tulis perintah SQL untuk:

id nama kelas nilai
1 Andi XII RPL 85
2 Sari XII TKJ 90
  • a) Menampilkan semua siswa kelas XII RPL
  • b) Menampilkan nama siswa yang nilainya di atas 80
  • c) Mengubah nilai Andi menjadi 88
  • d) Menambah siswa baru: Budi, XII MM, nilai 75

4️⃣ Studi Kasus

Sebuah toko online mengalami masalah: data produk sering hilang saat banyak customer berbelanja bersamaan. Jelaskan:

  • a) Apa kemungkinan penyebab masalah ini?
  • b) Komponen DBMS mana yang berperan mengatasi masalah ini?
  • c) Solusi apa yang bisa diterapkan?
  • d) Bagaimana cara mencegah masalah serupa di masa depan?
